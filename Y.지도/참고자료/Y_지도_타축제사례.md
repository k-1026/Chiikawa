# 지도 관련 타 축제 사례 (오시는 길·주차·셔틀·배치도)

> 다른 축제 공식 홈페이지에서 **지도·교통 관련으로 어떤 항목을 안내하는지** 모은 참고 자료. 우리 축제 대입은 하지 않음 (대입은 Y_축제전체_지도.md 등에서).
> 조사일: 2026-11-19 · 조사 범위: 각 축제 2026년 공식 홈페이지
> 근거 라벨: 표의 사례는 모두 `[확인]` 해당 공식 홈페이지 (출처는 맨 아래). 대구 치맥페스티벌은 **우리와 같은 두류공원**에서 열림.

## A. 오시는 길 (대중교통)

| 항목 | 실제 사례 |
|---|---|
| 행사장 주소 + 내비 주소·주소 복사 버튼 | [치맥] "네비게이션 주소 / 주소 복사하기" |
| 지도 앱 바로가기 (카카오·네이버 지도, 길찾기, 로드뷰) | [진주] 카카오·네이버 지도 바로보기 / [안동] 로드뷰·길찾기·지도 크게 보기 |
| 지하철: 역 이름 + 출구 번호 + 도보 시간 | [치맥] 2호선 두류역 ⑨~⑭번 출구 / [떡볶이] 3호선 북구청역 4번 출구 도보 9분 (지도에 걸어가는 길 표시) |
| 시내버스: 정류장 이름 + 노선 번호 | [치맥] 길(가로명)별 정류소·노선 표 / [떡볶이] 지도 위에 정류장 위치와 노선 표시 |
| 축제 전용 버스 표시 | [진주] "축제장 가는 버스" 안내판을 붙인 시내버스 (58개 노선) |
| 기차: 역별로 버스·지하철 갈아타는 법 | [떡볶이] 동대구역·서대구역·대구역마다 따로 안내 |
| 고속·시외버스 터미널 → 행사장 | [떡볶이] 동대구터미널·서부정류장·북부정류장마다 승차·하차 정류장 안내 |
| 막차 시간, 연장 운행 여부 | [치맥] 도시철도 방면별 평시 막차·연장 운행 / [진주] "막차시간을 꼭 확인" |
| 시내버스 늘려서 운행 (증회) | [치맥] "시내 버스 증회 운행" 항목 (당시 "미정"으로 표기) |
| 수요응답형 버스(DRT)·관광 택시 | [진주] 하모콜버스 축제장 순환 (4대, 20분 간격, 정류장 5곳, 요금) / [김천] 소풍택시(관광 DRT) |
| 다른 도시에서 오는 직행 셔틀 (사전 예약) | [김천] 카카오 T 직행 셔틀 (서울·대전·대구·광주·부산) / [진주] 카카오T 셔틀 예약 링크 |
| 먼 지역에서 오는 길 별도 페이지 | [안동] "안동으로 오시는 길 자세히 보기" |
