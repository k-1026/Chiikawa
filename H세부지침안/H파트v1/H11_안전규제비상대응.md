# H-11 안전 규제·비상 대응 — 세부 지침

> 구분: 고정 · 기본 지침: 9장, 10장 · 진행: 초안 v1 (대피 경로·기관 위치는 지도 갱신 후) · 최종 수정: 2026-11-18
> 기준 문서: 재난 및 안전관리 기본법 제66조의11·제66조의12, 같은 법 시행령 제73조의9, 행정안전부 「지역축제장 안전관리 매뉴얼」(2024.9, B-8 인용), P0-3·P0-5, 담당자 결정 2026-11-18 (5·15번)
> ⚠️ 법령 내용은 2026-11-18 조사 기준 요약이다. 안전관리계획을 쓰기 전에 국가법령정보센터에서 최신 조문을 다시 확인한다.

## 1. 이 파트의 역할

- 축제가 **법적으로 지켜야 할 의무**와 **현장에서 지켜야 할 규제**를 한곳에 모은다.
- **비상 대응**(화재·지진·정전·강풍·응급·미아·인파 밀집)과 **비상 연락 체계**를 정한다.
- 운영 중 판단(폭염·우천·혼잡)은 H-4, 기관 확인 목록은 H-5다. H-11은 "꼭 지킬 것"과 "일이 터졌을 때"를 맡는다.
- 읽는 파트: 전체 (특히 A·B·E 무대·부스), H-2(인력), H-3(기한), H-4, H-5

## 2. 확정 값

### 2-1. 재난안전법 — 지역축제 안전관리 의무

**우리 축제가 대상인가**

| 기준 (시행령 제73조의9 제1항) | 우리 축제 | 판단 |
| --- | --- | --- |
| 축제 기간 중 **순간 최대 관람객 1천 명 이상** 예상 | 메인 무대 고정석만 1,080석 (P0-3 `[확인]`) | 해당 가능성 높음 `[해석]` |
| 불, 폭죽, 석유류, **가연성 가스** 등 폭발성 물질 사용 | 포장마차 화기·LPG 사용 (B-8) | 해당 `[해석]` |

- 둘 중 하나만 맞아도 대상이다 `[확인]`. 최종 판단은 관할 구청이 한다 (H-5 1번).

**누가 계획을 세우나** (법 제66조의11)

- 중앙행정기관장이나 지방자치단체장이 여는 축제는 **스스로** 안전관리계획을 세우고 조치한다 (제1항) `[확인]`.
- 그 밖의 자가 여는 축제는 계획을 세워 **관할 시장·군수·구청장에게 미리 알린다**. 바꿀 때도 같다 (제3항) `[확인]`.
- 우리 축제는 주최 유형이 연도별 입력값이다 (P0-5). 주최가 정해지면 둘 중 어느 쪽인지 적는다.

**기한·절차** (시행령 제73조의9)

| 항목 | 내용 |
| --- | --- |
| 제출 기한 | 축제 개최일 **3주 전**까지 관할 구청에 제출 `[확인]` |
| 변경 제출 | 개최일 **7일 전**까지 `[확인]` |
| 사전 의견 | 계획을 세울 때 관할 지자체, **소방서·경찰서** 등 안전관리 유관기관의 의견을 먼저 듣는다 `[확인]` |
| 보완 요구 | 통보를 받은 구청장은 보완을 요구할 수 있다 (법 제66조의11 제4항) `[확인]` |
| 협조 요청 | 경찰·소방 등에 협조나 역할 분담을 요청할 수 있다 (제5항) `[확인]` |

**안전관리계획에 꼭 들어가는 것** (시행령 제73조의9)

| # | 항목 | H파트에서 채우는 곳 |
| --- | --- | --- |
| 1 | 지역축제의 개요 | P0-1, P0-3, P0-4 |
| 2 | 축제 장소·시설을 관리하는 사람, 관리 조직과 임무 | H-2, 2-4 |
| 3 | 화재 예방과 인명 피해 방지 조치 | B-8, 2-2, 2-3 |
| 4 | 안전관리 인력 확보·배치 계획 | H-2 |
| 5 | 비상시 대응 요령, 담당 기관·담당자 연락처 | 2-3, 2-4 |

**다중운집 예방조치** (법 제66조의12, 요약)

- 지자체장은 다중운집 우려 장소에 실태조사·긴급안전점검을 하고, 위험이 크면 행사 주최자에게 **안전조치를 명할 수 있다** `[확인]`.
- 안전조치 명령을 이행하지 않으면 3년 이하 징역 또는 3천만 원 이하 벌금 (제78조의3) `[확인]`.
- 질서 유지와 안전 확보가 어렵다고 판단되면 행사 중단·해산을 권고할 수 있다 `[확인]`.

### 2-3. 비상 대응

> 대피 경로·집결지는 **지도 업데이트 후** 넣는다 (담당자 결정 15번). 공식 출입로가 **1곳**뿐이라(P0-3) 비상 대피 때 바리게이트 ⑴⑵⑶을 여는 방안을 지도와 함께 정한다 (제안, 7장 2번).

| 상황 | 첫 조치 (제안 — 안전관리 전문가 검토 필요) | 담당 |
| --- | --- | --- |
| 화재 | 해당 부스 화기 차단, 소화기 초기 진화, 119 신고, 주변 부스·관객 대피 안내 | 안전요원, 비상 연락 담당 |
| 지진 | 무대·천막·구조물에서 떨어지게 안내, 흔들림이 멈춘 뒤 넓은 공간(집결지)으로 이동 | 안전요원, 무대 진행자 |
| 정전 | 무대 진행 중단 안내, 조명 없는 구역 이동 통제, 발전기·비상 조명 확인 | 운영 총괄, 시설 담당 |
| 강풍·낙뢰 | 천막·무대 구조물 점검, H-4 2-2 판단(담당자 + 현장 운영자) | 운영 총괄 |
| 응급 환자 (온열질환 포함) | 의료실 연결, 필요 시 119, 구급차 위치 안내 | 의료 인력 |
| 미아 | 운영본부 보호, 안내 방송, 보호자 확인 | 운영본부 |
| 인파 밀집 | 입장 일시 통제, 줄 분산, 퇴장 동선 개방 | 안전요원, H-4 |

- 국민행동요령(행정안전부) 원문을 확인해 각 칸을 고친다 (7장 3번).
- 무대 진행자용 비상 안내 멘트를 A-9 진행 대본에 넣도록 요청한다.

### 2-4. 비상 연락 체계

| 항목 | 내용 |
| --- | --- |
| 비상 연락망 | 운영 총괄 → 안전 책임자 → 구역별 담당(운영 부스·메인 구역·공원순환로·식사존) → 부스. 연락처는 운영안 부록 (공개본에는 넣지 않음) |
| 무전 | 운영진·안전요원 무전 채널 운영 (채널 구분은 제안: 총괄 / 안전 / 무대) |
| 외부 신고 | 119·112 신고 담당을 정해 둔다 (중복 신고·누락 방지) |
| 안내 방송 | 상황별 방송 문구(대피, 일시 중단, 미아)를 미리 써 둔다. 사투리 문구는 쓰지 않거나 표준어를 함께 쓴다 |
| 기관 위치 | 경찰·소방·구급차 대기 위치는 **지도 업데이트 후** 받는다 (담당자 결정 15번) |

## 3. 에이전트 행동 규칙

1. 법 조문·기한·벌칙은 2-1에 있는 확인값만 쓴다. 새 법적 기준을 지어내지 않는다.
2. "법적으로 문제없다", "신고 불필요" 같은 판단을 하지 않는다. H-5 목록으로 돌린다.
3. 2-3 첫 조치는 "전문가 검토 필요"를 빼지 않는다.
4. 대피 경로·집결지·기관 위치를 지도 없이 정하지 않는다.
5. 주류 판매 여부를 에이전트가 정하지 않는다.
