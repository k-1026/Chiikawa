# H-2 인력 — 세부 지침

> 구분: 고정(역할 구분·배치 규칙) + 연도별(인원수·배치표) · 기본 지침: 9장 · 진행: 초안 v2 · 최종 수정: 2026-11-18
> 기준 문서: 기본 지침 v1.1 9장 인력 구분, E-4 2-3, A-9 4장 "장비·인력 요청표", D-5, I-2, 담당자 결정 2026-11-18 (2번)

## 1. 이 파트의 역할

- 각 파트가 넘긴 **역할표**를 받아 **인원수와 일자·시간대별 배치표**를 만든다. 다른 파트는 역할과 이유만 적고 인원수는 쓰지 않는다 (E-4 2-3).
- 운영 공통 인력(운영본부, 현장 점검, 입구 계수, 스탬프 교환, 안전·의료, 비상 연락)을 정한다.
- 읽는 파트: A·B·C·D·E(역할표), H-3(시간), H-4·H-11(안전 인력), I-2(계수)

## 2. 확정 값

### 2-1. 역할 구분 6종 (기본 지침 9장)

| 구분 | 하는 일 예 |
| --- | --- |
| 총괄 | 운영 총괄, 현장 운영 책임자, 날씨·중단 판단 (H-4 2-2) |
| 프로그램 운영 | 무대 진행, 토론·골든벨 운영, 체험 부스 진행 |
| 부스 관리 | 부스 배정·현장 점검(H-7), 스탬프 교환(H-10), 굿즈 판매·정산(D-5) |
| 안전·의료 | 안전관리요원, 의료 인력, 혼잡 관리, 퇴장 유도 |
| 홍보·촬영 | 현장 촬영, 촬영 제외 요청 처리 (A-10) |
| 자원봉사 | 안내, 줄 관리, 계수, 쓰레기 분리 안내 |

### 2-2. 운영 공통 인력 (H가 직접 정하는 역할)

| 역할 | 하는 일 | 근거 |
| --- | --- | --- |
| 운영본부 상주 | 운영·안전 부스마다 같은 업무(H-6 2-1)를 한다 | H-6 |
| 현장 점검조 | 운영일마다 **최소 2회** 전 부스를 돌며 규정 위반을 점검·기록한다 (H-7 2-2) | 담당자 결정 2026-11-18 |
| 입구 계수 | 공식 출입로에서 시간대별 입장 수를 센다 (계수기 종류는 H가 정함) | I-2 2-2, I-3 |
| 스탬프 교환 | 스탬프 북 배부·완성 확인·상품 지급·기록 (H-10) | P0-1 |
| 비상 연락 담당 | 비상 연락망 유지, 무전 관리 (H-11 2-4) | H-11 |
| 심사위원 | 출점 업소·셀러 서류·시식 심사 (구성·인원은 담당자와 정함) | B-5, C-3 미확정 |

### 2-3. 배치표 규칙

- 배치표는 **날짜 × 시간대(1시간) × 장소 × 역할 × 인원**으로 만든다.
- 운영 시간: 매일 12:00 개장, 금·토 22:00 / 일 20:00 폐막 (P0-4). 설치·철거·개점 전 점검 시간대도 배치표에 넣는다 (H-3 2-3).
- 한낮(12:00~15:00) 야외 인력은 교대·휴식 간격을 적는다 (E-3 2-2 한낮 기준, H-4 폭염).
- 자원봉사자는 귀가 시각과 교통비를 배치표 옆에 적는다. 폐막 뒤 늦게 귀가하게 배치하지 않는다 `[해석]` (치맥 2019: 학생 자원봉사자 일부 새벽 3시 귀가, 교통비 5천원 지적 `[확인]`).

## 3. 에이전트 행동 규칙

1. 인원수를 지어내지 않는다. 첫해는 `[가정]` 파일·담당자 입력의 가용 인력 범위 안에서 배치하고, 없으면 "역할만, 인원 미입력"으로 낸다.
2. 다른 파트 역할표에 없는 역할을 그 파트 대신 만들지 않는다. 빠진 것 같으면 질문으로 돌려준다.
3. 한 사람을 같은 시간대 두 장소에 배치하지 않는다 (충돌 0건, 기본 지침 v2 S8 통과 기준).
4. 안전관리요원 수는 안전관리계획(H-11)과 맞춘다. 법정 기준·전문가 검토 전에는 "전문가 검토 필요"를 붙인다.
