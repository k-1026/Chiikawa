# H-10 스탬프 운영 — 세부 지침

> 구분: 고정(8칸·5개·묶음·보상 구조) + 연도별(쿠폰·추첨 상품·부대 프로그램 목록) · 기본 지침: 3장 · 진행: 초안 v2 · 최종 수정: 2026-11-18
> 기준 문서: P0-1 스탬프 구조(P세부지침안V12), A-1(A파트v5), B-6(B파트v5), C-6(C파트v3), E-2, I-3, 원본지정표, 담당자 결정 2026-11-18 (3·4번)

## 1. 이 파트의 역할

- 축제장 안 **오프라인 스탬프 북** 운영 전체를 맡는다: 배부, 도장 지급처, 완성 기준, 상품 교환, 재고, 기록.
- 담당자 결정(2026-11-18)으로 **어디서 도장을 찍을 수 있는지, 몇 개를 모아야 상품을 주는지**도 이 파일(운영안 스탬프 부분)에서 정한다.
- 도장을 주는 파트(B·C·D·E)는 **자기 부스에서 언제 도장을 찍어 주는지**만 정한다. A 사투리 콘텐츠는 도장을 주지 않는다 (2-2). 동선에서 지급처가 어디에 있는지는 M-6(flow-designer)이 그린다.
- 읽는 파트: B·C·D·E(지급처), F(인스타그램 추첨), M-6(동선), I(기록·방문객 예측), K(웹 안내)

### 2-2. 도장을 받는 곳 — 3개 묶음 (담당자 결정 2026-11-18)

| 묶음 | 받는 곳 | 받는 조건 | 이 묶음에서 받을 수 있는 최대 개수 |
| --- | --- | --- | --- |
| **① 부대 프로그램 (E)** | E파트 부대 프로그램 각각 | 프로그램마다 **참여하면 1번씩** | 그해 운영하는 E 프로그램 수만큼 (프로그램당 1개) |
| **② 먹거리·플리마켓 (B·C)** | 플리마켓 | 플리마켓 **어느 셀러든 1번 사면** | **1개** (플리마켓 전체에서) |
| | 10미 포장마차 | 10미 부스 중 **아무 곳이나 1번 사면** | **1개** (10미 전체에서) |
| | 7구 맛집거리 | 7구 부스 중 **아무 곳이나 1번 사면** | **1개** (7구 전체에서) |
| **③ 굿즈 상점 (D)** | 축제 공식 굿즈 상점 | 굿즈를 **1번 사면** | **1개** |

- 스탬프 북은 **8칸**이므로 8개를 넘게 찍을 수 없다. 묶음 ②·③에서 최대 4개, 나머지는 ① 부대 프로그램으로 채운다.
- **5개 이상이면 완성**이다. 예: 부대 프로그램 2개 + 10미 1개 + 7구 1개 + 플리마켓 1개 = 5개 → 완성 보상(2-5).
- 부대 프로그램만으로도 5개를 채울 수 있다 (E 프로그램이 5개 이상 운영될 때). 먹거리·굿즈 구매를 꼭 넣어야 하는 조건은 두지 않는다 (담당자 결정에 없는 조건을 더하지 않음).
- **A 사투리 콘텐츠(토론 투표·골든벨·뮤지컬·NPC)는 도장을 주지 않는다.** 시간이 정해진 무대 프로그램이라 방문객이 일정하게 받기 어렵기 때문이다 (담당자 결정 2026-11-18). NPC 이벤트의 보상 굿즈(A-8, D)는 스탬프와 별개로 그대로 둔다.

### 2-3. 지급 규칙

1. **같은 묶음 안의 "1개" 제한은 스탬프 북 1권 기준이다.** 10미 부스를 여러 곳 돌아도 10미 도장은 1개, 플리마켓에서 여러 번 사도 플리마켓 도장은 1개다.
2. **부대 프로그램은 프로그램마다 1개.** 같은 프로그램에 두 번 참여해도 1개다.
3. 구매·참여 없이 도장을 찍어 주지 않는다 (위반은 H-7 2-1 6번).
4. 이미 그 묶음 도장이 있으면 부스는 **찍지 않고** "이미 받으셨어요"라고 안내한다. 부스가 확인할 수 있게 스탬프 북에 **칸마다 묶음 이름**을 인쇄한다 (2-4).
5. 스탬프 북은 1인 1권. 축제 3일 동안 이어서 모을 수 있다 (제안 — 1박·재방문 유도).
6. 스탬프 북을 잃어버리면 새로 받되 이전 도장은 인정하지 않는다 (제안).
7. 도장 위조, 선착순 상품 반복 수령, 응모권 중복·대리 응모는 **참가 제한 대상**이다. 처리와 블랙리스트는 H-7 2-8을 따른다. 스탬프 북 뒷면과 응모권에 이 내용을 미리 알린다.

### 2-4. 스탬프 북과 도장 만들기

**스탬프 북 칸 배치 (제안)**

| 칸 | 인쇄할 이름 | 찍어 주는 곳 |
| --- | --- | --- |
| 1 | 10미 포장마차 | 10미 부스 중 1곳 |
| 2 | 7구 맛집거리 | 7구 부스 중 1곳 |
| 3 | 소상공인 플리마켓 | 플리마켓 셀러 중 1곳 |
| 4 | 공식 굿즈 상점 | 굿즈 상점 |
| 5~8 | 부대 프로그램 | E 프로그램 (프로그램마다 1개) |

- 칸을 묶음별로 나눠 두면 부스가 "이미 받았는지"를 바로 볼 수 있다. 부대 프로그램이 4개를 넘게 운영되면 5~8칸 안에서 아무 프로그램이나 4개까지 받는다 (8칸 상한).
- 스탬프 북 뒷면에 **완성 기준(5개 이상), 교환 장소(운영·안전 부스), 교환 시간, 선착순 상품 안내**를 인쇄하고, 아래쪽에 **인스타그램 추첨 응모권**(아이디 적는 칸, 팔로우 조건, 개인정보 수집 안내, 절취선)을 둔다 (2-5 ③). 외국인용 영어 안내는 웹(H-8)으로 연결하는 QR을 둔다 (제안).

**도장**

| 묶음 | 도장 수 | 도장 모양 |
| --- | --- | --- |
| ② 10미·7구·플리마켓 | **부스마다 1개씩** 나눠 준다 (어느 부스에서 받아도 되므로) | 같은 묶음은 같은 도장 디자인 (예: 10미 도장 1종) — 부스별로 다르게 만들지 않는다 (제안) |
| ① 부대 프로그램 | 프로그램마다 1개 | 프로그램마다 다른 디자인 |

- 도장은 H가 만들어 개점 전에 나눠 주고 축제가 끝나면 회수한다. 수량은 확정 부스·프로그램 명단(B-5, C-3, E-2 채택안)을 받은 뒤 정한다.
- 도장 디자인에 사투리 문구를 넣으면 J-3 검수, 마스코트를 넣으면 D-1 검수를 받는다.

### 2-5. 완성 보상 (담당자 결정 2026-11-18)

스탬프 북을 **5개 이상** 채워 운영·안전 부스에 가져오면 아래 세 가지를 받는다.

**① 할인 쿠폰북 — 완성한 사람 모두**

- 쿠폰북에는 **실제 후원사와 대구 관련 협업처**의 할인 쿠폰이 들어간다. 담당자가 받기로 한 협업처·후원사 리스트를 **그대로** 넣는다 (P0-1 "그해 협업처와 선정된 업소", B-4 대구 본점 프랜차이즈 후원사 트랙 등).
- 쿠폰 내용(할인율·사용 기간·사용처)은 협업처와 담당자가 정한다. 에이전트는 리스트에 없는 업체를 넣지 않는다.
- 쿠폰 문구에 사투리를 쓰면 J-3, 마스코트를 쓰면 D-1 검수를 받는다.

**② 선착순 상품**

> **날마다 따로 센다** (담당자 결정 2026-11-18). 매일 교환 번호를 1번부터 다시 시작한다.

| 그날 교환 순서 | 상품 | 하루 수량 | 3일 합계 |
| --- | --- | --- | --- |
| 1 ~ 50번째 | **우리 캐릭터가 들어간 손선풍기** | 50개 | **150개** |
| 51 ~ 250번째 | **부채** | 200개 | **600개** |
| 251번째부터 | 선착순 상품 없음 (쿠폰북 + 추첨 응모만) | - | - |

- 하루 수량을 날짜별로 **미리 나눠 따로 보관**한다 (금 50·200 / 토 50·200 / 일 50·200). 그날 남은 상품은 다음 날로 넘기지 않고 그날 수량만 쓴다. 3일 뒤 남은 상품은 H-7 2-7(기부)을 따른다.
- 날마다 세므로 금요일에 온 사람과 일요일에 온 사람이 같은 기회를 가진다 (1박·재방문 유도와 맞음) `[해석]`.
- 교환할 때 **그날의 교환 번호**를 순서대로 기록해 몇 번째인지 확인한다. 선착순이 끝나면 운영 부스와 안내판에 "손선풍기 마감", "부채 마감"을 바로 표시한다.
- 손선풍기(캐릭터)와 부채는 D파트가 만든다. 캐릭터가 들어가므로 **D-1 검수**를 받는다. 남으면 H-7 2-7(기부)을 따른다.

**③ 인스타그램 추첨 응모**

| 항목 | 기준 |
| --- | --- |
| 응모 조건 | 축제 **공식 인스타그램 계정을 팔로우**하고, 스탬프 북 **뒷면에 인스타그램 아이디**를 적어 낸다 |
| 응모 방법 | 교환할 때 뒷면 응모권을 운영 부스 응모함에 넣는다. 응모권은 **절취선으로 떼는 방식**을 제안한다 (스탬프 북은 방문객이 가져가고 응모권만 냄) |
| 1인 응모 | 스탬프 북 1권에 응모 1번 (제안) |
| 추첨 | **축제 마지막 날**(일요일) 추첨 |
| 당첨 확인 | 추첨 뒤 해당 아이디가 공식 계정을 팔로우하고 있는지 확인한다. 팔로우하지 않았으면 다시 추첨한다 (제안) |
| 발표 | 공식 인스타그램 게시물과 DM으로 알린다 (F파트 계정 운영) |
| 추첨 상품 | 상품 내용·수량은 담당자가 정한다 (7장 2번) |
| 상품 전달 | 현장 수령 또는 배송. 배송할 때만 당첨자에게 주소를 받고, 발송 뒤 파기한다 |

**추첨 응모의 개인정보·운영 기준**

- 인스타그램 아이디도 개인을 알아볼 수 있는 정보로 보고 **필요한 만큼만** 받는다 (P0-10). 응모권에 **수집 목적(추첨·당첨 연락), 보관 기간, 파기 시점**을 적는다. 보관 기간은 I-3 2장 규칙과 담당자 입력값을 따른다.
- 응모권은 추첨이 끝나고 당첨자 연락·상품 전달이 끝나면 파기한다. 당첨자 아이디를 게시물에 공개할 때는 일부를 가리는 것을 제안한다.
- 인스타그램 프로모션 규칙(플랫폼 공식 가이드라인)을 지키는지 F파트가 운영 전에 확인한다 (예: 이벤트가 인스타그램과 관계없다는 안내). 확인 전에는 "플랫폼 규칙 확인 필요"로 둔다.

## 3. 에이전트 행동 규칙

1. 8칸·5개 이상·묶음별 1개 규칙을 바꾸지 않는다. 3일 누적, 칸 배치, 도장 디자인처럼 "제안"인 것은 확정 전까지 제안으로 쓴다.
2. 웹 스탬프, 축제장 밖 스탬프, 축제 팔찌, A 사투리 콘텐츠 도장을 다시 넣지 않는다.
3. 쿠폰북에 담당자 리스트에 없는 업체를 넣지 않는다. 추첨 당첨자를 에이전트가 정하지 않는다.
4. 스탬프 북 수량은 "방문객 예측 수 × 1.5" 계산식으로만 낸다. 방문객 수를 지어내지 않는다.
5. 각 부스가 언제 찍어 주는지(구매 직후 등)는 파트가 정하지만, **몇 개를 인정하는지는 2-2·2-3을 따른다.**
6. 지급처 위치는 지도에 있는 부스 위치만 쓴다.
