## P1 — 활동 후보 목록 (7쪽)

```
research/company/○○/onepager.md를 읽어 줘.
이 기업이 원료·IP를 확보해 고객에게 전달하기까지의 활동을
주활동 5단계(인바운드 · 운영·제작 · 아웃바운드 · 마케팅·판매 · 서비스)와
지원활동 4층(인프라 · 인적자원 · 기술개발 · 조달)으로 나눠
'동사 + 목적어' 한 줄씩 나열해 줘.
활동마다 근거가 된 원페이지 칸과 [출처 n]을 붙이고, 근거가 없으면 [I]로 표시해서
valuechain/activities_v0.md로 저장해 줘.
```

## P2 — 이해관계자 표 (11쪽)

```
valuechain/activities_v0.md와 research/company/○○/onepager.md를 읽어 줘.
FigJam에서 우리 팀이 정한 단계는 ① … ② … ③ … ④ … ⑤ …야.
단계마다 이해관계자를 원천 / 제조·제작 / 플랫폼·유통 /
소비자·고객사 / 파트너·인프라 / 공공·규제·커뮤니티 유형으로 나누고,
'하는 사람'과 '영향 주는 사람'을 구분해 표로 정리해 줘.
이름은 onepager.md와 공시 계열회사 표에 있는 것만, 없으면 유형 이름 + [U].
결과는 valuechain/stakeholders.md로 저장해 줘.
```
- 실제 적용: 단계 = ① 트렌드·타깃 인사이트 → ② IP 콘텐츠 제작 → ③ 캠페인·참여 → ④ 커머스 전환 → ⑤ 데이터 환류.

## P3 — 신호 근거표 (15쪽)

```
valuechain/stakeholders.md, research/company/○○/onepager.md,
research/reviews/report.md 와 metrics.md(10/29 리뷰 분석 결과)를 읽어 줘.
단계마다 정보 재입력 · 대기·지연 · 품질 편차 · 한 사람 의존 ·
데이터 단절 · 중간 차감 중첩 여섯 신호의 근거 문장을 찾아
신호 · 단계 · 근거 문장 · [출처 n] · 짝이 되는 AI 기회 유형 표로 만들어 줘.
근거가 없는 신호는 만들지 말고, 결과는 valuechain/signals.md로 저장해 줘.
```
- 실제 적용: 리뷰 분석 파일을 찾지 못해 해당 근거는 쓰지 않았고, 결과는 `signals_v02.md`(근거 있는 5건)로 저장.

## P4 — Mermaid 초안 (17쪽)

```
research/company/풀무원/onepager.md를 읽어 줘.
이 기업이 속한 산업의 밸류체인을 Mermaid flowchart LR로 그려 줘.
단계는 우리 팀이 정한 5개: 지역 생산자 → 가공 → 식품 온라인 플랫폼 → 주문 → 물류·배송.
각 단계를 subgraph로 만들고 그 안에 이해관계자(하는 사람은 굵게, 영향 주는 사람은 괄호)를 노드로.
상품 흐름은 -->, 돈 흐름은 ==> (라벨: 결제·수수료·정산·납품 단가), 데이터 흐름은 -.-> (라벨: 데이터 이름·
보유자).
수수료율·금액 같은 숫자는 onepager.md에 [출처]가 있는 것만 쓰고 나머지는 쓰지 마.
결과를 valuechain/valuechain_v0.md에 ```mermaid 블록으로 저장하고, 아래에 단계별 근거
(onepager.md의 어느 칸인지)를 표로 적어 줘.
```
- 실제 적용: 기업은 `대전 꿈돌이&꿈씨 패밀리`, 단계는 **팀 5단계**로 교체(풀무원 예시 단계 사용 안 함).

## P5 — 원페이지 대조 검증 (18쪽)

```
valuechain/valuechain_v0.md를 research/company/풀무원/onepager.md, sources.md와
대조해 줘. 단계 이름·순서, 이해관계자, 돈·데이터 라벨 중 원페이지에 근거가 없는 항목을 표로 만들고(항목 ·
초안 내용 · 원페이지 근거 유무 · 제안), 숫자가 들어간 라벨은 모두 [출처] 여부를 표시해 줘. 결과는
valuechain/analysis.md의 '검증' 절에 추가.
```
- 실제 적용: 결과는 `analysis_v01.md` 8장(8-1 · 8-2 · 8-6).

## P6 — HTML 한 장 (23쪽)

```
valuechain/valuechain_v1.md의 내용을 1280×720 HTML 한 장으로 그려 줘.
위에서부터 네 층: 1 활동 5단계(가로 상자, 화살표) 2 이해관계자(단계 아래 텍스트) 3 돈 흐름(오른쪽→
왼쪽 주황 화살표, 라벨) 4 데이터 흐름(파란 점선, 피드백 화살표 포함).
병목은 주황 테두리, 비용은 코랄 테두리, 기회는 라임 배경으로 표시하고 오른쪽 아래에 범례.
팀 자산(지역 생산자)이 들어가는 상자는 틸 배경. 글자는 모두 실제 텍스트, 외부 이미지 없이 인라인 SVG나
CSS로.
valuechain/valuechain_v1.html로 저장하고, 브라우저에서 열어 잘리는 글자가 없는지 확인해 줘.
```
- 실제 적용: "팀 자산(지역 생산자)" → ② IP 콘텐츠 제작 단계의 대키미·외지몽 IP·세계관·IP 가이드를 틸로 표시.
