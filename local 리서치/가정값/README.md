# 가정값

첫해(과거 운영 데이터가 없는 해)에 쓸 **예산 · 방문객 · 단가 같은 수치**를 팀이 넣는 폴더예요.

- 파일 이름 앞에 `[가정]`을 붙여요. 예: `[가정]_예산_대분류.csv`, `[가정]_방문객.md`
- 예산 대분류 총액은 P0-6 양식(`세부지침안/P파트/.../P0-6_예산입력_양식.csv`)의 열을 그대로 써요.
- 어느 연도 값인지 파일 이름이나 `연도` 열에 적어요.
- 순환형 축제 에이전트는 수치를 이 폴더에서만 가져와 `[가정]` + 파일 경로로 표시해요. 여기 없는 수치는 "미입력"으로 두고 담당자에게 물어봐요.
