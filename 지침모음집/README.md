# 지침모음집

축제 기획을 위해 만든 에이전트를 에이전트별 폴더로 모아 둬요.

| 폴더 | 상태 | 설명 |
|---|---|---|
| `대구사투리축제기획에이전트v1/` | **사용 중** | 대구 사투리 축제 기획 에이전트. 구성은 폴더의 `README.md` 참고 |

## 규칙

- 에이전트 내용은 이 폴더 안에만 둬요. 같은 파일을 다른 곳에 복사하지 않아요.
- 레포 맨 위 `CLAUDE.md`와 `.claude/skills/`는 연결 파일이에요. 내용을 쓰지 않아요.

## 버전 올리는 순서

1. 작업 브랜치를 만들고 에이전트 폴더의 파일을 고쳐요.
2. 2027 산출물 등으로 시험해 보고 main에 합쳐요.
3. 합치기 전 main에 `agent-v1` 같은 태그를 달아요. 지난 버전은 복사본 대신 이 태그로 찾아요.
4. 폴더 이름을 `git mv`로 `...v2`로 바꾸고, 연결 파일 5개(`CLAUDE.md`, `SKILL.md` 4개)의 경로를 고쳐요.
5. 아래 변경 기록에 한 줄 남겨요.

## 변경 기록

| 버전 | 날짜 | 주요 내용 |
|---|---|---|
