# 기획안 작성 (지침 5장 4~9단계)

인자: `$ARGUMENTS` — 첫 단어는 연도, 나머지는 부분 항목(없으면 전체 기획안)

## 1. 전제 확인
- `01_기획조건표.md`, `02_조사보고서.md` 가 없으면 앞 단계를 먼저 하자고 안내하고 멈춘다.
- `00_결정기록.md` 를 읽는다. 01과 다르면 결정기록이 우선이다.
- 01의 가정값이 아직 `[가정]`이면 기획안 맨 앞 "미확정 사항"에 그대로 옮긴다. 특히 **연도 주제가 확정 전**이면 작성은 하되 "주제 미확정 — 확정 후 5장(연도 주제)·6장(프로그램) 재검토"라고 문서 맨 위에 적는다.
- 이미 있는 03 맨 위에 "⚠ … 갱신 필요" 경고가 있으면 해당 부분을 반영하고 경고를 지운다.
- `local 리서치/공통/단가표.md` 를 읽는다. 1장 단가와 2장 집행 실적을 예산 근거로 쓴다.

## 2. 진행 순서
1. **연도 주제·전략** — 01의 주제(또는 후보)를 02의 문제 정의와 연결해 확정안 1개 + 대안 1개
2. **아이디어 발굴** — 지침 4장 요소별로 고르게. 체류·상권·사투리 목적이 한쪽에 몰리지 않게
3. **타당성 평가** — 지침 8장
   - 필수 조건(3대 프로그램 포함, 예산, 두류공원·8월 말 적합, 안전) 통과 여부
   - 가중치 표(체류 25 / 상권 25 / 사투리 25 / 실행 15 / 2030 10)로 5점 척도 점수, 점수 근거 한 줄
   - 점수는 비교용, 최종 채택은 담당자라고 명시
4. **상세 기획** — 지침 3장 원칙
   - 토론 대회: 대구 시민 vs 타지역, 토너먼트, 심사위원+관객 투표, 논제마다 찬반 논거·난이도·예상 시간·관객 참여 방식. 금지 논제(지역 비하·정치 프레임·젠더/세대 갈등) 점검
   - 10미 포장마차·플리마켓: 업체 모집·선정·배치
   - 야간 프로그램과 축제 → 관광지·숙박·상권 동선 필수
5. **운영 계획** — 지침 9장
   - 3일 일정표 (폭염: 낮은 실내·그늘, 야간 중심)
   - 예산 최소/기본/확장 3안: 항목·수량·단가·산정 근거·견적 확인 여부. **총액과 세부 합계를 직접 계산해 맞춘다.** 미확인 단가는 `[추정]`
     - 단가마다 근거 종류(집행/견적/공공/언론/추정)를 표시하고, 예산표 아래에 "근거 종류별 금액 비중"을 적는다. `[추정]` 비중이 절반을 넘으면 "견적 확보 필요 항목" 목록을 따로 만든다.
     - 단가표에 없는 단가를 새로 조사했으면 산출물 출처에 적고, 사용자에게 단가표 1장에 추가할지 묻는다.
     - KPI 측정 비용(설문·데이터 구매·쿠폰 등)을 예산 항목에 넣는다.
   - 인력, 시설·구역 배치(통합본 5-1의 치맥 구역 참고), 안전(인파·온열·우천·혼잡·인력 부족), 신고·허가·보험 체크리스트(관계 기관 최신 기준 확인 안내)
   - 저작권·촬영 동의·개인정보 체크리스트 (지침 10장)
6. **KPI** — 지침 11장. 지표마다 정의·측정 방법·수집 시점·담당 주체
   - **KPI 측정 준비표를 반드시 만든다.** 축제가 끝난 뒤에는 모을 수 없는 데이터가 있으므로, 지표마다 아래를 적는다.

     | 지표 | 데이터 출처 | 필요한 협조·도구 | 협조 기관 | 준비 시작(D-) | 축제 중 수집 방법 | 사후 수집 기한 | 담당 | 비용 |

   - 목표 1순위(1박 체류)는 최소 한 가지 이상 **직접 측정 수단**을 넣는다. 예: 숙박 연계 할인 쿠폰 사용 수, 현장·사후 설문의 숙박 여부 문항, 숙박업 협조 집계. 기관 통계(통신·카드 데이터)는 제공 가능 여부와 시점을 확인할 곳까지 적는다.
   - 준비 시작 시점은 01의 8장(연간 추진 일정) "KPI 측정 준비" 단계와 맞춘다. 어긋나면 01 갱신이 필요하다고 보고한다.
   - 설문·쿠폰은 개인정보 수집 동의 항목을 지침 10장 체크리스트와 연결한다.
7. **검증** — 아래 체크리스트를 문서 끝 "검토 결과"에 표로 남긴다
   - [ ] 3대 프로그램 모두 포함
   - [ ] 지침 4장 요소 누락 없음
   - [ ] 예산 3안 합계 일치 (계산식 표시)
   - [ ] 모든 수치에 라벨·출처
   - [ ] 다른 사례 수치를 목표치로 그대로 쓰지 않음
   - [ ] 금지 논제·할매 말투 없음
   - [ ] 폭염·우천·혼잡 대응 포함
   - [ ] 프로그램 간 시간·장소 충돌 없음
   - [ ] 예산 단가마다 근거 종류 표시, `[추정]` 비중 계산
   - [ ] 모든 KPI에 측정 준비표 행이 있고, 1박 체류 직접 측정 수단 1개 이상
   - [ ] 00_결정기록의 확정 사항과 충돌 없음

## 3. 출력
- 전체 요청: `local 리서치/<연도>/03_기획안.md` 를 지침 13장 표준 목차로 작성
  기획 요약 → 목표·콘셉트 → 조사 결과 → 타깃 → 연도 주제 → 프로그램 구성·상세 → 모집·선발 → 지역 협업 → 온라인 연계 → 홍보 → 3일 일정표 → 예산·인력 → 안전 → KPI(측정 준비표 포함) → 기대 효과 → 미확정 사항 → 출처 → 검토 결과
- 부분 요청: 03_기획안.md 의 해당 장만 작성·수정하고 나머지는 건드리지 않는다. 파일이 없으면 목차만 만들고 해당 장을 채운다.
- 개조식, 실무 보고서 톤. 사투리는 자연스러운 곳에만.
