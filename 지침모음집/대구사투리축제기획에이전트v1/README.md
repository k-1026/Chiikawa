## 연결 파일

Claude Code는 정해진 위치의 파일만 자동으로 읽어요. 그래서 아래 파일은 원래 자리에 남아 있고, 이 폴더를 가리키는 역할만 해요. 내용은 여기에 쓰지 않아요.

| 연결 파일 | 왜 그 자리에 있어야 하나 | 가리키는 곳 |
|---|---|---|
| `/CLAUDE.md` | 레포 맨 위에 있어야 에이전트 지침으로 읽혀요 | `대구사투리축제기획에이전트.md` |
| `/.claude/skills/festival-*/SKILL.md` | 이 위치에 있어야 `/festival-*` 명령이 나타나요. 명령 이름·설명(frontmatter)은 이 파일에 있어요 | `skills/festival-*.md` |
