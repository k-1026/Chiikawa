# 웹설계 파트 인덱스 (먼저 이 파일만 읽으세요)

> 원본 초안: `../01_전체워크플로우.md`, `../03_파트별_기능명세_범용템플릿.md` (통째로 읽지 마세요 — 토큰 낭비)

## 토큰 아끼는 사용법

1. 이 INDEX만 읽는다.
2. 새 주제에 필요한 **모듈 파일만** 골라 읽는다 (아래 목록·선택표 참고).
3. 주제 단어 바꾸기가 필요하면 `치환표.md`만 추가로 읽는다.
4. 결과물은 **파일로 저장**하고, 이미지는 열어 보지 않는다.
5. 한 작업이 끝나면 새 세션/`/clear`로 넘어간다.

### 요청 문구 예시
```
웹설계/파트/00_INDEX.md만 읽고, {주제}에 필요한 모듈을 골라 목록만 먼저 보여줘.
내가 확인하면 그 모듈 파일만 읽고 {주제} 버전으로 파일에 저장해줘 (이미지 확인 생략).
```

## 공통 변수 · 사용 순서

1. **[1. 주제 치환표](#1-주제-치환표)**에서 내 주제의 단어를 정합니다(예: "부스" → "작품", "무대" → "세션룸").
2. **[2. 모듈 선택 매트릭스](#2-모듈-선택-매트릭스)**에서 내 주제에 필요한 모듈만 고릅니다.
3. 고른 모듈의 명세(3장)를 복사하고 `{{변수}}`를 내 주제 값으로 바꿉니다.
4. 각 모듈 끝의 **체크리스트**로 빠진 것이 없는지 확인합니다.

| `{{STAGE}}` | 프로그램이 열리는 공간 | 들썩들썩 스테이지, 뽀기 스테이지 |
