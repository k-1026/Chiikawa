# 근거 규칙

> **원본은 P0-9 (공통 작업 규칙) 2장 · 3장이다.** 라벨 4종, 출처 우선순위와 통일 표기, 임의 생성 금지, 문서 우선순위는 P0-9를 직접 읽는다.
> 이 파일에는 P0-9에 없는, 에이전트가 팀 자료를 쓸 때의 규칙만 둔다. (구버전 `로컬에이전트/CLAUDE.md` "근거 사용 규칙"에서 옮김)

## 0. `[가정]` 과 "미입력" — 첫해 수치 규칙
첫해(과거 운영 데이터가 없는 해)에는 **예산 · 방문객 · 단가 같은 수치를 팀이 `[가정]` 파일로 따로 넣어 준다.** 에이전트는 수치를 만들지 않는다. (기본지침v2 3-1, P0-6 2-3과 같은 원칙)

| 표시 | 뜻 | 언제 |
|---|---|---|
| `[가정]` | **팀이 넣어 준 가정값.** 파일 이름에 `[가정]`이 붙은 파일에서 가져온 값 | 첫해 수치 전부 |
| 미입력 | 팀 가정 파일에도 없고 담당자도 아직 안 준 값 | 비워 두고 질문 |
| `[추정]` | 위 `[가정]` 값이나 `[확인]` 값으로 **계산만** 한 수치. 계산식 필수 | 예: 예비비 = 1~6 합계 × 10% |

- `[가정]` 값에는 **가져온 파일 경로**를 출처로 적는다. 예: `[가정] 4,200만 원 (local 리서치/가정값/[가정]_예산_대분류.csv)`
- 가정 파일에 없는 수치를 에이전트가 다른 축제 수치 · 일반론으로 채우지 않는다. "미입력"으로 두고 반환 질문에 올린다.
- 수치가 아닌 근거(사실 · 해석 · 가설)에는 P0-9 라벨 4종을 그대로 쓴다.
- evidence-auditor는 `[가정]`을 라벨 위반으로 잡지 않는다. **출처 파일이 없는 `[가정]`, 에이전트가 만든 수치, 계산식 없는 `[추정]`** 을 잡는다.
- 2년 차부터는 전년 04 집행 실적 · 단가표가 먼저이고, `[가정]` 파일은 새 항목에만 쓴다 (P0-6 2-3).
- (P0-9 라벨표에 이 구분이 없다 — P파트 담당 확인 필요)

### 가정 파일 위치 (확정 2026-11-18)
- **`../local 리서치/가정값/`** 한 곳에만 둔다 (main에 만듦, 연도 폴더 밖). 어느 연도 값인지는 파일 이름이나 `연도` 열로 구분한다. 파일 이름은 `[가정]_<내용>` (예: `[가정]_예산_대분류.csv`, `[가정]_방문객.md`).
- 예산 대분류 총액은 P0-6 양식(`P0-6_예산입력_양식.csv`)과 같은 열로 받는다.
- 다른 폴더에 `[가정]` 파일이 있으면 쓰지 않고, 가정값 폴더로 옮겨 달라고 질문한다.
- 폴더가 없거나 비어 있으면 수치는 모두 "미입력"이다.
- 같은 항목이 두 파일에 다르게 있으면 고르지 말고 둘 다 적고 질문한다.

## 1. 팀 조사 자료 읽는 순서
1. `../local 리서치/통합_조사결과V1.md` 를 먼저 읽는다 (목차 · 요약 · 불일치 · 공백).
2. 통합본이 가리키는 팀원별 원본(`../local 리서치/<이름>/`)은 필요한 장만 연다.
3. 팀 원본 조사 파일은 **고치지 않는다.** 고칠 점은 산출물의 "미확정 사항"에 적는다.

## 2. 팀 자료를 인용할 때
- 팀원마다 등급 기호가 다르다. 인용할 때는 P0-9 2-2의 통일 표기(공식/통계/학술/언론/비공식)로 바꿔 적는다.
- 통합본의 **불일치 수치**를 쓸 때는 두 값과 출처를 함께 적고, 하나를 골랐다면 이유를 적는다.
- 다른 사례의 수치(방문객 · 매출 · 부스 수)는 그 사례의 관측값이다. 우리 목표치로 쓸 때는 `[추정]`으로 계산식을 보인다.

## 3. 새로 조사할 때
- 팀 자료에 없는 내용만 조사한다. P0-9 출처 우선순위를 따르고, 링크 · 자료 기준일 · 원문 확인/요약 기반을 붙인다.
- 새로 찾은 근거는 산출물 "출처" 장에 **"에이전트 추가 조사"** 로 구분한다.
- 찾지 못하면 "확인 안 됨"과 확인할 곳을 적는다.

## 4. 예산 근거
- 단가는 `../대사투/공통/단가표.md` 를 먼저 쓴다. 단가마다 근거 종류(집행/견적/공공/언론/추정)를 표시한다.
- 단가표에 없는 단가를 새로 조사했으면 출처에 적고, 단가표에 추가할지는 오케스트레이터가 담당자에게 묻는다.

## 5. 날짜
- 날짜 · 요일 · D-day는 추측하지 않고 `date` 명령으로 계산한다. 예: `date -j -f %Y-%m-%d 2027-08-27 +%a` (macOS)
