# 호출 순서 (전체 기획 모드)

> 오케스트레이터가 S0~S11을 돌 때 **누구를, 어떤 순서로, 어떤 검증과 함께** 부르는지 정한 표다. 단계별 통과 기준은 `기본지침v2.md` 4장.

## 단마다 같은 패턴

```
작업 에이전트 → 🔍 단계 검증 → (불통과) ↺ 재작업 최대 2회 → (넘으면) 담당자 보고
                             → (통과) ✅ 게이트 단이면 담당자 확인 → 00_진행상태 기록 → 다음 단
```

- **병렬:** 같은 칸에 `·`로 묶인 에이전트는 Agent 도구를 한 메시지에서 동시에 부른다.
- **차례:** `→`로 이어진 에이전트는 앞 결과를 받아 부른다.
- 재작업은 **불통과 항목을 만든 에이전트만** 다시 부르고, 검토 결과표를 같이 넘긴다.
