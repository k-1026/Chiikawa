# 원본 지정표 — 한 내용은 한 곳에서만

> 서브에이전트는 아래 원본만 읽고 값을 가져온다. 다른 파트에는 링크나 한 줄 요약만 둔다.
> `duplicate-finder`는 원본이 아닌 곳에 같은 내용이 길게 있으면 잡아낸다.
> 기준: main 세부지침안 (`세부지침안_버전.md`), 2026-11-18

| 내용 | 원본 | 다른 파트에 남기는 것 | 상태 |
|---|---|---|---|
| 지도 · 구역 번호(0~6) · 메인구역 구획 | Y.지도 | P0-3: 요약만, 다르면 Y 우선 | 확정 |
| 장소 · 구역 · 부스 수 | P0-3 | B · C: 구역 안 세부 배치 | 확정 |
| 기간 · 운영 시간 (매일 12:00 개장 · 금토 22:00 · 일 20:00) | P0-4 | E-3: 시간대 안 배치만 | 확정 |
| 축제장 안 동선 · 스탬프 찍는 지점 | flow-designer (M-6) | A · B · C · E: 찍어 주는 방식 한 줄 | 확정 |
| 스탬프 운영 (판 배부 · 완성 확인 · 상품 · 쿠폰북 · 재고) | H | P0-1: 요약 | 결정됨 · H 지침 없음 |
| 축제장 밖 쿠폰 · 혜택 (스탬프 없음) | G-3 | B-6: 매장 카드(QR) 정보만 | 확정 |
| 근거 라벨 · 출처 · 문서 우선순위 | P0-9 | 링크만 | 확정 |
| 금지 기준 · 개인정보 · 동의 | P0-10 | A-4: 신청서 항목만 | 확정 |
| 사투리 표현 검수 절차 | J-3 | "J-3 검수를 받는다" 한 줄 | 지정 |
| 마스코트 IP 규칙 · 검수 | D-1 | P0-11은 만들지 않고 링크 | 회의 |
| 문서 양식 (공고 · 안내문) | M-7 (오케스트레이터) | 각 모집 파트: 들어갈 항목만 | 회의 |
| 예산 상세 · 수입 | H-1 | P0-6: 입력 방식 · 대분류 | 회의 |
| 예산 단가 · 집행 실적 | `local 리서치/공통/단가표.md` | H-1: 단가 근거로 인용 | 확정 |
| 담당자 결정 · 게이트 승인 | `local 리서치/<연도>/00_결정기록.md` | 01: 확정값만 옮김 | 확정 |
| 진행 단계 · 재작업 횟수 · ⚠ 목록 | `local 리서치/<연도>/00_진행상태.md` | — | 확정 |
| KPI · 측정 계획 | I-1 | 각 파트: 지표 이름만 | 지정 |
| 역산 일정 (D-180~D+30) | H-3 ? | P0-4와 중복 | 회의 필요 |
| 교통 · 이동 · 주차 | P0-3 / G-6 / H-6 | 3곳 경계 정하기 | 회의 필요 |
| 식사 · 테이블 · 돗자리 존 | Y(위치) · 담당 ? | B-1: 관할 아님 | 담당 없음 |
| 3일 타임테이블 | 없음 | A · E · P0-4가 모두 미룸 | 담당 없음 |

- 상태가 **회의 필요 / 담당 없음**인 내용은 에이전트가 원본을 정하지 않는다. 산출물 "미확정 사항"에 올리고 담당자에게 묻는다.
