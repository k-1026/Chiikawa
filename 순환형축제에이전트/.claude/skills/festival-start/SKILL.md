# 이어 하기 입구 1 — S0 ~ S1

인자: `$ARGUMENTS` — 첫 단어는 연도(없으면 묻는다). 두 번째 단어가 `갱신`이거나 담당자가 결정을 알려 주면 **갱신 모드**.

## 새로 시작
1. `../대사투/<연도>/00_진행상태.md` 가 있으면 새로 만들지 않고 멈춘 단계를 알려 준 뒤 거기서 이어 간다.
2. 없으면 `양식/00_결정기록.md`, `양식/00_진행상태.md` 를 `../대사투/<연도>/` 에 복사하고 `<연도>`를 채운다.
3. CLAUDE.md 1장 순서로 `지침/호출순서.md` **1단**을 실행한다.
   - `retro-reader` (S0) → 오케스트레이터가 `양식/01_기획조건표.md` 로 01 작성 (기본지침v2 3장 입력값은 AskUserQuestion으로 한 번에)
   - 단계 검증: `evidence-auditor` · `format-checker` (재작업 최대 2회)
4. **게이트 S1** — 조건 확정 승인을 받을 때까지 멈춘다. 승인되면 00_결정기록 · 00_진행상태에 적는다.
5. 다음 단계로 `/festival-research <연도>` 를 안내한다.

## 갱신 모드
CLAUDE.md 4장대로 결정을 새 D-번호로 추가하고, 01을 고치고, 영향받는 02 · 03 · 03_파트 파일에 ⚠ 경고를 단다. 다시 할 단계를 안내한다.
