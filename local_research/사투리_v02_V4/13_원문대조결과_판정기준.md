- 목적: "근거로 삼을 수 있는 자료"만 골라내기 위해 v02의 모든 링크를 열어 원문과 대조하고, 판정 기준을 통합해 적용함
- 방법: 링크를 8개 묶음(국립국어원·언어의식조사 / 매일신문 / 경북매일 / AI허브·데이터 / 관광·굿즈 / 해외 / 정책·조례 / 학술·기사)으로 나눠 실제로 열람해 대조. 열리지 않은 곳은 아래 "직접 확인 경로"에 정리
- 개별 행의 정정 내용은 01~09번 파일에 반영했고, 항목별 등급은 [12_자료원본목록.csv](12_자료원본목록.csv)의 "근거 등급"·"분류(A~F)" 열에 있음

## 1. 통합 판정 기준

v1의 3질문(고유성·지속성·활용성)과 지침 v2의 A~F 분류를 합치고, **"원문으로 확인된 것만 근거"**라는 조건을 추가함.

### 1-1. 근거 등급 (인용해도 되는가)

| 등급 | 조건 | 사용 방법 |
|---|---|---|
| **사용 가능** | 원문을 직접 열어 확인했고, 핵심 수치·사실이 원문에 명시되어 있으며, 출처 간 불일치가 없음 (①공식 또는 ②기사) | 근거로 인용 가능 |
| **조건부** | 원문은 확인했으나 ① 단일 출처, ② ③ 비공식(칼럼·기업 발표), ③ 표본·문항·집계 기준이 불명확 중 하나 이상 | 인용 시 조건을 함께 적음 |
| **보류** | 원문 미확인·열람 실패, 또는 출처 간 불일치가 풀리지 않음 | 근거로 쓰지 않음 |
| **제외** | 원문에 해당 내용이 없음, 사투리와 무관, 구체 사례가 아님, 기간 밖(예외 아님) | 근거로 쓰지 않음 |

### 1-2. 자산 판정 (대구 직접 자산인가) — 아래를 모두 충족해야 A

1. 고유성: 대구 직접 해당 (대구 지명·기관·인물과 결합)
2. 지속성: 원문에 2회 이상 반복 또는 현재 운영 중이라는 근거가 있음
3. 활용성: **원문에 명시된** 공식 수치(방문·참여·매출) 1개 이상 (규모 하한 없음)
4. 근거 등급이 "사용 가능"

### 1-3. 분류

| 분류 | 의미 |
|---|---|
| A | 직접 활용 가능한 대구 자산 (1-2를 모두 충족) |
| B | 자산을 뒷받침하는 근거 정보 (대구 직접·전국 통계·공공 데이터 등) |
| C | 타지역·해외 벤치마크 (대구의 사실로 일반화하지 않음) |
| D | 사회적 반응·전문가 의견·칼럼 |
| E | 보류·가설·자료 공백 (원문 미확인, 불일치, 미발견) |
| F | 제외 (기간 밖, 무관, 구체 사례 아님) |

## 6. 결론

- 지금 인용해도 되는 자료는 **9건("사용 가능")**과, 조건을 함께 적는 **26건("조건부")**임
- **대구 직접 자산은 0건**이고, 가장 가까운 후보 3건(05-01, 09-01, 08-01)은 대구 기관 자료실에서 수치를 확보해야 승급됨
- 자산 판정에 필요한 핵심 공백: 대구 지역어 조례, 대구 단독 방언 사용 통계, 사투리 상품·콘텐츠 성과 수치
