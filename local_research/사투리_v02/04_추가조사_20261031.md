# 04. 추가 조사 (2026-10-31, 지침 v2 기준 1차)

- 방식: 웹 검색 요약 확인. **원문 링크를 열어 본 것이 아니라 검색 요약 단계**이므로 모든 항목에 "원문 확인 필요"가 붙는다.
- 목적: 기존 `03_제외_확인필요.md`의 "자료 부족" 6개 항목을 지침 v2 기준으로 재조사.

## 2. 자료별 기록 (지침 v2 §6 형식, 핵심 항목만)

### S01. 국민의 언어 의식 조사 (N09 보강) — [전국 참고] [확인]
- 핵심 내용: 국립국어원이 2025년 전국 만 20~69세 성인 5000명 대상으로 조사. 지역 방언 **유지 필요 59.2%(2020 대비 +8.3%p)**, 방언의 복수 표준어 인정 **긍정 47.7%**.
- 인용 출처: 뉴시스 2026-01-27 https://www.newsis.com/view/NISX20260127_0003491289
- 출처 등급: 4(언론) → 원자료 국립국어원 보고서(1~3등급) 확인 필요
- 검증 상태: 단일 출처
- **불일치 주의**: 기존 N09에 적힌 "2025 국어 사용 실태 조사(15~69세 3000명)"와 대상·규모가 다름. 같은 조사인지, 다른 조사인지 **미확인**.
- 활용 가능성: 홍보 메시지의 "보존 필요성 공감" 근거 [해석]
- 추가 조사: 국립국어원 보고서 원문(https://www.korean.go.kr/front/reportData/reportDataList.do)에서 연령·지역별 표 확인

### S02. 경상 방언 사용률 (연령별) — [경상권 참고] [미확인]
- 검색 요약상 "경상 방언 사용 22.5%→21.4%, 20·30대 10%대"라는 문구(매일신문 2026-10-06 https://www.imaeil.com/page/view/2026100612314981820).
- 요약 문구일 뿐 원자료를 보지 못했고, 대구 단독 수치도 아님 → **사용하지 않음**. 원문 확인 후 승급.

### S03. 경북대 사투리 백일장 2026 (T09 보강) — [대구 직접] [확인]
- 핵심 내용: 경북대 박물관·한국어문화원 주최 '사투리 백일장-복현골에 핀 글꽃을 찾습니다', 한글날(10/9) 교내 월파원, 각 부문 대상에 총장상.
- 인용 출처: 매일신문 https://www.imaeil.com/page/view/2026100810162109171
- 지속성: 2015 '사투리 가사 공모전'(경북대 한국어문화원, 기간 밖)은 확인되나 같은 행사의 반복은 아님 → 반복 **미확인**
- 활용성: 참가자 수 **미확인**
- 판정(rules v1 3질문): 고유성 O / 지속성 △ / 활용성 X → **정보(자산 후보)**

### S04. 대구시민주간 사투리 프로그램 (T14 보강) — [대구 직접] [확인]
- 2023-02-21~28 '사투리, 이쁘다 아이가' (꽃자리다방, 팝아트·시 낭송·서재 재현). 참여 인원 **미확인**.
- 2026 시민주간은 2/21~28 운영(https://www.heraldk.com/article/2026021816043221660)이나 사투리 프로그램 언급은 검색에서 나오지 않음.
- 판정: 지속성 X(1회 확인) → **정보**.

### S05. 대구 지역어 조례 — [미확인]
- 대구시 국어·지역어 조례는 검색에서 찾지 못함. **"없다"는 뜻이 아니라 "찾지 못했다"**.
- 창원 조례(T13)는 국어기본법이 지자체의 방언 보전 노력을 명시했다는 점을 함께 보도(https://www.metroseoul.co.kr/article/20240311500609).
- 추가 조사: 국가법령정보센터 자치법규에서 '대구광역시 국어' 검색

### S06. 전주 사투리 볼펜 (굿즈 벤치마크) — [전국 참고] [확인]
- 라한호텔 로컬 굿즈 기획에서 '전주 사투리 볼펜'이 언급되고, 검색 요약에는 "가장 높은 판매량"이라고 되어 있음. 판매 수치는 **미확인**.
- 인용 출처: 한국경제 2026-04-15 https://www.hankyung.com/amp/2026041519611
- 대구: 사투리를 직접 상품화한 사례는 **찾지 못함**(수성구 '뚜비' 굿즈 공모전 등은 사투리와 무관).
- 판정: 벤치마크 정보(대구 아님)

### S07. 사투리 변환 (N06 재확인) — [미확인]
- 소비자용 상용 서비스는 못 찾음. LLM(ChatGPT·CLOVA X)으로 경상도 방언→표준어 변환을 실험한 기술 문서(https://wikidocs.net/195839)만 확인. 개인 실험 수준 → 6등급.

### S08. 스코틀랜드 Royal National Mòd (해외 벤치마크 2/5) — [해외 참고] [확인]
- 2024 Oban: 평가보고서 존재(Argyll & Bute 의회 PDF), 방문자 "10,000"은 **언론 헤드라인 수치**(Scotsman) → 평가보고서 대조 필요.
- 2019 Glasgow: 지역경제 효과 **£3.2m**(게일어 위원회 gaidhlig.scot), 방문자 81%가 게일 문화 목적.
- 2016 Lochaber: 경연 참가자 3,666명. 2022 Perth: £2.5m(eventsbase).
- 참고: 개최 사실과 성과를 구분(지침 §3-10). 경제효과 수치는 평가 주체·산정 방식 확인 전이므로 [확인]이 아닌 "공식(미검증)"으로 취급.
- 출처: https://www.argyll-bute.gov.uk/moderngov/documents/s216555/APPENDIX%201%20ROYAL%20NATIONAL%20MD%202024%20EVALUATION%20REPORT.pdf, https://www.gaidhlig.scot/?p=4699

### S09. 대구 사투리 축제 공백 — [해석]
- "대구 사투리 축제·행사 2025·2026" 검색에서 사투리를 주제로 한 축제는 나오지 않고 치맥·떡볶이·판타지아 등만 나옴.
- 해석: 사투리 단독 주제 축제는 확인되지 않는다(검색 1회 기준, 단정 불가).
