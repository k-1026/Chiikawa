- 주제: 대구 사투리 (축제 기획 AI 에이전트용 기초 데이터)

- 근거 문서: [`../사투리_리서치지침_v2.md`](../사투리_리서치지침_v2.md), [`../_rules.md`](../_rules.md)(v1 규칙, 자산 판정에 사용)

## 출처 등급 (조사 순서)

| 등급 | 범위 | 사용 원칙 |
|---|---|---|
| **① 공식** | 공공기관·지자체 원문/보도자료/통계, 학술논문·학회지·학술기관 보고서 | 가장 먼저 조사. 표에서 맨 위 |
| **② 기사** | 언론 보도 | 공식 자료로 확인되지 않는 내용만 보충. 수치는 원자료 확인 전까지 "요약 기반" |
| **③ 비공식** | 전문가 칼럼, 기업·민간 발표, 민간 출판, 블로그·SNS | 반응·참고용으로만 사용. 링크 필수 |

- 같은 필자·같은 기사·같은 원출처는 독립 근거 1건으로 셈

## 라벨

- 내용: [확인] 출처로 확인된 사실 / [해석] 자료 기반 분석 / [가설] 검증 필요 / [추정] 계산·가정 수치 / [미확인] 근거 미확보
- 지역: [대구 직접] [경북 참고] [경상권 참고] [전국 참고] [해외 참고]. B~D 자료는 대구의 사실로 일반화하지 않음
- 검증 수준: **"원문 확인"**은 원문을 직접 열어 대조한 항목, **"요약 기반"**은 검색 결과 요약으로만 확인한 항목 (인용 전 원문 대조 필요). 이번 조사는 대부분 **요약 기반**임

## 기간 예외

- 지침 v2는 "방언의 역사·형성·언어적 특성을 설명하는 과거 연구"를 예외로 허용함 (v1 규칙은 역사만 허용 → **v2 기준으로 넓힘**)
- 예외로 쓴 자료: 01-01, 01-02, 01-03, 01-04 (언어적 특성), 02-03 (제주어 비교). 그 외 2022년 이전 자료는 "기간외 참고"로 표시하고 판정에서 뺌

## 자산 판정 (v1 3질문, 모두 통과해야 "자산")

| 질문 | 기준 |
|---|---|
| 고유성 | 지명·인물·역사·원산지 중 1개 이상 결합, **대구 직접 해당** |
| 지속성 | 2회 이상 반복 또는 확인일 기준 운영 중(근거 필요) |
| 활용성 | 공식 수치(방문객·매출·참여자) 1개 이상, 규모 하한 없음 [가안] |

- 지침 v2 §7은 "최소 판정 기준이 없으면 질문"하라고 하며 A~F 6분류를 제시함. 기준값이 정해지지 않아 **A~F 분류는 적용하지 않았음** ([10_미확인_추가조사.md](10_미확인_추가조사.md) 질문 1)

## 전체 핵심 (확인된 것만)

1. **대구 단독 자산 0건**: 3질문을 모두 통과한 대구 사례가 없음. 후보는 경북대 사투리 백일장(09·05), 대구시민주간 사투리 프로그램(09), 앞산전망대 사투리 퀴즈 미디어보드(08), AI허브 경상 방언 데이터(07)이며 모두 지속성 또는 활용성 수치가 부족함
2. **국가 단위 수치는 확보**: 국립국어원 국민의 언어 의식 조사(2025, 20~69세 5,000명)에서 방언 유지 필요 59.2%(2020 대비 +8.3%p), 복수 표준어 인정 긍정 47.7%
3. **젊은 층 방언 사용 감소**: 경북 20대 조사에서 부모·고향 친구와는 41.3%, 교수 0%, 아르바이트 2.7% (경북 표본, 대구 단독 아님)
4. **대구 사투리 축제는 검색에서 확인되지 않음** (치맥·떡볶이·판타지아 등 다른 주제만 나옴, 검색 1회 기준)
5. **대구 지역어 조례는 찾지 못함** (없다고 단정 불가). 창원(2024)·전북(2021)·제주(2007) 조례는 확인됨
6. **정량 근거가 가장 약한 영역**: 사투리 굿즈·변환기 서비스·타지역 2030 인식 설문·대구 세대별 사용 통계는 미확보
