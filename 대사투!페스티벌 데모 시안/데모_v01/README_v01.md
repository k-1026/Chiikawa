# 대사투! 페스티벌 · 축제 기획 AI 에이전트 데모 v01

시연용 시뮬레이션 데모예요. 실제 AI를 호출하지 않고, 미리 정리한 자료로 답해요.

## 열어 보기
- `index_v01.html` 한 파일에 이미지까지 들어 있어서 더블클릭만 하면 돼요.

## 고쳐서 다시 만들기
- 수정은 `index.src_v01.html`(화면·스타일), `app_v01.js`(대화·기획 틀·굿즈샵), `map_v01.js`(축제 지도)에서 해요.
- 이미지는 `assets_v01/`에 있어요.
- 수정 후 터미널에서 `python3 build_v01.py`를 실행하면 `index_v01.html`이 새로 만들어져요.

## 담긴 것
- 컨셉 추천 → 선택 → 내 기획 틀, 질문 답변(오타 허용), 시연 투어
- 축제 지도(두류공원 안내도 + 구역 버튼)
- 굿즈샵(대키미/외지몽 버전, 에코백 색상 2종, 머리띠 6방향)

## 자료 출처
- main `Y.지도`, `P파트 P0-3_장소`, B·C·D 파트 세부지침안, `대사투/2027` 기획안, `Mascot` 지침·디자인 자료
- 안내도와 일부 수치는 계속 바뀔 수 있어요. 문서끼리 다른 값은 화면에 같이 적어 뒀어요.
