# 대사투! 페스티벌 v06

기관 사용자용 가입·인증·승인과 메뉴별 AI 기획 작업 화면. v05는 수정하지 않습니다.

## 실행

```sh
python3 backend/server_v06.py --port 8002
```

http://localhost:8002/index_v06.html

기본 서비스는 127.0.0.1에만 바인딩합니다. v05의 8001번 서버와 독립적입니다.

## 최고관리자 로그인 (김승희 운영자)

공개 화면에 운영자 선택이나 초기 설정 버튼은 표시하지 않습니다. 기관을 선택하지 않고 사원번호에 운영자 이름과 운영자가 지정한 비밀번호를 입력합니다. 비밀번호는 로컬 DB에 scrypt 해시로만 저장하며 문서·프런트엔드에 기록하지 않습니다.

최초 로그인에서는 인증 앱의 수동 키 등록을 완료하고 6자리 코드를 입력합니다. 새 기기·브라우저나 토큰 만료·로그아웃 후에는 사원번호와 비밀번호 확인이 끝난 뒤 인증 앱 코드 입력 화면이 열립니다. 이 중간 세션은 5분 동안 유효하며 작업공간·관리자 데이터에는 접근할 수 없습니다. 인증 코드 확인 후에만 관리자 세션을 발급합니다.

공개 회원가입으로 운영자 권한을 선택하거나 만들 수 없습니다. 최고관리자 등록은 로컬의 명시적 운영자 설정으로만 진행합니다. 이전 로컬 초기 설정 코드를 입력할 필요는 없습니다. 인증 앱을 잃어버리지 않도록 안전하게 보관하세요.

관리자 화면에서 기관별 이메일 도메인을 실제 기관에 확인한 뒤 등록합니다. 기관 선택에는 대구광역시청, 대구문화예술진흥원, 각 구·군청 담당 부서만 표시합니다. 문화재단·DIMF·한국치맥산업협회는 신규 기관 선택에서 제외했습니다.

## 일반 사용자 등록

기관 → 사원번호/실명/비밀번호 → 인증 수단/연락처 → 운영자 업무 자료 열람 안내 동의 → 등록.
로그인한 상태에서 인증번호를 발송하고 입력합니다. 인증번호는 10분 유효, 5회 오입력 제한, 재발송은 최소 60초 간격입니다. 연락처 인증 후에도 소속 승인이 필요합니다.

최고관리자는 인증 완료 사용자에 대해 실제 재직 확인 기록을 입력해야 승인할 수 있습니다. 휴대폰 인증은 번호 소유 확인이며 재직·명의 인증을 대신하지 않습니다. 반려·정지에는 사유가 필요합니다.

## 실제 이메일/문자 발송

`.env.example`을 `.env`로 복사해 설정한 뒤 서버를 다시 실행합니다. SMTP는 465 SSL 또는 STARTTLS를 사용합니다. Twilio는 SMS 발송 계정과 발신 번호가 필요합니다.

연동 전에는 발송 불가 상태를 안내하고 인증 완료로 처리하지 않습니다. 개발용 인증번호 노출·우회 로그인·테스트 사용자 자동 승인은 없습니다.

기관 이메일 인증은 관리자가 등록한 **정확한 도메인**만 허용합니다. 하위 도메인도 개별 등록해야 합니다. 휴대폰 인증으로 가입해도 반드시 운영자의 소속 확인·승인이 뒤따릅니다.

## 화면

- 홈: 로고, 짧은 AI 소개, 새 기획/이어서 작업, 단계별 시연과 사용설명서.
- AI 기획: 대화, 편집 가능한 조건, 질문 제안, 실제 작업 처리 상태. 질문 시 서버에 저장된 최근 대화와 조건을 함께 전달합니다.
- 내 기획안: API 기획안 작성, 항목 수정, 미정 사항, 문서 내보내기.
- 축제 지도/굿즈: 8001번 v05의 지도·굿즈 자료를 보존한 인증 보호 화면. 배치 자체를 AI가 변경하거나 상품을 구매하는 기능은 아닙니다.
- 관리자: 전체 가입자·승인 상태, 소속 확인 기록, 개별 대화·기획안, 이용/오류/열람 기록, 기관 도메인 설정.

최고관리자도 비밀번호, 일회용 인증번호, 인증 앱 키, API 키 원문을 조회할 수 없습니다. 전체 대화·기획안 열람은 감사 로그에 기록합니다.

## AI와 문서 내보내기

v05 backend의 기존 Gemini 오케스트레이터·문서 작성/내보내기 모듈을 재사용합니다. 기존 `config.py`의 자료 경로와 해당 docs의 `.env`, RAG 색인이 있어야 합니다. v06 시작에는 AI 연결이 필수가 아니지만 실제 질문/기획안 작성 시 필요합니다. 실패 시 에러를 안내하고 시연 답변으로 바꾸지 않습니다.

PDF 생성에는 로컬 Chrome, Word 변환에는 기존 vendor/python-docx 구성 등이 필요합니다. 외부 서비스의 자격 증명과 도메인은 사용자의 실제 운영 설정이 필요합니다. 실제 SMS·메일 도착과 실 API 응답은 운영 계정으로 별도 확인해야 합니다.

## 데이터와 권한

계정·세션·작업·감사 로그는 `.runtime/accounts.sqlite3`에 저장됩니다. 암호는 scrypt 해시, 세션은 해시된 토큰과 HttpOnly/SameSite=Strict 쿠키, 인증번호는 솔트된 해시로 저장합니다. 일반 사용자·미완료 인증 세션은 8시간 후 만료하며, 인증을 마친 최고 관리자·일반 관리자는 30일 후 만료합니다. 관리자 세션은 사이트 HTML 재접속 시 30일로 갱신합니다. DB·초기 설정 파일과 폴더는 로컬 사용자만 읽도록 권한을 설정합니다. 운영 전 데이터 백업·보존/삭제 정책을 정하세요.

일반 사용자는 자신의 데이터만 조회합니다. 서버에서 모든 기획/AI/내보내기 API와 지도·굿즈 원본 접근을 재검사하므로 화면을 숨기는 것만으로 보호하지 않습니다. 승인 취소·정지는 기존 로그인 세션에도 즉시 적용됩니다.

인터넷 공개 배포 전에는 HTTPS, Secure 쿠키, 운영용 애플리케이션 서버, 백업/모니터링을 구성해야 합니다. 현재 실행 구성은 로컬 검토용입니다.

## 고정 기획안 양식

기획안은 `plan_template_v06.json`에서 정의한 8개 항목(축제 개요, 목적·필요성·차별화, 프로그램 구성, 추진 계획, 사업비 계획, 안전관리, 기대효과·자체 점검, 신청 단체·실적·확약)의 순서를 유지합니다. AI는 내용만 채웁니다. 빠진 항목은 빈칸으로 보완하고 임의 항목·표 열 추가는 반영하지 않습니다. 기존 저장 자료, 편집 화면, 서버 미리보기, PDF·Word·한글 다운로드에 동일하게 적용됩니다. 프로그램 등의 행 수는 내용에 맞게 바뀔 수 있지만 표의 열과 제목은 고정입니다.

## 외부 공유 링크

Cloudflare Quick Tunnel로 실행 중인 로컬 v06에 임시 HTTPS 주소를 연결할 수 있습니다. 현재 주소는 `.runtime/public_origin.json`, 연결 상태는 `.runtime/cloudflared.log`에만 저장합니다. 서버는 이 파일에 등록된 정확한 HTTPS 호스트와 출처만 추가 허용하며, 외부 세션 쿠키에는 Secure를 적용합니다. 로컬 서버와 터널이 모두 실행 중이어야 접속할 수 있고, 터널을 새로 만들면 주소가 바뀝니다. 공개 링크에서도 가입·연락처 인증·소속 승인이 필요합니다. 인증 발송 서비스 미설정 상태에서는 일반 사용자의 인증 완료가 불가능합니다.

## 사전 등록 일반 관리자

최고 관리자의 요청으로 원현희·양유현·오민주 계정은 기관 선택 없이 이름·지정된 비밀번호로 로그인합니다. 공개 가입이 아닌 로컬 사전 등록 계정이며 별도의 연락처 인증·승인·인증 앱 없이 개인별 기획 기능을 사용할 수 있습니다. 화면 명칭은 일반 관리자이고 전체 사용자 조회·승인·다른 사용자의 업무자료 열람 권한은 없습니다. 최고 관리자 계정은 기존 인증 앱 2단계 인증을 유지합니다. 비밀번호는 문서나 클라이언트 코드에 저장하지 않습니다.

## 대화 파일 첨부와 재접속 로그인

대화 입력창 왼쪽 + 버튼 또는 대화창으로 파일을 끌어다 놓아 첨부합니다. 전송 전 첨부 해제가 가능하며, 읽기 실패한 파일은 해제하거나 다시 첨부해야 합니다. 파일만 전송하면 핵심 내용과 기획 반영 사항을 요청합니다.

지원: PDF, DOCX, PPTX, XLSX, HWPX, TXT, MD, CSV, JSON, PNG, JPG, JPEG, WebP. HWP·XLS 등 구형 바이너리 파일은 변환이 필요합니다. 파일당 8MB, 회당 5개·20MB이며 1개 파일에서 최대 4만 자, 한 답변에 최대 12만 자를 참고합니다. 일부만 읽은 경우 첨부 목록과 AI 참고 정보에 표시됩니다. PDF·이미지는 기존 Gemini API로 읽으며, Office·HWPX·텍스트는 로컬에서 텍스트를 추출합니다. Office 안에 그림으로만 들어 있는 자료는 PDF나 이미지로 변환하세요. 원본 바이너리는 보관하지 않고 추출한 내용과 메타정보만 비공개 DB에 저장합니다.

첨부 ID의 소유자를 매번 확인합니다. 다음 대화·기획안 작성에서도 최근 첨부 5개를 참고합니다. 파일 기반 답변은 첨부 파일명을 출처로 구별하고, 파일 내용은 명령이 아닌 참고 자료로 취급합니다. 파일 기반 답변의 도구는 로컬 지침·수치 자료 조회만 허용합니다.

일반 사용자는 사이트 HTML 재접속·새로고침 시 다시 로그인합니다. 인증을 마친 최고 관리자와 일반 관리자는 같은 브라우저에서 30일간 자동 로그인되며 재방문 시 만료일을 갱신합니다. 새 기기·다른 브라우저·쿠키 삭제·만료·로그아웃 뒤에는 새 로그인이 필요합니다. 최고 관리자 MFA 중간 세션은 자동 로그인 대상이 아니며, 정지 계정도 즉시 차단됩니다. 브라우저에는 비밀번호 대신 HttpOnly 인증 토큰만 저장합니다.


## 사용자 중심 기획 흐름 (2026-11-24)

상단 메뉴: 홈 → 기획 시작 → 조건 선택 → 기획 결과 → (지도·굿즈 탐색) → 최종 검토 → 저장·활용. 기획 결과에서는 조건표·조사 내용·고정 양식 기획안·검토 항목을 탭으로 확인합니다. 담당자 검토는 미정·근거·예산·역할 확인과 담당자·의견을 저장하며, 대화/조건/기획/굿즈 변경 시 재검토 표시됩니다. 원문 링크와 첨부는 참고 근거 목록이지 자동 사실 검증 인증이 아닙니다.

홈의 1분 예시 시연은 60초 MP4 자막형 안내 영상입니다. 재생·일시정지·구간 탐색과 한국어 VTT 자막이 있으며 예시 데이터임을 명시합니다. 사용법 안내는 6단계와 수정 가능한 질문 예시를 제공하고 실제 질문창으로 옮깁니다. `tools/make_tutorial.swift`로 재생성할 수 있습니다.

대화는 `agent_mode: true`로 요청 분류·조건 추출 → 지침/근거 참고 답변 → 고정 양식 기획안 초안 작성을 이어서 실행합니다. 필수 정보(개최 연도·주최·예산)가 없으면 한 번에 구체적으로 질문합니다. 미입력 진행 요청을 받으면 임의 수치 없이 다음 초안 작업으로 갑니다. 지침의 S0~S10은 초안 작성 지시로 전달하고 담당자 결정·전문가 검증·S11 운영 성과를 자동 완료로 주장하지 않습니다.

각 사용자 메시지 오른쪽 아래에 새 기획·돌아가기·메시지 수정이 있습니다. 수정은 해당 턴부터 재실행하고 이후 대화와 기존 기획안은 최근 3개 수정 이력에 보관합니다. 기존 이력은 AI 입력에서 제외합니다. 실패하면 원본을 그대로 유지합니다. 새 기획은 확인 후 현재 작업을 초기화합니다.

검사: `python3 -m unittest discover -s tests -v`. 별도 임시 happy-dom 설치 후 `HAPPY_DOM_MODULE=/absolute/path/to/happy-dom/lib/index.js node tests/journey_dom_v06.mjs`로 화면 연결·버튼·수정·영상 구간 선택을 검사할 수 있습니다.

차경훈 계정은 동일한 manager 권한의 로컬 사전 등록 계정이며 표시 명칭만 차경훈 강사님으로 설정합니다. 맞춤 명칭은 권한 상승을 의미하지 않고, 본인 작업만 이용할 수 있습니다. 실제 암호는 해시로만 비공개 DB에 저장합니다.


## 문서 줄바꿈·표 서식

v06 전용 `backend/plan_export_v06.py`를 이용합니다. 사이트/미리보기/PDF는 keep-all 어절 줄바꿈과 자동 하이픈 해제를 사용하고, Word는 한국어 문단의 어절 줄바꿈 설정을 저장합니다. HWPX는 비라틴/라틴 KEEP_WORD 설정입니다. 제목 셀 #EEE8F7, 본문 교차 음영 #F8F6FC, 명시적 사방 테두리를 적용합니다. PDF는 반복 thead와 행 단위 페이지 넘김, Word는 반복 제목 행과 행 쪼개기 방지, HWPX는 글자처럼 취급 해제·셀 단위 쪽 나눔·경계선 표시를 적용합니다. A4를 사용합니다. 검증용 긴 표는 PDF 8쪽·Word 렌더링 11쪽에서 마지막 행과 하단선을 확인했으며 HWPX 구조/넘침 검사 결과 경고가 없었습니다. 실제 편집기·글꼴 변경 시 재배치될 수 있으므로 최종 출력의 미리보기를 확인하세요.


## 조건 선행 필수 정책 · 최신 변경

메뉴는 01 홈 → 02 조건 선택 → 03 AI 기획 → 04 기획 결과 → 05 축제 지도 → 06 굿즈 → 07 최종 검토 → 08 저장·활용 순서입니다. 상단 메뉴 바로 아래의 중복 단계 버튼은 제거했습니다. 조건 선택 11개 항목은 모두 필수이며 빈칸·미정·미입력으로 건너뛸 수 없습니다. 예산의 산정 요청은 명시적 선택으로 허용합니다. 기획 시작/초안 생성/메시지 수정 재실행은 화면과 서버 양쪽에서 조건 완료 여부를 검사하고, 미완료 시 AI 호출 없이 차단합니다. 이전의 미입력 진행 정책보다 우선합니다.

메시지 아래는 새 기획·메시지 수정 버튼만 남깁니다. 수정 입력창을 열 때 기존 대화 스크롤과 화면 위치를 보존하고 preventScroll로 포커스합니다. 차경훈 계정의 최신 표시 명칭은 강사님 최고✨이며 실제 역할은 manager 그대로입니다.

- 신규 가입자의 연락처 인증은 실제 메일/SMS 발송 서비스 설정이 필요합니다. 기존 관리자 계정은 현재 DB를 사용합니다.

### 2026-11-24 접속 장애 수정

위 배포 설명 중 첫 HTML 프록시 부분은 이 변경으로 대체합니다. `index.html`/`index_v06.html`은 이제 Vercel 정적 파일이며 루트 HTML의 외부 rewrite는 제거했습니다. 백엔드가 없어도 로그인 화면·단계별 사용법·60초 시연 영상은 표시됩니다. 서버가 응답하지 않으면 로그인/가입을 비활성화하고 실제 연결 상태를 안내하며 인증 우회나 가짜 저장을 제공하지 않습니다. 정적 페이지 진입 시 `/api/entry`가 기존 관리자 로그인 유지/일반 사용자 초기화 정책을 처리합니다.

현재 로그인·AI·기록 저장은 여전히 임시 서버 의존 상태로, 상시 운영 완료가 아닙니다. Supabase 프로젝트 생성 후 계정·세션·작업공간의 PostgreSQL 이전과 Vercel 서버 API 배포가 필요합니다. 지침 DB 구축은 계정/작업공간 DB 이전과 별개로 진행할 수 있습니다. 대표 주소 `https://daesatu-festival-v06.vercel.app/`는 유지합니다.
