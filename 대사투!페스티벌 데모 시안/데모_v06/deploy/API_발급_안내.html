대사투! 페스티벌 · API·사이트 발급 안내

AI 축제 기획 에이전트(v06)에 필요한 키와 발급 사이트를 한 번에 정리했습니다. 키 값은 직접 발급받아 아래 “넣는 곳”에만 입력하세요.

꼭 지킬 것 · 키 값은 채팅·메모·GitHub(공개 저장소)에 붙여 넣지 마세요. 넣는 곳은 두 곳뿐입니다.
① 내 컴퓨터: 데모_v06/.env 파일(git에 올라가지 않음)   ② 운영 서버: Render → daesatu-festival-api → Environment (Key에는 이름만, Value에는 값만. 이름=이나 따옴표를 붙이지 않기)

3. 지식 자동 갱신용 (GitHub Secrets)

main에 지침 문서(세부지침안·대사투)가 올라오면 AI 지식 DB를 자동으로 맞추는 설정입니다. 등록 전에는 아무 일도 하지 않습니다.

어디에무엇을
github.com/k-1026/Chiikawa → Settings → Secrets and variables → Actions → New repository secretDATABASE_URL · GEMINI_API_KEY · EMBEDDING_MODEL · EMBEDDING_DIM (값은 .env와 동일, 4개 모두 등록)

4. 값을 넣는 순서 (한 번에 정리)

  1. 키 발급 → 데모_v06/.env에 한 줄씩 이름=값 형태로 저장(공백·따옴표·대괄호 없이).
  2. Render → daesatu-festival-api → Environment → Edit → Add로 같은 이름·값 입력 → Save, rebuild, and deploy (1~2분).
  3. (지식 자동 갱신을 쓰려면) GitHub Secrets 4개 등록.
  4. 채팅에는 “넣었어”라고만 알려 주세요. 값은 읽지 않고 연결·동작만 확인합니다.

5. 굿즈 종류 추천은 별도 API가 필요한가요?

아니요. 이미 연결된 Gemini가 컨셉·대상·예산을 보고 3종을 추천합니다. Gemini 한도가 찼을 때는 컨셉 키워드로 고르는 방식으로 자동 전환되어 추천이 비지 않습니다.

알아둘 점 · 무료 한도는 서비스마다 정책이 바뀔 수 있습니다. “한도·과금” 칸은 발급 화면에서 한 번 더 확인하세요. · 키가 노출되었다고 의심되면 해당 사이트에서 키를 삭제하고 새로 발급한 뒤 같은 위치만 교체하면 됩니다. · 운영 서버(Render 무료)는 한동안 쓰지 않으면 잠들어 첫 접속에 약 50초 걸립니다.
