# Supabase 이전 준비

프로젝트 이름: **대사투!festival-ai agent demo**
대표 사이트: https://daesatu-festival-v06.vercel.app/

현재 이 폴더는 이전 준비 파일입니다. Supabase 프로젝트 생성 및 실데이터 이전은 아직 실행되지 않았습니다.

## 이전 범위

기존 계정, 비밀번호 해시, 최고/일반관리자 구분 및 표시 명칭, 인증 앱 설정, 세션, 기관, 개인 작업공간(조건·채팅·고정 양식 기획안·검토·굿즈), 첨부 추출 텍스트, 감사 기록을 보존합니다. 지침 원문 DB 구축은 별도 단계입니다.

`001_accounts.sql`은 `daesatu` 비공개 스키마를 사용하고 모든 테이블의 RLS를 활성화합니다. 브라우저의 anon/authenticated 역할은 이 스키마와 테이블에 접근할 수 없습니다. 비밀번호 해시와 인증 앱 비밀값은 서버에서만 취급합니다.

## 실행 조건

1. Supabase 프로젝트를 생성해야 합니다. 자동 생성 가능한 Supabase 연결은 현재 대화에 제공되지 않았습니다.
2. DB 연결 문자열은 안전한 로컬 환경변수 `DATABASE_URL`에만 설정합니다. 채팅, Git, 공개 파일에 기록하지 않습니다.
3. 서버 측 Python 환경에 `psycopg[binary]`가 필요합니다. 연결은 `sslmode=require`를 사용합니다.
4. `python3 tools/migrate_supabase_v06.py`는 원본 DB를 읽기 전용으로 점검하고 테이블별 건수만 출력합니다.
5. `python3 tools/migrate_supabase_v06.py --apply`는 대상 스키마/데이터를 단일 트랜잭션으로 생성·복사하고 건수를 대조합니다. 기존 대상에 데이터가 있으면 덮어쓰지 않고 중단합니다. 원본 SQLite는 변경하지 않습니다.

## 서비스 이전과 AI 분리

DB 복사만으로 기존 SQLite 서버가 Supabase로 자동 전환되지는 않습니다. PostgreSQL 저장소 어댑터와 Vercel 서비스 API 배포·환경변수 설정·실제 계정 검증을 마쳐야 로그인이 복구됩니다. 현재 이 단계는 미완료이며 임시 터널 의존성을 제거해야 합니다.

`AI_ENABLED=0`이면 AI 채팅/초안 생성은 명시적인 준비 중 응답을 반환하고 수동 작업공간, 지도·굿즈, 검토, 문서 편집·내보내기는 AI API를 호출하지 않습니다. 화면의 '빈 양식으로 직접 작성'은 11개 필수 조건 저장 후 기존 고정 양식을 열고 개인 작업공간에 저장합니다. 자동 조사·자동 생성 기능은 AI API 연결까지 사용할 수 없습니다.

PDF 서버 변환은 Chrome 설치가 필요하므로 Vercel 전환 시 브라우저 인쇄 또는 별도 변환기를 확인해야 합니다. Word/HWPX에는 별도의 Python 의존성이 필요합니다.

## 검증 범위

읽기 전용 추출, 민감정보 미출력, 스키마 접근 제한과 AI 비활성 수동 작업은 로컬 검사 대상입니다. 실제 PostgreSQL 연결·DDL 실행·마이그레이션·클라우드 로그인의 성공은 아직 검증되지 않았습니다.
