# D. 대사투 페스티벌 굿즈 공통 지침서 v01

작성일: 2026-11-17 · 브랜드: 대구 얼라들 · 적용: 고정 굿즈 8개 품목군

**문서 상태: 검토용 초안.** 사용자가 정한 운영 조건은 확정 조건으로 기록하고, 아래 배치·평가·출력 방식은 작성자의 실행 제안으로 구분한다. 이 문서 작성은 상품 디자인, 사투리 문구, 소재·치수 또는 양산 승인을 뜻하지 않는다.

## 1. 목적과 적용 범위

대키미·외지몽과 대구 사투리를 활용해 하나의 브랜드로 보이는 축제 굿즈를 만든다. 이후 제작할 품목별 디자인 시트, 상품 샘플 이미지, 수정 프롬프트와 검수에 이 지침을 함께 사용한다.

목표 인상은 **캐릭터의 귀여움, 사투리를 알아가는 재미, 축제 이후에도 쓰고 싶은 일상성**이다. 지역민에게는 공감, 관광객에게는 이해와 기념의 경험을 준다. 이는 디자인 방향 제안이며 실제 구매 선호를 검증한 결과는 아니다.

현재 단계는 공통 규칙 작성이다. 개별 디자인 시트와 샘플 이미지는 이 기준을 검토한 뒤 아래 순서대로 제작한다. 이 문서는 실행 중인 자동화 프로그램이 아니라 사람이든 AI든 같은 절차로 작업하도록 하는 문서형 하네스다.

## 2. 사용자가 정한 프로젝트 조건

| 항목 | 조건 |
|---|---|
| 축제 | 대사투 페스티벌 — 대구 사투리 페스티벌 |
| 지역·시기 | 대구 / 여름 |
| 방문객 | 대구 주민 및 타지역 관광객 |
| IP·브랜드 | 대키미 / 외지몽 / 대구 얼라들 |
| 지역 소재 | 산과 더위. 캐릭터·사투리를 보조하는 소재로 사용 |
| 고정 상품 | 아래 8개 품목군을 매년 운영 |
| 예산 | 매년 기획자가 입력 |
| 판매가 | 외부 유사 상품 조사 → AI가 가격 제안 → 사람이 최종 선택 |
| 제작 완료 | 축제 홍보 시작 전 전체 판매 물량의 제작·입고·검수 완료 |

| 향후 데이터 | 회차별 판매·재고·후기를 수집하고 다음 회차에 활용 |

신규 상품은 기존 협의안인 **매년 후보 5종 추천 → 사람이 2종 선택**을 운영 기본안으로 둔다. 고정 상품의 색상·문구·캐릭터 옵션을 새 상품 종류로 중복 집계하지 않는다. 고정 8종은 품목군 수이며 실제 SKU 수·제작 수량은 별도 결정한다.

## 3. 품목별 작업 순서와 핵심

| 순서 | 품목 | 반드시 담을 특징 | 다음 단계에서 정할 것 |
|---|---|---|---|
| 01 | 사투리 키링 & 마스코트 키링 | 사투리형과 캐릭터형을 구분하고 함께 연출 가능하게 구성 | 소재, 문구, 성체/아기, 형태, 크기, 체결 방식 |

| 04 | 마그넷 | 캐릭터와 사투리를 결합한 기념품 | 단독/듀오 구성, 자석 구조, 크기 |

| 08 | 텀블러 | 캐릭터·사투리·로고의 읽힘을 곡면 위에서 유지 | 용량, 본체·뚜껑, 표면, 인쇄 영역·공법 |

### 4.2 충돌 시 우선순위

1. 사용자의 최신 명시적 수정·선택.
2. 사용자가 승인한 해당 버전 이미지 및 그 버전에 적용되는 확정 규칙.
3. 이 공통 지침의 확정 조건 및 승인된 품목별 시트.
4. 기존 가이드의 참고 수치, 과거 시안, 작성자의 신규 제안.

승인 상태가 불명확하거나 기준끼리 충돌하면 해당 항목을 ‘확인 필요’로 적고 두 기준을 섞어 새 정답을 만들지 않는다. 충돌하지 않는 문서 작업은 계속할 수 있다. 미확정 항목이 시안의 핵심을 바꾸는 경우 샘플 생성 전에 사람이 선택한다.

첨부된 타 축제 굿즈 사진은 **상품 구성과 진열 방식의 참고**다. 타 브랜드의 로고·캐릭터·고유 그래픽을 복제하거나 사진 속 제품 수를 우리 확정 수량으로 읽지 않는다. 공유된 Claude 전체 기획 링크는 본문을 읽지 못했으므로 그 안의 구조를 확인했다고 쓰지 않는다.

## 5. 캐릭터 정체성 고정 규칙

### 5.1 공통으로 해야 할 것

- 작업마다 **성체 또는 아기 버전 중 무엇을 쓰는지와 기준 이미지**를 먼저 지정한다. 미지정이면 시트에 선택 칸을 남기고 최종 샘플 생성은 보류한다.
- 대키미는 고양이형 외계인, 외지몽은 강아지형 외계인으로 유지한다.
- 각 캐릭터의 귀·더듬이·눈·코·입·주둥이·꼬리와 신체 비율은 선택한 기준 이미지에 맞춘다.
- 더듬이는 캐릭터당 2개이고 끝 구슬은 각각 1개다. 프레임 밖 잘림이나 가림은 없는지 별도로 확인한다.
- 성체의 완전히 뜬 눈은 기존 얼굴 기준에 따라 눈마다 큰 별 1개와 작은 반짝임 2개를 유지한다. 감은 눈은 하이라이트도 가려진다. 아기는 선택한 아기 시트를 따른다.
- 성체 대키미의 입 주변은 하늘색이다. 성체 외지몽의 크림빛 주둥이와 혼동하지 않는다. 기본 홍조 여부 역시 선택 버전 기준을 따른다.
- 대키미는 설명하는 토박이, 외지몽은 질문하고 배우는 여행자다. 서로 동등한 친구로 표현한다.
- 얼굴만 쓰는 인쇄 그래픽과 전신 그래픽을 구분한다. 얼굴형 그래픽에서 몸통·꼬리가 없는 것을 누락으로 판정하지 않는다.

### 5.2 하면 안 되는 것

- 두 캐릭터의 종, 귀 형태, 얼굴 특징, 역할을 뒤바꾸기.
- 승인 없이 성체 얼굴에 아기 몸통을 붙이거나 버전별 털·홍조·꼬리를 혼합하기.
- 얼굴을 다른 캐릭터처럼 둥글게 다시 그리거나 눈·볼·배·구슬을 임의로 키우기.
- 축제 분위기에 맞춘다는 이유로 몸색을 변경하기.
- 실제 몸 전체를 보여주는 장면에서 더듬이·귀·팔다리를 누락·추가하기.
- 제품 소재와 캐릭터의 원본 표현을 혼동하기. 봉제 안대의 원단은 표현할 수 있지만 인쇄된 캐릭터를 임의로 털 인형 스타일로 바꾸지 않는다.
- 미승인 보정 수치를 원본 모델의 실측치 또는 검증된 재현값으로 표현하기.

| 요소 | 적용 기준 |
|---|---|
| 대키미 성체 대표색 | 하늘색 #6DCFF5. 조명·인쇄·소재 차이를 몸 무늬로 만들지 않음 |
| 외지몽 성체 대표색 | 초록색 #008C3A. 선택한 아기 버전의 색을 이 값으로 임의 덮어쓰지 않음 |
| 승인 로고 | 민트·코랄·크림 배색과 2단 구성 유지 |
| 바탕색 제안 | 흰색·아이보리 등 캐릭터와 문구가 읽히는 바탕 우선 검토 |
| 산·더위 소재 제안 | 산 능선, 햇빛, 더위에 대한 캐릭터의 반응 등을 보조 요소로 제한 |

로고는 승인 PNG와 로고 시트를 사용한다. ‘대구 / 얼라들’ 2단 구성, 행성이 ‘얼’의 ㅇ 역할을 하는 구조, 행성 고리·더듬이·별의 구성을 보존한다. 일반 폰트로 재입력하거나 파랑·초록으로 일괄 변경하지 않는다. 승인되지 않은 가로형·단색형·자수 단순화형을 확정 로고로 취급하지 않는다.

로고를 모든 상품 정면에 크게 넣을 필요는 없다. 작은 제품은 뒷면·포장·행택에 적용할 수 있다. 승인 PNG는 벡터 파일이나 투명 배경 파일이라고 가정하지 않으며, 생산용 가공이 필요하면 별도 작업·검토한다.

장식은 캐릭터·사투리의 읽힘을 돕는 범위에서 사용한다. 과도한 문구·로고 반복과 상충하는 여러 스타일을 한 상품에 몰아넣지 않는다. 타 지역을 낮추거나 관광객을 조롱하는 웃음 대신 질문·설명·공감의 웃음을 지향한다.

## 7. 사투리 문구와 한글 처리

### 해야 할 것

- 문구마다 원문, 뜻풀이, 화자, 적용 상품, 상태를 기록한다.
- 사투리의 실제 의미·지역 어감은 대구 지역 담당자가 확인한다. AI의 추정을 검증된 사실로 적지 않는다.
- 관광객에게 설명이 필요하면 포장·상품 카드·스티커 구성에 뜻풀이를 배치한다. 작은 상품에 모든 설명을 억지로 넣지 않는다.
- 승인 문구는 띄어쓰기·문장부호·줄바꿈을 포함해 그대로 유지한다.
- 이미지에서 한글이 깨지면 정확한 문자 그래픽을 후편집으로 합성한다. 생성 모델이 쓴 틀린 글자를 그대로 통과시키지 않는다.

### 하면 안 되는 것

- 새로운 문구를 승인된 문구처럼 사용하기.
- 기존 티셔츠 문구를 교정·축약하면서 변경 내역을 남기지 않기.
- 사투리를 모두 과장된 억양·무례한 말투로 표현하기.
- 뜻이 다르거나 대구 표현인지 확인하지 않은 문장을 대표 사투리로 단정하기.

문구 기록 양식:

| 문구 ID | 원문·줄바꿈 | 뜻풀이 | 화자 | 상품 | 근거·확인자 | 상태 |
|---|---|---|---|---|---|---|
| COPY-001 | 입력 | 입력 | 대키미/외지몽/공통 | 입력 | 입력 | 제안/검토/확정 |

## 8. 품목별 디자인 시트의 필수 구성

각 품목의 MD는 다음 항목을 갖춘다.

1. 상품 ID, 버전, 작업일, 상태와 이번 변경점.
2. 상품 목적, 판매 단위, 디자인 옵션. 품목군·SKU·사이즈·생산 개수 구분.
3. 캐릭터 버전과 기준 이미지의 실제 경로, 문구 원문·로고 파일.
4. 고정할 요소 / 변경 가능한 요소 / 금지 사항.
5. 정면·뒷면·측면·인쇄 전개 등 필요한 면과 그래픽 배치.
6. 치수·소재·공법 표. 확정값·디자인 제안값·업체 확인 필요값 구분.
7. 샘플 이미지 생성 프롬프트와 수정 프롬프트.
8. 품목별 시각 검수 및 실물 샘플 확인 항목.
9. 선택 결과, 미정 사항, 다음 작업.

치수는 mm, 원단 중량은 해당 단위, 용량은 mL처럼 단위를 명시한다. 캐릭터 세계관상의 키를 실제 굿즈 높이로 가져오지 않는다. 재단선·도련·최소 획·색상 수 등은 업체 템플릿을 확인한 뒤 확정한다. 근거 없는 ‘생산 가능’ 판정을 내리지 않는다.

## 9. 티셔츠·수면안대 추가 디벨롭 원칙

두 품목은 기존 시안의 단순 재출력으로 완료 처리하지 않는다. 다음 비교안 3개씩은 **작성자 제안**이며 어느 안도 아직 선택되지 않았다.

| 품목 | A — 기존안 보정 | B — 일상 사용 중심 | C — 사투리 관계 중심 |
|---|---|---|---|
| 티셔츠 | 기존 대구토박이/외지인 문구를 유지하고 인쇄 크기·행간·대비 보정 | 작은 가슴 그래픽과 절제된 뒷면 구성. 문구 축약은 별도 제안 | 두 캐릭터의 질문·설명을 앞뒤에 연결하는 신규 그래픽 제안 |
| 수면안대 | 기존 잠온다/졸리다 문구와 캐릭터 장식을 유지하고 비율·자수 가독성 보정 | 더 낮고 작은 장식, 중앙 문구, 안감·밴드 편안함 검토 | 두 안대를 나란히 놓았을 때 사투리와 표준어가 짝으로 읽히는 배치 |

티셔츠는 실제 앞·뒷면, 착용자 왼쪽과 관찰자 오른쪽을 구별한다. 흰 바탕·파란/초록 인쇄라는 기존 방향과 새 색상 제안은 구분한다. 원문 보존본과 문구 개선안을 각각 기록한다.

안대는 눈을 덮는 영역, 코 부분, 얼굴 접촉면, 귀·더듬이 돌출, 밴드 조절부를 확인한다. 장식이 예쁘다는 이유만으로 눈 압박·빛샘·착용감을 통과했다고 표시하지 않는다. 자수의 뒷면이 얼굴에 직접 닿는지 실물에서 확인한다.

### 10.2 공통 생성 프롬프트

다음 문장에 작업 카드와 품목별 시트를 붙이고 실제 기준 이미지를 첨부한다.

> 대사투 페스티벌의 대구 얼라들 공식 굿즈 검토용 상품 샘플을 만든다. 첨부한 선택 버전의 대키미·외지몽을 동일 캐릭터로 재현한다. 캐릭터별 귀·더듬이 2개·얼굴·색상·주둥이·신체 비율을 유지한다. 성체와 아기 버전을 섞지 않는다. 로고를 노출하는 면에는 승인 로고 원본을 사용하고 글자·행성 구조·민트/코랄 배색을 바꾸지 않는다. 문구는 작업 카드의 원문과 줄바꿈 그대로 적용한다. 상품의 실제 재질·구조·인쇄 면에 맞게 표현하며 정확한 치수와 기능이 검증된 것으로 주장하지 않는다. 작업 카드에 없는 문구·캐릭터·장식·다른 브랜드를 추가하지 않는다. 이번 작업의 고정 요소와 변경 요소를 지키고, 상품을 자르지 않은 비교 가능한 시점으로 출력한다. 읽히지 않는 한글·누락된 부품·불가능한 연결 구조는 검수 실패로 보고 수정한다.

### 10.3 출력 형식 제안

- 한 품목에 같은 기본 모델·조명·배경을 적용한다. 비교안은 우선 배치·크기 등 한두 요소만 바꾼다.
- 기본 상품 컷은 밝은 중립 배경, 부드러운 조명, 전체 외형이 보이는 구도로 한다.
- 치수 설명용 정투영 도안과 분위기용 실사 목업을 구분한다. 원근 목업에서 실측했다고 쓰지 않는다.
- 필요한 면은 별도 컷으로 제공한다. 티셔츠 앞뒷면, 머리띠 구조, 텀블러 곡면 전체를 한 시점으로 검증하지 않는다.
- 상품에 인쇄되는 그래픽과 시트 외부의 제목·주석을 구분한다. 샘플 컷의 표기는 ‘검토용 시안’으로 한다.
- 평면 그래픽은 투명 배경이 필요한지 명시한다. 흰 배경 파일을 투명 배경이라고 전달하지 않는다.
- 파일명 제안: `D01_키링_대키미_성체_A_v01_정면.png`. 수정 시 v02로 증가시키고 원본은 보존한다.

### 10.4 검수 판정

각 항목은 **통과 / 수정 필요 / 확인 불가 / 해당 없음**으로 적는다. 해당 없음에는 이유를 쓴다. AI 자체 검수와 사람이 확인한 결과를 구분한다.

| ID | 검수 항목 | 실패 예 |
|---|---|---|
| H01 | 캐릭터 버전·종·정체성 | 대키미가 강아지처럼 보임, 아기·성체 혼합 |
| H02 | 귀·더듬이·얼굴·꼬리 | 더듬이 3개, 전신 컷 꼬리 누락, 주둥이 뒤바뀜 |
| H03 | 색상·로고 | 몸색 임의 변경, 로고 재타이핑, 행성 구조 변형 |
| H04 | 문구 정확성 | 오탈자, 임의 축약, 줄바꿈·문장부호 변경 |
| H05 | 상품 구조·면의 일관성 | 앞뒷면 불일치, 불가능한 고리 연결, 인쇄가 솔기를 넘어감 |
| H06 | 선택 규격·작업 조건 | 요청하지 않은 재질·색상·장식 추가 |
| H07 | 원본·상태·근거 표시 | 미승인 이미지를 승인본으로 표기, 추정치를 실측으로 주장 |

**H01~H07의 해당 항목 중 하나라도 ‘수정 필요’면 선택안 완료로 넘기지 않는다.** 확인 불가는 통과로 치지 않으며 시각 검수와 실물 검수의 남은 범위를 명시한다. 작은 출력에서 얼굴 디테일이 뭉개지면 도안을 임의 생략하기보다 크기·구도·공법 조정을 제안한다.

필수 검수 통과 후에만 다음 4항목을 각각 1~5점으로 비교한다: 캐릭터 매력, 사투리 전달력, 가독성, 품목 간 통일성. 점수는 담당자의 비교 판단을 돕는 제안 기준이며 원본 유사도 백분율이 아니다. 높은 점수로 필수 위반을 상쇄하지 않는다.

### 10.5 수정 루프

1. 원본과 결과를 나란히 보고 오류 위치·기대값·실제값을 기록한다.
2. 이번 수정은 가장 큰 오류 1~2개를 우선 대상으로 한다. 합격한 요소는 보존한다.
3. 수정 이미지에서도 H01~H07 전체를 다시 확인해 다른 부분이 변하지 않았는지 본다.
4. 같은 오류가 3회 반복되면 동일 프롬프트 반복 대신 도안 합성·후편집·작업 분리를 적용한다. 원본이 부족한 경우 필요한 참조를 특정한다.
5. 사람의 선택·문구 확인 후 선택안으로 기록한다. 실물 샘플 검수 전 양산 승인으로 올리지 않는다.

수정 프롬프트 양식:

> 첨부한 현재 결과를 편집한다. 유지할 것은 [목록]이다. 수정할 것은 [위치]의 [실제 오류]이며 기준은 [파일/규칙]이다. [목표 모습]으로 바꾼다. 이번 요청과 관련 없는 얼굴·색상·문구·재질·구도는 유지한다. 완성 후 변경점과 남은 확인 사항을 별도로 적는다.

결과 기록 양식:

| 작업 ID | 기준 파일·버전 | 결과 파일 | 검수 결과·오류 위치 | 이번 수정 | 사람 선택 | 남은 확인 |
|---|---|---|---|---|---|---|
| 입력 | 입력 | 입력 | 입력 | 입력 | 미선택 | 입력 |

## 11. 가격·일정·실물 제작 연결 규칙

### 가격

예산은 매년 기획자가 입력한다. 판매가 조사는 해당 상품 디자인·소재·크기가 정리된 뒤 수행한다. 현재 문서에는 조사하지 않은 가격을 넣지 않는다.

조사 양식은 `상품명 / 판매처·직접 URL / 조사일 / 실제 판매가 / 정상가·할인가 / 소재·크기·세트 구성 / 배송비 / 비교 가능성`이다. 품목별 비교 가능한 사례 3건 이상을 목표로 하되 부족하면 실제 확인 건수와 차이를 공개한다. 실판매가, 제작 견적, 추정 원가를 구분한다. 범위·추천가·근거를 제시하고 최종 판매가는 사람이 결정한다.

### 일정

필수 입력은 홍보 시작일이며, 확정되지 않으면 임의 날짜를 넣지 않는다. 모든 기간은 업체·담당자가 확인한 영업일/달력일 기준을 구분해 계산한다.

- 검수 완료 목표일 = 홍보 시작일 - 담당자가 정한 여유 기간. 최소한 홍보 시작일보다 앞선 날짜여야 한다.
- 입고 목표일 = 검수 완료 목표일 - 검수·불량 대응 소요 기간.
- 발주 마감일 = 입고 목표일 - 생산·배송 소요 기간.
- 디자인 확정 마감일 = 발주 마감일 - 생산 파일 점검 소요 기간.
- 샘플 착수일 = 디자인 확정 마감일 - 샘플 제작·배송·검토·수정 소요 기간.

디자인 개발·가격 조사·업체 견적 기간도 위 일정 앞에 확보한다. 일정이 안 맞으면 수량·옵션·공법 조정안을 사람이 선택한다. AI가 홍보 시작일이나 검수 단계를 임의로 미루거나 없애지 않는다.

### 실물 확인

키링의 고리·절단면, 스티커의 칼선·접착, 머리띠·안대의 착용감, 마그넷의 부착, 에코백·티셔츠의 인쇄·봉제·세탁 후 상태, 텀블러의 인쇄·뚜껑·세척 편의 등은 실물에서 확인한다. 소재·용도에 맞는 업체 확인 자료를 받되, 이미지에서 내열·누수 방지·인체 적합성·냉감 등의 성능을 인증했다고 주장하지 않는다.

## 12. 첫 회차 KPI와 다음 회차 반영

첫해 자료 없음은 0건 판매나 낮은 선호가 아니다. 값은 `미수집`으로 두고 판매 기록과 후기 수집 절차를 운영해야 축적된다. 생성·선택 기록은 실제 고객 반응과 구분한다.

| 수집 항목 | 기준 |
|---|---|
| SKU별 판매 가능 입고 수량 | 불량 제외, 추가 입고 별도 기록 |
| 순판매 수량·순매출 | 취소·반품 차감, 할인 반영 기준 명시 |
| 판매율 | 순판매 수량 ÷ 판매 가능 누적 입고 수량 × 100. 분모 0/미수집이면 산출 안 함 |
| 재고·품절 | 실재고, 불량, 분실, 무상 지급, 품절 시각을 별도 기록 |
| 방문객 반응 | 문구·캐릭터·상품 선호와 불편 의견, 응답 수·수집 경로 함께 기록 |

전체 방문객 수만으로 굿즈 구매 전환율을 단정하지 않는다. 집계 가능한 굿즈샵 방문 수와 구매 건수 등이 있어야 해당 정의로 계산한다. 품절 때문에 판매가 멈춘 상품과 선호가 낮은 상품을 구분해 다음 회차 추천에 반영한다.

## 13. 상태와 다음 단계

문서·이미지 상태는 `초안 → 검토 중 → 선택안 → 디자인 확정 → 실물 샘플 확인 → 양산 승인`으로 구분한다. 단계가 바뀔 때 날짜·확인자·대상 버전을 기록한다. 파일이 있다는 이유만으로 다음 상태로 자동 승격하지 않는다.

현재 완료 범위는 **공통 지침서 초안 작성**이다. 다음 작업은 **01 키링 품목별 디자인 시트**이며, 실제 이미지 생성 전에 캐릭터 버전·소재·문구·기준 이미지를 작업 카드로 정한다. 이후 02~08 순서로 이어간다. 티셔츠·안대는 9절의 추가 개발 절차를 적용한다.
