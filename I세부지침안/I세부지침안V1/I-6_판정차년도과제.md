# I-6 판정·차년도 과제 — 세부 지침

> 구분: 고정 · 기본 지침: v1.1 12장(유지·개선·실험, 차년도 과제) · 진행: 초안 v1 · 최종 수정: 2026-11-18

## 1. 이 파트의 역할
- 04 운영결과를 보고 **문제별 판정**과 **프로그램별 분류(유지·개선·실험)**를 하는 기준이에요.
- 판정 결과를 **`05_차년도과제.md`**로 정리해 다음 해 기획의 입력으로 넘겨요.
- 읽는 PART: M(/festival-review, /festival-start 다음 해), 각 프로그램 파트

## 2. 확정 값

### 2-1. 문제별 판정 (P0-1 3-4 기준)

| 판정 | 뜻 |
| --- | --- |
| 해결 | 2년 연속 개선 (P0-1 3-4 초안 제안) |
| 개선 | 전년 대비 판단 지표가 좋아짐 |
| 변화 없음 | 전년과 차이가 기준 안 |
| 악화 | 전년 대비 나빠짐 |
| 측정 안 됨 | 판단 지표 중 하나라도 측정 안 됨. 추정으로 채우지 않음 |

- **첫해(2027)는 판정하지 않아요.** "해당 없음(첫해, 기준선 수집)".
- "좋아짐/나빠짐"의 수치 기준(예: ±○%p)은 아직 없어요 (P0-1 7장 5번). 정해지기 전에는 **증감 값과 방향만** 적고, 판정 칸에 "기준 미정"을 같이 적어요.

### 2-2. 프로그램 분류

| 분류 | 기준 | 다음 해 할 일 |
| --- | --- | --- |
| 유지 | 운영 지표·만족도가 안정적이고, 고칠 문제점이 없음 | 같은 형식, 규모만 조정 |
| 개선 | 계속하되 문제점(대기 시간, 혼잡, 낮은 만족도 등)이 확인됨 | 문제점 1개마다 고칠 방법 1개 |
| 실험 | **올해 처음 했거나 형식을 크게 바꾼 프로그램** | 다음 해 아래 2-3으로 다시 판정 |

- 3대 프로그램(토론·10미 포장마차·플리마켓)은 "폐지"로 분류하지 않아요 (기본 지침 3장 고정). 문제가 크면 "개선"으로 두고, 형식 변경은 사유·대안과 함께 담당자 승인으로 넘겨요.
- 분류마다 **근거(04의 어느 장·지표)**를 적어요. 근거가 "측정 안 됨"뿐이면 분류하지 않고 "판단 보류"로 둬요.

### 2-3. 실험 프로그램의 다음 해 판정

| 결과 | 다음 해 분류 |
| --- | --- |
| 참여·만족도가 같은 해 다른 부대 프로그램 평균 이상 | 유지 |
| 참여는 있으나 문제점 확인 | 개선 |
| 참여·만족도가 다른 부대 프로그램 평균보다 낮음 | 제외 후보 (담당자 결정) 또는 형식 바꿔 실험 1회 더 |
| 측정 안 됨 | 실험 1회 더 + 측정 준비 보강 |

- "평균 이상/이하" 비교는 같은 해 같은 유형(E-1 1차 유형) 안에서만 해요. 비교 대상이 없으면 판단 보류.

### 2-4. 05_차년도과제 목차 (festival-review 형식 + I 추가)

| 장 | 내용 |
| --- | --- |
| 1. 프로그램 분류 | 프로그램 / 유지·개선·실험 / 근거(04의 어디) / 다음 해 할 일 |
| 2. 올해와 공통점·변경 사항 | |
| 3. 다음 해 기획조건표 입력값 후보 | 예상 방문객(올해 실측 기준), 부스 재배분안(B-2), 플리마켓 확장 판단(C-1) 등 |
| 4. 보강할 조사 | 기대 대비 실제 차이가 가장 컸던 입력값 (I-8) 포함 |
| 5. 연간 추진 일정 조정 | 늦었던 측정 준비 → 다음 해 시작 시점 |
| **6. 다음 해 KPI 목표값 제안** | 2년 차부터. "전년 ○ → 올해 ○, 근거" `[추정]`, 확정은 담당자 (I-1 2-3) |
| **7. 설문 수정 제안** | 응답 수 부족, 쓸모없던 문항, 다음 해 추가 문항 후보 (I-4) |

## 3. 에이전트 행동 규칙
- 판정과 분류는 **제안**이에요. 최종 결정은 담당자가 해요 (기본 지침 8장 3번).
- 좋은 결과만으로 "유지"를 주지 않아요. 불리한 지표(악화, 측정 안 됨)도 근거 칸에 함께 적어요.
- 05 3장 입력값 후보는 다음 해 `/festival-start`가 읽어요. 실측이 아닌 값은 `[추정]`을 붙여요.
