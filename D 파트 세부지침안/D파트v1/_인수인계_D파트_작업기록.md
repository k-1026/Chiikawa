## 3. 작업 규칙
- **한 단계씩 순서대로** 진행한다: D-00 → D-01 → … → D-06 → 통합본 → 품목 시트 01~08. 순서를 앞당기지 않는다.
- **한 내용은 한 곳에서만 정하고 다른 파트는 링크한다** (사투리 뜻 검수 J-3, 콘텐츠 윤리 P0-10, 상점 위치 P0-3, 운영 시간 P0-4, 예산 P0-6/H-1, KPI I-1, 마스코트 IP 요약 P0-11, 스탬프 M-6/E/G-3).
- 파일 양식은 E파트 형식(0~9장, 근거 라벨 `[확인] [해석] [가설] [추정]`). 품목 시트는 `D-03_품목별수치/_품목시트_양식.md`(0~11장)를 따른다.
- 수치는 확정 / 디자인 제안값 / 업체 확인 필요값으로 구분한다. 업체 템플릿 전에는 "생산 가능" 판정을 쓰지 않는다.
- 사투리 문구는 전부 `제안` 상태로 두고, 대구 지역 담당자(J-3) 확인 전에는 확정으로 쓰지 않는다. 사투리가 맞다고 단정하지 않는다.
- 원본 자료는 보존한다. 파일이 있다는 사실이 승인을 뜻하지 않는다 ("최종"·가장 큰 v번호도 자동 승인 아님, `Mascot/00_팀원용_현재자료안내/` 참고).
- 품목 시트는 **샘플 이미지 없이 내용만** 쓴다. 8~9장은 `이미지 대기`.
- 분리 파일을 고치면 `D_굿즈_지침_통합본_v1.md`에도 같은 내용을 반영한다 (헤딩 한 단계 낮춤, `> 목차:` 줄 제거, 형제 링크는 일반 텍스트로).
- 커밋은 `세부지침안/D파트v1`만 대상으로 한다. 작업 폴더에 사용자가 만든 다른 변경이 많으니 건드리지 않는다.
