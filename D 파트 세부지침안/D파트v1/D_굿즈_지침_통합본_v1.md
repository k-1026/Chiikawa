#### 2-2. 캐릭터 정체성 고정 규칙

- 작업마다 **성체 / 아기 버전 중 무엇을 쓰는지와 기준 이미지**를 먼저 지정한다. 미지정이면 시트에 선택 칸을 남기고 최종 샘플 생성은 보류한다.
- 대키미는 **고양이형 외계인**, 외지몽은 **강아지형 외계인**으로 유지한다.
- 귀·더듬이·눈·코·입·주둥이·꼬리와 신체 비율은 선택한 기준 이미지에 맞춘다.
- 더듬이는 캐릭터당 **2개**이고 끝 구슬은 각각 1개다. 프레임 밖 잘림이나 가림이 없는지 별도로 확인한다.
- 성체의 완전히 뜬 눈은 눈마다 **큰 별 1개와 작은 반짝임 2개**를 유지한다. 감은 눈은 하이라이트도 가려진다. 아기는 선택한 아기 시트를 따른다.
- 성체 대키미의 입 주변은 **하늘색**이다. 성체 외지몽의 **크림빛 주둥이**와 혼동하지 않는다. 기본 홍조 여부는 선택 버전 기준을 따른다.
- 대키미는 설명하는 토박이, 외지몽은 질문하고 배우는 여행자다. 서로 **동등한 친구**로 표현한다.
- 얼굴만 쓰는 인쇄 그래픽과 전신 그래픽을 구분한다. 얼굴형 그래픽에 몸통·꼬리가 없는 것은 누락이 아니다.

- 문구마다 **원문, 뜻풀이, 화자, 적용 상품, 상태**를 기록한다.
- 사투리의 실제 의미·지역 어감은 **대구 지역 담당자가 확인**한다 (J-3). AI의 추정을 검증된 사실로 적지 않는다.
- 관광객에게 설명이 필요하면 포장·상품 카드·스티커 구성에 뜻풀이를 둔다. 작은 상품에 모든 설명을 억지로 넣지 않는다.
- 승인 문구는 띄어쓰기·문장부호·줄바꿈까지 그대로 유지한다.
- 이미지에서 한글이 깨지면 정확한 문자 그래픽을 **후편집으로 합성**한다. 생성 모델이 쓴 틀린 글자를 그대로 통과시키지 않는다.

#### 2-5. 검수 판정 (H01~H07)

각 항목은 **통과 / 수정 필요 / 확인 불가 / 해당 없음** 으로 적는다. 해당 없음에는 이유를 쓴다. AI 자체 검수와 사람이 확인한 결과를 구분한다.

| H02 | 귀·더듬이·얼굴·꼬리 | 더듬이 3개, 전신 컷 꼬리 누락, 주둥이 뒤바뀜 |

#### 2-6. 상태 승격

문서·이미지 상태는 다음 순서로만 올린다.

`초안 → 검토 중 → 선택안 → 디자인 확정 → 실물 샘플 확인 → 양산 승인`

- 단계가 바뀔 때 **날짜·확인자·대상 버전**을 기록한다.
- 파일이 있다는 이유만으로 다음 상태로 올리지 않는다.
- 디자인 검토와 양산 발주는 별도 상태다. 실물 샘플 검수 전에는 양산 승인으로 올리지 않는다.

#### 2-3. 연도별 신규 상품 (5종 추천 → 2종 선택)

- 기존 협의안을 운영 기본안으로 둔다: **AI가 후보 5종을 추천하고, 사람이 2종을 고른다.**
- 후보 5종은 아래 기준을 통과한 것만 올린다. (작성자 제안, 팀 검토 전 `[해석]`)

| # | 후보 기준 | 이유 |
|---|---|---|
| 1 | 고정 8종과 다른 **새 품목** | 색상·문구 변경은 새 상품이 아님 |
| 2 | 대키미·외지몽·사투리를 중심으로 쓰고, 산·더위는 보조 소재로만 사용 | D-1 2-3절 |
| 3 | 연도 주제(M-4)와 연결되는 이유를 한 줄로 적을 수 있음 | 연도별 구분의 기본 요건 (기본 지침 4-0) |

- 후보마다 **연도 주제 연결 1줄, 예상 가격대 근거(2-6절), 제작 가능성 확인 필요 항목, 전년 대비 유지·개선·실험 구분**을 적는다.
- 선택된 2종은 D-3에 새 시트를 만든다. 다음 해에 고정으로 올릴지는 판매·후기 기록(D-5)을 보고 담당자가 정한다. `[해석]`

#### 2-4. 스탬프 교환용 현장 한정 굿즈 — D와 E의 분담

2026-11-17 담당자 결정에 따라 아래처럼 나눈다.

| 구분 | D가 정한다 | E가 정한다 |
|---|---|---|
| 굿즈 자체 | 품목, 디자인, 수량, 재고·품절 기록, IP 검수(D-1), 제작 일정(D-4) | - |
| 교환 | 교환용으로 몇 개를 따로 빼 둘지(수량), 교환용 재고가 소진되면 어떻게 표시할지 | **교환 기준(스탬프 몇 개)과 교환 단계**(어디서 확인하고 누구에게 받는지) |

#### 2-5. 예산·수량

- **예산은 매년 기획자가 입력한다** (P0-6 입력 양식, 상세 산정은 H-1). D-2는 입력받은 예산 안에서 SKU 구성안과 수량 배분 방식을 제안한다.
- 숫자를 지어내지 않는다. 입력이 없으면 `입력 필요`로 두고 8장 미확정으로 보낸다.
- **품목군 · SKU · 제작 수량은 구분해서 적는다.**

| 구분 | 뜻 | 예 (가상, 실제 값 아님) |
|---|---|---|
| 품목군 | 상품 종류. 고정 8 + 신규 2 | 아크릴 키링 |
| SKU | 품목군 × 디자인 옵션 × 사이즈 | 아크릴 키링 × 대키미·외지몽 |
| 제작 수량 | SKU별 생산 개수 | 입력 필요 |

- 첫 개최라 과거 판매·후기 자료가 없다. 이는 판매 0건이나 낮은 선호가 아니고 **`미수집`**이다. **첫 해 수량은 팀이 임의로 정하고**(`[추정]` + "임의 설정" 표시), **다음 해부터는 판매 KPI를 근거로 예측**한다 (D-4 2-3절). 이번 회차의 기록을 다음 회차 근거로 쓴다 (D-5).
- 발주 완료·제작·입고·검수는 모두 홍보 시작 전에 끝나야 한다 (2026-11-17 담당자 결정). 일정 계산은 D-4에서 한다.

#### 2-6. 판매가

- 순서는 **외부 유사 상품 조사 → AI가 가격 제안 → 사람이 최종 선택**이다.
- 판매가 조사는 해당 상품의 디자인·소재·크기가 정리된 뒤에 수행한다. 이 문서에는 조사하지 않은 가격을 넣지 않는다.
- 조사 양식:

| 상품명 | 판매처·직접 URL | 조사일 | 실제 판매가 | 정상가·할인가 | 소재·크기·세트 구성 | 배송비 | 비교 가능성 |
|---|---|---|---|---|---|---|---|
| 입력 | 입력 | 입력 | 입력 | 입력 | 입력 | 입력 | 입력 |

- 품목별로 비교 가능한 사례 **3건 이상**을 목표로 하되, 부족하면 실제 확인한 건수와 차이를 밝힌다.
- **실판매가, 제작 견적, 추정 원가를 구분한다.** 가격은 범위·추천가·근거를 함께 제시하고, 최종 판매가는 사람이 정한다.

### 3. 에이전트 행동 규칙

#### 3-1. 해야 할 것

- 라인업을 낼 때 품목군 / SKU / 제작 수량을 나눠서 적는다.
- 신규 후보는 2-3절 기준 6개를 각각 통과 여부로 표시한다.
- 스탬프 교환용 굿즈는 판매 수량과 교환 수량을 분리해 적고, 교환 기준·단계는 "E 확인"으로 둔다.
- 가격은 조사표를 채운 뒤에만 제안하고, 조사일과 건수를 함께 쓴다.

#### 3-2. 하면 안 되는 것

- 고정 8종을 임의로 늘리거나 줄이기. 색상·문구·캐릭터 옵션을 새 상품 종류로 세기.
- 5종 추천을 건너뛰고 신규 상품을 확정하기. 사람이 선택하기 전에 시트·샘플 이미지를 만들기.
- 스탬프 몇 개로 교환하는지, 교환 장소가 어디인지를 D에서 정하기.
- 조사하지 않은 가격이나 판매량·선호도를 사실처럼 쓰기. 첫 해 판매 자료 없음을 0건으로 쓰기.
- 예산·수량·홍보 시작일을 임의로 넣기.
- 타 축제 굿즈 사진 속 제품 수를 우리 확정 수량으로 읽기, 타 브랜드 그래픽 복제하기 (D-1 2-1절).

- 품목별 **디자인 시트**(치수·소재·공법·그래픽 배치)를 같은 양식으로 만들게 해요.
- 샘플 이미지를 **입력 → 생성 → 검수 → 수정** 순서로 만드는 문서형 하네스를 정해요. 사람이든 AI든 같은 절차로 작업해요.
- 캐릭터·로고·문구 규칙과 검수표(H01~H07)는 D-1이 원본이고, 여기서는 그대로 가져다 써요.
- 디자인 검토와 양산 발주는 **별도 상태**예요. 이 파트는 샘플 이미지와 시트까지만 다뤄요. 발주는 D-4예요.

#### 2-2. 품목 시트 필수 구성

시트 양식(부록 A 품목 시트 양식)의 항목을 모두 채운다.

1. 상품 ID, 버전, 작업일, 상태, 이번 변경점
2. 상품 목적, 판매 단위, 디자인 옵션 (품목군·SKU·사이즈·생산 개수를 구분)
3. 캐릭터 버전과 기준 이미지 **실제 경로**, 문구 원문, 로고 파일
4. 고정할 요소 / 변경 가능한 요소 / 금지 사항
5. 정면·뒷면·측면·인쇄 전개 등 필요한 면과 그래픽 배치
6. 치수·소재·공법 표
7. 샘플 이미지 생성 프롬프트와 수정 프롬프트
8. 품목별 시각 검수 및 실물 샘플 확인 항목
9. 선택 결과, 미정 사항, 다음 작업

#### 2-3. 수치 표기 규칙

- 치수는 **mm**, 원단 중량은 해당 단위, 용량은 **mL**처럼 단위를 반드시 적는다.
- 모든 수치에 상태를 붙인다.

| 상태 | 뜻 |
|---|---|
| 확정 | 담당자가 결정했거나 업체·규격 자료로 확인된 값 |
| 디자인 제안값 | 디자인 검토를 위해 작성자가 제안한 값. 검증 전 |
| 업체 확인 필요값 | 업체 템플릿·견적·샘플로 확인해야 하는 값 |

- 캐릭터 세계관상의 키를 실제 굿즈 높이로 가져오지 않는다.
- 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 근거 없이 "생산 가능"이라고 판정하지 않는다. 판정은 업체 확인 뒤에 쓴다.

#### 2-4. 이미지 생성 하네스: 작업 카드

생성하기 전에 작업 카드를 채운다. (시트 6장에 같은 양식이 있다.)

```yaml
작업_ID: D-03-01_v01_A
생성도구: ChatGPT
첨부한_참조파일: 실제_경로_목록
품목: 입력
목적: 상품_샘플이미지
상태: 검토용_시안
선택_캐릭터버전: 성체_또는_아기_명시
캐릭터_기준파일: 실제_경로
로고_기준파일: 실제_경로_또는_이번면_미노출
기존상품_참고파일: 실제_경로_또는_없음
참고역할: 캐릭터정체성_로고_소재_구도_각각구분
문구_원문과줄바꿈: 입력_또는_문구없음
규격: 제안값_또는_확정값과단위
재질과공법: 제안_또는_확정
필수_시점: 정면_뒷면_측면_등
고정할것: 입력
이번에_바꿀것: 입력
출력_파일명: 입력
미정사항: 입력
```

- **생성 도구는 ChatGPT의 이미지 생성이다** (2026-11-17 담당자 결정).
  - 작업 카드의 기준 파일(캐릭터·로고·기존 상품)을 **실제로 첨부**하고, 첨부한 파일 목록을 작업 카드에 적는다.
  - 참조 이미지를 볼 수 없거나 첨부가 빠졌으면 그 사실을 알리고, 문자 설명만으로 같은 재현을 보장하지 않는다.
  - 한 번에 작업 카드 1개씩 요청한다. 결과를 저장할 때 작업 ID, 생성 날짜, 사용한 프롬프트 원문을 함께 남긴다.
  - ChatGPT가 만든 이미지의 캐릭터 재현·한글 표기는 보장되지 않는다. 검수(H01~H04)를 거치고, 한글이 틀리면 후편집으로 합성한다 (D-1 2-4절).
- 여러 레퍼런스는 "캐릭터 정체성"과 "사진 구도·소재 참고"의 역할을 구분해서 적는다.
- 캐릭터 버전이 미지정이면 최종 샘플 생성을 보류한다 (D-1 2-2절).

#### 2-5. 공통 생성 프롬프트

아래 문장에 작업 카드와 품목 시트를 붙이고, 실제 기준 이미지를 첨부한다.

> 대사투 페스티벌의 대구 얼라들 공식 굿즈 검토용 상품 샘플을 만든다. 첨부한 선택 버전의 대키미·외지몽을 동일 캐릭터로 재현한다. 캐릭터별 귀·더듬이 2개·얼굴·색상·주둥이·신체 비율을 유지한다. 성체와 아기 버전을 섞지 않는다. 로고를 노출하는 면에는 승인 로고 원본을 사용하고 글자·행성 구조·민트/코랄 배색을 바꾸지 않는다. 문구는 작업 카드의 원문과 줄바꿈 그대로 적용한다. 상품의 실제 재질·구조·인쇄 면에 맞게 표현하며 정확한 치수와 기능이 검증된 것으로 주장하지 않는다. 작업 카드에 없는 문구·캐릭터·장식·다른 브랜드를 추가하지 않는다. 이번 작업의 고정 요소와 변경 요소를 지키고, 상품을 자르지 않은 비교 가능한 시점으로 출력한다. 읽히지 않는 한글·누락된 부품·불가능한 연결 구조는 검수 실패로 보고 수정한다.

- 품목에서만 추가하는 문장은 시트 7장에 적는다.

#### 2-6. 출력 형식

- 한 품목에 같은 기본 모델·조명·배경을 쓴다. 비교안은 우선 **배치·크기 등 한두 요소만** 바꾼다.
- 기본 상품 컷은 밝은 중립 배경, 부드러운 조명, 전체 외형이 보이는 구도로 한다.
- **치수 설명용 정투영 도안**과 **분위기용 실사 목업**을 구분한다. 원근이 있는 목업을 실측했다고 쓰지 않는다.
- 필요한 면은 별도 컷으로 만든다. 티셔츠 앞뒷면, 머리띠 구조, 텀블러 곡면 전체를 한 시점으로 검증하지 않는다.
- 상품에 인쇄되는 그래픽과 시트 바깥의 제목·주석을 구분한다. 샘플 컷의 표기는 **"검토용 시안"** 으로 한다.
- 평면 그래픽에 투명 배경이 필요하면 명시한다. 흰 배경 파일을 투명 배경이라고 전달하지 않는다.
- 파일명: `D-03-01_아크릴키링_대키미_성체_A_v01_정면.png`. 품목 번호는 폴더와 같은 `D-03-NN`을 쓴다 (2026-11-17 담당자 결정). 수정하면 v02로 올리고 **원본은 보존**한다.

#### 2-7. 검수와 점수

- 생성한 모든 이미지는 **D-1의 H01~H07**로 검수한다. 결과 표와 판정 기준(통과 / 수정 필요 / 확인 불가 / 해당 없음)은 D-1 2-5절과 같다.
- H01~H07 중 하나라도 "수정 필요"면 선택안으로 넘기지 않는다.
- 필수 검수를 통과한 뒤에만 4항목(캐릭터 매력, 사투리 전달력, 가독성, 품목 간 통일성)을 1~5점으로 비교한다. 점수는 참고용이고 필수 위반을 상쇄하지 않는다.

#### 2-8. 수정 루프

1. 원본과 결과를 나란히 보고 **오류 위치·기대값·실제값**을 기록한다.
2. 이번 수정은 가장 큰 오류 **1~2개**만 대상으로 한다. 합격한 요소는 보존한다.
3. 수정 이미지에서도 H01~H07 **전체**를 다시 확인해 다른 부분이 변하지 않았는지 본다.
4. 같은 오류가 **3회 반복**되면 같은 프롬프트를 되풀이하지 않고 도안 합성·후편집·작업 분리를 적용한다. 원본이 부족하면 필요한 참조를 특정한다.
5. 사람의 선택과 문구 확인 후 "선택안"으로 기록한다. **실물 샘플 검수 전에 양산 승인으로 올리지 않는다.**

#### 2-9. 티셔츠·수면안대 추가 개발

두 품목은 기존 시안을 **그대로 다시 출력해 완료 처리하지 않는다**. 아래 비교안 3개씩은 작성자 제안이며 **어느 안도 선택되지 않았다**.

| 품목 | A — 기존안 보정 | B — 일상 사용 중심 | C — 사투리 관계 중심 |
|---|---|---|---|
| 티셔츠 | 기존 대구토박이/외지인 문구를 유지하고 인쇄 크기·행간·대비 보정 | 작은 가슴 그래픽과 절제된 뒷면 구성. 문구 축약은 별도 제안 | 두 캐릭터의 질문·설명을 앞뒤에 연결하는 신규 그래픽 제안 |
| 수면안대 | 기존 잠온다/졸리다 문구와 캐릭터 장식을 유지하고 비율·자수 가독성 보정 | 더 낮고 작은 장식, 중앙 문구, 안감·밴드 편안함 검토 | 두 안대를 나란히 놓았을 때 사투리와 표준어가 짝으로 읽히는 배치 |

- 티셔츠는 실제 앞·뒷면, **착용자 왼쪽**과 **관찰자 오른쪽**을 구별한다. 흰 바탕·파란/초록 인쇄라는 기존 방향과 새 색상 제안은 구분한다. **원문 보존본**과 **문구 개선안**을 각각 기록한다.
- 안대는 눈을 덮는 영역, 코 부분, 얼굴 접촉면, 귀·더듬이 돌출, 밴드 조절부를 확인한다. 장식이 예쁘다는 이유만으로 눈 압박·빛샘·착용감을 통과했다고 표시하지 않는다. 자수의 뒷면이 얼굴에 닿는지 실물에서 확인한다.
- 기존 시안: 대구토박이 티셔츠 원페이지 v01, 외지인 티셔츠 화이트 원페이지 v03와 프롬프트·문구 원문, 수면안대 실사상품컷 v04 (경로는 공통 지침서 v01 4.1절).

| COPY-KEY-013 | 와 이래 덥노? | 왜 이렇게 덥니? | 대화형 | 더위 소재 |
| COPY-KEY-014 | 무시<br>= 무 | 무시는 무를 가리키는 경상도 말 | 풀이형 | 일상에서 "무시하다"와 혼동할 수 있어 재미 요소로 쓸지 확인 |
| COPY-KEY-015 | 함 해보자 | 한번 해보자 | 대화형 | 참여형 프로그램과 연결 가능 |

- 문구 종류는 두 가지로 나눈다: **대화형**(토박이 대키미가 건네는 말)과 **풀이형**("사투리 = 표준어" 형태). 풀이형은 외지인 관광객이 이해하기 쉽게 하려는 것이다.
- 대키미는 설명하는 토박이, 외지몽은 질문하고 배우는 여행자다 (D-1 2-2절). **사투리 문구의 화자는 대키미**를 기본으로 하고, 외지몽이 말하는 문구가 필요하면 질문·반응 형태("…뭐라고?" 등)로 따로 제안한다 (이번 세트에는 없음).
- **어감 주의:** "뭘 보노?"는 시비가 아니라 진짜 궁금해서 묻는 말투지만, 글자만 보면 싸움을 거는 느낌으로 읽힐 수 있어 **후보 전용**으로 뒀다(담당자 결정). 쓰게 되면 장난스럽거나 궁금한 표정과 함께 쓴다. D-1은 사투리를 "무례한 말투로만" 표현하지 않도록 한다.
- 풀이형 뜻풀이는 사전에 올라 있는 표현만 쓰고, 지역별로 뜻이 다른 말(예: 갱시기 = 김치죽류, 지역마다 의미 다름)은 이번 세트에 넣지 않았다.

#### 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |
|---|---|---|---|
| 소재 | 아크릴 (투명) | **확정** | 담당자 결정 (2026-11-17) |
| 종류 | 캐릭터형 + 사투리형 2종류 | **확정** | 담당자 결정 (2026-11-17) |

- 캐릭터 세계관상의 키를 굿즈 높이로 가져오지 않는다 (D-3 2-3절).
- 작은 출력에서 얼굴 디테일이 뭉개지면 도안을 임의로 생략하지 않고 크기·구도·공법 조정을 제안한다 (D-1 2-5절).

## D-4. 제작·발주 일정

> 구분: 조건부 (홍보 시작일·업체 소요 기간·예산에 따라 바뀜) · 기본 지침: 4장 · 진행: 초안 (팀 검토 전) · 최종 수정: 2026-11-17 17:25
> 옮겨 온 출처: [공통 지침서 v01](../../Mascot/goods/%EA%B5%BF%EC%A6%88%20%EC%A7%80%EC%B9%A8%EC%84%9C/%EB%A1%9C%EC%BB%AC%EC%B6%95%EC%A0%9C%20%EA%B5%BF%EC%A6%88%20%EC%A7%80%EC%B9%A8%EC%84%9C/%EB%A1%9C%EC%BB%AC%EC%B6%95%EC%A0%9C%EA%B5%BF%EC%A6%88_%EA%B3%B5%ED%86%B5%20%EC%A7%80%EC%B9%A8%EC%84%9C_v01.md) 11절(일정), 12절(KPI 수집 항목)

### 0. 이전 버전과 달라진 점

- 첫 버전이에요.
- 발주 기준을 2026-11-17 담당자 결정으로 정했어요: **발주 완료는 홍보 시작 전에 끝내고 제작에 들어가야 하고, 입고·검수까지 홍보 시작 전에 끝나야 해요.**
- main의 P0-4 3-1 역산 일정은 "D-60 굿즈 발주"예요. 이 결정과 맞지 않아서 8장 미확정 1번으로 올렸어요 (P0-4 갱신 필요).
- 발주 **수량** 기준도 정했어요: 첫 해는 팀이 임의로 정하고, 다음 해부터는 판매 KPI를 근거로 예측해요 (2-3절).

### 1. 이 파트의 역할

- 굿즈를 **언제까지 무엇을 끝내야 하는지** 홍보 시작일에서 거꾸로 계산해요: 샘플 → 디자인 확정 → 발주 완료 → 제작 → 입고 → 검수.
- 얼마나 발주할지의 **기준**(첫 해/다음 해)도 정해요. 실제 수량 숫자는 매년 예산·견적·판매 기록을 받아 채워요.
- 디자인 내용은 D-3, 예산 입력은 P0-6·H-1, 홍보 시작일은 F-5(홍보 캘린더)가 원본이에요. D-4는 그 값을 받아서 일정만 계산해요.

### 2. 확정 값

#### 2-1. 발주 기준 (2026-11-17 담당자 결정)

- **발주 완료, 제작, 입고, 검수까지 모두 홍보 시작 전에 끝난다.** 전체 판매 물량의 제작·입고·검수가 홍보가 시작되기 전에 완료되어야 한다. (공통 지침서 v01 조건과 같다.)
- 홍보 시작일은 이 파트에서 정하지 않는다. F-5(홍보 캘린더)와 기획자 입력을 받는다. **확정되지 않았으면 임의 날짜를 넣지 않는다.**
- **"홍보 시작"의 뜻은 아직 정해지지 않았다.** F-5에는 두 가지 시점이 있다 (미확정 1).

| 해석 | F-5 기준 | 2027 개최일(2027-08-20) 기준 날짜 `[추정]` |
|---|---|---|
| ① 전체 홍보 시작 | D-180 "준비" 단계 시작 (계정 개설·브랜드 키트) | D-180 = 2027-02-21 |
| ② 굿즈 홍보 시작 | D-60~D-31 "관심" 단계의 굿즈 예고 | D-60 = 2027-06-21 |

- 계산식: 2027 개최일 2027-08-20 `[확인]` (P0-4 2-1) − 180일 / − 60일. 개최일은 `date`로 계산한 값이다.
- **P0-4 3-1 역산 일정은 "D-60 굿즈 발주"로 되어 있다.** 이 결정대로면 어느 해석이든 D-60은 늦다. 해석 ①이면 D-180 전에, 해석 ②여도 입고·검수가 D-60 전에 끝나야 하므로 발주는 D-60보다 훨씬 앞이다. P0-4 3-1과 에이전트 PART 구성 v1의 "D-60 발주 일정"은 갱신이 필요하다.

#### 2-2. 일정 계산 (홍보 시작일에서 거꾸로)

아래 단계를 모두 **홍보 시작일에서 거꾸로** 계산한다. 소요 기간은 업체·담당자가 확인한 값만 쓴다. **지어내지 않는다.**

| 순서 | 마감 | 계산 | 필요한 입력 | 상태 |
|---|---|---|---|---|
| ① | 홍보 시작일 | 입력 | F-5, 기획자 (위 2-1 해석 선택) | 입력 필요 |
| ② | 검수 완료 목표일 | ① − 담당자가 정한 여유 기간 | 여유 기간 | 입력 필요 |
| ③ | 입고 목표일 | ② − (검수·불량 대응 소요) | 담당자 확인 | 입력 필요 |
| ④ | **발주 완료 마감** | ③ − (생산·배송 소요) | 업체 확인 필요 | 입력 필요 |
| ⑤ | 디자인 확정 마감 | ④ − 생산 파일 점검 소요 | 업체 확인 필요 | 입력 필요 |
| ⑥ | 샘플 착수일 | ⑤ − (샘플 제작·배송·검토·수정 소요) | 업체 확인 필요 | 입력 필요 |
| ⑦ | 시작 한계일 | ⑥ − (디자인 개발·가격 조사·업체 견적 소요) | 담당자 확인 | 입력 필요 |

- 발주 완료 마감(④)은 홍보 시작일(①)보다 반드시 앞이어야 한다. 앞서지 않는 일정은 정상 일정으로 제시하지 않는다.
- 모든 기간은 **영업일**인지 **달력일**인지 구분해서 적는다.
- 홍보 시작일, 여유 기간, 업체 소요 기간이 입력되지 않으면 날짜를 계산하지 않고 `입력 필요`로 둔다.

#### 2-3. 발주 수량 기준

**첫 해 (과거 판매 자료 없음)**

- **팀이 임의로 정한다** (2026-11-17 담당자 결정). 근거 자료가 없는 값이므로 `[추정]`과 "임의 설정"을 함께 표시한다.
- 입력받은 예산(P0-6)과 업체 최소 주문 수량 안에서 정한다. 예산을 넘는 수량을 제안하지 않는다.
- 첫 해 자료 없음은 판매 0건이나 낮은 선호가 아니다. 값은 **`미수집`**이다.
- 첫 해에 아래 기록을 반드시 쌓는다 (D-5). 다음 해 발주 기준의 근거가 된다.

| 수집 항목 | 기준 (공통 지침서 v01 12절) |
|---|---|
| SKU별 판매 가능 입고 수량 | 불량 제외, 추가 입고는 별도 기록 |
| 순판매 수량·순매출 | 취소·반품 차감, 할인 반영 기준 명시 |
| 판매율 | 순판매 수량 ÷ 판매 가능 누적 입고 수량 × 100. 분모가 0이거나 미수집이면 산출하지 않음 |
| 재고·품절 | 실재고, 불량, 분실, 무상 지급, **품절 시각**을 별도 기록 |
| 방문객 반응 | 문구·캐릭터·상품 선호와 불편 의견. 응답 수·수집 경로 함께 기록 |

**다음 해부터 (판매 KPI 기반 예측)**

- **전년 판매 KPI를 근거로 예측해서 발주 수량 기준을 잡는다.** 예측 방식은 아래 구조를 따른다. (작성자 제안, 팀 검토 전 `[추정]`)

> SKU별 발주 수량 = (전년 순판매 수량 + 품절 보정분) × 규모 보정 × (1 + 여유율)

| 항목 | 규칙 |
|---|---|
| 전년 순판매 수량 | D-5 기록. 취소·반품 차감 후 |
| 품절 보정분 | 전년에 **품절된 SKU**는 판매량이 실제 수요보다 낮을 수 있다. 판매량을 상한으로 쓰지 않고, 품절 시각을 보고 상향 여부를 **사람이 판단**한다 |
| 규모 보정 | 전년 대비 방문객·판매 기회 변화. 근거(예상 방문객 등)가 있을 때만 쓰고, 근거가 없으면 1로 둔다 |
| 여유율 | 담당자가 정한다. 이 문서에 숫자를 넣지 않는다 |
| 상·하한 | 예산(P0-6·H-1), 업체 최소 주문 수량 |

- 판매율이 높고 품절이 빨랐던 SKU는 늘리고, 재고가 많이 남은 SKU는 줄이는 방향으로 사람이 최종 확인한다. AI는 계산한 값과 근거를 제시하고, **수량은 사람이 확정한다.**
- 전체 방문객 수만으로 굿즈 구매 전환율을 단정하지 않는다. 굿즈 상점 방문 수·구매 건수가 집계됐을 때만 그 정의로 계산한다 (KPI 정의 원본은 I-1).
- 품절 때문에 판매가 멈춘 상품과 선호가 낮은 상품을 구분해서 다음 회차 추천(D-2 2-3절)에 반영한다.
- 신규 상품(전년 자료 없음)은 이 식을 쓸 수 없다. 첫 해 기준(임의 설정)을 따르고 `미수집`을 표시한다.
- 스탬프 교환용 굿즈는 판매 수량과 **교환 수량을 따로** 예측한다. 교환 수량 근거는 E(교환 기준·단계)와 스탬프 참여 기록에서 받는다 (D-2 2-4절).

#### 2-4. 일정이 안 맞을 때

- 계산 결과 ⑤ 시작 한계일이 이미 지났거나 업체 소요 기간 안에 끝나지 않으면, **수량·옵션·공법 조정안**을 만들어 사람이 선택한다.
  - 예: 옵션(SKU) 수 줄이기, 공법 단순화, 품목 우선순위 조정 (납기 짧은 품목부터).
- **AI가 홍보 시작일이나 검수 단계를 임의로 미루거나 없애지 않는다.**
- 조정안마다 줄어드는 것(옵션·수량·마감 여유)과 늘어나는 위험(불량 대응 시간 부족 등)을 함께 적는다.

#### 2-5. 제작 중 검수와 실물 확인

- 실물 샘플 확인 항목은 D-3 2-10절을 따른다. 실물 샘플 확인 전에는 양산 승인(D-1 2-6절)으로 올리지 않는다.
- **디자인 확정 ≠ 발주 승인.** 디자인 확정 후 생산 파일 점검(③)을 거쳐 발주한다.
- 입고 후 검수에서 불량이 나오면 불량 수량과 원인을 기록하고 판매 가능 입고 수량에서 제외한다 (2-3절 수집 항목).

### 3. 에이전트 행동 규칙

#### 3-1. 해야 할 것

- 일정을 낼 때 **홍보 시작일 출처**(F-5 또는 기획자 입력)를 적는다. 영업일/달력일을 구분한다.
- 수량은 첫 해인지 다음 해인지를 먼저 밝히고, 첫 해는 "임의 설정"을, 다음 해는 계산식과 입력 근거를 함께 적는다.
- 홍보 시작일은 2-1절의 두 해석(전체 홍보 D-180 / 굿즈 홍보 D-60)을 각각 계산해 보여 주고, 어느 쪽이 정해졌는지 표시한다 (미확정 1).
- 품절 SKU는 보정 검토 대상으로 따로 표시한다.

#### 3-2. 하면 안 되는 것

- 홍보 시작일, 업체 소요 기간, 여유율, 예산을 임의로 넣기.
- 발주 완료·입고·검수가 홍보 시작 이후로 나오는 일정을 정상 일정으로 제시하기. P0-4 3-1의 D-60 발주를 근거로 일정을 맞추기.
- 첫 해 자료 없음을 0건·낮은 선호로 쓰기. 임의 설정 수량을 근거 있는 예측처럼 쓰기.
- 품절된 SKU의 판매량을 그대로 상한으로 쓰기. 전체 방문객 수만으로 구매 전환율 단정하기.
- 사람이 확정하기 전에 발주 수량을 "확정"으로 쓰기.
- 검수 단계나 샘플 단계를 일정을 맞추려고 생략하기.

### 1. 이 파트의 역할

- 현장에서 굿즈를 **어떻게 팔고, 어떻게 세고, 어떻게 기록하는지** 정해요.

### 2. 확정 값

#### 2-3. 일일 기록 (필수)

상점은 영업일마다 아래를 **SKU별로** 기록한다. 이 기록이 D-4 2-3절 발주 수량 예측과 I-1 KPI의 원본이다.

| 기록 | 뜻 | 비고 |
|---|---|---|
| 판매 가능 입고 수량 | 불량 제외한 누적 입고 수량 | 추가 입고는 별도 줄로 기록 |
| 판매 수량 | 판매 건수 합 | |
| 취소·반품 | 차감 항목 | **순판매 수량 = 판매 수량 − 취소·반품** |
| 할인 반영 | 할인 적용 시 기준을 명시 | 순매출 계산용 |
| 불량·분실 | 판매 불가 수량 | 사유 함께 |
| 무상 지급 | 행사·홍보용으로 준 수량 | 판매 수량과 구분 |
| **교환 지급** | 스탬프 교환으로 나간 수량 | 판매 수량과 **구분** (D-2 2-4절) |
| 마감 재고 | 실재고 (장부가 아니라 실사) | |
| **품절 시각** | SKU가 0이 된 시각 | 품절로 판매가 멈춘 것과 선호가 낮은 것을 구분하는 근거 |

- **판매율 = 순판매 수량 ÷ 판매 가능 누적 입고 수량 × 100.** 분모가 0이거나 `미수집`이면 산출하지 않는다 (공통 지침서 v01 12절, KPI 정의 원본은 I-1).
- 첫 해 자료 없음은 판매 0건이나 낮은 선호가 아니다. 값은 `미수집`으로 둔다.
- 전체 방문객 수만으로 굿즈 구매 전환율을 단정하지 않는다. 굿즈 상점 방문 수와 구매 건수가 **둘 다 집계된 경우에만** 그 정의로 계산한다.
- 추정으로 채우지 않는다. 기록하지 못한 칸은 `미수집`으로 두고 사유를 적는다.

|---|---|
| 문구·캐릭터·상품 선호, 불편 의견 | **응답 수와 수집 경로**를 함께 기록한다 |

#### 2-5. 교환용 굿즈 지급 (D와 E의 분담)

D-2 2-4절을 그대로 따른다.

- **D (상점):** 교환용 재고 수량 관리, 교환 지급 기록, 교환용 재고가 소진됐을 때 상점에 표시하는 방법.
- **E:** 교환 기준(스탬프 몇 개)과 교환 단계(어디서 확인하고 누구에게 받는지).
- 교환 기준·단계는 E의 값을 그대로 쓴다. 상점이 현장에서 임의로 바꾸지 않는다.
- 스탬프 교환 지급 위치가 굿즈 상점인지 별도 부스인지는 E·M-6·P0-3과 함께 정한다 (미확정 4).

#### 2-6. 실물·검수 확인

- 입고 시 불량은 판매 가능 입고 수량에서 제외하고 사유를 기록한다 (D-4 2-5절).
- 상품 성능(내열·누수·인체 적합성 등)은 상점에서 안내하거나 광고하지 않는다. 업체 확인 자료가 있을 때만 그 범위 안에서 안내한다 (D-3 2-10절).

### 3. 에이전트 행동 규칙

#### 3-1. 해야 할 것

- 상점 운영 안을 낼 때 위치·시간은 P0-3·P0-4를 링크하고, 제안한 항목은 "제안"으로 표시한다.
- 일일 기록표는 SKU별로 만들고, 판매·교환·무상 지급·불량·분실을 따로 적게 한다.
- 품절 시각을 반드시 기록하게 한다.
- 기록이 없는 값은 `미수집`으로 쓰고, 이유와 앞으로 수집할 방법을 적는다.

#### 3-2. 하면 안 되는 것

- 상점 위치, 운영 시간, 결제·정산 방식, 인원수를 이 파트에서 임의로 확정하기.
- 첫 해 자료 없음을 0건·낮은 선호로 쓰기. 기록하지 못한 판매량을 추정치로 채우기.
- 판매 수량과 교환 지급 수량을 합쳐서 기록하기.
- 전체 방문객 수만으로 구매 전환율 쓰기.
- 교환 기준·단계를 D에서 바꾸기.
- 이미지만 보고 상품 성능을 인증했다고 안내하기.

## D-6. 판매 채널

> 구분: 연도별 · 기본 지침: 4-4, 9장 (F-5 기준) · 진행: 초안 (팀 검토 전) · 최종 수정: 2026-11-17 18:45
> 공통 지침서 v01에는 판매 채널 내용이 없어요. 이 파트는 main의 F-3·F-5·F-7·P0-6·P0-8·C-7 등에 흩어진 기준을 모아서 **새로 정리한 초안**이에요. 새로 정한 부분은 "제안"으로 표시해요.

### 0. 이전 버전과 달라진 점

- 첫 버전이에요. 공통 지침서 v01에 없던 파트라서 새로 썼어요.
- main에는 "사후 온라인 굿즈 판매(D+1~D+30)"가 F-5·F-3·F-7에 있지만, 어디서 어떻게 파는지는 P0-8에 `[가설]` "판매 채널 미정"으로 남아 있어요. 이 파트가 그 빈칸을 채워요 (8장).

### 1. 이 파트의 역할

- 굿즈를 **어느 채널에서, 어느 기간에, 어떤 품목을** 팔지 정해요.
- 현장 상점의 운영(위치·기록)은 D-5, 라인업·가격은 D-2, 재고 입고는 D-4가 정해요. D-6은 그 값을 **채널별로 나눠서** 배정해요.
- 홍보에서 굿즈를 알리는 방법은 F, 판매 데이터 집계는 D가 맡아 F-7·I-1에 넘겨요.

### 2. 확정 값

#### 2-1. 채널 구분

| 채널 | 기간 | 상태 | 근거 |
|---|---|---|---|
| ① 공식 굿즈 상점 (현장) | 축제 3일 (개장~폐막) | 확정 (채널 존재). 위치는 미확정 | P0-6 "굿즈 판매 — 공식 굿즈 상점·온라인", P0-3, D-5 |
| ② 사후 온라인 굿즈 판매 | 축제 후 **D+1 ~ D+30** | 확정 (단계·기간 `[확인]`). 플랫폼·방식은 미확정 | F-5 2-1 "사후" 단계, F-3, F-7 |
| ③ 원정 팝업 | 홍보 집중 단계(D-30~D-8)에 팝업 미션 | **후보.** 굿즈를 팝업에서 팔지 정해지지 않음 | F-3 6장 "D 굿즈 — 팝업·현장 한정 굿즈", F-5 2-1 |

- 채널 ①·②는 main 파트들이 이미 전제하고 있다. 어떤 플랫폼으로 파는지, 사전 판매를 하는지는 이 문서가 정하지 않고 8장 미확정으로 둔다.
- 상설 매장·자판기 같은 장기 판매 채널은 이번 범위에 넣지 않는다. 사례(부산교통공사)는 **관측값으로만** 보고, 채널 비중을 그대로 가져오지 않는다 (축제 사례 V1 `[제안]`).

#### 2-2. 마스코트 굿즈의 판매 위치 (규칙)

- **대키미·외지몽 공식 마스코트를 쓴 굿즈는 D(공식 굿즈 상점·온라인)에서만 판매한다.** 플리마켓 셀러 등 다른 판매처에서는 마스코트 굿즈를 팔 수 없다. 같은 종류의 상품(키링, 에코백 등)을 파는 것은 괜찮지만 마스코트의 캐릭터·이름·이미지를 쓰면 안 된다. (C-7, P0-10 금지 20번)
- 이 규칙 때문에 D 채널이 마스코트 굿즈의 **유일한 판매처**다. 채널을 늘릴 때(팝업, 협업 매장 등) 새 판매처에 이 규칙을 알리고 IP 검수(D-1)를 적용한다.

#### 2-3. 라인별 채널 배정 (제안)

작성자 제안이고 팀 검토 전이다. `[해석]` 첫 해에는 과거 판매 자료가 없어서 채널 간 수요를 비교할 근거가 없다.

| 라인 (D-2) | ① 현장 상점 | ② 사후 온라인 | ③ 원정 팝업 | 이유 |
|---|---|---|---|---|
| 기본 라인 (고정 8종) | 판매 | 판매 | 연도별 결정 | 매년 운영. 축제 후에도 살 수 있게 |
| 연도별 신규 2종 | 판매 | 연도별 결정 | 연도별 결정 | 첫 해 판매 자료 없음, 사람이 결정 |
| 연도 한정판 | 판매 | **연도별 결정** | 연도별 결정 | "한정"의 정의는 정해짐(D-2 2-2: 현장에서만 구할 수 있고 매년 디자인이 달라짐). 이 정의대로면 온라인 판매는 한정의 약속과 충돌하므로 시행 여부는 축제 담당자가 매년 결정 (담당자 답변, 확인 필요) |
| 스탬프 교환용 현장 한정 | 교환 지급만 | **판매 안 함** | 해당 없음 | 교환 전용 (D-2 2-4절) |
| 팝업·현장 한정 굿즈 | 현장 전용 | **판매 안 함** | 연도별 결정 | "한정"이라는 약속을 지킴 |

- 현장 한정·교환 전용 굿즈를 온라인에서 판매하면 홍보한 약속과 어긋난다. 온라인 판매 목록에 넣지 않는다.
- 온라인에서 팔 수 없는 품목(깨지기 쉬운 곡면 상품 등)이 있는지는 D-3 실물 확인과 배송 조건 확인 뒤 판단한다 (미확정 5).

#### 2-4. 채널별 재고 배분

- 입고·검수는 **홍보 시작 전에 끝난다** (D-4 2-1절). 따라서 사후 온라인 판매에 쓸 재고는 이 입고 수량 안에서 **미리 배분**해야 한다.
- 배분 방식 (제안 `[추정]`):
  1. 교환용 수량을 먼저 따로 뺀다 (D-2 2-4절, D-5).
  2. 남은 수량을 현장용과 온라인용으로 나눈다.
  3. 현장 판매가 끝난 뒤 남은 현장 재고는 온라인으로 넘길지 사람이 정한다.
- **첫 해 배분 수량은 팀이 임의로 정한다** (D-4 2-3절과 같다). `[추정]` + "임의 설정"을 표시한다.
- 다음 해부터는 **채널별 판매 KPI**를 근거로 예측한다. 채널별 순판매, 판매율, 품절 시각을 각각 기록한다 (2-6절).
- 추가 발주·추가 입고는 사람이 결정하고, 발생하면 별도 줄로 기록한다 (D-5 2-3절). 발주 완료가 홍보 시작 전이라는 기준(D-4 2-1절)과 충돌하는지 먼저 확인한다 (미확정 6).

#### 2-5. 가격 (제안)

- 온라인 판매가는 **같은 SKU의 현장 판매가를 기준**으로 하고, 배송비·수수료는 별도 항목으로 적는다. 사람이 최종 확정한다 (D-2 2-6절).
- 가격 조사에 **배송비** 항목을 포함한다 (D-2 2-6절 조사 양식).
- 온라인 판매가가 현장 판매가와 달라질 이유(배송비 포함, 한정 할인 등)가 있으면 이유를 적고 사람이 승인한다. 근거 없이 할인가를 만들지 않는다.

#### 2-6. 채널별 기록 (D-5 기록 확장)

D-5 2-3절 일일 기록에 **채널** 칸을 더한다. 다음 해 발주 수량(D-4 2-3절)과 F-7·I-1 지표의 입력이 된다.

| 채널 | 추가로 기록할 것 |
|---|---|
| ① 현장 상점 | D-5 2-3절 그대로 |
| ② 사후 온라인 | 주문 건수, 순판매 수량(취소·반품 차감), 배송비, 유입 경로(홍보 단계·링크), 품절 시각 |
| ③ 팝업 (진행 시) | 팝업 일자·장소, 판매·교환 수량 |

- **판매 데이터 집계 시점은 D+7과 D+30**이다 (F-7 2-1 "사후 온라인 판매 — 웹 집계, 판매 데이터(D)"). 이 시점에 D가 데이터를 넘긴다.
- 첫 해 자료 없음은 `미수집`이다. 0건으로 쓰지 않는다.
- 채널 간 수요 비교는 판매율과 품절 시각을 함께 본다. 품절 때문에 멈춘 것과 선호가 낮은 것을 구분한다.

### 3. 에이전트 행동 규칙

#### 3-1. 해야 할 것

- 채널을 제안할 때 ①·②는 main 근거(F-5, P0-6)를 달고, ③ 및 신규 채널은 "후보"로 표시한다.
- 품목마다 어느 채널에서 파는지 배정표를 낸다. 현장 한정·교환 전용 품목은 온라인 목록에 넣지 않는다.
- 채널별 재고 배분을 낼 때 교환용을 먼저 빼고, 첫 해 수량은 "임의 설정"으로 표시한다.
- 마스코트 굿즈를 새 판매처에 넘기기 전에 2-2절 규칙과 D-1 검수를 확인한다.
- 온라인 판매 요건(2-8절)은 모두 "확인 필요"로 두고 담당에 넘긴다.

#### 3-2. 하면 안 되는 것

- 마스코트 굿즈를 플리마켓·제3자 판매처에서 팔도록 제안하기.
- 플랫폼, 결제·정산, 배송 규정, 필요한 신고 절차를 임의로 확정하거나 법적 판단처럼 쓰기.
- 현장 한정·교환 전용 굿즈를 온라인 판매 목록에 넣기.
- 첫 해에 채널별 수요나 비중을 근거 없이 쓰기. 사례의 판매 채널 비중을 우리 값으로 옮기기.
- 홍보에서 약속하지 않은 사전 판매·할인을 만들기.
