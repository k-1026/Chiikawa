# 아크릴 키링 일체형 6종 · 전달 안내

## 먼저 열 파일
- 02_디자인시트: 대키미/외지몽 각각의 HTML. 이미지가 파일 안에 내장되어 문서 하나로 열람 가능하다. Markdown은 편집용이며 이미지를 함께 전달한다.
- 03_제작사양서: 대키미/외지몽 각각의 HTML 및 편집용 Markdown. 수치·양면 방식은 업체 확인 전 제안이다.
- 01_상품이미지: 대키미 3종 정면/후면 상품 이미지 생성본.
- 04_재현기준: 선택한 6종 원본, 대키미 v08, 외지몽 최종 SAMPLE 05와 원문 규칙.
- 05_프롬프트: 실제 사용/대기 프롬프트 원문. 도구는 built-in image_gen.

## 현재 중요한 미완료 항목
외지몽 단독 정면/후면 상품 이미지는 이미지 생성 사용량 한도로 생성되지 않았다. 대신 기존 6종 선택원본 아래 행이 정면 디자인 기준이다. 후면의 실물 외형·글자 배치 검토는 추가 생성 후 필요하다. 외지몽 생성 대기 프롬프트를 보관했다. 빈 파일이나 임의 대체 이미지를 후면 완성본으로 넣지 않았다.

## 동일 결과와 제조의 구분
완전히 같은 픽셀을 원하면 원본 PNG를 그대로 사용한다. 디자인시트와 이미지는 AI 재현 기준이며 생성형 모델의 픽셀 동일성을 보장하지 않는다. 상품 사진에 포함된 배경·금속·투명 가장자리·그림자는 인쇄 원본이 아니다. 벡터 칼선·타공·앞뒤 컬러·백색판·폰트 아웃라인 작업은 별도다.
