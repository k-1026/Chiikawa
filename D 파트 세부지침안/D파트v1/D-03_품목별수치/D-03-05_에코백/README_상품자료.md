## AI·제작업체 전달 방법

AI에는 확정 상품 이미지 2장을 실제 이미지 입력으로 첨부하고 디자인시트·제작 사양서를 함께 전달한다. 파일명만 프롬프트에 쓰는 것으로 대체하지 않는다. 두 PDF에도 확정 사진과 확대도를 내장했다. 상세 입력 지시와 재현 프롬프트는 디자인시트 9장에 있다.

이미지의 픽셀 단위 동일성이나 실물의 완전 동일 생산을 보장하는 자료는 아니다. 실물 제작용 고해상도 인쇄 원고·벡터 레터링·최종 패턴·색상 스와치와 초도 샘플은 문서의 기준에 따라 별도로 제작·검증한다.
