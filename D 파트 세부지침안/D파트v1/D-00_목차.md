## 파일 양식 (A·E파트와 같음)

> 0. 이전 버전과 달라진 점 → 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(해야 할 것 + 하면 안 되는 것) → 4. 출력 형식 → 5. 매년 받을 입력·조사할 항목 → 6. 다른 파트 연결 → 7. 노션·기본 지침과 다른 점 → 8. 미확정·회의 필요 → 9. 출처

- 머리말: `> 구분: … · 기본 지침: … · 진행: … · 최종 수정: YYYY-MM-DD HH:MM`, 다음 줄 `> 목차: [D-00_목차.md](D-00_목차.md)`
- 말투: 규칙 본문은 한다체, 0·1·7장의 설명 문장은 해요체
- 근거 라벨 (기본 지침 7장, P0-9): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요 · `[추정]` 계산·가정 기반 수치
  - 원문을 보지 못한 자료는 라벨 옆에 "원문 미확인"이라고 적어요.
- 확정값 / 디자인 제안값 / 업체 확인 필요값은 라벨과 별도로 항상 구분해서 적어요. (공통 지침서 8절)
- 미확정 형식: # / 항목 / 이유 / 확인 주체 / 확인 기한
- 출처 형식: 자료 / 위치 / 쓰는 내용 / 상태
- 다른 파트로 넘기는 내용(KPI → I, 사투리 뜻 검수 → J-3, 예산 → H-1)은 6장에 적고, 그 파트의 내용은 대신 정하지 않아요.
