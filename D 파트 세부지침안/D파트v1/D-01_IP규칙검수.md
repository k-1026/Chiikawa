## 0. 이전 버전과 달라진 점

- 첫 버전이에요.
- 공통 지침서 v01의 4~7절, 10.4절, 13절을 옮겨 왔어요. 사투리 뜻 검수는 J-3, 콘텐츠 금지 기준은 P0-10이 원본이라 여기서는 링크로만 가리켜요.

## 1. 이 파트의 역할

- 대키미·외지몽·대구 얼라들 로고를 굿즈에 쓸 때 **무엇을 지키고, 무엇을 하면 안 되고, 어떻게 검수하는지** 정해요.
- 규칙(D-1)과 검수(D-7)를 한 파트로 합쳤어요 (축약안 v1, 2장 14번). 규칙을 어겼는지 보는 기준이 검수표라서 따로 두면 두 곳이 어긋나요.
- 품목별 시트(D-3)가 이 파트의 검수표 H01~H07을 그대로 가져다 써요.
- 사람이든 AI든 같은 절차로 작업하게 하는 **문서형 하네스**예요. 실행 중인 자동화 프로그램이 아니에요.

### 2-1. 참조 자료와 우선순위

**충돌이 생기면 아래 순서로 따른다.**

| 순위 | 기준 |
|---|---|
| 1 | 사용자(담당자)의 최신 명시적 수정·선택 |
| 2 | 담당자가 승인한 해당 버전 이미지와 그 버전에 적용되는 확정 규칙 |
| 3 | 이 파트의 확정 규칙 및 승인된 품목별 시트 (D-3) |
| 4 | 기존 가이드의 참고 수치, 과거 시안, 작성자의 신규 제안 |

- 승인 상태가 불명확하거나 기준끼리 충돌하면 해당 항목을 **"확인 필요"** 로 적는다. 두 기준을 섞어 새 정답을 만들지 않는다.
- 충돌하지 않는 문서 작업은 계속한다. 미확정 항목이 시안의 핵심을 바꾸면 샘플 생성 전에 사람이 선택한다.
- 기존 생성물에 "최종"이 붙어 있어도 자동으로 승인본으로 쓰지 않는다. 승인 여부는 `Mascot/00_팀원용_현재자료안내/` 문서로 확인한다.
- 기존 로고·캐릭터·상품 원본은 그대로 보존하고 새 파일을 만든다. 기존 티셔츠·안대 시안은 개발의 출발점이지 확정 결과가 아니다.
- 타 축제 굿즈 사진은 상품 구성·진열 방식의 **참고**로만 쓴다. 타 브랜드의 로고·캐릭터·고유 그래픽을 복제하지 않고, 사진 속 제품 수를 우리 확정 수량으로 읽지 않는다.

### 2-2. 캐릭터 정체성 고정 규칙

- 작업마다 **성체 / 아기 버전 중 무엇을 쓰는지와 기준 이미지**를 먼저 지정한다. 미지정이면 시트에 선택 칸을 남기고 최종 샘플 생성은 보류한다.
- 대키미는 **고양이형 외계인**, 외지몽은 **강아지형 외계인**으로 유지한다.
- 귀·더듬이·눈·코·입·주둥이·꼬리와 신체 비율은 선택한 기준 이미지에 맞춘다.
- 더듬이는 캐릭터당 **2개**이고 끝 구슬은 각각 1개다. 프레임 밖 잘림이나 가림이 없는지 별도로 확인한다.
- 성체의 완전히 뜬 눈은 눈마다 **큰 별 1개와 작은 반짝임 2개**를 유지한다. 감은 눈은 하이라이트도 가려진다. 아기는 선택한 아기 시트를 따른다.
- 성체 대키미의 입 주변은 **하늘색**이다. 성체 외지몽의 **크림빛 주둥이**와 혼동하지 않는다. 기본 홍조 여부는 선택 버전 기준을 따른다.
- 대키미는 설명하는 토박이, 외지몽은 질문하고 배우는 여행자다. 서로 **동등한 친구**로 표현한다.
- 얼굴만 쓰는 인쇄 그래픽과 전신 그래픽을 구분한다. 얼굴형 그래픽에 몸통·꼬리가 없는 것은 누락이 아니다.

### 2-3. 색상·로고·조형

| 요소 | 기준 | 상태 |
|---|---|---|
| 대키미 성체 대표색 | 하늘색 #6DCFF5. 조명·인쇄·소재 차이를 몸 무늬로 만들지 않음 | 공통 지침서 기준, 보드 원본 미확인 |
| 외지몽 성체 대표색 | 초록색 #008C3A. 선택한 아기 버전의 색을 이 값으로 임의 덮어쓰지 않음 | 공통 지침서 기준, 보드 원본 미확인 |
| 승인 로고 | 민트·코랄·크림 배색과 2단 구성 유지 | 확정 |
| 바탕색 | 흰색·아이보리 등 캐릭터와 문구가 읽히는 바탕을 우선 검토 | 제안 |
| 산·더위 소재 | 산 능선, 햇빛, 더위에 대한 캐릭터의 반응 등 **보조 요소로 제한** | 제안 |

- 로고는 승인 PNG와 로고 시트를 쓴다. "대구 / 얼라들" **2단 구성**, 행성이 "얼"의 ㅇ 역할을 하는 구조, 행성 고리·더듬이·별의 구성을 보존한다. 일반 폰트로 다시 입력하거나 파랑·초록으로 일괄 변경하지 않는다.
- 승인되지 않은 가로형·단색형·자수 단순화형을 확정 로고로 취급하지 않는다.
- 로고를 모든 상품 정면에 크게 넣을 필요는 없다. 작은 제품은 뒷면·포장·행택에 적용할 수 있다.
- 승인 PNG를 벡터 파일이나 투명 배경 파일이라고 가정하지 않는다. 생산용 가공이 필요하면 별도로 작업·검토한다.
- 장식은 캐릭터·사투리의 읽힘을 돕는 범위에서만 쓴다. 한 상품에 과도한 문구·로고 반복이나 상충하는 여러 스타일을 몰아넣지 않는다.
- 타 지역을 낮추거나 관광객을 조롱하는 웃음 대신 **질문·설명·공감의 웃음**을 지향한다 (콘텐츠 윤리 원본은 P0-10).

### 2-4. 사투리 문구와 한글 처리

- 문구마다 **원문, 뜻풀이, 화자, 적용 상품, 상태**를 기록한다.
- 사투리의 실제 의미·지역 어감은 **대구 지역 담당자가 확인**한다 (J-3). AI의 추정을 검증된 사실로 적지 않는다.
- 관광객에게 설명이 필요하면 포장·상품 카드·스티커 구성에 뜻풀이를 둔다. 작은 상품에 모든 설명을 억지로 넣지 않는다.
- 승인 문구는 띄어쓰기·문장부호·줄바꿈까지 그대로 유지한다.
- 이미지에서 한글이 깨지면 정확한 문자 그래픽을 **후편집으로 합성**한다. 생성 모델이 쓴 틀린 글자를 그대로 통과시키지 않는다.

### 2-5. 검수 판정 (H01~H07)

각 항목은 **통과 / 수정 필요 / 확인 불가 / 해당 없음** 으로 적는다. 해당 없음에는 이유를 쓴다. AI 자체 검수와 사람이 확인한 결과를 구분한다.

| ID | 검수 항목 | 실패 예 |
|---|---|---|
| H01 | 캐릭터 버전·종·정체성 | 대키미가 강아지처럼 보임, 아기·성체 혼합 |
| H02 | 귀·더듬이·얼굴·꼬리 | 더듬이 3개, 전신 컷 꼬리 누락, 주둥이 뒤바뀜 |
| H03 | 색상·로고 | 몸색 임의 변경, 로고 재타이핑, 행성 구조 변형 |
| H04 | 문구 정확성 | 오탈자, 임의 축약, 줄바꿈·문장부호 변경 |
| H05 | 상품 구조·면의 일관성 | 앞뒷면 불일치, 불가능한 고리 연결, 인쇄가 솔기를 넘어감 |
| H06 | 선택 규격·작업 조건 | 요청하지 않은 재질·색상·장식 추가 |
| H07 | 원본·상태·근거 표시 | 미승인 이미지를 승인본으로 표기, 추정치를 실측으로 주장 |

- **H01~H07의 해당 항목 중 하나라도 "수정 필요"면 선택안 완료로 넘기지 않는다.**
- "확인 불가"는 통과가 아니다. 시각 검수와 실물 검수의 남은 범위를 적는다.
- 작은 출력에서 얼굴 디테일이 뭉개지면 도안을 임의로 생략하지 않고 크기·구도·공법 조정을 제안한다.
- 필수 검수를 통과한 뒤에만 4항목을 각각 1~5점으로 비교한다: **캐릭터 매력, 사투리 전달력, 가독성, 품목 간 통일성.** 점수는 담당자의 비교 판단을 돕는 제안 기준이며 원본 유사도 백분율이 아니다. 높은 점수로 필수 위반을 상쇄하지 않는다.

### 2-6. 상태 승격

문서·이미지 상태는 다음 순서로만 올린다.

`초안 → 검토 중 → 선택안 → 디자인 확정 → 실물 샘플 확인 → 양산 승인`

- 단계가 바뀔 때 **날짜·확인자·대상 버전**을 기록한다.
- 파일이 있다는 이유만으로 다음 상태로 올리지 않는다.
- 디자인 검토와 양산 발주는 별도 상태다. 실물 샘플 검수 전에는 양산 승인으로 올리지 않는다.

## 3. 에이전트 행동 규칙

### 3-1. 해야 할 것

- 작업을 시작하기 전에 **성체/아기 버전, 캐릭터 기준 이미지, 로고 파일, 문구 원문**을 작업 카드(D-3)에 적는다.
- 새 문구는 2-4절 기록 양식으로 먼저 올리고, 담당자 확인 전에는 "제안" 상태로 둔다.
- 결과 이미지는 H01~H07을 모두 확인하고 항목별 판정과 오류 위치를 적는다.
- 수정할 때 합격한 요소를 보존하고, 수정 뒤에도 H01~H07을 **전체** 다시 확인한다.
- 추정치와 실측치, 확정값과 제안값을 분리해서 적는다.

### 3-2. 하면 안 되는 것

- 두 캐릭터의 종, 귀 형태, 얼굴 특징, 역할을 뒤바꾸기.
- 승인 없이 성체 얼굴에 아기 몸통을 붙이거나 버전별 털·홍조·꼬리를 혼합하기.
- 얼굴을 다른 캐릭터처럼 둥글게 다시 그리거나 눈·볼·배·구슬을 임의로 키우기.
- 축제 분위기에 맞춘다는 이유로 몸색을 변경하기.
- 몸 전체를 보여주는 장면에서 더듬이·귀·팔다리를 누락·추가하기.
- 제품 소재와 캐릭터의 원본 표현을 혼동하기. 봉제 안대의 원단은 표현할 수 있지만, 인쇄된 캐릭터를 임의로 털 인형 스타일로 바꾸지 않는다.
- 미승인 보정 수치를 원본 모델의 실측치 또는 검증된 재현값으로 표현하기.
- 새로운 문구를 승인된 문구처럼 쓰기. 기존 문구를 교정·축약하면서 변경 내역을 남기지 않기.
- 사투리를 과장된 억양·무례한 말투로만 표현하기. 뜻이 다르거나 대구 표현인지 확인하지 않은 문장을 대표 사투리로 단정하기.
- 이미지만 보고 내열·누수 방지·인체 적합성·냉감 같은 성능을 인증했다고 주장하기.
