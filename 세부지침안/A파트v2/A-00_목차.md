## 파일 양식 (A파트 공통)

P0 `_양식.md`의 순서를 따르되, A파트에 필요한 장 2개(0장, 4장)를 더했어요.

> 0. 이전 버전과 달라진 점 → 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(금지 포함) → 4. 출력 형식 → 5. 매년 받을 입력·조사할 항목 → 6. 다른 파트 연결 → 7. 노션·기본 지침과 다른 점 → 8. 미확정·회의 필요 → 9. 출처

- 근거 라벨(기본 지침 7장): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요 · `[추정]` 계산·가정 기반 수치
- 미확정 형식(기본 지침 13장): 항목 / 이유 / 확인 주체 / 확인 기한
- A파트용 DB는 아직 없어서 출처는 파일 목록으로 대신해요.
