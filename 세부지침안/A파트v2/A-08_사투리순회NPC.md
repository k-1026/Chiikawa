# A-8. 사투리 순회 NPC

## 1. 이 파트의 역할

- 공연인이 의상을 입고 사투리로 말하며 축제장을 돌아다니는 이벤트를 다뤄요.
- 이름: 문서용 이름은 **사투리 순회 NPC**예요. 방문객에게 소개할 이름은 따로 정해요. (미확정 1번)

## 2. 확정 값

**출연자 (고정)**

- 연극·공연을 하는 사람이나 배우 준비생 같은 공연인이 맡는다.
- 한 팀은 **5명 이내**로 하고, **여러 팀**을 만든다.
- 옛날 옷이나 공연 옷을 입는다. 너무 더운 옷은 피한다.
- 사투리로 말하며 축제장을 돌아다닌다.
- 캐릭터는 나중에 정한다. (미확정 2번)

**관객이 즐기는 방법**

- 보는 것
- 대화하며 즐기는 것
- 그해 이벤트에 참여하고 스탬프 받기

**연도별 이벤트 (고정: 매년 바뀜)**

- 이벤트는 **매년 다르게** 기획한다.
- 이벤트에 참여하면 **스탬프를 준다.** 스탬프를 주는 것은 매년 같다. (A-1 QR·스탬프)
- 이벤트 예시: 퀴즈
  - 사투리 관련 인터넷 밈
  - 가벼운 대구 상식. 예: 대구 연고지 야구팀은? 대구에 있는 가장 큰 놀이공원은?

**보상 (고정)**

- 스탬프 보상은 **따로 만드는 굿즈**로 준다. (D(굿즈))

**운영 시간과 휴식**

- 토요일 또는 일요일에 **종일** 진행한다. 날짜는 타임테이블 배치 때 정한다. (미확정 3번)
- NPC 휴식 공간을 **운영부스 쪽에** 마련한다.

## 3. 에이전트 행동 규칙

**금지**

- 할매 말투 콘셉트를 캐릭터로 쓰지 않음 (기본 지침 10장). 캐릭터를 정할 때 확인
- 지역 비하, 타지역 조롱, 사투리 비하 표현 금지 (A-1 공통)
- 출연자의 참여 의사와 섭외 결과를 임의로 만들지 않음 (기본 지침 7장)
- 정답 근거를 확인하지 않은 퀴즈를 쓰지 않음 (기본 지침 7장)

## 4. 출력 형식

**1. 팀 구성표** — 팀, 인원, 의상, 캐릭터(정해지면), 담당 구역

**2. 연도별 이벤트안** — 이벤트, 참여 방법, 스탬프 지급 조건, 문제(퀴즈일 때), J(사투리) 검수

**3. 운영표** — 순회 시간, 휴식 시간, 휴식 공간 위치

**4. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한

## 5. 매년 받을 입력·조사할 항목
