### v1에서 지운 내용 (원문 보관): 팀전 숙박 지원 (구 A-5)

- 숙박: 타지역 팀전은 **2명당 객실 1개**를 지원한다. 2인 팀 1실, 3~4인 팀 2실

| 대상 | 경기 | 지원 |
|---|---|---|
| 타지역 개인전 | 금 예선, 진출 시 토 4강·결승 | 금 1박, 진출자는 토 1박 추가 |
| 타지역 팀전 | 토 4강·결승 | 토 1박 |

## 1. 이 파트의 역할

- 사투리 콘텐츠 참가자 혜택, 입상자 혜택, 우승자 상품을 다뤄요.
- v1에서 옮긴 것: 구 A-5 "타지역 출전자 숙박 지원", "참가 혜택"

## 2. 확정 값

**혜택 대상 (고정)**

- 혜택은 **사투리 콘텐츠 참가자**에게 준다.
  - 토론대회 출전자
  - 골든벨 참가자 (사전 신청자와 현장 신청자 모두)
- 사투리 순회 NPC 이벤트 참여자는 이 혜택과 별개로 스탬프 보상 굿즈를 받는다. (A-1, A-8)

**혜택 단계 (고정)**

| 대상 | 혜택 |
|---|---|
| 참가자 | 대구에서만 쓸 수 있는 혜택 |
| 입상자 | 같은 혜택을 더 크게 준다. 예: 금액을 늘리거나 할인율을 높임 |
| 우승자 (토론대회, 골든벨처럼 등수를 나누는 콘텐츠) | 상품. 전용 굿즈, 상패, 대구에서 쓸 수 있는 돈 등을 검토 중 |

**혜택 종류**

- 혜택의 공통점은 **대구에서만 쓸 수 있다**는 것이다.
- 예시: 대구로페이 머니, 대구 지역화폐, 대구 숙박 할인권. 종류는 정해지지 않았다. (미확정 1번)
- **숙박은 여러 혜택 중 하나**로 넣는다. v1의 "타지역 출전자 숙박 지원"은 콘텐츠가 당일 진행으로 바뀌면서 혜택 중 하나로 바뀌었다. (2026-11-11)

**예산**

- 혜택 금액과 할인율은 메인 예산안의 혜택 예산 부분을 참고해 정한다.

**v1에서 옮긴 기존 결정 (다시 맞춰야 함, 미확정 4번)**

- 타지역 출전자 숙박 지원 (구 A-5)
  - 타지역 출전자에게 **정원 2인 객실**을 지원한다.
  - 일행이 3명 이상이면 객실 업그레이드를 요청할 수 있고, 추가 비용은 본인이 부담한다.
  - 지원하는 밤은 경기 일정에 맞춘다. (v1: 금 예선 1박, 진출자는 토 1박 추가. 요일이 바뀌어 맞지 않음)
- 참가 혜택 (구 A-5, 예산이 정해지기 전까지 이 수준으로 둠)

| 대상 | 혜택 |
|---|---|
| 수상자 | 우승·준우승, 특별상 1개 (상금은 미확정) |
| 출전자 전원 | 출전 기념품, 응원 부채, 굿즈 교환권 |
| 신청자 전원 | 관람·굿즈 할인 코드 |

## 3. 에이전트 행동 규칙

**연도별 작성**

- 혜택 종류와 금액, 우승 상품 구성
- 연도 주제 연결 1줄, 주 목표(사투리·체류), 전년 대비 유지 / 개선 / 실험 분류와 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"

**금지**

- 정해지지 않은 혜택 금액, 할인율, 상금을 확정값처럼 쓰지 않음 (기본 지침 7장)
- 숙박 업체, 결제 수단 제휴처를 확정처럼 쓰지 않음. 업체명은 "후보"로만 표기 (기본 지침 7장)
- 예산 범위를 넘는 혜택을 제안하지 않음 (기본 지침 4-1)

## 4. 출력 형식

**1. 혜택표** — 대상(참가자 / 입상자 / 우승자), 콘텐츠, 혜택 종류, 금액·할인율, 예상 인원, 비용 라벨

**2. 우승 상품 구성표** — 콘텐츠, 순위, 상품, 요청 파트(D(굿즈) 등)

**3. 다른 파트 요청표** — 요청 내용, 대상 파트, 필요 시점

| 요청 | 대상 파트 |
|---|---|
| 전용 굿즈, 상패 | D(굿즈) |
| 대구 숙박 할인, 숙박 제휴 | G-5(관광) |
| 지역화폐 등 결제 수단, 예산 | H-1(운영), M(메인) 예산안 |

**4. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한

## 5. 매년 받을 입력·조사할 항목

| 입력 | 가져올 곳 |
|---|---|
| 혜택 예산 | 메인 예산안의 혜택 예산 부분 (M(메인)) |
| 참가자, 입상자, 우승자 명단 | A-3 (토론대회), A-6 (골든벨) |
| 전용 굿즈, 상패 | D(굿즈) |
| 숙박 제휴, 대구 숙박 할인 | G-5(관광) |
| 지역화폐 등 대구 전용 결제 수단, 단가 | H-1(운영) |
