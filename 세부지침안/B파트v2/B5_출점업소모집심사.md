# B-5 출점 업소 모집·심사 — 세부 지침

> 구분: 연도별(매년 다시 모집·심사) · 기본 지침: 3장, 7장 · 진행: 확정 v2 · 최종 수정: 2026-11-13
> 기준 문서: 기본 지침 v1.1 3장 "출점 업소 모집(①·② 공통)", 7장 조사·근거 규칙, [축제 사례 V1.md](참고자료/축제%20사례%20V1.md) 카드 ②-2(서울시 푸드트럭), ②-5(대구 서문·칠성 야시장)

## 1. 이 파트의 역할

- B-2(10미)·B-4(7구 맛집거리) 후보를 실제로 모집·심사해 "후보"에서 "확정 업소"로 전환하는 절차와 기준을 정한다.
- 읽는 파트: B-3·B-4(후보 목록 제공), B-9(모집 안내문 작성), B-6(확정 업소 명단 전달)

## 2. 확정 값

### 2-1. 모집 순위

| 구역 | 1순위 | 2순위 |
| --- | --- | --- |
| ① 10미 포장마차 | 원조 골목 상인회·소속 업소 | 대구10미데이 참여 업소(2026년 기준 86곳) |
| ② 7구 맛집거리 | 구청 추천 업소 | 공개 모집 업소(B-4 선정 기준 충족) |

- 제과점(B-4 추가 배정분)도 같은 순위 체계(구청 추천 → 공개 모집)를 따른다.

### 2-2. 심사 절차

1. 공개 모집 공고(B-9) → 신청 접수
2. 서류 심사(자격 요건 + 아래 배점표)
3. 시식 심사(서류 통과 업소 대상)
4. 결과 발표 → "후보" 꼬리표를 떼고 확정 업소로 전환(3절)

### 2-3. 심사 배점표 (100점 만점, 초안)

> 서울시 푸드트럭 모집(2026)·대구 서문·칠성 야시장 상인 선정(서류+시식) 방식을 참고해 설계. `[가설]`, 팀 확정 전.

| 구분 | 항목 | 배점 |
| --- | --- | --- |
| 서류 (40) | 서류 완성도(사업자 정보·영업 이력) | 10 |
| | 대구 연계성(원조 골목·구청 추천 여부, B-3·B-4 기준 부합) | 15 |
| | 위생·영업 등록(영업신고·보건증·위생교육 이수) | 15 |
| 시식 (60) | 메뉴 맛·품질 | 25 |
| | 가격 적정성 | 15 |
| | 위생·조리 환경(현장 확인) | 10 |
| | 사투리 콘셉트 연계 가능성(B-7, 가점) | 10 |

- 70점 미만 탈락(서울시 푸드트럭 사례 기준 참고, `[가설]`).
- 제외 대상: 프랜차이즈, 영업 미등록 업소, 위생교육 미이수 업소, 10미·7구 메뉴 중복 위반 업소.

### 2-4. 부족 시 보충 규칙

1. 1업소 다부스 운영(예: B-3 납작만두 — 후보 3곳뿐)
2. 2순위 업소로 보충(2-1 모집 순위)
3. 그래도 부족하면 같은 구역 내 다른 품목·업소로 대체하거나 부스 수를 줄인다.

## 3. 에이전트 행동 규칙

**금지**

1. 서류·시식 심사를 통과하지 않은 업소를 확정 업소로 전환하지 않는다 — 참여 의사가 서면으로 확인돼야 "확정 업소"다.
2. 업소 정보·참여 의사·점수를 임의로 만들어내지 않는다(7장). B-3·B-4의 후보 목록도 전부 "1순위 후보"일 뿐 확정이 아니다.
3. 프랜차이즈·영업 미등록·위생교육 미이수·메뉴 중복 위반 업소를 심사 대상에 포함하지 않는다(2-3 제외 대상).
4. 신청 업소가 부족하다고 빈 부스를 임의 업소로 채우지 않는다 — 2-4 보충 규칙 순서(다부스 → 2순위 → 대체/축소)를 따른다.
5. 70점 미만 업소를 "합격선 근접"이라는 이유로 선정하지 않는다.
