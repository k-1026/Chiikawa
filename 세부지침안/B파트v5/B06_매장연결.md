# B06 매장 연결 — 세부 지침

> 구분: 고정(QR 운영 자체, 10미·7구 업소 스탬프 지급 방식) + 연도별(실제 매장 목록, 교환 상품·쿠폰북) · 기본 지침: 3장 · 진행: 확정 v5 · 최종 수정: 2026-11-17
> 기준 문서: 기본 지침 v1.1 3장 "실제 매장 연결(상권)", main `세부지침안/하위파트_기본목차/하위파트_축약안_v1.md` 3장 7·8번(스탬프 담당 구분 기준)
> 목적: ① QR로 실제 매장(원조 매장) 위치·영업시간을 안내하는 정보 전달 장치, ② 축제장 **안**에서 10미·7구 업소가 스탬프를 지급하는 방식(2026-11-17 신설)

## 1. 이 파트의 역할

- B02·B04에서 확정된 출점 업소를 매장 카드(QR)로 어떻게 안내할지 정한다.
- 축제장 **밖** 스탬프 연계(실제 매장 3곳 방문 시 혜택, 구 2-2)는 **폐지**한다(2026-11-17) — QR은 실제 매장 위치·영업시간 등 정보 안내 용도로만 쓴다.
- 축제장 **안** 스탬프는 전체 제도(스탬프 북 양식·교환 기준·교환소 운영)를 **M-6(메인 에이전트, 현장 안 스탬프 소관)**이 설계한다 — B06은 **10미·7구 음식 부스 업소가 스탬프를 어떤 방식으로 지급하는지**까지만 다룬다(2-4).
- 읽는 파트: M-6(메인 — 축제장 안 스탬프 제도 설계), B03·B04(확정 업소 명단 입수), B05(모집·심사 — 스탬프 활용 방안 제출 연동)

## 2. 확정 값

### 2-1. 매장 카드(QR) 내용

부스마다 매장 카드(QR)를 비치한다. 카드에 담을 내용:

1. 업소명 + 대표 메뉴
2. 원조 골목·위치 안내(B03 기준, 골목 없는 품목은 개별 업소 위치)
3. 실제 매장 영업시간·전화번호·지도 링크

### 2-2. 실제 매장 목록 구성 규칙

- B02(10미)·B04(7구)에서 **확정 업소**(B05의 "후보" 딱지를 뗀 업소)만 목록에 올린다.
- 목록은 매년 B05 심사 결과 확정 직후 갱신한다. 전년도 목록 재사용 금지.
- 업소가 폐업·이전하면 즉시 목록에서 제외하고 매장 카드 QR도 갱신한다.

### 2-3. 필수 기획 요소

- 기획안에는 "축제 부스 → 실제 매장" 동선을 **1개 이상** 포함한다(3장 연계 원칙).

### 2-4. 축제장 내 스탬프 — 10미·7구 업소 지급 방식 (B파트 소관, 2026-11-17 신설)

> **결정(2026-11-17)**: 축제장 안에서도 방문객이 스탬프를 모으는 제도를 둔다. 스탬프 북 양식·목표 개수·교환소 운영 등 **제도 전체 설계는 M-6 소관**이고, B06은 "10미·7구 음식 부스 업소가 스탬프를 어떻게 지급할지"까지만 정한다. 축제장 **밖** 스탬프 연계는 폐지했으므로, 이 제도가 B06이 다루는 유일한 스탬프 제도다.

- **지급 방식**: 10미·7구 부스는 **1회 구매당 스탬프 1개**를 지급한다. 지급 수단(현장 도장·스티커 등)은 M-6이 배부하는 스탬프 북 양식에 맞춰 통일한다 — 부스마다 다른 수단을 임의로 쓰지 않는다.
- **스탬프 북**: 방문객은 M-6이 배부하는 스탬프 북에 부스별로 스탬프를 모은다. 목표 개수를 채우면 **상품 또는 쿠폰북**으로 교환할 수 있다(목표 개수는 M-6 확정, 7절 1번).
- **교환 상품·쿠폰북**: 내용은 **매년 관리자(M-6)가 정한다** — 그 해 협업처·선정된 가게에 따라 바뀌므로 B06에서 고정값으로 쓰지 않는다. 관리자가 후보 리스트 중에서 선정하는 방식이다.
- **업소 제출 의무**: 10미·7구 출점 업소는 모집·심사 단계(B05)에서 **스탬프 활용 방안**(자기 부스에서 스탬프를 어떻게 지급·안내할지 계획)을 제출해야 한다 — B05 2-2 심사 절차와 연동(B05 참고).

## 3. 에이전트 행동 규칙

**금지**

1. B05 심사를 통과하지 못한 "후보" 업소를 매장 카드·실제 매장 목록에 올리지 않는다.
2. 전년도 매장 목록을 그대로 재사용하지 않는다 — 매년 B05 확정 결과로 갱신한다.
3. 폐업·이전이 확인된 업소를 목록에서 제외하지 않고 방치하지 않는다.
4. 매장 카드(QR)에 "축제장 밖 방문 혜택" 등 스탬프 인센티브 안내를 넣지 않는다 — 축제장 밖 스탬프 연계는 폐지했다(2026-11-17).
5. 기획안에 "부스 → 실제 매장" 동선을 0개로 설계하지 않는다.
6. 축제장 내 스탬프 북 양식·목표 개수·교환 상품(쿠폰북) 구성을 이 문서에서 임의로 정하지 않는다 — **M-6** 결정을 따른다(2-4).
7. 10미·7구 업소별로 스탬프 지급 방식(1회 구매당 1개)을 다르게 적용하지 않는다 — 통일된 기준을 따른다.
8. B05로부터 받은 확정 업소 명단에 "스탬프 활용 방안" 제출 여부가 빠져 있으면 확인 없이 매장 카드 제작을 진행하지 않는다 — B05에 확인을 요청한다.

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| B05 확정 업소 명단 | 입력 | 심사 종료 직후 | 목록 갱신 보류, 전년도 목록 사용 금지 — 심사 완료까지 "미확정"으로 표시 |
| 축제장 내 스탬프 북 양식·목표 개수 | 입력(M-6) | 부스 운영 교육 전 | 미정 시 임시로 "스탬프 10개 기준" 안내, 확정 후 정정 |
| 그 해 교환 상품·쿠폰북 구성 | 입력(M-6, 매년) | 축제 시작 전 | 미정 시 "상품 구성 추후 공지"로 표시 |
| 업소별 스탬프 활용 방안 | 입력(B05, 신청 서류) | 모집·심사 시 | 미제출 업소는 B05에 보완 요청 |
