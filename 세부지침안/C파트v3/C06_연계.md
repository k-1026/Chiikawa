# C-6 연계 — 세부 지침

> 구분: 고정(스탬프 지급 방식 자체) + 연도별(스탬프판·교환 상품 세부 구성) · 기본 지침: 3장 · 진행: 확정 v3 · 최종 수정: 2026-11-17
> 기준 문서: 기본 지침 v1.1 3장 "3대 프로그램 연계 원칙" + "소상공인 플리마켓 — 운영", main `세부지침안/하위파트_기본목차/하위파트_축약안_v1.md` 3장 7·8번(스탬프 담당 구분 기준)

## 1. 이 파트의 역할

- 플리마켓 구매가 축제장 **내** 스탬프 적립 대상이라는 것과, 셀러가 스탬프를 어떻게 지급하는지를 정한다. 스탬프 제도 전체(스탬프판 양식·목표 개수·교환소 운영)는 **M-6(메인 에이전트)** 소관이다 — B-6(매장 연결)이 10미·7구 업소에 적용하는 것과 같은 체계를 플리마켓 셀러에도 동일하게 적용한다.
- 플리마켓 셀러 품목이 D(굿즈 상점)의 마스코트 IP와 겹치지 않는지 확인하는 기준도 정한다.
- 읽는 파트: M-6(메인 — 축제장 안 스탬프 제도 설계), B-6(매장 연결 — 같은 스탬프 체계), C-3(모집·심사 — 스탬프 활용 방안 제출 연동), D(굿즈 상점 — 마스코트 사용 확인)

## 2. 확정 값

### 2-1. 축제장 내 스탬프 — 플리마켓 셀러 지급 방식

> **결정(2026-11-17)**: 플리마켓의 스탬프 적립도 B-6(10미·7구 업소)과 같은 **축제장 내 M-6 스탬프 체계**로 통합한다. 스탬프판 양식·목표 개수·교환소 운영 등 **제도 전체 설계는 M-6 소관**이고, C-6은 "플리마켓 셀러가 스탬프를 어떻게 지급할지"까지만 정한다.

- **지급 방식**: 플리마켓 셀러는 **1회 구매당 스탬프 1개**를 지급한다(B-6과 동일 기준). 지급 수단(현장 도장·스티커 등)은 M-6이 배부하는 스탬프판 양식에 맞춰 통일한다 — 셀러마다 다른 수단을 임의로 쓰지 않는다.
- **스탬프판**: 방문객은 M-6이 배부하는 스탬프판에 부스별로 스탬프를 모은다. 목표 개수를 채우면 **상품 또는 쿠폰북**으로 교환할 수 있다(목표 개수는 M-6 확정, 7절 3번).
- **교환 상품·쿠폰북**: 내용은 **매년 관리자(M-6)가 정한다** — 그 해 협업처·선정된 가게에 따라 바뀌므로 C-6에서 고정값으로 쓰지 않는다.
- **셀러 제출 의무**: 플리마켓 셀러는 모집·심사 단계(C-3)에서 **스탬프 활용 방안**(자기 부스에서 스탬프를 어떻게 지급·안내할지 계획)을 제출해야 한다 — C-3 2-1 7번과 연동.

### 2-2. 굿즈 상점과 마스코트 사용 확인 (→ D)

> **결정(2026-11-11)**: 품목이 겹치는 것 자체는 금지 사유가 아니다. 금지 대상을 "같은 품목"에서 "마스코트 사용"으로 좁힌다.

- 플리마켓 셀러의 상품이 D(굿즈 상점)와 **같은 종류(예: 키링, 에코백 등)여도 상관없다.**
- 금지되는 것은 **대키미·외지몽 공식 마스코트를 사용한 굿즈를 셀러가 만들어 파는 것**뿐이다 — 캐릭터·이름·이미지를 쓴 상품은 D(굿즈 상점)에서만 판매한다.
- 실제로 어떤 상품이 "마스코트를 사용했다"에 해당하는지(실루엣만 써도 해당되는지 등) 애매한 경우는 **D**(축제 공식 굿즈 상점 담당 파트) 또는 마스코트 IP 가이드를 기준으로 확인한다(문서 경로는 7절 2번 미확정).
- 셀러 선정(C-3) 단계에서 신청 품목에 마스코트 사용 여부를 확인하고, 마스코트를 사용한 품목이 있으면 그 품목만 빼거나 신청 자체를 반려한다.

## 3. 에이전트 행동 규칙

**금지**

1. 플리마켓 셀러별로 스탬프 지급 방식(1회 구매당 1개)을 다르게 적용하지 않는다 — 통일된 기준을 따른다.
2. 축제장 내 스탬프판 양식·목표 개수·교환 상품(쿠폰북) 구성을 이 문서에서 임의로 정하지 않는다 — **M-6** 결정을 따른다(2-1).
3. C-3로부터 받은 확정 셀러 명단에 "스탬프 활용 방안" 제출 여부가 빠져 있으면 확인 없이 진행하지 않는다 — C-3에 확인을 요청한다.
4. 마스코트 사용 여부를 확인하지 않고 셀러 품목을 그대로 승인하지 않는다.
5. 품목이 겹친다는 이유만으로 신청을 반려하지 않는다 — 금지 사유는 마스코트 사용뿐이다(2-2 결정).
