## 1. 이 파트의 역할

- 사투리 콘텐츠 참가자 혜택, 입상자 혜택, 우승자 상품을 다뤄요.
- v1에서 옮긴 것: 구 A-5 "참가 혜택". "타지역 출전자 숙박 지원"은 경기가 모두 당일이라 없앴어요 (2026-11-18).

## 2. 확정 값

**혜택 대상 (고정)**

- 혜택은 **사투리 콘텐츠 참가자**에게 준다.
  - 토론대회 출전자
  - 골든벨 참가자는 입상(결승 진출) 때만 상을 받는다. 참가 혜택은 없다 (아래)
- **골든벨 참가자는 사전 신청자든 현장 참가자든 참가 자체의 혜택이 없다.** 사전 신청은 자리를 안정적으로 잡는 사전 예약일 뿐, 사전과 현장 사이에 혜택 차이는 없다. 결승까지 가면 다른 결승 진출자와 같은 상을 받는다. (A파트 담당 결정, 2026-11-18)
- 사투리 순회 NPC는 보상이나 순위를 두지 않는다. 놀이공원 마스코트처럼 돌아다니며 함께 놀고 즐기는 프로그램이다. 스탬프 보상도 없다. (A-8, A파트 담당 결정, 2026-11-18)

**혜택 단계 (고정)**

| 대상 | 혜택 |
|---|---|
| 참가자 | 대구에서만 쓸 수 있는 혜택 (토론대회 출전자. 골든벨 참가자는 없음) |
| 입상자 | 같은 혜택을 더 크게 준다. 예: 금액을 늘리거나 할인율을 높임 |
| 우승자 (토론대회, 골든벨처럼 등수를 나누는 콘텐츠) | 상품. 전용 굿즈, 상패, 대구에서 쓸 수 있는 돈 등을 검토 중 |

**입상자 기준 (고정, 2026-11-18)** (A파트 담당 결정, 2026-11-18)

| 콘텐츠 | 입상자 |
|---|---|
| 토론대회 | **우승, 준우승 (총 2명)**. 3위는 따로 가리지 않는다 |
| 골든벨 | 결승 진출자(무대로 올라가는 사람) = 전체 참가자의 10%(기본값) (A-6) |

**수상자 구성 (고정, 모든 대회 공통, 2026-11-18)**

| 상 | 여부 |
|---|---|
| 우승자 | **필수** |
| 준우승자 | **필수** |
| 특별상 | 선택 |

- 특별상을 줄지는 담당자가 고른다. 특별상의 종류는 **담당자가 요청하면 그에 맞춰** 만든다. (A파트 담당 결정, 2026-11-18)

**골든벨 시상 (고정, 2026-11-17)**

| 대상 | 상 |
|---|---|
| 결승 진출자 (무대로 올라가는 사람, 전체 참가자의 10% 기본값, A-6) | **기본 상** |
| 준우승자 | 기본 상 + **추가 상** |
| 우승자 | 기본 상 + **추가 상** |

- **상을 주는 형식·방식과 무슨 상을 줄지는 담당자가 고른다.** 우승자와 준우승자의 추가 상을 다르게 할지도 담당자가 정한다.
- 에이전트는 **추천만** 한다. (아래 3장) (A파트 담당 결정, 2026-11-17)

**시상 형식별 규칙 (고정, 토론대회·골든벨 공통, 2026-11-17)**

에이전트는 아래 규칙에 맞춰 추천안을 내고, 고르는 것은 담당자다.

- 지금 적힌 5가지 형식만 고정된 것이 아니다. 좋은 형식이 생기면 **더 추가할 수 있다.** (A파트 담당 결정, 2026-11-18)

| 형식 | 규칙 | 예시 |
|---|---|---|
| **상금(대구전용)** | 현금 대신 **대구 안에서 쓰도록 이끄는 형태**로 준다. 목적은 수상자가 상금을 **대구에서 소비**하게 하는 것이다. 대구에서만 쓸 수 있는 것, 또는 대구 소비로 이어지는 것을 고른다. 정해진 한 가지 형태는 없다. | 대구 지역사랑상품권(지역화폐), 대구로페이 머니, 축제 안에서 쓰는 바우처 |
| **굿즈** | **우리 마스코트** 굿즈로 준다. (D(굿즈) 협업) | 굿즈 키트, 굿즈 인형 |
| **수상 인형** | 올림픽 수상자가 받는 인형처럼, 마스코트 인형을 **프로그램마다 다른 모습**으로 만들어 그 프로그램만의 특별함을 준다. **비매품**으로 기획해 희소성을 높인다. 제작 규칙은 아래 "수상 인형 제작" | 토론대회: 마이크를 든 마스코트 / 골든벨: 골든벨 모자를 쓰고 종을 든 마스코트 |
| **상장** | 상장 문구에 **사투리가 잘 묻어나게** 쓴다. 시상 종류의 이름(인기상, 우수상 같은 것)도 **사투리나 대구가 묻어나는 이름**으로 제안한다. 문구와 상 이름은 J(사투리) 검수를 받는다. | 쥑이네상, 이기뿟다상 / 예시 1: 우승 "억수로 잘했데이상", 준우승 "쪼매 아깝데이상", 특별상 "배꼽 빠졌데이상"(가장 웃긴 참가자) / 예시 2: 우승 "말빨 대장상", 준우승 "말빨 단디상", 특별상 "찰지다상"(사투리를 맛깔나게 쓴 참가자) (A파트 담당 제시, 2026-11-18) |
| **상패** | 디자인에 **대구나 사투리**를 담아낸다. (D(굿즈) 또는 디자인 담당과 협의) | - |

- **상장·상패:** 상 이름과 문구는 에이전트가 제안하고, J(사투리) 검수 후 담당자가 고른다.
- **수상 인형 제작** (A파트 담당 결정, 2026-11-18)
  - 수량: 우승자에게만 주면 필요 개수의 **3배**, 준우승자까지 주면 **2배**를 만든다. 인형이 더러워지는 등 지급에 문제가 생길 수 있기 때문이다.
  - 제작 기간: 기존 인형 제작 기간과 같다.
  - 단가: 기존 인형 단가에서 크게 벗어나지 않게 한다. 단가는 **담당자가 판단**한다.
  - 디자인은 프로그램별 모습(예시: 토론 마이크, 골든벨 모자+종)으로 D(굿즈)와 정한다.
- **상장 이름:** 사투리 단어나 어미를 살린 이름으로 만든다. 위 예시를 참고하고, J(사투리) 검수 후 담당자가 고른다.
- "상금(대구전용)"은 현금 대신 대구 안에서 쓰도록 이끄는 상금이다. 지역화폐처럼 **대구 안에서 돈이 돌게 한다**는 뜻을 담았다.
- 상장 문구와 상 이름에도 할매 말투 콘셉트, 지역 비하, 사투리 비하 표현을 쓰지 않는다. (A-1 공통)

**혜택 종류**

- 혜택의 공통점은 **대구에서만 쓸 수 있다**는 것이다.
- 혜택 종류는 **대구로페이 머니, 대구 지역화폐, 대구 숙박 할인권**으로 정한다. (A파트 담당 결정, 2026-11-18)
- 숙박 할인권은 여러 혜택 중 하나일 뿐이다. **참가했다고 숙박 할인권이나 숙박을 무조건 주지 않는다.** 경기가 모두 당일(일요일)에 끝나서 숙박 지원은 하지 않는다. (A파트 담당 결정, 2026-11-18)

**예산**

- 혜택 금액과 할인율, 우승 상품 금액은 **H-1(예산)**에서 정한다. (A파트 담당 결정, 2026-11-18)

## 3. 에이전트 행동 규칙

**연도별 작성**

- 혜택 종류와 금액, 우승 상품 구성
- 시상은 에이전트가 **추천안**을 만든다: 상의 형식(상금(대구전용), 마스코트 굿즈·수상 인형, 상장, 상패 등), 주는 방식(무대 시상, 현장 지급, 사후 지급 등), 상의 내용 후보를 2~3개씩 이유·예산 근거와 함께 낸다. 2장 "시상 형식별 규칙"을 따른다. **고르는 것은 담당자**다.
- 연도 주제 연결 1줄, 주 목표(사투리·체류), 전년 대비 유지 / 개선 / 실험 분류와 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"

**금지**

- 정해지지 않은 혜택 금액, 할인율, 상금을 확정값처럼 쓰지 않음 (기본 지침 7장)
- 시상 형식·방식·내용을 에이전트가 정하지 않음. 추천안으로만 냄
- 숙박 업체, 결제 수단 제휴처를 확정처럼 쓰지 않음. 업체명은 "후보"로만 표기 (기본 지침 7장)
- 예산 범위를 넘는 혜택을 제안하지 않음 (기본 지침 4-1)

## 4. 출력 형식

**1. 혜택표** — 대상(참가자 / 입상자 / 우승자), 콘텐츠, 혜택 종류, 금액·할인율, 예상 인원, 비용 라벨

**2. 우승 상품 구성표** — 콘텐츠, 순위, 상품, 요청 파트(D(굿즈) 등)

**3. 다른 파트 요청표** — 요청 내용, 대상 파트, 필요 시점

| 요청 | 대상 파트 |
|---|---|
| 전용 굿즈, 상패 | D(굿즈) |
| 대구 숙박 할인권 (혜택 종류 중 하나) | G-5(관광) |
| 지역화폐 등 결제 수단, 예산 | H-1(운영) |

**4. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한
