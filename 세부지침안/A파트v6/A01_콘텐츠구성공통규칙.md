## 1. 이 파트의 역할

- 사투리 콘텐츠 4개를 소개하고, 모든 콘텐츠에 같이 적용하는 규칙과 QR 체크인 규칙을 정해요. A 콘텐츠는 스탬프를 주지 않아요 (H-10).
- 참가자 모집·선발은 A-4, 혜택과 시상은 A-5, 메인 무대 진행은 A-9, 문서 초안은 A-10에서 콘텐츠를 함께 다뤄요.

## 2. 확정 값

**콘텐츠 구성 (고정)**

| 콘텐츠 | 형식 | 날짜 | 장소 | 장 |
|---|---|---|---|---|
| 사투리 토론대회 | 개인전, 대구 vs 타지역 말싸움 | 예선은 축제 전 온라인(신청·영상 심사), 본선·결승은 **일요일**. 일요일 우천이 심할 때만 최후 수단으로 토요일에 앞당김 (A-2) | 메인구역 메인무대 | A-2, A-3 |
| 사투리 골든벨 | 관객 단체 참여 퀴즈 | **토요일** (A파트 담당 결정, 2026-11-19) | 메인무대 앞 의자석 → 메인무대 | A-6 |
| 뮤지컬 공연 | 지역 극단 초청, 대구 사투리 창작 뮤지컬 (A-7) | 미정 (타임테이블 때) | 메인구역 메인무대 | A-7 |
| 사투리 순회 NPC | 공연인이 사투리로 돌아다니며 관객과 즐기는 이벤트 | **토요일** 종일 (A-8) | 팀별 담당 구역 (구역 안 자유 이동) | A-8 |

- 프로그램을 먼저 기획하고, 시각은 나중에 타임테이블에 하나씩 넣는다. (A파트 담당 결정, 2026-11-11)

**공통 규칙 (고정)**

- 모든 콘텐츠의 사투리 표현(논제, 퀴즈, 대본, 음원, 안내 문구)은 J(사투리) 검수를 받는다.
- 분위기는 가볍고 유머러스하게 즐기는 축제로 만든다.
- 대구·타지역 구분이 필요한 콘텐츠는 토론대회뿐이다. 구분 기준은 A-2를 따른다. 골든벨은 구분 없이 다 같이 참여한다. (A-6)

**QR 체크인 (고정)**

- 현장 QR 체크인을 하나로 쓴다.
- 토론대회 관객 투표(A-3)는 **QR 체크인과 상관없이** 웹페이지에 로그인한 뒤 1인 1표로 한다. (A파트 담당 결정, 2026-11-19)
- 골든벨은 웹 O/X를 쓰지 않고, 무대 앞 의자석에서 화이트보드로 진행한다. (A-6)
- QR 체크인 화면에 **객석이 무대 영상에 나올 수 있다는 안내**를 넣는다. 현장 안내문, 진행자 멘트와 함께 쓴다. (A-10)

**스탬프 (고정, 2026-11-18 바뀜)**

- **A 사투리 콘텐츠는 스탬프를 주지 않는다. 스탬프 제도는 H-10을 따른다.** (A파트 담당 결정, 2026-11-18)
- 웹 QR 스탬프도 쓰지 않는다. (2026-11-17)

**구역 지도 (고정)**

- 지도는 **Y 지도 파일**을 따른다: 축제 전체는 `../Y.지도/Y_축제전체_지도.md`, 메인구역 안은 `../Y.지도/Y_메인구역_지도.md`. **메인구역 안 배치는 Y_메인구역_지도가 최신**이다. (지도 담당, 2026-11-18)
- 지도의 위치와 기본 배치는 **고정**이다. (A파트 담당 확인, 2026-11-17)

![축제 전체 안내도](../Y.지도/이미지/Y_축제전체_1안내도.webp)

- 축제 전체 안내도는 GPT로 만들었고 계속 고치는 중이다. 위치·순서는 이 안내도, 실제 지형은 위성지도를 기준으로 한다. 안내도의 메인구역 부분은 아직 고치기 전이라 Y_메인구역_지도와 다르다. (Y_축제전체_지도 0장)
- 지도 속 구역: 축제 출입로(공식 출입로 1곳), 운영·안전 부스(공원순환로 초입 부근 + 2.28자유광장 앞 광장 일부), 플리마켓, 7구 맛집거리, 메인구역, 식사존(두류공원2공영주차장, 메인무대 중계 대형 디스플레이), 임시 바리게이트 3곳 (Y_축제전체_지도 3장)
- **방문객 동선:** 축제 출입로 → 운영·안전 부스 → 플리마켓 → 7구 맛집거리 → 메인구역. (Y_축제전체_지도 2장)

**메인구역 구역 (Y_메인구역_지도 기준)**

![메인구역 구획](../Y.지도/이미지/Y_메인구역_2구획.webp)

- **메인구역 = 메인무대(코오롱야외음악당) + A~G + X·Y·Z (X-1 포함)**

| 구역 | 용도 | A파트에서 쓰는 법 |
|---|---|---|
| A~G | **돗자리 존** (E·F·G는 경사가 있어 테이블 대신 돗자리, Y_메인구역_지도 2026-11-18). 외곽 인도(n-2)에 10미 포장마차 | 무대 관객석 |
| 무대 앞 의자석 | 골든벨 참가자 자리 | 골든벨 (A-6, 2026-11-19). 토론·뮤지컬 관객은 쓰지 않음 |
| X (X-1 포함) | 2027 기준: 운영·안전 부스, 굿즈샵·이벤트 부스 | 메인구역 운영·안전 부스 (아래 "운영·안전 부스 쓰는 법") |
| Y | 2027 기준: X와 Z 부스가 섞임 | - |
| Z | 2027 기준: 10미 포장마차 | - |

- X·Y·Z 용도는 해마다 바뀔 수 있다. 그해 용도는 Y_메인구역_지도를 따른다.
- 위치를 말할 때는 Y_메인구역_지도 3장 지칭 규칙(앞쪽/뒤쪽, n-1/n-2, 내부/외곽)을 쓴다.

| 콘텐츠 | 쓰는 구역 | 쓰는 법 | 장 |
|---|---|---|---|
| 사투리 토론대회 | 메인구역 **메인무대** | 경기는 무대에서. 관객은 **돗자리 존(A~G)**에서 보고 투표 | A-2, A-3, A-9 |
| 사투리 골든벨 | 메인무대 **앞 의자석** → 메인무대 | 의자석에 앉아 화이트보드로 인원을 줄이고, 결승 진출자(전체 참가자의 10%)만 무대에서 결승. 돗자리 존은 제한하지 않음 | A-6, A-9 |
| 뮤지컬 공연 | 메인구역 **메인무대** | 관객은 돗자리 존(A~G) | A-7, A-9 |
| 사투리 순회 NPC | 팀마다 **담당 구역**을 정함 | 담당 구역 안에서는 정해진 길 없이 자유롭게(랜덤) 돌아다님. 담당 구역 배정은 매년 A-8 팀 구성표에 적음 | A-8 |

- **돗자리 존은 자리를 나누지 않는다.** B(맛집) 10미 포장마차 손님과 무대 관객 모두 편한 대로 자유롭게, **선착순**으로 쓴다. (2026-11-17 테이블 존 결정을 E·F·G가 돗자리 존으로 바뀐 데 맞춤, 2026-11-19)

**운영·안전 부스 쓰는 법**

| 할 일 | 부스 | 장 |
|---|---|---|
| 토론대회 리허설 시작 때 신분증 확인 | 메인구역 운영·안전 부스 (2027 기준 X구역) | A-2, A-10 |
| 촬영 제외 요청 받기 (운영본부) | 두 부스 모두 (메인구역 X구역, 공원순환로 초입) | A-10 |
| NPC 휴식 | 담당 구역에서 가까운 부스 | A-8 |

**QR 체크인 지점과 관객 촬영 안내문 위치**

- QR 체크인 지점과 "객석이 영상에 나올 수 있다" 현장 안내문을 **축제 출입로**와 **메인 구역 들어가는 곳** 두 곳에 둔다. (A-3, A-10)
- 메인 구역 들어가는 곳은 방문객 동선에서 7구 맛집거리가 끝나고 메인 구역이 시작되는 곳이다. (A파트 담당 확인, 2026-11-17)

## 3. 에이전트 행동 규칙

**연도별 작성 (모든 콘텐츠 공통, 기본 지침 4-0)**

- 연도 주제와의 연결 1줄, 주로 기여하는 목표(사투리), 전년 대비 유지 / 개선 / 실험 분류와 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"
- 입력된 예산 범위를 처음부터 제약 조건으로 적용 (기본 지침 4-1)

**금지**

- 할매 말투 콘셉트 사용 금지, 사투리 비하·희화화 목적의 과장 표기 금지 (기본 지침 10장, J(사투리) 검수)
- 지역 비하, 타지역 출신 조롱 금지 (기본 지침 10장)
- 참가자 수, 참여 의사, 섭외 인물을 임의로 만들어 확정값처럼 쓰지 않음 (기본 지침 7장)
- 정해지지 않은 혜택 금액을 확정값처럼 쓰지 않음
- 고정 항목을 담당자 승인 없이 바꾸지 않음

## 4. 출력 형식

**1. 콘텐츠 구성표** — 콘텐츠, 형식, 날짜, 장소, 담당 장

**1-2. 구역 사용표** — 콘텐츠, 구역, 쓰는 법, 운영·안전 부스 할 일, QR·안내문 위치 (그해 지도 기준)

**2. 연도 정보** — 콘텐츠별 연도 주제 연결 1줄, 주 목표, 전년 대비 분류와 이유

**3. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한

## 7. 노션·기본 지침과 다른 점

- 노션 "파트별 키워드랑 파일 이름 어떻게할지"의 A는 "사투리 토론대회 (A-1~A-8)"이고, 이 장은 없어요. A파트 담당이 구성을 바꿨어요 (2026-11-11, 팀 회의 전).
