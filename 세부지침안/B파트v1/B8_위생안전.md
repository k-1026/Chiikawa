# B-8. 위생·안전 — 지침

> 근거: `기본지침서 v1.1` 3장 "위생·안전(9장 보강)" + 9장 운영·예산·안전 규칙 + [행정안전부 「지역축제장 안전관리 매뉴얼」(2024.9)](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000015&nttId=121801)
> 참고 사례: [축제 사례 V1.md](참고자료/축제%20사례%20V1.md) 카드 ②-2(서울시 푸드트럭 위생 의무), ②-3(서울국제정원박람회 매일 위생 점검·소화기 비치)
> 구분: 고정

## 1. 생식 품목 관리

대상: **뭉티기, 무침회**

- 냉장·보관 설비 확인 필수. 확인이 안 되면 현장 판매 대신 **원조 매장 쿠폰으로 대체**한다(현장에서 직접 만들어 팔지 않고, 방문객을 원조 매장으로 보낸다).
- 당일 반입량을 관리한다 — 남는 재료를 다음 날로 넘기지 않는다.
- 부스 배치 시 냉장 설비에 가까운 자리를 우선 배정한다(B-1 공간 배치 참고).

## 2. 화기 품목 체크리스트

대상: **막창, 곱창, 야끼우동, 찜갈비, 석쇠불고기 등**

| 체크 항목 | 기준 |
| --- | --- |
| 소화기 | 가스 사용 업소당 최소 1개, 부스 2~3개당 최소 1개 이상 비치. 기름 사용 부스는 K급 소화기 비치. 사용연한(10년)·충전압력·안전핀 부착 상태 확인 `[확인]` |
| 가스 호스·배관 | 호스 길이 3m 초과 금지, T자형 연결 금지(금속 강관 사용) `[확인]` |
| 가스통(LPG 용기) 보관 | 화기 취급 장소와 **2m 이상 우회하여 옥외 보관**. 보호캡 설치(햇빛·눈·비 차단), 체인 등으로 전도방지 조치. 저장량 100kg 초과 시 별도 가스보관실 설치 `[확인]` |
| 화기-천막 간 간격 | 정량(미터) 기준은 없음. 화기와 부스 천막이 가까우면 텐트에 불연재를 부착하거나, 화기와 천막 사이에 테이블 등으로 완충 구간을 두어 간격을 확보한다. 가스난로 연통은 천장과 거리를 두도록 높이를 조정한다 `[확인]` |
| 배치 위치 | 야외음악당 무대 관람석 반대편·바람 방향 고려(B-1 참고) |

- 매일 개점 전 위생·화기 점검을 한다(서울국제정원박람회 참고 사례의 "매일 개점 전 위생 점검" 방식 + 아래 출처의 "지역축제 진행 중" 점검 항목).
- 조리장 바닥재는 방염 처리한다 `[확인]`.

## 3. 비상 차량 이동로

- 공원순환로(7구 맛집거리 구간)는 일방향 동선과 별도로 비상 차량 이동로를 확보한다(B-1 참고).
- 도로를 사용하는 구간은 차량 통제·점용 허가 여부를 사전에 확인한다.

## 4. 불꽃 연출 없음

- 부스·무대 어디에서도 불꽃 연출을 하지 않는다. (2026년 치맥페스티벌 불꽃 낙하 사고를 참고한 원칙)

## 5. 추가 운영 의무

> 서울시 푸드트럭·서울국제정원박람회 운영 규정에서 설계 형태를 참고하되, 실제 적용 기준은 대구시·구청의 통상적인 영업신고·위생 관리 기준을 따른다. 아래 항목은 대구시·구청 기준으로 확정한다.

- 신청서에 적은 품목만 판매, 주 메뉴를 바꿀 경우 사전 통보
- 가격·원산지 표시
- 영업 등록·영업자 신고 확인, 보건증·위생교육 이수증 보유(B-5 심사 자격 요건과 연동) — 대구시·구청의 임시 영업신고 절차를 따름
- 쓰레기 수거 체계 마련

## 6. 변경 범위

- **고정**: 생식 품목 관리 원칙, 화기 체크리스트(2절 수치 포함 — 행정안전부 매뉴얼 기준), 비상 차량 이동로, 불꽃 연출 없음
- 축제장 현장 여건(바람 방향, 천막 배치 등)에 따른 세부 조정은 매년 개점 전 점검에서 소방·안전 담당자가 확인

## KPI 연계 (11장)

- 안전 점검 체크리스트 이행률, 사고·민원 발생 건수(0건 목표)
