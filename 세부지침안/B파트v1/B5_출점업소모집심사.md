# B-5. 출점 업소 모집·심사 — 지침

> 근거: `기본지침서 v1.1` 3장 "출점 업소 모집(①·② 공통)" + 7장 조사·근거 규칙
> 참고 사례(공공 공모): [축제 사례 V1.md](참고자료/축제%20사례%20V1.md) 카드 ②-2(서울시 푸드트럭), ②-5(대구 서문·칠성 야시장 서류+시식 심사)
> 구분: 연도별 변경(매년 다시 모집·심사)

## 1. 모집 순위

| 구역 | 1순위 | 2순위 |
| --- | --- | --- |
| ① 10미 포장마차 | 원조 골목 상인회·소속 업소 | 대구10미데이 참여 업소(2026년 기준 86곳) |
| ② 7구 맛집거리 | 구청 추천 업소 | 공개 모집 업소(B-4 선정 기준 충족) |

- 제과점(B-4의 추가 배정분)도 같은 순위 체계(구청 추천 → 공개 모집)를 따른다.

## 2. 서류·시식 심사

### 2-1. 절차

1. 공개 모집 공고(B-9 안내문 참고) → 신청 접수
2. 서류 심사 (자격 요건 충족 여부 + 아래 배점표)
3. 시식 심사 (서류 통과 업소 대상)
4. 결과 발표 → 선정 업소에 "후보" 꼬리표를 떼고 확정 업소로 전환 (3절)

### 2-2. 심사 배점표 (초안 — 100점 만점)

> 서울시 푸드트럭 모집(2026)·대구 서문·칠성 야시장 상인 선정(서류+시식) 방식을 참고해 설계한 초안이다. ❓ 팀 확정 필요

| 구분 | 항목 | 배점 |
| --- | --- | --- |
| 서류 (40) | 서류 완성도(사업자 정보·영업 이력) | 10 |
| | 대구 연계성(원조 골목·구청 추천 여부, B-3·B-4 기준 부합) | 15 |
| | 위생·영업 등록(영업신고·보건증·위생교육 이수) | 15 |
| 시식 (60) | 메뉴 맛·품질 | 25 |
| | 가격 적정성 | 15 |
| | 위생·조리 환경(현장 확인) | 10 |
| | 사투리 콘셉트 연계 가능성(B-7, 가점 성격) | 10 |

- 70점 미만은 탈락(서울시 푸드트럭 사례 기준 참고). ❓ 대구 축제 기준으로 확정 필요
- 제외 대상: 프랜차이즈, 영업 미등록 업소, 위생교육 미이수 업소, 10미·7구 메뉴 중복 위반 업소(B-2·B-4 참고)

## 3. "후보" 표기 규칙

- 선정 전까지 모든 업소명은 반드시 **"후보"**로 표기한다. 업소 정보·참여 의사를 임의로 만들어내지 않는다(7장).
- 이 지침 폴더 안의 B-3·B-4에 나온 업소 목록도 전부 **조사 단계의 1순위 후보**이지, 확정된 출점 업소가 아니다.
- 서류·시식 심사를 통과하고 참여 의사가 서면으로 확인된 업소만 "확정 업소"로 바꿔 쓴다.

## 4. 부족 시 보충 규칙

- 신청 업소가 부스 수보다 적으면:
  1. **1업소 다부스 운영** (예: B-3의 납작만두처럼 후보가 3곳뿐인 품목)
  2. 그래도 부족하면 **2순위 업소로 보충**(1절 모집 순위 표)
- 보충도 안 되면 해당 부스는 공석으로 두지 않고, 같은 구역 내 다른 품목·업소로 대체하거나 부스 수를 줄인다. 빈 부스를 임의 업소로 채우지 않는다.

## 5. 변경 범위

- **연도별 변경**: 모집·선발 과정 전체(참여 업소, 배점 세부 조정)
- **고정**: 서류→시식 2단계 심사 구조, "후보" 표기 원칙

## KPI 연계 (11장)

- 신청 업소 수, 서류·시식 통과율, 선정 후 참여 확정률 → 다음 해 모집 공고 개선에 반영
