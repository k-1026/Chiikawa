# B-9. 출점 업소 모집 안내문 (초안)

> B-1~B-8 지침을 바탕으로 작성한 안내문 초안. ❓ 표시된 항목은 연도별 확정값(일정·장소·연락처 등)을 채워야 발행 가능.
> 구분: 연도별 변경(매년 새로 작성)

---

## 2027 대구 사투리 축제 「타지에서 온 말손님」 — 먹거리 부스 출점 업소 모집 안내

대구 사투리 축제는 대구 10미 포장마차·대구 7구 맛집거리에 함께할 출점 업소를 모집합니다. 대구의 원조 맛집과 구별 대표 맛집을 소개하고, 축제 방문객이 축제가 끝난 뒤에도 실제 매장을 찾아가도록 연결하는 자리입니다.

### 1. 모집 분야

| 구역 | 모집 품목·대상 | 부스 수 |
| --- | --- | --- |
| ① 대구 10미 포장마차 (야외음악당 둘레) | 따로국밥·찜갈비·막창·무침회·납작만두·누른국수·야끼우동·뭉티기·복어불고기·논메기매운탕 | 품목당 최소 2동, 기준 4동 |
| ② 대구 7구 맛집거리 (공원순환로) | 중·동·서·남·북·수성·달서구 대표 맛집 (10미 메뉴 제외) | 구당 7동, 달서구 8동 |
| ③ 제과점 (7구 맛집거리 추가 배정) | 구별 유명 제과점 | 참여 확정 업소 수에 따라 결정 |

- ①은 원조 골목·업소(상인회 소속), 대구10미데이 참여 업소 우선 모집합니다.
- ②·③은 구청 추천 업소와 공개 모집 업소를 함께 선정합니다.
- ②·③은 한 구 안에서 같은 메뉴를 2곳까지만 선정합니다.

### 2. 자격 요건

- 대구 해당 구에서 **실제 영업 중**인 업소 (축제 후에도 방문 가능해야 함)
- 영업 등록·영업자 신고 완료, 보건증·위생교육 이수증 보유
- 프랜차이즈 업소 제외
- ①은 신청 메뉴가 해당 10미 품목과 일치해야 함, ②·③은 10미 10종 메뉴와 겹치지 않아야 함

### 3. 모집 일정 ❓ (연도별 확정)

| 시점 | 내용 |
| --- | --- |
| D-120 | 모집 공고 게시, 신청 접수 시작 |
| D-100 | 신청 접수 마감 |
| D-90 | 서류 심사 결과 발표 |
| D-80 | 시식 심사 |
| D-75 | 최종 선정 결과 발표, 참여 의사 서면 확인 |
| D-60 | 매장 카드(QR)·배치 확정 |

### 4. 제출 서류

1. 참가 신청서 (업소명, 사업자등록증, 대표 메뉴, 희망 구역)
2. 영업신고증·보건증·위생교육 이수증 사본
3. 대표 메뉴 사진·가격표
4. 대구 연계성 소개서(원조 여부·업력·구청 지정 이력 등)

### 5. 심사 기준 (100점, B-5 참고)

| 구분 | 항목 | 배점 |
| --- | --- | --- |
| 서류 (40) | 서류 완성도 | 10 |
| | 대구 연계성 | 15 |
| | 위생·영업 등록 | 15 |
| 시식 (60) | 메뉴 맛·품질 | 25 |
| | 가격 적정성 | 15 |
| | 위생·조리 환경 | 10 |
| | 사투리 콘셉트 연계 가능성(가점) | 10 |

- 70점 미만 업소는 선정에서 제외합니다.
- 신청 업소가 부스 수보다 적은 품목·구역은 2순위 후보로 보충하거나 1업소 다부스로 운영할 수 있습니다.

### 6. 참여 혜택

- 부스 임차료 없음 (수수료 조건은 예산 확정 후 별도 공지) ❓
- 매장 카드(QR)로 축제 기간 중 업소·골목 홍보
- 축제 종료 후 "축제장 밖 스탬프" 연계로 실제 매장 방문객 유입 효과

### 7. 운영 시 유의 사항

- 메뉴판에 사투리를 함께 표기합니다(비하·과장 표기는 하지 않습니다).
- 생식 품목(뭉티기·무침회)은 냉장 설비 확인이 안 되면 현장 판매 대신 원조 매장 쿠폰으로 대체될 수 있습니다.
- 화기 품목은 소화기 비치·가스 점검 등 안전 체크리스트를 준수해야 합니다.
- 선정 전까지는 "후보" 신분이며, 서류·시식 심사 통과 및 참여 의사 서면 확인 후 최종 확정됩니다.

### 8. 문의처

- ❓ 담당 부서·연락처는 주최 측 확정 후 기입
