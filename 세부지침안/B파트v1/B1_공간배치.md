## 1. 구역 정의 (사용 범위: 코오롱 야외음악당 ~ 공원순환로)

> 소상공인 플리마켓의 위치·배치는 **C-1(구성·배치)**에서 다룬다. B-1은 10미 포장마차·7구 맛집거리·굿즈 상점만 다룬다.

| 구역 | 프로그램 | 최소 부스 |
| --- | --- | --- |
| 야외음악당 진입로 | 축제 공식 굿즈 상점 | 상점 1곳 |
| 코오롱 야외음악당 둘레 | 대구 10미 포장마차 | 40동 |
| 야외음악당 옆 공원순환로 | 대구 7구 맛집거리 | 50동 + 제과점 추가 |
| 합계 | | 90동 + 제과점 추가 + 굿즈 상점 |

- 소상공인 플리마켓(공원순환로 위 7구 맛집거리와 연결된 구간, 최소 15동)은 C-1 참고.
- 2·28 자유광장은 사용하지 않는다. 별도 식음 테이블·휴게 존은 두지 않는다.
- 부스 수는 최소 기준이다. 첫해는 최소 규모로 시작하고, 매년 판매·대기·방문객 데이터를 쌓으며 연도별로 조정·확장한다(11장 KPI, 12장 연도별 개선).

## 2. 동선 원칙

- **일방향 동선**: 7구 맛집거리(공원순환로)는 걸으면서 7개 구를 차례로 지나가는 일방향 동선으로 구성하고, 구별 구간을 표시한다.
- **비상 차량 이동로**: 공원순환로는 일방향 동선과 별도로 비상 차량 이동로를 확보한다. 도로를 사용하는 구간은 차량 통제·점용 허가 여부를 사전에 확인한다.
- **3대 프로그램 연계 동선**: 토론 관람 → 투표 참여 → 포장마차 할인 → 플리마켓 스탬프 → 굿즈 교환처럼, 기획안에는 연계 동선을 1개 이상 포함한다(3장 연계 원칙).

## 3. 화기 부스 배치 원칙

- 화기 품목(막창·곱창·야끼우동·찜갈비·석쇠불고기 등) 부스는 **야외음악당 무대와 인접**하므로, 관람석 반대편·바람 방향을 고려해 배치한다.
- 생식 품목(뭉티기·무침회) 부스는 냉장·보관 설비 확인 여부에 따라 위치를 정하고, 설비 확인이 안 되면 현장 판매 대신 원조 매장 쿠폰으로 대체한다(B-8 위생·안전 참고).
- 화기 품목 부스 간 간격·소화기 비치는 B-8 체크리스트를 따른다.

- 구역별 정확한 좌표·면적·대관 조건은 **K 지도**(담당 파트) 자료를 따른다. → ❓ K 지도 문서 위치를 팀에 확인 후 이 문서에 링크 추가 필요
- 조사 단계에서 `[확인]` 필요한 항목: 야외음악당 둘레 면적, 공원순환로 길이·차량 통제 가능 여부, 대관 조건, 전기·급수 설비

## 5. 변경 범위

- **고정**: 4구역 구분, 각 구역의 역할
- **조건부 변경**: 부스 수(최소 이상), 배치, 실내외 운영
- **연도별 변경 아님**: 구역 자체의 위치는 공간 활용 원칙에 따라 고정하되, 세부 부스 배치는 매년 데이터로 조정
