# B-4. 대구 7구 맛집거리 — 지침

> 근거: `기본지침서 v1.1` 3장 "② 대구 7구 맛집거리(공원순환로, 최소 50동)"
> 구분: 고정(7구 모두 참여, 구당 최소 7동) + 연도별 변경(참여 맛집·메뉴)

## 1. 대상 구역

대구 7개 구: 중구·동구·서구·남구·북구·수성구·달서구. **군 지역은 제외**한다.

## 2. 구별 부스 수

| 구 | 부스 | 비고 |
| --- | --- | --- |
| 중구, 동구, 서구, 남구, 북구, 수성구 | 각 7동 | 구청 추천·공모 업소 |
| 달서구 | 8동 | 개최지 추가 1동 |
| 합계 | 50동 | |
| 제과점 | 추가 배정 | 50동과 별도. 영업·참여 의사가 확인된 업소 수에 따라 부스 수 결정 |

## 3. 맛집 선정 기준

- **구성 단위**: 골목 단위가 아니라 **각 구의 유명 맛집(업소 단위)**으로 구성한다. 1업소 1동 원칙.
- **후보 출처**: 구청 추천·지정 업소(예: 북구청 "오래된맛집"), 대구푸드 구·군별 인증업소, 대구10미데이 참여 업소, 공개 모집 신청 업소.
- **영업 조건**: 해당 구에서 실제 영업 중인 매장만 후보로 둔다 — 축제 후 방문 가능해야 한다.
- **메뉴 중복 금지(10미와)**: 10미 10종 메뉴는 이 구역에서 판매하지 않는다(B-2 참고). 10미 품목 취급 업소는 10미 구역 후보로만 둔다.
- **구 안 메뉴 중복 제한**: 같은 구 안에서 같은 메뉴는 **2곳 이하**로 제한한다.
- 업소명은 기획 단계에서 미리 지정하지 않는다. 구청 추천 + 공모 → 서류·시식 심사로 매년 선정하고, 확정 전에는 반드시 **"후보"**로 표기한다(B-5 참고).
- 개최지 달서구는 구청 음식 안내(달서맛나)와 협업해 추천 업소를 확보한다.

## 4. 제과점 추가 배정

- 각 구의 유명 제과점을 기존 맛집 부스(2절 50동)에 **추가**로 배정한다. 기존 맛집 후보와 바꾸지 않는다.
- 선정 기준은 맛집과 같다: 백년가게·오래된 업소 우선, 실제 영업 중인 매장, 한 구 안에서 같은 메뉴 2곳 이하.
- 구별 구간 안에 맛집과 함께 배치한다.
