## 1. 이 파트의 역할

- 사투리 콘텐츠 4개를 소개하고, 모든 콘텐츠에 같이 적용하는 규칙과 QR 체크인·스탬프 규칙을 정해요.
- 참가자 모집·선발은 A-4, 혜택과 시상은 A-5, 메인 무대 진행은 A-9, 문서 초안은 A-10에서 콘텐츠를 함께 다뤄요.

## 2. 확정 값

**콘텐츠 구성 (고정)**

| 콘텐츠 | 형식 | 날짜 | 장소 | 장 |
|---|---|---|---|---|
| 사투리 토론대회 | 개인전, 대구 vs 타지역 말싸움 | 토 예선, 일 4강·결승 (예상, 금·토도 검토 중) | 메인구역 메인무대 | A-2, A-3 |
| 사투리 골든벨 | 관객 단체 참여 퀴즈 | 토요일 (처음 논의 기준) | 메인구역 A구역 → 메인무대 | A-6 |
| 뮤지컬 공연 | 지역 극단 초청, 사투리 관련 공연 | 미정 | 메인구역 메인무대 | A-7 |
| 사투리 순회 NPC | 공연인이 사투리로 돌아다니며 관객과 즐기는 이벤트 | 토 또는 일, 종일 | 팀별 담당 구역 (구역 안 자유 이동) | A-8 |

- 프로그램을 먼저 기획하고, 시각은 나중에 타임테이블에 하나씩 넣는다. (A파트 담당 결정, 2026-11-11)

**공통 규칙 (고정)**

- 모든 콘텐츠의 사투리 표현(논제, 퀴즈, 대본, 음원, 안내 문구)은 J(사투리) 검수를 받는다.
- 분위기는 가볍고 유머러스하게 즐기는 축제로 만든다.
- 대구·타지역 구분이 필요한 콘텐츠는 토론대회뿐이다. 구분 기준은 A-2를 따른다. 골든벨은 구분 없이 다 같이 참여한다. (A-6)

**QR 체크인 (고정)**

- 현장 QR 체크인을 하나로 쓴다. 토론대회 관객 투표(A-3)가 이 체크인을 쓴다.
- 골든벨을 웹 O/X·단답으로 진행할지는 검토 중이다. (A-6)
- QR 체크인 화면에 **객석이 무대 영상에 나올 수 있다는 안내**를 넣는다. 현장 안내문, 진행자 멘트와 함께 쓴다. (A-10)

**스탬프 (고정, 2026-11-17 바뀜)**

- **웹 QR 스탬프는 쓰지 않는다.** 웹사이트 스탬프 기능은 삭제하기로 했다. (A파트 담당 확인, 2026-11-17)
- 스탬프는 **오프라인 스탬프 북**으로 한다. 축제장 초입(축제 출입로 옆) 운영·안전 부스에서 스탬프 북을 나눠 주고, A·B·C·E 부스와 프로그램에서 **실제 도장**을 찍어 준다. (A-1 구역 지도)
  - A·B·C·E가 스탬프 북 하나를 같이 쓰는 것은 A파트 담당이 정했다(2026-11-17). 이렇게 해도 되는지 **팀 회의에서 확인이 필요**하다. (미확정 4번)
- 스탬프 북 **제도 전체**(스탬프 북 양식, 목표 개수, 교환 기준, 교환소 운영)는 **M-6(메인)**이 설계한다. A파트는 A 콘텐츠에서 도장을 주는 곳, 찍는 시점과 횟수까지만 다룬다. (B-6 2-4와 같은 기준, 2026-11-18)
- 운영·안전 부스의 스탬프 북 배부·안내는 M파트가 담당할 예정이다. (Y_축제전체_지도 3-1, 2026-11-18)
- A파트에서 도장을 주는 곳은 4개다: **토론 투표 참여, 사투리 순회 NPC 이벤트 참여, 골든벨 참여, 뮤지컬 관람**
- 도장은 **콘텐츠 담당자가 직접** 찍어 준다. NPC 이벤트는 NPC가, 나머지는 그 콘텐츠의 담당 스태프가 찍는다.
- **찍는 시점:** 콘텐츠마다 담당자가 아래 4개 중 하나를 고른다.
  1. 시작 전 입구에서
  2. 프로그램 중간에 (정확한 타이밍을 적는다. 예: 2라운드 끝난 직후)
  3. 끝난 후 출구에서
  4. 기타 — 1~3 중에서 고를 수 없을 때만 쓰는 최후의 수단이다. 고르면 방법과 이유를 적는다.
- **횟수:** 콘텐츠마다 담당자가 **하루 1회** 또는 **축제 기간 중 1회** 중 하나를 고른다. 콘텐츠를 보고 더 나은 쪽을 고른다.
- 고른 시점과 횟수는 매년 4장 "스탬프 운영표"에 적는다.
- NPC 이벤트 스탬프 보상은 **따로 만드는 굿즈**로 준다. (D(굿즈))
- 스탬프 북 교환 내용, 할인 금액과 정산은 M-6(메인), B(맛집) 담당과 정한다. (미확정 1번)

**구역 지도 (고정)**

- 지도는 **Y 지도 파일**을 따른다: 축제 전체는 `../../Y.지도/Y_축제전체_지도.md`, 메인구역 안은 `../../Y.지도/Y_메인구역_지도.md`. **메인구역 안 배치는 Y_메인구역_지도가 최신**이다. (지도 담당, 2026-11-18)
- 지도의 위치와 기본 배치는 **고정**이다. (A파트 담당 확인, 2026-11-17)

![축제 전체 안내도](../../Y.지도/Y_축제전체_1안내도.webp)

- 축제 전체 안내도는 GPT로 만들었고 계속 고치는 중이다. 위치·순서는 이 안내도, 실제 지형은 위성지도를 기준으로 한다. 안내도의 메인구역 부분은 아직 고치기 전이라 Y_메인구역_지도와 다르다. (Y_축제전체_지도 0장)
- 지도 속 구역: 축제 출입로(공식 출입로 1곳), 운영·안전 부스(공원순환로 초입 부근 + 2.28자유광장 앞 광장 일부), 플리마켓, 7구 맛집거리, 메인구역, 식사존(두류공원2공영주차장, 메인무대 중계 대형 디스플레이), 임시 바리게이트 3곳 (Y_축제전체_지도 3장)
- **방문객 동선:** 축제 출입로 → 운영·안전 부스 → 플리마켓 → 7구 맛집거리 → 메인구역. (Y_축제전체_지도 2장)

**메인구역 구역 (Y_메인구역_지도 기준)**

![메인구역 구획](../../Y.지도/Y_메인구역_2구획.webp)

- **메인구역 = 메인무대(코오롱야외음악당) + A~G + X·Y·Z (X-1 포함)**

| 구역 | 용도 | A파트에서 쓰는 법 |
|---|---|---|
| A·B·C·D | 돗자리 존 | 무대 관객석. **A구역은 골든벨 예선**에 씀 (A-6) |
| E·F·G | 테이블 존. 뒤쪽(n-2)은 10미 포장마차 | 무대 관객석 (앞쪽 n-1) |
| X (X-1 포함) | 2027 기준: 운영·안전 부스, 굿즈샵·이벤트 부스 | 메인구역 운영·안전 부스 (아래 "운영·안전 부스 쓰는 법") |
| Y | 2027 기준: X와 Z 부스가 섞임 | - |
| Z | 2027 기준: 10미 포장마차 | - |

- X·Y·Z 용도는 해마다 바뀔 수 있다. 그해 용도는 Y_메인구역_지도를 따른다.
- 위치를 말할 때는 Y_메인구역_지도 3장 지칭 규칙(앞쪽/뒤쪽, n-1/n-2, 내부/외곽)을 쓴다.

| 콘텐츠 | 쓰는 구역 | 쓰는 법 | 장 |
|---|---|---|---|
| 사투리 토론대회 | 메인구역 **메인무대** | 경기는 무대에서. 관객은 **돗자리 존(A~D)·테이블 존(E·F·G)**에서 보고 투표 | A-2, A-3, A-9 |
| 사투리 골든벨 | 메인구역 **A구역** → 메인무대 | A구역에서 이지선다·화이트보드로 인원을 줄이고, 최종 통과자만 무대에서 결승. 시작 n시간 전까지 A구역 돗자리 회수(미리 펴는 건 가능) | A-6, A-9 |
| 뮤지컬 공연 | 메인구역 **메인무대** | 관객은 돗자리 존(A~D)·테이블 존(E·F·G) | A-7, A-9 |
| 사투리 순회 NPC | 팀마다 **담당 구역**을 정함 | 담당 구역 안에서는 정해진 길 없이 자유롭게(랜덤) 돌아다님. 담당 구역 배정은 매년 A-8 팀 구성표에 적음 | A-8 |

- **테이블 존(E·F·G)은 자리를 나누지 않는다.** B(맛집) 10미 포장마차 손님과 무대 관객 모두 편한 대로 자유롭게, **선착순**으로 쓴다. (A파트 담당 결정, 2026-11-17)

**운영·안전 부스 쓰는 법**

| 할 일 | 부스 | 장 |
|---|---|---|
| 토론대회 리허설 시작 때 신분증 확인 | 메인구역 운영·안전 부스 (2027 기준 X구역) | A-2, A-10 |
| 촬영 제외 요청 받기 (운영본부) | 두 부스 모두 (메인구역 X구역, 공원순환로 초입) | A-10 |
| NPC 휴식 | 담당 구역에서 가까운 부스 | A-8 |

**QR 체크인 지점과 관객 촬영 안내문 위치**

- QR 체크인 지점과 "객석이 영상에 나올 수 있다" 현장 안내문을 **축제 출입로**와 **메인 구역 들어가는 곳** 두 곳에 둔다. (A-3, A-10)
- 메인 구역 들어가는 곳은 방문객 동선에서 7구 맛집거리가 끝나고 메인 구역이 시작되는 곳이다. (A파트 담당 확인, 2026-11-17)

## 3. 에이전트 행동 규칙

**연도별 작성 (모든 콘텐츠 공통, 기본 지침 4-0)**

- 연도 주제와의 연결 1줄, 주로 기여하는 목표(사투리), 전년 대비 유지 / 개선 / 실험 분류와 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"
- 입력된 예산 범위를 처음부터 제약 조건으로 적용 (기본 지침 4-1)

**금지**

- 할매 말투 콘셉트 사용 금지, 사투리 비하·희화화 목적의 과장 표기 금지 (기본 지침 10장, J(사투리) 검수)
- 지역 비하, 타지역 출신 조롱 금지 (기본 지침 10장)
- 참가자 수, 참여 의사, 섭외 인물을 임의로 만들어 확정값처럼 쓰지 않음 (기본 지침 7장)
- 정해지지 않은 혜택 금액을 확정값처럼 쓰지 않음
- 고정 항목을 담당자 승인 없이 바꾸지 않음

## 4. 출력 형식

**1. 콘텐츠 구성표** — 콘텐츠, 형식, 날짜, 장소, 담당 장

**1-2. 구역 사용표** — 콘텐츠, 구역, 쓰는 법, 운영·안전 부스 할 일, QR·안내문 위치 (그해 지도 기준)

**2. 스탬프 운영표** (연도별, 열 구성은 담당자 확인 전 제안)

| 콘텐츠 | 도장 담당자 | 찍는 시점 (1 입구 / 2 중간 + 타이밍 / 3 출구 / 4 기타 + 방법·이유) | 횟수 (하루 1회 / 축제 기간 중 1회) | 고른 이유 |
|---|---|---|---|---|
| 토론 투표 참여 | | | | |
| 사투리 순회 NPC 이벤트 | NPC | | | |
| 골든벨 참여 | | | | |
| 뮤지컬 관람 | | | | |

**2-1. 스탬프 교환표** — 조건, 스탬프 수, 교환 내용, 정산 담당

**3. 연도 정보** — 콘텐츠별 연도 주제 연결 1줄, 주 목표, 전년 대비 분류와 이유

**4. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한

## 7. 노션·기본 지침과 다른 점
