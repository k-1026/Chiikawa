# P0-6 예산 범위 — 세부 지침

> 구분: 입력 · 기본 지침: 6장, 9장 · 진행: **확정 v13 (2026-11-19)** · 최종 수정: 2026-11-19
> 기준 문서: 기본 지침 v1.1, main `세부지침안/B파트v5/`(10미·7구 수수료 규정 없음), `세부지침안/C파트v3/`(C-4 수수료·정산), `대사투/공통/단가표.md`
> 상세 산정(항목·수량·단가)은 H(운영) 파트가 맡아요. 이 파일은 예산을 **어떻게 받고, 어떤 틀로 나누는지**만 정해요.

## 1. 이 파트의 역할
- 매년 예산을 입력으로 받을지, 에이전트가 산정할지 정하고, 예산 대분류 7개와 근거 자료 순서를 고정해요.
- 읽는 PART: M(메인) 기획조건표, H(운영) 예산 상세, 각 PART(예산 제약 조건)

## 2. 확정 값

### 2-1. 예산 입력 방식

| 방식 | 언제 | 에이전트가 하는 일 |
| --- | --- | --- |
| A. 예산 범위 입력 | 담당자가 금액 범위를 줄 때 | 그 범위를 **첫 기획 요소부터 제약 조건**으로 적용 (기본 지침 v1.1 4-1). 범위 안에서 최소/기본/확장 3안 |
| B. 산정 요청 | 금액이 정해지지 않았을 때 | 2-3 근거 자료 순서로 최소/기본/확장 3안을 산정 → 담당자가 확정 |

- 기본 지침 6장 필수 입력이에요. 둘 다 없으면 기획 전에 물어보고, 답이 없으면 `[가정] 산정 요청`으로 진행해요.

### 2-2. 예산 대분류 7개 (기본 지침 v1.1 9장)

| # | 대분류 | 들어가는 것 (예) | 주로 관련된 PART |
| --- | --- | --- | --- |
| 1 | 무대·시설 | 무대·음향·조명, 부스(텐트·조리), 화장실, 전기·급수, 그늘·냉방 | A, B, C, H |
| 2 | 프로그램 운영 | 토론 상금·심사·진행, 업소 모집·심사, 부대 프로그램, 웹(체크인·투표·스탬프), 스탬프 이벤트(운영 부스) 보상: 매년 정하는 상품 + 쿠폰북 제작 | A, B, C, E, H, K |
| 3 | 굿즈·제작 | 마스코트 굿즈, 출전자 기념품, 매장 카드(QR)·메뉴판 | D, B |
| 4 | 홍보 | 숏폼·콘텐츠 제작, 지역 크리에이터 협업, 원정 팝업, 오프라인 홍보물·교통 연계 (온라인 유료 광고는 넣지 않음, F-2) | F |
| 5 | 인건비 | 운영 스태프, 안전관리 인력, 의료 | H |
| 6 | 안전·보험 | 배상책임보험, 소방·안전 장비, 인허가 행정 | H |
| 7 | 예비비 | 1~6 합계의 일정 비율 | H |

- 숙박 인증 보상·축제장 밖 쿠폰 같은 **상권·관광 연계 지원금**과 **성과 측정 비용**은 7개 중 어디에 넣을지 정해야 해요 (7장).
  - G가 금액 3안 `[추정]`과 계산 틀을 제안했어요 (확정은 담당자·H): 원조 매장 쿠폰 3,000 / 5,000 / 10,000원(G-3 A), 외지인 영수증 쿠폰 사용액 5%·최대 1만 원 / 10%·최대 2만 원 / 10%·최대 3만 원(G-3 B), 숙박 인증 보상 1만 / 2만 / 3만 원(G-5 2-2).
  - 쿠폰 사용처는 원조 매장에서 **협업하는 대구 가게·관광지·놀이공원**으로 넓혔어요 (담당자 결정 2026-11-17). G-3 금액 3안은 G 갱신 때 다시 맞춰요. 쿠폰 기대효과 예측은 P0-2 3-4를 따라요.
  - 쿠폰은 **스탬프 판 완성 보상의 쿠폰북**으로 나눠 줘요 (담당자 결정 2026-11-17). 쿠폰북 제작비는 대분류 2, 쿠폰 할인액을 누가 부담할지(협업처 부담 / 축제 지원금)는 7장 6번이에요.
  - 계산 틀: **혜택 예산 = 혜택 금액 × 상한 건수(선착순).** 배포 수·사용률은 근거가 없어 담당자가 상한을 정해요 (G-3 2-3).

### 2-3. 팀 입력 방식 (확정 2026-11-11)

| 항목 | 정한 값 |
| --- | --- |
| 입력 단위 | **대분류 7개 총액** (항목별 단가는 받지 않음) |
| 파일 형식 | **CSV / 엑셀** — 양식: `P0-6_예산입력_양식.csv` |
| 3안 차이 | **항목 포함 여부** — 대분류마다 "필수" 묶음과 "선택" 묶음으로 나누고, 묶음별로 최소/기본/확장에 넣을지 O/X로 표시 |
| 예비비 | **10%** — 1~6 대분류 합계 × 10%, 안마다 따로 계산 (팀 입력 안 함) |

**양식 열 (한 줄 = 대분류 안의 한 묶음)**

| 열 | 뜻 |
| --- | --- |
| 연도 | 개최 연도 |
| 대분류 | 2-2의 1~6 중 하나 (예비비는 자동 계산이라 넣지 않음) |
| 묶음 | 필수 / 선택 |
| 설명 | 이 묶음에 들어가는 것 (예: 메인 무대·음향·부스) |
| 최소 · 기본 · 확장 | 이 묶음을 그 안에 넣으면 O, 빼면 X. 필수 묶음은 셋 다 O |
| 금액(원) | 이 묶음의 총액 |
| 근거 | 첫해: "팀 제공" / 2년 차부터: "전년 집행" / 그 외: 견적·공공·추정 |
| 기준일 · 메모 | 금액 기준일, 참고 사항 |

**에이전트 계산 순서**
1. 안마다 O 표시된 묶음 금액을 대분류별로 더해요.
2. 1~6 합계를 구하고, 예비비 = 합계 × 10%를 더해 총액을 만들어요.
3. 대분류 합 → 소계 → 예비비 → 총액을 **계산식과 함께** 표로 보여 줘요.
4. 입력된 예산 범위(2-1 A)가 있으면 어느 안이 범위 안인지 표시해요.

### 2-3-1. 산정 근거 자료 순서

| 연차 | 근거 | 처리 |

| 보조 | 공공 발주 단가, 다른 지자체 축제 결산, 견적 | 팀이 요청할 때만 참고값으로 제시, 근거 종류 표시 |

### 2-4. 수입 항목 (예산과 따로 표시)

| 항목 | 내용 | 상태 |
| --- | --- | --- |
| 출점 수수료 | **플리마켓: 판매 수익의 5.3%, 참가비 없음** (C파트v3 C-4, 고정). 현금 판매분은 셀러가 일자별 판매 기록 제출, 정산일까지 못 마치면 다음 해 참여 불가 | 플리마켓 수수료는 확정 전까지 `[추정]` 수입으로 표기 (C-4). 10미·7구는 B파트v4에 수수료 규정이 없어요 (B-9 삭제, 모집 공고는 M-7). 이전 B-9 메모: "부스 임차료 없음, 수수료 조건은 예산 확정 후 공지 ❓" |
| 협찬 | 협찬 기업·단체 (P0-5 2-3) | 사람이 가져온 경우만 |
| 프랜차이즈 후원금 | 대구 본점 프랜차이즈 약 10곳의 후원금(또는 투자금). **최소 후원금 기준액은 매년 담당자가 입력**하고, 에이전트는 금액을 정하거나 전년 값을 그대로 쓰지 않아요 (B-5 2-6) | 담당자 입력 전에는 "미입력" |
| 굿즈 판매 | 공식 굿즈 상점 (사후 온라인 판매는 보류, D-6). 남은 재고는 할인·이월 판매 없이 기부, 남으면 자체 폐기 (D-5 2-7, H-7 2-7) — 굿즈 수입 추정에 할인 판매분을 넣지 않음 | D파트 |

- 수입은 확정 전까지 예산 총액에서 빼지 않고 **별도 표**로만 보여 줘요.
- 수입원 6종(입점비·수수료, 스폰서, 굿즈, 광고, 홍보부스, 협업업체)과 취소 시 일부 환불(취소된 날만큼)의 구조는 **H-9**, 수입 합산과 예산 상세는 **H-1**이 원본이에요. P0-6은 입력 방식·대분류만 정해요.

## 3. 에이전트 행동 규칙
- 예산은 항상 **최소/기본/확장 3안**으로 내요.
- 첫해에는 팀이 넣은 **대분류 총액만** 써요. 항목별 단가·수량으로 쪼개지 않고, 쪼갠 상세 산정이 필요하면 H(운영) 파트로 넘겨요.
- 팀이 비워 둔 금액을 에이전트가 채우지 않아요. "미입력"으로 두고 담당자에게 물어봐요.
- **총액과 세부 합계를 직접 계산해서 맞추고, 계산식을 보여 줘요.**
- 확인 안 된 비용을 확정값처럼 쓰지 않아요. 단가표에 근거가 없으면 `[추정]`이에요.
- 2년 차부터 전년 집행액과 올해 입력값이 크게 다르면(예: ±20% 이상, 제안값) 이유를 담당자에게 확인해요.
- 예산을 확정하지 않아요. 3안 비교와 추천안·근거까지만 내고, 확정은 담당자가 해요 (기본 지침 v1.1 0장).
- 입력된 예산 범위를 넘는 아이디어는 평가 필수 조건에서 탈락이에요 (기본 지침 8장).
