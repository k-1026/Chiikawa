## 자료집 다시 만들기

1. 바꿀 곳을 고친다 — 단어 정밀 정보는 `../J01_사투리사전.md` 본문표, 위험 단어는 `../J02_표기규칙.md` 2-5 표 "스크립트용 목록" 열, 새 근거·단어는 `원천자료(AI 미사용)/`에 CSV(열: 단어, 표준어 뜻, 지역 표시, 출처 사이트, URL)를 추가.
2. 이 폴더에서 `python -I J자료집생성.py` 실행.
3. 출력된 수(자료집·판정·보관)를 J03 2-7-2 숫자와 맞춘다.

## 판정·범위 기준 (요약)

- 들어가는 조건: 대구·경북 근거가 하나라도 있음 — 대구 달성군 지역어 조사(G1), 대구시 블로그(G2·G5), 대구 언론·연구(G3), Quizlet 대구 세트(G4, 약함), 공식 자료의 경북·경상 표시(G6·G7), 비공식 자료의 경북·경상 표시(G8, 약함), D파트 굿즈 문구(G9, 약함 — 다른 근거가 없으면 ⚠️ W11).
- 기준 범위는 대구·경북 하나다(팀 결정). 대구를 따로 입증할 필요는 없고, 경상도 전체에서 널리 쓰는 말도 대구에서 쓰는 말로 보고 넣는다. 근거 코드는 어디서 확인했는지를 보여 줄 뿐이다.
- 판정: 위험 단어·비속어·욕설 → 반려(J02 2-6) / 약한 근거뿐·문장형·용언·다의·표준어 추출 불가·주의 단어 → ⚠️ 사람 확인(J03 2-7-3) / 나머지 → 자동 사용.

- "쌔비다"(훔치다)는 우리말샘에서 방언이 아니라 속어로 확인돼 스크립트가 뺀다.
- 지역어 종합 정보의 표제어에 붙은 억양 표기(예: `가거(=가'거)`)는 표제어에서 떼어 자료집 "원문 뜻" 칸 끝에 적는다.
- 더 많은 대구 단어를 얻으려면 지역어 종합 정보의 대구광역시 자료를 끝까지 받아야 한다. 사이트의 Open API는 회원가입·키 발급이 필요하다(J파트 담당이 판단).
