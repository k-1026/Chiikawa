# J-4. 능력고사 데이터

> 목차: [J00_목차.md](J00_목차.md)
> 구분: 연도별 · 기본 지침 4-4 · 진행: 초안 v5(8문항 — 대구·경북 자료집 "자동 사용" J-1 단어, 유명한 경상도 사투리 포함, 쌔리다 문항 삭제) · 최종 수정: 2026-11-18

## 1. 이 파트의 역할

- 사투리 단어 뜻 맞히기 **문제·정답·해설 데이터**를 만들고 난이도를 구분한다.
- 이 데이터는 **A-6(사투리 골든벨)의 "사투리 단어 시험" 문제 유형**에 쓰인다(2026-11-17 A06_사투리골든벨.md 원문 대조로 확인) — J-4는 축제장에서 퀴즈를 진행하는 프로그램이 아니라, A-6이 쓸 문제은행을 만드는 역할이다. "능력고사"라는 이름은 이 문제은행을 가리키는 J파트 내부 명칭이다.
- **웹 능력고사용(K 구현, 2026-11-26)**: 같은 문항을 K 웹의 "온라인 사투리 능력고사"(4지선다 5문제)에도 쓴다. 문항 8개 중 **무작위 5개**를 내고, 풀이마다 해설을 보여 준다. 점수는 저장하지 않고 계정·스탬프와 무관하다. 문항·해설은 A-6용과 같은 J-3 검수를 받은 것만 쓴다.
- 시작 규모: **5~10문항, 난이도 1단계**로 시작한다(2026-11-17 결정) — 유튜브 '하말넘많' 채널의 사투리 능력고사(조회수 190만 회 이상)처럼 난이도 단계·문항 유형을 다양화하는 것은 다음 단계 과제다.
- 문제는 **대구·경북 자료집(`사투리 사전 전체자료/J사투리사전_자료집.md`)에서 ID가 D로 시작하고 판정이 "자동 사용"인 단어만으로** 낸다(v4). 기준 범위는 대구·경북 하나라 경상도 전체에서 쓰는 유명한 말도 낸다. ⚠️ 단어로는 문제를 내지 않는다.

## 2. 확정 값

### 2-1. 문제 형식 (1단계)

- 사투리 단어의 표준어 뜻을 맞히는 **4지선다형**.
- 오답 선택지는 J-1에 등재된 다른 단어의 뜻이나, 그럴듯하지만 틀린 뜻으로 구성한다(출처 없이 지어낸 오답 뜻풀이도 "오답"이라는 용도로만 쓰고 정답처럼 혼동되게 적지 않는다).

### 2-2. 예시 문항 8개 (v5 — 대구·경북 자료집의 "자동 사용" J-1 단어, 난이도 1단계)

> 문제 단어는 **`사투리 사전 전체자료/J사투리사전_자료집.md`에서 ID가 D로 시작하고(사람이 품사·예문까지 확인) 판정이 "자동 사용"인 단어**로 고른다. 기준 범위는 대구·경북 하나라서, 억수로·와이카노·정구지처럼 **경상도 전체에서 널리 쓰는 말도 대구에서 쓰는 말로 보고 문제로 낸다**(2026-11-18 팀 결정). 관객이 알 만한 유명한 말을 우선한다. 쌔리다는 폭력 연상 주의 단어(J-2 2-5, 자료집 ⚠️)라 공식 퀴즈에서 뺐다.

## 3. 에이전트 행동 규칙(금지)

1. 대구 자료집에서 ID가 D로 시작하고 판정이 "자동 사용"인 단어가 아니면 문제로 내지 않는다(S로 시작하는 자동 판정 단어는 품사·예문이 확인 안 돼 퀴즈 정답으로 쓰지 않는다).
2. 정답·해설은 J-1의 뜻풀이와 다르게 쓰지 않는다.
3. 오답 선택지를 비하·희화화 표현으로 만들지 않는다(J-2 공통 금지).
4. 난이도를 임의로 올리거나(예: 우리말샘 미등재 단어, 활용형이 복잡한 단어) 2단계 이상으로 확대하지 않는다 — 1단계(단어 뜻 맞히기)로만 시작한다.
5. 자료집 판정이 "⚠️ 사람 확인"인 단어(예: D11 가시나, D13 쌔리다)는 사람이 확인해 판정이 바뀌기 전까지 문제로 내지 않는다. J-2 2-5 위험 단어 모음의 단어(예: 쌔리다)는 "주의"여도 공식 퀴즈에는 쓰지 않는다.
6. 문제를 만든 뒤 J-3 검수에 넘긴다 — 검수 결과가 "사람 확인 대기"면 A-6에 "확정"으로 넘기지 않는다.

## 6. 기본 지침·다른 문서와 다른 점

- A-6(사투리 골든벨)의 "문제와 정답의 사투리 표현은 J(사투리) 검수를 받는다"는 기존 규정을 그대로 따른다. **J-4와 A-6은 겹치는 게 아니라 역할이 나뉜다**: A-6은 축제장에서 실제 진행하는 관객 참여 퀴즈 프로그램(신청·무대·진행 방식을 다룸)이고, J-4는 그중 "사투리 단어 시험" 유형에 쓸 **문제·정답 데이터**만 만든다. A-6의 다른 두 유형("사투리 듣기 평가", "대구 퀴즈")은 J-4 범위가 아니다(2026-11-17 확인, A06_사투리골든벨.md 원문 대조).
