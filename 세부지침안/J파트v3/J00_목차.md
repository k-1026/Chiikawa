# J. 사투리 사전·검수 — 목차

> 사투리 사전·표기 규칙·검수(다른 파트 결과물의 사투리 표현 검수)를 다루는 J파트의 세부 지침이다. J파트 담당이 관리한다.
> 하위 파트마다 md 파일 1개를 만들고, 모두 같은 양식(아래 "파일 양식")을 쓴다.
> 기준 지침: 기본 지침 v1.1 · 최초 작성: 2026-11-17

- 파일 이름: `J00_이름.md`처럼 파트 문자 바로 뒤에 두 자리 번호를 붙인다(하이픈 없음). 버전은 파일 이름에 적지 않고 폴더 이름(`J파트v1`, `J파트v2`…)에만 적는다(2026-11-17 파일명 규칙).
- **사투리 단어 데이터는 `사투리 사전 전체자료/J사투리사전_자료집.md` 한 파일이다**(v18). 대구·경북 근거가 있는 단어만 들어 있고, 단어마다 판정(자동 사용·⚠️ 사람 확인·반려)이 붙어 있다. 기준 범위는 **대구·경북 하나**다(팀 결정 — 대구를 따로 입증하지 않고, 경상도 전체에서 널리 쓰는 말도 포함). 에이전트와 다른 파트는 이 파일만 읽는다. `원천자료(AI 미사용)/` 폴더는 사람용 보관 자료다.
- 자료집은 `사투리 사전 전체자료/J자료집생성.py`가 J01 본문표·J02 위험 단어 표·원천자료 CSV(굿즈 문구 CSV 포함)를 읽어 만든다. 셋 중 하나를 고치면 그 폴더에서 `python -I J자료집생성.py`를 다시 실행한다.
- 모든 경로는 이 J파트 폴더 기준 상대경로다 — 폴더를 `세부지침안/J파트vN/`으로 옮겨도 그대로 작동한다.
- "진행"이 "대기"인 하위 파트는 아직 내용을 채우지 못한 상태다 — 자료 조사 후 채워 나간다.
- 이 목차와 하위 파트 구성은 확정이 아니다. 자료 조사 중 바뀔 수 있다.

## 구분 뜻

- **고정**: 매년 같음. 바꾸려면 담당자 승인 + 지침 버전 변경
- **연도별**: 매년 새로 확정하는 값(능력고사 문제 등)
- **조사**: 한 번 조사해 확정되면 유지하고, 필요 시에만 갱신

## 파일 양식 (J파트 공통)

> 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(금지) → 4. 매년 받을 입력·조사할 항목 → 5. 다른 파트 연결 → 6. 기본 지침·다른 문서와 다른 점 → 7. 미확정·회의 필요 → 8. 출처 → 변경 이력

- 근거 라벨(P0-9 기준): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요(검증 방법 함께 적음) · `[추정]` 계산·가정 기반 수치(계산식 함께 적음) · 라벨 없는 수치·주장은 쓰지 않음, 확인 안 된 건 "확인 안 됨"으로 표시
- 사람이 직접 판단해야 하는 일(표기 금지 여부의 애매한 사례, 비하·희화화 여부 판단 등)은 각 파일에 "⚠️ 사람이 해야 하는 일" 콜아웃으로 표시한다.
