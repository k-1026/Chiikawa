# J-3. 검수 절차

> 목차: [J00_목차.md](J00_목차.md)
> 구분: 고정 · 기본 지침 10장 · 진행: 초안 v6(대구·경북 자료집 단일화 — 근거 없는 단어 제외, 에이전트 실행 절차 2-8 신설) · 최종 수정: 2026-11-18

## 1. 이 파트의 역할

- A~G파트 결과물 중 **사투리 표현이 들어간 텍스트**를 검수하는 절차를 정한다.
- 검수는 2단계다: **① 에이전트 1차 검사 → ② 사람(J파트 담당) 최종 확인**(2026-11-17 결정) — 에이전트가 자동으로 승인·확정하지 않는다. 순환형 축제 에이전트로 돌릴 때 ②는 "기획 담당자 확인"이 되고, 에이전트는 반환 상태 `질문 필요`로 넘긴다(2-8).
- 검수 기준 데이터는 **`사투리 사전 전체자료/J사투리사전_자료집.md` 한 파일**이다(v6). 이 파일에는 **대구·경북에서 쓰인다는 근거가 있는 단어만** 있고(2026-11-18 결정: 기준 범위는 대구·경북 하나 — 대구를 따로 입증하지 않는다), 단어마다 판정(자동 사용·⚠️ 사람 확인·반려)이 미리 붙어 있다(2-7). 사람이 단어를 골라 옮기는 단계는 없다.
- 이 문서 자체는 기준 단어를 만들지 않고, 자료집·J-2를 어떻게 적용해 통과·반려를 가르는지만 다룬다.

## 2. 확정 값

### 2-1. 검수 대상

- 사투리 표현이 들어간 모든 텍스트: 메뉴판·미션 문구(B-7), 플리마켓 연계 문구(C-6), 굿즈 문안(D), 홍보 카피(F), 토론대회 논제 문구(A-2), 골든벨 문제(A-6), 능력고사 문항(J-4) 등.
- 검수 대상이 아닌 것: 사투리가 전혀 안 들어간 일반 안내문, 통계·행정 문서.

### 2-2. 체크리스트 (에이전트 1차 검사용, v6)

> v6에서 "J-1 본문표 / 전체수집본 / 둘 다 없음" 3분기를 **"자료집에 있음 / 없음"** 2분기로 바꿨다. 자료집이 J-1 본문표 단어(ID가 D로 시작)와 원천자료 자동 판정 단어(ID가 S로 시작)를 한 표에 담기 때문이다.

| # | 확인 항목 | 기준 |
| --- | --- | --- |
| 1 | 쓴 사투리 단어가 **자료집에 있는가** — 있으면 ID를 적는다. 없으면 6번으로 | 자료집 |
| 2 | 자료집의 **"표준어(병기용)" 뜻과 다르게** 쓰지 않았는가. 표기는 "표기" 열 그대로인가. D 단어는 품사·예문 열에 맞는 활용만, S 단어는 표기 열 형태 그대로만 썼는가 | 자료집, 2-7-4 |

### 2-3. 절차

1. 요청 파트가 검수할 문구를 제출한다(쓴 사투리 단어의 자료집 ID를 함께 적으면 빠르다).
2. 에이전트가 2-2 체크리스트를 대조한다(1차 검사).
3. 다 통과하고 ⚠️도 없으면 "1차 통과 — 사람 최종 확인 대기"로 넘긴다. **사람(J파트 담당 또는 기획 담당자)이 최종 확인**하고 승인한다.
4. 통과했어도 **⚠️가 있으면**(2-2 3번) 반려는 아니지만 "⚠️ 사람 확인 필요"를 달아 넘긴다 — 사람은 이 표시를 보고 특히 더 주의해서 본다.
5. 2·4·5·6·7번 중 하나라도 걸리면 반려하고, 2-4 수정요청 양식으로 돌려준다.
6. 수정 후 다시 1번부터 반복한다.

### 2-6. 드라이런 테스트 기록 (2026-11-18) — **이전 규칙 기록, 지금은 2-7로 대체됨**

### 2-7. 자동 판정 — J-3 몫 (v5 신설, v6에서 대구·경북 근거 기준으로 갱신)

> 품사·예문이 없는 원천자료 단어도 사람이 먼저 골라 옮기지 않고 쓸 수 있도록, **단어마다 판정을 미리 붙여 둔다.** J-2가 표기 위험(J-2 2-6: X1~X3·W7)을, J-3이 대구·경북 근거·검증 상태(아래 W1~W10)를 맡고, `J자료집생성.py`가 둘을 합쳐 자료집을 만든다.
> 결과: `사투리 사전 전체자료/J사투리사전_자료집.md` · 스크립트: `사투리 사전 전체자료/J자료집생성.py` · 실행: 그 폴더에서 `python -I J자료집생성.py`
> **v6에서 바뀐 핵심**: v5는 지역 표시를 글자로만 보고 통과시켰고, 그 표시가 무엇을 뜻하는지(대구인지, 경북 전체인지) 구분하지 않았다(교차 검증 지적). v6은 ① 기준 범위를 **대구·경북 하나**로 정하고(2026-11-18 팀 결정 — 대구를 따로 입증하지 않는다. 경상도 전체에서 널리 쓰는 말도 대구에서 쓰는 말이므로 포함), ② 어디서 확인했는지를 G1~G8로 단어마다 적고, ③ 대구·경북 근거가 없는 단어(경남만 표시 등)는 자료집에서 뺀다.

#### 2-7-4. "자동 사용" 단어의 사용 조건

1. **표기**는 자료집 "표기" 열 그대로(우리말샘의 `-` 표시를 뺀 형태).
2. **표준어를 먼저, 사투리를 괄호로 병기** — 병기하는 표준어는 "표준어(병기용)" 열 그대로. 예: "두부(조피) 조림".
3. **뜻을 바꾸거나 넓혀 쓰지 않는다.**
4. **S 단어는 활용형·합성어를 새로 만들지 않는다.** D 단어는 품사·예문 열 범위 안에서 쓴다.
5. 결과 파일에 **쓴 단어의 자료집 ID**를 적는다.

## 3. 에이전트 행동 규칙(금지)

1. 체크리스트를 통과했다고 해서 에이전트가 최종 승인까지 하지 않는다 — 사람의 최종 확인 전까지는 "검수 중" 상태다.
2. 반려 이유를 "부적절함" 같이 뭉뚱그려 적지 않고, 2-2의 몇 번에 걸렸는지 구체적으로 적는다.
3. J-1·J-2에 없는 새로운 금지 기준을 에이전트가 임의로 만들어 적용하지 않는다.
4. 자료집의 판정을 검수 때 다시 매기지 않는다 — 열 그대로 따른다. 이상해 보이면 반환의 '질문'에 적는다.
5. 자료집에 없는 단어를 "비슷하니까" 하며 자료집 단어로 바꿔 끼우지 않는다(J-1 3절 10번). `원천자료(AI 미사용)/` 폴더의 파일을 근거로 쓰지 않는다.
6. 검수 중에 웹 검색으로 새 사투리를 찾아 바로 쓰지 않는다 — 찾은 근거는 '질문'으로 돌려 J파트 담당이 2-7-5 방식으로 자료집에 넣게 한다.
