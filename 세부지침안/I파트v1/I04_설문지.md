# I-4 설문지 — 세부 지침

> 구분: 고정(필수 항목) + 연도별(추가 문항) · 기본 지침: v1.1 0장, 11장 · 진행: 초안 v1 · 최종 수정: 2026-11-18

## 1. 이 파트의 역할
- 설문 **5종**의 대상·시점·**필수 항목**을 정해요 (담당자 결정 2026-11-18).
  1. 사전 설문 (방문 예정자)
  2. 사후 온라인 설문 (방문객)
  3. 협업처 설문 (쿠폰북 가게·관광지·놀이공원)
  4. 참가 업소 설문 (10미·7구 식당 사장님, 플리마켓 셀러)
  5. **현장 스탬프 교환 설문** (스탬프 북을 완성해 운영 부스에 온 방문객)
- 필수 항목은 매년 빼지 않아요. 그 밖의 문항은 **담당 기획자에게 추가할 문항이 있는지 물어서** 넣어요.
- 읽는 PART: K(설문 화면), H(현장 안내), G(협업처), B·C(업소), P0-8(페르소나 검증), I-2·I-5·I-8

### 2-6. ⑤ 현장 스탬프 교환 설문 — 필수 항목

스탬프 북을 완성한 사람은 스탬프를 찍어 주는 음식·플리마켓·토론·부대 프로그램을 직접 즐긴 사람이에요. 그래서 **즐긴 콘텐츠별 만족도**를 현장에서 바로 받아요 (담당자 결정 2026-11-18).

| # | 항목 | 쓰는 곳 | 비고 |
| --- | --- | --- | --- |
| 1 | 거주 시·도 | 외지인 비율 (현장 기준) | 시·도까지만 |
| 2 | **스탬프 받은 콘텐츠별 만족도** (10미 포장마차 / 7구 맛집거리 / 플리마켓 / 토론 대회 / 부대 프로그램, 5점) | 프로그램 판정 (I-6), 2층 운영 지표 | 그해 스탬프 북의 칸 구성대로 보기를 만들고, 안 간 곳은 "이용 안 함" |
| 3 | 가장 좋았던 것 1개 (보기) | 다음 해 배치·홍보 | |
| 4 | 전체 만족도 (5점) | ②와 비교 | |
| 5 | 오늘 대구에서 숙박하는지 (당일 / 1박 / 2박 이상) | 1박 비율 현장값 (②와 비교) | |
| 6 | 사후 설문 연락 동의 (선택) + 연락 수단 | ② 발송 | 개인정보 I-3 2-2. **거절해도 교환은 해 줘요** |

- 1~5번 응답이 끝나면 상품·쿠폰북을 줘요. 개인정보(6번)는 교환 조건이 아니에요.
- `[해석]` ⑤는 스탬프 북을 끝까지 채운 사람만 답해서 **만족도가 높게 나오기 쉬워요.** 결과에는 "스탬프 완성자 기준"이라고 적고, ②의 만족도와 같이 봐요.
- 종이로 받으면 운영 부스가 매일 운영 종료 뒤 응답 수와 함께 모아요 (I-2 2-3 일일 집계).

### 2-7. 추가 문항 묻기 (매년)
설문 초안을 만들 때(D-120) 에이전트가 담당 기획자에게 설문 5종마다 이렇게 물어요.

```
[① 사전 설문] 필수 8개 문항으로 초안을 만들었어요.
올해 추가로 확인하고 싶은 것이 있나요? (예: 연도 주제 관심도, 굿즈 선호, 특정 프로그램 참여 의향)
- 추가 문항: ___
- 넣는 이유(어느 지표·판단에 쓰는지): ___
```

- 추가 문항은 설문 파일에 **"연도별 추가"**로 구분하고 이유를 같이 적어요. 다음 해에는 그대로 두지 않고 다시 물어요.
- 이유가 없는 문항은 넣지 않고, 필수 항목과 같은 내용이면 합쳐요.
- 추가 문항이 2-1 문항 수 상한을 넘으면 기획자에게 알리고, 넘는 만큼 빼거나 합칠 문항을 같이 제안해요.

## 3. 에이전트 행동 규칙
- 필수 항목을 빼거나 문장을 바꾸지 않아요. 특히 **사투리 인식 문항은 ①②가 같은 문장**이어야 비교가 돼요.
- 질문 문장은 표준어로, 한 문항에 하나만 물어요. 사투리 표현은 보기나 예시에만 써요 (P0-10).
- 설문 결과는 응답 수와 함께 적어요 (예: "1박 이상 42% (응답 310명)"). 응답이 **30명 미만**이면 "참고용"으로 표시해요 (담당자 결정 2026-11-18).
- 응답 수를 지어내거나, 응답이 없는 문항을 추정으로 채우지 않아요.

## 6. 기본 지침과 다른 점
- 기본 지침 11장·구성안 초안은 "현장 설문 + 업체·셀러 설문"이었어요. 담당자 결정(2026-11-18)으로 **사전·사후 온라인·협업처·참가 업소·현장 스탬프 교환 5종**으로 바꿨어요. 현장 설문은 운영 부스에서 스탬프 북을 바꿀 때 받는 짧은 설문(⑤)으로 해요.
