# I-3 수집 데이터 정의 — 세부 지침

> 구분: 연도별 · 기본 지침: v1.1 11장, 10장(개인정보 수집·보관 체크리스트) · 진행: 초안 v1 · 최종 수정: 2026-11-18

## 1. 이 파트의 역할
- 지표를 재려면 **어떤 데이터를, 어디서, 어떤 항목으로** 모을지 정해요. 웹 화면(K)과 현장 기록표(H)를 만들 때 이 목록을 써요.
- 개인정보는 **지표 계산에 꼭 필요한 것만** 모으고, 동의·보관·파기 규칙을 정해요.
- 읽는 PART: K(웹 화면), H(현장 기록), A(투표), C-4(결제 시스템), G-3·G-5, I-2·I-4·I-5

## 2. 확정 값

### 2-1. 데이터 출처와 항목

| 출처 | 모으는 항목 | 개인 정보 | 쓰는 지표 (I-1) | 담당 |
| --- | --- | --- | --- | --- |
| 입구 계수 | 날짜, 출입구, 시간대(1시간), 입장 수 | 없음 | 총 방문객, 혼잡 시간대 | H |
| 웹 체크인 (K) | 체크인 시각, 거주 시·도(선택 입력) | 없음 (기기 식별값은 저장하지 않음) | 웹 이용 방문객, 외지인 비율 보조 | K |
| 관객 투표 (A·K) | 경기 번호, 투표 열림·닫힘, 투표 수, 득표율 | 없음 (중복 투표 방지 값은 집계 후 삭제) | 투표 수 | A·K |
| 스탬프 판 배부·교환 (운영 부스) | 날짜, 배부 수, 완성 판 교환 수, 상품·쿠폰북 지급 수 | 없음 | 완성률, 쿠폰북 지급 수 | H |
| 쿠폰북 사용 | 협업처, 쿠폰 종류, 사용 일자, 사용 건수, (가능하면) 결제 금액 | 없음 | 쿠폰북 사용 수·사용률 | 협업처 → G |
| 숙박 인증 (G-5) | 신청일, 숙박일, 숙소 지역(구 단위), 주소지 시·도, 보상 지급 여부 | **있음** (본인 확인·주소지) | 숙박 인증 수 | G·K |
| 결제 시스템 (B·C-4) | 부스, 품목, 판매 시각, 금액 | 없음 (카드 정보는 받지 않음) | 품목별 판매량, 완판 시각, 셀러 매출 | B·C |
| 부스 운영 기록표 | 부스, 시간대별 대기 줄 길이 또는 대기 시간, 완판 시각 | 없음 | 대기 시간, 완판 시각 | B·E (현장) |
| 부대 프로그램 기록표 | 프로그램, 회차, 참여 수, 대기 시간 | 없음 | 회차별 참여 수 | E |
| 설문 5종 | I-4 문항 (⑤ 현장 스탬프 교환 설문은 운영 부스에서 종이·태블릿) | 선택 시 연락처 (사후 설문 발송용) | 1박 비율, 지출, 콘텐츠별 만족도 등 | I (⑤ 현장 수거는 H) |
| 데이터랩 | 기간·지역 방문자 수, 거주지별 비율 | 없음 (집계 자료) | 외지인 비율 | I |
| SNS·웹 홍보 지표 | F-7 2-1 | 없음 | 사투리 콘텐츠 조회·공유 | F |

### 2-2. 개인정보 규칙

| 항목 | 규칙 | 이유 |
| --- | --- | --- |
| 수집 범위 | 지표 계산에 안 쓰는 항목은 모으지 않아요. 거주지는 **시·도**까지만 (숙박 인증만 본인 확인 필요) | 기본 지침 10장, 개인 단위 추적 안 함 (F-7 2-2) |
| 동의 | 수집 항목·목적·보관 기간·파기 방법을 화면 첫머리에 보여 주고 동의를 받아요. 사후 설문 연락은 **선택 동의** | 동의 없이 연락하지 않으려고 |
| 보관 | 연락처·본인 확인 자료는 목적이 끝나면(사후 설문 발송, 보상 지급) 파기. 결과는 **비식별 집계**로만 보관 | 연도별 결과 저장(12장)은 집계로 충분해요 |
| 보관 기간 숫자 | 담당자가 정해요. 에이전트는 기간을 임의로 정하지 않고 "관계 기관 최신 기준 확인"으로 적어요 | 법적 판단은 에이전트가 하지 않음 (기본 지침 0장·9장) |
| 결과 공유 | 개인이 드러나는 원자료는 다른 파트·외부에 넘기지 않고 집계표만 넘겨요 | |

### 2-3. 데이터 파일 저장
- 원자료(계수표, 기록표, 설문 응답)는 `local리서치v2/<연도>/자료/`에 두고, 개인정보가 있는 파일은 레포에 올리지 않아요 (담당자가 따로 보관).
- 시연용 가상 데이터는 I-7 규칙대로 파일 이름에 `가상`을 붙여요.

## 3. 에이전트 행동 규칙
- K에 웹 화면을 요청할 때 2-1의 항목 목록만 넘겨요. 목록에 없는 항목(이름, 생년월일, 휴대폰 번호)을 요청하지 않아요.
- 데이터를 받으면 항목이 2-1과 맞는지 먼저 보고, 빠진 항목은 "수집 안 됨"으로 적어요. 비어 있는 값을 채우지 않아요.
- 개인정보가 들어간 원자료를 받으면 집계만 하고 원문은 산출물에 옮기지 않아요.

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| 그해 웹 화면 구성 | 입력 (K) | D-90 | 웹 집계 지표 "측정 도구 없음" |
| 결제 시스템 사용 여부·항목 | 입력 (B·C-4) | D-60 | 부스 기록표로 대체 |
| 개인정보 보관 기간 | 입력 (담당자) | D-90 | 동의 화면 보류 |
| 개인정보 관련 최신 기준 | 조사 (관계 기관) | D-90 | "확인 필요" 체크리스트만 |

## 6. 기본 지침과 다른 점
- 기본 지침 10장은 "개인정보 수집·보관 체크리스트 포함"만 적었어요. I-3은 출처별 수집 항목, 거주지는 시·도까지, 비식별 집계 보관을 정했어요. 보관 기간 숫자는 담당자 입력으로 남겼어요.
