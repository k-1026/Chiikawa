# I-7 시연용 가상 데이터 — 세부 지침

> 구분: 프로젝트 한정 · 기본 지침: v1.1 7장(통계 임의 생성 금지), 12장(과거 데이터 없으면 성과 가정 금지) · 진행: 초안 v1 · 최종 수정: 2026-11-18

## 1. 이 파트의 역할
- 우리 축제는 **첫해(2027)라 이전 연도 운영 데이터가 없어요.** 그래서 에이전트의 성과 분석(04·05)이나 예산·기대효과 흐름을 시연하려면 값이 필요해요.
- 이때만 쓰는 **가상 데이터의 규칙**이에요. 가상 값이 실제 근거처럼 섞이지 않게 하는 것이 목적이에요 (담당자 결정 2026-11-18).
- 읽는 PART: 전체 (가상 값이 들어갈 수 있는 모든 산출물), M(시연)

## 2. 확정 값

### 2-1. 파일 이름 규칙

| 규칙 | 예 |
| --- | --- |
| 가상 수치가 하나라도 들어간 파일은 **파일 이름 앞에 `가상_`**을 붙여요 | `가상_04_운영결과.md`, `가상_03_기획안_예산.md`, `가상_입구계수.csv` |
| 예산부터 방문객·매출·설문 응답까지 **가상으로 준 수치는 모두** 해당 | 가상 예산표, 가상 설문 응답, 가상 경제효과 |
| 실제 파일과 같은 이름을 쓰지 않아요 | `04_운영결과.md`(실제)와 `가상_04_운영결과.md`(가상)는 따로 |

### 2-2. 파일 안 표시
- 맨 위 첫 줄: `> ⚠ 가상 데이터 — 시연용으로 만든 값이에요. 실제 근거로 쓰지 않아요.`
- 가상 값마다 `[가상]` 라벨을 붙여요. `[확인]`·`[추정]`과 같이 쓰지 않아요.

### 2-3. 실제 값이 생기면
- 그 연도·항목에 **실제 값이 하나라도 생기면 `가상_` 파일은 읽지 않아요.** 확인하지 않는 값으로 취급해요.
- 가상 값을 실제 파일로 옮기거나, 실제 값과 섞어 평균·비교하지 않아요.
- 가상 값은 단가표(`local리서치v2/공통/단가표.md`)·다음 해 기획조건표·KPI 목표값의 근거로 쓰지 않아요.

### 2-4. 언제 쓰나
- 사용자가 **"가상으로 돌려", "시연용으로"**처럼 직접 요청할 때만 만들고 읽어요.
- 요청이 없으면 값이 없는 칸은 지금처럼 "측정 안 됨", "확인 안 됨"으로 둬요.

## 3. 에이전트 행동 규칙
- 가상 값을 만들 때는 그럴듯한 범위를 쓰되, 실제 축제·기관 이름을 붙여 실제 발표처럼 보이게 쓰지 않아요.
- 가상 파일에서도 계산 규칙(I-2 공통 분모, I-8 추정식, 3안)은 실제와 똑같이 따라요. 시연은 계산 흐름을 보이려는 거예요.
- 산출물을 보고할 때 가상 파일을 썼으면 "가상 데이터 사용"을 맨 앞에 적어요.
- 시연이 끝나도 가상 파일을 지우지 않아요 (파일 이름으로 구분되므로). 지우려면 사용자에게 물어요.

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| 시연 범위 (어느 산출물) | 입력 (사용자) | 시연 요청 때 | 가상 파일 만들지 않음 |
| 가상 값의 범위 지정 | 입력 (사용자, 선택) | 시연 요청 때 | 에이전트가 정하고 `[가상]` 표시 |
