# J-1. 사투리 사전

> 목차: [J00_목차.md](J00_목차.md)
> 구분: 조사 · 기본 지침 7장 · 진행: 초안 v7(예시 13개, 국립국어원 우리말샘 직접 대조까지 완료) · 최종 수정: 2026-11-18

## 1. 이 파트의 역할

- 대구 사투리 표제어를 모아 **표준어 뜻·예문·사용 맥락·출처**를 정리한 1차 사전이다.
- 다른 파트가 사투리 표현을 쓸 때(B-7 메뉴판·미션, A파트 토론대회 논제·골든벨 등) 이 사전을 1차로 참고하고, 실제 사용 가능 여부의 최종 판단은 **J-2 표기 규칙 + J-3 검수 절차**를 따른다. 이 파일(J-1)은 "어떤 뜻인가"까지만 다루고, "써도 되는가"는 J-2·J-3 범위다.
- 범위: 대구 사투리 전반(축제 콘텐츠에 쓰일 단어로 한정하지 않음) — 2026-11-17 결정.
- 표제어는 **단어 단위로만** 조사한다 — 완성된 문장·대화체 표현은 표제어로 올리지 않는다(2026-11-17 결정). 문장 형태는 "예문" 칸에서만 보여준다.

- **[확인](교차검증 부분일치)**: 2개 이상 출처가 있으나 세부 표기·뉘앙스가 다름 — 차이점을 함께 적는다.
- **[확인](단일출처)**: 출처 1개뿐 — 추가 조사 전까지 "교차검증 전" 상태로 남기고, 등재는 하되 7절 미확정 목록에 올린다.
- 2026-11-17 결정: 신규 표제어는 단일 출처로 바로 올리지 말고, 가능하면 교차검증까지 마친 뒤 올린다.

## 3. 에이전트 행동 규칙(금지)

1. 표제어는 **단어 단위로만** 올린다 — 완성된 문장·대화체 표현을 표제어로 올리지 않는다.
2. 출처 없이 표제어·뜻·예문을 지어내지 않는다 — 출처가 없는 항목은 "확인 안 됨"으로 둔다.
3. **단일 출처만으로 "확정"처럼 쓰지 않는다** — [확인](단일출처)로 표시하고 7절 미확정 목록에 올려 교차검증을 계속한다.
4. 지역 범위를 출처보다 좁게 쓰지 않는다 — 예: 출처가 "경상도"라고 하면 "대구만의 말"로 적지 않는다. 반대로 출처가 "대구"라고 특정했는데 "경상도 전역"으로 넓히지도 않는다.
5. 비하·희화화 목적으로 뜻풀이·예문을 왜곡하지 않는다(J-2 표기 규칙과 동일 원칙).
6. 할매 말투 콘셉트의 표현을 대표 예문으로 쓰지 않는다(B-7·J00 공통 금지 사항과 동일).
7. 출처가 서로 다른 뜻을 줄 때(교차검증 불일치) 하나를 임의로 고르지 않고 둘 다 적고 "확인 필요"로 표시한다.
8. **"두 번째 출처"는 실제 URL·문서를 특정할 수 있어야 교차검증으로 인정한다** — 검색 결과 요약 문장만 보고 "강의자료", "~기사" 등으로 뭉뚱그려 적지 않는다. URL을 못 찾으면 단일출처로 등급을 낮춘다(2026-11-17 2차 재검증에서 D01·D03·D04가 이 규칙 위반으로 드러나 수정됨).
9. **교차검증 등급([확인](교차검증 일치) 등)을 매기기 전에 출처 문서를 직접 열어서 확인한다** — 검색 결과 요약문만 보고 "두 출처가 같은 뜻"이라고 판단하지 않는다. 요약문과 원문이 다를 수 있다(2026-11-17 3차 재검증에서 D02·D04·D06의 등급이 요약문 기반 판단과 실제 원문이 달라 다시 바뀜).
10. **이 사전에 없는 단어가 필요할 때(B-7 메뉴판, A파트 콘텐츠 등에서 요청)는 에이전트가 단어를 지어내거나 비슷한 다른 단어로 대체하지 않는다.** 대신: ① 해당 항목은 표준어로만 두고 ② 요청한 파트(B-7/A파트 등)에 "J-1 사전에 없음"을 알리고 ③ J파트 담당에게 추가 조사를 요청한다. 사전 분량이 부족한 지금 단계에서 특히 자주 발생할 수 있다(2026-11-17 추가 — 6개뿐인 현재 수록량으로는 실제 메뉴판·콘텐츠 운영에 못 미칠 수 있음을 염두에 둔 규칙).
