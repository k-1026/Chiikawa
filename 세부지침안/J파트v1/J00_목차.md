# J. 사투리 사전·검수 — 목차

> 사투리 사전·표기 규칙·검수(다른 파트 결과물의 사투리 표현 검수)를 다루는 J파트의 세부 지침이다. J파트 담당이 관리한다.
> 하위 파트마다 md 파일 1개를 만들고, 모두 같은 양식(아래 "파일 양식")을 쓴다.
> 기준 지침: 기본 지침 v1.1 · 최초 작성: 2026-11-17
> 다른 파트(A~G) 결과물에 쓰이는 사투리 표현은 J파트가 검수한다 — A파트 등을 참고해 형식을 맞췄다.

## 구분 뜻

- **고정**: 매년 같음. 바꾸려면 담당자 승인 + 지침 버전 변경
- **연도별**: 매년 새로 확정하는 값(능력고사 문제 등)
- **조사**: 한 번 조사해 확정되면 유지하고, 필요 시에만 갱신

## 파일 양식 (J파트 공통)

> 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(금지) → 4. 매년 받을 입력·조사할 항목 → 5. 다른 파트 연결 → 6. 기본 지침·다른 문서와 다른 점 → 7. 미확정·회의 필요 → 8. 출처 → 변경 이력

- 근거 라벨(P0-9 기준): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요(검증 방법 함께 적음) · `[추정]` 계산·가정 기반 수치(계산식 함께 적음) · 라벨 없는 수치·주장은 쓰지 않음, 확인 안 된 건 "확인 안 됨"으로 표시
- 사람이 직접 판단해야 하는 일(표기 금지 여부의 애매한 사례, 비하·희화화 여부 판단 등)은 각 파일에 "⚠️ 사람이 해야 하는 일" 콜아웃으로 표시한다.
