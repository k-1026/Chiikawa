# F03 온라인 연계 흐름 — 세부 지침

> 구분: 고정(흐름 틀) + 연도별(콘텐츠 내용) · 기본 지침: v1.1 4-4 "온라인 연계 (사전 + 현장 + 사후)" · 진행: 초안 · 최종 수정: 2026-11-16

## 1. 이 파트의 역할
- 온라인 콘텐츠가 사람을 **다음 단계로 보내는 고리(CTA)**를 정해요. "본 사람 → 참여한 사람 → 온 사람 → 다시 올 사람"으로 이어지게 해요.
- **F는 흐름과 시점만 정해요** (담당자 결정 2026-11-12). 고사 화면·문항은 K·J, 팝업 굿즈는 D, 1박 코스는 G, 토론 신청은 A가 상세를 맡아요. 실제로 만들 때는 그 파트 세부 지침을 확인한 뒤 자세히 짜요.
- 읽는 PART: F04·F05·F07, K, A, D, G, I

## 2. 확정 값

### 2-1. 전체 흐름 (P0-8 6단계 기준)

```
[사전]                                              [현장 3일]                    [사후]
1. 알아보기 ──→ 2. 관심·참여 ──→ 3. 체험 ──→ 4. 이동·방문 ──→ 5. 구매·즐기기 ──→ 6. 공유·재방문
 숏폼·팔로우      사투리 고사·변환기    원정 팝업     교통·숙박 안내    토론·먹거리·굿즈     하이라이트·알림
                 결과 카드 공유        미션·인증                       스탬프·인증샷       현장 하이라이트
```

### 2-2. 단계별 고리

| 단계 | 들어오는 곳 | 하는 일 | 다음 단계로 보내는 CTA | 넘어갈 때 남기는 기록 | 상세 담당 |
| --- | --- | --- | --- | --- | --- |
| 1. 알아보기 | 숏폼(인스타·쇼츠·틱톡), 크리에이터, 네이버 검색 | 대키미·외지몽 시리즈 시청 | **팔로우** + 프로필 링크 → 고사 | 조회·팔로우 | F02, E |
| 2. 관심·참여 | 프로필 링크, 스토리 링크 | 사투리 고사·변환기 참여 → 결과 카드 | **결과 카드 공유** + 토론 참가 신청(D-120~D-75) 또는 방문 할인 코드(D-60~) + 알림 동의 | 응시·공유·코드 발급·알림 동의 | K, J, A |
| 3. 체험 | 고사 결과 화면, 인스타 공지 | 원정 팝업 미션·SNS 인증 | **한정 굿즈·숙박/쿠폰 추첨 응모** + 1박 코스 안내 | 인증 수·추첨 응모 | D, G |
| 4. 이동·방문 | 알림 메시지, 네이버 안내글 | 교통·주차·입구·숙박 확인 | **웹 지도 열기** | 지도 열람 | G, K |
| 5. 구매·즐기기 | 현장 QR | 토론 관람·투표, 먹거리, 굿즈, 스탬프 | **인증샷 해시태그** + 내년 알림 신청 | 인증 게시물·투표·코드 사용 | A, B, C, D |
| 6. 공유·재방문 | 하이라이트 숏폼, 알림 | 하이라이트 시청, 업체 소개 | **내년 알림 신청** + 원조 매장 방문 | 알림 신청 | D, B, G |

- `[해석]` 각 단계의 CTA는 하나만 크게 보여요. 한 화면에 신청·구매·팔로우를 모두 넣지 않아요.
- 2단계와 3단계는 기간이 겹쳐요. 팝업 현장에서 고사를 권하고, 고사 결과 화면에서 팝업을 알려 서로 사람을 보내요 (P0-8 2-2 `[가설]`).
- 3일 구성과 연결: 1·2일차 밤 토론 하이라이트 숏폼 → 2·3일차 방문 유도 (기본 지침 v1.1 3장 3일 구성, `local 리서치/minju_03_온라인콘텐츠.md` 3장 `[가설]`).

### 2-3. 고정 원칙
- 고리마다 **추적 코드**(F07)를 붙여요. 기록이 남지 않는 고리는 만들지 않아요.
- 결과 카드 등급에 따라 혜택을 다르게 주지 않아요. 할인·쿠폰은 모두 같게 줘요 (`local 리서치/minju_03_온라인콘텐츠.md` 1장 주의 사항).
- 알림 동의·개인정보는 **최소 수집**, 목적·보관 기간 고지, 마케팅 수신 동의 분리 (P0-10, K).

## 3. 에이전트 행동 규칙
- 그해 흐름을 짤 때 **F06 트렌드 조사 결과와 F02 그해 채널별 전략을 먼저 읽어요.** 고리 방식(예: 결과 카드, 챌린지, 인증)은 그해 반응이 큰 형식으로 골라요.
- 홍보안을 쓸 때 모든 콘텐츠·이벤트를 위 6단계 중 하나에 넣고, "다음 단계 CTA"를 반드시 적어요. CTA가 없는 콘텐츠는 검증 단계에서 표시해요.
- 흐름을 짤 때 **상세 담당 파트의 세부 지침이 있으면 먼저 읽고** 그 값(화면 구성, 굿즈 품목, 코스)을 따라요. 없으면 "○ 파트 지침 확인 후 작성"으로 남기고 내용을 지어내지 않아요.
- 고사·변환기의 문항·변환 결과는 F가 만들지 않아요. J·K 몫이에요.
- 시점이 다른 파트 일정(H파트v4 `H03_일정.md` 2-1, 큰 마감은 P0-4 3-1)과 부딪히면 표시하고 담당자에게 물어요.

## 6. 기본 지침과 다른 점
- **고사 시점 불일치:** 기본 지침 v1.1 4-4는 고사·변환기를 "사전: 모집 유도 D-120~D-60", "사전: 방문 유도 D-60~D-1"로 두고, P0-8 2-2는 고사를 D-45~D-7로 적었어요. F03은 두 값을 모두 적고, **모집용(D-120~D-75, 토론 신청 연결)과 방문용(D-60~D-1, 할인 코드 연결)**으로 나누는 안을 제안해요 → 담당자 결정 필요
- 기본 지침 v1.1 4-4 표에는 사전·사후 줄만 보여요. F03은 P0-8의 4·5단계를 현장으로 넣었어요.
