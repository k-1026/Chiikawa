# F04 온라인 콘텐츠 홍보 (E 연계) — 세부 지침

> 구분: 연도별 갱신 · 기본 지침: v1.1 4-2(채널별 콘텐츠 형식), 4-4 · 진행: 초안 · 최종 수정: 2026-11-16

## 1. 이 파트의 역할
- 온라인 콘텐츠 **기획**(무엇을 만들지)은 E 부대 프로그램이 맡아요 (담당자 결정 2026-11-16). 기존 초안은 `참고자료/E_온라인콘텐츠기획_초안.md`로 옮겼어요.
- F04는 **E가 기획한 콘텐츠·프로그램을 가져와 어떻게 홍보할지**를 정해요. 콘텐츠 자체의 기획은 E, 홍보 유형·채널·참여 유도·시점 설계는 F가 맡아요. 그해 "온라인 콘텐츠 홍보 기획"을 만들 때 쓰는 틀이에요.
- 읽는 PART: E(부대 프로그램), F02·F03·F05·F07, J(사투리 검수), K(웹 연결)

## 2. 확정 값

### 2-1. 작업 순서 (그해 기획 때)

```
F06 트렌드 조사 ─→ E 온라인 콘텐츠·부대 프로그램 기획 ─→ F04 홍보 기획 ─→ F05 캘린더에 배치 ─→ F07 지표 연결
       └───────────── 트렌드 결과는 E 기획과 F04 홍보 방식에 모두 쓰임 ─────────────┘
```

- E 기획이 없으면 F04를 쓰지 않아요. "E 기획 확정 후 작성"으로 표시하고 내용을 지어내지 않아요.

### 2-2. 홍보 방식 고르는 기준

E 콘텐츠·프로그램마다 아래 질문으로 홍보 방식을 정해요.

| 질문 | 답에 따라 |
| --- | --- |
| 이 콘텐츠는 **그 자체가 온라인 콘텐츠**인가, **현장 프로그램**인가? | 온라인 콘텐츠(고사·변환기·시리즈) → "참여시키는" 홍보 / 현장 프로그램(체험 부스·퀴즈·게임) → "오게 만드는" 홍보 |
| 어느 단계(F03 1~6)의 사람을 움직이나? | 그 단계를 맡는 채널(F02 2-3)을 주 채널로 |
| 누가 주 타깃인가? (S1~S7, F1·F2) | F01 2-4 타깃별 메시지 강조점을 적용 |
| 현장에서만 할 수 있는 것이 있나? | 있으면 "현장 한정"을 앞세움 (S4·S6가 4단계에서 막히는 이유를 푸는 지점, P0-8 2-3) |
| 사투리가 들어가나? | F01 2-3 범위 + J 검수 |

### 2-3. 홍보 유형

| 홍보 유형 | 언제 쓰나 | 방식 | 주 채널 |
| --- | --- | --- | --- |
| **예고형** | 현장 프로그램을 미리 알릴 때 | 캐릭터가 "이거 하러 와" 하고 맛보기 보여 주기, 시간·장소 카드 | 인스타 릴스·카드뉴스, 쇼츠 |
| **참여 유도형** | 온라인 콘텐츠(고사·변환기·챌린지)에 참여시킬 때 | 결과 공유가 곧 홍보가 되게 설계, 크리에이터가 먼저 참여 | 인스타 스토리, 틱톡, 크리에이터 |
| **현장 한정형** | 현장에서만 받는 경험·굿즈·보상이 있을 때 | "여기서만" 강조, 온라인 참여 → 현장 보상 연결 | 인스타, 틱톡 |
| **안내형** | 가족·여행 계획 단계 사람에게 | 시간표·동선·나이별 추천을 표준어로 정리 | 네이버 블로그, 인스타 하이라이트 |
| **후기·재가공형** | 축제 중·후 | 참여자 인증·결과를 리포스트, 하이라이트로 다시 묶기 | 인스타, 쇼츠 |

### 2-4. 홍보 기획표 양식 (E 콘텐츠·프로그램 1개마다)

| 항목 | 적는 것 |
| --- | --- |
| E 항목 | E 문서의 콘텐츠·프로그램 이름과 번호 (출처 파일·버전) |
| 홍보 유형 | 2-3 중 1개 (보조 1개까지) |
| 주 타깃 | S1~S7, F1·F2 중 1개 |
| 화자 | 공식 / 대키미·외지몽 (F01 2-2) |
| 주 채널 · 재사용 채널 | F02 2-3 |
| 단계 · CTA | F03 단계 번호와 다음 단계 CTA 1개 |
| 그해 트렌드 반영 | F06 결과 중 쓴 것 (없으면 "기본 방식") |
| 홍보 시점 | F05 단계 |
| 사용 사투리 | J 검수 목록 표현 + 표준어 뜻 |
| 측정 지표 | F07 |
| 점검 | F01 3장 점검표 통과 여부 |

## 3. 에이전트 행동 규칙
- 그해 홍보 기획을 쓰기 전에 **E 최신 문서와 F06 트렌드 조사 결과를 먼저 읽어요.** 어느 버전을 읽었는지 기획표 "E 항목" 칸에 적어요.
- E 항목의 내용(문항, 규칙, 보상, 시간)을 F가 바꾸지 않아요. 홍보에 맞지 않는 점이 보이면 "E에 제안"으로 따로 적어요.
- E 항목마다 2-4 양식을 채우고, 메인 타깃(S3·S2·F1·F2)을 겨냥한 홍보가 절반 이상인지 확인해요 `[가설]`.
- 출전자·참여자·시민이 나오는 홍보물은 촬영·활용 동의가 있는지 표시해요 (P0-10).
- 홍보 문안 검수 순서: 에이전트 초안(F01 점검표) → J 사투리 검수 → D01 기준으로 D 담당 캐릭터 확인 → 담당자 승인 → 게시는 사람이 함 (기본 지침 0장).

| F06 트렌드 조사 결과 | 조사 (F06) | 홍보 기획 전 | 2-3 기본 방식 사용 |

| 전년 콘텐츠별 홍보 성과 | 입력 (I, 전년 04) | 기획 시작 | 첫해는 기준선 수집 |

## 5. 다른 파트 연결

| 연결 파트 | 넘겨주는 것 / 받는 것 |

| E 부대 프로그램 | 온라인 콘텐츠·프로그램 기획을 받음 / 홍보에서 본 제안을 넘김 |
