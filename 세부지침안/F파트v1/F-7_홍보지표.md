# F-7 홍보 지표 — 세부 지침

> 구분: 고정(지표 틀) + 연도별(목표치) · 기본 지침: v1.1 11장 (사투리 콘텐츠·온라인 전환 KPI) · 진행: 초안 · 최종 수정: 2026-11-12

## 1. 이 파트의 역할
- 홍보가 **사람을 다음 단계로 보냈는지** 재는 지표와 측정 방법을 정해요. 축제 전에 측정을 준비하게 해요.
- 축제 전체 성과(체류·상권)는 I 파트가 맡아요. F-7은 홍보·온라인 단계 지표만 다루고 I에 넘겨요.
- 읽는 PART: I(성과), K(추적 화면), F-2~F-5, H(측정 인력)

## 2. 확정 값

### 2-1. 단계별 지표 (F-3 6단계)

| 단계 | 핵심 지표 (1개) | 보조 지표 | 측정 방법 | 수집 시점 |
| --- | --- | --- | --- | --- |
| 1. 알아보기 | **팔로워 증가 수** | 조회·도달, 저장·공유, 네이버 검색 지수 | 각 플랫폼 인사이트, 네이버 데이터랩 | 주 1회 |
| 2. 관심·참여 | **고사 결과 공유율** (공유 수 ÷ 응시 수) | 응시 수, 토론 신청 수, 코드 발급 수, 알림 동의율 | 웹 집계(K) + UTM | 주 1회 |
| 3. 체험 | **팝업 인증 수** | 팝업 방문자, 추첨 응모 수, 쿠폰 발급 | 현장 집계, 해시태그 수 | 팝업 종료 후 |
| 4. 이동·방문 | **채널별 코드 사용 수** (온라인 → 현장 전환) | 웹 지도 열람, 길찾기 클릭 | 코드·QR 집계 | 축제 중 매일 |
| 5. 구매·즐기기 | **공식 해시태그 인증 게시물 수** | 라이브 시청, 하이라이트 조회 | 해시태그 검색, 인사이트 | 축제 중 매일 |
| 6. 공유·재방문 | **내년 알림 신청 수** | 사후 온라인 판매, 하이라이트 조회 | 웹 집계, 판매 데이터(D) | D+7, D+30 |

- 조회수보다 **저장·공유와 다음 단계 행동**을 먼저 봐요 (민주 03 3장 측정 원칙).
- SNS 언급량·긍정 비중은 보조 지표로 둬요. `[확인·언론]` 2025 대구치맥페스티벌은 대구시가 SNS 언급 1,616건·긍정 89.3%를 발표했어요 (king R-01). 비교 기준선일 뿐 우리 목표가 아니에요.

### 2-2. 추적 코드 규칙
- 모든 외부 링크에 UTM을 붙여요: `utm_source`=채널(instagram, youtube, tiktok, naver, creator_이름), `utm_medium`=형식(reels, story, shorts, blog), `utm_campaign`=연도_단계(예: 2027_관심).
- 현장 전환은 **채널별 할인 코드·QR**로 재요. 온라인 클릭과 현장 사용을 합쳐 누락을 줄여요 `[해석]` (에이전트 추가 조사, 비공식).
- 링크는 K 웹페이지 한 곳으로 모아요 (F-2 2-2).
- 개인 단위 추적은 하지 않아요. 집계 수치만 써요 (P0-10 개인정보).

### 2-3. 지표 정의표 양식 (I에 넘길 때)

| 지표 | 정의(계산식) | 측정 도구 | 수집 시점 | 담당 | 목표 | 라벨 |
| --- | --- | --- | --- | --- | --- | --- |

- 기본 지침 v1.1 11장 "지표별 정의·측정 방법·수집 시점·담당 주체 명시" 규칙을 따라요.

## 3. 에이전트 행동 규칙
- **첫해는 목표치를 정하지 않고 기준선을 모아요** (P0-8 2-2 "단계별 전환율 목표 없음"). 둘째 해부터 전년 04_운영결과를 기준으로 목표를 제안해요.
- 다른 축제 수치를 목표로 쓰려면 `[추정]`과 계산 근거를 붙여요.
- 측정 준비(UTM·코드·QR·해시태그)는 **D-60 전**에 끝나야 해요. 03 KPI 측정 준비표와 F-5 캘린더가 맞는지 확인해요.
- 측정하지 못한 지표는 "측정 안 됨"으로 적고, 추정값으로 채우지 않아요 (기본 지침 11장).

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| 공식 해시태그 | 입력 (축제 이름 확정 후) | D-120 | 연도_사투리축제 임시 태그 |
| 채널별 코드 발급 가능 여부 | 입력 (K·B·H) | D-90 | UTM 클릭만 측정 |
| 전년 지표 | 입력 (I, 전년 04) | 기획 시작 | "과거 데이터 없음", 기준선 수집 |
| 측정 담당 | 입력 (H) | D-60 | 미정 표시 + 담당자 확인 요청 |

## 5. 다른 파트 연결

| 연결 파트 | 넘겨주는 것 / 받는 것 |
| --- | --- |
| I 성과 | 홍보 지표 정의표·수집 결과 |
| K 웹 | UTM 집계, 고사·알림 집계 |
| D 굿즈 | 사후 온라인 판매 |

| F-8 | 오프라인 수단별 QR·쿠폰 지표 (F-8 2-5) |

## 6. 기본 지침과 다른 점
- 기본 지침 v1.1 11장은 "콘텐츠 조회·공유", "고사·변환기 참여 → 신청 → 방문 전환율"만 적었어요. F-7은 6단계별 핵심 지표 1개와 추적 코드 규칙을 더했어요.
