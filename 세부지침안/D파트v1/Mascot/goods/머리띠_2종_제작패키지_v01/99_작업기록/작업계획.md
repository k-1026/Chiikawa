# 머리띠 2종 제작 계획

2026-11-18 / 사용자의 앞선 디자인 설명 승인에 따라 진행.

승인 범위: 대키미와 외지몽 각각 1종. 캐릭터별 귀 2개와 구슬 안테나 2개. 단모 봉제 소재와 같은 색 원단 밴드. 대키미 하늘색·분홍 삼각 귀, 외지몽 초록색·크림 안쪽의 처진 귀. 얼굴·문구·추가 장식 없음.

1. 기존 캐릭터 기준과 사용자 머리띠 참고 사진 확인.
2. 상품 이미지 생성 시도 및 귀·안테나 개수와 형태 확인.
3. 별도의 설명용 정면·측면·후면 도식 작성. 치수는 승인되지 않은 제안값으로 표시.
4. 디자인 시트와 샘플 제작사양서를 PDF로 작성하고 수정용 원문 저장.
5. 전 페이지 렌더링 및 글꼴·잘림·표·귀 배치 확인.

상품 이미지 생성: 내장 image_gen 도구 사용 시도. usage_limit_reached / HTTP 429로 실패. 상품 사진은 미생성. 외부 API 전환·대체 사진 제작은 하지 않음. 프롬프트만 보관.

정밀 실측, 생산 패턴, 확정 자재, 검증된 공차, 착용 적합성은 이번 승인 범위에 포함되지 않음.
