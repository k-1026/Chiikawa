1. 이 Markdown 디자인 시트와 동봉 PNG를 이미지 생성 도구에 **함께 첨부**한다. 문서의 이미지 링크만으로 사진이 자동 전달된다고 가정하지 않는다.
2. 7장의 공통 지시문에 6장의 원하는 표정별 재현 문장을 더한다.
3. 단독 캐릭터·12종 원페이지·투명 배경 중 용도를 지정한다.
4. 9장의 검수 기준으로 확인한다.

외형·표정·포즈의 시각 기준은 동봉 사진, 안테나와 패드의 개수·재질·허용 변형의 명시적 기준은 이 문서다. 이미지에서 작거나 가려진 요소를 임의의 새 디자인으로 해석하지 않는다. 이 두 자료는 일관된 재현을 돕지만, 생성 모델별 결과 차이나 픽셀 단위 동일성을 보장하지 않는다. 정밀 3D 도면·리깅 데이터·실물 제작 치수표는 아니다.

**사용자 최종 수정 사항:** 놀란 귀는 뿌리만 조금 들리고 크림색 안쪽이 아주 조금 보인다. 서운함의 안테나는 길어지지 않는다. 으르렁 눈은 지나치게 무섭게 찌그러뜨리지 않고 미간 주름을 유지한다. 반가움에 헬리콥터 꼬리 궤적은 사용하지 않는다. 킁킁은 코를 땅 가까이 둔다. 피부에 불규칙한 얼룩·물결형 명암을 만들지 않는다.

## 2. 공통 고정 외형

외지몽은 초록색 강아지형 외계인 마스코트다. 큰 머리와 짧고 통통한 몸, 늘어진 강아지 귀, 별빛 검정 눈, 크림색 주둥이·배·꼬리 끝, 구슬 안테나 두 개가 정체성이다. 전체 키는 기존 성체 설정상 안테나 구슬 최고점부터 발바닥까지 105cm다. 이 원페이지로 새로운 정밀 치수를 역산하지 않는다.

| 부위 | 고정 기준 |
|---|---|
| 머리 | 사진의 둥근 이마·볼·턱선과 정면 폭 유지. 대키미처럼 가로로 넓게 바꾸거나 아기 비율로 머리만 키우지 않는다. |
| 머리·몸 비율 | 큰 머리와 짧고 충분히 넓은 몸통. 목을 길게 드러내거나 허리를 좁히지 않는다. |
| 팔다리 | 짧고 둥근 원래 길이 유지. 손 들기·앉기·놀라기 때문에 길어지지 않는다. |
| 손발 | 둥근 덩어리형. 보이는 자세에서 작은 엄지만 구분 가능. 사람 손가락·발가락 분할·발톱·손톱·신발 밑창 금지. |
| 귀 | 초록 겉면과 크림색 안쪽을 가진 길고 둥근 처진 강아지 귀 두 개. 귀 끝은 무게를 받아 부드럽게 내려온다. |
| 안테나 | 정확히 두 줄기, 각각 끝에 둥근 구슬 하나. 머리에서 이어지는 두 줄기·두 구슬을 각각 확인할 수 있어야 한다. |
| 눈 | 코 쪽 아래가 좁아지는 둥근 삼각형 계열의 큰 검정 광택 눈. 기본 간격과 크기 유지. |
| 코·입 | 둥근 역삼각형의 검정 코와 아래 곡선 입. 크림색 주둥이는 얼굴에 붙은 얕은 볼륨이며 큰 공처럼 돌출되지 않는다. |
| 배 | 중앙에 거의 원형이며 세로로 아주 조금 긴 크림색 무늬 하나. 주변 초록 여백과 사진의 상대 크기 유지. 돌출 배지·봉제 패치 아님. |
| 꼬리 | 몸 뒤 하단에서 나와 바깥·위쪽으로 휘는 통통한 강아지 꼬리. 끝은 둥글고, 길게 말린 고양이 꼬리나 뾰족한 여우 꼬리가 아님. |

원래 깊이를 모르는 정면 사진을 단순히 옆으로 늘여 측면을 만들지 않는다. 새로운 측면을 정밀하게 만들 때는 기존 프로젝트의 승인 측면 자료를 추가로 참고할 수 있으나, 이 시트의 표정 재현을 위해 별도 자료가 반드시 필요한 구성은 아니다.

### 눈 하이라이트와 입 표현

- 완전히 뜬 눈 하나당 큰 밝은 네 갈래 별 1개, 작은 회색 반짝임 1개, 아주 작은 회백색 반짝임 1개로 총 3개다.
- 감거나 반쯤 감은 눈에서는 눈꺼풀에 가려지는 만큼 하이라이트도 가려진다. 감은 곡선 위에 별을 얹지 않는다.
- 눈꺼풀은 얼굴에 통합된 부드러운 곡면으로 표현한다. 날카로운 검정 조각, 과하게 두꺼운 눈썹, 속눈썹·아이라인을 새로 만들지 않는다.
- 혀는 작고 분홍색이다. 웃음에 자연스럽게 보일 수 있으나 길게 늘어진 사람 혀나 과도한 침 표현은 없다.
- 으르렁에만 작은 윗송곳니 두 개를 허용한다. 다른 표정에 이빨을 추가하지 않는다.
- 기본 홍조는 없다. 기존 사진에 없는 영구 볼 무늬·반점은 넣지 않는다.

**표면 금지 항목:** 이마·볼·귀·배·팔다리·구슬 안의 얼룩, 구름 무늬, 대리석 무늬, 물결형 반사, 물 반사무늬, 밝은 띠·반점, 잔굴곡, 거친 점토 입자, 비닐 광택. 사진에 남은 작은 생성 오차를 고유 무늬로 복사하지 않는다.

표면을 정리하더라도 3D 입체감은 유지한다. 크림색 주둥이·배·패드는 의도된 색 영역이므로 얼룩으로 보고 지우지 않는다. 으르렁의 짧은 미간 주름은 의도된 표정 굴곡이며, 다른 이마 전체에 번지는 물결 명암과 구분한다.

꼬리는 초록색에서 길고 부드러운 그라데이션을 거쳐 **작은 크림색 끝 영역**으로 이어진다. 흰 캡·강한 경계선·줄무늬·큰 흰 덩어리를 만들지 않는다. 기본 꼬리는 매끈하며, 으르렁 표정에서만 절제된 털 갈래가 허용된다.

## 4. 젤리패드 — 대키미와 혼동 금지

양손 손바닥과 양발 발바닥 네 곳에 각각 **큰 패드 1개 + 작은 패드 3개**, 총 4개 요소가 있다. 외지몽 패드는 크림색이며, 대키미의 분홍색·작은 패드 4개 구성을 가져오지 않는다.

- 큰 패드: 말랑한 둥근 삼각형 계열, 아래 중앙에 얕은 굴곡. 작은 패드: 가운데가 조금 높고 양옆이 낮은 타원 3개.
- 패드 전체 묶음 폭은 표면을 정면으로 볼 때 손바닥·발바닥 폭의 약 55%를 기준으로 하며, 사진의 시각적 규모와 원근을 함께 따른다.
- 패드는 매우 얕고 주변에 초록 여백이 남는다. 두꺼운 젤리·스티커 테두리·흰 털·봉제선·별도 손목 패드 없음.
- 손발과 함께 회전·압축 투영·가림이 일어난다. 가려진 요소를 꺼내 개수를 맞추거나 손등·발등으로 옮기지 않는다.
- 패드를 보여주기 위해 손발을 키우거나 몸을 좁히지 않는다. 앉거나 발라당해도 원래의 몸통 폭과 짧은 손발 비율을 유지한다.

## 6. 표정·자세 개별 상세 시트

### 01. 기본 미소

- **의도:** 처음 보는 사람에게도 편안한 외지몽의 대표 기본형. 안내·소개 이미지의 기준이다.
- **눈·입:** 양쪽 눈을 기본 크기로 열어 별빛을 보인다. 크림색 주둥이 안의 입을 작게 열고 작은 혀가 보이는 밝은 미소. 과도한 입 벌림이나 웃음 주름 없음.
- **귀·안테나:** 귀는 양옆으로 자연스럽게 처진다. 안테나는 기본 길이와 간격으로 선다.
- **몸·손발:** 두 발로 편안히 정면 서기, 어깨에 힘을 빼고 손을 옆으로 내린다. 손등·발등만 보이면 패드가 안 보여도 정상이다.
- **꼬리·효과:** 기본 곡률로 위로 부드럽게 휜 꼬리. 별도 효과 없음.
- **재현 문장:** `사진 1행 1열의 기본 미소. 정면 두 발 서기, 양손 내림, 기본 별빛 눈 두 개, 작은 혀가 보이는 부드러운 강아지 미소, 자연스럽게 늘어진 귀와 기본 안테나 두 개, 기본 둥근 꼬리. 부가 효과 없이 친근한 기본형.`

### 02. 활짝 웃음

- **의도:** 즐거움·환영·축하에 쓰는 확실한 웃음. 기본 미소와 눈 개폐·손동작으로 구분한다.
- **눈·입:** 양쪽 눈을 둥근 곡선으로 감고 입을 기쁘게 연다. 작은 혀가 보이되 입이 얼굴을 압도하지 않는다. 감은 눈에 별을 넣지 않는다.
- **귀·안테나:** 귀는 가볍게 들썩이지만 끝이 둥글고 처진 구조 유지. 안테나 줄기와 구슬은 정확히 두 개씩.
- **몸·손발:** 두 발로 서서 양팔을 볼 아래 높이까지 들고 손바닥을 앞쪽으로 향한다. 노출 패드 구성 확인.
- **꼬리·효과:** 꼬리는 가볍게 흔들고 얼굴 양옆에 작은 직선 환호 표시 허용. 피부 속 반사무늬로 기쁨을 표현하지 않는다.
- **재현 문장:** `사진 1행 2열의 활짝 웃음. 양쪽 눈은 부드러운 감은 곡선, 작고 즐겁게 열린 입과 혀, 양팔을 들어 크림색 손바닥 패드 표시, 원래 짧은 다리로 서기. 귀는 부드럽게 들썩이고 꼬리를 가볍게 흔든다.`

### 03. 깜짝 놀람

- **의도:** 순간적으로 움찔 놀라는 반응. 놀란 귀를 자연스럽게 재현하는 것이 핵심이다.
- **눈·입:** 양쪽 별빛 눈을 크게 뜨고 주둥이 안에 작은 O자 입. 눈 크기나 간격을 과장해 바꾸지 않는다.
- **귀:** **뿌리만 조금 위·바깥쪽으로 들리고, 둥근 귀 끝은 아래로 처진다.** 살짝 회전한 귀의 안쪽 아래 가장자리에 크림색이 가늘게 보인다. 대부분은 초록 겉면이다. 토끼 귀처럼 세우거나 안쪽 전체를 하늘로 뒤집지 않는다.
- **안테나:** 귀와 별개인 기본 짧은 안테나 두 개 유지. 귀를 새 안테나처럼 만들지 않는다.
- **몸·손발:** 상체가 약간 뒤로 기울고 양손을 든다. 사진의 한 발이 살짝 들린 움찔 동작을 따른다. 다리 길이·발 크기를 늘이지 않는다.
- **꼬리·효과:** 기본 매끈한 꼬리와 작은 느낌표 하나. 털 세움 없음.

뜬 눈은 코 쪽 아래가 좁아지는 둥근 삼각형 검정 광택 눈이다. 각 눈에 큰 네 갈래 별 하나와 작은 반짝임 두 개를 유지한다. 감은 눈은 부드러운 곡선이며 별은 눈꺼풀에 가려진다. 검정 칼날 눈·과도한 눈썹·속눈썹·아이라인을 만들지 않는다. 검정 코와 작은 강아지 입을 유지하고 혀는 작게 표현한다. 송곳니는 으르렁 표정에만 작은 두 개를 허용한다.

## 8. 출력 용도와 재현 작업 순서

### 단독 표정 이미지

선택한 표정만 크게 만들고 머리·귀·안테나 구슬·손발·꼬리를 모두 포함하는 여백을 둔다. 다른 칸이나 원페이지 제목을 재생성하지 않는다. 얼굴·재질·패드를 큰 이미지에서 확인한 뒤 다른 표정을 생성한다.

### 12종 원페이지

5장의 순서로 4열×3행 배치한다. 제목은 ‘외지몽 시그니처 표정·자세’. 이름은 표의 표기대로 정확하게 쓴다. 새 SAMPLE 번호·새 이름은 요청할 때만 넣는다. 사진 안 SAMPLE 05를 모든 새 결과에 의무적으로 복사하지 않는다.
