대키미·외지몽 수면안대 제작 패키지 V09

시작: 패키지_시작.html

캐릭터별 폴더의 상품이미지 PNG + 제작사양서 HTML + 디자인시트 PNG를 AI에 함께 첨부하세요. SVG를 지원하면 정면 배치 도안과 레터링 선도안도 함께 넣으세요. AI재현프롬프트 TXT를 지시문으로 사용하세요.

확정된 시각 방향: 이목구비 없음 / 대키미 분홍 잠와 / 외지몽 크림 졸려.

치수·자재·봉제 수치는 1차 샘플 설계 제안입니다. 실제 측정치·양산 승인 패턴·자수 펀칭 파일이 아닙니다. 1:1 SVG는 완성선으로 시접이 없습니다.

레터링 SVG는 설치 폰트에 의존하지 않는 둥근 획 선도안입니다. 원래 폰트 파일이나 실제 자수 외곽의 자동 트레이싱은 아닙니다. 자수 펀칭은 샘플 업체에서 실물 테스트 후 확정하세요.

생성형 AI에서 완전히 같은 픽셀 이미지를 보장할 수는 없습니다. 정확한 글자 획은 도안 재사용과 국소 편집으로 고정하세요.

상품 사진: OpenAI 내장 이미지 생성 도구 사용. 사진이 원단 물성이나 차광 시험 통과를 증명하지 않습니다.
