### 문구 기록 (D-1 2-4절 양식)

**사투리 문구는 한 곳에서만 정한다.** 키링 시트의 문구(COPY-KEY-NNN)와 마그넷 시트의 외지몽 표준어 반응(COPY-MAG-NNN)은 ID를 그대로 가져온다. 에코백에서만 쓰는 새 문구는 만들지 않았다. **아래 문구는 전부 작성자 제안이고, 뜻풀이는 AI의 일반 지식에 기반한 것이다.** 대구 지역 담당자의 확인(J-3)과 표기 확인(J-2) 전에는 확정으로 쓰지 않는다. 사투리가 맞다고 단정하지 않는다.

## 4. 면·그래픽 배치

에코백은 앞·뒤·측면이 서로 다른 면이라 **시점별로 적는다.** 한 시점으로 모든 면을 검증하지 않는다.

| 시점 | 들어가는 그래픽 | 로고 노출 | 비고 |
|---|---|---|---|
| **앞면** | 캐릭터(단독 또는 듀오) + 문구 + 작은 뜻풀이 | 아니오 | 글자는 후편집으로 합성 (D-1 2-4절). 큰 면적이라 전신 사용 가능 (외지몽은 미정 7) |
| 뒷면 | 단색 또는 작은 로고 한 개 | **예 (제안, 미정 6)** | 승인 로고 구조 보존. 양면 인쇄 여부는 미정 3 |
| 측면·바닥 | 무늬 없음 | 아니오 | 바닥 폭(거셋) 유무는 업체 확인 |
| 평면 전개 | 가방 본체 + 손잡이 모양을 펼친 도식 | 아니오 | 치수 표시용 |
| 착용·들기 도식 | 마네킹 토르소 또는 걸이에 걸린 모습 (**사람 얼굴 생성 안 함**) | 아니오 | 손잡이 길이와 가방 위치만 보여 줌 |
| **라벨·행택·포장 카드** | 상품명, "대구 얼라들" 로고, 문구 뜻풀이, 세탁·취급 안내, 캐릭터 간단 소개 | **예** | 담당자 결정: **카드는 표준어로 표기**. 세탁 안내는 업체 확인 내용만 적음 |

- 얼굴형(귀·더듬이·눈 포함)과 상반신·전신 그래픽을 구분해 적는다.

**비교 시안 (샘플 이미지는 나중에 만든다. 여기서는 내용만 정의한다)**

| 안 | 방향 | 내용 | 확인할 점 |
|---|---|---|---|
| A | 캐릭터 단독 | **가방 앞면 중앙에 캐릭터 상반신 + 문구 한 줄** (대키미 `마이 무라`) | 큰 면적에서 캐릭터가 균형 있게 놓이는지, 문구 크기 |
| B | 듀오(대화) | **대키미 `정구지 = 부추` + 외지몽 `부추…?`** 가 위아래로 이어짐 | 두 캐릭터 구분, 읽는 순서, 가방 접힘선과 겹치지 않는지 |
| C | 문구 중심 | **큰 글자 문구 + 작은 캐릭터**, 캐릭터는 글자 옆 포인트 | 사투리 글자가 먼저 읽히는지, 캐릭터 존재감이 약해지지 않는지 |

- 비교안은 **방향(캐릭터 중심/듀오/문구 중심) 한 요소만 바꿔** 비교한다 (D-3 2-6절). 선택은 사람이 한다 (미정 2).
- 같은 방향 안에서 대키미와 외지몽 버전을 각각 만든다.

## 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다. 공통 지침서 v01은 "원단, 가방·손잡이 치수, 양면/단면 인쇄"를 정할 항목으로만 두었고 값은 없다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |

| 손잡이 폭 | 약 25~35 mm | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |

| 원단 중량 | 약 280~340 g/㎡ (약 8~10 oz) | 업체 확인 필요값 | 작성자 제안. 업체 확인 필요 |
| 원단 색 | 생지(아이보리 계열) 또는 흰색 | 디자인 제안값 | 대표색(하늘색·초록)이 잘 읽히는 밝은 바탕. 미정 2 |
| 인쇄 방식 | 실크스크린 / 전사 / 디지털 직접 인쇄 후보 | 업체 확인 필요값 | 색 재현·세탁 후 상태 확인. 방식 선택은 업체 견적 후 |

| 인쇄 영역 | 앞면 중앙 가로 약 250~300 mm 이내 | 디자인 제안값 | 작성자 제안. 업체 템플릿 필요 |

| 내하중 | 확인 필요 | 업체 확인 필요값 | 이미지로 판정 불가. 업체 자료와 실물 확인. 임의 수치를 쓰지 않음 |
| 색 재현 | 하늘색 #6DCFF5, 초록 #008C3A | 업체 확인 필요값 | 생지 위에서 대표색이 다르게 보일 수 있음. 샘플 색 확인 |
| 안전 기준 | **운영 파트의 안전 기준을 따른다** (이 시트가 정하지 않음) | 확정(연결 방식) | 담당자 결정. 염료·원단 관련 기준과 해당 파트 번호는 확인 필요 `[가설]` |

- 근거 없이 "생산 가능"이라고 쓰지 않는다. 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 캐릭터 세계관상의 키를 굿즈 크기로 가져오지 않는다 (D-3 2-3절).
- 이미지로 내하중·내구성·세탁 후 상태·소재 성능을 인증했다고 쓰지 않는다 (D-3 2-10절).

## 6. 작업 카드 (이미지 생성 전에 채움)

샘플 이미지는 나중에 따로 넣는다. 아래 카드는 **그때 바로 쓸 수 있게 미리 채운 것**이다. 대키미 A안을 기준으로 하고, 나머지는 바뀌는 항목만 적는다.

```yaml
작업_ID: D-03-05_v01_A
생성도구: ChatGPT
첨부한_참조파일: 대키미_캐릭터_원본설정보드.png (위 2장 경로)
품목: 에코백 · 대키미 단독 · 앞면 중앙 상반신 + 문구
목적: 상품_샘플이미지
상태: 검토용_시안
선택_캐릭터버전: 성체
캐릭터_기준파일: 대키미_캐릭터_원본설정보드.png
로고_기준파일: 앞면_미노출 (뒷면 로고는 별도 컷, 승인 로고 PNG)
기존상품_참고파일: 없음
참고역할: 캐릭터정체성=원본설정보드
문구_원문과줄바꿈: COPY-KEY-010 "마이 무라" + 작은 뜻풀이 "많이 먹어라" (제안, 글자는 후편집 합성)
규격: 본체 가로 약 350~380 mm × 세로 약 380~420 mm, 손잡이 약 550~650 mm (디자인 제안값)
재질과공법: 면 캔버스, 인쇄 방식 확인 필요 (업체 확인 필요값)
필수_시점: 앞면, 뒷면, 평면 전개, 걸이 도식
고정할것: 성체 대키미의 종·귀·더듬이 2개·눈·하늘색 입 주변·대표색
이번에_바꿀것: 캐릭터 단독 방향 (비교안 A)
출력_파일명: D-03-05_에코백_대키미_성체_A_v01_앞면.png
미정사항: 원단·인쇄 방식·손잡이·내하중은 업체 확인 필요
```

| 작업 ID | 바뀌는 항목 |
|---|---|
| D-03-05_v01_A2 | 외지몽 단독. 참조: 외지몽 원본설정보드 (+ 승인정면 v04). 문구 COPY-MAG-001 `…뭐라고?`. 주둥이 크림빛 |
| D-03-05_v01_B | 듀오. 대키미 `정구지 = 부추` (COPY-KEY-004) + 외지몽 `부추…?` (COPY-MAG-002). 두 캐릭터 참조 모두 첨부. 출력 파일명 `…_듀오_성체_B_v01_앞면.png` |
| D-03-05_v01_C | 문구 중심. 큰 글자 문구 + 작은 캐릭터 (대키미 `마이 무라` 또는 키링 후보 풀 문구). 출력 파일명 `…_대키미_성체_C_v01_앞면.png` |
| D-03-05_v01_L | 뒷면 로고 컷. 로고 기준: 승인 로고 PNG 첨부. 로고 구조를 바꾸지 않고 작게 한 개만. 출력 파일명 `…_뒷면.png` |

- 시점별로 별도 컷을 만든다 (앞면·뒷면·평면 전개·걸이 도식). 한 장으로 구조 전체를 검증하지 않는다.
- 첨부 없이 문자 설명만으로는 같은 캐릭터를 보장할 수 없다. 참조 이미지는 반드시 첨부한다 (D-3 2-4절). 듀오는 두 캐릭터 보드를 모두 첨부한다.

- **생성 프롬프트:** [D-03 공통 생성 프롬프트](../D-03_품목별수치.md)(2-5절) + 위 작업 카드를 붙여 쓴다. 이 품목에서만 추가하는 문장:

  - `가방 전체 외형(본체와 손잡이)을 자르지 않고 보여 준다. 걸이에 걸리거나 평평하게 놓인 모습만 쓰고, 사람 얼굴이나 사람 모델은 넣지 않는다.`
  - `문구는 아래 원문을 한 글자도 바꾸지 않고, 큰 글자와 작은 뜻풀이로 나눠 배치한다. 글자가 깨지면 실패로 본다. 최종 글자는 후편집으로 합성한다.`
  - `앞면에는 로고를 넣지 않는다. 로고는 뒷면 컷에서만 승인 PNG 구조 그대로 작게 한 개 넣는다.`
