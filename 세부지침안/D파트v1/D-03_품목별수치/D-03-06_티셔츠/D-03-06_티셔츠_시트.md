## 0. 이전 버전과 달라진 점

- 첫 버전이에요. **기존 시안에서 추가 개발하는 품목**이라, 기존 시안을 그대로 다시 출력해 완료 처리하지 않아요 (D-3 2-9절).
- 기존 시안 두 개를 열어서 확인했어요: 대구토박이 티셔츠(대키미) 원페이지 v01, 외지인 티셔츠(외지몽) 원페이지 v03. 흰 티셔츠, 앞면 큰 글자 + 왼쪽 가슴(착용자 기준) 작은 머리 그래픽, 뒷면 문구 블록 구성이에요.
- **기존 문구는 원문 그대로 보존**하고, 고친 문구는 따로 적어요 (공통 지침서 v01은 "변경 내역 없이 교정·축약"을 금지). 비교안 A·B·C는 작성자 제안이며 **어느 안도 선택되지 않았어요.**
- 이미 정해진 공통 결정을 가져왔어요 (2026-11-17, 담당자): **성체 기준 · 모든 굿즈가 매년 달라짐 · 로고는 라벨이나 포장에 노출 · 포장 카드는 표준어 표기 · 안전 기준은 운영 파트 기준으로 연결 · 판매 위치는 상점 운영안을 본 뒤 결정 · 온라인 판매는 보류 · 일정은 축제 담당자가 매년 결정(D는 후보안까지)**.
- 담당자 요청(2026-11-17)에 따라 **사투리 밈·유머 후보 풀**을 따로 만들었어요 ([부록](../_사투리_밈유머_후보.md)). 이 시트의 신규 문구(비교안 C)는 거기서 가져왔어요.
- 크기·원단·핏·인쇄 방식은 **전부 작성자 제안이나 업체 확인 필요값**이에요.

### 문구 기록 (D-1 2-4절 양식)

**사투리 문구는 한 곳에서만 정한다.** 키링·스티커 등에서 쓴 문구는 ID를 가져오고, [밈·유머 후보 풀](../_사투리_밈유머_후보.md)의 문구는 `COPY-MEME-NNN`, 티셔츠 전용 문구는 `COPY-TEE-NNN`으로 적는다. **아래 문구는 전부 `제안`이다.** 기존 시안 문구도 "기존 시안 원문(승인 전)"일 뿐 확정이 아니다. 사투리처럼 읽히는 말("물어보이소", "가드립니다")은 대구 지역 담당자 확인(J-3) 전에는 확정으로 쓰지 않는다. 사투리가 맞다고 단정하지 않는다.

- 공통 금지는 D-1 3-2절을 따른다.
- 산·더위 소재는 보조 요소로 제한한다 (D-1 2-3절). 티셔츠에는 쓰지 않는다.
- **외지인 티셔츠의 "길을 잃은거니 도와주세요" 같은 문장은 관광객에 대한 놀림이 아니라 도움을 청하는 말인지**를 확인한다 (D-1 3-2절). 현재 원문은 외지몽이 자신을 낮추는 유머이므로 통과 후보로 보되 J-3 어감 점검 대상이다.

## 4. 면·그래픽 배치

티셔츠는 **착용자 왼쪽**과 **보는 사람 오른쪽**을 구분해 적는다 (D-3 2-9절). 앞면과 뒷면은 별도 컷으로 만든다.

| 면 | 들어가는 그래픽 | 로고 노출 | 비고 |
|---|---|---|---|
| **앞면** | 큰 한 줄 문구(대구토박이 / 외지인) + **착용자 왼쪽 가슴**(보는 사람 오른쪽)에 작은 머리 그래픽 | 아니오 | 얼굴형(머리만). 전신 그래픽 아님 |
| **뒷면** | 문구 블록(원문 보존본·개선안·신규 중 선택) | 아니오 | 위쪽~중간 등판 중앙. 3블록: 첫 문장 가장 크게 |
| 소매·옆선 | 무늬 없음 | 아니오 | |
| 목 안쪽 라벨 | 로고, 사이즈, 세탁 안내 | **예** | 라벨 방식(직물/인쇄)은 업체 확인 (미정 8) |
| **행택·포장 카드** | 상품명, "대구 얼라들" 로고, 두 캐릭터와 짝 소개, 문구 뜻풀이 | **예** | 담당자 결정: **카드는 표준어로 표기** |

- 문구 위치는 기존 시안의 값을 출발점으로 삼고 **한두 요소만 바꿔** 비교한다.

**비교 시안 (샘플 이미지는 나중에 만든다. 여기서는 내용만 정의한다)** — 작성자 제안, 어느 안도 선택되지 않음

| 안 | 이름 | 내용 | 확인할 점 |
|---|---|---|---|
| A | **기존안 보정** | 문구는 **원문 보존본(COPY-TEE-001~004)** 또는 띄어쓰기 개선안(004a) 중 선택. 글자 크기·행간·**대비**를 보정. 앞면 구성은 기존과 같음 | 하늘색이 흰 바탕에서 읽히는지 (아래 5장 대비 계산). 문구 줄바꿈이 원문과 같은지 |
| B | **일상 사용 중심** | 앞면은 **작은 머리 그래픽만 (또는 작은 한 줄 문구)**, 뒷면은 **한 문장으로 축약** (예: "화난 거 아닙니다...", "지금 사투리 해석 중입니다..."). **문구 축약은 별도 제안이며 원문은 보존** | 축약해도 뜻과 웃음이 남는지. 길에서 부담 없이 입을 수 있는지 |
| C | **사투리 관계 중심** | 두 티셔츠의 뒷면이 **서로 대화가 되도록** 구성 (COPY-TEE-005 ↔ COPY-TEE-006). 앞면은 기존과 같음 | 한 사람이 입었을 때도 말이 되는지, 짝이 만나면 웃음이 커지는지. 사투리 뜻은 J-3 |

- 같은 안 안에서 대구토박이(대키미)와 외지인(외지몽) 버전을 각각 만든다.
- 비교안은 문구 구성·그래픽 크기 같은 **한두 요소만 바꿔** 비교한다 (D-3 2-6절). 선택은 사람이 한다 (미정 2).

## 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다. 공통 지침서 v01은 "그래픽·문구 크기, 위치, 핏, 사이즈, 공법"을 정할 항목으로만 두었고 값은 없다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |
|---|---|---|---|
| 품목 방향 | 대구토박이 / 외지인 관계를 살린 티셔츠 | **확정** | 공통 지침서 v01 / 담당자 결정 |
| 바탕색 | 흰색 | 디자인 제안값 | 기존 시안 방향 (흰 바탕). 새 색 제안은 별도 |
| 인쇄색 | 대키미 하늘색 #6DCFF5 / 외지몽 초록 #008C3A | 확정(방향) / 업체 확인 필요(재현) | 보드 표기와 일치. 천 위 재현은 업체 샘플 확인 |
| 인쇄색 대비 (흰 바탕) | 하늘색 약 **1.8 : 1**, 초록 약 **4.4 : 1** | 작성자 계산 `[추정]` | WCAG 상대 휘도 공식, 흰색 #FFFFFF 기준. 일반적으로 큰 글자에도 3 : 1 이상을 권장하는데 하늘색은 **미달**. 작은 뒷면 문구에서 특히 흐릿해질 수 있어 비교안 A에서 점검 |
| 짙은 톤 대체안 | 하늘색의 짙은 톤 또는 짙은 외곽선 | 디자인 제안값 (**대표색 변경이므로 담당자 승인 필요**) | 읽힘 때문에 제안. 대표색 자체를 임의로 바꾸지 않는다 (D-1 2-3절) |
| 원단 | 면 100% 계열 (제안) | 업체 확인 필요값 | 업체 확인 필요 |
| 원단 중량 | 약 160~200 g/㎡ | 업체 확인 필요값 | 작성자 제안. 업체 확인 필요 |
| 핏 | 남녀공용 레귤러 또는 약간 여유 있는 핏 | 업체 확인 필요값 | 실제 사이즈표는 업체에서 받는다 |
| 사이즈 | S·M·L·XL | 업체 확인 필요값 | 사이즈별 치수표(가슴·총장·어깨)는 업체 확인. 사이즈에 따라 그래픽 크기를 같게 둘지는 미정 6 |
| 앞면 문구 크기 | 가슴 폭의 약 75% (기존 시안 프롬프트 값) | 디자인 제안값 | 기존 시안 값 `[확인]`. 실제 mm는 업체 템플릿 후 |
| 가슴 머리 그래픽 | 가로 약 40 mm (착용자 왼쪽) | 디자인 제안값 | 기존 시안 프롬프트의 "약 4 cm" `[확인]`. 외지인은 더 작게 (기존 55% 축소) |
| 뒷면 문구 블록 | 폭 약 250~300 mm, 등판 위~중간 | 디자인 제안값 | 작성자 제안. 업체 템플릿 필요 |
| 인쇄 공법 | 실크스크린 / 전사 / 디지털 직접 인쇄 후보 | 업체 확인 필요값 | 색 재현·세탁 후 상태·소량 단가 확인 (기존 시안은 실크스크린 느낌으로 묘사) |
| 봉제 | 확인 필요 | 업체 확인 필요값 | 목 라벨 위치·방식 포함 |
| 안전 기준 | **운영 파트의 안전 기준을 따른다** (이 시트가 정하지 않음) | 확정(연결 방식) | 담당자 결정. 원단·염료 관련 기준과 해당 파트 번호는 확인 필요 `[가설]` |
| 포장 | 접어서 개별 포장 + 행택, 카드는 표준어 | 확정(방향) / 제안(형태) | 담당자 결정. 카드 크기·방식은 업체·F와 협의 |

- 근거 없이 "생산 가능"이라고 쓰지 않는다. 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 캐릭터 세계관상의 키를 굿즈 크기로 가져오지 않는다 (D-3 2-3절).
- 이미지로 핏·세탁 후 상태·소재 성능을 인증했다고 쓰지 않는다 (D-3 2-10절).

- **생성 프롬프트:** [D-03 공통 생성 프롬프트](../D-03_품목별수치.md)(2-5절) + 위 작업 카드를 붙여 쓴다. 이 품목에서만 추가하는 문장:
  - `흰 면 티셔츠 상품의 샘플 컷이다. 앞면과 뒷면을 각각 따로 만든다. 그래픽은 천 위에 인쇄된 평면 그래픽이며 자수나 패치가 아니다.`
  - `앞면의 작은 머리 그래픽은 착용자의 왼쪽 가슴(보는 사람 기준 오른쪽)에 둔다. 머리 부분만 쓰고 몸은 그리지 않는다.`
