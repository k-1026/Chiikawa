## 1. 이 파트의 역할

현장 굿즈샵·이벤트 부스 운영은 E가 맡는다. D는 굿즈 품목·로고·가격·라인업과 제작·검수를 맡는다. 아래 현장 운영·판매 기록은 E가 적용하고 D에 인계한다.

- 현장에서 굿즈를 **어떻게 팔고, 어떻게 세고, 어떻게 기록하는지** 정해요.
- 굿즈 **재고를 어떻게 보관하고, 남은 재고를 어떻게 처리하는지**(폐기하지 않고 기부, 폐기는 불량·검수 불통과품만)도 정해요 (2-7절). 남은 굿즈 처리 원본은 H07 2-7이에요.
- 이 파트의 기록이 **다음 해 발주 수량(D04 2-3절)의 유일한 근거**예요. 첫 해에는 과거 자료가 없어서, 올해 기록이 곧 기준선이에요.
- 상점 **위치**는 Y지도, **운영 시간**은 P0-4가 원본이에요. 여기서는 링크로만 가리켜요.
- 판매 채널(현장 외 온라인 등)은 D06, KPI 정의는 I-1이에요.

## 2. 확정 값

### 2-1. 위치와 운영 시간 (원본은 다른 파트)

| 항목 | 값 | 원본 | 상태 |
|---|---|---|---|
| 상점 위치 | 전체 지도 (4) 굿즈샵·이벤트 부스. 코오롱야외음악당 동쪽 길과 원형 광장 옆 길의 평탄한 구간 | Y 축제 전체 지도 3장 (4) | Y 지도 기준 |
| 개장 | 매일 12:00 | P0-4 2-2 | 확정 |
| 폐막 | 금·토 22:00 / 일 20:00 | P0-4 2-2 | 확정 |
| 상점 운영 시간 | 개장~폐막에 맞추는 것을 제안 | P0-4 (상점 값은 따로 없음) | 제안, 미확정 |

- 상점 위치는 D가 정하지 않는다. **Y지도를 읽어 그대로 옮긴다.** Y지도가 바뀌면 Y지도를 따른다. Y지도를 읽을 수 없으면 위치를 지어내지 않고 "확인 불가 — Y지도 없음"으로 두고 담당자에게 묻는다.
- 상점 면적·진열 가능 범위는 Y지도·P0-3에 값이 없으면 `확인 필요`로 둔다.
- 모든 프로그램과 부스는 그날 폐막 시각에 끝난다 (P0-4 2-2). 상점 마감 후 정산·재고 확인 시간은 인력(H02)과 함께 정한다.

### 2-3. 일일 기록 (필수)

상점은 영업일마다 아래를 **SKU별로** 기록한다. 이 기록이 D04 2-3절 발주 수량 예측과 I-1 KPI의 원본이다.

| 기록 | 뜻 | 비고 |
|---|---|---|
| 판매 가능 입고 수량 | 불량 제외한 누적 입고 수량 | 추가 입고는 별도 줄로 기록 |
| 판매 수량 | 판매 건수 합 | |
| 취소·반품 | 차감 항목 | **순판매 수량 = 판매 수량 − 취소·반품** |
| 할인 반영 | 할인 적용 시 기준을 명시 | 순매출 계산용 |
| 불량·분실 | 판매 불가 수량 | 사유 함께 |
| 무상 지급 | 행사·홍보용으로 준 수량 | 판매 수량과 구분 |
| 보관(기록용) | 폐막 후에도 남겨 두는 기록용 샘플 수량 | 판매 가능 입고 수량에서 미리 뺌 (2-7절 B) |
| **교환 지급** | 스탬프 교환용으로 운영·안전 부스에 넘긴 수량 | 판매 수량과 **구분** (D02 2-4절, H10) |
| **도장 지급** | 굿즈 상점에서 찍어 준 스탬프 수 (구매 1건당 1개) | H10 2-6 기록(묶음별 도장 분포) |
| 마감 재고 | 실재고 (장부가 아니라 실사) | |
| **품절 시각** | SKU가 0이 된 시각 | 품절로 판매가 멈춘 것과 선호가 낮은 것을 구분하는 근거 |

- **판매율 = 순판매 수량 ÷ 판매 가능 누적 입고 수량 × 100.** 분모가 0이거나 `미수집`이면 산출하지 않는다 (공통 지침서 v01 12절, KPI 정의 원본은 I-1).
- 첫 해 자료 없음은 판매 0건이나 낮은 선호가 아니다. 값은 `미수집`으로 둔다.
- 전체 방문객 수만으로 굿즈 구매 전환율을 단정하지 않는다. 굿즈 상점 방문 수와 구매 건수가 **둘 다 집계된 경우에만** 그 정의로 계산한다.
- 추정으로 채우지 않는다. 기록하지 못한 칸은 `미수집`으로 두고 사유를 적는다.

### 2-5. 스탬프 — 굿즈 상점 도장과 교환용 굿즈 (원본 H10)

스탬프 운영 원본은 **H10**이다 (원본지정표 13행 확정, H10 담당자 결정 2026-11-18). D02 2-4절을 함께 본다.

| 항목 | 값 | 원본 |
|---|---|---|
| 굿즈 상점 도장 | 굿즈를 **1번 사면 1개** (묶음 ③ 굿즈 상점). 계산대가 여럿이면 계산대 수만큼 도장을 둔다 | H10 2-2·2-3 |
| 교환 장소 | **운영·안전 부스** (굿즈 상점이 아님) | H10 2-5·2-6 |
| 완성 기준 | 8칸 중 5개 이상 | H10 2-1 |
| 선착순 상품 | 하루 손선풍기(캐릭터) 50·부채 200, 3일 합계 150·600. **D가 제작**, D01 검수 | H10 2-5 |

- **D (상점):** 구매 1건마다 도장 1개를 찍고 **일일 기록에 도장 지급 수**를 적는다. 교환용 굿즈(손선풍기·부채)는 판매 재고와 따로 보관하고, 운영·안전 부스로 넘긴 수량을 기록한다.
- 도장 지급 기준·교환 기준·교환 장소는 H10 값을 그대로 쓴다. 상점이 현장에서 바꾸지 않는다. H10에 값이 없거나 바뀌었으면 "H10 확인 필요"로 두고 멈춘다.

### 2-6. 실물·검수 확인

- 입고 시 불량은 판매 가능 입고 수량에서 제외하고 사유를 기록한다 (D04 2-5절).
- 상품 성능(내열·누수·인체 적합성 등)은 상점에서 안내하거나 광고하지 않는다. 업체 확인 자료가 있을 때만 그 범위 안에서 안내한다 (D03 2-10절).

### 2-7. 재고 보관과 잔여 재고 처리 (담당자 결정 2026-11-18, 원본 H07 2-7)

> 남은 굿즈 처리의 원본은 **H07 2-7**이다. 이 절은 D가 할 일(실사·분류·기록·후보안)만 적는다. 둘이 다르면 H07을 따르고 멈춰서 담당자에게 알린다.

**결정 요약**

| 항목 | 결정 | 상태 |
|---|---|---|
| 재고 보관 장소 | **축제 담당자가 매년 결정한다.** D는 후보 유형까지만 낸다 | 결정 |
| 남은 굿즈 | **폐기하지 않고 기부한다.** 대구에 한정하지 않고 **전국**의 **보육원 등 아동복지시설**에 기부한다 (H07 2-7 기준 2) | 결정 |
| 폐기 | **불량품·D01 검수 불통과품만** 폐기한다. 폐기 수량과 이유를 기록한다 (H07 2-7) | 결정 |
| 다음 해 판매 보관 | 기본 라인(고정 8종) 중 **연도 표기가 없는 품목**은 다음 해 판매로 보관할지 D 담당이 정한다. 연도 한정판·현장 한정 굿즈는 다음 해에 팔지 않으므로 남으면 기부 대상이다 (H07 2-7 기준 1의 3번) | 제안 (H07) |
| 남은 수량 확정 시점 | 폐막 다음 날 현장 실사 및 정산 후 확정 | E 실사 → D 인계 |
| 할인 판매·후속 행사 판매 | **하지 않는다.** 할인해서 팔 상황이면 기부로 돌린다 | 결정 |
| 기록용 샘플 | 품목·디자인당 1개를 폐막 후에도 보관한다. 수는 아래 B의 계산식으로 매년 낸다 | 제안 (수량은 매년 담당자 확인) |
| 기록용 샘플 보관 기간 | 매년 담당자가 정한다. 기한 숫자는 문서에 적지 않는다 | 결정 |

- 기부는 판매가 아니므로 "축제에 와야만 구할 수 있다"는 한정판 정의(D02 2-2절)와 충돌하지 않는다.
- 기부 일정과 대상·절차는 폐막 후 잔여 수량을 확인한 뒤 축제 담당자가 외부 기부 협력처와 정한다.

**A. 보관 (후보 유형은 제안, 장소는 담당자가 매년 결정)**

| 단계 | 후보 유형 | 비고 |
|---|---|---|
| 입고 후 ~ 축제 전 | 별도 창고, 또는 현장 보관 | 장소·보안은 담당자 결정. 현장 보관 가능 여부는 공원 관리소 확인 필요 (미확정 5) |
| 축제 기간 | 상점 진열분만 상점에, 나머지는 보관 장소에 | 반입·반출은 일일 기록표(2-3절)에 적는다 |
| 폐막 다음 날 실사 후 | 기록용 샘플 / 다음 해 보관 후보 / 기부 대상 / 불량·검수 불통과품으로 분류 | 아래 C |

- 실사 시점은 개장 전과 마감 후다. 보관 장소 확보는 H06, 인원은 H02로 연결하고, 인원수는 D가 정하지 않는다.
- 직물류(티셔츠·에코백)는 습기·직사광선, 스티커·마그넷은 휨·들뜸, 텀블러는 파손을 조심해서 보관한다. 구체 조건은 업체 확인이 필요하다 `업체 확인 필요값`.

**B. 기록용 샘플 (제안)**

- **품목·디자인당 1개, 사이즈가 있는 품목은 대표 사이즈 하나**만 남긴다. 사이즈까지 전부 남기지 않는다.
- 총량: **기록용 샘플 수 = 품목 시트의 현재 SKU 합계 − (사이즈가 있는 SKU 수 − 대표 사이즈 수) `[추정]`.** 매년 품목 시트(D03)가 확정된 뒤 시트의 최신 SKU로 다시 계산하고, 계산에 쓴 SKU 목록을 함께 적는다. 숫자를 미리 정해 두지 않는다.
- 대표 사이즈가 무엇인지는 담당자가 매년 정한다.
- 입고 때 **판매 가능 입고 수량에서 미리 뺀다.** 그래야 판매율·잔여 재고 계산에 섞이지 않는다 (2-3절 "보관(기록용)" 칸).
- 일일 기록표의 "무상 지급" 칸과 따로 적는다.
- 기부·폐기 대상에서 제외한다. 보관 장소와 담당 역할을 기록한다.
- **보관 기간은 매년 담당자가 정한다.** 보관 기간이 끝난 샘플도 기부 대상이다. 불량·검수 불통과품만 폐기한다 `제안`.

**C. 잔여 재고 처리 흐름 (D는 후보안까지, 결정은 축제 담당자)**

| 순서 | 하는 일 | 누가 |
|---|---|---|
| 1 | 폐막 다음 날 실사로 현장 잔여 수량을 적는다 (장부 수량으로 대신하지 않는다). 온라인으로 넘길지는 사람이 정한다 (D06 2-4) | D파트 담당자(사람), 상점 인력 |
| 2 | 실사 및 정산 후 잔여 수량 확정 | E 현장 운영 담당 → D 상품 담당 |
| 3 | 기록용 샘플을 빼고, 연도 표기 없는 기본 상품 중 다음 해 보관 후보를 표시한다. 보관할지는 D 담당이 정한다 | D파트 담당자(사람) |
| 4 | 불량품·D01 검수 불통과품을 따로 뺀다 → 폐기 대상 (아래 E) | D파트 담당자(사람) |
| 5 | 나머지 = 기부 대상. 후보안(시설 유형, 품목·수량 배분, 연령 적합성)을 만든다 | 에이전트가 후보안 작성 → D파트 담당자(사람) 확인 |
| 6 | 기부처·품목·수량·배송비 결정, 시설 수요 및 인계 조건 확인 | 외부 기부 협력처 + 축제 담당자 (H07 2-7 기준 5) |
| 7 | 기부 실행·수령 확인 기록, 처리표를 다음 해 수량 예측(D04 2-3절)에 넘긴다 | 담당자, D파트 담당자(사람) |

**D. 기부 조건 (원본 H07 2-7 기준 2~4. 아래는 D가 챙길 부분)**

- **기부처:** 전국의 보육원 등 아동복지시설이다. 대구·경북에 한정하지 않는다. 외부 기부 협력처와 수요·검수·인계를 협의하고 구체 기부처는 담당자가 매년 정하며, D는 대상 유형과 후보까지만 낸다.
- **품목 선별(연령 안전):** 외부 기부 협력처와 수령 가능 품목, 대상 연령, 안전 확인 기준을 정한다. 작은 부품이 있는 품목은 업체의 사용 연령과 안전 자료를 확인하고 협력처가 수령 가능하다고 확인한 경우에만 영유아 대상에 포함한다.
- **재판매 금지 안내:** 기부받는 곳에 재판매하지 않도록 안내한다.
- **로고:** D01 검수를 통과한 정품 그대로 기부한다. 기부를 위해 로고를 새로 붙이거나 재포장·디자인 변경을 하지 않는다 (H07 2-7 기준 4, D01 2-3절).
- **기록:** 기부처, 품목·수량, 일자, 인수 확인, 확인자를 남긴다.
- 기부 절차·비용·영수증은 H07 2-7 기준 3·5를 따른다. 세부 값(시설 범위, 배분 기준)은 H07 미확정 7·8에 남아 있다 (미확정 8).

**E. 폐기 — 불량·검수 불통과품만 (제안)**

- 불량품·D01 검수 불통과품만 폐기한다. 판매 가능한 정품은 폐기하지 않는다 (H07 2-7).
- 포장재와 본체를 나누고, 분리배출은 H07 2-6절 쓰레기 관리 기준(일반·재활용 분리)을 따른다.
- 캐릭터·로고가 그대로 보이는 상태로 버리지 않는다. 로고·캐릭터 부분을 훼손한 뒤 배출하는 방식을 제안한다.
- 대량 폐기물 수거 방법과 비용은 관할 구청과 H에 확인해야 한다 (미확정 9).
- 폐기 수량·방법·일자·확인자를 기록한다.

**F. 기록**

- 폐막 다음 날 실사 후 "잔여 재고 처리표"(4장)를 만들고, 폐막 다음 날 실사 및 정산 후 확정한다. 첫 해 수량은 팀 입력값이면 그대로 표시한다.
- 잔여 수량이 많이 남은 SKU는 다음 해 수량을 줄이는 근거로 D04 2-3절에 넘긴다. 줄일지는 사람이 정한다.

## 3. 에이전트 행동 규칙

### 3-1. 해야 할 것

- ⚠️ **사람이 해야 하는 일:** 업체·기부처·구청 연락, 발주·기부·폐기 확정, 이미지 생성 도구(ChatGPT 등) 실행. 에이전트는 후보안·확인 항목·작업 카드까지만 만든다 (P0-10 16번). 표의 "D 담당"은 D파트 담당자(사람)다.
- 기준 자료(`Mascot/…`, `Daegu Mascot Lifestyle/…`)는 main `세부지침안/D파트v1/` 아래에 있다 (D00 "기준 자료 위치"). 파일을 읽을 수 없으면 그 작업을 "확인 불가 — 기준 자료 없음"으로 두고 담당자에게 경로를 묻는다. 비슷한 이미지를 찾아 대신 쓰지 않는다.
- 상점 운영 안을 낼 때 위치는 Y지도, 시간은 P0-4, 결제·정산은 H01 2-5를 링크하고, 제안한 항목은 "제안"으로 표시한다.
- 일일 기록표는 SKU별로 만들고, 판매·교환·무상 지급·불량·분실을 따로 적게 한다.
- 품절 시각을 반드시 기록하게 한다.
- 잔여 재고는 폐막 다음 날 실사 및 정산 후 확정하고, 기부 후보안(시설 유형, 품목·수량 배분)까지만 낸다. 기부처 선정은 축제 담당자가 매년 결정하게 한다. 기부는 전국의 보육원 등 아동복지시설이 대상이다 (H07 2-7).
- 기부 품목의 대상 연령과 안전 자료를 확인하고, 외부 기부 협력처와 품목·검수·인계 조건을 협의한다.
- 기록용 샘플은 판매 가능 입고 수량에서 미리 빼서 따로 적게 한다.
- 기록이 없는 값은 `미수집`으로 쓰고, 이유와 앞으로 수집할 방법을 적는다.

### 3-2. 하면 안 되는 것

- 상점 위치, 운영 시간, 결제·정산 방식, 인원수를 이 파트에서 임의로 정하거나 원본(Y지도·P0-4·H01 2-5·H02)과 다르게 쓰기.
- 첫 해 자료 없음을 0건·낮은 선호로 쓰기. 기록하지 못한 판매량을 추정치로 채우기.
- 판매 수량과 교환 지급 수량을 합쳐서 기록하기.
- 전체 방문객 수만으로 구매 전환율 쓰기.
- 도장 지급 기준·교환 기준·교환 장소를 D에서 바꾸기 (원본 H10).
- 잔여 재고를 할인 판매·후속 행사 판매 후보로 제시하기 (결정: 남은 굿즈는 기부, H07 2-7).
- 정품 잔여 재고를 폐기 대상으로 제시하기. 폐기는 불량품·D01 검수 불통과품만이다 (H07 2-7).
- 연도 한정판·현장 한정 굿즈를 다음 해 판매 보관 후보로 넣기.
- 기부처 이름, 기부 절차, 폐기 비용을 지어내기. 실사 없이 장부 수량으로 잔여 수량을 쓰기.
- 이미지만 보고 상품 성능을 인증했다고 안내하기.
