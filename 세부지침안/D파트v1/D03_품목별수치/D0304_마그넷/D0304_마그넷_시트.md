## 0. 이전 버전과 달라진 점

- **2026-11-20 수정, 담당자 답 반영:** 굿즈 문구는 **사투리만** 써요 (D01 2-4). 상품 면·포장 카드·행택에서 **표준어 뜻풀이를 뺐어요**. 뜻 칸은 J03 검수용 내부 기록이에요. 외지몽의 표준어 대사(질문·반응)는 캐릭터 대사 예외라 그대로 둬요. 사후 온라인 판매는 2026-11-20에 확정으로 바뀌었어요 (D06).
- 첫 버전이에요.
- 공통 지침서 v01 3절의 "캐릭터와 사투리를 결합한 기념품"(단독/듀오 구성, 자석 구조, 크기가 정할 항목)을 구체화했어요.
- 이미 정해진 공통 결정을 그대로 가져왔어요 (2026-11-17, 담당자): **성체 기준 · 모든 굿즈가 매년 달라짐 · 로고는 라벨이나 포장에 노출 · 포장 카드는 표준어 표기 · 안전 기준은 운영 파트 기준으로 연결 · 판매 위치는 상점 운영안을 본 뒤 결정 · 온라인 판매는 보류**.
- **마그넷만의 결정은 아직 없어요.** 구성(단독/듀오)·문구·크기·자석 구조는 전부 **작성자 제안이나 업체 확인 필요값**이에요. 확정은 "캐릭터와 사투리를 결합한다"는 품목 방향까지예요.

### 문구 기록 (D01 2-4절 양식)

**사투리 문구는 한 곳에서만 정한다.** 키링 시트의 [문구 기록](../D0301_아크릴키링/D0301_아크릴키링_시트.md)(COPY-KEY-NNN)에 있는 문구는 ID를 그대로 가져오고, 마그넷에서만 쓰는 새 문구는 `COPY-MAG-NNN`으로 적는다. **아래 문구는 전부 작성자 제안이고, 뜻풀이는 AI의 일반 지식에 기반한 것이다.** 대구 지역 담당자의 확인(J03)과 표기 확인(J02) 전에는 확정으로 쓰지 않는다. 사투리가 맞다고 단정하지 않는다.

| 문구 ID | 원문·줄바꿈 (제안) | 뜻 (내부 기록용) | 화자 | 상품 | 근거·확인자 | 상태 |
|---|---|---|---|---|---|---|
| COPY-KEY-001 | 어데 가노? | 어디 가니? | 대키미 | 단독 ① (대키미) | 키링 문구 재사용. **⚠️ 사람 확인 필요 — S-811ee** | 제안 |
| COPY-KEY-003 | 밥 묵었나? | 밥 먹었니? | 대키미 | 단독 ② (대키미) | 키링 문구 재사용. **⚠️ 사람 확인 필요 — S-25d67** | 제안 |
| COPY-MAG-001 | …뭐라고? | 뭐라고? (표준어, 못 알아들은 반응) | 외지몽 | 단독 ③ (외지몽) | 작성자 제안. 외지몽은 질문·반응 형태로만 말함 (D01 2-2절). 사투리가 아님 | 제안 |
| COPY-KEY-004 | 정구지 | 정구지는 부추를 가리키는 경상도 말 | 대키미 | 듀오 ① 말 | 키링 문구 재사용 | 제안 |
| COPY-MAG-002 | 부추…? | 부추? (표준어 반응) | 외지몽 | 듀오 ① 반응 | 작성자 제안. 사투리가 아님 | 제안 |
| COPY-KEY-006 | 얼라 | 얼라는 아기를 가리키는 경상도 말. 브랜드 "대구 얼라들"과 연결 | 대키미 | 듀오 ② 말 | 키링 문구 재사용 | 제안 |
| COPY-MAG-003 | 아기…? | 아기? (표준어 반응) | 외지몽 | 듀오 ② 반응 | 작성자 제안. 사투리가 아님 | 제안 |

- **후보 풀:** 키링 시트의 COPY-KEY-007~015는 이번 세트에 넣지 않았다. 매년 문구를 바꿀 때 같은 풀에서 고른다. "뭘 보노?"(COPY-KEY-008)는 후보 전용이다 (담당자 결정).
- **화자 규칙:** 사투리 문구는 대키미가 말한다. 외지몽은 표준어로 질문하거나 반응한다. 두 캐릭터의 역할을 뒤바꾸지 않는다.
- **중복:** 키링·스티커와 같은 문구를 마그넷에도 쓰는 것을 허용할지는 정해지지 않았다 (키링 시트 미정 7과 같은 사안, 이 시트 미정 6).
- 문구를 매년 바꿀 때 **표기·띄어쓰기는 승인된 값을 임의로 바꾸지 않는다** (D01 2-4절).

## 4. 면·그래픽 배치

마그넷은 앞면 인쇄와 뒷면 자석 구조가 모두 중요해서 **시점별로 적는다**. 한 시점으로 앞면·자석 구조를 함께 검증하지 않는다.

| 시점 | 들어가는 그래픽 | 로고 노출 | 비고 |
|---|---|---|---|
| **앞면 (단독)** | 캐릭터 1명(얼굴형 또는 상반신) + 말풍선(사투리 문구만, 뜻풀이 없음) | 아니오 | 글자는 후편집으로 합성 (D01 2-4절) |
| **앞면 (듀오)** | 대키미 마그넷 + 외지몽 마그넷, 대화가 이어지는 배치 | 아니오 | 두 개를 나란히 붙였을 때 말풍선이 자연스럽게 이어지는지 |
| 뒷면 | 자석 위치와 형태가 보이는 구조, 무늬 없음 또는 단색 | 라벨 부착 시 예 | 라벨 위치·형태는 업체 확인 (미정 8) |
| 측면 | 두께, 가장자리 마감 | 아니오 | 자석 층이 보이는지 업체 확인 |
| 부착 도식 | 금속 면(냉장고 문 등)에 붙은 모습 | 아니오 | 사람·집 안 배경 없이 금속판 단색 배경 |
| **포장·라벨·카드 (행택)** | 상품명, "대구 얼라들" 로고, 캐릭터 간단 소개 | **예** | 담당자 결정: **카드는 표준어로 표기** (상품명·안내 문장. 사투리 문구의 뜻풀이는 넣지 않음, 2026-11-20). 사투리 문구는 마그넷 본체에만 둠 |

- 얼굴형(귀·더듬이·눈 포함)과 상반신·전신 그래픽을 구분해 적는다. 전신 그래픽을 쓰면 외지몽 v02 승인 범위가 전신 컷을 포함하는지 확인한다 (미정 7).

**비교 시안 (샘플 이미지는 나중에 만든다. 여기서는 내용만 정의한다)**

| 안 | 구성 | 내용 | 확인할 점 |
|---|---|---|---|
| A | 단독 | **대키미 얼굴형 + 말풍선** (둥근 사각형 한 장) — COPY-KEY-001 | 말풍선 글자가 작은 크기에서 읽히는지 |
| B | 듀오 (두 장 한 쌍) | **대키미 마그넷 1 + 외지몽 마그넷 1** — COPY-KEY-004 + COPY-MAG-002 | 나란히 붙였을 때 대화가 이어지는지, 한 장씩 따로 붙여도 어색하지 않은지 |
| C | 듀오 (한 장) | **한 장에 두 캐릭터**와 말풍선 둘 | 크기가 커지고 자석 위치가 늘 수 있음. 두 캐릭터 구분 |

- 비교안은 **구성(단독/쌍/한 장) 한 요소만 바꿔** 비교한다 (D03 2-6절). 선택은 사람이 한다 (미정 2).
- 같은 구성 안에서 대키미와 외지몽 버전을 각각 만든다.

## 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다. 공통 지침서 v01은 "단독/듀오 구성, 자석 구조, 크기"를 정할 항목으로만 두었고 값은 없다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |
|---|---|---|---|
| 품목 방향 | 캐릭터와 사투리를 결합한 기념품 | **확정** | 공통 지침서 v01 / 담당자 결정 |
| 구성 | 단독 + 듀오 | 제안 | 공통 지침서 v01의 "단독/듀오". 판매 단위는 미정 5 |
| 단독 크기 | 가장 긴 변 약 50~65 mm | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 듀오 크기 | 한 장당 약 45~55 mm (쌍 합계 가로 약 100~120 mm 이내) | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 두께 | 약 2~5 mm (자석 층 포함) | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 본체 소재 | 확인 필요 | 업체 확인 필요값 | 후보: 아크릴(키링과 통일감), 에폭시 돔, 고무자석에 직접 인쇄. 선택은 업체 견적 후 |
| 자석 종류·위치 | 확인 필요 | 업체 확인 필요값 | 후보: 고무자석(얇고 가벼움) / 소형 자석 내장. 인쇄 면을 가리지 않는 뒷면 위치 |
| 부착력 | 확인 필요 | 업체 확인 필요값 | 냉장고 문·철제 보드 부착을 기준으로 실물 확인. 이미지로 판정 불가 |
| 듀오 자석 방향 | 두 개가 서로 밀어내지 않음 | 업체 확인 필요값 | 한 쌍을 나란히 붙일 때 극성·간격 확인 |
| 인쇄 공법 | UV 인쇄 또는 후보 공법 확인 | 업체 확인 필요값 | 색 재현(하늘색·초록), 가장자리 마감 |
| 컷 라인 | 둥글게 단순화 (얇은 돌출부 최소화) | 디자인 제안값 | 더듬이·귀 부러짐 방지. 업체 최소 두께·폭 확인 |
| 색 재현 | 하늘색 #6DCFF5, 초록 #008C3A | 업체 확인 필요값 | 소재에서 대표색이 다르게 보일 수 있음. 샘플 색 확인 |
| 안전 기준 | **운영 파트의 안전 기준을 따른다** (이 시트가 정하지 않음) | 확정(연결 방식) | 담당자 결정 (머리띠와 같은 원칙). 작은 자석의 삼킴 위험 등 구체 기준과 해당 파트 번호는 확인 필요 `[가설]` |
| 포장 | 라벨 또는 포장에 로고, 포장 카드는 표준어 표기 | 확정(방향) / 제안(형태) | 담당자 결정. 카드 크기·방식은 업체·F와 협의 |

- 근거 없이 "생산 가능"이라고 쓰지 않는다. 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 캐릭터 세계관상의 키를 굿즈 크기로 가져오지 않는다 (D03 2-3절).
- 작은 출력에서 얼굴 디테일이 뭉개지면 도안을 임의로 생략하지 않고 크기·구도·공법 조정을 제안한다 (D01 2-5절).
- 이미지로 부착력·자석 안전성·내구성을 인증했다고 쓰지 않는다 (D03 2-10절).

## 6. 작업 카드 (이미지 생성 전에 채움)

샘플 이미지는 나중에 따로 넣는다. 아래 카드는 **그때 바로 쓸 수 있게 미리 채운 것**이다. 대키미 단독 A안을 기준으로 하고, 나머지는 바뀌는 항목만 적는다.

```yaml
작업_ID: D03-04_v01_A
생성도구: ChatGPT
첨부한_참조파일: 대키미_캐릭터_원본설정보드.png (위 2장 경로)
품목: 마그넷 · 단독 · 대키미 얼굴형 + 말풍선
목적: 상품_샘플이미지
상태: 검토용_시안
선택_캐릭터버전: 성체
캐릭터_기준파일: 대키미_캐릭터_원본설정보드.png
로고_기준파일: 이번면_미노출
기존상품_참고파일: 없음
참고역할: 캐릭터정체성=원본설정보드
문구_원문과줄바꿈: COPY-KEY-001 "어데 가노?" (뜻풀이 없음) (제안, 글자는 후편집 합성)
규격: 가장 긴 변 약 50~65 mm, 두께 약 2~5 mm (디자인 제안값)
재질과공법: 확인 필요 (업체 확인 필요값)
필수_시점: 앞면, 뒷면(자석 위치), 측면, 금속판 부착 도식
고정할것: 성체 대키미의 종·귀·더듬이 2개·눈·하늘색 입 주변·대표색, 본체 로고 없음
이번에_바꿀것: 단독 · 얼굴형 + 말풍선 (비교안 A)
출력_파일명: D0304_마그넷_대키미_성체_A_v01_앞면.png
미정사항: 소재·자석 구조·부착력·안전은 업체 확인 필요
```

| 작업 ID | 바뀌는 항목 |
|---|---|
| D03-04_v01_A2 | 외지몽 단독. 참조: 외지몽 원본설정보드 (+ 승인정면 v04). 문구 COPY-MAG-001 `…뭐라고?` (표준어). 주둥이 크림빛 |
| D03-04_v01_B | 듀오 두 장 한 쌍. 대키미 `정구지 = 부추` (COPY-KEY-004) + 외지몽 `부추…?` (COPY-MAG-002). 두 캐릭터 참조 모두 첨부. 출력 파일명 `…_듀오_성체_B_v01_앞면.png` |
| D03-04_v01_C | 듀오 한 장. 한 장에 두 캐릭터와 말풍선 둘. 출력 파일명 `…_듀오_성체_C_v01_앞면.png` |

- 시점별로 별도 컷을 만든다 (앞면·뒷면·측면·부착 도식). 한 장으로 구조 전체를 검증하지 않는다.
- 첨부 없이 문자 설명만으로는 같은 캐릭터를 보장할 수 없다. 참조 이미지는 반드시 첨부한다 (D03 2-4절). 듀오는 두 캐릭터 보드를 모두 첨부한다.

## 7. 프롬프트

- **생성 프롬프트:** [D03 공통 생성 프롬프트](../D03_품목별수치.md)(2-5절) + 위 작업 카드를 붙여 쓴다. 이 품목에서만 추가하는 문장:
  - `마그넷 상품의 샘플 컷이다. 캐릭터와 말풍선이 인쇄된 납작한 마그넷이며 인형이나 입체 피규어가 아니다. 털 질감을 입체로 표현하지 않는다.`
  - `뒷면 컷에는 자석 위치가 보이게 하되 인쇄 면과 겹치지 않게 한다. 부착 도식은 사람이나 집 안 배경 없이 금속판 위에 붙은 모습만 보여 준다.`
  - `문구는 아래 원문을 한 글자도 바꾸지 않고, 사투리 문구만 크게 배치한다(표준어 뜻풀이를 넣지 않는다). 글자가 깨지면 실패로 본다. 최종 글자는 후편집으로 합성한다.`
  - `제품 본체에 로고를 넣지 않는다.`
  - `밝은 중립 배경, 부드러운 조명, 전체 외형이 보이는 구도. 샘플 컷의 표기는 "검토용 시안"으로 한다.`
- **수정 프롬프트:** [D03 수정 프롬프트 양식](../D03_품목별수치.md)(2-8절)을 쓴다. 이 품목에서 자주 나올 오류와 수정 문장:

| 예상 오류 | 수정 문장 |
|---|---|
| 더듬이가 3개이거나 구슬이 없음 (H02) | `더듬이는 2개, 각각 끝에 구슬 1개. 나머지는 유지한다.` |
| 사투리 글자가 깨지거나 바뀜 (H04) | 같은 프롬프트를 되풀이하지 않고 **글자만 후편집으로 합성**한다 (3회 반복 규칙) |

| 입체 피규어·인형처럼 보임 (H05) | `납작한 인쇄 마그넷이다. 입체 인형이나 피규어처럼 만들지 않는다.` |
| 뒷면 자석이 앞면 인쇄를 가림 (H05) | `자석은 뒷면에만 두고 앞면 그래픽과 겹치지 않게 한다.` |
| 듀오에서 두 캐릭터 색이 섞임 (H03) | `대키미 하늘색 #6DCFF5 / 외지몽 초록 #008C3A. 두 색을 섞지 않는다.` |
| 제품에 로고가 생김 (H03) | `제품 본체에서 로고를 지운다. 후편집으로 제거해도 된다.` |

- 프롬프트 원문은 이미지를 만들 때 `프롬프트/` 폴더에 `D0304_마그넷_<대키미 또는 외지몽 또는 듀오>_<안>_v01.txt`로 저장한다.
