## 0. 이전 버전과 달라진 점

- **2026-11-20 수정, 담당자 답 반영:** 굿즈 문구는 **사투리만** 써요 (D01 2-4). 사투리형 키링에서 **표준어 뜻풀이를 뺐어요** — 앞면·뒷면·포장 카드 모두. "사투리 = 표준어" 풀이형 문구(COPY-KEY-004·005·006·014)는 사투리 단어만 남겼어요. 뜻 칸은 J03 검수용 내부 기록이에요.
- v1: 첫 버전이에요.
- 공통 지침서 v01 3절의 "사투리 키링 & 마스코트 키링"(소재 미정)을 **아크릴 키링**으로 정했어요. **사투리형**과 **캐릭터형** 두 종류로 구성해요 (2026-11-17 담당자 결정).
- **봉제 키링(인형)은 이번 라인에서 제외**해요. 기존 아기버전 봉제 키링 개발 이력은 그대로 보존하고, 이 시트의 기준 자료로 쓰지 않아요.

- 문구 종류는 두 가지로 나눈다: **대화형**(토박이 대키미가 건네는 말)과 **단어형**(정구지·찌짐처럼 사투리 단어 하나). "사투리 = 표준어" 풀이형은 굿즈에 쓰지 않는다 (D01 2-4, 담당자 결정 2026-11-20).
- 대키미는 설명하는 토박이, 외지몽은 질문하고 배우는 여행자다 (D01 2-2절). **사투리 문구의 화자는 대키미**를 기본으로 하고, 외지몽이 말하는 문구가 필요하면 질문·반응 형태("…뭐라고?" 등)로 따로 제안한다 (이번 세트에는 없음).
- **어감 주의:** "뭘 보노?"는 시비가 아니라 진짜 궁금해서 묻는 말투지만, 글자만 보면 싸움을 거는 느낌으로 읽힐 수 있어 **후보 전용**으로 뒀다(담당자 결정). 쓰게 되면 장난스럽거나 궁금한 표정과 함께 쓴다. D01은 사투리를 "무례한 말투로만" 표현하지 않도록 한다.
- 단어형은 사전에 올라 있는 표현만 쓰고, 지역별로 뜻이 다른 말(예: 갱시기 = 김치죽류, 지역마다 의미 다름)은 이번 세트에 넣지 않았다.

| **사투리형 앞면** | 사투리 문구만 (큰 글자) | 아니오 | 말풍선 모양 제안. 표준어 뜻풀이 없음. 글자는 후편집으로 합성 (D01 2-4절) |
| 사투리형 뒷면 | 단색 또는 반전 | 아니오 | 뜻풀이 넣지 않음 (D01 2-4) |
| **포장 카드 (행택)** | 상품명, "대구 얼라들" 로고, 캐릭터 간단 소개 | **예** | 로고는 포장 카드에만 노출. 표준어 뜻풀이는 넣지 않음 (D01 2-4절) |

**비교 시안 (샘플 이미지는 나중에 만든다. 여기서는 내용만 정의한다)**

| 안 | 종류 | 내용 | 확인할 점 |
|---|---|---|---|
| A | 캐릭터형 | **얼굴형** — 얼굴+귀+더듬이 2개. 컷 라인이 둥글고 단순 | 더듬이 구슬이 작아 컷·인쇄가 뭉개지지 않는지 |
| B | 캐릭터형 | **전신형** — 몸통·팔다리·꼬리까지 포함 | 꼬리·더듬이 같은 얇은 부분이 부러질 위험 (H02, 실물 확인) |
| C | 사투리형 | **말풍선형** — 둥근 말풍선에 사투리 문구만, 꼬리 부분에 고리 구멍 | 한 고리에 캐릭터형과 같이 걸 때 방향이 자연스러운지 |
| D | 사투리형 | **둥근 사각형** — 문구 위주의 단순한 모양 | 캐릭터와 짝이라는 느낌이 약해지지 않는지 |

- 비교안은 **배치·크기 등 한두 요소만 바꿔** 비교한다 (D03 2-6절). 선택은 사람이 한다 (미확정 2·3).
- 짝 세트 연출: 캐릭터형 + 사투리형을 한 고리에 걸었을 때 말풍선이 캐릭터 옆에 오는 구도를 기본으로 제안한다. `[해석]`

## 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |
|---|---|---|---|
| 소재 | 아크릴 (투명) | **확정** | 담당자 결정 (2026-11-17) |
| 종류 | 캐릭터형 + 사투리형 2종류 | **확정** | 담당자 결정 (2026-11-17) |
| 캐릭터형 크기 | 가장 긴 변 약 50~60 mm | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 사투리형 크기 | 가로 약 55~65 mm × 세로 약 40~45 mm | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 두께 | 약 2~3 mm | 디자인 제안값 | 작성자 제안. 업체 템플릿·견적 확인 필요 |
| 구멍 위치·지름 | 확인 필요 | 업체 확인 필요값 | 업체 템플릿 필요 |
| 체결 (고리·볼체인 등) | 확인 필요 | 업체 확인 필요값 | 업체 확인 필요. 한 고리에 2개를 함께 걸 수 있어야 함 |
| 인쇄 공법 | UV 인쇄 후보 (투명 아크릴 위 인쇄) | 업체 확인 필요값 | 백색 바탕 인쇄 여부, 양면 인쇄, 색 재현을 업체에서 확인 |
| 컷 라인 | 둥글게 단순화 (얇은 돌출부 최소화) | 디자인 제안값 | 더듬이·꼬리 부러짐 방지. 업체 최소 두께·최소 폭 확인 필요 |
| 색 재현 | 하늘색 #6DCFF5, 초록 #008C3A | 업체 확인 필요값 | 투명 아크릴에서 대표색이 다르게 보일 수 있음. 샘플 색 확인 필요 |
| 포장 | 포장 카드(행택) + 개별 포장 | 제안 | 카드 크기·방식은 업체·F와 협의 |

- 근거 없이 "생산 가능"이라고 쓰지 않는다. 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 캐릭터 세계관상의 키를 굿즈 높이로 가져오지 않는다 (D03 2-3절).
- 작은 출력에서 얼굴 디테일이 뭉개지면 도안을 임의로 생략하지 않고 크기·구도·공법 조정을 제안한다 (D01 2-5절).
