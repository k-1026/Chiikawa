### 문구 기록 (D01 2-4절 양식)

**사투리 문구는 한 곳에서만 정한다.** 안대 전용 문구는 `COPY-EYE-NNN`으로 적는다. **아래 문구는 전부 `제안`이다.** 기존 시안 문구도 "기존 시안 원문(승인 전)"일 뿐 확정이 아니다. 대구 지역 담당자 확인(J03)과 표기 확인(J02) 전에는 확정으로 쓰지 않는다. 사투리가 맞다고 단정하지 않는다.

**① 원문 보존본 (기존 시안 이미지에서 읽음)**

| 문구 ID | 원문·줄바꿈 | 위치 | 화자 | 근거·확인자 | 상태 |
|---|---|---|---|---|---|
| COPY-EYE-001 | 잠온다.. | 대키미 안대 앞면 (한 줄, 가운데) | 대키미 | **⚠️ 사람 확인 필요 — S-438f8**("잠온다"=졸리다, J 자료집). 기존 시안(v01~v04 공통). 마침표 두 개. 프롬프트 원문 파일 없음 → 이미지에서 읽음. 확인자 없음 | 제안 |
| COPY-EYE-002 | 졸리다.. | 외지몽 안대 앞면 (한 줄, 가운데) | 외지몽 | 기존 시안(v01~v04 공통). 마침표 두 개. 표준어. 확인자 없음 | 제안 |

- **마침표는 이미지대로 두 개(`..`)로 보존한다.** 이 표기가 의도된 것인지는 담당자 확인 (미정 1).
- 대키미 = 사투리, 외지몽 = 표준어 반응 구조는 D01 2-2절과 맞다.

**② 확인할 점 (문구 자체의 성격)**

- **"잠온다"가 사투리인지 표준어를 줄인 말인지** 불분명하다. 표준어에서도 "잠이 온다"를 줄여 쓸 수 있어서, "사투리 ↔ 표준어 짝"이 성립하는지 J03가 확인해야 한다 (미정 2). 이 시트는 사투리라고 단정하지 않는다.
- 두 안대의 웃음은 **같은 상태를 서로 다른 말로 말하는 짝**(질문·설명 구조가 아닌 말씨 대비)이다. 공통 지침서 9절의 "두 안대를 나란히 놓았을 때 사투리와 표준어가 짝으로 읽히는 배치"가 이를 가리킨다.

**③ 신규 문구**

- 이번 시트에서는 **새 사투리 문구를 만들지 않았다.** 연도별로 문구를 바꿀 때는 [밈·유머 후보 풀](../_사투리_밈유머_후보.md)의 규칙(오해 해소형·풀이형·질문·반응형 등)을 따르고, 수면·피로 소재(예: "졸리다" 짝)에 맞는 후보는 J03 확인 후 후보 풀에 추가한다.

| 금지 | 성체와 아기 혼합 · 두 캐릭터 종·역할 뒤바꾸기 · 더듬이 개수·구슬 변경 · 대키미에 처진 귀, 외지몽에 뾰족한 귀 · 임의 몸색 변경 · 기존 문구를 변경 내역 없이 교정·축약 · 승인 전 문구를 승인 문구처럼 사용 · 사투리를 과장된 억양/무례한 말투로만 표현 · 본체에 로고 넣기 · **수면 개선·눈 건강·안전성 등 효능·성능을 이미지나 문구로 주장** · 장식이 예쁘다는 이유로 눈 압박·빛샘·착용감을 통과했다고 표시 |

- 공통 금지는 D01 3-2절을 따른다.
- 산·더위 소재는 보조 요소로 제한한다 (D01 2-3절). 안대에는 쓰지 않는다.

## 4. 면·그래픽 배치

안대는 **눈을 덮는 면**과 **얼굴에 닿는 면**이 서로 달라서 **시점별로 적는다.** 한 시점으로 모든 면을 검증하지 않는다 (D03 2-9절).

| 시점 | 들어가는 그래픽 | 로고 노출 | 비고 |
|---|---|---|---|
| **앞면 (바깥면)** | 본체 + 귀 + 더듬이 2개 + 가운데 문구(자수) | 아니오 | 기존 시안의 구성. 눈 위치와 문구가 겹치는 구조 |
| **뒷면 (얼굴에 닿는 면)** | 부드러운 안감, 코 부분 요철, 밴드 연결부 | 라벨 부착 시 예 | **자수의 뒷면이 얼굴에 닿는지** 실물 확인 (미정 5). 안감으로 가려지는지 |
| 측면 | 귀·더듬이의 돌출 높이, 본체 두께 | 아니오 | 누웠을 때 베개에 눌리는 높이 확인 |
| 밴드 | 밴드 모양, 조절부(버클/고무) | 아니오 | 조절 범위·압박은 실물 확인 |
| 착용 도식 | 마네킹 헤드에 쓴 모습 (**사람 얼굴 생성 안 함**) | 아니오 | 눈 위치와 귀 위치만 보여 줌 |
| **라벨·행택·포장 카드** | 상품명, "대구 얼라들" 로고, 세탁 안내 | **예** | 담당자 결정: **카드는 표준어로 표기** (상품명·안내 문장. 사투리 문구의 뜻풀이는 넣지 않음, 2026-11-20) |

- 안대 앞면의 문구는 **눈 위치에서 읽히는가**를 점검한다. 얼굴 중앙에 글자가 오므로 글자 크기가 너무 크면 눈을 덮는 느낌이 달라질 수 있다.

**비교 시안 (샘플 이미지는 나중에 만든다. 여기서는 내용만 정의한다)** — 작성자 제안, 어느 안도 선택되지 않음

| 안 | 이름 | 내용 | 확인할 점 |
|---|---|---|---|
| A | **기존안 보정** | **v04(실사상품컷)를 출발점**으로 문구와 캐릭터 장식을 유지하고, **비율·자수 가독성**을 보정 (글자 크기, 남색/크림 자수 대비, 장식 높이) | 자수가 읽히는지, 구슬 더듬이가 누웠을 때 부담이 되지 않는지 |
| B | **낮고 작은 장식** | **v02(납작한 원판 더듬이, 작은 자수)를 참고**해 장식을 더 낮고 작게, 문구는 중앙에 두고, **안감·밴드 편안함**을 별도 검토 | 낮은 장식에서도 캐릭터가 알아보이는지 (귀 형태 구분), 착용감 |
| C | **짝 배치** | 두 안대를 **나란히 놓았을 때** 대키미 "잠온다.." ↔ 외지몽 "졸리다.."가 짝으로 읽히도록 크기·위치·색을 맞춤 (외지몽 "졸리다.."는 캐릭터 대사 예외, D01 2-4). 포장 카드에 뜻풀이 없음 | 나란히 두면 말씨 대비가 보이는지, 한 개만 봐도 어색하지 않은지. 짝 문구 어감은 J03 |

- 같은 안 안에서 대키미와 외지몽 버전을 각각 만든다.
- 비교안은 장식 크기·자수 비율·안감 같은 **한두 요소만 바꿔** 비교한다 (D03 2-6절). 선택은 사람이 한다 (미정 3).

## 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다. 공통 지침서 v01은 "글자·장식 비율, 안감, 밴드, 소재·봉제"를 정할 항목으로만 두었고 값은 없다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |
|---|---|---|---|
| 품목 방향 | 잠온다 / 졸리다 관계를 살린 수면안대 | **확정** | 공통 지침서 v01 / 담당자 결정 |
| 본체 크기 | 가로 약 190~210 mm × 세로 약 85~100 mm | 디자인 제안값 | 작성자 제안. 업체 규격 확인 필요 |
| 귀 높이 | 약 30~45 mm | 디자인 제안값 | 작성자 제안. 누웠을 때 눌림을 줄이려 낮게 제안 |
| 더듬이 높이 (본체 위) | 약 30~50 mm, 끝 구슬 지름 약 15~20 mm (비교안 B는 더 낮고 납작) | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 문구 자수 크기 | 글자 높이 약 20~30 mm | 디자인 제안값 | 작성자 제안 (기존 v02는 작은 자수, v03·v01은 더 큼). 자수 최소 획·크기는 업체 확인 |
| 문구 색 (자수) | 대키미 짙은 남색 / 외지몽 크림 | 디자인 제안값 | 기존 시안 방향. 대표색 변경이 아니라 문구 색. 읽힘은 실물 확인 |
| 바깥 원단 | 플러시(기모) 또는 면 | 업체 확인 필요값 | 기존 시안 v04 = 플러시, v02 = 면. 선택은 업체 견적 후 |
| 안감 (얼굴에 닿는 면) | 부드러운 면·폴리 계열 | 업체 확인 필요값 | **피부 접촉 소재**: 운영 파트 안전 기준과 업체 확인 자료 필요 |
| 충전재 | 얇은 폼 또는 솜 | 업체 확인 필요값 | 빛 차단·눈 압박은 이미지로 판정 불가 |
| 코 부분 | 요철(코 가림 형태) 유지 | 업체 확인 필요값 | 빛샘과 관련. 실물 확인 |
| 밴드 | 조절 버클 또는 고무 밴드, 폭 약 20~30 mm | 업체 확인 필요값 | 기존 v04는 버클, v02는 가는 밴드. 압박·조절 범위는 실물 확인 |
| 귀·더듬이 고정 | 확인 필요 (봉제/체결) | 업체 확인 필요값 | 누웠을 때 눌림, 떨어짐 |
| 자수 공법 | 자수 (기존 시안 방향) | 업체 확인 필요값 | 자수 뒷면 처리(안감으로 덮기) 포함. 소량 단가 확인 |
| 색 재현 | 하늘색 #6DCFF5, 초록 #008C3A | 업체 확인 필요값 | 원단에서 다르게 보일 수 있음. 샘플 색 확인 |
| 안전 기준 | **운영 파트의 안전 기준을 따른다** (이 시트가 정하지 않음) | 확정(연결 방식) | 담당자 결정. 피부 접촉 소재 기준과 해당 파트 번호는 확인 필요 `[가설]` |
| 포장 | 개별 포장 + 행택, 카드는 표준어 표기 | 확정(방향) / 제안(형태) | 담당자 결정. 카드 크기·방식은 업체·F와 협의 |

- 근거 없이 "생산 가능"이라고 쓰지 않는다. 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 캐릭터 세계관상의 키를 굿즈 크기로 가져오지 않는다 (D03 2-3절).
- **수면 개선·눈 건강·빛 차단율·안전성 등 성능은 이미지나 문구로 주장하지 않는다** (D03 2-10절). 업체 확인 자료가 있을 때만 그 범위 안에서 안내한다.

## 7. 프롬프트

- **생성 프롬프트:** [D03 공통 생성 프롬프트](../D03_품목별수치.md)(2-5절) + 위 작업 카드를 붙여 쓴다. 이 품목에서 자주 쓰는 추가 문장:
  - `수면안대 상품의 샘플 컷이다. 봉제 원단으로 만든 눈가리개이며 귀 2개와 더듬이 2개만 달려 있다. 눈·입·몸통은 그리지 않는다.`
  - `문구는 첨부한 원문을 한 글자도, 마침표 개수도 바꾸지 않는다. 글자가 깨지면 실패다. 최종 글자는 후편집으로 합성한다.`
  - `대키미는 뾰족한 고양이 귀(안쪽 분홍), 외지몽은 아래로 처진 강아지 귀로 첨부 보드와 같게 유지한다. 귀 모양을 바꾸지 않는다.`
  - `제품 단독 컷 또는 투명 마네킹 헤드 착용 도식. 사람 얼굴이나 사람 모델은 넣지 않는다. 안대 본체에 로고를 넣지 않는다.`
  - `기존 시안을 그대로 다시 그리지 않고, 이번에 바꿀 항목만 바꾼다. 인쇄된 캐릭터를 털 인형 스타일로 바꾸지 않는다.`
- **수정 프롬프트:** [D03 수정 프롬프트 양식](../D03_품목별수치.md)(2-8절)을 쓴다. 이 품목에서 자주 나올 오류와 수정 문장:

| 예상 오류 | 수정 문장 |
|---|---|
| 한글 글자가 깨지거나 마침표 개수가 바뀜 (H04) | 같은 프롬프트를 되풀이하지 않고 **글자만 후편집으로 합성**한다 (3회 반복 규칙) |
