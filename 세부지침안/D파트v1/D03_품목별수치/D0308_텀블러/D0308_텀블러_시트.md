## 0. 이전 버전과 달라진 점

- **2026-11-20 수정, 담당자 답 반영:** 굿즈 문구는 **사투리만** 써요 (D01 2-4). 상품 면·포장 카드·행택에서 **표준어 뜻풀이를 뺐어요**. 뜻 칸은 J03 검수용 내부 기록이에요. 외지몽의 표준어 대사(질문·반응)는 캐릭터 대사 예외라 그대로 둬요. 사후 온라인 판매는 2026-11-20에 확정으로 바뀌었어요 (D06).
- 첫 버전이에요. 고정 8종 중 **마지막 품목**이에요.
- 공통 지침서 v01 3절의 "캐릭터·사투리·로고의 읽힘을 곡면 위에서 유지"(용량, 본체·뚜껑, 표면, 인쇄 영역·공법이 정할 항목)를 구체화했어요.
- 기존 샘플 3장을 열어서 확인했어요 (`Mascot/goods/텀블러_머그컵_샘플_v01/`, 아래 1장). **티셔츠·안대와 달리 공통 지침서가 추가 개발 대상으로 지정한 시안이 아니라 "참고"** 예요. 기존 샘플은 **텀블러+머그컵**이고 문구·로고가 없으며 캐릭터와 색이 성체 보드와 달라서, 기준으로 삼지 않고 **달라진 점을 따로 기록**했어요.
- 이미 정해진 공통 결정을 가져왔어요 (2026-11-17, 담당자): **성체 기준 · 모든 굿즈가 매년 달라짐 · 로고는 라벨이나 포장에 노출 · 포장 카드는 표준어 표기 · 안전 기준은 운영 파트 기준으로 연결 · 판매 위치는 상점 운영안을 본 뒤 결정 · 온라인 판매는 보류 · 일정은 축제 담당자가 매년 결정(D는 후보안까지)**.
- 용량·소재·뚜껑·인쇄 공법·치수는 **전부 작성자 제안이나 업체 확인 필요값**이에요. 비교안 A·B·C는 작성자 제안이며 **어느 안도 선택되지 않았어요.**

### 문구 기록 (D01 2-4절 양식)

**사투리 문구는 한 곳에서만 정한다.** 키링 시트의 문구(COPY-KEY-NNN)는 ID를 그대로 가져오고, 텀블러에서만 쓰는 새 문구는 `COPY-TMB-NNN`으로 적는다. **아래 문구는 전부 `제안`이다.** 대구 지역 담당자 확인(J03)과 표기 확인(J02) 전에는 확정으로 쓰지 않는다. 사투리가 맞다고 단정하지 않는다.

- **화자 규칙:** 사투리는 대키미, 외지몽은 표준어 질문·반응이다.
- **중복:** 키링·스티커·마그넷·에코백과 같은 문구를 쓰는 것을 허용할지는 정해지지 않았다 (키링 시트 미정 7과 같은 사안, 이 시트 미정 6).

## 4. 면·그래픽 배치

텀블러는 곡면이라 **시점별로 적는다.** 한 시점으로 곡면 전체를 검증하지 않는다 (공통 지침서 v01 4절).

| 시점 | 들어가는 그래픽 | 로고 노출 | 비고 |
|---|---|---|---|
| **정면 (캐릭터면)** | 캐릭터 얼굴형(귀·더듬이·눈 포함) + 문구 (뜻풀이 없음) | 아니오 | 글자는 **곡면 정면 중앙 부근**에 모음 (제안: 정면 중심에서 좌우 약 60° 안). 글자는 후편집으로 합성 |
| 후면 | 보조 장식(별·점) 또는 작은 로고 한 개 | **예 (제안, 미정 5)** | 승인 로고 구조 보존 |
| 둘레 전개 | 360° 띠 모양 도안을 평면으로 펼친 도면 | 아니오 | 곡면 인쇄 공법의 도안 규격은 업체 템플릿 필요. 비교안 B에서 사용 |
| 뚜껑·빨대 | 무늬 없음 또는 더듬이 모티브 소형 장식 | 아니오 | 뚜껑 구조·빨대는 업체 확인. 작은 부품은 안전 확인 (미정 4) |
| 바닥 | 무늬 없음 또는 작은 로고 | 선택 (제안) | 인쇄 가능 여부는 업체 확인 |
| **라벨·행택·포장 카드** | 상품명, "대구 얼라들" 로고, 세척·취급 안내 | **예** | 담당자 결정: **카드는 표준어로 표기** (상품명·안내 문장. 사투리 문구의 뜻풀이는 넣지 않음, 2026-11-20). 취급 안내는 업체 확인 내용만 적음 |

- 얼굴형(귀·더듬이·눈 포함)과 전신 그래픽을 구분해 적는다. 곡면에는 얼굴형을 기본으로 제안한다. 전신을 쓰면 외지몽 v02 승인 범위를 확인한다 (미정 7).

**비교 시안 (샘플 이미지는 나중에 만든다. 여기서는 내용만 정의한다)** — 작성자 제안, 어느 안도 선택되지 않음

| 안 | 이름 | 내용 | 확인할 점 |
|---|---|---|---|
| A | **정면 한 면형** | 곡면 정면에 캐릭터 얼굴형 + 문구 한 줄(대키미 `덥다 아이가` / 외지몽 `…덥다고?`) | 곡면 가장자리에서 글자가 왜곡되지 않는지, 인쇄 영역 안에 들어가는지 |
| B | **둘레 전개형** | 본체를 한 바퀴 두르는 띠에 별·점 장식과 문구를 반복 배치. 캐릭터 얼굴형은 정면 한 곳 | 이음선(시작·끝)이 눈에 띄지 않는지, 반복해도 과하지 않은지 (공통 지침서 6절: 과도한 반복 금지) |
| C | **손잡이 장식형 (기존 샘플 방향, 성체 보드 기준으로 보정)** | 손잡이나 뚜껑에 **캐릭터 머리·더듬이 모양 소형 입체 장식**, 본체는 단순. **성체 보드와 다른 요소(리본·배 무늬)는 넣지 않음** | 입체 장식의 부러짐·세척 시 분리 위험, 원가, 작은 부품 안전. 업체가 제작 가능한지부터 확인 |

- 같은 안 안에서 대키미와 외지몽 버전을 각각 만든다.
- 비교안은 그래픽 방식 한 요소만 바꿔 비교한다 (D03 2-6절). 선택은 사람이 한다 (미정 3).

## 5. 치수·소재·공법

값마다 상태를 적는다. **근거 없는 "생산 가능" 판정은 쓰지 않는다.** 아래 숫자는 모두 디자인을 검토하기 위한 제안값이다. 공통 지침서 v01은 "용량, 본체·뚜껑, 표면, 인쇄 영역·공법"을 정할 항목으로만 두었고 값은 없다.

| 항목 | 값 (단위 포함) | 상태 | 근거·확인자 |
|---|---|---|---|
| 품목 방향 | 캐릭터·사투리·로고의 읽힘을 곡면 위에서 유지하는 텀블러 | **확정** | 공통 지침서 v01 / 담당자 결정 |
| 용량 | 약 350~500 mL | 디자인 제안값 | 작성자 제안. 업체 규격에서 확인 필요 (기존 샘플은 이보다 크게 보이나 측정하지 않음) |
| 본체 형태 | 원통형 (곡면 인쇄가 쉬운 단순 곡면) | 디자인 제안값 | 작성자 제안. 업체 확인 필요 |
| 본체 소재 | 스테인리스 또는 플라스틱 계열 | 업체 확인 필요값 | **식품 접촉 소재**: 운영 파트 안전 기준과 업체 확인 자료 필요. 이미지로 안전성을 말하지 않음 |
| 뚜껑·빨대 | 뚜껑 포함, 빨대 포함 여부 | 업체 확인 필요값 | 뚜껑 구조(밀폐 여부)·빨대 재질은 업체 확인 |
| 인쇄 영역 | 정면 가로 약 60~80 mm × 세로 약 70~90 mm | 디자인 제안값 | 작성자 제안. 업체 템플릿 필요. 곡면이라 평면 치수와 실제가 다름 |
| 글자 크기 | 문구 글자 높이 약 8~12 mm | 디자인 제안값 | 작성자 제안. 곡면 인쇄 최소 크기는 업체 확인 |
| 인쇄 공법 | 곡면 UV 인쇄 / 수전사 / 패드 인쇄 / 레이저 각인 후보 | 업체 확인 필요값 | 색 재현·번짐·벗겨짐·세척 후 상태는 업체 확인과 실물 확인 |
| 표면 | 무광 또는 유광 | 업체 확인 필요값 | 인쇄 공법과 연동 |
| 본체색 | 대키미 하늘색 계열 / 외지몽 초록 계열 | 확정(방향) / 업체 확인 필요(재현) | 보드 표기와 일치. 금속·도장 위 재현은 샘플 색 확인 |
| 색 재현 | 하늘색 #6DCFF5, 초록 #008C3A | 업체 확인 필요값 | 소재·공법에 따라 다르게 보일 수 있음 |
| 보온·보냉 | **주장하지 않음** | - | 업체 시험 자료가 있을 때만 그 범위 안에서 안내 (D03 2-10절). 이 시트는 수치를 적지 않음 |
| 누수·내열·세척 | **주장하지 않음** | - | 같은 이유. 실물 확인과 업체 자료 |
| 안전 기준 | **운영 파트의 안전 기준을 따른다** (이 시트가 정하지 않음) | 확정(연결 방식) | 담당자 결정. 식품 접촉 소재 기준과 해당 파트 번호는 확인 필요 `[가설]` |
| 포장 | 개별 포장 박스 + 행택, 카드는 표준어 | 확정(방향) / 제안(형태) | 담당자 결정. 카드 크기·방식은 업체·F와 협의 |

- 근거 없이 "생산 가능"이라고 쓰지 않는다. 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 캐릭터 세계관상의 키를 굿즈 크기로 가져오지 않는다 (D03 2-3절).
- **내열·누수 방지·보온·냉감·식품 접촉 안전성 등 성능은 이미지나 문구로 인증하지 않는다** (D03 2-10절).

- **생성 프롬프트:** [D03 공통 생성 프롬프트](../D03_품목별수치.md)(2-5절) + 위 작업 카드를 붙여 쓴다. 이 품목에서만 추가하는 문장:

  - `문구는 아래 원문을 한 글자도 바꾸지 않고 곡면 정면 중앙에 배치한다. 글자가 깨지거나 가장자리에서 늘어나면 실패다. 최종 글자는 후편집으로 합성한다.`
  - `전체 외형(뚜껑 포함)이 잘리지 않게 보여 준다. 사람·손·배경 소품 없이 제품만. 보온·보냉·누수 방지를 보여 주는 표현(김, 물방울 효과 등)은 넣지 않는다.`
  - `밝은 중립 배경, 부드러운 조명. 샘플 컷의 표기는 "검토용 시안"으로 한다.`

**품목별 실물 샘플 확인 항목** (이미지로 판정할 수 없다)

- [ ] 곡면 인쇄 읽힘: 글자가 가장자리에서 왜곡되지 않는지, 색 재현(하늘색·초록), 번짐
- [ ] 이음선: 둘레 전개형(B)에서 도안의 시작·끝이 눈에 띄지 않는지
- [ ] 뚜껑: 닫힘·열림, 밀폐 상태, 빨대 구멍 (업체 자료와 함께 확인, 이미지로 판정 불가)
- [ ] 세척 편의: 입구 크기, 뚜껑 분해, 인쇄가 세척으로 벗겨지지 않는지
- [ ] 손에 쥐는 느낌: 지름·무게·미끄러짐
- [ ] 비교안 C 입체 장식: 부러짐, 분리, 세척 시 떨어짐, 작은 부품 위험
- [ ] 식품 접촉 소재의 안전: 운영 파트 안전 기준에 따라 업체 자료 확인

- 소재·용도에 맞는 업체 확인 자료를 받는다. **내열·누수 방지·보온·냉감·식품 접촉 안전성 등을 이미지로 인증했다고 주장하지 않는다** (D03 2-10절).
