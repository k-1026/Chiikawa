## 1. 이 파트의 역할

- 품목별 **디자인 시트**(치수·소재·공법·그래픽 배치)를 같은 양식으로 만들게 해요.
- 샘플 이미지를 **입력 → 생성 → 검수 → 수정** 순서로 만드는 문서형 하네스를 정해요. 사람이든 AI든 같은 절차로 작업해요.
- 캐릭터·로고·문구 규칙과 검수표(H01~H07)는 D01이 원본이고, 여기서는 그대로 가져다 써요.
- 디자인 검토와 양산 발주는 **별도 상태**예요. 이 파트는 샘플 이미지와 시트까지만 다뤄요. 발주는 D04예요.

- 작업 순서는 위 순서대로다. **한 품목의 선택안을 정리한 뒤 다음 품목으로 넘어가는 것**을 기본으로 한다. (공통 지침서 v01의 작성자 제안)
- 각 품목은 **디자인 시트 초안 → 비교 시안 → 선택안 보정 → 샘플 이미지 검수** 순서로 진행한다.
- **샘플 이미지는 시트 내용을 먼저 채운 뒤 나중에 `샘플이미지/` 폴더에 따로 넣는다** (2026-11-17 담당자 결정). 시트의 1~7장(상품 정보·기준 자료·고정/변경/금지·면 배치·치수 소재 공법·작업 카드·프롬프트)은 이미지 없이 완성한다. 8장(검수)과 9장(결과 기록)은 이미지가 들어온 뒤 채우고, 그 전에는 `이미지 대기`로 표시한다.

### 2-2. 품목 시트 필수 구성

시트 양식([_품목시트_양식.md](_품목시트_양식.md))의 항목을 모두 채운다.

1. 상품 ID, 버전, 작업일, 상태, 이번 변경점
2. 상품 목적, 판매 단위, 디자인 옵션 (품목군·SKU·사이즈·생산 개수를 구분)
3. 캐릭터 버전과 기준 이미지 **실제 경로**, 문구 원문, 로고 파일
4. 고정할 요소 / 변경 가능한 요소 / 금지 사항
5. 정면·뒷면·측면·인쇄 전개 등 필요한 면과 그래픽 배치
6. 치수·소재·공법 표
7. 샘플 이미지 생성 프롬프트와 수정 프롬프트
8. 품목별 시각 검수 및 실물 샘플 확인 항목
9. 선택 결과, 미정 사항, 다음 작업

### 2-3. 수치 표기 규칙

- 치수는 **mm**, 원단 중량은 해당 단위, 용량은 **mL**처럼 단위를 반드시 적는다.
- 모든 수치에 상태를 붙인다.

| 상태 | 뜻 |
|---|---|
| 확정 | 담당자가 결정했거나 업체·규격 자료로 확인된 값 |
| 디자인 제안값 | 디자인 검토를 위해 작성자가 제안한 값. 검증 전 |
| 업체 확인 필요값 | 업체 템플릿·견적·샘플로 확인해야 하는 값 |

- 캐릭터 세계관상의 키를 실제 굿즈 높이로 가져오지 않는다.
- 재단선·도련·최소 획·색상 수는 **업체 템플릿을 받은 뒤** 확정한다.
- 근거 없이 "생산 가능"이라고 판정하지 않는다. 판정은 업체 확인 뒤에 쓴다.

### 2-4. 이미지 생성 하네스: 작업 카드

생성하기 전에 작업 카드를 채운다. (시트 6장에 같은 양식이 있다.)

```yaml
작업_ID: D03-01_v01_A
생성도구: ChatGPT
첨부한_참조파일: 실제_경로_목록
품목: 입력
목적: 상품_샘플이미지
상태: 검토용_시안
선택_캐릭터버전: 성체_또는_아기_명시
캐릭터_기준파일: 실제_경로
로고_기준파일: 실제_경로_또는_이번면_미노출
기존상품_참고파일: 실제_경로_또는_없음
참고역할: 캐릭터정체성_로고_소재_구도_각각구분
문구_원문과줄바꿈: 입력_또는_문구없음
규격: 제안값_또는_확정값과단위
재질과공법: 제안_또는_확정
필수_시점: 정면_뒷면_측면_등
고정할것: 입력
이번에_바꿀것: 입력
출력_파일명: 입력
미정사항: 입력
```

- **생성 도구는 ChatGPT의 이미지 생성이다** (2026-11-17 담당자 결정).
  - 작업 카드의 기준 파일(캐릭터·로고·기존 상품)을 **실제로 첨부**하고, 첨부한 파일 목록을 작업 카드에 적는다.
  - 참조 이미지를 볼 수 없거나 첨부가 빠졌으면 그 사실을 알리고, 문자 설명만으로 같은 재현을 보장하지 않는다.
  - 한 번에 작업 카드 1개씩 요청한다. 결과를 저장할 때 작업 ID, 생성 날짜, 사용한 프롬프트 원문을 함께 남긴다.
  - ChatGPT가 만든 이미지의 캐릭터 재현·한글 표기는 보장되지 않는다. 검수(H01~H04)를 거치고, 한글이 틀리면 후편집으로 합성한다 (D01 2-4절).
- 여러 레퍼런스는 "캐릭터 정체성"과 "사진 구도·소재 참고"의 역할을 구분해서 적는다.
- 캐릭터 버전이 미지정이면 최종 샘플 생성을 보류한다 (D01 2-2절).

### 2-5. 공통 생성 프롬프트

아래 문장에 작업 카드와 품목 시트를 붙이고, 실제 기준 이미지를 첨부한다.

> 대사투(대구 사투리 페스티벌)의 대구 얼라들 공식 굿즈 검토용 상품 샘플을 만든다. 첨부한 선택 버전의 대키미·외지몽을 동일 캐릭터로 재현한다. 캐릭터별 귀·더듬이 2개·얼굴·색상·주둥이·신체 비율을 유지한다. 성체와 아기 버전을 섞지 않는다. 로고를 노출하는 면에는 승인 로고 원본을 사용하고 글자·행성 구조·민트/코랄 배색을 바꾸지 않는다. 문구는 작업 카드의 원문과 줄바꿈 그대로 적용한다. 상품의 실제 재질·구조·인쇄 면에 맞게 표현하며 정확한 치수와 기능이 검증된 것으로 주장하지 않는다. 작업 카드에 없는 문구·캐릭터·장식·다른 브랜드를 추가하지 않는다. 이번 작업의 고정 요소와 변경 요소를 지키고, 상품을 자르지 않은 비교 가능한 시점으로 출력한다. 읽히지 않는 한글·누락된 부품·불가능한 연결 구조는 검수 실패로 보고 수정한다.

- 축제 이름을 상품이나 프롬프트에 넣을 때는 P0-1 2-0 표기(줄임 "대사투" / 풀네임 "대구 사투리 페스티벌")만 쓴다. "대사투 페스티벌"처럼 섞어 쓰지 않는다 (P0-10 금지 17번).
- 품목에서만 추가하는 문장은 시트 7장에 적는다.

### 2-6. 출력 형식

- 한 품목에 같은 기본 모델·조명·배경을 쓴다. 비교안은 우선 **배치·크기 등 한두 요소만** 바꾼다.
- 기본 상품 컷은 밝은 중립 배경, 부드러운 조명, 전체 외형이 보이는 구도로 한다.
- **치수 설명용 정투영 도안**과 **분위기용 실사 목업**을 구분한다. 원근이 있는 목업을 실측했다고 쓰지 않는다.
- 필요한 면은 별도 컷으로 만든다. 티셔츠 앞뒷면, 머리띠 구조, 텀블러 곡면 전체를 한 시점으로 검증하지 않는다.
- 상품에 인쇄되는 그래픽과 시트 바깥의 제목·주석을 구분한다. 샘플 컷의 표기는 **"검토용 시안"** 으로 한다.
- 평면 그래픽에 투명 배경이 필요하면 명시한다. 흰 배경 파일을 투명 배경이라고 전달하지 않는다.
- 파일명: `D0301_아크릴키링_대키미_성체_A_v01_정면.png`. 품목 번호는 폴더와 같은 `D03-NN`을 쓴다 (2026-11-17 담당자 결정). 수정하면 v02로 올리고 **원본은 보존**한다.

### 2-7. 검수와 점수

- 생성한 모든 이미지는 **D01의 H01~H07**로 검수한다. 결과 표와 판정 기준(통과 / 수정 필요 / 확인 불가 / 해당 없음)은 D01 2-5절과 같다.
- H01~H07 중 하나라도 "수정 필요"면 선택안으로 넘기지 않는다.
- 필수 검수를 통과한 뒤에만 4항목(캐릭터 매력, 사투리 전달력, 가독성, 품목 간 통일성)을 1~5점으로 비교한다. 점수는 참고용이고 필수 위반을 상쇄하지 않는다.

### 2-8. 수정 루프

1. 원본과 결과를 나란히 보고 **오류 위치·기대값·실제값**을 기록한다.
2. 이번 수정은 가장 큰 오류 **1~2개**만 대상으로 한다. 합격한 요소는 보존한다.
