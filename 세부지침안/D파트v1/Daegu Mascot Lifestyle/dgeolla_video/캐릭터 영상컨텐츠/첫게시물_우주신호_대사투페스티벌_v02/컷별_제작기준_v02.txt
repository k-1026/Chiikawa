대구 얼라들 · 우주 신호와 대사투 페스티벌 · 제작기준 v02
성체 캐릭터 / 캐러셀 12장 = 영상 12컷 / 최종 편집 60초
두류 야외음악당에서 열리는 가상의 대구 사투리 토론 축제. 가칭: 대사투 페스티벌.
기존 6컷 v01을 대체하는 새 이야기. 기존 파일은 보존한다.

01 00–05초 / 우주 항해 / 얼라별과 지구 사이에서 외지몽이 우주선을 조종. 지구가 전방에 보인다.
02 05–10초 / 신호 수신 / 지구 위를 지나던 중 축제 방송 신호를 감지. 계기판 파형과 물음표.
03 10–15초 / 대구를 향해 / 지구 → 대한민국 → 대구. 대구에서 신호가 퍼짐. 우주선이 진로를 바꾼다.
04 15–20초 / 대구 착륙 / 두류 야외음악당 인근 빈 공간에 착륙. 외지몽이 내린다.
05 20–25초 / 축제 탐험 / 잔디광장, 실제 장소를 참고한 야외무대, 축제 부스. 대사투 페스티벌 현수막.
06 25–30초 / 대키미 발견 / 잔디광장 놀이 부스에서 고리 던지기를 하는 대키미와 눈이 마주친다.
07 30–35초 / 아직은 물음표 / 마주 보고 인사. 대키미 말풍선 …!, 외지몽 말풍선 ?. 서로 이해 못하지만 우호적.
08 35–40초 / 번역기 작동 / 외지몽이 번역기를 들어 올린다. ! 표시. 엉킨 파형이 정렬된다.
09 40–45초 / 친구가 된 순간 / 같은 기호 말풍선, 이해한 미소, 하이파이브.
10 45–50초 / 함께 노는 축제 / 같은 고리 던지기 놀이를 함께 즐긴다. 외지몽이 던지고 대키미가 응원.
11 50–55초 / 굿즈샵 구경 / 축제 내 대구 얼라들 부스. 자신들을 닮은 키링인형을 가리키며 구경.
12 55–60초 / 대구에서 생긴 친구 / 두 친구가 잔디광장을 나란히 걷는다. 표현이 달라도, 친구가 된다.

공통 규칙
- 캐러셀과 영상은 같은 사건·같은 순서. 위 5초는 편집상 시간이며 생성 모델의 지원 길이는 실행 시 확인.
- 영상은 음성 대사와 내레이션 없음. …, ?, ! 등 말풍선으로 대화 암시.
- 효과음: 우주선 엔진 → 신호 수신음 → 착륙 → 축제 앰비언스 → 번역기 작동음 → 하이파이브 → 놀이/발소리.
- 군중 앰비언스도 알아들을 수 있는 대사를 요구하지 않는다.
- 작은 글씨, 지도 라벨, 말풍선, 로고, 현수막은 최종 제작 때 후편집 권장.
- 한 페이지 전체를 영상 시작 이미지로 사용하지 않는다. 장면별 문구 없는 시작 이미지를 별도 제작.
- 캐러셀은 각 장 4:5, 영상은 9:16. 핵심 캐릭터와 동작을 중앙에 두고 매체별로 배경 여백 확보.
- 원페이지 그림은 장면·구도 검토용이며, 개별 업로드용 캐러셀이나 실제 영상 결과물이 아니다.
- 성체 원본 우선. 아기 버전/새 털 재질 금지. 대키미 핑크 리본은 꼬리에만. 외지몽은 크림 주둥이·배·꼬리 끝 유지.
- 번역기의 기존 확정 디자인은 폴더에서 발견되지 않아 크림/민트 휴대형 화면 장치로 임시 시각화.
- 굿즈 부스는 세계관 속 브랜드 판타지. 실제 제품 판매/출시를 알리는 광고가 아니다.
- 무대·잔디광장은 두류 야외음악당을 참고한 양식화 이미지이며 실제 축제 개최를 주장하지 않는다.
