S02 조종석 반응 · 제작 이미지 패키지 v02

영상 목표: 세로9:16, 최종 편집3초.
외지몽이 창밖 정면을 보다가 오른쪽 아래 기존 조종간 쪽으로 고개를 조금 돌리고 멈추는 장면.
첫 S01–S03 구간과 같은 귀여운 3D 애니메이션. 실사 강아지·털 재질·아기 버전으로 변경하지 않음.

생성 프레임
01_START_정면주시.png: 기본 시작 프레임. 이미지→영상의 시작 이미지로 사용.
02_MID_시선이동.png: 약1.5초 동작 참고. 시작 이미지와 동시에 여러 장을 받는 기능이 실제 지원되는 경우에만 용도를 지정.
03_END_조종간주시.png: 약3초 종료 포즈 참고. 끝 프레임 입력을 실제 지원하면 종료 프레임으로 사용.
중간/종료 프레임은 새 표정·동작의 참고용 생성 이미지이며 픽셀 단위 동일 배경·3D 형상을 보장하지 않음.

원본 레퍼런스
references/01_외지몽_성체정면.png: 고유 얼굴·몸비율 기준.
references/02_외지몽_성체측면.png: 머리 앞뒤 폭·귀·3/4 시점 기준.
references/03_우주선_닫힘6방향.png: 닫힌 캐노피·한 좌석·조종간·외부 구조의 우선 기준.
references/04_탑승크기_검토참고.png: 기존 탑승 검토 시안. 인물 배치 참고만. 캐릭터 원본이나 닫힌6방향 구조를 대체하지 않음.

검수 반영
이전 S02 샘플의 이중 캐노피/열린 뚜껑처럼 보이는 외부 프레임을 새 이미지의 기준으로 사용하지 않았음.
새 구도는 카메라가 닫힌 조종석 안에 있는 클로즈업. 화면 위에 별도의 열린 캐노피/초록 아치 없음.
한 개의 닫힌 투명창, 크림 좌석, 두 개의 조종간과 중앙 낮은 버튼을 유지.
조종석의 보이지 않는 뒷면이나 정밀3D 내부 구조까지 승인/확정한 자료는 아님.

가장 간단한 실행
1. Claude에 01_START와 원본 정면·측면·닫힘6방향을 첨부.
2. 01_Claude에붙일프롬프트.txt 내용을 메시지로 붙여넣기.
3. 영상 도구의 실제 지원 입력을 확인. 기본은 START 한 장으로 영상 생성.
4. 끝 프레임을 지원하면 END 추가. MID는 동작 설명 참고로만 사용해도 됨.
5. 제목·글씨·말풍선·물음표는 넣지 않은 원본 이미지임. ?와 신호음은 후편집.

표정/동작 범위
몸·팔·손·좌석·조종간은 제자리. 얼굴형과 주둥이를 바꾸지 않음.
시작→중간 약3–4도→종료 약6–8도의 작은 고개 이동.
입 모양은 기본 미소 유지, 말하는 입·크게 벌어지는 입·고개 깊게 숙이기 없음.
열린 눈의 별/마름모 무늬는 눈 표면의 고유 디자인. 시선 이동을 이유로 패턴 위치를 재설계하지 않음.
모델이 복수 키프레임을 지원하지 않는데 세 이미지를 붙여 영상화하지 않음. 3장을 나란히 붙인 연락시트를 시작 프레임으로 사용하지 않음.

파일 상태
이번 패키지는 새 시작/중간/종료 이미지와 원본 레퍼런스, 생성 프롬프트, 영상화 지시를 제공.
실제 동영상은 아직 생성하지 않았음. 이전 오류 샘플은 이 압축에 포함하지 않음.
