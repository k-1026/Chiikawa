# C-1. 구성·배치 — 지침

> 근거: `기본지침서 v1.1` 3장 "소상공인 플리마켓 — 위치·규모"
> 구분: 고정 + 조건부(부스 수는 최소 기준, 세부 구성은 조건부 변경 가능)

## 1. 위치

> **결정(2026-11-10)**: 플리마켓을 체육공원에 독립 구역으로 두지 않고, **공원순환로 위 7구 맛집거리(B-4)와 연결된 구간**에 배치하는 것으로 변경한다. 최소 15동은 유지한다.

- 공원순환로의 7구 맛집거리 일방향 동선(B-1 2절) 뒤쪽 또는 옆에 플리마켓 구간을 이어 붙여, 방문객이 맛집거리를 지나며 자연스럽게 플리마켓으로 이어지게 한다.
- 7구 맛집거리와 같은 공원순환로를 쓰므로, 동선 설계(B-1 2절 일방향 동선·비상 차량 이동로)와 화기 부스 배치 원칙(B-1 3절)을 플리마켓 구간에도 함께 적용한다 — 플리마켓은 화기를 쓰지 않지만(조리 음식 판매 제외, C-2), 통행로 폭·비상 차량 이동로 확보는 동일하게 지켜야 한다.
- B-1은 10미 포장마차·7구 맛집거리·굿즈 상점만 다루도록 정리했고(플리마켓 제외), 플리마켓 배치는 여기 C-1에서 다룬다.

## 2. 구성 (최소안)

| 구성 | 부스 수 |
| --- | --- |
| 로컬 상품 판매 | 12동 |
| 체험·협업 | 3동 |
| 합계 | 15동 |

- 이 구성비는 `[가정]`이다 — 매년 신청 현황(판매 vs 체험 비율)에 따라 조정할 수 있다.

## 3. 확장 기준

- 15동은 최소 기준이다. 첫해는 최소 규모로 시작한다.
- 매년 **셀러 매출·만족도 데이터**를 쌓으면서 연도별로 부스 수를 조정·확장한다(11장 KPI, 12장 연도별 개선).
- 확장 우선순위: 판매 부스가 체험 부스보다 신청 경쟁률이 높았던 해에는 판매 부스를 먼저 늘리고, 그 반대면 체험 부스를 늘린다. ❓ 구체적인 확장 비율·상한은 팀 확인 필요

## 4. 변경 범위

- **고정**: 공원순환로 내 7구 맛집거리 연결 구간 배치, 최소 15동
- **조건부 변경**: 판매·체험 비율, 부스 수(최소 이상), 맛집거리 대비 정확한 위치(앞/뒤/옆)
