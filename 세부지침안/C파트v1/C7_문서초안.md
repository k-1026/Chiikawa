> C-1~C-6 지침을 바탕으로 작성한 초안. ❓ 표시 항목은 연도별 확정값을 채워야 발행 가능.

## 1. 소상공인 플리마켓 셀러 모집 공고 (초안)

### 2027 대구 사투리 축제 「타지에서 온 말손님」 — 소상공인 플리마켓 셀러 모집

대구 사투리 축제는 지역 소상공인·로컬 브랜드와 함께하는 플리마켓 셀러를 모집합니다. 축제장(야외음악당 뒤 체육공원)에서 로컬 상품을 소개하고, 축제 방문객과 직접 만나는 자리입니다.

**모집 분야**

| 구성 | 부스 수 |
| --- | --- |
| 로컬 상품 판매 | 12동 |
| 체험·협업 | 3동 |

**참가 자격**

- 대구 소재 소상공인·로컬 브랜드(사업자등록 보유) 우선
- 품목: 핸드메이드, 로컬 굿즈·디자인 상품, 대구 특산 가공품(영업 신고 업체만), 체험
- **조리 음식 판매 불가** (먹거리는 10미 포장마차·7구 맛집거리 구역에서만 운영)
- 축제 공식 굿즈(마스코트)와 같은 품목 불가

**모집 일정** ❓ (연도별 확정)

| 시점 | 내용 |
| --- | --- |
| D-90 | 모집 공고 게시, 계획서 접수 시작 |
| D-70 | 접수 마감 |
| D-60 | 심사 결과 발표 |
| D-50 | 참여 확정, 부스 배치 안내 |

**제출 서류 (계획서)**

1. 사업자 정보
2. 판매 품목·가격표
3. 대구 연계성 소개
4. 부스 연출안
5. 체험 운영 여부
6. 예상 판매 수량

**선정 기준 (100점)**

| 항목 | 배점 |
| --- | --- |
| 대구 로컬성 | 30 |
| 상품성·독창성 | 30 |
| 가격 적정성 | 20 |
| 사투리·대구 테마 연계 (가점) | 20 |

- 동점 시 대구 로컬성 점수가 높은 셀러를 우선 선정합니다.
- 비슷한 품목이 몰리지 않도록, 이미 선정된 품목과 겹치는 신청은 상품성·독창성 항목에서 낮게 평가될 수 있습니다.

**참가비·수수료**

- 참가비 없음
- 판매 수익의 **5.3%**를 수수료로 받습니다.
- 정산 방식: 축제 공용 결제 단말기·QR 결제 사용 ❓ (연도별 확정) / 현금 판매분은 아래 "2. 판매 기록 양식"을 작성해 제출

**운영 시간**

- 15:00~22:00, 그늘 텐트(몽골텐트) 제공, 우천 시 텐트 연결

**연계 혜택**

- 플리마켓에서 구매한 방문객에게 스탬프를 적립해 드리며, 축제 공식 굿즈 상점에서 교환할 수 있습니다.

**문의처**

- ❓ 담당 부서·연락처는 주최 측 확정 후 기입
