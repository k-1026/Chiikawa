# E-4. 운영 기준

> 구분: 연도별 · 기본 지침: 4장 (인력 구분·안전은 9장 참조) · 진행: 확정 v1 (담당자 확인, 팀 검토 전) · 최종 수정: 2026-11-16 01:58
> 목차: [E-00_목차.md](E-00_목차.md)

## 0. 이전 버전과 달라진 점

- 첫 버전이에요.

## 1. 이 파트의 역할

- 채택된 부대 프로그램을 **실제로 어떻게 운영할지** 정하는 기준이에요. 운영 시간, 수용 인원, 필요한 역할, 장소 형태, 비 올 때 대응, 참여 접수 방법을 다뤄요.
- 숫자는 미리 정하지 않아요. 대신 **"어떻게 계산하는지"** 를 정해 두고, 실제 숫자는 매년 견적·현장 테스트·전년 기록을 받아 채워요.
- 인원수와 배치표는 H-2(운영 인력), 금액은 H-1(운영 예산)이 정해요. E-4는 그 파트에 넘길 근거를 만들어요.
- 언제·어디에 둘지는 E-3, 어떤 유형인지는 E-1을 따라요.

## 2. 확정 값

### 2-1. 운영 시간

- 모든 프로그램은 **개장(15:00)과 폐막 사이**에서 운영한다. 폐막은 현재 기준값 금·토 22:00 / 일 20:00이다 (E-3 2-1).
- 낮·야간 배치와 A 메인 무대 충돌 규칙은 E-3을 따른다.
- 유형에 따라 적는 방법이 다르다.

| E-1 유형 | 운영 시간을 적는 방법 |
|---|---|
| ① 체험 · ⑤ 전시 (상시형, 한 곳) | 시작 시각 ~ 종료 시각 |
| ② 미션 (상시형, 이동) | 참여 시작 ~ 마지막 참여 접수 시각 ~ 완주 확인 마감 시각 |
| ⑥ 순회 (상시형, 이동) | 순회 시각 + **출연자 휴식 시간** (예: 몇 분 순회 후 몇 분 휴식) |
| ③ 대회 · ④ 이벤트 · ⑦ 무대 (정해진 시각형, 한 곳) | 한 회 몇 분 × 하루 몇 회 + 회차 사이 준비 시간 |
| ⑧ 투어 (정해진 시각형, 이동) | 출발 시각 × 하루 몇 회 + 한 회 소요 시간 + **진행자 휴식 시간** |

- 낮(15:00~19:00)에 움직이는 프로그램은 휴식 시간을 더 짧은 간격으로 둔다 (E-3 2-3, 기본 지침 9장 폭염 대응). `[해석]`

### 2-2. 수용 인원: 계산 방법

수용 인원은 E-1의 **계획 단위**로 계산한다.

| E-1 유형 | 계획 단위 | 계산식 | 필요한 입력값 |
|---|---|---|---|
| ① 체험 | 시간당 처리 인원 | 60 ÷ (1명당 소요 분) × 동시에 할 수 있는 자리 수 | 1명당 소요 분, 자리(작업자) 수 |
| ② 미션 | 지점 수, 참여·완주 수 | 가장 붐비는 지점의 시간당 처리 인원이 전체 한계 | 지점 수, 지점당 처리 시간 |
| ③ 대회 | 참가 정원 | 규칙으로 정한 참가 정원 (+ 관람 공간은 ⑦처럼 계산) | 참가 정원, 관람 공간 |
| ④ 이벤트 | 회차 정원 × 회차 수 | 한 회 정원 × 하루 회차 수 | 공간·재료로 정해지는 한 회 정원 |
| ⑤ 전시 | 동시 관람 인원 | 동시 관람 인원 × (운영 분 ÷ 1명 평균 관람 분) | 공간 넓이, 장비 수(헤드폰 등), 평균 관람 시간 |
| ⑥ 순회 | 출연 팀 수 | 관객 수는 세지 않는다. 출연 팀 수와 순회 구역으로 계획 | 팀 수, 구역 |
| ⑦ 무대 | 좌석·관람 공간 | 좌석(관람 공간) 수 × 회차 수 | 좌석 수, 관람 공간 넓이 |
| ⑧ 투어 | 회차 정원 | 한 회 정원 × 하루 회차 수 | 경로 폭·안전으로 정해지는 한 회 정원 |

> 이해를 돕기 위한 **가상 숫자**다. 실제 값이 아니다.
> - 체험: 1명당 5분, 자리 2개 → 60 ÷ 5 × 2 = 시간당 약 24명. 4시간 운영이면 하루 약 96명.
> - 이벤트: 한 회 20명 × 하루 3회 = 하루 60명.
> - 전시: 헤드폰 10개, 1명 평균 6분, 4시간(240분) 운영 → 10 × (240 ÷ 6) = 하루 약 400명.

**숫자를 적을 때의 규칙**

- 모든 수용 인원 숫자에 `[추정]` 라벨과 근거(견적, 현장 테스트, 전년 기록, 사례)를 붙인다.
- 모든 수용 인원 숫자에 **"전문가 검토 필요"** 를 표시한다. 안전과 관련된 숫자이기 때문이다 (노션 H-4의 표시 방식을 E에도 적용, 2026-11-16 담당자 결정).
- 근거가 없으면 숫자를 쓰지 않고 8장 미확정으로 보낸다.
- 첫해는 실제 대기 시간과 회차별 참여 수를 기록해 기준선으로 삼는다 (기본 지침 4-0 "첫해, 기준선 수집"). 2년 차부터는 전년 기록을 근거로 쓴다.

### 2-3. 필요 인력: 역할만 적기

- E-4는 프로그램마다 **필요한 역할, 하는 일, 필요한 이유**만 적는다. **인원수와 일자·시간대별 배치는 H-2가 정한다.**
- 역할은 기본 지침 9장의 인력 구분(총괄, 프로그램 운영, 부스 관리, 안전·의료, 홍보·촬영, 자원봉사) 중 어디에 속하는지 함께 적는다.
- 부대 프로그램에서 자주 쓰는 역할 이름 (예시)

| 역할 | 하는 일 | 9장 인력 구분 |
|---|---|---|
| 진행자 | 회차를 이끌고 설명함 (이벤트·무대·투어) | 프로그램 운영 |
| 작업자 | 방문객 한 명씩 체험을 해 줌 (예: 페이스페인팅) | 프로그램 운영 |
| 접수·줄 관리 | 접수, 대기 줄 안내, 마감 안내 | 부스 관리 / 자원봉사 |
| 출연자 | 공연·구연·순회 (외부 섭외일 수 있음, 3-7) | 프로그램 운영 |
| 이동 안전 | 투어·순회 경로 안전, 길 안내 | 안전·의료 |

- 외부 섭외가 필요한 역할(3-7 "외부 섭외")은 섭외 결과와 비용을 지어내지 않는다.

### 2-4. 장소 형태 (E-1 3-2)

| 장소 형태 | 운영할 때 확인할 것 |
|---|---|
| 실내 | 쓸 수 있는 실내 공간이 확인되기 전에는 전제하지 않는다 (E-3 미확정 1) |
| 부스(그늘 텐트) | 필요한 텐트 수, 전기 사용 여부, 대기 줄 공간 (텐트 규격과 배치는 장소·운영 파트와 확인) |
| 무대 | 음향, 객석 그늘(낮), 조명(야간), A 메인 무대와 소리 겹침 (E-3 2-5) |
| 야외 개방 | 낮에는 지양. 둘 때는 이유와 더위 대책 (E-3 2-3) |
| 이동 | 경로, 그늘 지점, 휴식 장소, 야간 조명 (E-3 2-3·2-4) |

### 2-5. 비 올 때 대응 (E-1 3-3)

프로그램마다 미리 셋 중 하나로 분류해 둔다.

| 분류 | 기준 |
|---|---|
| 그대로 운영 | 실내나 텐트 아래에서 하고, 장비와 재료가 젖지 않는다 |
| 축소·이전 운영 | 야외 부분이 있지만 텐트·실내로 옮기거나 회차를 줄여 운영할 수 있다 |
| 취소 | 전기·미끄럼·이동 안전 위험이 있고, 옮길 곳이 없다 |

- E-4는 **미리 분류만** 한다. 당일 운영·중단 판단은 운영 파트의 안전 기준을 따른다 (H-4).
- 취소로 분류한 프로그램은 가능하면 대체 프로그램을 함께 적는다. `[해석]`

### 2-6. 참여 접수 (E-1 3-4)

| 방식 | 운영 기준 |
|---|---|
| 자유 참여 | 정원 없음. 대기 줄이 길어질 때의 안내 방법을 적는다 |
| 현장 접수 (선착순) | 접수 시작 시각과 장소, 마감 표시 방법, 대기 안내를 적는다 |
| 사전 신청 | 신청 채널(K 웹페이지), 신청 기간, 불참자 대비 현장 추가 접수 여부를 적는다 |

- 접수할 때 받는 정보는 꼭 필요한 것만 받는다. 개인정보 없이 하는 방법을 먼저 검토한다 (기본 지침 4-0, E-1 3-6).

### 2-7. 비용 (E-1 3-5)

- 무료 / 부분 유료 / 유료 구분만 적는다. **금액은 H-1(운영 예산)이 정한다.**
- 기준은 **방문객이 프로그램에 직접 내는 돈**이다. 주최 측이 쓰는 운영비(섭외비, 재료 구입비 등)는 이 구분과 상관없이 H-1에서 다룬다.

| 구분 | 정의 | 예 (가상) |
|---|---|---|
| 무료 | 방문객이 참여·관람하는 데 돈을 내지 않는다. 기본 재료와 결과물도 무료로 받는다 | 사투리 듣기 전시 관람 |
| 부분 유료 | 기본 참여·관람은 무료다. 방문객이 고르는 추가 항목에만 돈을 낸다 | 네컷 촬영은 무료, 추가 인화만 유료 |
| 유료 | 참여하려면 돈을 내야 한다 (참가비, 재료비 포함) | 재료비를 받는 체험 클래스 |

**판정 질문**

1. 방문객이 이 프로그램을 하려면 돈을 꼭 내야 하는가? → 예: **유료**
2. 아니라면, 돈을 내면 더 받을 수 있는 것이 있는가? → 예: **부분 유료** / 아니요: **무료**

- 돌려받는 보증금(예: 장비 대여 보증금)은 방문객이 내는 돈으로 보지 않는다.
- 위 예는 이해를 돕기 위한 가상 예시이며, 실제 후보의 비용 구분은 정해지지 않았다.

## 3. 에이전트 행동 규칙

**연도별 작성 (매년 새로 작성)**

- 채택된 프로그램마다 4장 "운영 기준표"를 만든다.
- 수용 인원은 2-2 계산식으로 구하고, 입력값과 근거를 함께 적는다.
- 필요 역할을 정리해 H-2에 넘긴다. 인원수는 적지 않는다.
- 첫해는 기준선 수집표를 함께 만든다. 2년 차부터는 전년 기록으로 입력값을 고친다.

**금지**

- 수용 인원, 인원수, 비용, 섭외 결과를 근거 없이 쓰지 않는다 (기본 지침 7장).
- 수용 인원 숫자에서 `[추정]` 라벨과 "전문가 검토 필요" 표시를 빼지 않는다.
- 인원수·배치표(H-2)와 금액(H-1)을 E-4가 대신 정하지 않는다.
- 확인되지 않은 실내 공간을 쓸 수 있는 것처럼 계획하지 않는다.
- 다른 파트 지침의 규칙을 E에 그대로 넓혀 적용하지 않는다. 필요하면 담당자에게 먼저 확인한다.

## 4. 출력 형식

**1. 운영 기준표** — 프로그램 / E-1 유형 / 운영 시간 / 계획 단위 / 계산식과 입력값 / 수용 인원 `[추정]` / 근거 / 전문가 검토 필요 / 필요 역할 / 장소 형태 / 비 올 때 분류 / 참여 접수 / 비용 구분

**2. 역할표 (H-2 전달용)** — 프로그램 / 역할 / 하는 일 / 필요한 이유 / 9장 인력 구분 / 외부 섭외 여부

**3. 비 올 때 대응표** — 프로그램 / 분류(그대로·축소·이전·취소) / 옮길 곳 / 대체 프로그램

**4. 기준선 수집표 (첫해)** — 프로그램 / 기록할 값(대기 시간, 회차별 참여 수 등) / 기록 방법 / 기록 담당 (측정 계획은 I-2와 맞춤)

**5. 미확정 사항** — # / 항목 / 이유 / 확인 주체 / 확인 기한

## 5. 매년 받을 입력·조사할 항목

| 입력 | 가져올 곳 |
|---|---|
| 채택된 프로그램과 E-1 판정 | E-2 |
| 시간대·장소 배치 | E-3 |
| 1명당 소요 시간, 장비 수, 한 회 정원 | 현장 테스트, 업체 견적, 사례 |
| 장소 넓이, 텐트 규격, 전기 | P0-3(공통) 장소, H(운영) |
| 전년 기록 (대기 시간, 참여 수) | I-5(성과) |
| 예산 범위 | H-1(운영) |

## 6. 다른 파트 연결

| 파트 | 연결 내용 |
|---|---|
| H-1(운영 예산) | 비용 구분을 넘기고 금액을 받음 |
| H-2(운영 인력) | 역할표를 넘기고 인원수·배치표를 받음 |
| H-4(운영 안전) | 수용 인원 전문가 검토, 비 올 때 당일 판단 |
| K(웹페이지) | 사전 신청 기능 |
| I(성과) | 기준선 수집, 측정 계획(I-2), 전년 기록(I-5) |
| P0-3(공통) | 장소 넓이, 실내 공간 |
| E-1, E-2, E-3 | 유형·계획 단위, 채택 후보, 시간대 배치 |

## 7. 노션·기본 지침과 다른 점

- **필요 인력 (2026-11-16):** 노션 E-4는 "운영 시간, 수용 인원, 필요 인력 (→ H)"이에요. E-4는 인력 중 **역할과 이유만** 적고, 인원수와 배치표는 H-2로 넘기기로 했어요 (담당자 결정).
- **수용 인원 (2026-11-16):** 기본 지침 4-2는 부대 프로그램의 필수 항목으로 수용 인원을 요구해요. E-4는 숫자를 미리 정하지 않고 **계산 방법**을 정했어요. 숫자는 매년 `[추정]`과 근거를 붙여 채워요.
- **"전문가 검토 필요" 표시 (2026-11-16):** 노션에서는 H-4(운영 안전)의 표시 방식이에요. 담당자 결정으로 E 프로그램의 수용 인원에도 붙여요.
