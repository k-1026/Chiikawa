## 1. 이 파트의 역할

- E-1은 **프로그램을 만드는 파트가 아니라, 프로그램을 판정하고 분류하는 기준 파트**예요. 매년 바뀌는 프로그램 자체는 E-2에서 다루고, E-1은 매년 똑같이 적용하는 기준만 다뤄요.
- 새 아이디어가 들어오면 아래 순서로 판정해요.

> **소속 판정** → **1차 활동 유형** → **2차 콘텐츠 주제** → **3차 운영 속성** → **통과 조건** → (점수 평가는 M-5)

- 1·2·3차 분류는 서로 독립된 세 축이에요. 다른 축제의 부대 프로그램 사례(E-2 조사)에도 같은 틀로 태그를 붙일 수 있게 일반적으로 만들었어요. 우리 축제에만 쓰는 판단은 소속 판정과 2-2(사투리 쓰는 방식)에 따로 두었어요.
- 이 문서에서 **"방문객"** 은 축제에 온 사람 전체예요. 보는 관객과 직접 하는 참가자를 모두 포함해요.

## 2. 확정 값

### 2-1. 소속 판정: E파트 일인가?

위에서부터 차례로 묻고, 처음 "예"가 나온 곳으로 보낸다.

| 순서 | 질문 | "예"이면 |
|---|---|---|
| 1 | 셀러나 식당 업주가 운영하는가? | B(맛집)·C(플리마켓) |
| 2 | 마스코트(대키미·외지몽)가 주가 되는가? | D(굿즈) |
| 3 | 토론대회·골든벨·뮤지컬·사투리 순회 NPC인가? | A(사투리 콘텐츠) |
| 4 | 판매(장터·푸드트럭)나 편의(쉼터·휴게)인가? | B·C / H(운영) |
| 5 | 축제장 밖에서 진행하는가? | E-5에서 제안하고 G(관광)가 확정 |
| 6 | 위에 해당하지 않고 주최 측이 운영하는가? | **E** |

- E 프로그램에 마스코트를 쓰면 D와 협업한다. 마스코트가 "주"인지 애매한 경우의 세부 기준은 아직 없다. (미확정 1번)
- 다른 파트와 겹치면 후보에서 빼지 않고 **"겹침 확인 필요"** 로 표시한 뒤, 그 파트 담당과 확인할 항목으로 8장에 넣는다.
- 운영 주체 기준의 근거: C파트 v2에서 체험·협업 3동은 셀러 모집 분야이고, 셀러가 계획서에 "체험 운영 여부"를 적어 낸다. `[확인]` (C-1, C-3)

### 2-2. 1차 분류: 활동 유형 (프로그램당 1개만 선택)

**판정 질문**

1. **방문객이** 직접 하는가, 보고 듣는가?
2. **방문객이** 아무 때나 와서 시작하는가, 정해진 시각에 다 같이 시작하는가?
3. 1·2번 답에 따라 둘 중 하나를 묻는다.
   - 직접 + 정해진 시각 → **방문객끼리** 겨루는가?
   - 나머지 → **프로그램이** 한 장소에서 진행되는가, 이동하며 진행되는가?

- 3번 아래 질문의 주어가 "프로그램"인 이유: 순회는 공연자만 움직이고, 미션은 방문객이 움직이고, 투어는 둘 다 움직인다. "프로그램이 한 장소에 고정되어 있는가"로 물어야 세 경우가 모두 맞게 갈린다.
- 답은 **방문객 대부분이 하는 활동**을 기준으로 한다.

| ⑧ | **투어** | 보기 / 정해진 시각 / 이동 | 정해진 시각에 출발해 함께 이동하며 보고 듣는 프로그램 (해설 투어, 퍼레이드 포함) | 회차 정원, 출발 시각, 이동 경로 안전 | 대구 국가유산 야행 야간 해설투어 (④-3) · 인천 개항장 야행 스토리텔링 워킹투어, 정원 600명 매진 (④-6, 언론 보도) | 아직 없음 · 축제장 밖 투어는 E-5에서 제안하고 G가 확정 |

- "이벤트"는 E파트에서 **"정해진 시각 + 직접 + 겨루지 않음"** 의 뜻으로만 쓴다. A-8의 "연도별 이벤트"와는 다른 뜻이다.
- 다른 축제 예시의 "축제 사례 ④-1" 등은 팀 사례 자료의 카드 번호다. 출처가 없는 사례는 넣지 않는다.

**계획 단위란**

계획 단위는 유형마다 **"무엇을 기준으로 숫자를 정하는지"** 다. 실제 숫자는 E-4에서 정하고, 인력은 H가 정한다. 모든 프로그램을 "하루 몇 명"으로만 세면 운영에서 실제로 문제가 되는 것(체험의 대기 줄, 이벤트의 회차 정원, 투어의 이동 안전)을 놓치기 때문에 유형별로 나눈다.

> 아래 숫자는 이해를 돕기 위한 가상 숫자다. 실제 값이 아니다.
> - **체험 → 시간당 처리 인원:** 페이스페인팅이 1명당 5분이고 작업자가 2명이면 시간당 약 24명이다. 대기 줄이 길면 작업자를 늘릴지 판단한다.
> - **이벤트 → 회차 정원 × 회차 수:** 손글씨 클래스를 한 회 20명, 하루 3회 하면 하루 60명이다. 정원이 차면 다음 회차로 안내한다.
> - **전시 → 동시 관람 인원 + 동선:** 듣기 전시에 헤드폰이 10개면 동시에 10명이 듣는다. 들어가는 길과 나오는 길이 엉키지 않게 한다.
> - **투어 → 회차 정원 + 출발 시각 + 경로:** 함께 이동하므로 인원을 제한하고 밤길 안전을 확인한다.

**적용 원칙**

1. 체험 vs 미션: 한 부스 안에서 끝나면 체험, 여러 지점을 돌아야 끝나면 미션이다.
2. 대회 vs 이벤트: 순위나 승패가 있으면 대회, 없으면 이벤트다.
3. 전시 vs 무대: 아무 때나 와서 보면 전시, 시작 시각이 있으면 무대다. 영상도 반복 상영이면 전시, 정해진 시각에 상영하면 무대다.
4. 순회 vs 투어: 공연자만 움직이고 방문객은 우연히 마주치면 순회, 방문객이 함께 출발해 따라가면 투어다.
5. 활동이 섞여 있으면 방문객 대부분이 하는 활동으로 판정한다. 예: 라디오에 사연을 보내는 사람이 있어도 대부분은 듣기만 하므로 무대다.
6. 장소(예: 말손님 사랑방)는 유형이 아니다. 그 안의 프로그램을 하나씩 따로 분류한다.
7. 판매(장터·푸드트럭)와 편의(쉼터·휴게)는 1차 분류에 넣지 않는다.
8. 어디에도 맞지 않으면 "미분류"로 적고 판단 근거를 남긴다. 미분류가 반복되면 유형 추가를 검토한다 (담당자 승인).

### 2-3. 2차 분류: 콘텐츠 주제 (여러 개 선택 가능)

**2-1. 소재 (일반, 다른 축제 사례에도 씀)**

| 소재 | 정의 |
|---|---|
| 음식 | 음식, 식재료, 식문화 |
| 문화예술 | 음악, 미술, 공연예술, 공예 |
| 역사전통 | 역사 자산, 전통문화, 민속 |
| 지역장소 | 지역 명소, 지역 정체성 |
| **언어·사투리** | 말, 방언, 문자 |
| 자연환경 | 자연, 생태, 환경 보호 |
| 스포츠레저 | 신체 활동, 야외 놀이 |
| 캐릭터IP | 캐릭터, 마스코트, 지식재산 |
| 기술디지털 | AR·VR·AI 등 디지털 기술이 핵심인 것 |

- "언어·사투리"는 지역장소에서 떼어 따로 둔다. 묶어 두면 이 축제의 프로그램이 모두 한 칸으로 몰린다.
- 대구에서 열린다는 이유만으로 "지역장소"를 붙이지 않는다. 내용에 실제로 반영될 때만 붙인다.
- 기술을 도구로만 쓴 경우(예: QR 접수)에는 "기술디지털"을 붙이지 않는다.
- "캐릭터IP"가 붙으면 D와 협업이 필요하다는 표시로 쓴다.

**2-2. 사투리 쓰는 방식 (이 축제 전용)**

| 방식 | 뜻 | 예 |
|---|---|---|
| 듣기 | 사투리 소리를 들음 | 사투리 듣기 전시, 라디오 |
| 말하기 | 방문객이 직접 사투리로 말해 봄 | 라디오 사연 낭독 |
| 글자 | 사투리를 글자로 쓰거나 새김 | 네컷 프레임 문구, 타투·페이스페인팅, 빠른 우체통 |
| 이야기 | 사투리에 얽힌 사연·썰 | 라디오 사연, 셀러 1분 자랑 |
| 놀이 | 맞히기·퀴즈·밈 | 억양 맞히기 |

- 한 해 라인업이 한 방식에만 몰리지 않았는지 확인하는 데 쓴다.

### 2-4. 3차 분류: 운영 속성 (속성마다 하나씩 선택)

1·2차가 "무엇을 하는가"라면, 3차는 **"어떻게 운영하는가"** 다.

| # | 속성 | 고를 값 | 쓰는 곳 |
|---|---|---|---|
| 3-1 | 시간대 | 낮 / 야간 / 전 시간 | E-3. 낮과 야간의 경계 시각은 E-3에서 정한다 |
| 3-2 | 장소 형태 | 실내 / 부스(그늘 텐트) / 무대 / 야외 개방 / 이동 | E-3 폭염 배치, E-4 |
| 3-3 | 우천 대응 | 그대로 운영 / 축소·이전 운영 / 취소 | E-4, H(운영) 안전 |
| 3-4 | 참여 접수 | 자유 참여 / 현장 접수(선착순) / 사전 신청 | E-4 수용 인원, K(웹) 신청 기능 |
| 3-5 | 비용 | 무료 / 부분 유료 / 유료 | H-1 예산 (금액은 여기서 정하지 않는다) |
| 3-6 | 개인정보·동의 | 없음 / 개인정보 수집 / 촬영·녹음 동의 / 둘 다 | 기본 지침 4-0, 10장 체크리스트 |
| 3-7 | 운영 방식 | 주최 측 직접 / 다른 파트와 협업 / 외부 섭외(업체·공연자) | 6장 다른 파트 연결, H 인력 |

- 참여 접수가 "자유 참여"면 정원이 없고, 접수를 받으면 정원이 있다.
- "전년 대비 유지·개선·실험"은 분류가 아니라 해마다 붙이는 평가이므로 E-2 출력에 적는다 (기본 지침 4-0).
- 성격상 정해지는 칸만 미리 채운 예
  - 빠른 우체통: 3-6 개인정보 수집 (받는 사람 주소 또는 연락처. 배달 방식에 따라 달라짐)
  - 사투리 라디오: 3-2 무대 / 3-6 개인정보 수집 (사연 접수 시 실명·개인정보 제거 필요, 아이디어 킵 6번 메모)
  - 셀러 1분 자랑: 3-7 다른 파트와 협업 (C)

### 2-5. 통과 조건 (하나라도 걸리면 보류)

| 기준 | 질문 | 근거 |
|---|---|---|
| 윤리 | 할매 말투 콘셉트, 지역 비하, 타지역 조롱, 사투리 비하가 없는가? | 기본 지침 10장 |
| 저작권·초상권 | 도안·프레임·문구·사진·캐릭터의 권리를 확인했는가? | 10장 |
| 폭염 | 낮에 운영한다면 실내나 그늘에서 할 수 있는가? 그늘이 없다면 이유와 더위 대책이 있는가? (E-3 2-3) | 4-2, 9장 |
| 안전 | 피부·위생·화기·혼잡 위험을 점검했는가? | 9장 |
| 개인정보 | 꼭 필요한 것만 받는가? 개인정보 없이 하는 방법이 있는가? | 4-0 |
| 장소·시기 | 두류공원에서 8월 말에 할 수 있는가? | 8장 필수 조건 |
| 공정성 | 외지 방문객도 불리하지 않게 즐길 수 있는가? | 3장 토론 원칙을 응용 `[해석]` |
| 사투리 연결 | 사투리가 자연스럽게 들어가는가, 억지로 붙였는가? | 3장 "억지 삽입 금지" |
| 우천 | 비가 와도 운영할 수 있는가? (못 하면 대안이 있는가) | 9장 |
| 남는 것 | 사진이나 물건처럼 가져가거나 공유할 게 남는가? | 2030 확산, 사투리 정착 목표 `[해석]` |
| 연도 교체 | 연도 주제만 바꿔 매년 다시 쓸 수 있는가? | E-2가 연도별 후보 풀이므로 `[해석]` |

- 점수 평가는 E-1에 따로 만들지 않는다. M-5(메인) 기준(기본 지침 8장 가중치, 3.5 미만 보류)을 따른다.

## 3. 에이전트 행동 규칙

**판정할 때**

- 모든 후보에 2-1 → 2-5 순서를 빠짐없이 적용한다. 순서를 건너뛰지 않는다.
- 1차는 1개만, 2차는 해당하는 것을 모두, 3차는 속성마다 1개씩 고른다. 아직 정해지지 않은 속성은 "미정"으로 적는다.
- 애매한 판정에는 판단 근거를 한 줄로 적는다.
- 다른 파트와 겹치면 "겹침 확인 필요"로 표시하고 8장에 넣는다. 후보에서 임의로 빼지 않는다.
- 다른 축제 사례에 태그를 붙일 때도 같은 1·2·3차 기준을 쓴다. 2-2(사투리 쓰는 방식)는 사투리를 다룬 사례에만 붙인다.

**금지**

- 마스코트가 "주"인지 애매한 경우를 E 또는 D로 임의 확정하지 않는다 (미확정 1번).
- 유형·소재·속성 값을 담당자 승인 없이 추가하거나 바꾸지 않는다.
- 출처 없는 다른 축제 사례를 예시로 넣지 않는다.
- 업체·공연자의 참여 의사나 섭외 결과, 비용, 수용 인원 숫자를 지어내지 않는다 (기본 지침 7장).
- 저작권·초상권을 확인하지 않은 이미지·캐릭터·문구를 확정하지 않는다.
- 별도의 점수표를 만들지 않는다 (M-5 기준을 따름).

## 4. 출력 형식

**1. 프로그램 판정표** — 프로그램 / 소속 판정 / 1차 유형 / 2-1 소재 / 2-2 사투리 방식 / 3-1~3-7 / 통과 조건(통과·보류와 걸린 항목) / 판단 근거 / 겹침 확인

**2. 다른 축제 사례 태그표 (E-2 조사용)** — 축제 / 프로그램 / 1차 유형 / 2-1 소재 / 2-2 사투리 방식(해당 시) / 3차(확인된 속성만) / 출처 / 근거 라벨

**3. 라인업 점검표** — 1차 유형별 개수, 2-2 사투리 방식별 개수 (한쪽에 몰렸는지 확인)

**4. 미확정 사항** — # / 항목 / 이유 / 확인 주체 / 확인 기한

## 7. 노션·기본 지침과 다른 점

- **유형 (2026-11-15, 담당자 결정):** 노션 E-1은 "체험·전시·야간·팝업"이에요. E-1은 1차 8유형(체험·미션·대회·이벤트·전시·순회·무대·투어)으로 바꿨어요. 노션의 4개는 기준이 섞여 있었기 때문이에요. 체험·전시는 활동, 야간은 시간, 팝업은 장소 형태예요. 그래서 "야간"은 3-1 시간대로, "팝업"은 3-2 장소 형태의 "부스"로 옮겼어요. 노션 문구는 담당자가 고칠 예정이에요.

- 부대 프로그램 **후보**를 모아 두는 곳이에요. 여기 있는 것은 모두 후보이고, 확정이 아니에요. 채택 여부는 담당자가 정해요.

## 2. 확정 값

### 2-1. 후보 풀 규칙

- 후보는 확정이 아니다. 후보 목록에 있다는 이유로 섭외·예산·배치를 진행하지 않는다.
- 후보마다 아래 항목을 적는다.
  - E-1 판정: 소속, 1차 유형, 2-1 소재, 2-2 사투리 쓰는 방식, 3차 속성(정해진 것만), 통과 조건에서 확인이 필요한 항목
  - 연도 주제 연결 1줄
  - 주 목표: 체류 / 상권 / 사투리 중 하나 (기본 지침 2장)

  - 출처: 누가 낸 아이디어인지, 참고 사례는 어디서 왔는지
- 다른 파트와 겹치면 빼지 않고 "겹침 확인 필요"로 표시한다 (E-1 규칙).
- 비슷한 후보가 둘 이상이면 하나로 묶고, 출처를 모두 적는다.
- 정해지지 않은 것은 빈칸으로 두지 않고 8장 미확정으로 보낸다.

### 2-5. 후보별 메모

**3. 빠른 우체통**
- 배달 시점은 "일주일 뒤" 또는 "축제 마지막 날"을 검토 중이다 (미확정 3).
- 이름 예 "겁나게", "억수로"는 J(사투리) 검수 대상이다. "겁나게"는 주로 전라도 말로 알려져 있어 대구 축제 이름으로 맞는지 확인이 필요하다. `[해석]`

**4. 사투리 동화구연**
- 신데렐라·콩쥐팥쥐처럼 널리 알려진 동화를 **대구 사투리 대본으로 직접 옮겨** 구연한다. 『애린 왕자』를 그대로 쓰는 것이 아니라, 같은 방식(익숙한 이야기를 사투리로 옮기기)을 참고한다.
- 참고 사례: 『애린 왕자』는 『어린 왕자』를 경상도 사투리로 옮긴 책이다. 번역은 포항 출신 최현애, 출판은 포항의 도서출판 이팝이며 2020년에 나왔다. `[확인]` (검색 결과로 확인, 원문 미확인)
- 저작권 기준
  - 오래된 옛이야기(전래동화, 저작권 보호 기간이 끝난 원작)의 줄거리를 바탕으로 우리가 새로 쓴 사투리 대본은 사용할 수 있다. `[해석]`
  - 특정 출판본(그림책·번역본)의 문장을 그대로 읽거나 그림을 화면에 띄우거나, 영화·애니메이션 판의 캐릭터·노래·장면을 쓰면 권리 확인이 필요하다. 확인 전에는 확정하지 않는다.
  - 최종 판단은 담당자가 관계 기관 기준으로 확인한다 (기본 지침 10장).
- 대본은 J(사투리) 검수를 거친다.

**7. 말손님 사랑방**
- 2027 기획안 초안에서 사랑방은 대구문화예술회관 대관을 **가정**했다 (대관 미확인). 운영 시간 11:00~18:00도 초안 값이라 E파트의 개장 15:00 기준과 다르다.
- 같은 초안의 평가표에서 사랑방은 3.25점이었다. 기본 지침 8장 기준(3.5 미만 보류)으로는 보류 대상이었다. `[확인]` (2027 기획안 초안 80줄)

## 3. 에이전트 행동 규칙

**연도별 작성 (매년 새로 기획)**

- 그해 연도 주제를 받으면 모든 후보의 연도 주제 연결을 다시 쓴다.
- 새 후보를 넣을 때는 출처(제안자 또는 사례 자료)를 반드시 적는다.
- 2년 차부터 전년 대비(유지·개선·실험)를 전년 운영 결과(I-5, I-6)를 근거로 적는다.
- 후보를 채택하면 E-3, E-4, E-5로 넘기고, 이 표에는 "채택 (연도)"으로 표시한다.
- 라인업을 고를 때 E-1 라인업 점검표로 유형·사투리 방식이 한쪽에 몰리지 않았는지 확인한다.

**금지**

- 출처 없는 사례를 후보 근거로 쓰지 않는다.
- 업체·기관·공연자의 참여 의사, 섭외 결과, 비용, 수용 인원 숫자를 지어내지 않는다 (예: 국립한글박물관 콘서트 유치 가능 여부).
- 저작권·초상권을 확인하지 않은 이미지·캐릭터·문구, 특정 출판본의 문장·그림, 영상판의 캐릭터·노래를 확정하지 않는다.
- 할매 말투 콘셉트, 지역 비하, 타지역 조롱, 사투리 비하 표현을 쓰지 않는다.
- 마스코트를 쓰는 후보를 D와 협의 없이 확정하지 않는다.

# E-3. 시간대 배치

> 구분: 조건부 · 기본 지침: 4장, 9장 · 진행: 확정 v1 (담당자 확인, 팀 검토 전) · 최종 수정: 2026-11-16 00:13

## 0. 이전 버전과 달라진 점

- 첫 버전이에요.

## 1. 이 파트의 역할

- 채택된 부대 프로그램을 **언제(낮/야간), 어디에(실내·그늘) 둘지** 정하는 기준이에요. A파트 메인 무대 프로그램(토론대회·골든벨·뮤지컬 등)과 시간이 부딪치지 않게 하는 규칙도 여기서 다뤄요.
- 구분이 **조건부**인 이유는 날씨, 축제 날짜, 장소, A 메인 무대 일정에 따라 배치가 바뀌기 때문이에요.
- 실제 "몇 시에 무엇"을 적는 시각표는 축제 타임테이블 배치 때 A파트와 함께 정해요. E-3은 그때 쓸 기준을 미리 정해 두는 곳이에요.
- 이 문서의 "정해진 시각형"과 "상시형"은 E-1 1차 유형을 시작 방식으로 묶은 말이에요.
  - 정해진 시각형: ③ 대회 · ④ 이벤트 · ⑦ 무대 · ⑧ 투어
  - 상시형: ① 체험 · ② 미션 · ⑤ 전시 · ⑥ 순회

### 2-3. 낮 배치 (15:00 ~ 19:00)

- 낮 프로그램은 **그늘 텐트(E-1 3-2 "부스")를 기본**으로 한다.
- 실내(E-1 3-2 "실내")는 두류공원 안에 쓸 수 있는 실내 공간이 확인되면 추가한다. 확인 전에는 실내를 전제로 배치하지 않는다. (미확정 1)
- 낮에는 그늘이 없는 야외(E-1 3-2 "야외 개방")에 프로그램을 두는 것을 **지양**한다 (기본 지침 9장 폭염 대응). 꼭 두어야 하면 아래를 함께 적는다.
  - 그늘 없는 야외에 두는 이유
  - 더위 대책 (짧은 운영 시간, 가까운 그늘·휴게 존, 물, 쉬는 시간 등)
- 낮에 무대(⑦)를 쓰면 객석에 그늘이 있어야 한다.
- 낮에 움직이는 프로그램(② 미션, ⑥ 순회, ⑧ 투어)은 그늘 지점과 휴식 시간을 함께 정한다.
- 축제 전체 휴게 존은 따로 만든다 (2026-11-15 담당자 확인). 낮 프로그램을 휴게 존 가까이 두는 것을 검토한다. 휴게 존 위치를 정할 파트는 P0-3(공통) 장소 또는 H(운영)로 **예상**한다 (확정 아님). (미확정 5)

### 2-4. 야간 배치 (19:00 ~ 폐막)

- 1박 유도를 위해 저녁·야간 프로그램을 반드시 검토한다 (기본 지침 3장 체류형 설계 원칙).
- **19:30 전에 조명을 켠다.** 2027 예시 날짜 기준으로 19:34~19:36이면 완전히 어두워진다. `[확인]`
- 야간 프로그램이 있는 곳과 귀가 동선의 조명을 확인한다 (기본 지침 9장, H-4).
- 일요일은 폐막이 20:00이라 야간이 1시간(19:00~20:00)뿐이다. 이 시간의 마무리 프로그램이나 폐막식은 **야간 프로그램의 특성**(어두워지는 시각에 맞춘 조명·빛 연출 등)을 살리도록 기획한다. `[해석]`
  - 개막식과 폐막식을 할지는 아직 정하지 않았다 (지금 계획상으로는 하지 않는 쪽으로 검토 중). 한다면 E 프로그램으로 기획한다 (2026-11-16 담당자 의견). (미확정 7)

### 2-5. A 메인 무대 프로그램과 충돌 방지

- 적용 대상: A파트가 메인 무대에서 하는 **모든 프로그램**(토론대회, 골든벨, 뮤지컬 등. A-9 메인 무대 진행 기준). 사투리 순회 NPC는 메인 무대 프로그램이 아니므로 대상이 아니다.

| 구분 | A 메인 무대 프로그램 진행 중 | 쉬는 시간·식사 시간 |
|---|---|---|
| 정해진 시각형 (③ 대회 · ④ 이벤트 · ⑦ 무대 · ⑧ 투어) | 열지 않는다 | E 무대형(라디오 등)을 넣을 수 있는 자리로 본다. 넣을지는 A와 협의 |
| 상시형 (① 체험 · ② 미션 · ⑤ 전시 · ⑥ 순회) | 계속 운영한다. 단, 메인 무대 근처에서는 소리를 내지 않는다 | 계속 운영한다 |

- A 메인 무대 프로그램의 시각은 A파트가 정한다. E-3은 정해진 시각을 받아 충돌 여부만 점검한다.

### 2-6. 개장 직후 유도 프로그램

- 개장 시각(15:00)에 맞춰 방문객이 오게 만드는 프로그램을 **매일 1개 이상** 검토한다.
- 특히 **토·일 개장 직후**에 둔다. 전날 숙박한 방문객이 개장하자마자 다시 올 이유를 만들기 위해서다 (기본 지침 3장 "다음 날 오전 프로그램"을 15:00 개장에 맞춰 적용).
- 15:00은 더운 시간대(체감 33도 이상인 날 61%, `[추정]`)이므로 실내나 그늘에서 하는 프로그램이어야 한다.
- 시작 시각이 분명해야 사람이 맞춰 오므로 정해진 시각형(④ 이벤트, ⑦ 무대 등)을 우선 검토한다. `[해석]`

## 3. 에이전트 행동 규칙

**연도별 작성 (매년 다시 확인)**

- 그해 축제 날짜를 받으면 일몰 시각과 어두워지는 시각을 다시 확인하고, 2-2 표를 고친다.
- 그해 개장·폐막 시각을 확인하고, 바뀌었으면 2-1과 2-2를 고친다.
- A파트에서 메인 무대 프로그램 시각을 받으면 2-5 기준으로 E 프로그램의 충돌을 점검한다.
- 채택된 후보마다 E-1 3-1(시간대)과 3-2(장소 형태)를 정하고 시간대 배치표를 만든다.
- 낮에 그늘 없는 야외에 둘 수밖에 없는 프로그램은 이유와 더위 대책을 배치표에 적는다 (2-3).

**금지**

- A 메인 무대 프로그램 진행 중에 정해진 시각형 프로그램을 두지 않는다.
- A 메인 무대 프로그램 진행 중에 메인 무대 근처에서 소리 나는 프로그램을 두지 않는다.
- 확인되지 않은 실내 공간을 쓸 수 있는 것처럼 배치하지 않는다.
- A 메인 무대 시각, 개장·폐막 시각, 휴게 존 위치를 E-3이 대신 정하지 않는다.
- 개막식·폐막식 개최 여부를 E-3이 임의로 정하지 않는다 (미확정 7).
- 노션 P0-4의 개장 시각(12:00)을 E-3에서 고치지 않는다. 노션 수정은 담당자가 한다.

## 7. 노션·기본 지침과 다른 점

- **개장 시각 (2026-11-12):** 노션 P0-4는 12:00이에요. E파트는 15:00을 기준으로 해요. 노션은 담당자가 나중에 고칠 예정이에요.
- **다음 날 오전 프로그램 (2026-11-15):** 기본 지침 3장은 "다음 날 오전 프로그램(결승 관람, 투어 등) 배치로 숙박 이유 만들기"예요. 축제장이 15:00에 열기 때문에, E-3은 이걸 **"개장 직후 유도 프로그램"** 으로 바꿔 적용했어요.
