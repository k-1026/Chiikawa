# H-10 스탬프 운영 — 세부 지침

> 구분: 고정(운영 규칙) + 연도별(개수·상품) · 기본 지침: 3장 · 진행: 초안 v1 (개수는 제안값) · 최종 수정: 2026-11-18
> 기준 문서: P0-1 스탬프 구조(P세부지침안V12), A-1(A파트v5), B-6(B파트v5), C-6(C파트v3), E-2, I-3, 원본지정표, 담당자 결정 2026-11-18 (3·4번)

## 1. 이 파트의 역할

- 축제장 안 **오프라인 스탬프 북** 운영 전체를 맡는다: 배부, 도장 지급처, 완성 기준, 상품·쿠폰북 교환, 재고, 기록.
- 담당자 결정(2026-11-18)으로 **어디서 도장을 찍을 수 있는지, 몇 개를 모아야 상품을 주는지**도 이 파일(운영안 스탬프 부분)에서 정한다.
- 각 파트(A·B·C·E)는 **자기 부스에서 언제 도장을 찍어 주는지**만 정한다. 동선에서 지급처가 어디에 있는지는 M-6(flow-designer)이 그린다.
- 읽는 파트: A·B·C·E(지급 시점), D(보상 굿즈), M-6(동선), I(기록), K(웹 안내)

## 2. 확정 값

### 2-1. 기본 구조 (이미 정해진 것)

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 형태 | **오프라인 스탬프 북**. 웹 스탬프 없음 | P0-1, A-1 |
| 범위 | **축제장 안에서만**. 축제장 밖 원조 매장 스탬프는 폐지 | P0-1, B-6 |
| 배부 | **운영·안전 부스에서만** 나눠 준다 | P0-1 |
| 완성 보상 | 스탬프 판을 다 모아 운영 부스에 가져오면 **상품 + 쿠폰북** | P0-1 |
| 축제 팔찌 | **없앤다** (다른 파트에서도 제외 예정) | 담당자 결정 2026-11-18 |

### 2-2. 도장 지급처 (담당자 결정 2026-11-18, 4번)

> 체험 부스 + 음식 부스 등 **모든 참여 부스가 자기 도장 1개씩**을 가진다. 도장은 H가 만들어 나눠 주고 축제가 끝나면 회수한다.

| 영역 | 지급처 | 지급 시점 (원본 파트) |
| --- | --- | --- |
| ① 사투리 콘텐츠 | 토론대회 투표 참여, 골든벨 참여, 사투리 순회 NPC 이벤트 | 콘텐츠마다 "하루 1회" 또는 "축제 기간 중 1회" (A-1 스탬프 운영표, 매년) |
| ② 10미 포장마차 | 10미 부스 40동 각각 | 1회 구매당 1개 (B-6 2-4) |
| ③ 7구 맛집거리 | 7구 부스 50동 + 제과점 각각 | 1회 구매당 1개 (B-6 2-4) |
| ④ 소상공인 플리마켓 | 셀러 부스 15동 각각 | 구매 시 (C-6) |
| ⑤ 부대 프로그램 | E 체험·미션 부스 각각 | 참여 시 (E-2 후보별) |

- 굿즈 상점(D-5)과 운영·안전 부스는 지급처가 아니다 (교환처). 굿즈 상점을 지급처에 넣을지는 7장 3번.
- 도장마다 **부스 번호 또는 부스 이름**이 새겨져 있어, 어느 부스에서 받았는지 알 수 있게 한다 (제안).
- 사투리 주문 미션(B-7)의 추가 도장은 B-7 규칙을 따른다.

### 2-3. 지급 규칙

1. 구매·참여 1회에 도장 1개. 구매·참여 없이 도장을 찍어 주지 않는다 (위반은 H-7 6번).
2. **같은 부스 도장은 스탬프 북 1권에 1개만** 인정한다 (제안 — 여러 부스를 돌게 하려는 목적).
3. 스탬프 북은 1인 1권. 축제 3일 동안 이어서 모을 수 있다 (제안).
4. 스탬프 북을 잃어버리면 새로 받되 이전 도장은 인정하지 않는다 (제안).

### 2-4. 완성 기준 (제안 — 담당자 확정 필요)

| 항목 | 제안값 | 이유 |
| --- | --- | --- |
| 완성 칸 수 | **10칸** | B-6이 "미정 시 임시 10개 기준"으로 안내 중 |
| 영역 조건 | 5개 영역(2-2 ①~⑤)에서 **각 1개 이상** + 나머지 5칸 자유 | 3대 핵심 프로그램과 부대 프로그램을 모두 거치게 해 체류·상권 목표(P0-2)에 맞춤 `[해석]` |
| 보상 | 완성 1회에 상품 1개 + 쿠폰북 1권 | P0-1 |
| 상품·쿠폰북 내용 | 매년 담당자가 정함. 쿠폰은 그해 협업처·선정 업소 | P0-1, B-6 |

- NPC 이벤트 스탬프 보상 굿즈(A-1, D)는 스탬프 북 완성 보상과 **별개**다.

### 2-5. 교환·재고·기록

| 항목 | 운영 방법 |
| --- | --- |
| 교환처 | 운영·안전 부스 (위치는 지도 갱신 후, P0-3 미확정 13번) |
| 완성 확인 | 영역 조건·칸 수 확인 → 교환 표시(도장 또는 펀치)로 재사용 막기 |
| 재고 | 스탬프 북·상품·쿠폰북을 날짜별로 배정하고, 교환 시간 동안 남은 수를 운영본부에 알린다. 상품이 떨어지면 "상품 소진" 안내 후 쿠폰북만 지급할지 담당자가 정한다 (7장 4번) |
| 기록 | 날짜별 배부 수, 완성 판 교환 수, 상품·쿠폰북 지급 수 (I-3 수집 데이터) |
| 현장 설문 | 교환할 때 현장 설문(I-4 ⑤) 안내 |

## 3. 에이전트 행동 규칙

1. 완성 칸 수·영역 조건·상품은 담당자 확정 전까지 "제안"으로 쓴다.
2. 웹 스탬프, 축제장 밖 스탬프, 축제 팔찌를 다시 넣지 않는다.
3. 각 파트의 지급 시점(1회 구매당 1개 등)을 H에서 바꾸지 않는다.
4. 지급처 위치는 지도에 있는 부스 위치만 쓴다.
