# H-7 부정적 문제 예방 — 세부 지침

> 구분: 고정 · 기본 지침: 0장 (문화관광축제 점검 항목) · 진행: 초안 v1 · 최종 수정: 2026-11-18
> 기준 문서: B-5 2-5·B-8(B파트v5), C-2·C-3 2-7(C파트v3), 담당자 결정 2026-11-18 (1·2·7번), 치맥페스티벌 2019 소음 기사

## 1. 이 파트의 역할

- 축제 현장에서 생기는 부정적 문제를 **미리 막고, 생기면 같은 기준으로 처리**한다: 부스 규정 위반, 바가지요금, 소음 민원, 쓰레기.
- **부스 규정의 현장 집행**(점검·경고·원상복구·철수)은 H-7이 원본이다. 무엇이 위반인지는 B-5·B-8·C-2·C-3이 정하고, 다음 해 참여 제한도 B-5·C-3이 맡는다.
- 읽는 파트: B·C·D·E(부스 운영), H-2(점검조), H-6(민원 접수), I(기록)

### 2-2. 현장 점검 (담당자 결정 2026-11-18, 2번)

- 운영 부스(현장 점검조)는 **축제 운영일마다 최소 2번** 전 부스를 돌며 2-1 점검표로 점검한다.
  - 1회차: 운영 시간 앞부분 (개장 뒤)
  - 2회차: 운영 시간 뒷부분, 야간 포함 권장 (제안)
  - 매일 개점 전 위생·화기 점검(B-8)은 이 2번과 **별도**다.
- 민원·제보가 들어오면 회차와 관계없이 바로 확인한다.
- 점검 결과는 점검 기록표(날짜·시각·부스·항목·결과·점검자·사진 여부)에 남긴다.

### 2-3. 판단 규칙 (담당자 결정 2026-11-18, 1번)

**경고 대상 위반 (2-1의 1~7번)**

| 적발 | 현장 처리 |
| --- | --- |
| **1회** | **경고** + **원상복구**: 규정을 어긴 것을 처음 상태로 되돌린다 (확장한 집기 철거, 가격표 부착, 품목 판매 중지, 통로 비우기 등). 복구를 확인할 때까지 점검자가 그 자리에서 기다리거나 다시 확인한다 |
| **2회** | **철수**: 그 부스는 축제장에서 빠진다 |

- 적발 횟수는 **축제 3일 전체에서 합산**하고, **위반 종류가 달라도 합산**한다 (B-5·C-3 "경고 누적 2회 합산" 규칙과 같게).
- 원상복구를 하지 않으면 그 자체를 2회째 적발로 본다 (제안, 담당자 확정 필요).

**안전 직결 위반 (8번)** — 제안, 담당자 확정 필요

- 위험이 없어질 때까지 **그 자리에서 판매·조리를 멈추고** 시정한다. 시정하지 않거나 같은 축제 기간에 다시 적발되면 철수한다.

**즉시 제재 대상 (9·10번)**

- B-5·C-3에서 "즉시 다음 해 참여 불가"인 항목이다. 현장에서는 금지 품목을 바로 판매 중지하고, 양도·전대는 원래 선정 업소 확인 전까지 운영을 멈춘다. 당해 철수 여부는 담당자가 정한다 (7장 1번).

**절차**

1. 점검자 확인: 점검표 항목에 해당하는지 확인하고, 시각과 사진을 남긴다.
2. 경고: 서면 경고장(위반 항목·시각·원상복구 내용)을 주고 업소 대표가 확인 서명한다.
3. 철수: 현장 운영 책임자가 승인한 뒤 진행한다. 정산(판매 기록·수수료)은 철수 때 바로 마감한다 (H-1, C-4).
4. 이의 제기: 업소가 이의를 내면 담당자가 기록을 보고 판단한다. 에이전트는 판단하지 않는다.
5. 기록 넘기기: 경고·철수 기록을 B-5·C-3(다음 해 참여 제한)과 I(성과)에 넘긴다.

- 2회 적발로 철수한 업소는 B-5·C-3 규칙에 따라 **다음 해 참여도 제한**된다 (두 규칙은 함께 적용된다).
- ⚠️ 사람이 해야 하는 일: 위반 여부가 애매한 경우(예: 마스코트 "실루엣" 사용)는 사람이 보고 판단한다 (C-6).

### 2-4. 바가지요금 방지

- 모든 부스는 가격을 표시한다 (B-8 2-5). 표시와 다른 가격은 2-1의 2번 위반이다.
- 가격 상한은 모집 단계에서 업소·셀러와 협의한다 (노션 H-7). 상한 값은 담당자가 정한다 (7장 2번).

### 2-5. 소음 관리 기준안 (담당자 결정 2026-11-18, 7번)

**치맥페스티벌 사례에서 배운 것**

- 2019년 대구치맥페스티벌은 마감을 밤 11시로 1시간 늘렸다. 야외음악당 공연은 21:30에 끝났지만 두류야구장 공연이 23:00까지 이어져 주민이 소음 피해를 호소했고, 대구시에 소음 민원 2건이 접수됐다 `[확인]`.
- 대구시와 대구치맥산업협회는 주민에게 양해를 구하고 "쓰레기와 소음 관리를 더 철저히 하겠다"고 했다 `[확인]`. 음량 기준 같은 구체적 규정은 공개 자료에서 **확인 안 됨**.
- 같은 두류공원이므로, **운영 시간을 늘린 날·야외음악당이 아닌 무대**에서 민원이 났다는 점이 우리에게 가장 중요한 교훈이다 `[해석]`.
- 해외 사례: 미국 댈러스 Fair Park는 민원이 이어지자 소음 모니터링, 저음 측정 강화, 무대 위치 조정, 통제 시간 전 음량 낮추기를 했다 `[확인]`.

**기준 1. 시간 (고정)**

| 시간대 | 기준 |
| --- | --- |
| 개장 전 | 음향 점검·리허설은 **개장 2시간 전부터만** 한다 (제안). 아침 이른 시간 음향 점검 금지 |
| 운영 중 | 무대 프로그램은 A파트 타임테이블대로 |
| 폐막 30분 전 | 무대 음량을 낮추고, 저음(베이스)을 줄인다 (제안) |
| 폐막 | **금·토 22:00 / 일 20:00에 모든 음향 종료.** 치맥처럼 운영 시간을 늘리지 않는다 (P0-4) |
| 폐막 뒤 | 철거·정리 때 확성기·음악을 쓰지 않는다 |

**기준 2. 무대·스피커 (고정 + 지도 갱신 후)**

- 무대는 야외음악당 메인 무대 중심으로 둔다. 야외음악당 밖에 무대를 더 둘 때는 주거지와 거리를 지도에서 확인하고 담당자 승인을 받는다 (치맥 2019 교훈).
- 스피커는 주거지 반대쪽을 향하게 둔다. 방향은 지도 갱신 후 무대 배치도에 표시한다.
- 부스는 개별 스피커·확성기를 쓰지 않는다 (제안). 부스 음악을 허용하면 음량 상한을 정해 2-1 점검표에 넣는다.
- 식사존 대형 디스플레이(메인 무대 중계)의 음량도 같은 기준을 따른다.

**기준 3. 점검 (현장 점검 2회와 같이)**

- 현장 점검조(2-2)가 매 회차 **주거지 쪽 경계 지점**에서 소음을 확인한다. 측정 지점은 지도 갱신 후 정한다 (주거지 방향 2곳 이상, 제안).
- 측정 장비(소음계)와 기준 수치는 관할 구청 확성기 사용 기준을 확인한 뒤 정한다 (H-5 11번). 확인 전에는 숫자를 쓰지 않고 "기준 확인 전"으로 둔다.

**기준 4. 주민 사전 안내 (제안)**

- 개최 2주 전까지 주변 주민에게 안내문을 보낸다: 축제 일정, 운영 시간(금·토 22:00 / 일 20:00 종료), 무대 위치, **민원 연락처**.
- 안내문은 M-7 형식으로 만들고 배포 방법(관리사무소·구청 협조)은 담당자가 정한다.

**기준 5. 민원 처리**

| 단계 | 하는 일 | 담당 |
| --- | --- | --- |
| 1. 접수 | 운영본부(H-6)에서 받는다. 시각·위치·내용·연락처(동의 시)를 기록 | 운영본부 |
| 2. 현장 확인 | 접수 즉시 현장 점검조가 민원 위치 쪽에서 음량·스피커 방향 확인 | 현장 점검조 |
| 3. 조치 | 음량 낮추기, 스피커 방향 조정, 해당 무대 진행자에게 전달 | 무대 담당 |
| 4. 회신 | 조치 결과를 민원인에게 알림 (연락처를 받은 경우) | 운영본부 |
| 5. 기록 | 민원 기록표에 결과까지 적고, 같은 위치 민원이 반복되면 담당자에게 보고 | 운영본부 |

### 2-6. 쓰레기 관리 기준안

> 치맥 2019 사례에서 주최 측이 소음과 함께 약속한 것이 쓰레기 관리였다 `[확인]`. 해외 사례로 옥토버페스트는 일회용품 금지와 재활용 분리수거 용기를 두었다 `[확인]` (대구경북연구원 2015 보고서 표 3-5).

**기준 1. 책임 나누기 (고정)**

| 구역 | 책임 | 하는 일 |
| --- | --- | --- |
| 각 부스 안·앞 | **부스 (출점 업소·셀러)** | 부스 쓰레기 분리배출, 음식물 쓰레기 따로 모으기, 영업 종료 때 부스 앞 정리. 어기면 2-1의 7번 위반 |
| 공용 구역 (통로·돗자리 존·테이블 존·식사존) | **H (운영)** | 수거 거점 운영, 정기 수거, 폐장 뒤 전체 청소 |
| 무대·객석 | **A파트 무대 담당 + H** | 공연 뒤 객석 정리 |

**기준 2. 분리배출 종류 (고정)**

| 종류 | 예 |
| --- | --- |
| 일반 쓰레기 | 휴지, 오염된 포장재 |
| 재활용 | 캔·페트병·플라스틱 컵 (헹굼 안내) |
| 음식물 | 남은 음식, 국물 (국물은 따로 버리는 곳) |
| 일회용기 | 다회용기를 쓰면 반납처, 쓰지 않으면 재활용·일반으로 나눔 (H-8 다회용기 결정에 따름) |

**기준 3. 수거 거점 (지도 갱신 후 위치)**

- 거점마다 4종 분리 수거함을 둔다. 거점은 사람이 몰리는 곳을 먼저 둔다: 10미 포장마차·테이블 존, 돗자리 존, 식사존, 7구 맛집거리 끝, 축제 출입로.
- 거점 수와 위치는 지도 갱신 후 정한다. 수거함 수를 지어내지 않는다.
- 거점마다 **분리배출 안내 자원봉사자**를 붐비는 시간에 둔다 (H-2).

**기준 4. 수거 시간 (제안 — 첫해 운영 뒤 조정)**

| 시점 | 하는 일 |
| --- | --- |
| 개장 전 | 전날 남은 쓰레기 없는지 확인 (개점 전 점검과 같이, H-3) |
| 운영 중 | 거점이 차면 바로 비우는 것을 기본으로, 식사 시간대 앞뒤로 정기 수거 |
| 현장 점검 1·2회차 | 부스 앞 쓰레기 상태 점검 (2-1의 7번) |
| 폐장 뒤 | 공용 구역 전체 청소, 음식물 쓰레기 반출 |
| 다음 날 개장 전 | 청소 상태 확인 |

- 음식물 쓰레기 반출 방법(수거 업체·시간)은 관할 구청과 확인한다 (H-5에 줄 추가 필요).

**기준 5. 줄이기**

- 다회용기 적용 범위는 H-8에서 정한다.
- 체험 프로그램은 일회용 재료를 줄인다 (E-1·E-4).
- 굿즈·쿠폰북 포장을 줄인다 (D와 협의).

**기준 6. 기록**

- 날짜별 수거 횟수, 민원(쓰레기 관련), 부스 위반(2-1의 7번)을 기록해 I(성과)와 05_차년도과제에 넘긴다. 수거량을 잴 수 있으면(봉투 수 등) 같이 적는다.

### 2-7. 남은 굿즈 처리 — 기부 원칙 (담당자 결정 2026-11-18)

> 받은 피드백: "굿즈가 남았을 때 폐기·기부는 비용과 기부 대상 기준을 정해야 하고, 기부나 외부 반출 시 로고 사용 조건을 D-1 IP 규칙으로 검토해야 한다."
> 결정: **남은 굿즈는 폐기하지 않고 기부한다.** 기부처는 대구로 제한하지 않고 **전국**으로 하고, **보육원 등 아동복지시설**에 기부한다.

**기준 1. "남은 굿즈"를 정하는 시점**

| 순서 | 단계 | 원본 |
| --- | --- | --- |
| 1 | 현장 판매 종료 → 남은 현장 재고를 온라인으로 넘길지 사람이 정함 | D-6 2-4 |
| 2 | 사후 온라인 판매 D+1 ~ D+30, D+30 판매 집계 | D-6 2-2·2-6 |
| 3 | 다음 해에 다시 팔 품목을 뺀다: 기본 라인(고정 8종) 중 **연도 표기가 없는 품목**은 다음 해 판매로 보관할지 D 담당이 정함 (제안) | D-2, D-6 |
| 4 | 남은 수량 확정 = **기부 대상 재고** (D+30 이후) | D-5 마감 재고 |

- **연도 한정판·현장 한정 굿즈**는 다음 해에 팔지 않으므로(D-6 "한정 약속") 남으면 기부 대상이다.
- **불량품·D-1 검수 불통과품은 기부하지 않는다** (기준 4의 1번). 이것만 폐기 대상이며, 폐기 수량과 이유를 기록한다.

**기준 2. 기부 대상 기준**

| # | 기준 | 상태 |
| --- | --- | --- |
| 1 | 지역: **전국** (대구로 제한하지 않음) | 확정 |
| 2 | 시설: **보육원(아동양육시설) 등 아동복지시설**. 공동생활가정·지역아동센터를 넣을지는 담당자가 정함 | 확정(보육원) / 범위 제안 |
| 3 | 실제 운영 중인 사회복지시설인지 확인한다 (지자체·공공 시설 목록) | 제안 |
| 4 | 기부 전에 시설에 **필요한 물품인지** 묻는다. 아이 나이에 맞지 않는 품목(예: 성인 사이즈 티셔츠)은 보내지 않는다 | 제안 |
| 5 | 한 시설에 몰지 않고 시설 수요에 맞춰 나눈다. 배분 기준(수요 순 / 지역 고르게)은 담당자가 정함 | 제안 |
| 6 | 기부금 영수증이 필요하면 시설이 발급할 수 있는지 **기부 전에** 확인한다 | 제안 |

- ⚠️ 사람이 해야 하는 일: 시설 연락·수요 확인·기부처 확정은 담당자가 한다. 에이전트는 후보 목록과 확인 항목만 만든다.

**기준 3. 비용 기준**

| 비용 | 내용 | 예산 위치 |
| --- | --- | --- |
| 포장·배송비 | 전국 택배·화물. 시설별 묶음 배송 | H-1 "기타 — 기부 배송비" |
| 인력 | 분류·포장·발송 (D+30 이후) | H-2 |
| 서류 | 기부 확인서, 기부금 영수증 처리 | H-1 |

- **배송비가 기부 물품 가치보다 커지는 경우**는 같은 지역 시설끼리 묶어 보내거나 수량을 조정한다 (제안). 판단은 담당자가 한다.
- 기부 물품의 가액 산정과 세무 처리(기부금 종류, 장부가액 기준 등)는 주최 형태에 따라 달라서 **세무 확인**이 필요하다 `[해석]` (H-5 18번). 에이전트는 금액을 산정하지 않는다.

**기준 4. 로고·IP 조건 (D-1 검토 필수)**

| # | 조건 | 이유 |
| --- | --- | --- |
| 1 | D-1 검수(H01~H07)를 **통과한 정품 그대로** 기부한다. 불량·검수 불통과품은 기부하지 않는다 | 축제 밖에서 브랜드 이미지 손상 방지 |
| 2 | 기부를 위해 로고를 새로 붙이거나, 재포장하거나, 디자인을 바꾸지 않는다 | D-1 2-3 승인 로고 규칙 |
| 3 | 기부처가 물품을 **팔거나 재판매하지 않는다**는 내용을 기부 확인서에 넣는다 | 한정판 약속(D-6), 유통 질서 |
| 4 | 기부처나 우리가 기부 사실을 알릴 때 마스코트·로고를 쓰려면 **D-1 검수**를 받는다 | 외부 사용은 D-1 소관 |
| 5 | 기부 홍보에 아이 사진·시설 이름을 쓰려면 시설 동의를 받고, 아이 얼굴·개인정보는 쓰지 않는다 | P0-10 개인정보 |
| 6 | 사투리 문구 굿즈는 아동 시설에 맞는지 P0-10·J-3 기준으로 다시 본다 | 아동 대상 적합성 |

- D-1에는 아직 "외부 반출·기부 시 로고 사용" 항목이 없다. D 담당에게 위 조건을 D-1에 넣어 달라고 요청한다 (H00 "다른 파트에 알릴 것").

**기준 5. 절차**

1. D+30: 남은 재고 확정 (기준 1, D-5·D-6 기록)
2. D-1 검수 상태 확인 → 기부 가능 품목만 남김 (기준 4의 1번)
3. 후보 시설 목록 작성 → 담당자가 시설 수요 확인 (기준 2)
4. 담당자 승인: 기부처·품목·수량·배송비
5. 기부 확인서 작성 (품목·수량, 재판매 금지, 홍보 시 로고·사진 조건) — M-7 형식
6. 포장·발송 → 수령 확인
7. 기록: 기부처·품목·수량·배송비·폐기 수량 → I(성과), 04_운영결과, 다음 해 발주 수량(D-4) 근거

## 3. 에이전트 행동 규칙

1. 위반 판단·제재 결정을 에이전트가 내리지 않는다. 점검표·판단 규칙·기록 양식만 만든다.
2. 2-3의 순서(1회 경고 + 원상복구 → 2회 철수)를 바꾸거나 건너뛰지 않는다.
3. 위반 항목을 이 표에서 임의로 더하지 않는다. 새 항목은 그 규정의 원본 파트(B·C 등)와 담당자 확인 뒤 넣는다.
4. 소음 기준 수치(데시벨 등)를 확인 없이 쓰지 않는다.
5. 기부처를 정하거나 시설에 연락하지 않는다. 기부 물품의 금액·세무 처리를 판단하지 않는다.
6. 남은 굿즈를 폐기하는 안을 내지 않는다. 폐기는 불량·검수 불통과품만이다 (2-7).
