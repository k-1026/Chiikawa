# H-1 예산 — 세부 지침

> 구분: 고정(질문 흐름·검증 규칙) + 연도별(금액) · 기본 지침: 9장 · 진행: 초안 v1 · 최종 수정: 2026-11-18
> 기준 문서: P0-6 예산 범위(P세부지침안V12), 기본 지침 v2 3-1 "첫해 수치 규칙", `대사투/공통/단가표.md`, `local 리서치/가정값/README.md`, 담당자 결정 2026-11-18 (12번, 9번)

## 1. 이 파트의 역할

- 축제 예산의 **상세 산정**(항목·수량·단가·합계)과 **수입 합산**을 맡는다. 예산을 어떤 틀로 받는지는 P0-6, 수입원 구조는 H-9가 원본이다.
- 에이전트가 예산 숫자를 **만들지 않고**, 기획자에게 **무엇을 얼마로 정해야 하는지 묻는 순서**를 정한다.
- 현장 결제·정산·현금 관리 방식을 정한다 (C-4·D-5·D-6이 "미정"으로 H에 넘긴 항목).
- 읽는 파트: 전체 (A~G의 비용 요청을 받아 합산), I(집행 실적), P0-6

### 2-3. 3안과 합계 검증

- 최소·기본·확장 3안은 **항목 포함 여부**(필수·선택 묶음)로 나눈다 (P0-6 2-3). 같은 항목의 단가를 3안마다 다르게 만들지 않는다.
- **총액 = 세부 합계**를 계산식으로 보여 준다. 다르면 그 안을 내보내지 않는다.
- 금액 칸마다 근거 종류를 적는다: `집행`(전년 실제) > `견적` > `공공` > `언론·비공식` (단가표 작성 규칙). **견적 확인 여부**를 따로 표시한다.
- 예비비 10% (P0-6 2-3).

### 2-4. 수입 표시

- 수입은 H-9 구조를 받아 **수입 항목**으로 따로 표시하고, 예산 총액에서 빼지 않는다 (P0-6 2-4).
- 확정 전 수입은 모두 `[추정]` + 계산식. 플리마켓 수수료는 매출의 5.3% (C-4).

### 2-5. 결제·정산·현금 관리 (담당자 결정 2026-11-18, 9번)

**굿즈 상점(D-5)과 운영 직영 판매처 공통**

| 수단 | 운영 방법 |
| --- | --- |
| 카드 리더기 | 판매처마다 둔다. 단말기 판매 내역을 그날 마감 기록과 맞춘다 |
| 굿즈 전용 계좌 | 굿즈 판매용 계좌를 따로 만들어 계좌이체는 이 계좌로만 받는다. 계좌 안내판을 판매대에 둔다 |
| 현금 돈통 | 판매처마다 잠금 돈통 1개. 시작 시재(거스름돈)를 기록하고 시작한다 |
| 판매 영수증 | 판매마다 영수증(또는 판매 기록)을 남기고 모은다. 영수증 합계 = 카드 + 계좌 + 현금 합계인지 마감 때 확인한다 |

**일일 마감 순서**

1. 현금은 권종별로 세어 시재와 장부 금액의 차이를 적는다 `[해석]` (소상공인 마감 관행 자료).
2. 카드 매출은 단말기 내역으로, 계좌 매출은 입금 내역으로 확인한다. 카드 매출은 며칠 뒤 입금되므로 입금 확인은 정산일에 다시 한다 `[해석]`.
3. 카드 수수료는 매출에서 바로 빼지 않고 비용 항목으로 따로 적는다 `[해석]`.
4. 마감 기록에 판매자·확인자 2명이 서명한다. 현금은 그날 운영본부 금고 또는 은행 입금으로 옮긴다 (보관 장소는 7장 2번).

- 치맥페스티벌 공식 굿즈 판매처의 결제·현금 관리 방식은 **확인 안 됨** (2026-11-18 조사, 공개 자료 없음). 확인되면 이 절에 사례로 넣는다.
- 굿즈 **재고** 보관은 D파트 담당이 다시 정한다 (D-5). H는 보관 장소 확보만 연결한다 (H-6).

## 3. 에이전트 행동 규칙

1. 예산·단가·수량 숫자를 만들지 않는다. 첫해는 `[가정]` 파일과 담당자 입력만 쓰고, 없으면 "미입력" + 질문한다.
2. 2-1 순서를 건너뛰지 않는다. 기획자가 금액을 넣기 전에 "예산은 대략 얼마"라고 단정하지 않는다 (1단계 예측은 전년 자료가 있을 때만, `[추정]`으로).
3. 다른 파트 기획을 예산에 맞출 때, 줄인 항목과 이유를 그 파트의 "영향 파트"로 돌려준다. 파트 지침의 고정값(예: 10미 10종 전부 출점)을 예산 때문에 임의로 빼지 않고 담당자에게 묻는다.
4. 총액과 세부 합계가 다른 안을 내보내지 않는다.
5. 업체명이 들어간 견적은 업체 동의 없이 외부 공유 문서에 쓰지 않는다 (단가표 규칙).
6. 결제 수단·계좌 정보를 기획안 공개본에 그대로 쓰지 않는다 (계좌번호는 담당자만).
