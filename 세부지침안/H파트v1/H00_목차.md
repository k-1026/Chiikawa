## 구분 뜻

- **고정:** 매년 같음. 바꾸려면 담당자 승인 + 지침 버전 변경
- **연도별:** 매년 새로 정하는 값 (예산 금액, 배치표, 교환 상품 등)
- **조건부:** 날씨·인원·현장 상황에 따라 바뀜
- **조사:** 에이전트가 자료로 채우고 출처·기준일을 붙임

## 파일 양식 (H파트 공통)

> 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(금지) → 4. 매년 받을 입력·조사할 항목 → 5. 다른 파트 연결 → 6. 기본 지침·다른 문서와 다른 점 → 7. 미확정·회의 필요 → 8. 출처 → 변경 이력

- 근거 라벨 (P0-9 기준): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요(검증 방법 함께) · `[추정]` 계산·가정 기반 수치(계산식 함께)
- **"제안"**: 담당자가 아직 값을 정하지 않아 H파트가 처음 내놓은 값이다. 확정 전에는 기획안에 "제안(담당자 확정 필요)"으로 쓴다.
- **수치는 만들지 않는다.** 첫해 금액·인원·방문객은 `local 리서치/가정값/`의 `[가정]` 파일과 담당자 입력에서만 가져온다 (기본 지침 v2 3-1).
- 사람이 해야 하는 일(현장 확인, 기관 문의, 최종 판단)은 "⚠️ 사람이 해야 하는 일"로 표시한다.
