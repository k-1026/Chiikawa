## 구분 뜻

노션 E파트 표의 구분을 그대로 써요. 뜻은 기본 지침 3장 "변경 범위 3층위"를 따라요.

- **고정:** 매년 같아요. 바꾸려면 담당자 승인과 지침 버전 변경이 필요해요.
- **연도별:** 매년 새로 기획해요. 연도 주제 연결 1줄, 주 목표, 전년 대비 유지·개선·실험을 적어요 (기본 지침 4-0).
- **조건부:** 날씨·장소·규모 같은 조건에 따라 바뀌어요. 예: 운영 시간, 배치, 실내외 운영.

## 파일 양식 (E파트 공통, A파트 v2와 같음)

> 0. 이전 버전과 달라진 점 → 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(연도별 작성 + 금지) → 4. 출력 형식 → 5. 매년 받을 입력·조사할 항목 → 6. 다른 파트 연결 → 7. 노션·기본 지침과 다른 점 → 8. 미확정·회의 필요 → 9. 출처

- 머리말: `> 구분: … · 기본 지침: … · 진행: … · 최종 수정: YYYY-MM-DD HH:MM`, 다음 줄 `> 목차: [E00_목차.md](E00_목차.md)`
- 말투: 규칙 본문은 한다체, 0·1·7장의 설명 문장은 해요체
- 근거 라벨 (기본 지침 7장, A파트와 같음): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요 · `[추정]` 계산·가정 기반 수치
  - 원문을 보지 못한 자료는 라벨 옆에 "원문 미확인"이라고 적어요.
  - **E파트는 이 4개만 써요.** 본문, 9장 출처 표의 "근거 라벨" 칸 모두 같아요. 라벨 옆 메모("원문 미확인" 등)는 붙여도 돼요 (2026-11-17).
- 미확정 형식: # / 항목 / 이유 / 확인 주체 / 확인 기한
- 출처 형식: 자료 / 위치 / 쓰는 내용 / 근거 라벨. E파트용 DB는 아직 없어서 파일 목록으로 대신해요.
- 다른 파트로 넘기는 내용(인력 → H, 연계 지점 → G)은 6장에 적고, 그 파트의 내용은 대신 정하지 않아요.
- **미션 범위:** E는 축제장 안 E 프로그램과 연계한 현장 참여 미션을 담당한다. F 미션은 F파트의 온라인 홍보 이벤트다.
- **공통 문서:** `H파트v4/H03_일정.md`의 축제 3일 타임테이블(최종표 추후 입력)과 `Y.지도/`의 지도. 지도 업데이트 완료 후 구역 번호·동선 참조를 맞춘다.
