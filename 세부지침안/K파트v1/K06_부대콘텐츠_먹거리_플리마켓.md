# 06. 부대 콘텐츠·먹거리·플리마켓 (A06~A08, B02, B04, C01, C02 요약)

> 1차 작성(2026-11-19)에서는 토론 대회(02번 파일)만 다뤘는데, main 브랜치를 더 읽어 보니 **메인무대를 쓰는 콘텐츠가 토론 대회 하나가 아니었어요.** 사이트의 "행사개요·시간표·지도" 탭은 이 내용을 모두 반영해야 합니다.

## 1. 메인무대 콘텐츠 4개 (A01)

메인무대(코오롱 야외음악당) **1개**를 토론 대회·골든벨·뮤지컬이 나눠 쓰고, NPC만 무대 없이 축제장을 돌아다닙니다.

| 콘텐츠 | 형식 | 날짜(예정) | 비고 |
|---|---|---|---|
| 사투리 토론대회 | 개인전, 대구 vs 타지역 말싸움 | **일요일**(본선·결승) | [K02_토론대회_지침.md](K02_토론대회_지침.md) 참고 |
| 사투리 골든벨 | 관객 단체 참여 퀴즈 | 토요일(예상) | 아래 2장 |
| 뮤지컬 공연 | 지역 극단 초청, 대구 사투리 창작 뮤지컬 | 미정(타임테이블 때) | 하루 2회, 1회 1.5시간 |
| 사투리 순회 NPC | 공연인이 사투리로 돌아다니며 관객과 노는 이벤트 | **토요일 종일**(일요일은 토론 있어서 제외) | 무대 없음, 팀별 담당 구역 |

- 토론·골든벨 진행자는 **1명**(기본값: 같은 사람)이 맡습니다.

## 2. 사투리 골든벨 (A06)

| 항목 | 내용 |
|---|---|
| 참가 | 웹(구글 폼) 사전 신청으로 받음(웹 결정 2026-11-26: 현장 신청 안내 없음, A-4·A-6과 확인 ⚠️). **나이·보호자 제한 없음**(단, 결승 무대 촬영은 만 14세 미만 보호자 동의 필요) |
| 진행 장소 | 무대 앞 **의자석**에서 화이트보드로 답 작성 → 결승 진출자(전체 참가자의 **10%**)만 **무대**로 올라가 결승 |
| 비참가 관람객 | 중계 화면으로 함께 보며 **같이 풀면서** 즐김 |
| 문제 | 사투리 단어 / 사투리 듣기 / 간단 대구 상식 — 3분야 각 10개(총 30개), 쉬운 것부터 |
| 상품 | 결승 진출자는 기본 상, 우승·준우승은 추가 상 |

## 3. 뮤지컬 공연 (A07)

- **지역 극단을 초청**하는 공연. 대구 사투리를 이용한 **창작 뮤지컬**.
- 하루 2회, 1회 1.5시간, 메인 무대.
- 섭외 극단은 확정 전까지 사이트에도 "후보"로만 표기.

## 4. 사투리 순회 NPC (A08)

- 연극·공연인(배우 준비생 포함)이 의상을 입고 사투리로 말하며 축제장을 돌아다니는 이벤트.
- 한 팀 5명 이내, 여러 팀. 팀마다 담당 구역(메인구역·7구 맛집거리·식사존·플리마켓·축제 출입로 일대 중 하나) 배정.
- 관객과 보기·대화·그해 이벤트(예: 퀴즈) 함께하기로 즐김. **놀이공원 마스코트처럼** 노는 프로그램 — 순위·보상 없음.
- 캐릭터·의상은 아직 미정(섭외된 공연 팀이 정함).

## 7-1. 사전 신청·사연 접수 (2026-11-25 추가, K07)
- **골든벨 사전 신청**: 행사정보 > 부대 프로그램의 골든벨 카드에서 구글 폼 링크로 연결. 기간 D-120 시작·D-90 중간 점검·D-75 마감(H-3), 정원은 의자석 수용 인원, 초과 시 선착순(A-4). 만 14세 미만 항목(보호자 연락처·촬영 동의)은 폼에 포함(A-10).
- **라디오 사연 접수**: 사투리 라디오 카드에서 구글 폼 링크로 연결. E파트 최신(2026-11-26)이 접수 방법을 K에 넘겼고(E-02 미확정 19번 "K에서 수정 중") 이 결정이 그 답이에요. 사연은 실명·개인정보를 지우고 지역 비하 사연을 거른 뒤 J 검수를 거쳐 낭독해요. 라디오 프로그램 자체(E-02 후보 5)의 확정은 E 쪽에서 확인해요.
- 뮤지컬·순회 NPC는 신청 없이 안내만. 토론 참가 신청(A-4)은 메인무대 소관이라 이번 범위 밖.
- 두 신청·접수는 웹 로그인 여부와 상관없이 구글 폼으로 받아요(현장 신청·접수는 두지 않아요 ✅ 2026-11-26. A-4·A-6이 "사전·현장 신청 모두"라고 돼 있어 A파트와 맞춰야 해요 ⚠️).

## 9. 온라인 주문·결제 (2026-11-25 추가, K07)
- 10미 포장마차·7구 맛집거리 부스는 웹에서 주문·카카오페이 결제(또는 현장 결제기)와 대기번호를 받을 수 있어요. 현장 결제도 그대로 가능해요.
- 플리마켓·굿즈 상점은 현장 결제만 해요.
- 업소는 주문 접수·호출 화면을 써야 해요(정산은 웹에서 정하지 않아요, K07 6장).
