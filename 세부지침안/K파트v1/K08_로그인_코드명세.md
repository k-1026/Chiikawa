# 08. 로그인 — 코드 명세 (K07 4장 "로그인"·2-1 첫 진입)

> 작성: 2026-11-26 · 설계 허브: [K07](K07_웹기능설계_로그인_주문결제_대기_사전챗봇.md) · 코드: `웹코드/login/login.js`
> 이 파일은 **사람이 관리하는 기능 코드**의 명세예요. 전체 에이전트는 이 파일과 `웹코드/login/`을 고치지 않아요(K00 5장).

## 1. 하는 일
| 기능 | 내용 | 상태 |
|---|---|---|
| 첫 화면 | **카카오로 시작 / 구글로 시작 / 로그인 없이 둘러보기** 3가지 (2026-11-26 ✅) | 시험판 구현 |
| 둘러보기 | 일정·지도·사투리·사전·챗봇 등 열람은 로그인 없이 가능. **주문·투표만 로그인 필요** | 시험판 구현 |
| 시작 전 질문 | **로그인(둘러보기 포함) 직후 가장 먼저** "1분만요"(I-4 8문항) 화면. 모두 선택이고 **건너뛰기** 가능, 끝나면 홈 (2026-11-26 ✅) | 시험판 구현 |
| 설문 저장 | **기기 단위 익명 토큰**으로 저장, 계정 ID와 연결하지 않음. 중복 응답은 통계에서 감수 (✅ 2026-11-26) | 실제는 서버(K10 DB) |
| 권한 | 카카오=열람·투표·카카오페이 구매 / 구글=열람·투표(구매는 현장) / 둘러보기=열람만 | 시험판 구현 |

## 2. 입력·출력
- 입력: 로그인 방식 선택, (시험판) 닉네임
- 출력: `auth = { provider: 'kakao'|'google'|'guest', name }` — 다른 기능이 `K.auth()`로 읽음
- 설문 답: `survey = { done, skipped, ans }` (시험판은 브라우저 저장소)

## 3. 시험판(모의) vs 실제 연동
| | 시험판 | 실제 |
|---|---|---|
| 카카오 로그인 | 닉네임만 입력, 항상 성공 | 카카오 개발자 앱 + **Supabase 로그인(Auth)**. 닉네임만 동의 |
| 구글 로그인 | 동일(모의) | 구글 OAuth 클라이언트 + **Supabase 로그인(Auth)** |
| 토큰 검증·세션 | 없음 | **Supabase가 처리**(우리 서버 코드 불필요). 사용자 구분값은 투표·주문에 사용 |

## 3-1. 실제 연결 순서 (2026-11-26 ✅ 방향: Supabase 로그인 사용)
카카오·구글 앱에 등록할 **콜백 주소가 Supabase 프로젝트에서 나오므로 Supabase를 먼저** 만든다.
1. Supabase 프로젝트 정하기(팀 기존 프로젝트 재사용 ❓) → `웹/supabase`의 `schema.sql`, `seed.sql` 실행
2. 카카오 개발자 앱: 플랫폼(Web) 도메인(`http://localhost:5190`, 배포 주소) 등록 → 카카오 로그인 켜기 → Redirect URI에 Supabase 콜백 주소(`https://<프로젝트ID>.supabase.co/auth/v1/callback`) → 동의항목 **닉네임만** → REST API 키·Client Secret 발급 → 팀원 초대
3. 구글 Cloud 콘솔: OAuth 동의 화면(외부·테스트, 테스트 사용자 등록) → OAuth 클라이언트 ID(웹): 승인된 JavaScript 원본과 리디렉션 URI(위 콜백 주소) → 클라이언트 ID·보안 비밀번호
4. Supabase **Authentication > Providers**에서 Kakao·Google 켜고 위 값 입력 → **URL Configuration**에 Site URL·Redirect URLs 등록
5. 웹 코드(`login.js`)의 모의 로그인을 Supabase 로그인으로 교체
6. `localhost`에서 시험 → 배포 후 배포 주소를 카카오·구글·Supabase **세 곳**에 다시 등록 → 구글 앱을 일반 공개용으로 게시
- 카카오 REST 키·Client Secret, 구글 보안 비밀번호는 **Supabase 대시보드에만** 입력하고 레포·웹 코드에 넣지 않는다.
- 이메일은 받지 않는다(닉네임만). 이메일 없이 가입 허용 설정은 확인 필요.
- 게시한 미리보기 링크(아티팩트)에서는 로그인을 시험할 수 없다(등록할 주소가 없음).

## 4. 필요한 키 (이름만)
| 키 | 위치 | 무료 여부 |
|---|---|---|
| `KAKAO_JS_KEY` | 웹(공개) + 허용 도메인 등록 | 무료 |
| 카카오 REST 키·Client Secret | **Supabase 대시보드**(레포·웹에 넣지 않음) | 무료 |
| `GOOGLE_CLIENT_ID` | 웹(공개) | 무료 |

## 5. MVP에서 못 구하는 것과 대체
- **카카오 로그인 심사 항목**(동의 항목 중 일부, 비즈 앱 전환)은 개인 개발 단계에서 제한이 있어요 → 닉네임만 받는 기본 범위로 시작.
- 키를 아직 못 넣은 동안은 시험판의 모의 로그인을 그대로 써요(코드 변경 없음).
