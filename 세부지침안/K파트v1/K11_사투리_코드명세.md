# 11. 사투리 — 코드 명세 (K07 4장 "사투리 사전·번역기·능력고사·챗봇")

> 작성: 2026-11-26 · 설계 허브: [K07](K07_웹기능설계_로그인_주문결제_대기_사전챗봇.md) · 코드: `웹코드/dialect/dialect.js` · 데이터: `웹코드/data/dict.js`(J-1 사전), `웹코드/data/quiz.js`(J-4 문항)

## 1. 하는 일
| 기능 | 내용 | 데이터 | 상태 |
|---|---|---|---|
| 사전 | 사투리·표준어 검색 | `dict.js` (J-1 본문) | 시험판 구현 |
| 번역기 | 표준어↔사투리. 표기는 "표준어(사투리)" | `dict.js` 단어 치환 | 시험판 구현(단어 단위) |
| 능력고사 | 5문제 4지선다, 8문항 중 무작위. 점수 저장·계정 연결 없음 | `quiz.js` (J-4) | 시험판 구현 |
| AI 챗봇 | 일정·위치·주문·사투리 뜻 질문 | 사전·K01~K06 사실 | 시험판은 규칙 기반 모의 |

## 2. 로그인 필요 여부
**없음.** 사전·번역기·능력고사·챗봇은 로그인 없이 쓴다(둘러보기도 가능).

## 3. 시험판(모의) vs 실제
| | 시험판 | 실제 |
|---|---|---|
| 챗봇 | 키워드 규칙 응답 | 서버 `/api/chat`이 **Gemini**를 호출. 사전 DB·축제 사실만 근거로 답하게 지시 |
| 번역기 | 사전 단어 치환 | 서버 `/api/translate`로 Gemini 호출 + 사전 우선(사전에 있는 단어는 사전 값) |
| 키 | 없음 | `GEMINI_API_KEY`는 **서버에만** (브라우저에 넣으면 노출) |

## 4. 필요한 키
| 키 | 위치 | 무료 여부 |
|---|---|---|
| `GEMINI_API_KEY` | **서버만** | Google AI Studio 무료 키 사용 가능(분·일 요청 한도 있음, 한도는 공식 문서 확인) |

## 5. MVP에서 못 구하는 것과 대체
- 무료 한도를 넘으면 챗봇이 막힐 수 있다 → **규칙 기반 응답으로 자동 전환**(지금 시험판 코드가 이미 있음) + 자주 묻는 질문 버튼 유지.
- 챗봇이 모르는 건 지어내지 않고 "운영·안전 부스에 문의"로 안내한다(P0 정보 일관성).
- 언어는 한국어·영어(✅). 시험판은 한국어만 구현.
- 챗봇은 행사 정보만 답하고 주문은 대신 하지 않는다(✅).

## 6. 기획자 확인 항목 ❓
**확정(2026-11-26)**: 행사 정보만 답변(일정·위치·주문 방법·사투리 뜻), 주문 대행 안 함, 한국어·영어, 모를 때 "행사 정보만 답할 수 있어요. 운영·안전 부스에서 안내받을 수 있어요." 능력고사는 8문항 중 무작위 5개, J-4에 웹 능력고사용 한 줄 추가.
