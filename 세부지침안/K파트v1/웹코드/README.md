# 웹코드 — 대사투 웹 기능 코드 (K파트v1)

설계는 [K07](../K07_웹기능설계_로그인_주문결제_대기_사전챗봇.md), 기능별 명세는 K08~K11. **로그인·결제·알림은 모의(데모)**, 데이터는 브라우저 저장소예요.

## 실행
```bash
python3 -m http.server 5190 --bind 127.0.0.1 --directory "세부지침안/K파트v1/웹코드"
```
http://127.0.0.1:5190 (레포 맨 위에서 실행)

## 폴더
| 폴더 | 내용 | 누가 고치나 |
|---|---|---|
| `data/` | 축제 정보·부스·설문·사전·퀴즈 (`data.js` `data2.js` `dict.js` `quiz.js`) | **에이전트(연도별)** |
| `core/` | 기본 화면(홈·행사정보·지도 등), 공용 도구, 더보기·투표 | 사람 |
| `login/` | K08 로그인·둘러보기·시작 전 질문 | 사람 |
| `order/` | K09 부스·메뉴·장바구니·결제 | 사람 |
| `queue/` | K10 대기번호·내 주문 | 사람 |
| `dialect/` | K11 사전·번역기·능력고사·챗봇 | 사람 |
| `server/` | 키가 필요한 서버 함수 자리(아직 없음) + `.env.example` | 사람 |
| `assets/` | 이미지 | 사람 |

## 키 넣는 법
`server/.env.example`을 복사해 `server/.env`로 이름 바꾸고 값만 채워요. `.env`는 git에 안 올라가요. 서버 함수는 Vercel에 올리고 같은 이름으로 환경변수를 넣어요. 키가 없으면 지금 모의 동작 그대로 돌아요.

## 더미 자료
`local리서치v2/가정값/[가정]_웹_*.md`에 부스·대기·설문·로그인 더미 정의가 있어요.
