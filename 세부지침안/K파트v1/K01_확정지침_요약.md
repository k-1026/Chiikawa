## 1. 축제 정체성 (P0-1)

| 항목 | 값 |

| 풀네임 | **대구 사투리 페스티벌** (공문·보도자료·첫 언급에 씀) |
| 2027년 표기 | **2027 대사투** + 그해 세부 콘셉트 (세부 콘셉트는 아직 미정 — 00_결정기록·02_토론대회 참고) |

- ⚠️ 옛 시안의 캐릭터("토박이 냥이"·"말손님 멍이")는 지금 지침의 마스코트(대키미·외지몽)와 다릅니다. 다시 만들 때는 **대키미·외지몽**으로 바꿔야 해요.
  - 대키미: **고양이형 외계인**, 대표색 하늘색 `#6DCFF5`, 대구 토박이·설명하는 쪽
  - 외지몽: **강아지형 외계인**, 대표색 초록색 `#008C3A`, 우주 여행자·질문하고 배우는 쪽
  - 둘은 서로 **동등한 친구**로 표현해야 해요(한쪽이 가르치고 한쪽이 어리숙한 구도 금지). 마스코트를 화면에 쓸 때는 D-1(마스코트 IP 규칙) 검수를 받아야 해요 — 색상·설정을 임의로 바꾸면 안 돼요(P0-10 금지 18번).
- 핵심 타깃(P0-7): **사투리를 처음 접하든 이미 알든 즐길 수 있는, 여러 지역의 20~30대 직장인·학생**(메인) + **가족 단위 방문객**(메인, 타지역/대구경북 모두). 이 사람들에게 하는 말: *"사투리를 몰라도 괜찮다. 외지몽도 처음엔 못 알아들었고, 대키미가 친구가 돼 줬다."* 이 톤을 사이트 전체 문구에 유지해야 해요.
- "타지역 vs 대구" 대결 구도(토론 대회)는 유지되고, **숙박 인증 보상 기능도 실제로 있어요(G-5, 아래 5장)** — 다만 옛 시안의 "2만 원 고정, 체크인 데모"와는 세부 흐름·금액이 다릅니다.

## 4. 스탬프·혜택 구조 (H-10)

| 항목 | 값 |
|---|---|
| 형태 | **오프라인 스탬프 북만** — 웹 스탬프 없음, 축제 팔찌 없음 |
| 범위 | 축제장 안에서만 (축제장 밖 원조 매장 스탬프는 폐지) |
| 칸 수 | 8칸, **5개 이상** 모으면 완성 |
| 도장 받는 곳 (3묶음) | ① 부대 프로그램(E) — 참여마다 1개 ② 플리마켓 / 10미 포장마차 / 7구 맛집거리 — 각 구역에서 1번 사면 1개(구역당 최대 1개) ③ 굿즈 상점 — 1번 사면 1개 |
| **토론 대회(A) 관람·투표** | **도장을 주지 않음** — 시간이 정해진 무대 프로그램이라 모두에게 일정하게 주기 어렵기 때문 |
| 완성 보상 | 할인 쿠폰북 + 날마다 선착순 상품(1~50번째 손선풍기, 51~250번째 부채) + 공식 인스타그램 추첨 응모 |
| 교환 장소 | 운영·안전 부스에서만 배부·교환 |

- ⚠️ 옛 시안의 "체크인 → ①숙박 인증 ②능력고사 ③관객 투표 = 스탬프 3단계" 구성은 지금 지침과 맞지 않아요. **숙박 인증·능력고사는 지금 지침에 없는 기능**이고, **관객 투표는 스탬프를 주지 않아요.** 새 사이트에서는 스탬프 안내를 "오프라인 스탬프 북(8칸 중 5개)" 기준으로 다시 써야 해요.
- 쿠폰북 수록처·선착순 상품 재고 등은 해마다 담당자가 정하는 값이라, 사이트에는 "협업처는 추후 공개" 식으로 미확정 표시를 해 둬요.

## 5. 숙박 인증 보상 (G-5) — ⚠️ 옛 시안이 맞았던 기능, 세부만 다름

> 옛 시안의 "체크인 → 숙박 영수증 인증 → 대구로페이 2만 원"은 **완전히 틀린 기능이 아니었어요.** 실제로 G-5에 "숙박 인증 보상"이 **담당자 결정(2026-11-16)으로 기본 방식**으로 들어가 있습니다. 다만 세부 흐름·금액·수령처가 달라요.

| 항목 | 지금 지침 (G-5) |
|---|---|
| 흐름 | **사전 신청(웹)** → 축제 기간 대구 숙소에 1박 → **숙박 인증**(영수증 또는 예약 확인 화면 + 주소지 확인) → 보상 수령 |
| 대상 | **대구 외 거주자**(주소지 기준)만 |
| 인정 숙소 | 대구 소재 숙박업소 **전체** (특정 제휴 업소 없음) |
| 보상 | 대구로페이 — **최소 1만 / 기본 2만 / 확장 3만 원**(3안, 아직 확정 아님) |
| 수령처 | **축제장 현장 + 동대구역 관광안내소** |
| 상한 | 선착순 ○건(미확정) |

- ⚠️ 옛 시안은 "영수증 촬영(결제정보 가림) → 즉시 삭제"라는 간단 데모 흐름이었는데, 지금 지침은 **사전 신청(웹)이 먼저** 있고 숙박 "후"에 인증하는 순서예요. 사이트에 이 순서를 반영해야 해요.
- 토론 대회의 타지역 참가자 숙박 지원(A-5)은 이것과는 **별개**예요(참가자 전용, G-5는 일반 방문객 대상).
- 이 보상은 G-5(아직 "초안" 단계, H-10처럼 "확정"까지 간 건 아님)라서, 금액·상한은 사이트에 "미확정"으로 표시해야 해요.
