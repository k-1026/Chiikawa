## 행사개요 — 축제 소개

```
[확정] 행사명: 대사투 (대구 사투리 페스티벌)
[확정] 기간: 2027. 8. 20(금) ~ 8. 22(일), 3일
[확정] 장소: 두류공원 일원 (코오롱 야외음악당 ~ 공원순환로)
[확정] 운영: 매일 12:00 개장 / 금·토 22:00 · 일 20:00 폐막
[확정] 콘셉트: 대구 사투리를 테마로, 누구나 편하게 대구의 말·음식·로컬을 즐기고
       하루 더 머무는 축제
[초안] 2027년 세부 콘셉트: 미정 (팀 회의 후 공개)
```

## 행사개요 — 3대 프로그램·부대콘텐츠

```
[확정] 1. 사투리 토론 대회 (A)
       대구 시민과 타지역 참가자가 "대구 표현 vs 외지 표현"으로
       유쾌하게 겨루며 사투리 문화를 알린다.
       개인전 · 8강 토너먼트 · 일요일 본선·결승

[확정] 2. 대구 10미 포장마차 & 7구 맛집거리 (B)
       대구 대표 음식 10미(따로국밥·찜갈비·막창·무침회·납작만두·
       누른국수·야끼우동·뭉티기·복어불고기·논메기매운탕)를 알린다.
       구별 유명 음식점을 소개해 축제 뒤에도 다시 찾기 쉽게 만든다.

[확정] 3. 소상공인 플리마켓 (C)
       대구 소상공인을 살린다. 조리 음식은 팔지 않고
       로컬 상품·체험만 다룬다. (마스코트 굿즈는 굿즈 상점에서만)

[초안] 메인무대 부대 콘텐츠
🎓 사투리 골든벨 — 의자석에서 화이트보드로, 상위 10%는 무대 결승
🎭 뮤지컬 공연 — 대구 사투리 창작 뮤지컬, 지역 극단 초청
🚶 사투리 순회 NPC — 토요일 종일, 캐릭터가 축제장을 돌아다녀요
```

## 행사개요 — 스탬프·혜택

```
[확정] 오프라인 스탬프 북(8칸) 모으기 — 축제장 안에서만
[확정] 5개 이상 모으면 → 할인 쿠폰북 + 날마다 선착순 상품 + 인스타그램 추첨 응모
[확정] 도장 받는 곳
  ① 부대 프로그램 — 참여마다 1개
  ② 플리마켓 · 10미 포장마차 · 7구 맛집거리 — 구역마다 1번 사면 1개
  ③ 굿즈 상점 — 1번 사면 1개
[확정] 토론 대회 관람·투표는 스탬프를 주지 않아요.
```

## 토론대회 — 대회 소개

```
[확정] 개인전 · 대구 참가자 vs 타지역 참가자
[확정] 대구/타지역은 주민등록상 주소지로 구분 (경북은 대구로 포함)
[확정] 2027년 참가 8명(대구 4 · 타지역 4) · 8강 토너먼트
[확정] 일반 승자 진출전이 아니라 지역 대표 선발전 — 라운드마다 지역별 점수 상위 50% 진출
[확정] 논제는 찬반 토론이 아니라 "대구 표현 vs 외지 표현" 이지선다 말싸움
[확정] 가볍고 유머러스한 분위기로 진행
```

## 토론대회 — 대진표

```
[초안] 2027 본선 8강 (일요일)

대구 1   VS   타지역 1
대구 2   VS   타지역 2
대구 3   VS   타지역 3
대구 4   VS   타지역 4

[확정] 4강은 "대구 1위 vs 타지역 2위", "대구 2위 vs 타지역 1위" 식으로
       지역별 순위를 엇갈려 짭니다. (담당자 확인 전 제안)
[초안] 출전자 명단은 예선(온라인 심사) 이후 공개됩니다.
```

## 토론대회 — 논제

```
[확정] 논제 형식: 대구인이 할 법한 말 vs 외지인이 할 법한 말
[초안] 예시 (실제 확정 논제가 아닙니다)
  "졸려 vs 잠 와, 뭐가 더 귀여운 표현일까"

[확정] 본선 논제는 경기 시작 후 무대에서 추첨해 공개됩니다.
[확정] 결승 논제는 미리 알리지 않습니다.
       메인구역 입구 쪽지함에 방문객이 추천 → 검수 → 결승 무대에서 즉석 추첨
[확정] 이 웹사이트로는 논제 추천을 받지 않습니다. 현장에서 쪽지로만 추천해 주세요.
```

## 토론대회 — 관객 투표

```

[확정] 관객 투표는 최종 점수의 40%예요. (심사위원 60% + 관객 40% + 승리 보너스 10점)
[초안] 로그인(데모) → 투표 → 득표율 실시간 반영(데모 데이터)
[확정] 투표에는 스탬프가 적립되지 않습니다.
```
