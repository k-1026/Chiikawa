## 구분 뜻

- **고정**: 매년 같음. 바꾸려면 담당자 승인 + 지침 버전 변경
- **연도별**: 매년 새로 확정하는 값(모집 공고 문구, 교환 상품 등)
- **조건부**: 날씨·현장 여건 등 그때그때 상황에 따라 조정 가능

## 파일 양식 (C파트 공통)

> 1. 이 파트의 역할 → 2. 확정 값 → 3. 에이전트 행동 규칙(금지) → 4. 매년 받을 입력·조사할 항목 → 5. 다른 파트 연결 → 6. 기본 지침·다른 문서와 다른 점 → 7. 미확정·회의 필요 → 8. 출처 → 변경 이력

- 근거 라벨(P0-9 기준): `[확인]` 출처 있는 사실 · `[해석]` 자료 기반 의미 · `[가설]` 검증 필요(검증 방법 함께 적음) · `[추정]` 계산·가정 기반 수치(계산식 함께 적음) · 라벨 없는 수치·주장은 쓰지 않음, 확인 안 된 건 "확인 안 됨"으로 표시
- 사람이 직접 판단해야 하는 일(주관적 채점, 마스코트 디자인 유사성 판단 등)은 각 파일에 "⚠️ 사람이 해야 하는 일" 콜아웃으로 표시한다.
