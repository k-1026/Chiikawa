# C-2 참가 대상·품목 원칙 — 세부 지침

> 구분: 고정 · 기본 지침: v2 2장 · 진행: 확정 v4 · 최종 수정: 2026-11-20
> 기준 문서: 기본 지침 v2 2장(프로그램 운영 원칙 — 플리마켓 세부 값은 v2에 없어, v1.1 3장에서 가져온 값을 이 파트가 원본으로 가진다) + v1.1 3장 "소상공인 플리마켓 — 참가 대상·선정 방식" + "품목 원칙", main `세부지침안/D파트v1/D-01_IP규칙검수.md`(마스코트 IP 규칙 원본)

## 1. 이 파트의 역할

- 플리마켓 참가 자격(누가 신청할 수 있는지)과 허용·금지 품목 원칙을 정한다.
- 읽는 파트: C-3(선정 심사 연동), C-6(마스코트 사용 확인 연동), D-1(마스코트 IP 규칙 원본), B-2·B-4(먹거리 품목 분리 기준)

## 2. 확정 값

### 2-1. 참가 대상

- **대구 소재 소상공인·로컬 브랜드(사업자 보유) 우선**으로 모집한다.
- 참가 희망 셀러가 계획서를 제출하고, 주최 측(우리)이 심사·선정한다(C-3 참고).

### 2-2. 허용 품목

- 핸드메이드 상품
- 로컬 굿즈·디자인 상품
- 대구 특산 가공품 (**영업 신고된 업체만**)
- 미리 만들어 포장해 온 간단한 먹거리 (**부스에서 조리하지 않는 것**, 영업 신고된 업체만)
- 체험 프로그램

> **결정(2026-11-19)**: 플리마켓에서 막는 것은 "음식 전체"가 아니라 **부스에서 조리가 필요한 음식**이다. 대구 특산 가공품과, 미리 조리해 포장해 온 간단한 먹거리는 판매할 수 있다.

### 2-3. 품목 다양성 원칙

> **정정(2026-11-19)**: "이미 선정된 품목과 겹치는 신청은 상품성·독창성에서 낮게 평가" 규칙을 **삭제**한다 — 점수를 한꺼번에 매기면 "이미 선정된"의 기준 시점이 없기 때문이다.
> **정정(2026-11-19)**: 카테고리당 상한(허용 품목 4종 각각 요청 부스 수 12부스)을 **없앤다**. 4종 × 12부스 = 48부스라 최소 50부스(C-1 2-2)를 채울 수 없어 C-1과 충돌했기 때문이다. 수치 기준은 C-1 2-2의 **판매:체험 7:3 한도**(어느 한쪽도 70%를 넘지 않음)만 둔다.

- 품목은 최대한 다양하게 구성한다 — 허용 품목 4종(① 핸드메이드 ② 로컬 굿즈·디자인 상품 ③ 대구 특산 가공품 ④ 체험)이 두루 들어가는지 C-3 심사에서 분포를 확인한다. 이 "다양하게"는 **정성 원칙**이고, 4종을 같은 수로 나누라는 뜻이 아니다 — 수치 기준은 판매:체험 7:3 한도(C-1 2-2) 하나뿐이다.
- 판매(①~③)와 체험(④)의 요청 부스 수 비율은 C-1 2-2의 7:3 한도를 따른다.

### 2-4. 금지 품목

- **부스에서 조리하는 음식 판매 제외**(결정 2026-11-19): 부스 안에서 굽기·튀기기·끓이기·데우기 등 조리가 필요한 음식은 팔지 않는다 — 그런 먹거리는 B-2(10미 포장마차)·B-4(7구 맛집거리) 구역에서만 판매한다. 미리 만들어 포장해 온 간단한 먹거리와 대구 특산 가공품은 2-2에 따라 허용한다.
- **대키미·외지몽 공식 마스코트를 사용한 굿즈 판매 금지**: D(굿즈 상점)와 같은 종류의 상품(키링, 에코백 등)을 파는 건 상관없지만, 마스코트 캐릭터·이름·이미지를 쓴 상품은 D에서만 판매한다. 판단 규칙의 원본은 D-1(마스코트 IP 규칙·검수)이고, 확인 절차는 C-6(연계)을 따른다.

## 3. 에이전트 행동 규칙

**금지**

1. 부스에서 조리가 필요한 음식을 플리마켓 허용 품목으로 승인하지 않는다 — 그런 먹거리는 B-2·B-4 구역에서만 판매한다. 미리 만들어 포장해 온 간단한 먹거리와 대구 특산 가공품은 승인할 수 있다(2-2·2-4).
2. 마스코트(대키미·외지몽) 사용 굿즈를 셀러 품목으로 승인하지 않는다 — D에서만 판매한다(C-6 확인 절차 연동).
3. 품목 분포를 확인하지 않고 비슷한 품목이 몰린 신청 목록을 그대로 승인하지 않는다 — C-3 심사에서 분포를 확인한다.
4. 판매:체험 요청 부스 수 비율이 7:3보다 벌어지게(어느 한쪽이 70% 초과) 선정하지 않는다(C-1 2-2). 카테고리당 12부스 상한은 폐지됐으므로 적용하지 않는다(2-3).
5. 영업 신고가 안 된 가공품·먹거리 셀러를 허용 품목으로 승인하지 않는다.
6. 대구 소재가 아니거나 로컬 브랜드가 아닌 셀러를 우선순위 확인 없이 선정하지 않는다(2-1).
