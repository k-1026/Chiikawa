# C-4 수수료·정산 — 세부 지침

> 구분: 고정 · 기본 지침: v2 2장 · 진행: 확정 v4 · 최종 수정: 2026-11-20
> 기준 문서: 기본 지침 v2 2장(프로그램 운영 원칙 — 플리마켓 세부 값은 v2에 없어, v1.1 3장에서 가져온 값을 이 파트가 원본으로 가진다) + v1.1 3장 "소상공인 플리마켓 — 참가비·수수료", P0-6(예산 입력 방식 — v1.1 9장이 옮겨 감)

## 1. 이 파트의 역할

- 플리마켓 참가비·수수료율과 정산 방식, 미제출 시 처리를 정한다.
- 읽는 파트: C-3(확정 셀러 명단), C-7(판매 기록 양식), H(운영 — 예산 수입 반영)

## 2. 확정 값

### 2-1. 참가비·수수료

- **참가비 없음.**
- **매출(판매 금액)의 5.3%**를 수수료로 받는다(이익이 아니라 매출 기준, H-1·H-9와 같음).

### 2-2. 정산 방식

- 셀러 결제 방식(축제 공용 결제 단말기·QR 결제 등)은 **H파트(H-1 2-5 결제·정산·현금 관리)가 정한 대로 따른다**(결정 2026-11-20). C-4에서 따로 정하지 않고, 정해진 방식을 모집 공고(C-7)에 적는다. 정해지기 전에는 "결제 방식 미정(H파트 결정 대기)"으로 적는다.
- 공용 결제 시스템을 쓰는 거래는 자동으로 매출이 집계되므로 수수료 계산이 바로 가능하다.

### 2-3. 현금 판매분 처리

- 현금으로 판매한 분은 셀러가 **일자별 판매 기록(품목·수량·금액)을 제출**하고, 이 기록이 수수료 계산에 포함된다.
- 판매 기록 양식은 모집 공고에 첨부한다(C-7 문서 초안 참고).

### 2-4. 제출 기한·미제출 처리

> **결정(2026-11-11)**: 미제출 처리를 감점에서 참여 제한으로 강화한다.

- 제출 기한: **축제 종료 후 정산일까지**. 정산일은 **H파트가 정한 날짜를 따른다**(결정 2026-11-20 — H파트를 고칠 때 정함, 7절 1번). 정해지기 전에는 기한 판정을 하지 않고 "정산일 미정"으로 적는다.
- 정산(판매 기록 제출 포함)을 기한 내에 마치지 못하면 **다음 연도 플리마켓 참여가 불가능**하다. 감점이 아니라 참여 자격 자체를 제한하는 조치다.
- 이 규칙은 **단순 지연 제출**에 적용된다. 판매 기록을 고의로 축소·누락해 제출한 사실이 적발되면 지연 제출과 별개로 C-3 2-7(위반 시 제재)의 "현금 매출 고의 누락 신고 적발" 항목이 적용되어 **즉시** 다음 해 참여가 불가능하다.
- 셀러가 낸 현금 판매 기록(셀러명·서명 포함)은 **다음 해 축제 종료일까지** 보관한 뒤 파기한다(결정 2026-11-20, C-3 2-1 1번 사업자 정보와 같은 기간).

### 2-5. 예산 처리

- 수수료 수입은 **예산 수입 항목**으로 표기한다.
- 확정 전에는 `[추정]`으로 표시한다(P0-6, P0-9 근거 라벨).

## 3. 에이전트 행동 규칙

**금지**

1. 수수료율(5.3%)을 임의로 변경하지 않는다.
2. 현금 판매분 기록 제출 없이 수수료를 집계하지 않는다.
3. 정산 기한을 넘긴 셀러를 경고·감점으로 낮춰 분류하지 않는다 — 다음 연도 참여 불가 대상으로 분류해 기록을 정리하고, 결정은 C파트 담당이 확정한다(2-4, C-3 2-7 "사람이 해야 하는 일").
6. 정산일이 정해지기 전에 "기한 초과"를 판정하지 않는다(2-4).
4. 단순 지연 제출과 고의적 매출 누락을 같은 수위로 처리하지 않는다 — 고의 누락이 확인되면 C-3 2-7 즉시 제재를 적용한다(2-4).
5. 확정 전 수수료 수입을 `[추정]` 라벨 없이 예산 수입 항목에 기재하지 않는다.
