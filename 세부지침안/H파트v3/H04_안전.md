# H-4 안전 — 세부 지침

> 구분: 고정(판단 규칙) + 조건부(날씨·인원) · 기본 지침: 9장 · 진행: 초안 v3 (동선·주의 지점은 지도 갱신 후) · 최종 수정: 2026-11-18
> 기준 문서: 기본 지침 v2 2장 "폭염", P0-3·P0-4(P세부지침안V12), Y.지도, B-1·B-8, C-5, E-3·E-4, G-2·G-6, 담당자 결정 2026-11-18 (8·15번)

## 1. 이 파트의 역할

- 축제 **운영 중 안전**을 맡는다: 폭염, 우천·강풍, 혼잡, 야간 조명·귀가, 퇴장 동선, 수용 인원.
- 법적 의무와 비상 대응(화재·지진·정전·비상 연락)은 **H-11**이 맡는다. H-4는 운영 판단, H-11은 지켜야 할 규칙과 대피다.
- 다른 파트는 프로그램별로 "그대로 / 축소·이전 / 취소"를 미리 분류만 하고(E-4), 당일 판단은 H-4 기준을 따른다.
- 읽는 파트: A·B·C·D·E(프로그램 분류), G(야간 동선), H-2(인력), H-11

## 2. 확정 값

### 2-1. 폭염

- 8월 말이므로 낮은 실내·그늘, 야간 중심 배치, 온열질환 대응을 넣는다 (기본 지침 v2 2장).
- 한낮(12:00~15:00)은 체감 33도 이상 비율이 가장 높은 시간대다 `[추정]` (E-3 2-2). 한낮 야외 프로그램은 E-3 한낮 규칙을 따르고, 운영안에 그늘·물·휴식 간격·더위 쉼터 위치를 적는다.
- 폭염 특보가 나와도 개장·폐막 시각은 바꾸지 않고, 낮 야외 이벤트 축소안만 낸다 (P0-4 3장).

### 2-2. 우천·강풍·날씨 판단 (담당자 결정 2026-11-18, 8번)

- **원칙: 안전에 위협이 될 만큼 심하지 않으면 그대로 운영한다.** 방문객이 내는 입장권이 없으므로, 일부 프로그램 축소보다 축제 자체를 멈추는 쪽의 손해가 더 크다 `[해석]`.
- 축제 당일 비·강풍·낙뢰 등 날씨 문제가 생기면 **담당자 + 현장 운영자가 함께 판단**하고, **재회의**를 거쳐 축소·중단을 정한다. 에이전트는 운영안에 "당일 판단: 담당자 + 현장 운영자, 재회의 필요"로 적고 미리 중단을 정하지 않는다.
- 중단·대피를 판단할 수치 기준(풍속·강수량 등)은 아직 없다. 정해지면 이 절에 넣는다 (7장 1번). 대피 절차는 H-11.
- 부스: 우천 시 텐트를 연결해 대응한다 (C-5). 강풍 때 천막 전도방지는 B-8 수준을 따른다.
- 토론 대회 우천 일정은 A파트가 정한다 (P0-4 3장).

### 2-3. 혼잡·수용 인원

- 공식 출입로는 **1곳**이다 (P0-3 구역 0, Y). 입구 계수(I-2)로 시간대별 입장 수를 보고 혼잡 시간대를 판단한다.
- 대기 줄은 통행로 밖으로 유도하고, 결제 단말기를 여러 대 둔다 `[해석]` (기본지침서 3장 진입로 혼잡 대비).
- 출입구 분리·병목 통제를 동선 설계에 넣는 방안을 검토한다 (B 참고자료 축제 사례 제안).
- **모든 수용 인원 숫자에 "전문가 검토 필요"를 붙인다** (노션 H-4 표시 방식, E-4에도 적용 중).
- 순간 최대 예상 인원이 3만 명을 넘는지 먼저 판단하고 안전관리계획 범위를 정한다 (B-1). 법적 기준(1천 명 이상)은 H-11 2-1.

### 2-4. 야간 조명·귀가·퇴장

- 야간 프로그램이 있는 곳과 귀가 동선의 조명을 확인한다 (기본 지침 9장, E-3).
- **퇴장 동선:** 폐장 때 바리게이트 ⑵를 열어 출입로 혼잡을 줄인다 (B-8 3절). ⑵는 비상 차량로도 겸한다 (P0-3).
- 막차·셔틀은 G-6이 조사하고, 셔틀 운영은 H-6이 맡는다.

### 2-5. 화기 공통

- 먹거리 부스의 화기·생식 기준은 B-8이 원본이다. 그 밖의 부스(체험 등)에서 화기를 쓰면 B-8 체크리스트를 같이 쓴다.
- 부스·무대 어디에서도 불꽃 연출을 하지 않는다 (B-8 4절, H-11).

## 3. 에이전트 행동 규칙

1. 날씨 때문에 축제나 프로그램을 **미리 취소하는 안을 기본값으로 내지 않는다.** 판단 주체(담당자 + 현장 운영자)와 재회의 필요만 적는다.
2. 수용 인원 숫자에 "전문가 검토 필요"를 빼지 않는다.
3. 동선·주의 지점은 Y.지도 최신본만 쓴다. 지도에 없는 위치를 만들지 않는다 (지도 갱신 후 다시 고침, 담당자 결정 15번).
4. 폭염·우천 대응을 이유로 개장·폐막 시각을 바꾸는 안을 내지 않는다 (P0-4).
