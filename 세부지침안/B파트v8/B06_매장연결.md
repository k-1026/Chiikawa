# B06 매장 연결 — 세부 지침

> 구분: 고정(QR 운영 자체, 10미·7구 업소 스탬프 지급 방식) + 연도별(실제 매장 목록, 교환 상품·쿠폰북) · 기본 지침: 3장 · 진행: 확정 v8 · 최종 수정: 2026-11-19
> 기준 문서: 기본 지침 v1.1 3장 "실제 매장 연결(상권)", main `세부지침안/하위파트_기본목차/하위파트_축약안_v1.md` 3장 7·8번(스탬프 담당 구분 기준)
> 목적: ① QR로 실제 매장(원조 매장) 위치·영업시간을 안내하는 정보 전달 장치, ② 축제장 **안**에서 10미·7구 업소가 스탬프를 지급하는 방식(2026-11-17 신설)

## 1. 이 파트의 역할

- B02·B04에서 확정된 출점 업소를 매장 카드(QR)로 어떻게 안내할지 정한다.
- 축제장 **밖** 스탬프 연계(실제 매장 3곳 방문 시 혜택, 구 2-2)는 **폐지**한다(2026-11-17) — QR은 실제 매장 위치·영업시간 등 정보 안내 용도로만 쓴다.
- 축제장 **안** 스탬프는 전체 제도(스탬프 북·칸 수·완성 기준·도장 제작·교환)를 **H-10(H파트 스탬프 운영)**이 정한다(담당자 결정 2026-11-18) — B06은 **10미·7구 음식 부스에서 도장을 언제·어떻게 찍어 주는지**까지만 다룬다(2-4). M-6(메인)은 동선에서 지급처 위치만 그린다.
- 읽는 파트: H-10(스탬프 운영 원본), M-6(메인 — 지급처 위치), B03·B04(확정 업소 명단 입수), B05(모집·심사 — 스탬프 활용 방안 제출 연동)

## 2. 확정 값

### 2-1. 매장 카드(QR) 내용

부스마다 매장 카드(QR)를 비치한다. 카드에 담을 내용:

1. 업소명 + 대표 메뉴
2. 원조 골목·위치 안내(B03 기준, 골목 없는 품목은 개별 업소 위치)
3. 실제 매장 영업시간·전화번호·지도 링크

### 2-2. 실제 매장 목록 구성 규칙

- B02(10미)·B04(7구)에서 **확정 업소**(B05의 "후보" 딱지를 뗀 업소)와, 담당자가 입점을 확정한 프랜차이즈 후원사(B05 2-6)만 목록에 올린다.
- 목록은 매년 B05 심사 결과 확정 직후 갱신한다. 전년도 목록 재사용 금지.
- 업소가 폐업·이전하면 즉시 목록에서 제외하고 매장 카드 QR도 갱신한다.

### 2-3. 필수 기획 요소

- 기획안에는 "축제 부스 → 실제 매장" 동선을 **1개 이상** 포함한다(기본 지침 v1.1 3장 연계 원칙).

### 2-4. 축제장 내 스탬프 — 10미·7구 부스 지급 방식 (2026-11-17 신설, 2026-11-19 H-10 기준으로 정정)

> **결정(2026-11-17)**: 축제장 안에서도 방문객이 스탬프를 모으는 제도를 둔다. 축제장 **밖** 스탬프 연계는 폐지했으므로, 이 제도가 B06이 다루는 유일한 스탬프 제도다.
> **정정(2026-11-19, H-10 담당자 결정 2026-11-18 반영)**: 스탬프 제도 전체 틀(스탬프 북·칸 수·완성 기준·도장 제작·교환·쿠폰북)은 **H-10 소관**이다. B06은 H-10 틀 안에서 "10미·7구 부스가 도장을 언제 찍어 주는지"만 정한다. 이전의 "M-6 소관"·"1회 구매당 1개"는 폐기한다.

- **지급 기준 (H-10 2-2)**: 10미 부스 중 **아무 곳에서나 1번 사면 10미 도장 1개**(10미 전체에서 1개), 7구 부스 중 **아무 곳에서나 1번 사면 7구 도장 1개**(7구 전체에서 1개). 스탬프 북 1권 기준이라, 10미 부스를 여러 곳 돌아도 10미 도장은 1개다.
- **지급 수단**: 도장은 H가 묶음별로 같은 디자인으로 만들어 개점 전에 나눠 주고 축제 뒤 회수한다(H-10). 부스마다 다른 수단을 임의로 쓰지 않는다.
- **스탬프 북·완성 기준**: 운영·안전 부스에서 배부하는 스탬프 북(8칸), 5개 이상이면 완성 보상(H-10 2-1). B06은 이 값을 바꾸지 않는다.
- **교환 상품·쿠폰북**: 내용은 매년 H-10 기준으로 담당자가 받기로 한 협업처·후원사 리스트를 그대로 넣는다 — B06에서 고정값으로 쓰지 않는다.
- **업소 제출 의무**: 10미·7구 출점 업소는 모집·심사 단계(B05)에서 **스탬프 활용 방안**(자기 부스에서 스탬프를 어떻게 지급·안내할지 계획)을 제출해야 한다 — B05 2-2 심사 절차와 연동(B05 참고).

## 3. 에이전트 행동 규칙

**금지**

1. B05 심사를 통과하지 못한 "후보" 업소를 매장 카드·실제 매장 목록에 올리지 않는다.
2. 전년도 매장 목록을 그대로 재사용하지 않는다 — 매년 B05 확정 결과로 갱신한다.
3. 폐업·이전이 확인된 업소를 목록에서 제외하지 않고 방치하지 않는다.
4. 매장 카드(QR)에 "축제장 밖 방문 혜택" 등 스탬프 인센티브 안내를 넣지 않는다 — 축제장 밖 스탬프 연계는 폐지했다(2026-11-17).
5. 기획안에 "부스 → 실제 매장" 동선을 0개로 설계하지 않는다.
6. 축제장 내 스탬프 북 양식·칸 수·완성 기준·교환 상품(쿠폰북) 구성을 이 문서에서 임의로 정하지 않는다 — **H-10** 값을 따른다(2-4).
7. 10미·7구 업소별로 도장 지급 기준(10미 전체 1개·7구 전체 1개, 스탬프 북 1권 기준)을 다르게 적용하지 않는다 — 통일된 기준을 따른다.
8. B05로부터 받은 확정 업소 명단에 "스탬프 활용 방안" 제출 여부가 빠져 있으면 확인 없이 매장 카드 제작을 진행하지 않는다 — B05에 확인을 요청한다.

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| B05 확정 업소 명단 | 입력 | 심사 종료 직후 | 목록 갱신 보류, 전년도 목록 사용 금지 — 심사 완료까지 "미확정"으로 표시 |
| 축제장 내 스탬프 북 칸 수·완성 기준 | 입력(H-10) | 부스 운영 교육 전 | H-10 값(8칸, 5개 이상)을 쓴다. H-10에서 값이 비면 "완성 기준 추후 안내"로 적고 숫자를 넣지 않는다 |
| 그 해 교환 상품·쿠폰북 구성 | 입력(H-10, 매년 담당자 결정) | 축제 시작 전 | 미정 시 "상품 구성 추후 공지"로 표시 |
| 업소별 스탬프 활용 방안 | 입력(B05, 신청 서류) | 모집·심사 시 | 미제출 업소는 B05에 보완 요청 |
