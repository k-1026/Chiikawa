# B02 대구 10미 포장마차 — 세부 지침

> 구분: 고정(10종 출점) + 연도별(부스 재배분·출점 업소) · 기본 지침: 3장 · 진행: 확정 v12 · 최종 수정: 2026-11-19
> 기준 문서: 기본 지침 v1.1 3장 "① 대구 10미 포장마차", B01(공간 배치), B03(원조 골목·업소 연결표)

## 1. 이 파트의 역할

- 대구 10미 10종을 메인 구역(10미 존, B01에서 배정된 최소 25~최대 30부스, 2026-11-18 정정)에 품목당 몇 동씩 배분할지, 그 재배분 규칙을 정한다.
- 읽는 파트: B03(원조 골목·업소), B05(모집·심사), B06(매장 연결), I(성과 — 품목별 KPI)

### 2-2. 부스 배분 공식 (2026-11-18 정정 — 40동 고정 → 최소 25~최대 30부스 범위 + 업소별 요청제)

> **정정(2026-11-18)**: 10미 존 전체 부스 수를 "40동(품목당 4동) 고정"에서 **최소 25부스~최대 30부스** 범위로 바꾼다. 몇 부스를 쓸지는 더 이상 품목 단위로만 정하지 않고, **업소가 B05 계획서에 "요청 부스 수"를 적어 제출**하는 방식을 더한다(C-3·B04와 동일한 방식). 아래 품목별 기준은 "목표 배분"으로 남기고, 실제 배분은 요청 합계를 보며 조정한다.
> **결정(2026-11-19, 담당자)**: P0-3 V14·P0-1 V14의 "최소 40동(품목당 4동)"이 아니라 이 문서의 **최소 25~최대 30부스**를 유지한다. P0-3·P0-1·H01에 갱신을 요청했다.

| 구분 | 규칙 |
| --- | --- |
| 전체 범위 | 최소 25부스 ~ 최대 30부스 |
| 품목당 목표 배분 | 균등 배분 시 품목당 2.5~3동(25~30÷10품목) |
| 최소 보장 | 품목당 2동(어떤 품목도 이 밑으로 줄지 않음) |
| 재배분 폭 | 목표 배분 중 최대 1동분만 전년 데이터로 재배분 가능 |
| 1년 차 | 전년 데이터 없음 → 품목마다 2동씩 먼저 배분(20동)하고, 남는 5~10동은 신청 업소의 요청 부스 수 합계가 많은 품목부터 1동씩 더한다. 요청 수가 같아 순서를 정할 수 없으면 담당자에게 묻는다(담당자 결정 2026-11-19) |
| 출점 보류 품목이 있을 때 | 담당자가 출점 보류를 승인한 품목(B08 2-1, 생식 품목 냉장 미확인 등)은 배분에서 뺀다. 남은 품목에 품목당 2동씩 먼저 주고, 남는 부스는 위 "1년 차"(2년 차부터는 아래 "2년 차부터") 규칙으로 더한다. 합계가 25부스에 못 미치면 B05 2-4 보충 순서를 따른다 |
| 2년 차부터 | 품목별 완판 시각·대기 시간·판매량 비교 → 수요 높은 품목에 여유분 추가, 낮은 품목은 최소 2동까지 축소 |
| 연간 변동 상한 | 품목당 ±1동/년 (급격한 변경으로 특정 품목이 사실상 빠지는 상황 방지) — `[가설]`, 팀 확정 전. 검증: 2년 차에 품목별 완판 시각·대기 시간(I-1)을 보고 ±1동으로 부족했는지 확인 |
| 업소별 요청 부스 수 | 신청 업소가 B05 계획서(2-2)에 적어 제출. 품목 목표 배분을 넘겨 더 쓰고 싶으면 이 값으로 요청하고, 전체 범위(25~30)를 넘지 않는 선에서 반영 |

### 2-3. 중복 판매 금지

- 10미 품목은 이 구역(메인 구역 — 10미 존)에서만 판매한다.
- 7구 맛집거리(B04)는 10미 10종과 겹치지 않는 메뉴로만 업소를 선정한다.

### 2-4. 매장 카드(QR)

- 부스마다 매장 카드(QR)를 비치해 원조 업소·골목 위치를 안내한다(B03, B06).

## 3. 에이전트 행동 규칙

**금지**

1. 10미 품목 10종 중 하나라도 임의로 빼거나 다른 메뉴로 바꾸지 않는다 — 품목 교체는 2-1 "고정" 항목이라 담당자 승인 없이 불가.
2. 품목당 부스 수를 2동 미만으로 배분하지 않는다(2-2 최소 보장).
3. 1년 차(전년 데이터 없음)에는 2-2 "1년 차" 규칙(품목당 2동 → 남는 부스는 요청 부스 수 순)만 쓰고, 전년 데이터로 차등을 두지 않는다.
4. 연간 변동 상한(±1동)을 넘겨 한 번에 재배분하지 않는다.
5. 10미 품목을 7구 맛집거리(B04) 후보에 중복으로 넣지 않는다.
6. 전년 데이터가 불완전(일부 품목만 집계됨 등)한데도 전체 품목을 재배분하지 않는다 — 데이터 없는 품목은 전년과 동일하게 유지한다.
7. 업소별 요청 부스 수(2-2)를 반영해 전체 부스 수를 최소 25부스 밑으로 줄이거나 최대 30부스를 넘기지 않는다.

**일반 규칙**

- 재배분 근거(품목별 완판 시각·대기 시간·판매량)는 반드시 전년도 실측 데이터를 인용하고, 추정치면 `[추정]`과 계산식을 함께 적는다.
