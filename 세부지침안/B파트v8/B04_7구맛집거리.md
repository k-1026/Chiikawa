# B04 대구 7구 맛집거리 — 세부 지침

> 구분: 고정(7구 참여, 구당 최소 7동) + 연도별(참여 맛집·메뉴) · 기본 지침: 3장 · 진행: 확정 v11 · 최종 수정: 2026-11-19
> 기준 문서: 기본 지침 v1.1 3장 "② 대구 7구 맛집거리", [맛집리스트_V1.md](참고자료/맛집리스트_V1.md)

## 1. 이 파트의 역할

- 7구 존(공원순환로, B01에서 배정된 최소 60~최대 70부스)에 대구 7개 구의 대표 맛집·제과점을 어떻게 배분·선정할지 정한다.
- 읽는 파트: B05(모집·심사), B06(매장 연결), C(플리마켓 — 같은 공원순환로 동선 공유)

## 2. 확정 값

### 2-1. 대상 구역

대구 7개 구: 중구·동구·서구·남구·북구·수성구·달서구. **군 지역은 제외**한다.

### 2-2. 구별 부스 수 (2026-11-18 정정 — 고정 동수 → 최소 배정 + 범위)

> **정정(2026-11-18)**: 7구 존 전체 부스 수를 "50동 고정"에서 **최소 60부스~최대 70부스**(B01 2-1) 범위로 바꾼다. 아래 "구당 7동(달서구 8동)"은 더 이상 고정값이 아니라 **구별 최소 배정**(바닥 보장치)이고, 업소가 1동을 넘겨 더 쓰고 싶으면 **B05 계획서(2-2)에 "요청 부스 수"를 적어 제출**한다. 실제 운영 부스 수는 선정된 업소들의 요청 부스 수 합계로, 60~70부스 범위 안에서 정해진다(프랜차이즈 후원사 목표 10곳 포함, B05 2-6).

| 구 | 최소 배정 | 비고 |
| --- | --- | --- |
| 중구, 동구, 서구, 남구, 북구, 수성구 | 각 최소 7동 | 구청 추천·공모 업소. 더 받고 싶으면 요청 부스 수로 추가 신청 |
| 달서구 | 최소 8동 | 개최지 추가 1동 |
| 7구 존 합계(최소) | 60동 | 구별 최소 배정 50동(7동×6구 + 8동 달서구) + 프랜차이즈 후원사 목표 10곳(B05 2-6). 프랜차이즈 부스가 10동 미만이면 부족분은 B05 2-4 보충 순서로 일반 업소에서 채워 60동을 맞춘다(담당자 결정 2026-11-19) |
| 전체 범위 | 최소 60부스 ~ 최대 70부스 | B01 2-1과 동일 수치, 초과분 10부스는 신청 현황에 따라 배분 |
| 제과점 | 위 범위 안에서 배정 | 더 이상 50동과 별도가 아니라, 60~70 범위 안의 추가 요청으로 처리(영업·참여 의사 확인된 업소 수에 따라 결정) |

- "1업소 1동 원칙"(2-3)은 기본값이다 — 더 넓은 자리가 필요한 업소는 B05 계획서에 요청 부스 수(2동 이상)를 적어 제출할 수 있다.

### 2-3. 맛집 선정 기준

- **구성 단위**: 골목 단위가 아니라 각 구의 유명 맛집(업소 단위)으로 구성. 1업소 1동 원칙.
- **후보 출처**: 구청 추천·지정 업소(예: 북구청 "오래된맛집"), 대구푸드 구·군별 인증업소, 대구10미데이 참여 업소, 공개 모집 신청 업소.
- **영업 조건**: 해당 구에서 실제 영업 중인 매장만. 축제 후 방문 가능해야 한다.
- **메뉴 중복 금지**: 10미 10종 메뉴는 이 구역에서 판매하지 않는다(10미와 겹치는 메뉴를 막기 위함, B02).
- **구 안 메뉴 중복 제한**: 같은 구 안에서 같은 메뉴는 2곳 이하.
- 개최지 달서구는 구청 음식 안내(달서맛나)와 협업해 추천 업소를 확보한다.

> ⚠️ **사람이 해야 하는 일**: 구청 추천 요청·명단 확보(구청 연락)는 담당자가 한다(요청 주체는 P0-5 7장). 에이전트는 받은 명단을 2-4-1·2-5 표에 반영만 한다.

### 2-4. 제과점 추가 배정

- 각 구의 유명 제과점을 기존 맛집 후보(최소 배정 업소)와 바꾸지 않고 **추가**로 배정한다.
- 선정 기준은 맛집과 같다(백년가게·오래된 업소 우선, 실제 영업 중, 같은 구 안 같은 메뉴 2곳 이하).
- **정정(2026-11-18)**: 부스 수는 더 이상 "50동과 분리된 별도 수량"이 아니라, 7구 존 전체 범위(최소 60~최대 70부스, 2-2) 안에서 처리한다. 영업·참여 의사가 확인된 업소 수에 따라 몇 부스를 쓸지 B05 계획서에 요청 부스 수로 적어 제출한다(7절 2번, 아직 구체 수 미정).
- 근거 등급: 백년가게·대구푸드·언론 = 공신력 높음 / 플랫폼·블로그·SNS = 참고용(7장 출처 6순위), 확인 필요.

## 3. 에이전트 행동 규칙

**금지**

1. 업소명을 기획 단계에서 확정 출점 업소로 표기하지 않는다 — 서류·시식 심사(B05) 전까지는 반드시 "후보"로 표기한다.
2. 10미 품목(B02 2-1) 취급 업소를 7구 맛집거리 후보에 넣지 않는다.
3. 같은 구 안에서 같은 메뉴를 2곳 넘게 선정하지 않는다.
4. 제과점을 기존 맛집 후보(2-2 최소 배정)와 바꿔치기하지 않는다 — 반드시 추가 배정이다.
5. 영업 여부가 ❔(공개 자료로 확인 못 함)·⚠️(이전·상호 변경 가능성)인 후보를 사람이 영업 확인을 마치기 전에 모집 공고에 올리지 않는다(4절과 같음).
6. 구청 지정 명단(중구 대표 맛집 86곳·동구맛집·달서맛나 음식점 68곳 등, `[확인]` 맛집리스트_V1.md)을 확보하기 전에 후보 수가 충분하다고 가정하지 않는다 — 2-5처럼 ❔ 비중이 높으면 추가 명단 확보를 먼저 진행한다.
7. 동구·남구에 공개 자료 기반 제과점 후보가 없다고 해서 임의로 업소명을 만들어내지 않는다 — 구청 추천으로만 확보한다(2-4-1).
