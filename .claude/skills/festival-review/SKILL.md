# 성과 분석·차년도 개선 (지침 5장 10단계, 12장)

대상 연도: `$ARGUMENTS`

## 1. 자료 받기
- `03_기획안.md` 의 KPI 표와 **KPI 측정 준비표**, `00_결정기록.md` 를 읽는다.
- 지표별로 실제 값을 사용자에게 받는다. 파일·표·메모 무엇이든 받는다. 측정 준비표대로 준비가 됐는지(협조 확보·도구 운영 여부)도 함께 묻는다.
- 예산은 항목별 실제 집행액(수량·단가·금액)을 받는다.
- **받지 못한 지표는 비워 두고 "측정 안 됨"으로 적는다. 추정으로 채우지 않는다** (지침 11·12장).
- 방문객·매출처럼 기관 발표가 있으면 출처와 집계 방식(통신·카드·현장 계수 등)을 함께 적는다.

## 4. 단가표 반영
- 04의 5장(예산 집행) 실제 값을 `local 리서치/공통/단가표.md` 2장 "실제 집행 실적"에 연도별 행으로 추가한다.
- 업체명은 넣지 않고 분류·항목으로만 적는다.
- 단가표 3장 갱신 이력에 한 줄을 추가한다.
- 1장 단가를 실제 단가로 바꿀지는 사용자에게 묻고, 바꾸면 근거 종류를 `집행`, 기준일을 축제 연도로 적는다.
