# A-6. 사투리 골든벨

## 1. 이 파트의 역할

- 관객 단체 참여 퀴즈의 신청 방식, 진행 방식, 문제 구성을 다뤄요.
- 아이디어 킵 18번(팀원 제안 골든벨)에서 시작했어요.

## 2. 확정 값

**참가 (고정)**

- **사전 신청과 현장 신청**을 모두 받는다. (신청 세부는 A-4)
- 대구 사람과 외지 사람을 **구분하지 않고 다 같이** 참여한다. 다 같이 대구 사투리를 체험하는 콘텐츠다.

**진행 장소 (고정)**

- **객석에서** 진행한다.
- 참가자가 일부만 남으면 **무대로 올라와서** 진행한다. 올라가는 기준은 정해지지 않았다. (미확정 2번)

**진행 방식 (검토 중)**

- 웹으로 O/X나 단답형을 풀어 인원을 줄이고, 어느 정도 남으면 무대에서 보드판으로 진행하는 방안을 검토 중이다. (미확정 1번)
  - 장점: QR 체크인 웹을 함께 쓸 수 있음(A-1), 돗자리 객석에서도 채점이 바로 됨, 무대 보드판은 답 공개 장면을 만들 수 있음
  - 걱정: 휴대폰 검색 부정, 동시 접속 부담(K(웹페이지) 확인), 휴대폰이 없는 참가자

**문제**

| 유형 | 내용 | 예시 |
|---|---|---|
| 사투리 듣기 평가 | 영어 듣기 평가처럼 녹음을 듣고 푸는 문제 | - |
| 사투리 단어 시험 | 사투리 단어의 뜻을 맞히는 문제 | - |
| 대구 퀴즈 | 어렵거나 역사 같은 문제가 아니라 **가벼운 문제** 위주 | 대구 연고지 야구팀은 어디? |

- 문제는 **쉬운 것부터 어려운 것** 순서로 낸다.
- 유형별 문제 수는 정해지지 않았다. (미확정 3번)
- 문제와 정답의 사투리 표현은 J(사투리) 검수를 받는다.

**듣기 평가 음원 (고정)**

- 음원은 **미리 녹음**해서 준비한다.
- 녹음은 **완전한 토박이 대구인**이 한다. 예: 토박이 대구인 공무원
- 녹음 내용은 J(사투리) 검수를 받는다.

## 3. 에이전트 행동 규칙

**연도별 작성**

- 문제 목록, 신청 정원
- 연도 주제 연결 1줄, 주 목표(사투리), 전년 대비 유지 / 개선 / 실험 분류와 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"

**금지**

- 정답 근거를 확인하지 않은 문제를 쓰지 않음 (기본 지침 7장)
- 금지 논제와 같은 소재(지역 비하, 정치 프레임, 젠더·세대 갈등, 실제 업소 비교)를 문제로 쓰지 않음 (A-2 금지 논제 준용, 담당자 확인 전 제안)
- 할매 말투 콘셉트, 사투리 비하 표현 금지 (A-1 공통)
- 참가자 수를 임의로 만들지 않음

## 4. 출력 형식

**1. 문제표** (열 구성은 담당자 확인 전 제안)

| 번호 | 유형 | 문제 | 정답 | 난이도 | 음원 여부 | 정답 근거 | J(사투리) 검수 |
|---|---|---|---|---|---|---|---|

**2. 진행 순서표** — 단계, 방식(웹 / 보드판), 남는 인원 기준, 문제 번호

**3. 음원 녹음 요청서** — 녹음자 조건, 문장 목록, 검수 결과

**4. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한
