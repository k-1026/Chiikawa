### v1에서 지운 내용 (원문 보관): 팀전 모집·선발 (구 A-5, A-6)

- 참가 비율: 팀전 대구 2팀·타지역 2팀
- `[가설]` 목표 신청 수: 팀전 지역별 6팀
- 신청 자격: 한 사람은 개인전과 팀전 중 **하나만** 출전할 수 있다.
- 신청서 항목: 출전 방식(개인전 / 팀전(팀을 만들어서 신청) / 팀전(혼자 신청, 매칭 희망)), 팀원 정보(팀원별 이름, 나이, 거주 지역, 팀 신청만)
- 대구 출신 타지역 거주자 25% 제한의 팀전 계산: 팀전 타지역 2팀 중 1팀
- 출전 제한: 한 사람은 개인전과 팀전 중 하나만 출전한다.
- 팀 매칭: 혼자 신청한 팀전 지원자는 **선발 담당 운영진이 개인 영상을 보고** 잘 어울릴 사람끼리 팀을 만든다. 팀 인원과 구분 규칙은 A-1을 따른다. (v1의 A-1은 v2의 A-2)
- 예비 출전자: 지역별 팀전 예비 1팀
- 출력 형식: 매칭 팀 구성표 — 팀 번호, 구분, 팀원 지원 번호, 조합 이유
- 지원자 점수표·신청 현황표의 "대회" 열 (개인전/팀전 구분)
- 안내: 경기 일정(금요일 예선, 진출 시 토요일 본선·결승)은 모집 공고와 출전자 공지로 안내
- 팀전 숙박 지원은 A-5 0장에 보관

## 1. 이 파트의 역할

- 노션 구 A-5, A-6에 해당해요: 모집 채널, 일정(D-120~), 대구·타지역 참가자 비율 / 선발 기준표, 지원자 점수표 형식 (최종 확정은 담당자)
- v2에서는 토론대회만이 아니라 **사투리 콘텐츠 참가자 전체**의 모집·선발을 다뤄요. 골든벨 사전·현장 신청이 들어와요. 참가 혜택과 숙박은 A-5에서 다뤄요.

## 2. 확정 값

### 사투리 골든벨 신청 (v2 추가)

- 골든벨은 **사전 신청과 현장 신청**을 모두 받는다. (A-6)
- 사전 신청 기간, 방법, 정원은 정해지지 않았다. (미확정 7번)

### 토론대회 모집 (구 A-5)

**모집 일정 (다른 파트와 조율 중이며 바뀔 수 있음)**

| 시점 | 내용 |
|---|---|
| D-120 | 모집 시작 |
| D-90 | 중간 점검 (지역별 신청 수 확인) |
| D-75 | 접수 마감 |
| D-74 ~ D-61 | 선발 |
| D-60 | 출전자 발표 |

**참가 비율과 목표 신청 수**

- 출전자는 대구·타지역 **같은 수**로 한다. 개인전 대구 4명·타지역 4명
- `[가설]` 목표 신청 수는 지역별로 출전 인원의 3배로 한다. 개인전 지역별 12명. 근거 자료가 없는 시작값이며 첫해 데이터로 조정한다.
- 목표 신청 수는 지원자 수이며, 실제 출전은 선발을 거친 인원만 한다.

**신청이 모자랄 때**

1. D-90 중간 점검에서 목표에 미달하면 홍보를 강화한다.
2. 접수를 1주 연장한다.
3. 그래도 모자라면 양쪽 인원을 같은 수로 줄인다. 예: 대구 4명·타지역 3명이면 3:3으로 진행
4. 인원이 홀수가 되어 상위 50%가 나누어떨어지지 않으면 올림한다. 예: 3명이면 2명 진출

**신청 자격**

- 나이 제한은 없다. **미성년자는 보호자 동행**이 필요하다.
- 대구·타지역 구분은 A-2를 따른다.
- 외국인도 신청할 수 있다. 외국인은 외국인등록상 체류지로 구분한다. 체류지가 대구·경북이면 대구 측, 다른 지역이거나 등록이 없는 관광객 등은 타지역 측이다.
- 토론대회 출전자가 골든벨에도 참가할 수 있는지는 정해지지 않았다. (미확정 8번)

**자기소개**

- 신청자 전원이 **자기소개**를 간단히 쓴다.
- 자기소개 예시
  - 대구 토박이 부모님 아래에서 20년 넘게 대구에서만 살고 있는 대학생입니다.
  - 케이팝을 너무 좋아해서 한국어를 배웠습니다.
  - 대구에서 몇 년째 일하고 있습니다.
- 외국인은 자기소개에 한국어 경험을 적을 수 있다.
- 자기소개는 선발 때 참고하고, 무대에서 진행자가 참가자를 소개할 때 쓴다.

**모집 채널 (담당자 확인 전 제안, 콘텐츠는 F(홍보)와 조율)**

| 대상 | 채널 |
|---|---|
| 타지역 | 능력고사 결과 화면의 신청 링크, 숏폼, 대학 커뮤니티 |
| 대구·경북 | 지역 대학, 구청·시 SNS, 축제 공식 SNS |

### 토론대회 선발 (구 A-6)

**선발 주체 (고정)**

- 선발은 **주최 측 운영진**이 한다. 일반인이 나오는 예능에서 제작진이 예선 출연자를 고르는 방식과 같다.

**제출물**

- 신청서와 **60초 이내 휴대폰 영상**을 받는다.
- 영상 내용은 자기소개와 그해 영상 주제에 대한 말하기다.
- 영상 주제는 매년 바뀐다. **그해 유행 소재에 사투리를 녹여** 정한다. 예: 깻잎 논쟁이 유행이면 사투리와 엮어 말하기
- 유행 소재는 F-6(홍보) 트렌드 조사를 참고한다.
- 예선 논제는 경기 직전에 추첨하므로 영상 주제로 쓰지 않는다.

**신청서 항목** (수집 목적·보관 기간과 동의는 A-10)

| 항목 | 내용 | 비고 |
|---|---|---|
| 이름, 나이, 연락처 | | 나이는 미성년자 확인용 |
| 거주 지역 | 구분용 주소지 (시·도) | 외국인은 외국인등록상 체류지 |
| 대구·경북과의 인연 | 출신 지역, 대구·경북에서 산 경험 | 대구 출신 타지역 거주자 확인용 |
| 외국인 구분 | 관광객 / 유학생 / 국내 거주자 | 해당자만 |
| 동행 보호자 | 보호자 이름, 연락처 | 미성년자만 |
| 혜택 관련 항목 | A-5에서 혜택 종류가 정해지면 필요한 항목을 넣음 (v1의 "숙박 지원 희망" 칸 자리) | A-5 |
| 자기소개 | 간단한 자기소개 | 대구와의 인연이 드러나도록 질문 문구 구성 |
| 사투리 관련 활동 | 사투리 콘텐츠 제작 등 (선택) | 다양성 참고 |
| 영상 | 60초 이내 | |
| 안내 확인 | 경기 규칙, 금지 표현, 촬영 안내를 읽었다는 확인 | |
| 동의 | 개인정보 수집·이용, 촬영·활용 | A-10 |

**채점 (고정)**

- 선발 채점 기준은 **본 대회 심사 기준과 같다.** 유머 40, 지역문화 표현력 40, 전달력 20 (A-3)
- 타지역 지원자는 사투리 사용 여부로 감점하지 않는다.

**다양성**

- 운영진은 **최대한 다양한 참가자**를 뽑도록 한다. 점수만으로 정하지 않고 아래 같은 사람을 고려한다.
  - 한국어를 잘하는 외국인
  - 나이가 아주 어린데 사투리를 잘하는 참가자
  - 대구 사투리 콘텐츠를 만드는 크리에이터
  - 신인 개그맨, 작은 극단 배우처럼 알려지지 않은 공연인
- 다양성은 가산점이 아니라 운영진 판단으로 반영한다.

**대구 출신 타지역 거주자**

- 타지역 측으로 출전할 수 있다. 신청서의 "대구·경북과의 인연"과 자기소개에 밝힌다.
- 타지역 측 출전자의 **25% 이하**로 제한하고, 계산값은 올림한다. (비율은 담당자 확인 전 제안)
  - 지금 규모: 타지역 4명 중 1명
  - 타지역이 8명으로 늘면 2명

**출전 제한 (고정)**

- 대중적으로 널리 알려진 방송인·희극인은 제외한다. 신인이나 잘 알려지지 않은 공연인은 출전할 수 있으며, 판단은 운영진이 한다.
- 심사위원과 운영진의 가족은 제외한다.
- 전년도 우승자는 제외한다.

**예비 출전자**

- 지역별로 예비 1명을 함께 뽑는다.
- 불참 확정 기한은 **D-14**다. 그 뒤 빠지면 예비 출전자로 채운다.

**안내**

- 경기 규칙, 금지 표현, 촬영 안내를 **신청서에 적고**, 축제 전에 **공지로 한 번 더** 보낸다.
- 경기 일정(예상: 토요일 예선, 진출 시 일요일 4강·결승. 요일은 추후 확정)은 신청서에 따로 묻지 않고 모집 공고와 출전자 공지로 안내한다.

**일정**

- 선발은 D-74 ~ D-61, 발표는 D-60이다.

## 3. 에이전트 행동 규칙

- 에이전트는 기준표, 점수표 양식, 지원자 요약까지만 만들고 출전자를 정하지 않는다.

**연도별 작성**

- 연도 주제 연결 1줄, 주 목표(사투리·체류), 전년 대비 유지 / 개선 / 실험 분류와 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"

**금지**

- 신청자 수, 지원자 수, 점수, 참가 의사를 임의로 만들지 않음 (기본 지침 7장)
- 에이전트가 출전자를 정하지 않음
- 지원자 개인정보와 영상을 선발 외 목적으로 쓰거나 외부에 공유하지 않음 (기본 지침 10장, A-10 동의 범위 안에서만)
- 타지역 지원자를 사투리 사용 여부로 감점하지 않음
- 보호자 동행 확인 없이 미성년자를 출전자로 확정하지 않음
- 대구 측과 타지역 측 출전 인원을 다르게 뽑거나 출전시키지 않음
- 모집 문구에 지역 비하, 타지역 조롱, 사투리 비하 표현을 쓰지 않음 (기본 지침 10장, J(사투리) 검수)

## 4. 출력 형식

**1. 모집 일정표** — 시점, 내용, 담당, 연결 파트

**2. 채널별 모집안** — 대상, 채널, 메시지, 담당

**3. 신청서 항목표** — 항목, 필수 여부, 수집 목적, 보관 기간 (A-10)

**4. 신청 현황표** (열 구성은 담당자 확인 전 제안)

| 시점 | 콘텐츠 | 구분 | 신청 수 | 목표 신청 수 | 달성률 | 조치 |
|---|---|---|---|---|---|---|

**5. 선발 기준표** — 항목, 배점, 정의 (A-3과 같음), 다양성 고려 예시

**6. 지원자 점수표** (열 구성은 담당자 확인 전 제안)

| 지원 번호 | 구분 | 대구 출신 타지역 거주 여부 | 유머 | 지역문화 표현력 | 전달력 | 합계 | 운영진 메모 |
|---|---|---|---|---|---|---|---|

**7. 선발 결과표** — 구분, 출전 / 예비 / 미선발, 25% 제한 확인

**8. 안내 공지문** — 규칙, 금지 표현, 촬영 안내 (A-10 문서 초안과 연결)

**9. 미확정 사항** — 항목 / 이유 / 확인 주체 / 확인 기한
