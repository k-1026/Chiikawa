# 축제 지도 (festival-map)

카카오 지도를 띄우는 웹 프로젝트입니다.

## 내가 직접 해야 하는 일 (처음 한 번)

### 1. 카카오 JavaScript 키 받기
1. https://developers.kakao.com 에 로그인합니다.
2. **내 애플리케이션** → **애플리케이션 추가하기**로 앱을 만듭니다. (이미 있으면 그 앱을 씁니다)
3. 앱을 열고 **앱 키**에서 **JavaScript 키**를 복사합니다.
   - REST API 키나 Admin 키가 아니라 **JavaScript 키**여야 합니다.
4. **플랫폼 → Web**(또는 JavaScript SDK 도메인)에 아래 주소를 등록합니다.
   ```
   http://localhost:5173
   ```
5. **카카오맵** 사용 설정이 꺼져 있으면 켭니다.

### 2. 키 넣기
1. `festival-map` 폴더의 `.env` 파일을 엽니다.
2. `여기에_JavaScript_키를_붙여넣으세요` 부분을 지우고 복사한 키를 붙여넣습니다.
   ```
   VITE_KAKAO_MAP_KEY=abcd1234...
   ```
3. 저장합니다.

### 3. 실행하기
`festival-map` 폴더에서 터미널을 열고 아래 명령을 입력합니다.
```
npm run dev
```
브라우저에서 http://localhost:5173 을 엽니다.
`.env`를 고친 뒤에는 실행 중인 창에서 `Ctrl + C`로 끄고 다시 `npm run dev` 해야 반영됩니다.

## 파일 안내
| 파일 | 하는 일 |
|---|---|
| `.env` | 카카오 키를 넣는 곳 (깃허브에 올라가지 않음) |
| `src/config.js` | **값만 바꾸는 곳**: 처음 화면 기준 장소(PC/모바일 따로), 여백, 마커 좌표 |
| `지도 json/최종_v18.json` | **윗지도와 아래지도의 공통 원본** (구역·시설 마커·아이콘 설정) |
| `public/icons/` | **시설 아이콘 이미지** (기본 아이콘 + 직접 넣은 PNG·SVG) |
| `src/markers/` | 시설 마커 데이터 모양·아이콘 표시 |
| `src/mapData.js` | 저장 파일(JSON) 전체 모양 (구역 + 마커 + 아이콘 설정) |
| `src/initialView.js` | 처음 화면 범위를 맞추는 코드 (LatLngBounds + setBounds) |
| `src/layers.js` | 마커·구역(폴리곤)을 실제 좌표로 그리는 코드 |
| `src/visitor.js` | 방문객 화면 (구역 표시, 누르면 이름) |
| `src/zones/zoneData.js` | 구역 데이터 모양 정의·검사, 이름 예시, 기본 색 |
| `src/admin/` | 관리자 편집 화면 (개발 서버에서만 동작, 배포 파일에는 안 들어감) |
| `src/resize.js` | 지도 상자 크기가 바뀌면 지도를 다시 맞추는 코드 |
| `src/main.js` | 위 기능들을 순서대로 실행하는 코드 |
| `src/style.css` | 화면 모양 |
| `index.html` | 웹페이지 뼈대 |

## 축제 구역 그리기 (관리자 편집 모드)

`npm run dev`로 실행하면 오른쪽 위에 **[관리자 편집] / [방문객 미리보기]** 전환 버튼이 보입니다.

### 도형 하나 그리기
1. 왼쪽 위 **[그리기]** 줄에서 도형 종류를 누릅니다. 아래에 "그리는 중" 안내가 뜹니다.
2. 도형별로 이렇게 그립니다. (천천히 클릭하세요. 너무 빠르면 점이 빠질 수 있어요)

| 도형 | 그리는 방법 | 완성하는 방법 |
|---|---|---|
| ⬠ 다각형 | 모서리를 차례대로 클릭 | **첫 번째 점을 다시 클릭** |
| ╱ 선 | 지나갈 점을 차례대로 클릭 | **마지막 점을 더블클릭** |
| ➜ 화살표 | 시작점부터 차례대로 클릭 | **마지막 점(화살촉 자리)을 더블클릭** |
| ◯ 원 | 중심을 클릭 → 마우스를 움직여 크기 정하기 | **한 번 더 클릭** |
| ▭ 사각형 | 한 모서리를 클릭 → 마우스를 움직이기 | **반대쪽 모서리를 클릭** |
| ⬭ 타원 | 한 모서리를 클릭 → 마우스를 움직이기 | **반대쪽 모서리를 클릭** |

   - 그만두려면 **Esc** 키 또는 **[그리기 취소]**.
   - 원·사각형·타원은 클릭한 뒤 **마우스를 움직여야** 크기가 생깁니다. 크기가 0이면 만들지 않고 안내가 뜹니다.
3. 왼쪽 패널에서 **이름**(예시 목록에서 골라도 됨)과 색을 정합니다.
   - 다각형·원·사각형·타원: 채우기 색·투명도, 테두리 색·투명도·두께
   - 선·화살표: 선 색·투명도·두께 (채우기 없음)
4. **[편집 완료]** 를 누릅니다.

### 이미 그린 도형 고치기
- 지도에서 도형을 클릭하거나, 왼쪽 **구역 목록**에서 이름을 누르면 편집 상태가 됩니다. (가는 선은 목록에서 고르는 게 편해요)
- 다각형·선·화살표: **하얀 작은 네모(점)** 를 끌면 모양이 바뀌고, **변 가운데 흐린 네모**를 끌면 점이 추가됩니다.
- 원·사각형·타원: **가장자리/모서리의 작은 네모**를 끌면 크기가 바뀝니다.
- 도형 **안쪽(선은 선 위)** 을 끌면 통째로 옮겨집니다.
- 지우려면 **[구역 삭제]**.
- 예전에 그린 다각형과 예전에 내보낸 JSON 파일도 그대로 불러와 고칠 수 있습니다.

## 시설 마커 놓기 (관리자 편집 모드)

1. 위 도구 막대 **[시설]** 에서 유형(의료실·안내소·화장실 등)을 고르고 **[📍 마커 놓기]** 를 누릅니다.
2. 지도에서 놓을 곳을 **클릭**합니다. (구역 도형 위를 눌러도 그 자리에 놓여요. 그만두려면 Esc 또는 [놓기 취소])
3. 왼쪽 패널에서 **이름**과 **시설 유형**을 정하고 [편집 완료]를 누릅니다.
- 마커를 **끌면** 위치가 바뀝니다. 선택한 마커 아래 파란 동그라미 가운데가 실제 위치(기준점)입니다.
- 패널 **[시설]** 탭에서 목록을 누르면 그 마커로 이동해 편집합니다.
- 시설 유형 목록은 `src/config.js`의 `FACILITY_TYPES`에서 바꿀 수 있습니다.

### 장소·시설 이름 규칙: 카카오맵 기준
- 웹페이지에 보이는 장소·주차장·시설 이름은 **카카오맵 표기**를 그대로 씁니다. (우리 지도 API가 카카오맵이라, 배경 지도에 찍힌 글자와 이름을 맞추기 위해서입니다)
- 네이버지도 이름은 **팀 내부 확인용**으로만 참고합니다.
- 이름은 카카오맵(map.kakao.com)에서 그 장소를 검색해 나오는 이름을 그대로 적습니다.

| 위치 | 웹페이지 이름 (카카오맵) | 카카오 주소 | 네이버지도 이름 (확인용) |
|---|---|---|---|
| 두류테니스장 앞 주차장 | **두류공원 주차장** | 대구 달서구 두류동 597-6 | 주차장 (두류테니스장 주차장) / 두류공원4공영주차장 |
| 코오롱야외음악당 옆 주차장 | **두류공원 주차장4** | 대구 달서구 야외음악당로 180 (두류동 1312-3) | 코오롱야외음악당주차장 |

- 두 주차장은 약 80m 떨어진 **서로 다른 곳**입니다. 카카오와 네이버가 "4번(제4공영)"을 서로 다른 주차장에 붙이고 있어서 헷갈리기 쉽습니다.
- 음악당 옆 주차장은 카카오에 "코오롱야외음악당 주차장"이라는 이름도 같은 자리에 하나 더 있지만, 공영주차장으로 분류된 **"두류공원 주차장4"** 를 씁니다.
- 확인 날짜: 2026-11-24 (카카오 장소 정보는 바뀔 수 있으니, 최종 배포 전에 한 번 더 검색해 확인하세요)

## 시설 아이콘 바꾸기

### 내 아이콘(Figma PNG·SVG) 넣기
1. 파일을 **`festival-map/public/icons`** 폴더에 복사합니다. (이름은 영어·숫자·하이픈 권장, 예: `medical-v2.svg`)
2. 패널 **[아이콘]** 탭에서 **[목록 새로고침]** 을 누르면 새 파일이 보입니다.

### 시설 유형별로 바꾸기 (같은 유형 마커 전체에 적용)
1. **[아이콘]** 탭에서 시설 유형을 고릅니다.
2. 아이콘 파일을 누르고, **표시 크기**(가로·세로 px, 원본 비율 유지)와 **기준점**(아래 가운데 = 핀 끝, 정가운데 등)을 정합니다.
   - 미리보기의 **빨간 점**이 지도 위 실제 위치에 닿는 기준점입니다.
3. 그 유형의 마커 전체에 바로 적용됩니다. 위치·이름·고유 ID는 바뀌지 않습니다.

### 마커 하나만 다른 아이콘 쓰기
- 마커를 선택 → **"이 마커만 다른 아이콘 쓰기"** → 아이콘·크기·기준점을 고릅니다.
- **[이 아이콘을 ○○ 유형 전체에 적용]** 을 누르면 같은 유형 마커가 모두 그 아이콘으로 바뀝니다(개별 아이콘은 정리됨).
- [아이콘] 탭의 **[이 유형 마커 모두 유형 아이콘으로 맞추기]** 로 개별 아이콘을 한 번에 없앨 수도 있습니다.

### 파일을 못 찾을 때
- 아이콘 파일이 폴더에 없으면 지도에는 **회색 물음표 핀**으로 보이고, [아이콘] 탭에 "파일 없음"으로 표시됩니다.

### 저장하기 (중요)
| 버튼 | 하는 일 | 주의 |
|---|---|---|
| **저장** | 지금 브라우저에 임시 저장 → 새로고침해도 남음 | 다른 브라우저·컴퓨터에는 없음. 브라우저 기록을 지우면 사라질 수 있음 |
| **JSON 내보내기** | 전체 구역을 `daesape-zones-날짜-시간.json` 파일로 내려받기 | **작업이 끝날 때마다 받아서 백업**하세요 |
| **JSON 가져오기** | 내보낸 파일을 골라 다시 불러오기 | 지금 지도의 구역을 파일 내용으로 바꿈. 가져온 뒤 [저장]을 눌러야 새로고침 후에도 남음 |

- 저장하지 않은 변경이 있으면 위에 **● 저장 안 된 변경 있음** 이 표시되고, 창을 닫을 때 한 번 묻습니다.

- 저장·JSON에는 **구역(도형) + 시설 마커 + 시설 유형별 아이콘 설정**이 함께 들어갑니다(파일 버전 3).
- 예전 파일(구역만 있는 버전 1·2)을 가져오면 **구역만 바뀌고, 지금 있는 마커와 아이콘 설정은 그대로** 둡니다.

### 방문객 화면에 실제로 보여 주기 (웹사이트로 옮기기)
방문객 화면은 `지도 json/최종_v18.json`을 공통 원본으로 사용합니다. 관리자 편집 기능과 브라우저 저장본은 실제 배포 파일에 들어가지 않습니다.
1. 관리자 편집에서 **[JSON 내보내기]** 로 파일을 받습니다.
2. 받은 파일을 `지도 json` 폴더에 다음 번호(`최종_v19.json` 등)로 넣고, `src/main.js`가 읽는 파일 이름을 그 번호로 바꿉니다. 이전 번호 파일은 지우지 않고 남겨 둡니다. 로컬 방문객 페이지를 새로고침하면 두 지도에 반영됩니다. 배포 사이트에는 다시 빌드하고 배포하면 반영됩니다.
3. **`public/icons` 폴더도 함께 옮깁니다.** JSON에는 `icons/파일이름` 경로만 저장되고, 쓰는 파일 목록은 JSON의 `iconFiles` 항목과 [아이콘] 탭 아래에 나옵니다. 구역 로고 그림이 있는 **`public/logos` 폴더**도 같이 옮깁니다(어느 구역에 어떤 로고를 쓰는지는 `src/config.js`의 `ZONE_LOGOS`).
   - `npm run build` 를 하면 `public/icons` 가 결과물(`dist/icons`)에 자동으로 복사됩니다.
4. 구역을 다 그린 뒤 처음 화면 범위를 바꾸고 싶으면 `src/config.js`의 `INITIAL_VIEW` 를 고칩니다.
