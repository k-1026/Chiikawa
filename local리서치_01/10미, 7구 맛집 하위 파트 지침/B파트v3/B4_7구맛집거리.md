# B-4 대구 7구 맛집거리 — 세부 지침

> 구분: 고정(7구 참여, 구당 최소 7동) + 연도별(참여 맛집·메뉴) · 기본 지침: 3장 · 진행: 확정 v3 · 최종 수정: 2026-11-16
> 기준 문서: 기본 지침 v1.1 3장 "② 대구 7구 맛집거리", [맛집리스트_V1.md](../../맛집리스트_V1.md)

## 1. 이 파트의 역할

- 공원순환로(B-1에서 배정된 50동+제과점)에 대구 7개 구의 대표 맛집·제과점을 어떻게 배분·선정할지 정한다.
- 읽는 파트: B-5(모집·심사), B-6(매장 연결), C(플리마켓 — 같은 공원순환로 동선 공유)

## 2. 확정 값

### 2-1. 대상 구역

대구 7개 구: 중구·동구·서구·남구·북구·수성구·달서구. **군 지역은 제외**한다.

### 2-2. 구별 부스 수

| 구 | 부스 | 비고 |
| --- | --- | --- |
| 중구, 동구, 서구, 남구, 북구, 수성구 | 각 7동 | 구청 추천·공모 업소 |
| 달서구 | 8동 | 개최지 추가 1동 |
| 합계 | 50동 | |
| 제과점 | 추가 배정 | 50동과 별도. 영업·참여 의사가 확인된 업소 수에 따라 부스 수 결정 |

### 2-3. 맛집 선정 기준

- **구성 단위**: 골목 단위가 아니라 각 구의 유명 맛집(업소 단위)으로 구성. 1업소 1동 원칙.
- **후보 출처**: 구청 추천·지정 업소(예: 북구청 "오래된맛집"), 대구푸드 구·군별 인증업소, 대구10미데이 참여 업소, 공개 모집 신청 업소.
- **영업 조건**: 해당 구에서 실제 영업 중인 매장만. 축제 후 방문 가능해야 한다.
- **메뉴 중복 금지**: 10미 10종 메뉴는 이 구역에서 판매하지 않는다(10미와 겹치는 메뉴를 막기 위함, B-2).
- **구 안 메뉴 중복 제한**: 같은 구 안에서 같은 메뉴는 2곳 이하.
- 개최지 달서구는 구청 음식 안내(달서맛나)와 협업해 추천 업소를 확보한다.

### 2-4. 제과점 추가 배정

- 각 구의 유명 제과점을 기존 맛집 부스(2-2의 50동)에 **추가**로 배정한다. 기존 맛집 후보와 바꾸지 않는다.
- 선정 기준은 맛집과 같다(백년가게·오래된 업소 우선, 실제 영업 중, 같은 구 안 같은 메뉴 2곳 이하).
- 부스 수는 영업·참여 의사가 확인된 업소 수에 따라 정한다 — 50동과 분리된 별도 수량이다(7절 2번, 아직 구체 수 미정).
- 근거 등급: 백년가게·대구푸드·언론 = 공신력 높음 / 플랫폼·블로그·SNS = 참고용(7장 출처 6순위), 확인 필요.

## 3. 에이전트 행동 규칙

**금지**

1. 업소명을 기획 단계에서 확정 출점 업소로 표기하지 않는다 — 서류·시식 심사(B-5) 전까지는 반드시 "후보"로 표기한다.
2. 10미 품목(B-2 2-1) 취급 업소를 7구 맛집거리 후보에 넣지 않는다.
3. 같은 구 안에서 같은 메뉴를 2곳 넘게 선정하지 않는다.
4. 제과점을 기존 맛집 부스(2-2의 50동)와 바꿔치기하지 않는다 — 반드시 추가 배정이다.
5. 영업 여부가 ❔(공개 자료로 확인 못 함)인 후보를 영업 확인 없이 모집 공고에 올리지 않는다.
6. 구청 지정 명단(중구 86곳·동구맛집·달서맛나 68곳 등)을 확보하기 전에 후보 수가 충분하다고 가정하지 않는다 — 2-5처럼 ❔ 비중이 높으면 추가 명단 확보를 먼저 진행한다.
7. 동구·남구에 공개 자료 기반 제과점 후보가 없다고 해서 임의로 업소명을 만들어내지 않는다 — 구청 추천으로만 확보한다(2-4-1).
