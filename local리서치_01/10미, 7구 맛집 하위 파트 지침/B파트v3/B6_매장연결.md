# B-6 매장 연결 — 세부 지침

> 구분: 고정(QR 운영 자체) + 연도별(실제 매장 목록) · 기본 지침: 3장 · 진행: 확정 v2 · 최종 수정: 2026-11-13
> 기준 문서: 기본 지침 v1.1 3장 "실제 매장 연결(상권)", `hyunhee` 브랜치 A파트 PART 구성(K-5 웹페이지, M-6 메인 에이전트 역할 확인)
> 목적: 축제 부스 방문 → 실제 매장 방문으로 이어지는 "축제장 밖" 전환 장치

## 1. 이 파트의 역할

- B-2·B-4에서 확정된 출점 업소를 매장 카드(QR)로 어떻게 안내하고, 축제장 밖 방문까지 어떻게 연결할지 정한다.
- 스탬프 시스템 자체의 기술 구현(K-5 웹페이지)·정산(M-6 메인 에이전트)은 이 문서 범위 밖이다 — "어떤 매장을, 어떤 정보로 QR에 담을지"까지만 다룬다.
- 읽는 파트: K(웹페이지 — QR·스탬프 화면), M(메인 — 스탬프 정산), B-3·B-4(확정 업소 명단 입수)

## 2. 확정 값

### 2-1. 매장 카드(QR) 내용

부스마다 매장 카드(QR)를 비치한다. 카드에 담을 내용:

1. 업소명 + 대표 메뉴
2. 원조 골목·위치 안내(B-3 기준, 골목 없는 품목은 개별 업소 위치)
3. 실제 매장 영업시간·전화번호·지도 링크
4. QR을 찍으면 뜨는 "축제장 밖 방문 혜택" 안내(2-2)

### 2-2. 축제장 밖 스탬프 연계

- 방문객이 축제 후 실제 매장 **3곳**을 방문하고 스탬프를 모으면 혜택을 받는다(예: 대구로페이 — 금액은 예산 단계에서 확정).
- 스탬프 적립·교환의 기술 구현(앱 QR 체크인/현장 도장, 유효 기간)은 **K-5(웹페이지)** 파트 범위.
- 스탬프 할인 금액·정산은 **M-6(메인 에이전트)**, **B(맛집)** 담당이 함께 정한다.

### 2-3. 실제 매장 목록 구성 규칙

- B-2(10미)·B-4(7구)에서 **확정 업소**(B-5의 "후보" 딱지를 뗀 업소)만 목록에 올린다.
- 목록은 매년 B-5 심사 결과 확정 직후 갱신한다. 전년도 목록 재사용 금지.
- 업소가 폐업·이전하면 즉시 목록에서 제외하고 매장 카드 QR도 갱신한다.

### 2-4. 필수 기획 요소

- 기획안에는 "축제 부스 → 실제 매장" 동선을 **1개 이상** 포함한다(3장 연계 원칙).

## 3. 에이전트 행동 규칙

**금지**

1. B-5 심사를 통과하지 못한 "후보" 업소를 매장 카드·실제 매장 목록에 올리지 않는다.
2. 전년도 매장 목록을 그대로 재사용하지 않는다 — 매년 B-5 확정 결과로 갱신한다.
3. 폐업·이전이 확인된 업소를 목록에서 제외하지 않고 방치하지 않는다.
4. 스탬프 적립·교환의 기술 구현이나 정산 금액을 이 문서에서 임의로 정하지 않는다 — K-5·M-6 결정을 따른다.
5. 기획안에 "부스 → 실제 매장" 동선을 0개로 설계하지 않는다.

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| B-5 확정 업소 명단 | 입력 | 심사 종료 직후 | 목록 갱신 보류, 전년도 목록 사용 금지 — 심사 완료까지 "미확정"으로 표시 |
| 스탬프 정산 규칙(할인 금액 등) | 입력(M-6, B) | 매장 카드 제작 전 | 미정 시 QR 안내 문구에 "혜택 내용 추후 공지"로 표시 |
| QR·스탬프 화면 사양 | 입력(K-5) | 매장 카드 제작 전 | 미정 시 QR은 매장 정보만 노출, 스탬프 기능은 추후 연동 |
