# B-2 대구 10미 포장마차 — 세부 지침

> 구분: 고정(10종 출점) + 연도별(부스 재배분·출점 업소) · 기본 지침: 3장 · 진행: 확정 v5 · 최종 수정: 2026-11-17
> 기준 문서: 기본 지침 v1.1 3장 "① 대구 10미 포장마차", B-1(공간 배치), B-3(원조 골목·업소 연결표)

## 1. 이 파트의 역할

- 대구 10미 10종을 메인 구역(10미 존, B-1에서 배정된 최소 25~최대 30부스, 2026-11-18 정정)에 품목당 몇 동씩 배분할지, 그 재배분 규칙을 정한다.
- 읽는 파트: B-3(원조 골목·업소), B-5(모집·심사), B-6(매장 연결), I(성과 — 품목별 KPI)

### 2-2. 부스 배분 공식 (2026-11-18 정정 — 40동 고정 → 최소 25~최대 30부스 범위 + 업소별 요청제)

> **정정(2026-11-18)**: 10미 존 전체 부스 수를 "40동(품목당 4동) 고정"에서 **최소 25부스~최대 30부스** 범위로 바꾼다. 몇 부스를 쓸지는 더 이상 품목 단위로만 정하지 않고, **업소가 B-5 계획서에 "요청 부스 수"를 적어 제출**하는 방식을 더한다(C-3·B-4와 동일한 방식). 아래 품목별 기준은 "목표 배분"으로 남기고, 실제 배분은 요청 합계를 보며 조정한다.

| 구분 | 규칙 |
| --- | --- |
| 전체 범위 | 최소 25부스 ~ 최대 30부스 |
| 품목당 목표 배분 | 균등 배분 시 품목당 2.5~3동(25~30÷10품목) |
| 최소 보장 | 품목당 2동(어떤 품목도 이 밑으로 줄지 않음) |
| 재배분 폭 | 목표 배분 중 최대 1동분만 전년 데이터로 재배분 가능 |
| 1년 차 | 전년 데이터 없음 → 품목당 균등 배분(25~30 범위를 10으로 나눠 가능한 한 균등하게) |
| 2년 차부터 | 품목별 완판 시각·대기 시간·판매량 비교 → 수요 높은 품목에 여유분 추가, 낮은 품목은 최소 2동까지 축소 |
| 연간 변동 상한 | 품목당 ±1동/년 (급격한 변경으로 특정 품목이 사실상 빠지는 상황 방지) — `[가설]`, 팀 확정 전 |
| 업소별 요청 부스 수 | 신청 업소가 B-5 계획서(2-2)에 적어 제출. 품목 목표 배분을 넘겨 더 쓰고 싶으면 이 값으로 요청하고, 전체 범위(25~30)를 넘지 않는 선에서 반영 |

### 2-3. 중복 판매 금지

- 10미 품목은 이 구역(메인 구역 — 10미 존)에서만 판매한다.
- 7구 맛집거리(B-4)는 10미 10종과 겹치지 않는 메뉴로만 업소를 선정한다.

### 2-4. 매장 카드(QR)

- 부스마다 매장 카드(QR)를 비치해 원조 업소·골목 위치를 안내한다(B-3, B-6).

## 3. 에이전트 행동 규칙

**금지**

1. 10미 품목 10종 중 하나라도 임의로 빼거나 다른 메뉴로 바꾸지 않는다 — 품목 교체는 2-1 "고정" 항목이라 담당자 승인 없이 불가.
2. 품목당 부스 수를 2동 미만으로 배분하지 않는다(2-2 최소 보장).
3. 1년 차(전년 데이터 없음)에 임의로 품목별 차등 배분하지 않는다 — 반드시 균등 4동으로 시작한다.
4. 연간 변동 상한(±1동)을 넘겨 한 번에 재배분하지 않는다.
5. 10미 품목을 7구 맛집거리(B-4) 후보에 중복으로 넣지 않는다.
6. 전년 데이터가 불완전(일부 품목만 집계됨 등)한데도 전체 품목을 재배분하지 않는다 — 데이터 없는 품목은 전년과 동일하게 유지한다.
7. 업소별 요청 부스 수(2-2)를 반영해 전체 부스 수를 최소 25부스 밑으로 줄이거나 최대 30부스를 넘기지 않는다.

**일반 규칙**

- 재배분 근거(품목별 완판 시각·대기 시간·판매량)는 반드시 전년도 실측 데이터를 인용하고, 추정치면 `[추정]`과 계산식을 함께 적는다.
