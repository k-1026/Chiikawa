- 10미 포장마차·7구 맛집거리·축제 공식 굿즈 상점이 **두류공원 어디에, 얼마나** 들어가는지를 고정하고, 동선·화기 배치 원칙을 정한다.

- 읽는 파트: D(굿즈 상점 위치), H(운영·안전), K(지도), C(플리마켓 — 동선·비상차량로 공유)

## 3. 에이전트 행동 규칙

**금지 (하나라도 어기면 기획안 반려)**

1. 2·28 자유광장 등 2-1 표에 없는 구역을 임의로 쓰지 않는다. 별도 식음 테이블·휴게 존도 새로 만들지 않는다.
2. 소상공인 플리마켓을 체육공원(다목적운동장)에 독립 배치하지 않는다 — 2026-11-10 결정으로 폐기된 안이다(C-1).
3. 2-1 최소 부스 수(진입로 1곳 / 40동 / 50동+제과점)보다 적게 배치하지 않는다. 늘리는 건 되지만 줄이는 건 금지한다.
4. 화기 부스를 관람석과 같은 방향·바람받이 쪽에 배치하지 않는다(B-3 화기 배치 원칙).
5. 생식 품목 부스를 냉장 설비 확인 없이 "현장 판매"로 기본 배치하지 않는다 — 미확인이면 원조 매장 쿠폰 대체안을 함께 제시한다(B-8).
6. 비상 차량 이동로 없이 공원순환로 동선을 설계하지 않는다.
7. 2-2·2-3에서 `[U]`·`[확인·원문 미확인]`으로 표시된 값을 확정값처럼 쓰지 않는다. 대관·사용 가능 여부도 가정하지 않고 "대관 미확인"으로 표시한다.
8. 3대 프로그램 연계 동선을 0개로 설계하지 않는다 — 최소 1개 포함(3장 연계 원칙).

**일반 규칙**

- 순간 최대 예상 인원이 3만 명을 넘는지 먼저 판단하고, 그에 맞는 안전관리계획 범위를 H(운영) 파트와 함께 정한다. 인원 추정치는 `[추정]`과 계산 근거를 함께 적는다.
- 실제 좌표·세부 지도는 K(지도) 파트 자료를 따른다 — 아직 문서 위치 미확인(7절 참고).

# B-2 대구 10미 포장마차 — 세부 지침

> 구분: 고정(10종 출점) + 연도별(부스 재배분·출점 업소) · 기본 지침: 3장 · 진행: 확정 v2 · 최종 수정: 2026-11-13
> 기준 문서: 기본 지침 v1.1 3장 "① 대구 10미 포장마차", B-1(공간 배치), B-3(원조 골목·업소 연결표)

## 1. 이 파트의 역할

- 대구 10미 10종을 코오롱 야외음악당 둘레(B-1에서 배정된 40동)에 품목당 몇 동씩 배분할지, 그 재배분 규칙을 정한다.
- 읽는 파트: B-3(원조 골목·업소), B-5(모집·심사), B-6(매장 연결), I(성과 — 품목별 KPI)

## 2. 확정 값

### 2-1. 출점 품목 (고정)

### 2-2. 부스 배분 공식

| 구분 | 규칙 |
| --- | --- |
| 기준 | 품목당 4동(B-1 합계 40동 = 10품목 × 4동) |
| 최소 보장 | 품목당 2동 |
| 재배분 폭 | 기준 4동 중 최대 2동분(=4동−2동)만 전년 데이터로 재배분 가능 |
| 1년 차 | 전년 데이터 없음 → 품목당 균등 4동 |
| 2년 차부터 | 품목별 완판 시각·대기 시간·판매량 비교 → 수요 높은 품목에 여유분 추가, 낮은 품목은 최소 2동까지 축소 |
| 연간 변동 상한 | 품목당 ±1동/년 (급격한 변경으로 특정 품목이 사실상 빠지는 상황 방지) — `[가설]`, 팀 확정 전 |

### 2-3. 중복 판매 금지

- 10미 품목은 이 구역(코오롱 야외음악당 둘레)에서만 판매한다.
- 7구 맛집거리(B-4)는 10미 10종과 겹치지 않는 메뉴로만 업소를 선정한다.

### 2-4. 매장 카드(QR)

- 부스마다 매장 카드(QR)를 비치해 원조 업소·골목 위치를 안내한다(B-3, B-6).

## 3. 에이전트 행동 규칙

**금지**

1. 10미 품목 10종 중 하나라도 임의로 빼거나 다른 메뉴로 바꾸지 않는다 — 품목 교체는 2-1 "고정" 항목이라 담당자 승인 없이 불가.
2. 품목당 부스 수를 2동 미만으로 배분하지 않는다(2-2 최소 보장).
3. 1년 차(전년 데이터 없음)에 임의로 품목별 차등 배분하지 않는다 — 반드시 균등 4동으로 시작한다.
4. 연간 변동 상한(±1동)을 넘겨 한 번에 재배분하지 않는다.
5. 10미 품목을 7구 맛집거리(B-4) 후보에 중복으로 넣지 않는다.
6. 전년 데이터가 불완전(일부 품목만 집계됨 등)한데도 전체 품목을 재배분하지 않는다 — 데이터 없는 품목은 전년과 동일하게 유지한다.

**일반 규칙**

- 재배분 근거(품목별 완판 시각·대기 시간·판매량)는 반드시 전년도 실측 데이터를 인용하고, 추정치면 `[추정]`과 계산식을 함께 적는다.

## 1. 이 파트의 역할

- 공원순환로(B-1에서 배정된 50동+제과점)에 대구 7개 구의 대표 맛집·제과점을 어떻게 배분·선정할지 정한다.
- 읽는 파트: B-5(모집·심사), B-6(매장 연결), C(플리마켓 — 같은 공원순환로 동선 공유)

## 2. 확정 값

### 2-1. 대상 구역

대구 7개 구: 중구·동구·서구·남구·북구·수성구·달서구. **군 지역은 제외**한다.

### 2-2. 구별 부스 수

| 구 | 부스 | 비고 |
| --- | --- | --- |
| 중구, 동구, 서구, 남구, 북구, 수성구 | 각 7동 | 구청 추천·공모 업소 |
| 달서구 | 8동 | 개최지 추가 1동 |
| 합계 | 50동 | |
| 제과점 | 추가 배정 | 50동과 별도. 영업·참여 의사가 확인된 업소 수에 따라 부스 수 결정 |

### 2-3. 맛집 선정 기준

- **구성 단위**: 골목 단위가 아니라 각 구의 유명 맛집(업소 단위)으로 구성. 1업소 1동 원칙.
- **후보 출처**: 구청 추천·지정 업소(예: 북구청 "오래된맛집"), 대구푸드 구·군별 인증업소, 대구10미데이 참여 업소, 공개 모집 신청 업소.
- **영업 조건**: 해당 구에서 실제 영업 중인 매장만. 축제 후 방문 가능해야 한다.
- **메뉴 중복 금지(10미와)**: 10미 10종 메뉴는 이 구역에서 판매하지 않는다(B-2).
- **구 안 메뉴 중복 제한**: 같은 구 안에서 같은 메뉴는 2곳 이하.
- 개최지 달서구는 구청 음식 안내(달서맛나)와 협업해 추천 업소를 확보한다.

### 2-4. 제과점 추가 배정

- 각 구의 유명 제과점을 기존 맛집 부스(2-2의 50동)에 **추가**로 배정한다. 기존 맛집 후보와 바꾸지 않는다.
- 선정 기준은 맛집과 같다(백년가게·오래된 업소 우선, 실제 영업 중, 같은 구 안 같은 메뉴 2곳 이하).

### 2-5. 후보 조사 현황

> 전수 조사 결과: [맛집리스트_V1.md](../../맛집리스트_V1.md) "2. 대구 7구 맛집 출점 후보" 참고. 구별 7곳(달서구 8곳)씩, 모두 **후보**다.

| 구역 | 후보 수 | ✅ | ◐ | ⚠️ | ❔ |
| --- | --- | --- | --- | --- | --- |
| 7구 전체 | 50 | 3 | 5 | 1 | 41 |

## 3. 에이전트 행동 규칙

**금지**

1. 업소명을 기획 단계에서 확정 출점 업소로 표기하지 않는다 — 서류·시식 심사(B-5) 전까지는 반드시 "후보"로 표기한다.
2. 10미 품목(B-2 2-1) 취급 업소를 7구 맛집거리 후보에 넣지 않는다.
3. 같은 구 안에서 같은 메뉴를 2곳 넘게 선정하지 않는다.
4. 제과점을 기존 맛집 부스(2-2의 50동)와 바꿔치기하지 않는다 — 반드시 추가 배정이다.
5. 영업 여부가 ❔(공개 자료로 확인 못 함)인 후보를 영업 확인 없이 모집 공고에 올리지 않는다.
6. 구청 지정 명단(중구 86곳·동구맛집·달서맛나 68곳 등)을 확보하기 전에 후보 수가 충분하다고 가정하지 않는다 — 2-5처럼 ❔ 비중이 높으면 추가 명단 확보를 먼저 진행한다.

# B-6 매장 연결 — 세부 지침

> 구분: 고정(QR 운영 자체) + 연도별(실제 매장 목록) · 기본 지침: 3장 · 진행: 확정 v2 · 최종 수정: 2026-11-13
> 기준 문서: 기본 지침 v1.1 3장 "실제 매장 연결(상권)", `hyunhee` 브랜치 A파트 PART 구성(K-5 웹페이지, M-6 메인 에이전트 역할 확인)
> 목적: 축제 부스 방문 → 실제 매장 방문으로 이어지는 "축제장 밖" 전환 장치

## 1. 이 파트의 역할

- B-2·B-4에서 확정된 출점 업소를 매장 카드(QR)로 어떻게 안내하고, 축제장 밖 방문까지 어떻게 연결할지 정한다.
- 스탬프 시스템 자체의 기술 구현(K-5 웹페이지)·정산(M-6 메인 에이전트)은 이 문서 범위 밖이다 — "어떤 매장을, 어떤 정보로 QR에 담을지"까지만 다룬다.
- 읽는 파트: K(웹페이지 — QR·스탬프 화면), M(메인 — 스탬프 정산), B-3·B-4(확정 업소 명단 입수)

## 2. 확정 값

### 2-1. 매장 카드(QR) 내용

부스마다 매장 카드(QR)를 비치한다. 카드에 담을 내용:

1. 업소명 + 대표 메뉴
2. 원조 골목·위치 안내(B-3 기준, 골목 없는 품목은 개별 업소 위치)
3. 실제 매장 영업시간·전화번호·지도 링크
4. QR을 찍으면 뜨는 "축제장 밖 방문 혜택" 안내(2-2)

### 2-2. 축제장 밖 스탬프 연계

- 방문객이 축제 후 실제 매장 **3곳**을 방문하고 스탬프를 모으면 혜택을 받는다(예: 대구로페이 — 금액은 예산 단계에서 확정).
- 스탬프 적립·교환의 기술 구현(앱 QR 체크인/현장 도장, 유효 기간)은 **K-5(웹페이지)** 파트 범위.
- 스탬프 할인 금액·정산은 **M-6(메인 에이전트)**, **B(맛집)** 담당이 함께 정한다.

### 2-3. 실제 매장 목록 구성 규칙

# B-9 출점 업소 모집 안내문(문서 초안) — 세부 지침

> 구분: 연도별(매년 새로 작성) · 기본 지침: 4-0, 4-2, 10장 · 진행: 초안 v2 · 최종 수정: 2026-11-13
> 기준 문서: B-1~B-8 지침, `hyunhee` 브랜치 A-10(문서 초안 구조 참고)

## 1. 이 파트의 역할

- B-1~B-8의 확정 값을 바탕으로 실제 출점 업소 모집 공고문·판매 기록 양식을 작성한다.
- ⚠️ A-10(사투리 콘텐츠 문서 초안)에 따르면 원래 설계상 "문서 초안은 메인 에이전트(M)가 작성하고 각 PART는 내용만 제공"하는 구조다. B-9는 그 분업 이전에 **B파트 자체적으로 먼저 완성 문서를 만들어 둔 것** — 추후 메인 에이전트 체계가 갖춰지면 이 문서의 표·문구를 M에 "제공할 내용"으로 재사용한다(6절 참고).

## 2. 확정 값 — 모집 공고 초안

### 2027 대구 사투리 축제 「타지에서 온 말손님」 — 먹거리 부스 출점 업소 모집 안내

대구 사투리 축제는 대구 10미 포장마차·대구 7구 맛집거리에 함께할 출점 업소를 모집합니다. 대구의 원조 맛집과 구별 대표 맛집을 소개하고, 축제 방문객이 축제가 끝난 뒤에도 실제 매장을 찾아가도록 연결하는 자리입니다.

**1. 모집 분야**

| 구역 | 모집 품목·대상 | 부스 수 |
| --- | --- | --- |
| ① 대구 10미 포장마차 (야외음악당 둘레) | 따로국밥·찜갈비·막창·무침회·납작만두·누른국수·야끼우동·뭉티기·복어불고기·논메기매운탕 | 품목당 최소 2동, 기준 4동 |
| ② 대구 7구 맛집거리 (공원순환로) | 중·동·서·남·북·수성·달서구 대표 맛집 (10미 메뉴 제외) | 구당 7동, 달서구 8동 |
| ③ 제과점 (7구 맛집거리 추가 배정) | 구별 유명 제과점 | 참여 확정 업소 수에 따라 결정 |

- ①은 원조 골목·업소(상인회 소속), 대구10미데이 참여 업소 우선 모집
- ②·③은 구청 추천 업소와 공개 모집 업소를 함께 선정
- ②·③은 한 구 안에서 같은 메뉴를 2곳까지만 선정

**2. 자격 요건**

- 대구 해당 구에서 실제 영업 중인 업소(축제 후에도 방문 가능해야 함)
- 영업 등록·영업자 신고 완료, 보건증·위생교육 이수증 보유
- 프랜차이즈 업소 제외
- ①은 신청 메뉴가 해당 10미 품목과 일치, ②·③은 10미 10종 메뉴와 겹치지 않아야 함

**3. 모집 일정** `[U]`(연도별 확정)

**4. 제출 서류**

1. 참가 신청서(업소명, 사업자등록증, 대표 메뉴, 희망 구역)

3. 대표 메뉴 사진·가격표
4. 대구 연계성 소개서(원조 여부·업력·구청 지정 이력 등)

**5. 심사 기준 (100점, B-5 참고)** — 70점 미만 제외. 신청 부족 시 2순위 보충 또는 1업소 다부스.

**6. 참여 혜택**

- 부스 임차료 없음(수수료 조건은 예산 확정 후 별도 공지) `[U]`

- 축제 종료 후 "축제장 밖 스탬프" 연계로 실제 매장 방문객 유입 효과

**7. 운영 시 유의 사항**

- 메뉴판에 사투리 병기(비하·과장 표기 금지)
- 생식 품목은 냉장 설비 확인 안 되면 원조 매장 쿠폰 대체 가능
- 화기 품목은 안전 체크리스트 준수
- 선정 전까지 "후보" 신분

**8. 문의처**

- `[U]` 담당 부서·연락처는 주최 측 확정 후 기입
