# 협업 사례 조사 V1: 우리 축제와 비슷한 지역 축제

- 목적: 할인쿠폰·환급, 교통·숙박·여행 연계, 주변 상권 연계 사례 참고
- 기간: 2022~2026
- 표기:
  - `[확인]`: 기사 원문으로 확인
  - `[요약]`: 검색 결과 요약으로만 확인. 원문 재확인 필요
  - `[미확인]`: 자료 없음

## 0. 축제 선정

- 사투리 축제 (강릉단오제 사투리 경연, 동해 팔도사투리 대회, 안동 사투리 경연): 2022~2026년 협업 사례 자료가 거의 없어 제외
- 대신 우리 축제와 성격이 비슷하면서 협업 사례가 많은 축제를 골랐음
  - 비슷한 점: 지역 문화가 주제, 먹거리, 축제장 → 골목상권 연계

| 축제 | 비슷한 점 | 협업 핵심 |
| --- | --- | --- |
| 광주 추억의 충장축제 | 광역시 원도심 문화축제, 상권 활성화가 목적 | 구 지역화폐 + 은행 이동점포 + 영수증 추첨 |
| 강진 축제·반값여행 | 지역 축제 → 관내 상가 소비 연결 | 방문 인증 + 영수증 → 상품권 환급, 여행비 절반 환급 |
| 화천 산천어축제 | 체험료를 지역 소비로 되돌리는 구조 | 체험료 일부 → 상품권·농특산물 교환권 |
| 안동국제탈춤페스티벌 | 경북 전통문화 축제, 원도심 개최 | 반값여행, 숙박 할인 (축제 직접 연계는 미확인) |

## 1. 광주 추억의 충장축제 (광주 동구)

- 개요: 2025년 제22회, 10월 15~19일, 충장로 원도심 일대. 문체부 명예 문화관광축제 `[확인]`

### 1-1. 동구랑페이 영수증 추첨 (2025) `[확인]`

| 항목 | 내용 |
| --- | --- |
| 주체 | 광주 동구청 |
| 조건 | 축제 기간 동구 가맹점에서 동구랑페이로 하루 10만 원 이상 결제, 영수증 지참 (여러 장 합산 가능) |
| 응모 | 축제장 이벤트 부스 |
| 혜택 | 매일 100명 추첨, 5만 원 선불카드 (5일간 총 500명, 총 2,500만 원) |
| 수령 | 다음 날 개별 통보, 부스에서 본인 확인 후 수령 |

### 1-2. 광주은행 이동점포 (2025) `[확인]`

- 10월 15~17일 축제장에서 동구랑페이 현장 구매 가능
- 동구랑페이는 2025년 9월 22일 첫 발행. 첫날 약 1억 5천만 원 판매, 누적 약 17억 원, 가맹점 약 2,500곳

### 1-3. 기타 `[요약]`

- 2026년 제23회 축제에 맞춰 동구랑페이 40억 원 추가 발행, 15% 할인 (50만 원권을 42만 5천 원에 판매)
- 상권 행사 '충장라온페스타'와 함께 야간 프로그램 운영. 2022~2025년 1만 3천 명 방문, 매출 효과 약 24억 7천만 원

### 시사점 `[해석]`

- **지역화폐 발행 + 축제 + 은행** 3자 협업: 화폐 판매는 은행 이동점포, 추첨 예산은 구청, 소비는 원도심 가맹점
- 축제장 안이 아니라 **축제장 밖 가맹점 영수증**을 응모 조건으로 해서 골목으로 동선이 이어짐
- 우리 축제 적용: 대구로페이 + iM뱅크 이동점포 + 원조 골목 영수증 추첨

## 2. 강진 축제 연계 환급 + 반값여행 (전남 강진군)

### 2-1. 축제 연계 상품권 환급 (2024 서부해당화 봄꽃축제) `[확인]`

| 항목 | 내용 |
| --- | --- |
| 기간 | 2024년 4월 6~14일, 부스 10~18시 |
| 조건 | 축제장에서 신청서·방문 도장을 받고, 같은 날 강진 상가에서 5만 원 이상 카드 결제 |
| 혜택 | 5만 원 이상 결제 시 강진사랑상품권 5천 원, 10만 원 이상 결제 시 1만 원. 기간 중 1인 1회 |
| 예산 | 1억 원, 소진 시 종료 |
| 제외 | 반값여행 예약자 (중복 방지), 현금·제로페이·캡처 영수증, 연매출 30억 원 이상 업소 |
| 신청 | 읍내 교환 부스, 실물 신분증 |

- 2025년 갈대축제에서도 이용 사진과 SNS 후기를 남기면 모바일 상품권을 주는 연계 행사 운영 (11월 15일까지) `[요약]`

### 2-2. 강진 누구나 반값여행 (2024 시작) `[확인]`

- 내용: 2인 이상 관광객이 강진에서 쓴 여행비의 절반을 강진사랑상품권으로 환급 (전국 최초)
- 한도: 팀당 최대 20만 원, 개인 최대 10만 원
- 사용처: 관광지, 식당, 카페, 농수산물 판매점
- 2024년 예산 22억 원. 같은 해 강진 방문객 약 282만 명
- 경제효과 (강진군 발표): 생산 유발 240억 원, 부가가치 100억 원 이상, 취업 유발 약 2,200명
  - 목포대 교수 분석 (10개월): 생산 150억 원, 부가가치 60억 원, 취업 2,213명
- 전국 확산: 2026년 정부 '지역사랑 휴가지원제' 시범사업
  - 대상: 인구감소지역 20곳, 10만 팀 목표
  - 예산: 국비 65억 원, 국비 30% · 지방비 70%
  - 하동·상주·해남·여수 등 벤치마킹

### 시사점 `[해석]`

- **방문 인증 + 관내 영수증** 2단계 조건: 축제장 방문과 실제 골목 소비를 둘 다 확인
- 중복 수혜 방지(반값여행 예약자 제외)와 대형 업소 제외(연매출 30억 원 이상)로 소상공인에게 효과 집중
- 대구는 인구감소지역이 아니라서 정부 '지역사랑 휴가지원제' 대상이 될 가능성은 낮음 `[가설]` → 시·구 자체 예산이나 재단 협업 필요

## 3. 화천 산천어축제 (강원 화천군)

### 3-1. 체험료 일부 환급 (2026) `[요약]`

- 축제 입장은 무료, 체험은 유료
- 얼음낚시 일반(중학생 이상) 15,000원 중 5,000원을 농특산물 교환권으로 환급
- 밤낚시는 화천사랑상품권으로 환급
- 2026년 1월 10일~2월 1일, 방문객 100만 명 돌파 보도

### 3-2. 2027 개편 검토안 (2026년 10월 기준, 미확정) `[확인]`

- 성인 체험료 15,000원 → 약 25,000원, 환급 5,000원 → 약 15,000원 (농특산물 교환권 + 화천사랑상품권)
- 목적: 관광객 실부담은 거의 그대로 두고, 지역에 남는 소비를 늘림
- 주민 소득 아이디어: 상품권 경품, 지역 공예가·사회적기업 부스 확대, 농특산물 현장 택배, 밀키트, 야시장, 교환권 온라인 판매
- 군청 회의에서 민간단체·부서 제안 약 100건 수렴

### 시사점 `[해석]`

- **참가비를 받고 일부를 지역화폐로 돌려주는 구조**: 축제 수입과 지역 소비를 같이 확보
- 우리 축제 적용: 유료 프로그램(예: 사투리 토론 관람석, 체험)이 생기면 요금 일부를 대구로페이·원조 골목 쿠폰으로 환급하는 안 검토 가능

## 4. 안동국제탈춤페스티벌 (경북 안동시)

- 개요: 2026년 9월 24일~10월 4일, 11일간. 안동역·탈춤공원·원도심·하회마을. 문체부 글로벌 축제 선정 `[요약]`

### 4-1. 안동 반값여행·숙박 페스타 (2026) `[요약]`

- 반값여행: 여행 3일 전 사전 신청, 지정 관광지 1곳 이상 방문 인증 → 여행 지출액 50%를 모바일 안동사랑상품권으로 환급
- 안동숙박 페스타: '경북봐야지' 누리집에서 최대 7만 원 숙박 할인 쿠폰 발급 (9월 2일까지)
- 2025년 하반기 정부 숙박세일페스타에서 안동은 산불 특별재난지역으로 7만 원 이상 숙박 시 5만 원 할인
- `[미확인]` 탈춤축제 관람과 직접 묶은 혜택인지 여부, 실적

### 시사점 `[해석]`

- 축제 자체보다 **시 단위 관광 정책(반값여행·숙박 할인)을 축제 기간에 맞춰** 운영하는 방식
- 우리 축제 적용: 대구시 숙박 연계 사업(2026 치맥 'STAY & 골목 PLAY')을 우리 축제 기간에도 운영하도록 시에 제안

## 6. 우리 축제에 적용할 후보 (회의 안건) ❓

1. **원조 골목 영수증 추첨·환급**: 축제장 스탬프 + 원조 골목 가맹점 영수증 → 대구로페이 지급 (강진·충장 방식)
2. **iM뱅크 이동점포 + 대구로페이 현장 판매** (충장 방식)
3. **유료 프로그램 요금 일부 환급** (화천 방식). 유료 프로그램을 운영할지부터 결정
4. **외지 관광객 숙박 연계**: 대구시 'STAY & 골목 PLAY'를 우리 축제 기간에도 운영하도록 제안 (치맥·안동 방식)
5. **중복 수혜·대형 업소 제외 규칙** (강진 방식)
