# C-6. 연계 — 지침

> 근거: `기본지침서 v1.1` 3장 "3대 프로그램 연계 원칙" + "소상공인 플리마켓 — 운영"
> 구분: 연도별 변경

## 1. 스탬프 적립 연계 (→ M-6)

- 플리마켓 구매 시 스탬프를 적립하고, 축제 공식 굿즈 상점에서 교환할 수 있게 한다(3장 연계 원칙 — "플리마켓 구매 시 스탬프 적립 → 축제 공식 굿즈 상점에서 교환").
- 스탬프 적립 지점의 구체적인 위치·운영 방식(앱 QR인지 현장 도장인지 등)은 **M-6**(담당 파트) 문서를 따른다. → ❓ M-6 문서 위치를 팀에 확인 후 이 문서에 링크 추가 필요
- 이 문서(C-6)가 책임지는 범위는 "플리마켓 구매가 스탬프 적립 대상이라는 것"까지이고, 스탬프 시스템 자체의 설계는 M-6 범위다. (B-6 매장 연결이 G 파트 스탬프를 참고하는 것과 같은 구조)

## 2. 굿즈 상점과 품목 중복 확인 (→ D)

- C-2(참가 대상·품목 원칙)에 따라 플리마켓에서는 **축제 공식 굿즈(마스코트)와 같은 품목을 판매할 수 없다.**
- 실제로 어떤 품목이 "같은 품목"에 해당하는지는 **D**(축제 공식 굿즈 상점 담당 파트)의 최종 굿즈 구성표와 대조해 확인한다. → ❓ D 파트 굿즈 구성표 위치를 팀에 확인 후 이 문서에 링크 추가 필요
- 셀러 선정(C-3) 단계에서 D 파트의 굿즈 품목 목록을 미리 받아 신청 품목과 겹치는지 확인하고, 겹치면 선정에서 제외하거나 품목 변경을 요청한다.

## 3. 변경 범위

- **연도별 변경**: 스탬프 적립 지점의 세부 운영, D 파트 굿즈 구성과의 중복 확인 결과
- **고정**: "플리마켓 구매 → 스탬프 적립" 연계 자체, "굿즈 상점과 품목 중복 금지" 원칙
