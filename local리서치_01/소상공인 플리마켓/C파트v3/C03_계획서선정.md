# C-3 계획서·선정 — 세부 지침

> 구분: 고정 · 기본 지침: 3장, 7장 · 진행: 확정 v3 · 최종 수정: 2026-11-17
> 기준 문서: 기본 지침 v1.1 3장 "소상공인 플리마켓 — 참가 대상·선정 방식" + "선정 기준(100점)", 7장 조사·근거 규칙
> 참고 사례: [축제 사례 V1.md](../../축제%20사례V1/축제%20사례%20V1.md) 카드 ③-1(구미 소상공인 희망 플리마켓, 40부스), ③-2(영등포 청년야장 마켓, 약 15개소·청년 소상공인 우대)

## 1. 이 파트의 역할

- C-1·C-2 후보(참가 희망 셀러)를 실제로 모집·심사해 "신청"에서 "확정 셀러"로 전환하는 절차와 기준을 정한다.
- 읽는 파트: C-1(부스 수 전제), C-2(허용·금지 품목 기준), C-6(스탬프 활용 방안 제출 연동), C-7(모집 공고·제출 서류 양식)

## 2. 확정 값

### 2-1. 계획서 필수 항목

1. 사업자 정보 (사업자등록증 등)
2. 판매 품목·가격표
3. 대구 연계성 (대구 소재·로컬 브랜드임을 보여주는 내용)
4. 부스 연출안
5. 체험 운영 여부
6. 예상 판매 수량
7. **스탬프 활용 방안**(자기 부스에서 축제장 내 스탬프를 어떻게 안내·운영할지 계획, 2026-11-17 신설 — C-6 1절 연동)

### 2-2. 선정 기준 (100점)

| 기준 | 배점 |
| --- | --- |
| 대구 로컬성 | 30 |
| 상품성·독창성 | 30 |
| 가격 적정성 | 20 |
| 사투리·대구 테마 연계 (가점, 필수 아님) | 20 |

- 계획서 내용으로 채점한다.
- 근거: 팀 2027 기획안 선정 기준 + 공공 플리마켓 공고의 심사 항목(독창성·가격 적정성·취지 부합) `[확인]`

> ⚠️ **사람이 해야 하는 일**: "상품성·독창성"·"대구 로컬성" 항목은 계획서 내용을 보고 사람이 주관적으로 판단해야 하는 평가라 에이전트가 대신 채점할 수 없다. 심사위원(사람)이 직접 채점하고, 에이전트는 채점 결과를 입력받아 집계·동점 처리·품목 분포 확인만 한다.

### 2-3. 동점 처리

- 동점 시 **대구 로컬성 점수가 높은 셀러를 우선** 선정한다.

### 2-4. 품목 다양성 반영

- C-2(참가 대상·품목 원칙)의 "최대한 종류가 다양하게" 원칙에 따라, 이미 선정된 품목과 크게 겹치는 신청은 "상품성·독창성" 항목에서 낮게 평가한다.

### 2-5. 참고 — 다른 지역 플리마켓 모집 방식

- 구미 소상공인 희망 플리마켓: 판매 부스 40개, 구미사랑상품권 구매 시 5% 할인 혜택. 입점 선정 기준·참가비는 공개되지 않았다 — 이 수치는 구미의 관측값일 뿐, 대구 기준으로 쓰지 않는다.
- 영등포 청년야장 마켓: 약 15개소 내외, 청년 소상공인 우선, 품목을 즉석 먹거리·수공예품·친환경 제품으로 구분해 모집. 대구는 조리 음식(즉석 먹거리)을 플리마켓에서 제외한다는 점이 다르다(C-2 참고).

### 2-6. 신청 부족 시 보충 규칙 (2026-11-17 신설)

> **결정(2026-11-17)**: 자격 갖춘 신청이 부스 수(15동, C-1)에 못 미칠 때의 순서를 정한다.

1. 접수 마감 후 자격 갖춘 신청이 15동 미만이면, 먼저 **모집 기간을 연장**해 2차 공고를 낸다.
2. 2차 공고 후에도 부족하면, 판매:체험 구성비(C-1 2-2, 기본 12:3)를 **그 해 신청 현황에 맞춰 조정**해 채운다 — 예: 체험 신청이 적고 판매 신청이 많으면 체험 동수를 줄이고 판매 동수를 늘린다(C-1 2-2 "검증 방법"과 동일한 조정 메커니즘).
3. 그래도 15동에 못 미치면 **최소 규모를 축소**해 운영한다 — 이는 C-1 3절 2번(최소 부스 수 미만 축소 금지)의 예외이며, 신청 부족이 실제로 확인된 경우에만 적용한다.

### 2-7. 위반 시 제재 (다음 해 참여 불가)

> **결정(2026-11-17)**: C파트의 위반 제재를 **B-5와 동일한 체계**로 맞춘다 — 안전·부정 관련 위반은 즉시 다음 해 참여 불가, 경미한 위반은 경고 누적 2회 시 다음 해 참여 불가.

| 위반 유형 | 처리 |
| --- | --- |
| 금지 품목(조리 음식·마스코트 무단 사용) 판매 적발 | 즉시 다음 해 참여 불가 |
| 현금 매출 고의 누락 신고 적발 | 즉시 다음 해 참여 불가 |
| 부스 임의 양도(신청하지 않은 제3자에게 운영을 넘김) | 즉시 다음 해 참여 불가 |
| 신청 품목 외 판매(계획서에 없는 품목 판매) | 1회 경고 → 재적발 시 다음 해 참여 불가 |
| 사전 통보 없는 판매 품목 변경 | 1회 경고 → 재적발 시 다음 해 참여 불가 |

- 경고 누적 2회(위반 종류가 달라도 합산)면 그 즉시 다음 해 참여 불가로 전환한다.
- "다음 해 참여 불가"는 1년 제한이다. 재적발을 반복하면 영구 참여 제한 여부를 팀 회의에서 정한다(7절 2번).
- C-4(수수료·정산) 2-4의 "정산 기한 미준수 → 다음 해 참여 불가" 규칙은 이 표와 별개로 그대로 유지한다 — 단순 지연 제출과 고의적 매출 누락은 다르게 처리한다.

## 3. 에이전트 행동 규칙

**금지**

1. 계획서 필수 항목(2-1) 중 하나라도 누락된 신청을 심사 대상에 포함하지 않는다.
2. "스탬프 활용 방안"(2-1 7번)을 제출하지 않은 셀러를 심사 통과로 처리하지 않는다 — 제출 전까지 보완 요청 상태로 둔다.
3. 2-2 배점표를 벗어난 기준으로 임의 채점하지 않는다 — "상품성·독창성" 등 주관적 항목은 사람이 채점한 결과만 입력받는다(2-2 "사람이 해야 하는 일").
4. 품목 분포 확인 없이 비슷한 품목이 몰린 신청을 그대로 선정하지 않는다(2-4, C-2 2-3).
5. C-2의 금지 품목(조리 음식, 마스코트 사용 굿즈)을 포함한 신청을 심사 대상에서 제외하지 않고 진행하지 않는다.
6. 동점 처리 기준(대구 로컬성 우선)을 따르지 않고 임의로 순위를 정하지 않는다.
7. 신청이 15동 미만인 상태에서 보충 규칙(2-6)을 거치지 않고 바로 축소·종료하지 않는다 — 모집 연장 → 비율 조정 → 축소 순서를 따른다.
8. 2-7의 즉시 제재 대상(금지 품목 판매, 현금 매출 고의 누락, 부스 임의 양도)을 경고로 낮춰서 봐주지 않는다 — 반드시 그 즉시 다음 해 참여 불가로 처리한다.

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| 심사위원 채점 결과(2-2) | 입력(심사위원) | 심사 종료 직후 | 미입력 신청은 "심사 대기"로 표시 |
| 셀러별 스탬프 활용 방안 | 조사(신청 접수) | 접수 마감 후 | 미제출 셀러는 보완 요청, 보완 전까지 심사 통과 보류 |
| 자격 갖춘 신청 수(15동 대비) | 조사(접수 마감 집계) | 접수 마감 시 | 15동 미만이면 2-6 보충 규칙(모집 연장→비율 조정→축소) 적용 |
| 위반 적발·경고 기록 | 입력(현장 운영, H) | 적발 시 즉시 | 기록 누락 시 제재 보류, H(운영)에 확인 요청 |
