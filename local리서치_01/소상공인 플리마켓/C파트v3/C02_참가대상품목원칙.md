# C-2 참가 대상·품목 원칙 — 세부 지침

> 구분: 고정 · 기본 지침: 3장 · 진행: 확정 v3 · 최종 수정: 2026-11-17
> 기준 문서: 기본 지침 v1.1 3장 "소상공인 플리마켓 — 참가 대상·선정 방식" + "품목 원칙"

## 1. 이 파트의 역할

- 플리마켓 참가 자격(누가 신청할 수 있는지)과 허용·금지 품목 원칙을 정한다.
- 읽는 파트: C-3(선정 심사 연동), C-6(마스코트 사용 확인 연동), D(굿즈 — 마스코트 IP 기준), B-2·B-4(먹거리 품목 분리 기준)

## 2. 확정 값

### 2-1. 참가 대상

- **대구 소재 소상공인·로컬 브랜드(사업자 보유) 우선**으로 모집한다.
- 참가 희망 셀러가 계획서를 제출하고, 주최 측(우리)이 심사·선정한다(C-3 참고).

### 2-2. 허용 품목

- 핸드메이드 상품
- 로컬 굿즈·디자인 상품
- 대구 특산 가공품 (**영업 신고된 업체만**)
- 체험 프로그램

### 2-3. 품목 다양성 원칙

- **최대한 종류(품목)가 다양하게 준비되도록** 선정한다. 비슷한 품목(예: 캔들 셀러만 5곳)이 몰리지 않게 심사 단계에서 품목 분포를 확인한다.
- C-3 선정 기준의 "상품성·독창성" 항목과 연동해, 이미 선정된 품목과 겹치는 신청은 상대적으로 낮은 점수를 받을 수 있다.

### 2-4. 금지 품목

- **조리 음식 판매 제외**: 먹거리는 B-2(10미 포장마차)·B-4(7구 맛집거리) 구역에서만 판매한다. 플리마켓에서는 조리 음식을 팔지 않는다.
- **대키미·외지몽 공식 마스코트를 사용한 굿즈 판매 금지**: D(굿즈 상점)와 같은 종류의 상품(키링, 에코백 등)을 파는 건 상관없지만, 마스코트 캐릭터·이름·이미지를 쓴 상품은 D에서만 판매한다. 확인 절차는 C-6(연계)을 따른다.

## 3. 에이전트 행동 규칙

**금지**

1. 조리 음식을 플리마켓 허용 품목으로 승인하지 않는다 — 먹거리는 B-2·B-4 구역에서만 판매한다.
2. 마스코트(대키미·외지몽) 사용 굿즈를 셀러 품목으로 승인하지 않는다 — D에서만 판매한다(C-6 확인 절차 연동).
3. 품목 분포를 확인하지 않고 비슷한 품목이 몰린 신청 목록을 그대로 승인하지 않는다 — C-3 심사에서 분포를 확인한다.
4. 영업 신고가 안 된 가공품 셀러를 허용 품목으로 승인하지 않는다.
5. 대구 소재가 아니거나 로컬 브랜드가 아닌 셀러를 우선순위 확인 없이 선정하지 않는다(2-1).

## 4. 매년 받을 입력 · 조사할 항목

| 항목 | 입력/조사 | 받는 시점 | 없을 때 처리 |
| --- | --- | --- | --- |
| 신청 품목 목록·분포 | 조사(C-3 접수 결과) | 접수 마감 후 | 분포 확인 전까지 선정 보류 |
| 마스코트 사용 여부 확인 결과 | 입력(D, C-6 연동) | 심사 전 | 미확인 품목은 C-6 기준으로 재확인 요청 |

## 5. 다른 파트 연결

| 연결 파트 | 넘겨주는 것 |
| --- | --- |
| C-3(계획서·선정) | 허용·금지 품목 기준, 품목 다양성 원칙 |
| C-6(연계) | 마스코트 사용 확인 기준 |
| D(굿즈) | 마스코트 IP 가이드 참고 요청 |
| B-2·B-4 | 먹거리 품목은 해당 구역에서만 판매한다는 전제 공유 |
