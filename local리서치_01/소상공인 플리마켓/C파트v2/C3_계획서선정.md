# C-3. 계획서·선정 — 지침

> 근거: `기본지침서 v1.1` 3장 "소상공인 플리마켓 — 참가 대상·선정 방식" + "선정 기준(100점)"
> 참고 사례: [축제 사례 V1.md](../../축제%20사례V1/축제%20사례%20V1.md) 카드 ③-1(구미 소상공인 희망 플리마켓, 40부스), ③-2(영등포 청년야장 마켓, 약 15개소·청년 소상공인 우대)
> 구분: 고정

## 1. 계획서 필수 항목

1. 사업자 정보 (사업자등록증 등)
2. 판매 품목·가격표
3. 대구 연계성 (대구 소재·로컬 브랜드임을 보여주는 내용)
4. 부스 연출안
5. 체험 운영 여부
6. 예상 판매 수량

## 2. 선정 기준 (100점)

| 기준 | 배점 |
| --- | --- |
| 대구 로컬성 | 30 |
| 상품성·독창성 | 30 |
| 가격 적정성 | 20 |
| 사투리·대구 테마 연계 (가점, 필수 아님) | 20 |

- 계획서 내용으로 채점한다.
- 근거: 팀 2027 기획안 선정 기준 + 공공 플리마켓 공고의 심사 항목(독창성·가격 적정성·취지 부합) `[확인]`

## 3. 동점 처리

- 동점 시 **대구 로컬성 점수가 높은 셀러를 우선** 선정한다.

## 4. 품목 다양성 반영

- C-2(참가 대상·품목 원칙)의 "최대한 종류가 다양하게" 원칙에 따라, 이미 선정된 품목과 크게 겹치는 신청은 "상품성·독창성" 항목에서 낮게 평가한다.

## 5. 참고 — 다른 지역 플리마켓 모집 방식

- 구미 소상공인 희망 플리마켓: 판매 부스 40개, 구미사랑상품권 구매 시 5% 할인 혜택. 입점 선정 기준·참가비는 공개되지 않았다 — 이 수치는 구미의 관측값일 뿐, 대구 기준으로 쓰지 않는다.
- 영등포 청년야장 마켓: 약 15개소 내외, 청년 소상공인 우선, 품목을 즉석 먹거리·수공예품·친환경 제품으로 구분해 모집. 대구는 조리 음식(즉석 먹거리)을 플리마켓에서 제외한다는 점이 다르다(C-2 참고).

## 6. 변경 범위
