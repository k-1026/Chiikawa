# C-6. 연계 — 지침

> 근거: `기본지침서 v1.1` 3장 "3대 프로그램 연계 원칙" + "소상공인 플리마켓 — 운영"
> 구분: 연도별 변경

## 1. 스탬프 적립 연계 (→ M-6)

- 플리마켓 구매 시 스탬프를 적립하고, 축제 공식 굿즈 상점에서 교환할 수 있게 한다(3장 연계 원칙 — "플리마켓 구매 시 스탬프 적립 → 축제 공식 굿즈 상점에서 교환").
- 스탬프 적립 지점의 구체적인 위치·운영 방식(앱 QR인지 현장 도장인지 등)은 **M-6**(담당 파트) 문서를 따른다. → ❓ M-6 문서 위치를 팀에 확인 후 이 문서에 링크 추가 필요
- 이 문서(C-6)가 책임지는 범위는 "플리마켓 구매가 스탬프 적립 대상이라는 것"까지이고, 스탬프 시스템 자체의 설계는 M-6 범위다. (B-6 매장 연결이 G 파트 스탬프를 참고하는 것과 같은 구조)

## 2. 굿즈 상점과 마스코트 사용 확인 (→ D)

> **결정(2026-11-11)**: 품목이 겹치는 것 자체는 금지 사유가 아니다. 금지 대상을 "같은 품목"에서 "마스코트 사용"으로 좁힌다.

- 플리마켓 셀러의 상품이 D(굿즈 상점)와 **같은 종류(예: 키링, 에코백 등)여도 상관없다.**
- 금지되는 것은 **대키미·외지몽 공식 마스코트를 사용한 굿즈를 셀러가 만들어 파는 것**뿐이다 — 캐릭터·이름·이미지를 쓴 상품은 D(굿즈 상점)에서만 판매한다.
- 실제로 어떤 상품이 "마스코트를 사용했다"에 해당하는지(실루엣만 써도 해당되는지 등) 애매한 경우는 **D**(축제 공식 굿즈 상점 담당 파트) 또는 마스코트 IP 가이드를 기준으로 확인한다. → ❓ D 파트 문서 위치를 팀에 확인 후 이 문서에 링크 추가 필요
- 셀러 선정(C-3) 단계에서 신청 품목에 마스코트 사용 여부를 확인하고, 마스코트를 사용한 품목이 있으면 그 품목만 빼거나 신청 자체를 반려한다.

## 3. 변경 범위

- **연도별 변경**: 스탬프 적립 지점의 세부 운영
- **고정**: "플리마켓 구매 → 스탬프 적립" 연계 자체, "마스코트 사용 굿즈 판매 금지(품목 중복은 허용)" 원칙
