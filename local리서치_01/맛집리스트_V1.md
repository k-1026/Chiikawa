## 대구 10미 · 7구 맛집 출점 후보 (최종)

- 조사일: 2026-11-03
- 목적: 3장 "대구 10미 포장마차거리"의 연도별 변경 항목(10미 출점 업소, 7구 참여 맛집·메뉴) 후보 확보
- 모든 업소는 **후보**임. 참여 의사는 확인 전 (7장: 업소 정보·참여 의사 임의 생성 금지)
- 제과점은 제외함

### 선정 기준

- 10미 구역: 대구푸드(대구시 공식 음식 사이트) "대구10미" 품목별 등록 업소 중 원조·오래된 업소 우선
- 7구 구역: 대구푸드 구·군별 인증업소 + 백년가게(중소벤처기업부 지정) + 구청 지정 업소 중에서 선정
  - 10미 메뉴(따로국밥, 찜갈비, 막창, 무침회, 납작만두, 누른국수, 야끼우동, 뭉티기, 복어불고기, 논메기매운탕) 업소는 10미 구역 후보로만 둠
  - 오래된 업소(30년 이상·백년가게) 우선, 한 구 안에서 같은 메뉴 2곳 이하
  - 제과점 제외

### 영업 여부 표시

| 표시 | 의미 |
| --- | --- |
| ✅ | 2025~2026년 날짜가 있는 근거(후기·사업자 상태·기사)로 영업 확인 |
| ◐ | 영업 정보(영업시간·"영업 중" 표시)는 있으나 날짜 미확인 |
| ⚠️ | 이전·상호 변경 가능성 등 주의 사항 있음 |
| ❔ | 공개 자료로 영업 여부 확인 못 함 |

- 웹 공개 자료로 확인한 결과이며, 폐업이 확인된 후보는 없음
- ◐·⚠️·❔ 후보는 모집 공고 전에 전화 또는 지도 앱(네이버·카카오)으로 최종 확인 필요
