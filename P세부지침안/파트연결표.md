# 파트연결표 — 다른 파트가 바뀌면 P의 어디를 봐야 하나

> `/p-sync`가 읽는 표예요. 다른 파트(main `세부지침안/<파트>파트vN/`)의 새 버전이 나오면, 이 표에서 그 파트 줄을 찾아 **영향받는 P0 파일만** 다시 봐요.
> 근거: P세부지침안V2 각 파일의 "5. 다른 파트 연결" 표를 거꾸로 모았어요. P0 파일에 연결이 새로 생기면 이 표도 함께 고쳐요.
> 최종 수정: 2026-11-12

## 3. 단순 반영 (바로 고침)

- 다른 파트 문서 위치·버전·링크 갱신
- P0 파일의 "기본 지침과 다른 점", "출처", "다른 파트 연결" 표 갱신
- 금지 목록 항목 **추가**
- 파트가 새로 정한 세부 값 중 P0 확정값과 겹치지 않는 것 (예: 경기 1회 시간, 업소 심사 배점)
- 미확정 항목이 파트에서 해결된 경우 → "해결된 항목"으로 옮김
