# P0-9 공통 작업 규칙 — 세부 지침

> 구분: 고정 · 기본 지침: 5장, 7장, 13장 (+ 4-0, 12장) · 진행: **초안 (팀 검토 전)** · 최종 수정: 2026-11-11
> 기준 문서: 기본 지침 v1.1, 노션 A·B 세부 지침안의 공통 형식, `local리서치v2/통합_조사결과.md` 1장

## 1. 이 파트의 역할
- 메인 에이전트와 모든 PART가 똑같이 따르는 작업 방식(근거 표시, 출처, 확인 단계, 출력 형식)을 한곳에 모아요.
- 읽는 PART: 전체

## 2. 확정 값

### 2-1. 근거 라벨 4종

| 라벨 | 뜻 | 예 |
| --- | --- | --- |
| `[확인]` | 출처가 있는 사실 | 대구치맥페스티벌 2024 첫날 약 20만 명 (대구시 뉴스룸 2024-07-08) |
| `[해석]` | 자료를 바탕으로 한 의미 | 두류공원은 대규모 인파 운영 실적이 있는 장소다 |
| `[가설]` | 검증이 필요한 주장. **검증 방법을 함께 적음** | 타지역 2030은 1박 코스가 있으면 방문한다 → 검증: 사전 설문 |
| `[추정]` | 계산·가정으로 만든 수치. **계산식을 함께 적음** | 하루 평균 약 20만 명 (100만 ÷ 5일) |

- 라벨이 없는 수치·주장은 쓰지 않아요.
- 팀원 자료에 다른 라벨([F]/[I]/[U] 등)이 있으면 위 4종으로 바꿔 적어요. [F] → `[확인]`, [I] → `[해석]` 또는 `[가설]`, [U] → "확인 안 됨".

### 2-2. 출처 우선순위와 등급 표기

| 순위 | 출처 | 통일 표기 |
| --- | --- | --- |
| 1 | 대구시·공공기관 | 공식 |
| 2 | 한국관광 데이터랩·공공데이터포털 | 통계 |
| 3 | 대구푸드 등 공식 자료 | 공식 |
| 4 | 국립국어원·학술자료 | 학술 |
| 5 | 언론 | 언론 |
| 6 | 블로그·SNS | 비공식 (반응 참고용으로만) |

- 팀원마다 등급 기호가 달라요 (예: "B"가 hyunhee·king은 언론, kimseunghee는 학술). 인용할 때는 통일 표기로 바꿔요 (통합본 1장).
- 모든 출처에 **자료 기준일**과 **원문 확인 / 요약 기반** 여부를 적어요.
- 최신 자료를 확인할 수 없으면 "확인 안 됨"이라고 적고, 확인할 곳을 함께 적어요.

### 2-3. 담당자 확인 단계 (✅에서는 담당자 답 없이 다음으로 가지 않음)

| 단계 | 작업 | 산출물 | 완료 기준 | 담당자 확인 |
| --- | --- | --- | --- | --- |
| 0 | 직전 연도 자료 읽기 | 전년도 요약 | 04 운영결과·05 차년도과제 반영 여부 정리 | - |
| 1 | 조건 확인 | 01 기획조건표 | 필수 입력 전부 채움 또는 가정 명시 | ✅ |
| 2 | 자료 조사 | 02 조사보고서 | 필수 조사 항목 전부 커버 | - |
| 3 | 문제 정의 | 문제 정의 (02 안) | 사실/가설 구분 | - |
| 4 | 연도 주제·전략 | 전략안 | 주제 후보 3개 + 추천 1개 | ✅ |
| 5 | 아이디어 발굴 | 아이디어 목록 | 목표 3개별 최소 3개씩 | - |
| 6 | 타당성 평가 | 평가표 | 기본 지침 8장 + P0-1 2-4-1 점수 기준 | ✅ |
| 7 | 상세 기획·통합 운영 | 03 기획안 | 요소별 필수 항목 다 채움 | - |
| 8 | 검증 | 검토 결과 | 누락·충돌·예산 합계·근거 라벨 확인 | ✅ |
| 9 | KPI 설정 | 성과 측정 계획 | 목표별 핵심 KPI (P0-2) + 측정 준비 | - |
| 10 | 성과 분석 → 개선 | 04 운영결과, 05 차년도과제 | 유지/개선/실험 판정 | ✅ |

- 부분 요청이면 해당 단계만 해요. 앞 단계 산출물이 없으면 가정을 명시해요.
- 담당자가 결정한 내용은 연도 폴더의 00_결정기록에 남겨요.

## 3. 에이전트 행동 규칙

### 3-1. 임의 생성 금지
- 통계·업체 정보·참여 의사·후기·투표 수·신청자 수를 지어내지 않아요 (P0-10 금지 15번).
- 업체·기관·인물은 확인 전까지 "후보"로만 적어요.
- 다른 축제의 수치는 그 축제의 관측값이에요. 우리 목표치로 그대로 쓰지 않아요.
- 측정하지 않은 성과를 결과로 쓰지 않아요. "측정 안 됨"으로 적어요.

### 3-2. 문서 우선순위
1. 담당자 결정 (00_결정기록)
2. 노션 PART별 세부 지침
3. P세부지침안 (P0 공통 포함)
4. 기본 지침 v1.1

- 위 문서끼리 다르면 위쪽을 따르고, **다르다는 사실과 내용을 산출물에 적어요.**
- 어느 쪽이 맞는지 판단이 안 되면 고치지 않고 "미확정 사항"에 올려요.

### 3-3. 요소마다 공통으로 적는 것 (기본 지침 v1.1 4-0)
- 연도 주제와의 연결 1줄
- 주로 기여하는 목표 (체류·상권·사투리 정착 중 1개, P0-2)
- 전년 대비 분류: 유지 / 개선 / 실험 + 이유. 첫해는 "해당 없음(첫해, 기준선 수집)"
- 개인정보를 받는 요소는 수집 항목·목적·보관 기간. 개인정보 없이 가능한 방식 우선

### 3-4. 출력 형식
- **톤:** 실무 보고서형, 개조식, 표 중심. 근거와 가정을 구분해요.
- **사투리:** 산출물 본문은 표준어로 쓰고, 사투리는 콘텐츠·문구 예시처럼 자연스러운 곳에만 써요.
- **전체 기획안 표준 목차 (기본 지침 13장):** 기획 요약 → 목표·콘셉트 → 조사 결과 → 타깃 → 연도 주제 → 프로그램 구성·상세 → 모집·선발 → 지역 협업 → 온라인 연계 → 홍보 → 3일 일정표 → 예산·인력 → 안전 → KPI → 기대 효과 → 미확정 사항 → 출처
- **부분 요청:** 해당 항목만 써요.
- **미확정 사항 형식:** 항목 / 이유 / 확인 주체 / 확인 기한 (노션 A·B파트 공통)
- **PART 지침 형식:** 노션 "part별 지침 공통 템플릿" 5칸 — 입력 / 처리 규칙 / 출력 형식 / 참조 자료 / 금지 사항
- **P0 공통 파일 형식:** `_양식.md` 7칸 — 역할 / 확정 값 / 행동 규칙 / 매년 입력·조사 / 다른 파트 연결 / 미확정 / 출처

### 3-5. 저장 위치
- 연도별 산출물: `local 리서치/<연도>/` 안에 00_결정기록, 01_기획조건표, 02_조사보고서, 03_기획안, 04_운영결과, 05_차년도과제
- 새 연도를 시작할 때는 직전 연도 04·05를 먼저 읽어요 (기본 지침 12장).
- 팀원 원본 조사 파일은 고치지 않아요. 고칠 점은 산출물의 미확정 사항에 적어요.
