# P0-6 예산 범위 — 세부 지침

> 구분: 입력 · 기본 지침: 6장, 9장 · 진행: **확정 v2 (2026-11-11)** · 최종 수정: 2026-11-12
> 기준 문서: 기본 지침 v1.1, main `세부지침안/B파트v1/`(B-9 수수료 메모), `세부지침안/C파트v2/`(C-4 수수료·정산), `local리서치v2/공통/단가표.md`
> 상세 산정(항목·수량·단가)은 H(운영) 파트가 맡아요. 이 파일은 예산을 **어떻게 받고, 어떤 틀로 나누는지**만 정해요.

## 1. 이 파트의 역할
- 매년 예산을 입력으로 받을지, 에이전트가 산정할지 정하고, 예산 대분류 7개와 근거 자료 순서를 고정해요.
- 읽는 PART: M(메인) 기획조건표, H(운영) 예산 상세, 각 PART(예산 제약 조건)

## 2. 확정 값

### 2-1. 예산 입력 방식

| 방식 | 언제 | 에이전트가 하는 일 |
| --- | --- | --- |
| A. 예산 범위 입력 | 담당자가 금액 범위를 줄 때 | 그 범위를 **첫 기획 요소부터 제약 조건**으로 적용 (기본 지침 v1.1 4-1). 범위 안에서 최소/기본/확장 3안 |
| B. 산정 요청 | 금액이 정해지지 않았을 때 | 2-3 근거 자료 순서로 최소/기본/확장 3안을 산정 → 담당자가 확정 |

- 기본 지침 6장 필수 입력이에요. 둘 다 없으면 기획 전에 물어보고, 답이 없으면 `[가정] 산정 요청`으로 진행해요.

### 2-2. 예산 대분류 7개 (기본 지침 v1.1 9장)

| # | 대분류 | 들어가는 것 (예) | 주로 관련된 PART |
| --- | --- | --- | --- |
| 1 | 무대·시설 | 무대·음향·조명, 부스(텐트·조리), 화장실, 전기·급수, 그늘·냉방 | A, B, C, H |
| 2 | 프로그램 운영 | 토론 상금·심사·진행, 업소 모집·심사, 부대 프로그램, 웹(체크인·투표·스탬프) | A, B, C, E, K |
| 3 | 굿즈·제작 | 마스코트 굿즈, 출전자 기념품, 매장 카드(QR)·메뉴판 | D, B |
| 4 | 홍보 | 온라인 광고·숏폼, 원정 팝업, 인쇄물 | F |
| 5 | 인건비 | 운영 스태프, 안전관리 인력, 의료 | H |
| 6 | 안전·보험 | 배상책임보험, 소방·안전 장비, 인허가 행정 | H |
| 7 | 예비비 | 1~6 합계의 일정 비율 | H |

- 숙박 인증 혜택·스탬프 상품권 같은 **상권·관광 연계 지원금**과 **성과 측정 비용**은 7개 중 어디에 넣을지 정해야 해요 (7장).

### 2-3. 팀 입력 방식 (확정 2026-11-11)

| 항목 | 정한 값 |
| --- | --- |
| 입력 단위 | **대분류 7개 총액** (항목별 단가는 받지 않음) |
| 파일 형식 | **CSV / 엑셀** — 양식: `P0-6_예산입력_양식.csv` |
| 3안 차이 | **항목 포함 여부** — 대분류마다 "필수" 묶음과 "선택" 묶음으로 나누고, 묶음별로 최소/기본/확장에 넣을지 O/X로 표시 |
| 예비비 | **10%** — 1~6 대분류 합계 × 10%, 안마다 따로 계산 (팀 입력 안 함) |

**양식 열 (한 줄 = 대분류 안의 한 묶음)**

| 열 | 뜻 |
| --- | --- |
| 연도 | 개최 연도 |
| 대분류 | 2-2의 1~6 중 하나 (예비비는 자동 계산이라 넣지 않음) |
| 묶음 | 필수 / 선택 |
| 설명 | 이 묶음에 들어가는 것 (예: 메인 무대·음향·부스) |
| 최소 · 기본 · 확장 | 이 묶음을 그 안에 넣으면 O, 빼면 X. 필수 묶음은 셋 다 O |
| 금액(원) | 이 묶음의 총액 |
| 근거 | 첫해: "팀 제공" / 2년 차부터: "전년 집행" / 그 외: 견적·공공·추정 |
| 기준일 · 메모 | 금액 기준일, 참고 사항 |

**에이전트 계산 순서**
1. 안마다 O 표시된 묶음 금액을 대분류별로 더해요.
2. 1~6 합계를 구하고, 예비비 = 합계 × 10%를 더해 총액을 만들어요.
3. 대분류 합 → 소계 → 예비비 → 총액을 **계산식과 함께** 표로 보여 줘요.
4. 입력된 예산 범위(2-1 A)가 있으면 어느 안이 범위 안인지 표시해요.

### 2-3-1. 산정 근거 자료 순서

| 연차 | 근거 | 처리 |

### 2-4. 수입 항목 (예산과 따로 표시)

| 항목 | 내용 | 상태 |
| --- | --- | --- |

## 3. 에이전트 행동 규칙
- 예산은 항상 **최소/기본/확장 3안**으로 내요.
- 첫해에는 팀이 넣은 **대분류 총액만** 써요. 항목별 단가·수량으로 쪼개지 않고, 쪼갠 상세 산정이 필요하면 H(운영) 파트로 넘겨요.
- 팀이 비워 둔 금액을 에이전트가 채우지 않아요. "미입력"으로 두고 담당자에게 물어봐요.
- **총액과 세부 합계를 직접 계산해서 맞추고, 계산식을 보여 줘요.**
- 확인 안 된 비용을 확정값처럼 쓰지 않아요. 단가표에 근거가 없으면 `[추정]`이에요.
- 2년 차부터 전년 집행액과 올해 입력값이 크게 다르면(예: ±20% 이상, 제안값) 이유를 담당자에게 확인해요.
- 예산을 확정하지 않아요. 3안 비교와 추천안·근거까지만 내고, 확정은 담당자가 해요 (기본 지침 v1.1 0장).
- 입력된 예산 범위를 넘는 아이디어는 평가 필수 조건에서 탈락이에요 (기본 지침 8장).
