# 리서치 규칙 (_rules.md)
- 버전: v1 / 작성일: 2026-10-29
- 대상: 대구 사투리 축제 기획 AI 에이전트(지침 v1)용 "사투리" 상위 키워드 리서치
- 표기: [확정] 사용자가 정함 / [가안] 제가 제안, 확인 필요

## 1. 자산 판정 (3질문, 모두 통과해야 "자산")
| 질문 | 기준 | 상태 |
|---|---|---|
| 고유성 | 지명·인물·역사·원산지 중 1개 이상 결합. **대구 직접 해당이어야 함.** 대구 외 지역 사례는 "벤치마크"로 분리하고 자산 판정에서 제외 | [확정] 지역 분리 / [가안] 대구 한정 |
| 지속성 | 2회 이상 반복, 또는 확인일 기준 현재 운영 중(근거 필요) | [확정] |
| 활용성 | 공식 수치(방문객·매출·참여자) 1개 이상. 규모 하한 없음 | [가안] 자료가 부족하면 재협의 |
- 보도자료·기사 인용 수치는 "공식(미검증)"으로 두고, 원문·통계로 확인되면 인정한다. [가안]
- 통과 못 하면 "정보(자산을 뒷받침하는 정보)". 판정 이유는 항목마다 한 줄.
- "맛집·핫플·인기" 같은 평가성 표현은 정량 기준이 없으면 근거로 쓰지 않는다.

## 2. 유형 규칙
- 1차 유형 = "무엇이 핵심인가" 기준으로 9개 축 중 1개: 지역별 방언 분류 / 역사·형성 배경 / 사회적 인식·편견 / 교육·학습 / 콘텐츠·미디어 / AI·기술 활용 / 관광·지역 브랜딩 / 시민 참여 / 보존·계승
- 두 축에 걸치면 2차 유형으로 태그한다.
- 경계 판정 규칙 [가안]: "수익·성과가 어디서 나오는가"를 1차 기준으로 한다.
  - 사투리 자체가 소재인 굿즈·캐릭터 → 콘텐츠·미디어
  - 판매·방문·체류 연계가 핵심인 굿즈·상품 → 관광·지역 브랜딩
  - 대회·행사 → 시민 참여(교육 목적이 핵심이면 교육·학습)
- 굿즈·관광 연계는 "사투리 관점"일 때만 수집하고, 팀원 파트와 겹치면 2차 유형으로 표시한다. [확정]

## 3. 지역 구분 (열: 지역구분)
- 대구: 자산 판정 대상
- 대구 외(경북·경남·부산·제주·강원 등): 국내 벤치마크, 판정 제외, 용도는 비교·참조
- 해외: 최대 5곳, 벤치마크 전용 [확정]

## 4. 기간
- 2022~2026 (확인일 2026-10-29 기준) [확정, 사용자 오타 수정 반영]

## 5. 출처 등급 (코드는 사용자 지정, 정의는 가안)
| 등급 | 정의 | 예 |
|---|---|---|
| S | 지자체·공공기관 공식 자료 원문 | 대구시·교육청·국립국어원 공식 문서 |
| A | 공공데이터·통계 | AI허브, 한국관광 데이터랩, 공공데이터포털, 실태조사 원문 |
| B | 학술·연구 | 논문, 학술지, 국립국어원 간행물 |
| C | 언론(기자 작성 기사) | 매일신문, 경북매일 등 |
| D | 전문가 칼럼, 기업 발표·보도자료 | 칼럼, 기업 주장 |
| E | 개인·미검증 민간 | 블로그, SNS, 민간 출판물 |
- 기존 코드 변환: P1→S 또는 A(내용 기준), 기존 S→C 또는 D(기자 기사/칼럼 구분), 기존 A→B, 기존 X→E
- 같은 필자·같은 원출처는 독립 근거 1건으로 센다.
- 출처 없는 수치 = "미확인"
- 한국관광 데이터랩, 공공데이터포털, 지자체 사이트 안에만 있는 자료는 "추천출처처" 열에 어디서 찾을지 적는다.
