# 03. 사회적 인식·태도·편견

- 확장 키워드: 방언 태도, 표준어 선호, 방언 호감도, 지역 비하 표현, 방송 사투리 연기, 언어 의식 조사, 방언 논란
- 자료 기준일: 2026-10-31 / 등급 정의는 [00_개요.md](00_개요.md)

---

## 0. 핵심 요약

- [확인·기사 원문] 국립국어원 국민의 언어 의식 조사(2025 실시, 전국 만 20~69세 5,000명): 방언 **유지해야 한다 59.2%**(2020 대비 +8.3%p), 방언의 복수 표준어 인정 **긍정 47.7%**
- [확인·기사 원문] 경북 20대 **83.6%**가 방언 보존 필요에 찬성, 방언 사용 자가평가 70.4점(전북 20대 37.8점) — 경북 표본, 대구 단독 아님
- [확인·기사 원문] 2026-07 '무섭노' 논란: 발언자는 리센느 원이(유튜브), 공개 사과는 이를 문제 삼은 조수진(노무현재단 이사)이 7/9에 했고, 언어학자들은 방언 표현으로 설명
- [미확인] **타지역 20·30대의 대구 사투리 호감도**를 직접 조사한 설문은 찾지 못함
