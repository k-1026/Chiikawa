# [가정] 웹 — 로그인·결제·알림 더미 동작 정의 (MVP)

> 용도: 키를 연결하기 전까지 **어떤 값을 가짜로 돌려줄지** 정리한다. 실제 계정·결제·알림이 아니다. 전부 `[가정]`.
> 위치: `local리서치v2/가정값/` · 작성: 2026-11-26 · 연결: K08·K09·K10·K11

## 1. 로그인 더미
| 상황 | 더미 동작 |
|---|---|
| 카카오 로그인 | 닉네임 입력 → 항상 성공, `provider: kakao` |
| 구글 로그인 | 닉네임 입력 → 항상 성공, `provider: google` (구매 불가) |
| 둘러보기 | 닉네임 "둘러보기", `provider: guest` (주문·투표 불가) |
| 테스트 계정 이름 | 테스터1(카카오), 테스터2(구글), 테스터3(둘러보기) |

## 2. 결제 더미
| 상황 | 더미 동작 |
|---|---|
| 카카오페이 결제 | 버튼 1번에 성공, 대기번호 바로 부여 |
| 결제 실패 시나리오 | 없음. 필요하면 "금액 0원이면 실패" 같은 규칙을 별도 추가 |
| 현장 결제(2안) | 웹 주문 접수 후 상태 "현장 결제 대기"로 표시(구현 예정) |
| 실제 연습 | 카카오페이 테스트 코드 `TC0ONETIME`으로 결제 흐름 시험(실제 돈 안 나감) |

## 3. 알림 더미
| 상황 | 더미 동작 |
|---|---|
| 호출 | 화면 상단 팝업 "🔔 N번 호출! 부스로 오세요" |
| 알림톡 | 보내지 않음(선택 기능). 팝업으로 대체 |
| 화면을 닫은 경우 | 안내 문구 "대기번호는 이 화면에서 확인하세요" |

## 4. 챗봇·번역기 더미
| 상황 | 더미 동작 |
|---|---|
| 챗봇 | 키워드 규칙 응답(개장 시간·토론·주문·숙박·위치·사전 단어) |
| 모르는 질문 | "잘 모르겠어요. 운영·안전 부스에서 안내받을 수 있어요" |
| 번역기 | 사전에 있는 단어만 치환 |

## 5. 연결 방법
실제 키를 연결하면 이 더미를 서버 호출로 교체한다. 교체 지점은 각 `K08~K11` 명세의 "시험판 vs 실제" 표를 따른다.
