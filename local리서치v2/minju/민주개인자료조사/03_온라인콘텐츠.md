### ③ 비공식

- '경상도 사투리 능력고사' 인스타 스토리 확산 후기. 대구·부산 사투리 차이, 억양(음계) 맞히기 문제가 재미 포인트로 언급됨. 광고성 콘텐츠로 보임 (캐릿): <https://www.careet.net/607>
- MBTI 마케팅 칼럼. 결과에 따라 고가 혜택을 차등하면 논란이 생길 수 있고, 미쏘 사례는 반응이 저조했다는 내용 (아이보스): <https://www.i-boss.co.kr/ab-74668-1755>

**시사점**
- [해석] 국가기관도 '능력고사' 형식을 썼음 → 형식 자체는 검증된 공공 선례이므로, 우리는 **대구 한정 + 축제 연결 CTA**로 차별화함
- [해석] 재미 포인트는 타지역 사람이 틀리는 지점(대구 vs 부산, 억양)이며, 이는 토론 대회의 '대구 시민 vs 타지역' 구도와 이어짐

**축제 적용 아이디어**
- [가설] '대구 사투리 능력고사' → 등급별 공유 이미지 → 마지막 화면에 토론 대회 신청·숙박 인증 혜택 CTA
  - 검증 방법: UTM으로 테스트 → 신청 → 현장 방문 단계별 전환율 측정 (지침 KPI '온라인 전환')
- [가설] 고득점 타지역 참가자를 토론 대회 '타지역 대표' 예선 풀로 활용
- 주의: 등급별 혜택 차등은 최소화하고 쿠폰은 동일하게 지급
- 확인 필요: 국립한글박물관 '사투리 능력고사' 참여 수 → 박물관에 문의

- [해석] 다만 '경상도' 단위라 **대구 특유 표현과 부산 표현이 섞일 수 있음** → 대구 시민 검수가 필수임
- [해석] 변환 결과가 어색하면 '미디어 사투리' 비판을 받을 수 있음

**축제 적용 아이디어**
- [가설] AI허브 데이터 + LLM + 대구 시민 감수 예문 사전으로 문장 변환기 제작, 결과를 이미지 카드로 공유
  - 검증 방법: 대구 출신 테스터 패널의 자연스러움 5점 척도 평가, 공유율
- [가설] 반응 좋은 변환 문장 → 현장 한정 굿즈 문구 후보
- 확인 필요: AI허브 데이터의 **상업적 이용 가능 여부**와 이용 약관
- 윤리 체크: 비속어·비하 필터, 정치·젠더 프레임 차단, 입력 텍스트 저장 여부 고지
