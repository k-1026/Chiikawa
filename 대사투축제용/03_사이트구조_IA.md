# 03. 사이트 구조 (정보 구조도)

옛 시안(`degu-one.vercel.app`)의 **탭 뼈대(1페이지 안에서 하단/상단 탭으로 전환하는 구조)는 그대로 가져오되**, 각 탭의 내용은 [01_확정지침_요약.md](01_확정지침_요약.md)·[02_토론대회_지침.md](02_토론대회_지침.md) 기준으로 바꿉니다.

## 1. 전체 메뉴(하단 탭 6개)

| 탭 | 역할 | 비고 |
|---|---|---|
| ① 홈 | 히어로(축제명·기간·장소) + 핵심 메시지 + 바로가기 카드(먹거리·토론·지도·스탬프) + 마스코트 소개 | 옛 시안의 "체크인하기" 중심 구성에서 **체크인 전제를 뺀** 안내 중심 구성으로 변경 |
| ② 행사개요 | 축제 소개 / 3대 프로그램+부대콘텐츠 / 먹거리·플리마켓 / 스탬프·숙박 혜택 | 옛 시안 "숙박·혜택" 서브탭은 **"스탬프·숙박 혜택"으로 교체**(숙박 인증은 삭제가 아니라 흐름이 바뀐 것, [01_확정지침_요약.md](01_확정지침_요약.md) 5장) |
| ③ 시간표 | 금/토/일 일자별 무대·구역 운영 시간표 | 토론 경기는 일요일에만, 골든벨·뮤지컬·NPC는 토요일 중심이라는 점을 반영 |
| ④ 토론대회 | 대회 소개 / 대진표 / 논제 / 관객 투표(로그인 데모) | 옛 시안 서브탭 구성(대진표·논제·관객투표)은 유지, **내용만 교체** |
| ⑤ 지도 | 구역별 실시간 지도(플리마켓/7구 맛집거리/메인구역/식사존/운영·안전 부스) | 구역 명칭·배치를 새 지침 기준으로 다시 그림 |
| ⑥ 스탬프·숙박 | 스탬프 북 안내(8칸·5개 완성) / 도장 받는 곳 3묶음 / 완성 보상 + 숙박 인증 신청·안내 | **신설 탭** — 혜택 구조가 두 가지(스탬프 완성 보상, 숙박 인증 보상)로 늘어나 하나의 "혜택" 탭에서 다룸 |

> 옛 시안에 있던 **"능력고사"(사투리 능력고사 퀴즈) 탭은 지금 지침에 해당 기능이 없어 제외**합니다. (단, 사투리 사전·변환기 자체는 J파트 소관으로 다른 곳에 있을 수 있어 추후 확인)
> 메인무대 콘텐츠가 토론대회 외에도 **골든벨·뮤지컬·사투리 순회 NPC**로 늘어났어요([06_부대콘텐츠_먹거리_플리마켓.md](06_부대콘텐츠_먹거리_플리마켓.md)). 토론대회 탭은 그대로 두고, 나머지 3개는 "행사개요 > 3대 프로그램" 서브탭에서 소개합니다.

## 2. 탭별 서브 구조

### ① 홈
- 히어로: "대사투 · 2027 대구 사투리 페스티벌" + 기간(8/20~22) + 장소(두류공원)
- 핵심 메시지 배너: "표현이 달라도, 친구가 된다."
- 마스코트 소개: 대키미 ↔ 외지몽
- 바로가기 카드 4개: 🎤 토론대회 / 🍢 10미·7구 맛집거리 / 🏮 소상공인 플리마켓 / 🎫 스탬프·혜택
- 하단: "이 페이지는 세부지침안(main 브랜치) 기준 가상 안내 시안입니다. 미확정 사항은 바뀔 수 있어요."

### ② 행사개요
- 서브탭: 축제 소개 / 3대 프로그램·부대콘텐츠 / 스탬프·숙박 혜택
- **축제 소개**: 이름, 콘셉트, 핵심 메시지, 마스코트(대키미·외지몽), 기간·장소·운영시간 표
- **3대 프로그램·부대콘텐츠**: A(토론대회·골든벨·뮤지컬·NPC) / B(10미 포장마차·7구 맛집거리) / C(소상공인 플리마켓) — [06_부대콘텐츠_먹거리_플리마켓.md](06_부대콘텐츠_먹거리_플리마켓.md) 기준
- **스탬프·숙박 혜택**: [01_확정지침_요약.md](01_확정지침_요약.md) 4장(스탬프)·5장(숙박 인증) 요약

### ③ 시간표
- 서브탭: 8/20(금) / 8/21(토) / 8/22(일)
- 금·토: 먹거리·플리마켓 영업시간(12:00~22:00)만 표시, "토론 경기 없음" 명시
- 일: 먹거리·플리마켓(12:00~20:00) + 토론 본선(8강·4강) + 결승(16:00~17:00) + 시상

### ④ 토론대회
- 서브탭: 대회 소개 / 대진표 / 논제 / 관객 투표
- **대회 소개**: 개인전, 대구 vs 타지역, 이지선다 말싸움, 8강 토너먼트(지역 대표 선발전) 설명
- **대진표**: 8강 대진(대구 1~4 vs 타지역 1~4, 출전자 미정 표시)
- **논제**: 논제 형식 설명 + 예시 2~3개(실제 확정 논제는 미정이므로 "예시"로 표시) + "결승 논제는 현장 쪽지로만 추천받아요" 안내
- **관객 투표**: "로그인 후 1인 1표" 데모 UI(실제 로그인 없이 데모로만 동작), 투표 결과는 득표율로 표시

### ⑤ 지도
- 구역 리스트: 운영·안전 부스 / 플리마켓 / 7구 맛집거리 / 메인구역(메인무대+10미 포장마차+굿즈·이벤트) / 식사존
- 구역 클릭 시 운영시간·역할 텍스트 표시 (옛 시안과 같은 인터랙션 패턴)

### ⑥ 스탬프·숙박
- 서브탭: 스탬프 / 숙박 인증
- **스탬프**: 스탬프 북 구조(8칸, 5개 이상 완성) 안내, 도장 받는 곳 3묶음 카드(부대 프로그램 / 플리마켓·10미·7구 맛집거리 / 굿즈 상점), "토론 대회 관람·투표는 스탬프를 주지 않아요" 명시, 완성 보상(쿠폰북 + 날마다 선착순 상품 + 인스타그램 추첨)
- **숙박 인증**: (데모) 사전 신청 폼 → "1박 후 인증" 안내 → 영수증/예약 확인 업로드(데모, 실제 저장 안 함) → 보상 안내(대구로페이, 금액 미확정) → 수령처(축제장 현장 / 동대구역 관광안내소) 안내. **대구 외 거주자만** 대상임을 명시
