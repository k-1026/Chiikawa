# 02. 토론 대회 지침 요약 (사이트 핵심 콘텐츠)

> 출처: main 브랜치 `세부지침안/A파트v6/A02_토론대회구조논제.md`, `A03_토론대회심사관객투표.md` — **확정 v6 (최종 수정 2026-11-18)**

옛 시안(`degu-one.vercel.app`)의 "토론대회" 탭은 **2인 1팀 16강, 대구말 찬스, 체크인 후 1회 투표** 구조였는데, 지금 지침은 완전히 달라요. 사이트를 다시 만들 때는 아래 내용으로 통째로 교체해야 해요.

## 1. 대회 구조

| 항목 | 지금 지침 (A-2) | 옛 시안과 다른 점 |
|---|---|---|
| 참가 단위 | **개인전만** (팀전 폐지, 2026-11-10) | 옛 시안은 "2인 1팀" |
| 대결 구도 | 대구 참가자 vs 타지역 참가자 (대구/타지역은 **주민등록상 주소지**로 구분, 경북은 대구로 포함) | 유지(대구 vs 타지역이라는 큰 구도는 같음) |
| 대회 성격 | 진지한 토론이 아니라 **가볍고 유머러스한 "이지선다 말싸움"** 대회 | 옛 시안은 "찬반 토론"형 |
| 방식 | 일반 토너먼트가 아니라 **지역 대표 선발전** — 라운드마다 지역별 점수 상위 50%가 진출 | 옛 시안은 "16강 토너먼트, 단순 승자 진출" |
| 2027년 참가 수 | **8명** (대구 4 · 타지역 4) → 8강 토너먼트 | 옛 시안은 "16팀(32명)" |
| 단계 이름 | **예선**(축제 전, 온라인 신청·심사로 출전자 확정) → **본선**(8강 4경기·4강 2경기) → **결승** | 옛 시안은 "16강·8강·4강·결승"을 모두 현장 경기로 표현 |
| 경기 일정 | **본선·결승 모두 일요일.** 금·토는 경기 없음. 결승 **16:00~17:00**(단판 1시간, 시상 포함) | 옛 시안은 금요일 16강, 토요일 8강·4강·결승 |
| 경기 시간 | 본선 1경기 **30분**(입장~승패 발표 포함), 결승 **1시간** 단판(논제 1개) | 옛 시안은 "1경기 12분" |
| 무대 | 메인무대(야외음악당) **1개만** — 토론·골든벨·뮤지컬 모두 같은 무대 | — |
| 우천 시 | H-4 기준으로 판단, 우천이면 **일요일 경기를 토요일로 앞당김**. 금요일 낮 최종 고지 | — |
| '대구말 찬스' 같은 보조 장치 | **두지 않음** (2027 기획안 초안의 "대구말 찬스"는 미채택) | 옛 시안에 있던 "대구말 찬스 2회"는 삭제 |

## 2. 논제

| 항목 | 지금 지침 |
|---|---|
| 형식 | **이지선다 말싸움** — "대구인이 할 법한 말 vs 외지인이 할 법한 말" (예: "졸려 vs 잠 와, 뭐가 더 귀여운 표현일까"). 찬반 논거를 다투는 형식이 아님 |
| 단계별 소재 | 8강: 가볍고 재미있는 일상 소재(그해 SNS 화제 반영) → 4강: 대구 소재를 점점 늘림 → 결승: 대구 소재가 가장 짙음, 가장 무겁게 |
| 논제 수 | 경기 수 × 3 (2027년 7경기 → **21개**) |
| 본선 논제 공개 | 경기 시작 **후** 무대에서 추첨 |
| 결승 논제 | **절대 미리 알리지 않음.** 메인구역 입구 쪽지함에 방문객이 추천 → 운영진이 금지 논제·사투리 검수로 거름 → 결승 진출자가 무대에 오른 뒤 **즉석 추첨** (쪽지 마감은 결승 시작 1시간 전, 기본 15:00) |
| 웹사이트로 논제 추천 | **받지 않음.** 결승 논제는 오직 현장 쪽지로만 받음 — ⚠️ 옛 시안이 "토론대회 탭 논제 메뉴에 추천 입력 칸"을 넣으려던 계획이 있었는데(지침 A-2 미확정 당시), **지금은 명확히 "웹 추천 안 받음"으로 확정됐어요.** 새 사이트에는 논제 추천 입력 폼을 넣지 않아요 |
| 금지 논제 | ① 지역 비하(대구와 특정 지역 우열 비교 포함) ② 정치 프레임 ③ 젠더·세대 갈등 유도 ④ 실제 업소·상호 비교 |

## 3. 심사·관객 투표 (A-3)

| 항목 | 지금 지침 | 옛 시안과 다른 점 |
|---|---|---|
| 점수 구조 | 심사위원 점수 **60점**(심사위원 평균×0.6) + 관객 점수 **40점**(득표율×40) + 승리 보너스 **+10점** | 옛 시안은 "심사위원 60% + 관객 투표 40%"까지만 같고 승리 보너스는 없었음 |
| 심사위원 채점 항목 | 유머 40 / 지역문화 표현력 40 / 전달력 20 (총 100점) | 거의 동일 |
| 심사위원 구성 | **3명** — 방언 연구자 1(필수) + 대구 지역 방송인/크리에이터 1 + 타지역 출신 희극인·방송인 1. **전년도 우승자는 심사위원에서 제외** | 옛 시안은 "4명: 방언연구자·지역방송인·코미디언·전년도 우승자(또는 시민대표)" |
| 투표 자격 | **웹페이지 로그인 후 1인 1표** ("1인 1계정 원칙"). 휴대폰 없는 관객은 투표 불가(운영 한계로 받아들임) | 옛 시안은 "체크인 후 한 번만 투표"(로그인 불필요) — ⚠️ **로그인 기능이 필요해졌어요.** 회원가입 정보·동의는 K(웹페이지) 파트 소관 |
| 투표 참여 보상 | **스탬프 없음** (A-1, H-10) | 옛 시안은 체크인 3단계 중 하나로 투표에 스탬프를 암시했음 — 삭제 필요 |
| 동점 처리 | ① 관객 득표율 높은 쪽 → ② 그래도 같으면 연장전 없이 심사위원이 더 많이 높은 점수를 준 쪽 → ③ 그래도 같으면 심사위원 회의 | 옛 시안에는 없던 세부 규칙 |
| 타지역 참가자 보조 장치 | **없음** ("대구말 찬스" 미채택) | 옛 시안의 "대구말 찬스" 제거 |

## 4. 사이트에 반영할 때 유의점

1. **대진표**는 "참가자가 정해지기 전에는 이름 대신 '대구 1', '타지역 1'처럼 표기"하는 규칙을 따릅니다 (A-2 4장). 2027년은 8강(대구 4·타지역 4)만 보여 주면 됩니다.
2. **논제 추천 입력 UI는 넣지 않습니다.** "현장에서 쪽지로 추천받아요"라고만 안내합니다.
3. **투표 화면에는 로그인(또는 1인 1계정 인증) 단계가 있어야** 실제 지침과 맞습니다. 데모로 구현할 때도 "로그인 후 투표" 흐름을 보여 주는 것이 좋습니다.
4. 참가자 명단·결승 논제·2027 세부 콘셉트는 아직 미확정이므로, 사이트에도 "미정 — 추후 공개"로 표시합니다.
