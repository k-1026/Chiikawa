- [기존 아이보리 배경 로고 PNG](01_확정_로고/대구_얼라들_로고_기존배경.png)
- [로고 디자인 시트](01_확정_로고/대구_얼라들_로고_디자인시트_v1.md)

## 폴더 구성

- `01_확정_로고`: 흰 배경·기존 배경 로고, 승인 원본, 디자인 시트, 라벨 적용 참고.
- `02_로고_시안`: 현재 작업 폴더에 남아 있던 이전 로고 시안의 PNG·SVG와 자료를 원래 하위 폴더 이름으로 보존.
- `03_라벨_목업`: 인형 봉제 라벨·종이 행택 목업.
- `04_초기_생성이미지`: 생성 보관소에서 확보한 초기 흑백·유기적 차콜 로고 원본.

흰 배경과 기존 배경 이미지는 모두 1448 × 1086px이다. 기존 배경 파일과 승인 원본은 동일한 이미지다. 흰 배경 파일은 승인 로고의 배경만 로컬 처리로 흰색으로 바꾼 버전이다.

파일 이동 기록에는 이동 전후 경로와 원본 파일의 SHA-256을 기록했다. 이 폴더에는 현재 남아 있는 자료와 확보 가능한 생성 원본을 모았으며, 이전 링크에 있었으나 현재 파일이 없는 시안을 새로 만들어 원본으로 표기하지 않았다.
