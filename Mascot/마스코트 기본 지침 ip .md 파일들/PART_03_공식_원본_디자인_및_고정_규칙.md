# PART 3. 공식 원본 디자인 및 고정 규칙

## 3-1. 원본 디자인 우선 원칙

사용자가 제공한 다음 두 장의 캐릭터 설정 보드를 공식 원본 디자인 레퍼런스로 사용한다.

- 대키미 캐릭터 설정 보드
- 외지몽 캐릭터 설정 보드

AI가 캐릭터를 새롭게 생성하거나 변형할 때는 반드시 해당 원본 디자인을 참고해야 한다.

텍스트 설명과 원본 이미지 사이에 차이가 있을 경우, 실제 외형은 원본 설정 보드를 우선한다. 단, 사용자가 이후 공식적으로 승인한 수정 사항은 새로운 기준으로 반영한다.

## 3-2. 절대 고정 요소

다음 요소는 축제 연도, 홍보 콘셉트, 제작 매체와 관계없이 변경할 수 없다.

| 항목 | 고정 규칙 |
|---|---|
| 캐릭터 종 | 대키미는 고양이, 외지몽은 강아지 |
| 기본 몸색상 | 캐릭터별 지정 색상 유지 |
| 귀 | 종별 기본 형태 유지 |
| 귀 안쪽 색상 | 원본 지정 색상 유지 |
| 꼬리 | 기본 형태와 색상 유지 |
| 얼굴 | 눈·코·입의 기본 디자인과 배치 유지 |
| 더듬이 | 각 캐릭터 2개 유지 |
| 신체 | 기본 실루엣과 비율 유지 |
| 고유 특징 | 원본 디자인의 특징 유지 |

### 기본 색상 정보

대키미:
- 기본 몸색상: #6DCFF5
- 귀 안쪽: 분홍색 계열
- 눈: 검정색
- 하이라이트: 흰색

외지몽:
- 기본 몸색상: #008C3A
- 주둥이 주변: 크림빛 흰색
- 눈: 검정색
- 하이라이트: 흰색

※ 원본 설정 보드에 정확한 HEX 값이 표시되지 않은 색상은 임의로 수치를 지정하지 않는다. 원본 이미지를 기준으로 유지하고, 별도의 공식 색상값이 확정되면 추가한다.

## 3-3. 색상 변경 규칙

**캐릭터의 기본 신체 색상은 변경할 수 없다.**

축제별 포인트 색상과 시즌별 콘셉트 색상은 다음 요소에만 적용할 수 있다.

변경 가능:
- 의상
- 액세서리
- 소품

변경 불가:
- 몸색상
- 귀 안쪽 색상
- 꼬리 색상
- 얼굴의 기본 색상
- 기본 신체에 포함된 고유 색상

예시:
- 여름 축제: 여름색 티셔츠, 모자, 부채
- 야간 축제: 야광 액세서리, 응원봉
- 토론 축제: 마이크, 토론 카드, 의상
- 관광 테마: 여행 가방, 모자, 카메라

축제 테마에 맞는 색상을 캐릭터의 몸에 직접 입히거나 기본 색상을 변경해서는 안 된다.
