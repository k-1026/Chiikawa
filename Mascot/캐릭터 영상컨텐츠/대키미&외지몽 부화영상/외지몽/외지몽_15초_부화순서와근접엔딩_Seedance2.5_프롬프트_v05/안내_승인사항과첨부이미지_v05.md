# 외지몽 15초 Seedance 2.5 프롬프트 v05

승인 근거: v04 스토리보드 확인 후 사용자가 “좋아 이제 프롬포트 제작”으로 승인.
모델 선택·길이: Seedance 2.5 / 15초 / 16:9. 실제 커넥터 지원 설정을 먼저 확인하도록 지시.
이 파일은 프롬프트 제작 결과이며 영상은 생성하지 않았음.

## 첨부 순서
1. 외지몽 아가버전 최종_v13 정면(외형 기준)
2. 같은 최종_v13의 45도 한 장(귀·주둥이·꼬리 구조 보조)
3. 같은 최종_v13 앉은 정면(손바닥·발바닥 보조)
4. 외지몽 크림·밀키민트 알 정면 단일 이미지
선택: 승인한 v04 원페이지 보드(장면 순서 참고용; 외형 기준으로 사용하지 않음).

알 6방향 시트를 사용할 경우 한 개의 알 디자인 참고임을 명시해야 하며, 가능하면 기존 알 정면 단일 컷을 우선 사용.

## 이번 변경
부화 순서: 꼬리 → 안테나 → 얼굴·귀 → 팔·다리 동시 + 남은 알 전체 파각.
처음부터 끝까지 꼬리 흔들기. 두 발 달리기. 빠른 두 번째 접근 후 가벼운 압박만 표현.
한두 걸음만 뒤로 물러나 근접한 웃음·갸웃 엔딩. 알 조각은 바닥에 유지.

완벽한 재현을 보장할 수 없으며, 생성 후 실제 결과 검토가 필요함. 추가 유료 생성은 자동 실행하지 않도록 지시함.
