# 외지몽 15초 스토리보드 v07 — 승인 대기

사용자 요청: 안테나 신호 반응 시 구슬 옆 전기 표시 추가. 원페이지 보드 검증·승인 후 최종 영상 프롬프트 작성.
현재 단계에서는 v07 영상 실행용 프롬프트를 작성하지 않음. 기존 v06은 전기 효과 요청 이전의 중간 수정안으로 보존.

## 신규 전기 표시 제안
03컷 2.5–3.3초 안테나 두 개가 드러나 작게 반응할 때 각 구슬 바깥 옆에 작은 지그재그 전기 표시 1개씩, 총 2개를 잠깐 표시.
색상 제안: 연한 따뜻한 노란색. 크기 제안: 각 구슬 지름 약 1/4 이하. 이 색·크기는 사용자 확정 전 제안값.
구슬과 떨어진 공중 효과이며 구슬의 색·재질·형태 및 캐릭터의 고정 디자인을 변경하지 않음.
얼굴·귀가 나오는 04컷 전에는 사라짐. 강한 번개, 두 구슬을 잇는 방전, 전체 발광 없음.

## 유지·명확화
- 꼬리 먼저 좌우 흔들기 → 안테나+전기 반응 → 얼굴·귀만 → 팔·다리가 함께 나오며 남은 알 전체 파각.
- 6–7.2초 두 발로 달리다 한 번 넘어짐.
- 7.2–8.3초 완전히 일어남. 8–8.3초 두 발을 딛고 몸통을 세우고 양손은 바닥에서 뗀 자세 확인.
- 8.3–10.5초 왼발·오른발 교대로 빠르게 달림. 양손은 허리~가슴 높이, 몸통 세로 유지.
- 10.5–11초 코가 카메라에 접근. 11–12초 살짝 눌리는 유리 같은 접촉.
- 12–15초 한두 걸음만 뒤로 물러나 가까이에서 카메라를 보며 웃고 갸웃.
- 꼬리는 처음 나온 순간부터 끝까지 계속 흔듦. 근접화면에서 안 보여도 동작은 계속.
- 깨진 알은 바닥에 유지. 외형·색상·몸 비율·꼬리 부착 위치 변경 없음.

승인받을 항목: 작은 연노랑 전기 표시의 위치·크기·지속 구간, 완전한 직립 후 재달리기 전환.
