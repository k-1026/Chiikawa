# 마스코트 디자인 스펙시트 v03

사용자 요청에 따라 최신 고정 외형을 기준으로 저장한 버전이다. 이전 v02 파일은 수정하지 않았다.

- [대키미 디자인 시트](daekimi_design_spec_v03.md)
- [외지몽 디자인 시트](oejimong_design_spec_v03.md)

대키미는 사용자가 마지막에 첨부한 단독 이미지와 같은 파일의 얼굴형·크기·머리와 몸 비율을 고정했다. 외지몽은 마지막 비교 이미지의 오른쪽 초록색 캐릭터를 잠정 고정했다. 비교 이미지 왼쪽 대키미는 기준이 아니다.

reference 폴더에는 두 기준 이미지와 초기 설정 보드를 바이트 그대로 복사했다. data 폴더에는 현재 기준 이미지에서 읽은 눈 경계·반짝임·수동 얼굴/몸통 판독점과 색상 관측값이 있다. 수동 경계는 근사값이며3D 정밀 도면이 아니다.

과거의 확대·축소 퍼센트를 누적하지 않는다. 원본PDF 관측값과 최신 고정 이미지 수치를 섞지 않는다. 대키미103cm·외지몽105cm를 유지하며, 두 캐릭터 비교는 같은 바닥선·거리·자세·축척에서 한다.

다른 AI에는 각MD와 해당고정이미지를 함께 첨부하고, 장면 설명만 추가한다. 기본형 검증용 흰 배경·팔 내림 지시는 다른 포즈·컨셉 요청을 막는 영구 규칙이 아니다. 텍스트만으로 모든 생성모델의 픽셀 단위 동일 결과를 보장한다고 주장하지 않는다.
