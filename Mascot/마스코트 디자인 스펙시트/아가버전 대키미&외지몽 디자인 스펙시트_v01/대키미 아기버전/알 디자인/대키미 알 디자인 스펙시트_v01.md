## 4. 정면과 좌우의 정의
정면은 승인한 매듭이 보이는 면이다. LEFT는 **정면을 바라보는 관찰자의 왼쪽 면을 보는 카메라**, RIGHT는 정면 관찰자의 오른쪽 면을 보는 카메라다. 알에는 캐릭터 같은 해부학적 좌우를 지정하지 않는다.
| 시트 칸 | 시점 |
|---|---|
| 위 왼쪽 FRONT | 정면0도 |
| 위 중앙 LEFT45 | 정면 기준 왼쪽에서45도 |
| 위 오른쪽 RIGHT45 | 정면 기준 오른쪽에서45도 |
| 아래 왼쪽 LEFT SIDE | 왼쪽에서90도. 정면이 화면 오른편 가장자리에 있음 |
| 아래 중앙 RIGHT SIDE | 오른쪽에서90도. 정면이 화면 왼편 가장자리에 있음 |
| 아래 오른쪽 BACK | 후면180도 |

같은 알을 회전해 관찰한다. 좌우 사진을 단순 반전해 대체하지 않는다. 명시 각도는 목표 시점이며 생성 PNG가 정밀 정투영 도면이라는 뜻은 아니다.

## 5. 리본 — 개수와 연속 경로
- 완성된 매듭은 **정면에1개**. 고리2개·긴 자락2개.
- 두 개의 띠 구간이 알 몸통을 사선으로 감싸 정면에서X방향으로 교차하고, 뒤에서도 단순X교차로 이어진다.
- “띠2개”는 보이는 감김 구간을 말한다. 별도 완성 리본2개나 매듭2개를 뜻하지 않는다. 하나의 비단 리본이 두 방향으로 알을 감싼 구조다.
- 앞의 한 띠는 왼쪽 위→오른쪽 아래, 다른 띠는 오른쪽 위→왼쪽 아래로 흐른다. 알 곡면을 감싸므로 화면에서는 곡선이다.
- 후면에는 매듭·고리·새 자락을 만들지 않는다. 후면X에서는 화면 왼쪽 위→오른쪽 아래로 내려오는 띠가 위층이다.
- 좌우 측면에는 앞의 나비 매듭이 옆모습으로 보일 수 있다. 이를 측면에 새로 붙인 리본으로 만들지 않는다.
- 리본은 알 표면을 부드럽게 감싸며 관통하거나 떠 있지 않는다. 부화 때 풀릴 수 있는 느슨한 결속이다.
- 자락2개는 정면 양쪽 아래로 길게 내려온다. 정수리 위에 대칭 리본을 얹거나 수직 선물포장으로 바꾸지 않는다.

## 9. 부화 장면과의 연결
기본 시트는 균열 없는 닫힌 알이다. 신체가 밖으로 보이거나 투명한 단면이 아니다.

꼬리는 작은 폭으로 어설프게 좌우에 꼬물거리며 나온다. 자락을 톡 건드려 리본이 느슨해지는 연출로 연결할 수 있다.
아기는 낯선 세상을 조심스럽게 살피는 소심한 신생아이며, 부화 후 리본을 꼭 쥐고 올려다본다. 성장하면 귀·안테나가 펴지고 보송털이 매끈해진다.
껍질 두께·균열 위치·열리는 패널 개수·리본이 실제로 풀리는 물리 경로·영상 길이·카메라·소리는 아직 별도 설계 대상이다. 이 정면과6방향 시트만으로 실제 천 풀림이나 내부 적합 검증을 했다고 주장하지 않는다.
