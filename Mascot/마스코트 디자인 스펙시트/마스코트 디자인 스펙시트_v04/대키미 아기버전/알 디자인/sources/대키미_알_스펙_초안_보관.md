## 1. 제작 상태와 범위
이 문서는 닫힌 알의 디자인과 부화 시 리본이 풀리는 방향을 정의하는 초안이다. 검증 샘플1장으로 형태·색·리본 감김을 확인한다. 사용자가 새 샘플을 승인하기 전에는 최종 승인 디자인이라고 표시하지 않는다.
영상·실제 부화 컷은 이번에 제작하지 않는다. 부화 구조는 이야기 연결을 위한 설계 의도이며 완성된3D 시뮬레이션 검증이 아니다.

## 2. 사용자 기준 자료
- 첫 번째 손그림: 리본의 사선 교차 감김, 정면의 위쪽 오른편 매듭, 양쪽 아래로 흐르는 자락의 구조 참고.
- 두 번째 첨부 사진: 아이보리 알 형태·무광 질감·하늘색 별과 점무늬의 기준. 참고 사본은 sources/shell_reference.png.
- 두 번째 사진의 정수리 중앙에 대칭으로 묶인 리본 배치는 채택하지 않는다.
- 손그림의 검정색·굵은 윤곽선·겹쳐 그린 선을 실제 리본의 색·매수·정밀 경로로 오해하지 않는다.
- 리본 재질과 색은 대키미 성체v04 및 baby.ver_v01과 연결한다.

## 3. 확정된 디자인 방향

| 무늬 | 옅은 하늘색 네 갈래 별과 작은 점. 큰 별·중간 별·작은 점의 크기 차이 |

아이보리와 무늬의 픽셀색은 조명과 음영을 포함한다. 이번 생성 샘플의 임의 픽셀색을 브랜드 공식색으로 지정하지 않는다.
알 정면의 기준은 매듭이 보이는 면이다. 여기서 말하는 좌우는 관찰자 기준으로, 캐릭터 신체의 해부학적 좌우와 혼동하지 않는다.

## 4. 크기 — 제안 상태
| 항목 | 제안값 | 상태 |
|---|---|---|
| 껍데기 외곽 높이 | 50cm | 미확정 |
| 최대 너비 | 42cm | 미확정 |
| 최대 깊이 | 40cm | 미확정 |
| 리본 포함 전체 외곽 | 별도 | 미정 |
| 껍질 두께 | 별도 | 미정 |
| 내부 유효 공간 | 별도 | 미검증 |

대키미 아기의 선 자세 전체 키는53cm로 확정됐다. 알 내부에서는 신생아처럼 등을C자로 말고 턱·무릎·손을 몸 가까이 모으며 꼬리를 감고 귀·안테나를 부드럽게 접는다. 따라서 알 높이가 선 자세 키보다 작을 수 있다.
50×42×40cm는 아기 큰 머리를 고려한 초기 제안이며, 사용자가 치수를 승인했거나 실제로 내부에 들어가는지 검증했다는 뜻이 아니다.
아기 머리 깊이·웅크린 자세의 외곽·껍질 두께를 함께 확인해야 한다. 외지몽 아기도53cm지만 종별 머리와 귀 형태가 달라 동일 알 외곽을 자동 적용하지 않는다.
baby.ver_v01의 앉은 높이49cm 역시 아직 제안이다. 이를 확정 치수로 연쇄 적용하지 않는다.

## 5. 리본 경로와 크기 — 이번 샘플의 작업 해석
손그림을 읽기 쉬운 형태로 구현하기 위해 아래를 임시 기준으로 둔다. 사용자 승인 후 고정하며, 손그림에 숫자가 있었다고 주장하지 않는다.
- 알 본체의 가로·세로를 각각100%로 볼 때 매듭 중심은 정면x≈60%, y≈40%를 목표로 한다.
- 한 띠는 왼쪽 위에서 오른쪽 아래로, 다른 띠는 오른쪽 위에서 왼쪽 아래로 이어지는 사선X방향이다. 곡면을 따라 돌아가므로 실제 화면의 선은 휘어진다.
- 각 띠는 뒷면과 옆면을 통해 이어져 알을 감싸는 연속 경로다. 정면에 조각을 따로 붙인 스티커처럼 만들지 않는다.
- 완성된 나비 매듭은 하나다. 고리2개·자락2개를 구분하며, 띠가 겹쳐 보인다고 새 자락이나 매듭을 추가하지 않는다.
- 자락은 얇고 유연하게 길게 내려오되 얼굴 크기를 압도할 거대한 장식으로 만들지 않는다.
- 띠 폭·고리 크기·자락 길이cm·정확한 뒤쪽 경로는 검증 이미지 확인 후 정한다. 이번 정면1장만으로 후면의 매듭 구조가 완전히 검증되지는 않는다.
- 강하게 죄는 결속이 아니라 부화 시 느슨해질 수 있는 부드러운 묶음이다. 리본이 껍데기를 관통하거나 떠 있지 않는다.

## 6. 무늬 배치
참고 사진의 하늘색 별·점의 차분한 밀도와 크기 관계를 유지한다. 별을 눈처럼 만들거나 글자·문장·얼굴·새 문양을 추가하지 않는다.
리본에 가려진 별은 자연스럽게 가리고, 별을 보이게 하려고 무늬를 띠 위에 덧그리지 않는다.
모든 면의 별 개수와 정확한좌표는 미확정이다. 샘플을 승인한 뒤 정면 패턴을 고정하고, 후면을 별도 설계한다. 영상 프레임마다 무늬가 이동·증식하지 않게 한다.

## 7. 내부 자세와 부화 동작
아기는 갓 부화해 걷기 서툴고 세상이 낯설어 소심하고 조심스럽다. 알 안에서는 신생아처럼 편안하게 웅크린 자세다.
1. 닫힌 알: 리본이 묶여 있고 신체는 보이지 않는다.
2. 꼬리: 뒤쪽 아래 작은 틈에서 말린 끝이 먼저 나오며, 나오는 동안과 나온 직후 작게 좌우로 흔들린다.
3. 발: 작은 두 발이 아래쪽에서 나오며 알을 서툴게 지탱한다.
4. 귀·안테나: 위쪽이 열리며 귀와 구슬 달린 안테나가 나온다. 얼굴과 손은 아직 가린다.
5. 손: 양옆으로 작은 손이 나와 껍데기를 밀어낸다.
6. 알 전체가 벌어짐: 아기가 중심을 잃고 엉덩방아를 찧는다. 리본은 완전히 풀려 천으로 떠오른다.
7. 리본이 내려앉음: 머리와 어깨 위로 느슨하게 얹히고, 아기가 자락을 꼭 쥔 채 조심스럽게 올려다본다.

꼬리가 자락을 건드리고 알이 벌어지며 리본이 단계적으로 느슨해지도록 연결한다. 꼬리 등장 즉시 리본이 완전히 사라지거나 나중에 다시 묶인 형태로 생기지 않는다.
발·귀·안테나·손이 나오는 위치를 사선 리본이 단단히 막지 않도록 경로와 느슨함을 검토한다. 실제 천 경로의 풀림 가능성은 추가 검증 대상이다.
균열의 정확한 지도·열리는 패널의 수·껍데기 두께는 아직 미정이다. 큰 조각으로 부드럽게 벌어지고 날카로운 파편이 아기를 향해 튀는 연출은 사용하지 않는다.
