# 외지몽 마스코트 디자인 스펙시트 v04

**버전04 / 2026-11-04 / 전체 키 105cm / v03 신체 기준 유지·배 무늬 추가·꼬리 끝 형태와 색 수정**

## 사용 목적과 재현 범위
이 문서는 외지몽을 다시 생성할 때 사용할 통합 디자인 명세다. 다른 파일을 열지 않아도 캐릭터의 종·신체 특징·기본색·배 무늬·꼬리·재질·허용 변형을 글로 이해할 수 있도록 정리했다. 아래 복사 지시문에 원하는 장면을 추가해 사용할 수 있다.

**MD만으로 생성할 수는 있지만, 최종 승인 사진과 동일한 얼굴·윤곽·픽셀을 보장하지 않는다.** 문서 안의 이미지 링크는 별도 PNG를 가리키므로 MD만 업로드하면 이미지가 자동 전달되지 않는다. 사진에 가깝게 재현하려면 이 MD와 최종 승인 PNG를 함께 첨부한다. 가려진 구조와 3D 깊이는 한 장의 정면 사진만으로 확정하지 않는다.

### 기준 우선순위
- 얼굴·눈·주둥이·귀·안테나·몸통·팔다리의 기본 구조와 상대 비율은 v03 신체 기준을 유지한다. 비교 이미지에서는 오른쪽 초록색 외지몽만 사용한다.
- 배 무늬와 꼬리의 형태·색 전환·최종 통통함은 위 v04 승인 정면을 우선한다. 초기의 배 없음·긴 타원·뾰족한 꼬리 시안으로 되돌리지 않는다.
- v04 승인 이미지는 생성 편집 결과다. v03과 픽셀 단위로 동일한 신체라고 주장하지 않으며, 편집 중 발생한 미세한 색·형태 차이를 새로운 배율 명령이나 새 브랜드색으로 해석하지 않는다.
- 과거 얼굴·몸통 5% 확대, 얼굴 추가 3% 확대, 구슬 3% 축소 등 검토 배율은 재적용하지 않는다.
- 아래 2·3·6·7절의 기존 이미지 좌표와 관측색은 **v03 비교 이미지의 관측값**이다. 중앙에 배치된 v04 정면에 그대로 좌표를 복사하지 않는다.

### 텍스트만 사용할 때의 캐릭터 요약
외지몽은 초록색 강아지형 외계인 마스코트다. 아래로 늘어진 둥근 강아지 귀와 끝에 구슬이 하나씩 있는 안테나 2개가 있다. 머리가 크고 몸은 짧고 통통하며 목은 별도로 노출되지 않는다. 검정 눈은 매우 크고 윤기가 나며 코 쪽 아래가 좁아지는 둥근 삼각형이다. 각 눈에 큰 밝은 네 갈래 별 1개·작은 회색 별 1개·아주 작은 회백색 마름모 1개가 있다. 코·입을 둘러싸는 크림색 주둥이가 있으며 코는 검정의 둥근 역삼각형이다. 기본 표정은 작은 혀가 보이는 밝은 미소다. 팔·다리는 짧고 둥글고, 몸 표면은 털 없이 부드럽고 매끈한 낮은 광택의 3D 질감이다. 배 중앙에는 거의 원형에 가까운, 세로로 아주 조금 긴 크림색 무늬 1개가 몸 표면과 평평하게 이어진다. 꼬리는 몸 뒤 하단에서 나와 바깥쪽·위쪽으로 부드럽게 휘며, 통통하고 끝이 둥글다. 초록색 꼬리에서 길고 부드러운 그라데이션을 거쳐 끝의 작은 크림색 영역으로 이어진다. 배·주둥이·꼬리 끝의 기본색은 모두 #F8F0E4다.

## 2. 크기와 비율 기준
전체 높이는 안테나 구슬 최고점부터 발바닥까지다. 아래 숫자는 고정 이미지에서 관찰한 투영값을 전체 키에 맞춰 환산한 근사값이며 실물·3D 모델의 정밀 치수가 아니다. 귀·팔에 가린 머리·몸통 경계는 수동 판독값이다. 원본 윤곽이 표의 사각형보다 우선하며, 몸통을 사각형이나 타원 하나로 재설계하지 않는다.

## 3. 얼굴형과 눈 윤곽
머리는 기준 이미지의 이마·볼·턱선과 가로세로 비율을 유지한다. 얼굴을 새 원·완전한 타원으로 단순화하거나 볼을 부풀리지 않는다. 눈은 코 쪽 아래 모서리가 좁아지는 둥근 삼각형 윤곽이다. 날카로움을 아이라인·속눈썹·각진 돌기로 추가하지 않는다. 눈의 가로폭만 맞추고 윤곽을 둥근 버튼으로 바꾸지 않는다.

| 관측 항목 | 화면 왼쪽 눈 | 화면 오른쪽 눈 |
|---|---|---|
| 검정 영역 경계 | [881, 384, 1025, 536] | [1147, 386, 1293, 540] |
| 너비×높이px | 144×152 | 146×154 |
| 전체 키 환산 크기 | 약19.6×20.6cm | 약19.8×20.9cm |

검정 영역은 max(R,G,B)<100으로 읽은 관측 경계다. 정확한 원본 벡터 곡선으로 오해하지 않는다. v03에서 언급한 행별 경계 JSON은 이번 묶음에 포함되어 있지 않다. 원본 이미지와 표를 함께 참고하며, 머리 크기를 바꿔 눈을 맞추거나 눈 간격을 임의로 넓히지 않는다.

### 눈 하이라이트
눈을 완전히 뜬 경우 각 눈에 **큰 별1개 + 작은 반짝임2개, 총3개**다. 큰 별은 밝고, 작은 별은 더 어두운 회색, 아주 작은 반짝임은 회백색으로 구분한다. 좌우 눈에 같은 좌표를 무조건 복사하지 않는다. 눈을 감거나 가리면 함께 가려질 수 있다.

| 눈·요소 | 눈 내부 중심(x%,y%) | 기준 이미지 관찰색 |
|---|---|---|
| 왼쪽 큰 별 | 58.8, 33.1 | #FBF9F3 |
| 왼쪽 작은 회색 반짝임 | 28.0, 70.7 | #A4A4A5 |
| 왼쪽 아주 작은 마름모 | 23.5, 23.8 | #D5D5D4 |
| 오른쪽 큰 별 | 53.7, 34.4 | #FDFAF4 |
| 오른쪽 작은 회색 반짝임 | 73.6, 73.7 | #A6A6A6 |
| 오른쪽 아주 작은 마름모 | 22.5, 53.9 | #F8F6F2 |

중심은 눈 경계 좌상단(0,0)·우하단(100,100) 기준이다. 색은 조명과 반사가 포함된 이미지 관찰값으로, 영구 색상 코드나 모든 장면에서 고정된 빛 위치가 아니다. 디자인 모티프3개와 눈 표면의 연속적인 광택을 구분한다.

## 4. 코·입·얼굴 색 영역
코는 대키미보다 큰 둥근 역삼각형 검정 형태이며 바로 아래로 곡선 입선이 이어진다. 코와 입을 둘러싼 크림빛 흰색 주둥이 #F8F0E4를 유지한다. 주둥이는 얼굴에 자연스럽게 붙은 얕은 볼륨이며 별도의 큰 흰 공처럼 돌출시키지 않는다.

기본 홍조는 없다. 감정에 따른 일시적인 연한 홍조는 허용하되 얼굴의 영구 무늬로 만들지 않는다.

## 5. 귀·안테나·꼬리
- 귀는 아래로 늘어진 강아지 귀다. 고정한 오른쪽 외지몽의 귀 크기·끝 위치·부착 구조를 유지한다. 고양이 귀로 세우거나 큰 날개처럼 펼치지 않는다.
- 귀 안쪽이 보이면 주둥이와 동일한 크림빛 흰색 #F8F0E4다. 겉면은 초록색이며 안쪽을 보여주려고 기본 자세의 귀를 뒤집지 않는다.
- 안테나2개, 각각 끝 구슬1개. 이번 잠정 고정 이미지의 크기를 유지한다. 과거3% 축소 지시를 다시 적용하지 않는다.
- 꼬리는 몸 뒤 하단에서 연결되는 통통하고 매끈한 강아지형이다. 바깥쪽으로 나왔다가 위로 부드럽게 휘며 끝은 첨부 v03 단독 이미지처럼 둥글게 마감한다. 최종 통통함·길이·곡률은 v04 승인 정면 기준이다.
- 꼬리를 너무 짧은 돌기로 줄이거나 길게 말린 고양이 꼬리로 바꾸지 않는다. 뾰족한 여우형 끝이나 가느다란 원뿔형 끝을 만들지 않는다. 리트리버 참고는 검토 중 형태 방향이었으며, 최종 끝은 사용자가 다시 지정한 둥근 강아지 꼬리다.
- 꼬리 표면은 몸과 같은 매끈하고 부드러운 낮은 광택이다. 털·잔털·복슬복슬한 윤곽을 추가하지 않는다.
- 뿌리·중간은 몸과 같은 초록색이고, 끝은 주둥이와 같은 **#F8F0E4**다. 전환 구간은 길고 자연스럽게 이어지며, 완전히 크림색인 끝 영역은 작게 남긴다. 길어진 그라데이션을 큰 흰색 덩어리로 바꾸지 않는다.
- 경계선·띠·별도 캡·봉제선 없이 연속적인 색 전환으로 표현한다. 그라데이션의 정확한 수치나 비율은 측정되지 않았으므로 임의의 공식값으로 지정하지 않는다.
- 꼬리 움직임과 시점에 따라 보이는 곡선·가림은 달라질 수 있다. 기본 통통함·둥근 끝·색 배치·몸 뒤 하단 연결 구조를 유지한다.

## 5.1. 배 무늬 — 최종 승인 형태

| 항목 | v04 확정 기준 |
|---|---|
| 개수·위치 | 배 중앙의 무늬 1개, 주변에 초록색 여백 유지 |
| 형태 | 거의 원형에 가까우며 세로로 아주 조금 긴 둥근 타원. 최종 승인 정면의 비율·크기 고정 |
| 색상 | #F8F0E4 / RGB 248, 240, 228. 주둥이·꼬리 끝과 같은 기본색 |
| 규모 | 초기 방향은 배 너비의 약 절반. 최종 크기는 승인 이미지 우선 |
| 표면 | 몸 표면의 색 영역. 별도 부착물·돌출된 공·배지·천 패치가 아님 |
| 경계 | 매끈하고 자연스러운 윤곽, 테두리·봉제선·거친 털 없음 |
| 빛 | 몸 곡면과 광원을 따라 부드러운 명암이 생김. 색 띠나 돌출 테두리로 오해하지 않음 |

사용자는 한 차례 세로를 줄인 배 무늬의 크기와 비율을 확정했다. 이후 이를 더 긴 타원으로 늘리거나 완전한 원·별·하트로 다시 설계하지 않는다. 배 무늬를 맞추려고 몸통을 넓히거나 배를 부풀리지 않는다.

## 6. 몸통 곡선·팔다리·엄지
몸은 이번 기준 이미지 그대로다. 머리 아래로 목이 별도 노출되지 않으며, 어깨는 자연스럽게 연결된다. 배·허리·가슴·볼을 부풀리거나 날씬하게 다시 깎지 않는다. 팔다리는 짧고 부드럽게 둥글다. 원본의 발등 명암을 신발·발목 띠로 바꾸지 않는다.

아래는 팔과 몸통이 겹치는 경계를 수동으로 읽은 확인용 폭이다. 정밀 제작 치수가 아니며 가려진 부분은 추정하지 않는다. 선을 연결해 새 옆선·봉제선으로 그리지 않는다.

| 기준 이미지y | 몸통 왼쪽x / 오른쪽x | 관측 폭px |
|---|---|---|
| 650 | 991 / 1167 | 176 |
| 680 | 971 / 1188 | 217 |
| 710 | 956 / 1204 | 248 |
| 740 | 946 / 1216 | 270 |
| 770 | 941 / 1220 | 279 |
| 810 | 943 / 1219 | 276 |

손은 둥근 손바닥 덩어리와, 보이는 자세에서의 작은 엄지 돌출·얕은 오목점으로 구분한다. 다섯 손가락·손톱을 추가하지 않는다. 기본 정면에서 가려진 엄지를 강제로 꺼내지 않는다. 치킨·마이크 등을 잡는 포즈에서는 원본 보드의 손을 든 동작을 구조 참고로 사용하되, 다른 시점의 엄지 픽셀 크기를 그대로 전신cm로 환산하지 않는다.

## 두 캐릭터가 함께 등장할 때의 공통 기준

- 대키미 전체 키103cm, 외지몽105cm. 같은 축척의 비슷한 자세에서 외지몽의 전체 키가 약1.94% 더 크다. 기준은 안테나 구슬 최고점부터 발바닥까지다.
- 대키미의 머리가 원래 더 넓으므로 머리 너비만 보고 전체 키를 판정하지 않는다. 크기 검증은 같은 바닥선·카메라 거리·시점·자세에서 한다.
- 앉은 장면에서는 골반 지지면과 상체 각도·다리 자세를 비슷하게 맞춘다. 외지몽을 더 뒤에 두거나 더 숙이게 만들어 작아 보이게 하지 않는다. 서로 다른 포즈의 머리 꼭대기 높이를 실제 키로 해석하지 않는다.
- 캐릭터별 얼굴·몸 비율을 유지한 채 전체 캐릭터를 하나의 단위로 배치한다. 상대 키를 맞추려고 얼굴·몸통·구슬을 각각 늘이지 않는다.
- 각 캐릭터의 원본 종, 귀 구조, 얼굴 색 영역, 안테나2개, 각 눈 하이라이트3개를 혼합하지 않는다.


## 8. 바꿀 수 있는 것과 고정할 것
고정: 승인 배 무늬의 위치·형태·상대 크기·색, 통통하고 둥근 꼬리 끝·작은 크림색 끝 영역·긴 색 전환, 종·얼굴형·머리와 몸 비율·눈 윤곽·코와 입의 고유 형태·얼굴 색 영역·귀의 종별 구조·안테나 개수와 구슬·꼬리 기본 형태·기본색·질감.

변경 가능: 상황에 맞는 시선·눈 개폐·입 표정·팔과 다리·몸 방향·종별 구조를 유지한 귀·안테나·꼬리 움직임, 의상·소품·배경. 축제별 색상은 의상·액세서리·소품에 적용하며 신체 기본색을 바꾸지 않는다.

흰색 배경·정면·팔 내림·소품 없음은 **기본형 검증 장면에만** 적용한다. 사용자가 피크닉·공연·관광 등 장면을 요청하면 포즈·배경·소품 지시는 그 요청을 따른다. 캐릭터 고정 디자인은 유지한다.

## 9. 다른 AI에 입력하는 방법
이 MD는 디자인 규칙을 독립적으로 읽을 수 있다. 정면 사진과의 외형 일관성이 중요하면 `reference/oejimong_approved_front_v04.png`를 이 MD와 함께 별도 첨부한다. MD의 상대 이미지 링크만으로 사진이 생성 도구에 전달된다고 가정하지 않는다. 원래 얼굴·몸 비율 검증에는 동봉한 v03 비교 기준을 보완 자료로 사용한다. 두 캐릭터가 함께 나오면 두 MD와 두 기준 이미지를 함께 제공한다. 외지몽 비교 참고 이미지의 왼쪽 대키미는 사용하지 말고, 대키미는 별도의 고정 단독 이미지를 사용한다. 원본 보드는 손·측면·후면처럼 최신 고정 이미지에서 보이지 않는 부분을 보완하는 참고다.

문서 수치만으로 모든 AI가 같은 픽셀·윤곽을 보장하지는 않는다. 기준 이미지·상대 비율을 함께 사용하고 결과를 검수한다. 원본에서 복원할 수 없는3D 깊이·재질계수를 공식값으로 임의 지정하지 않는다.

### 복사해서 사용할 고정 지시문

외지몽 v04 디자인 명세를 따라 같은 초록색 강아지형 외계인 마스코트를 재현한다. 첨부된 승인 정면이 있으면 이를 배 무늬·꼬리의 최우선 시각 기준으로 사용한다. 새 마스코트로 재디자인하지 않는다. v03 비교 기준을 함께 사용하는 경우 오른쪽 초록색 외지몽만 신체 기준으로 참고한다. 그 얼굴·몸통·귀·구슬의 현재 비율을 유지하고 추가 확대·축소를 하지 않는다. 주둥이와 보이는 귀 안쪽은 같은 크림빛 흰색이다. 전체 키는105cm이며 안테나 구슬 최고점부터 발바닥까지다. 눈은 안쪽 아래가 좁아지는 원본 윤곽을 유지한다. 각 눈에 큰 별1개·작은 회색 반짝임1개·아주 작은 회백색 반짝임1개로 총3개를 유지한다. 안테나는2개다. 기본 홍조는 없다. 손은 둥근 손바닥과 자세에 따라 보이는 엄지로 표현하고 추가 손가락을 만들지 않는다. 몸의 부드러운 낮은 광택과 눈의 검정 광택을 구분한다. 배 중앙에는 #F8F0E4의 거의 원형에 가까운 아주 살짝 세로로 긴 무늬 1개를 넣는다. 배 너비 약 절반 규모이며 최종 승인 정면의 비율을 유지하고, 돌출된 공·배지·봉제 패치로 만들지 않는다. 꼬리는 몸 뒤 하단에서 나와 바깥쪽·위쪽으로 부드럽게 휘는 통통하고 매끈한 강아지 꼬리이며 끝은 둥글다. 길이·통통함은 승인 정면을 유지하고 너무 짧게 줄이거나 뾰족하게 만들지 않는다. 몸과 같은 초록색에서 길고 자연스러운 그라데이션을 거쳐 작은 #F8F0E4 크림색 끝 영역으로 이어진다. 강한 경계선·흰색 캡·털·고양이형 나선 꼬리를 추가하지 않는다. 대표 몸색은 #008C3A이며 승인 이미지의 조명 아래 보이는 녹색 중간톤을 참고한다. 사진과 문서만으로 정밀 3D 깊이를 안다고 가정하지 않는다. 요청한 포즈·표정·소품·배경만 바꾸고 기본 디자인은 유지한다. 두 캐릭터가 함께 나오면 같은 축척·비슷한 자세에서 대키미103cm·외지몽105cm 관계를 유지한다. 장면: [원하는 포즈·상황·배경·의상·소품을 입력].

### 단독 MD 사용 안내
이 문서의 요약·표·고정 지시문은 MD만으로도 읽을 수 있다. 다만 텍스트는 실제 이미지·3D 모델을 대체하지 않으므로 단독 입력의 결과를 승인 사진과 동일하다고 보장하지 않는다. 상대경로 PNG는 ZIP을 풀어 문서를 볼 때의 연결이며, 다른 AI에 사진을 전달하려면 PNG도 별도 첨부해야 한다. 사진을 함께 사용해도 새 포즈·시점의 결과는 검수가 필요하다.
