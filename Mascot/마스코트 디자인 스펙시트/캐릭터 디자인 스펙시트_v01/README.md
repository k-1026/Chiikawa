# 대키미·외지몽 캐릭터 디자인 스펙 시트

## 실제 키 기준 v1.1
대키미 전체 키는 103cm, 외지몽 전체 키는 105cm다. 안테나 구슬 최고점부터 발바닥까지를 기준으로 한다. 100u 정규화 치수의 환산은 대키미 1u=1.03cm, 외지몽 1u=1.05cm다. 안테나 구슬 지름은 각각 11.845cm(표시 11.8cm), 13.65cm(표시 13.7cm)다. [전체 실치수·지름표](physical_dimensions.md)를 함께 적용한다.

버전: 1.1 / 정리일: 2026-11-03 / 상태: 전 항목에 작업 기준 지정. 원본 근사 판독값과 제작 지정값을 구분한 실무용 스펙.

## 목적과 기준
대구 사투리 축제 기획 AI 에이전트, 이미지 생성, 일러스트, 홍보물 및 굿즈에서 두 캐릭터의 외형을 일관되게 유지하기 위한 기준이다. 단순한 고양이·강아지 캐릭터로 대체하지 않는다.

첨부된 `character/대키미 캐릭터 설정보드.png`, `character/외지몽 캐릭터 설정보드.png`를 시각 기준으로 사용한다. 실제 파일명은 운영체제의 한글 정규화 방식에 따라 다르게 저장될 수 있으며, 정확한 상대 경로는 color_samples.json에 기록했다. `design/`의 가방 버전 등은 이번 기본형의 기준으로 채택하지 않았다.

이번 대화에서 사용자가 확정한 내용은 이전 진행 기록의 충돌하는 규칙보다 우선한다. 보드 안에서도 장면별 변형이 있으므로 모든 예시를 새로운 고정 규칙으로 채택하지 않는다.

## 캐릭터와 관계
- 대키미: 대구에서 태어나고 자란 고양이형 외계인. 자신만만, 허당미, 서툰 다정함. 사투리를 자연스럽게 쓰고 대구의 말과 일상을 소개한다.
- 외지몽: 우주에서 대구로 온 강아지형 외계인. 호기심, 솔직함, 재도전. 모르는 표현을 질문하고 직접 사용해 본다.
- 서로 오해하고 티격태격하면서도 서로 배우는 친구 관계다. 일방적인 교사와 학생 관계로 고정하지 않는다.
- 진행 기록의 메시지: “표현이 달라도, 친구가 된다.” 보드 문구: “말이 달라도, 친구가 된다.” v1의 기본 홍보 문구는 두 보드에 공통으로 적힌 “말이 달라도, 친구가 된다.”로 지정한다. 기존 기록의 문구는 의미 설명에만 사용한다.

## 근거의 구분
- 사용자 확정: 별 모양 하이라이트, 각 눈 총 3개, 기본 홍조 없음·감정에 따라 허용, 대키미 하늘색 얼굴, 외지몽 주둥이와 귀 안쪽에 동일한 크림빛 흰색, 코 형태의 캐릭터별 차이.
- 보드 표기: 대표색 대키미 #6DCFF5, 외지몽 #008C3A.
- 원본 근사 판독: 정면 부위 크기와 배치, 견본 및 렌더링 표면 색상. 픽셀 경계와 추출 방법을 기록했다.
- 이번 버전의 제작 지정: 깊이·가림 부위 치수·꼬리 중심선 길이와 굴곡·대칭화·하이라이트 세부 도형과 배치·홍조 강도·표정 각도·허용 오차. 원본에 없는 장식을 추가하기 위한 항목이 아니라 반복 제작을 위한 작업 규격이다. 원본의 숨은 3D 구조를 실측한 값이나 사용자 개별 승인값으로 표현하지 않는다.

## 적용 범위
모든 미결 항목에 v1 작업 기준을 지정했다. 원본 이미지 기반 시각 디자인·AI 생성·일러스트 제작에 사용한다. 기본 실제 키는 대키미 103cm, 외지몽 105cm이며 굿즈는 이 기준을 동일 배율로 축소한다. 제조용 금형, 구조·소재·출력 장비별 색 변환은 제품별 제작 단계에서 정한다. 이 문서는 원본 CAD나 물리 제작을 검증한 도면이 아니다.
