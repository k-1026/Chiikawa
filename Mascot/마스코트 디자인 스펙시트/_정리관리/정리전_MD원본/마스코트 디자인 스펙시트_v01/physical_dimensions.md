# 실제 크기·지름 기준 v1.1

## 전체 키
사용자 지정 전체 키: **대키미 103cm, 외지몽 105cm**. 두 캐릭터 모두 안테나 구슬의 가장 높은 지점부터 발바닥까지를 측정한다. 안테나를 제외한 머리 꼭대기까지의 키가 아니다.

기존 정규화 비율 100u를 유지하고 대키미 1u=1.03cm, 외지몽 1u=1.05cm로 환산한다. 외지몽은 대키미보다 2cm, 약 1.94% 크다.

아래 실치수는 기존 근사 판독값 또는 제작 지정값의 비례 환산 결과다. 원본 관찰값의 불확실성은 그대로 존재한다. 표시는 소수 첫째 자리까지이며, 계산 원장은 physical_dimensions.json에 저장했다.

## 둥근 부위의 지름 확인
구슬은 원본 이미지의 타원형 투영 경계 대신 v1에서 지정한 구형 지름(대키미 11.5u, 외지몽 13.0u)을 적용한다. 각 캐릭터의 좌우 구슬 지름은 동일하다.

| 항목 | 대키미 | 외지몽 |
|---|---|---|
| 안테나 구슬 지름 | 11.8cm | 13.7cm |
| 꼬리 기본 단면 지름 | 10.3cm | 11.6cm |

구슬 지름 계산: 대키미 11.5×1.03=11.845cm, 외지몽 13.0×1.05=13.65cm. 외지몽 구슬은 약 1.8cm, 15.2% 더 크다. 전체 키에 대한 구슬 비율은 각각 11.5%, 13.0%로 유지했다. 새 키 때문에 구슬 비율을 추가로 키우지 않았다.

머리와 몸통은 타원형이므로 단일 “지름” 대신 정면 너비·높이와 앞뒤 깊이를 구분한다. 안테나 줄기의 아래 너비는 기울어진 줄기의 투영 경계 너비이며 원통 단면의 실제 지름으로 해석하지 않는다. 꼬리 지름은 기본 몸통 부분의 단면이며 둥근 끝으로 갈수록 마감된다.

## 정면 부위 실치수
가로 × 세로, 단위 cm. 귀·구슬·팔·다리·발은 한쪽 기준. 부위는 서로 겹치므로 세로 치수를 합산하여 전체 키를 계산하지 않는다.

| 항목 | 대키미 | 외지몽 |
|---|---|---|
| 머리 본체 | 69.8 × 51.0 | 60.0 × 52.0 |
| 몸통 | 34.7 × 23.6 | 36.5 × 27.5 |
| 귀 1개 | 22.1 × 22.6 | 22.0 × 39.0 |
| 안테나 줄기 1개 | 6.7 × 12.5 | 7.0 × 10.0 |
| 팔 1개 | 10.6 × 16.4 | 10.0 × 17.0 |
| 다리와 발 1개 | 14.4 × 11.6 | 16.0 × 13.0 |
| 발 1개 | 14.4 × 5.8 | 16.0 × 6.0 |
| 화면 왼쪽 눈 | 21.7 × 21.2 | 20.0 × 21.5 |
| 화면 오른쪽 눈 | 21.2 × 21.7 | 20.5 × 21.0 |
| 코 | 3.9 × 2.4 | 6.0 × 4.5 |
| 기본 열린 입 | 6.7 × 6.3 | 10.0 × 9.0 |
| 크림색 주둥이 | 별도 영역 없음 | 22.5 × 20.0 |

눈의 좌우 차이는 원본 투영 경계 차이다. 대칭 기본형을 제작할 때는 얼굴 세부 가이드의 평균 눈 크기(대키미 20.8×20.8u, 외지몽 19.3×20.2u)를 환산하여 대키미 약 21.4×21.4cm, 외지몽 약 20.3×21.2cm로 사용한다.

## 얼굴·표정·허용 오차 환산
얼굴 도형과 표정 가이드에서 u로 정의된 모든 길이는 대키미 ×1.03, 외지몽 ×1.05로 cm 환산한다. 각도, 불투명도, 면적 비율, 눈 개폐율 등 무차원 비율은 그대로 사용한다. 안테나 구슬 2개·눈 하이라이트 각 3개 규칙도 그대로 적용한다.

| 작업 오차 범위 | 대키미 | 외지몽 |
|---|---|---|
| 머리·몸통 외곽 ±2u | ±2.06cm | ±2.10cm |
| 얼굴 중심·눈·코·입 크기 ±1u | ±1.03cm | ±1.05cm |
| 귀·안테나 크기 ±1.5u | ±1.545cm | ±1.575cm |

103cm·105cm는 이번에 지정한 정확한 전체 키 기준이다. 위 작업 오차는 개별 부위 조정용이며 전체 키를 임의로 바꾸는 허용 범위가 아니다. 굿즈를 축소 제작할 때는 전체 키와 각 부위를 같은 배율로 줄인다.
