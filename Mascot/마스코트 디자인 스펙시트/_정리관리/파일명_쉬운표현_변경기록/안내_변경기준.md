# 파일명 변경 안내

2026-11-13 · 디자인시트 범위만 정리했습니다. Brand logo·goods·AI·PDF·모델명·확장자·버전 번호는 유지했습니다.

- reference → 레퍼런스_이미지
- sources → 원본_참고자료
- data → 측정_제작기록
- prompts → AI_생성프롬프트
- supplement → 앉은자세_보조이미지
- README → 안내
- FRONT/BACK → 정면/후면
- VIEWER_LEFT/RIGHT → 관찰자왼쪽/관찰자오른쪽
- 기존 LEFT/RIGHT만 있는 대키미 파일 → 캐릭터왼쪽/캐릭터오른쪽

관찰자 기준과 캐릭터 기준을 서로 바꾼 것이 아니라 기존 파일의 방향 의미를 이름에 명시했습니다. 과거 경로/해시를 기록한 _정리관리·_관리자료는 감사 이력이므로 원문 보존합니다. ZIP 내부 이름과 PDF에 인쇄된 과거 파일명은 수정하지 않았습니다. 현재 실제 파일 위치는 이 기록의 변경표를 참고하세요.
디자인 내용·이미지·치수·승인 상태를 바꾼 작업이 아닙니다. 문서 안의 실제 경로와 파일명만 함께 갱신했습니다.
