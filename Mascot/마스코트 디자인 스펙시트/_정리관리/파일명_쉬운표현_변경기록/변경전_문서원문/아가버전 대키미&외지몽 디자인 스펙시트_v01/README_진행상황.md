# 대키미·외지몽 아기버전 — 주제별 제작 진행상황

정리일: 2026-11-13

## 버전 규칙

- **같은 주제의 최초 제작 자료가 v00, 이후 디벨롭 자료가 v01·v02로 이어집니다.**
- 캐릭터 디자인·알 디자인·부화 영상은 각각 독립적으로 v00부터 시작합니다. 전체 작업에 한 줄로 번호를 붙이지 않습니다.
- 한 버전 폴더에는 당시 만든 MD·레퍼런스·생성 기록 등을 함께 보관합니다. 없던 MD나 이미지를 새로 작성하지 않았습니다.
- 기존 개별 파일명·문서 본문의 버전은 당시 이력으로 보존했습니다. **폴더 버전이 주제별 정리 기준**입니다.
- sources는 당시 사용한 입력/과거 참고 자료입니다. 해당 버전에서 새로 만든 결과물과 구분합니다.

외지몽 승인 외형은 캐릭터 디자인 v12 두 샘플이며, 현재 최신 전달 묶음은 이를 계승한 캐릭터 디자인 v13입니다.
**최종 자료 저장 위치:** `외지몽 아기버전/캐릭터 디자인/외지몽 아가버전 최종_v13/`
**최종 MD:** `외지몽 아가버전 최종_디자인 측정시트_v13.md`
최종 MD·개별6방향·앉은보조를 제작했습니다. v13은 자료 제작 묶음 번호이며 새 외형 변경을 의미하지 않습니다. 회전 컷은 신규 파생 자료로서 사용자 추가 검수 대상입니다.

굿즈(시팅인형·무드등) 자료는 이미 이동한 Mascot/goods에 보관하며 이번에는 이동하지 않았습니다.
관리용 JSON에 이동 경로·원본 해시를 보관했습니다. 과거 경로를 기록한 이전 이동 로그는 감사 이력이므로 그대로 보존합니다. 현재 위치는 `_관리자료/원본파일_현재위치_검증목록.json`에서 확인합니다.
ZIP은 당시 전달본을 보존한 것이므로 내부의 옛 경로는 유지했습니다. 과거 sources 참고 문서 일부의 기존 끊긴 링크는 `_관리자료/과거참고문서_링크주의.txt`에 기록되어 있습니다.
Git 커밋·푸시는 수행하지 않았습니다.
