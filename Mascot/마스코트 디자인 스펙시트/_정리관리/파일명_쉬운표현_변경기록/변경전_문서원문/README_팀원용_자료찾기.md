## 공통 정리 규칙

1. **주제별 최초 제작 묶음이 `_v00`, 다음 디벨롭이 `_v01`, `_v02`입니다.** 캐릭터·알·영상·젤리패드·원본 분석은 서로 번호를 공유하지 않습니다.
2. 한 버전 폴더에는 당시 만든 MD·레퍼런스·관측데이터·생성기록 등을 함께 둡니다. 당시 없던 자료를 새 산출물처럼 채우지 않습니다.
3. 원본 파일명/본문의 예전v번호는 보존했습니다. **폴더의 버전이 정리용 디벨롭 순서**입니다. 예: 폴더v01 안에 예전 파일명v04가 있을 수 있습니다.
4. 이름의 최종/승인은 당시 상태일 수 있습니다. 위 시작표와 각 폴더 안내에서 현재 용도·과거안·검토본을 확인합니다. 새 승인 상태를 임의로 만들지 않았습니다.
5. 캐릭터 성체 대키미103cm·외지몽105cm, 아기 설정53cm, 굿즈 제품 치수는 서로 다른 기준입니다.
6. PNG는 실제로 첨부해야 AI가 볼 수 있습니다. MD 안 경로만 보내면 이미지가 자동 업로드되는 것이 아닙니다.
7. 정밀3D/봉제 패턴이 아닌 관측·AI 파생 자료는 원문에 적힌 한계를 유지합니다.
