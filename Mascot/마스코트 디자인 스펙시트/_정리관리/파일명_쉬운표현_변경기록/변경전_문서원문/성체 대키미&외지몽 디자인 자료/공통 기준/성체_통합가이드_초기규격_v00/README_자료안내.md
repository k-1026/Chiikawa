# 성체_통합가이드_초기규격_v00

정리일: 2026-11-13

과거 초기 작업 기준. 두 캐릭터/공통색/비율/표정/실치수 규칙과 관측 원장. 현재 최종 외형보다 우선하지 않음.

이 폴더의 `_v00`은 이 주제의 최초 제작/보관 묶음이고 다음 디벨롭은 `_v01`부터 이어집니다. 원본 파일명·문서 제목의 과거 버전은 변경하지 않았습니다. 숫자가 같아도 다른 주제의 같은 작업 단계를 의미하지 않습니다.

정리 과정에서 디자인·색상·치수·승인 여부를 새로 바꾸지 않았습니다. 문서의 기존 유효 링크는 이동 위치로 보정했으며 원래 끊긴 링크는 관리 목록에서 확인합니다.
