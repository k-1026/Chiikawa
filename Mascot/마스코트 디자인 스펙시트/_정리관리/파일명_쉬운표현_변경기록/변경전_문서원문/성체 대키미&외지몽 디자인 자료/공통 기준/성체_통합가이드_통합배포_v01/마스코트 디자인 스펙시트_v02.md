## 01. 문서 개요와 적용 기준

버전: **2.0** · 작성일: **2026-11-03**

대구 사투리 축제 기획 AI 에이전트, 일러스트, 홍보물, 굿즈 제작에 사용하는 대키미·외지몽 통합 디자인 가이드다. 기존 v1.1의 디자인·비율·색상을 유지하고, 최신 전체 키와 환산 치수를 한 문서로 정리한 배포 버전이다.

| 핵심 항목 | 대키미 | 외지몽 |
|---|---|---|
| 종족 | 고양이형 외계인 | 강아지형 외계인 |
| 출신 | 대구 | 우주 |
| 전체 키 | 103cm | 105cm |
| 키의 측정 구간 | 안테나 구슬 최고점~발바닥 | 안테나 구슬 최고점~발바닥 |
| 1u의 실제 길이 | 1.03cm | 1.05cm |
| 안테나 구슬 지름 | 11.845cm (표시 11.8cm) | 13.65cm (표시 13.7cm) |
| 대표색 | #6DCFF5 | #008C3A |

### 우선 적용하는 사용자 확정 사항

- 눈을 완전히 뜬 기본 표정에서 한쪽 눈당 하이라이트 총 3개. 큰 별 1개와 작은 반짝임 2개이며 별 모양 사용은 확정이다.
- 기본 얼굴에 홍조는 없다. 감정 표현에 따라 홍조를 허용한다.
- 대키미 얼굴은 코·입 주변까지 하늘색으로 유지하며 흰색 주둥이 영역을 만들지 않는다.
- 외지몽의 입 주변과 감정·귀 움직임으로 드러나는 귀 안쪽은 같은 크림빛 흰색이다.
- 두 캐릭터의 코와 입은 각각의 원본 형태를 유지한다.
- 대키미 전체 키 103cm, 외지몽 전체 키 105cm를 적용하며, 기존 부위별 상대 비율은 유지한다.

### 정보의 근거

| 구분 | 의미 |
|---|---|
| 사용자 확정 | 이번 대화에서 직접 확정한 외형·표현·키 규칙 |
| 보드 명시값 | 설정 보드에 적힌 대표색 등의 값 |
| 원본 근사 판독값 | 원본 PNG의 부위 경계·픽셀·색상 견본을 읽은 값 |
| 제작 지정값 | 깊이·가림 부위·세부 도형·허용 오차 등 반복 제작을 위해 지정한 작업 규격 |

제작 지정값을 원본 3D 모델의 실측값으로 해석하지 않는다. 전체 키를 제외한 부위 치수는 원본 근사 판독 또는 기존 작업 기준의 환산 결과다. 제조용 금형이나 물리 구조를 검증한 도면은 아니다.

### 캐릭터 관계와 메시지

대키미는 자신만만하지만 허당스럽고 친구를 진심으로 챙기는 대구 토박이다. 외지몽은 호기심이 많고 솔직하며 실수 후에도 다시 도전하는 여행자다. 둘은 표현을 오해하면서 티격태격하지만 서로 배우고 영향을 주는 친구다.

기본 보드 문구는 **“말이 달라도, 친구가 된다.”**다. 이전 기록의 “표현이 달라도, 친구가 된다.”는 같은 관계의 의미를 설명하는 문구로 남긴다.

## 02. 실제 키·지름·cm 치수표

### 전체 키
사용자 지정 전체 키: **대키미 103cm, 외지몽 105cm**. 두 캐릭터 모두 안테나 구슬의 가장 높은 지점부터 발바닥까지를 측정한다. 안테나를 제외한 머리 꼭대기까지의 키가 아니다.

기존 정규화 비율 100u를 유지하고 대키미 1u=1.03cm, 외지몽 1u=1.05cm로 환산한다. 외지몽은 대키미보다 2cm, 약 1.94% 크다.

아래 실치수는 기존 근사 판독값 또는 제작 지정값의 비례 환산 결과다. 원본 관찰값의 불확실성은 그대로 존재한다. 표시는 소수 첫째 자리까지이며, 계산 원장은 physical_dimensions.json에 저장했다.

### 둥근 부위의 지름 확인
구슬은 원본 이미지의 타원형 투영 경계 대신 v1에서 지정한 구형 지름(대키미 11.5u, 외지몽 13.0u)을 적용한다. 각 캐릭터의 좌우 구슬 지름은 동일하다.

| 항목 | 대키미 | 외지몽 |
|---|---|---|
| 안테나 구슬 지름 | 11.8cm | 13.7cm |
| 꼬리 기본 단면 지름 | 10.3cm | 11.6cm |

구슬 지름 계산: 대키미 11.5×1.03=11.845cm, 외지몽 13.0×1.05=13.65cm. 외지몽 구슬은 약 1.8cm, 15.2% 더 크다. 전체 키에 대한 구슬 비율은 각각 11.5%, 13.0%로 유지했다. 새 키 때문에 구슬 비율을 추가로 키우지 않았다.

머리와 몸통은 타원형이므로 단일 “지름” 대신 정면 너비·높이와 앞뒤 깊이를 구분한다. 안테나 줄기의 아래 너비는 기울어진 줄기의 투영 경계 너비이며 원통 단면의 실제 지름으로 해석하지 않는다. 꼬리 지름은 기본 몸통 부분의 단면이며 둥근 끝으로 갈수록 마감된다.

### 정면 부위 실치수
가로 × 세로, 단위 cm. 귀·구슬·팔·다리·발은 한쪽 기준. 부위는 서로 겹치므로 세로 치수를 합산하여 전체 키를 계산하지 않는다.

| 항목 | 대키미 | 외지몽 |
|---|---|---|
| 머리 본체 | 69.8 × 51.0 | 60.0 × 52.0 |
| 몸통 | 34.7 × 23.6 | 36.5 × 27.5 |
| 귀 1개 | 22.1 × 22.6 | 22.0 × 39.0 |
| 안테나 줄기 1개 | 6.7 × 12.5 | 7.0 × 10.0 |
| 팔 1개 | 10.6 × 16.4 | 10.0 × 17.0 |
| 다리와 발 1개 | 14.4 × 11.6 | 16.0 × 13.0 |
| 발 1개 | 14.4 × 5.8 | 16.0 × 6.0 |
| 화면 왼쪽 눈 | 21.7 × 21.2 | 20.0 × 21.5 |
| 화면 오른쪽 눈 | 21.2 × 21.7 | 20.5 × 21.0 |
| 코 | 3.9 × 2.4 | 6.0 × 4.5 |
| 기본 열린 입 | 6.7 × 6.3 | 10.0 × 9.0 |
| 크림색 주둥이 | 별도 영역 없음 | 22.5 × 20.0 |

눈의 좌우 차이는 원본 투영 경계 차이다. 대칭 기본형을 제작할 때는 얼굴 세부 가이드의 평균 눈 크기(대키미 20.8×20.8u, 외지몽 19.3×20.2u)를 환산하여 대키미 약 21.4×21.4cm, 외지몽 약 20.3×21.2cm로 사용한다.

### 입체·꼬리 실치수
아래 치수는 v1의 제작 지정값을 비례 환산했다.

| 항목 | 대키미 | 외지몽 |
|---|---|---|
| 머리 앞뒤 깊이 | 57.7 | 54.6 |
| 몸통 앞뒤 깊이 | 27.8 | 28.4 |
| 발 앞뒤 길이 | 19.6 | 19.9 |
| 꼬리 중심선 길이 | 45.3 | 31.5 |
| 꼬리 끝 말림 반지름 | 10.3 | 고리 말림 없음 |
| 구슬 중심 간격 | 22.7 | 27.3 |

### 얼굴·표정·허용 오차 환산
얼굴 도형과 표정 가이드에서 u로 정의된 모든 길이는 대키미 ×1.03, 외지몽 ×1.05로 cm 환산한다. 각도, 불투명도, 면적 비율, 눈 개폐율 등 무차원 비율은 그대로 사용한다. 안테나 구슬 2개·눈 하이라이트 각 3개 규칙도 그대로 적용한다.

| 작업 오차 범위 | 대키미 | 외지몽 |
|---|---|---|
| 머리·몸통 외곽 ±2u | ±2.06cm | ±2.10cm |
| 얼굴 중심·눈·코·입 크기 ±1u | ±1.03cm | ±1.05cm |
| 귀·안테나 크기 ±1.5u | ±1.545cm | ±1.575cm |

103cm·105cm는 이번에 지정한 정확한 전체 키 기준이다. 위 작업 오차는 개별 부위 조정용이며 전체 키를 임의로 바꾸는 허용 범위가 아니다. 굿즈를 축소 제작할 때는 전체 키와 각 부위를 같은 배율로 줄인다.

## 03. 공통 디자인 규칙

### 형태
- 둥근 큰 머리와 작은 몸통의 치비형. 약 2등신에 가까운 인상이지만 수치 2.0을 측정값으로 사용하지 않는다.
- 목은 별도로 드러나지 않는다. 몸통은 짧고 통통한 타원형이며 옆모습에서도 볼륨을 유지한다. 배는 측면에서 조금 앞으로 나온다.
- 팔과 다리는 짧고 통통하다. 어깨 관절을 별도 구체로 분리하지 않는다.
- 손은 둥근 덩어리형이다. 기본적으로 개별 손가락이 없으며 동작에 필요한 경우 엄지 정도를 구분할 수 있다.
- 다리와 작고 둥근 발은 형태가 구분되어야 한다.
- 머리 위 안테나는 정확히 2개. 각 줄기 끝에 둥근 구슬 1개가 달린다. 줄기는 가깝게 배치하되 서로 맞닿지 않는다.
- 꼬리는 몸통 뒤쪽 하단에 연결된다. 캐릭터별 길이와 굴곡을 유지한다.

### 얼굴
- 큰 검정 눈을 사용한다. 기본 정면은 좌우 대칭을 기준으로 하며 간격과 외곽 윤곽은 원본을 따른다.
- 완전히 뜬 각 눈에는 하이라이트 총 3개: 큰 별 1개와 작은 반짝임 2개. 별 모양 사용은 확정되었다. 작은 반짝임은 작은 네 갈래 1개와 둥근 마름모 1개로 제작 기준을 통일한다. 도형별 크기와 좌표는 「얼굴·하이라이트 세부 기준」를 따른다.
- 감거나 찡그린 눈은 눈꺼풀에 의해 하이라이트가 가려질 수 있다. 닫힌 눈 위에 하이라이트 3개를 따로 붙이지 않는다.
- 기본 얼굴에는 홍조가 없다. 감정 표현에 따라 일시적으로 허용한다.
- 코 바로 아래에 입선이 이어진다. 코와 입 사이에 분리된 빈 간격을 만들지 않는다.
- 코와 입의 기본 형태는 캐릭터마다 다르다. 같은 얼굴로 통일하지 않는다.

### 표현과 재질
원본 보드의 부드러운 입체 볼륨과 매끄러운 표면을 기준으로 한다. 눈은 광택이 있는 검정 표면이다. 반사광과 음영은 재질 표현이며 별도 고정 무늬로 추가하지 않는다. 털 결, 수염, 무늬, 옷, 가방은 기본형의 필수 요소가 아니다.

### 관리 원칙
이번 대화의 확정 내용 > 첨부 보드의 기본형 > 이전 기록 순으로 충돌을 해석한다. 해결되지 않은 충돌은 임의로 확정하지 않는다. 색상은 「색상 팔레트와 추출 근거」를 참조한다.

### 제작 기준의 적용
치수·가려진 연결부·깊이는 「정규화 비율·배치 기준」의 지정값을 사용한다. 새로운 디자인 장식 없이 기존 실루엣을 수치화하기 위한 기준이다. 문서의 “제작 지정값”은 원본에서 실측된 값이나 사용자가 개별적으로 승인한 값과 구별한다.

## 04. 대키미 개별 스펙

### 정체성
대구 출신 고양이형 외계인. 이름은 대구지킴이의 느낌을 담는다. 자신만만하고 가끔 허당스러우며 친구를 진심으로 챙긴다.

### 고정 외형
- 얼굴·몸통·팔다리·안테나·꼬리는 하늘색 계열. 대표색 #6DCFF5.
- 얼굴은 코와 입 주변까지 하늘색을 유지한다. 흰색·크림색 주둥이 패치를 만들지 않는다. 보드 일부 표정의 흰색 입 주변은 기본형으로 채택하지 않는다.
- 귀는 머리 위쪽에 솟은 삼각형 고양이 귀. 끝은 뾰족한 실루엣을 유지하고 안쪽은 분홍색 #FDB6C1(견본 추출값)이다.
- 안테나 2개. 줄기는 외지몽보다 길며 고양이 귀 높이와 비슷한 인상을 유지한다. 구슬은 외지몽보다 약간 작다. 정규화 치수는 「정규화 비율·배치 기준」를 따른다.
- 꼬리는 외지몽보다 길고 굵은 고양이형이며 둥글게 위로 말린다.
- 코는 작고 가로로 납작한 검정색. 외지몽처럼 크고 둥근 코로 변경하지 않는다.
- 코 바로 아래에 작은 고양이형 곡선 입선이 이어진다. 웃을 때 벌어진 입과 혀를 표현할 수 있으며 얼굴 바탕색을 유지한다.
- 눈 검정은 #282727(견본 추출값), 하이라이트는 #FEFEFE(견본 추출값). 각 눈 하이라이트 3개 규칙을 따른다.

### 표정과 동작
보드의 자신만만, 답답함, 머쓱함, 인정, 위로, 토론을 예시로 사용한다. 귀의 기울기는 바뀔 수 있으나 삼각형 구조를 유지한다. 안테나와 꼬리는 움직일 수 있다. 기본 홍조는 없고 감정에 따라 허용한다.

### 치수·얼굴·색상 기준

## 07. 얼굴·하이라이트 세부 기준

전체 높이를 100u로 두며, 1u는 전체 높이의 1%다.

이 문서는 관찰된 얼굴을 반복 제작할 수 있도록 지정한 도형·배치 기준이다. 원본 벡터 경로를 복원한 데이터가 아니다. 전체 위치와 크기는 「정규화 비율·배치 기준」를 따른다.

### 코와 입
- 대키미: 코 너비 3.7u, 높이 2.3u. 가로로 납작하고 모서리가 둥근 검정 형태. 코 아래 중앙에서 두 갈래의 짧은 고양이형 곡선 입선이 이어진다. 기본 열린 입의 너비 6.5u, 높이 6.1u. 입 주변 패치 없음.
- 외지몽: 코 너비 5.7u, 높이 4.3u. 둥근 역삼각형에 가까운 검정 형태. 코 아래 중앙에서 둥근 주둥이를 따라 두 갈래 곡선 입선이 이어진다. 기본 열린 입의 너비 9.5u, 높이 8.6u.

- 코와 입선은 연결되며 분리 간격 0. 닫힌 입에서는 열린 입 내부와 혀가 보이지 않는다. 혀는 열린 입 하단에 너비 입 너비의 55%, 높이 입 높이의 35%로 지정한다. 입선 두께는 0.7u, 끝은 둥글게 처리한다. 이 선 두께와 혀 비율은 제작 지정값이다.

### 눈과 하이라이트
기본 정면의 검정 눈 형태와 좌우 간격은 원본 판독값을 사용한다. 대칭 제작을 위한 눈 하나의 평균 크기는 대키미 20.8 × 20.8u, 외지몽 19.3 × 20.2u로 지정한다. 표정에 따라 눈꺼풀이 가리거나 눈이 감기는 것은 허용한다.

각 눈의 하이라이트는 큰 별 1개 + 작은 반짝임 2개로 고정한다. 큰 별은 보드처럼 끝이 둥글고 팔이 네 방향으로 뻗은 형태를 사용한다. 작은 반짝임 2개의 형태는 작은 네 갈래 반짝임 1개와 작은 둥근 마름모 1개로 제작 기준을 통일한다. 모두 같은 크기의 별 3개로 만들지 않는다.

눈 하나의 경계 사각형 좌상단=(0,0), 우하단=(100,100) 기준: 큰 별 중심 (57,30), 크기 31×34; 작은 네 갈래 중심 (29,73), 크기 14×16; 작은 마름모 중심 (23,18), 크기 7×8. 이 배치·도형 수치는 반복 제작을 위한 지정값이며 원본 모든 장면의 하이라이트 좌표와 일치한다는 의미가 아니다. 두 눈 모두 화면 기준 같은 배치를 사용한다. 눈을 가리는 눈꺼풀이 있으면 하이라이트도 함께 가린다.

### 홍조
기본은 없음. 감정에 따라 눈 아래 바깥쪽에 연한 홍조를 허용한다. 타원 크기 너비 5u × 높이 2.5u, 중심은 해당 눈 중심에서 얼굴 바깥쪽으로 4u, 아래로 10u 이동한 위치를 기준으로 한다. 색상 #FDB6C1, 불투명도 15%, 강한 감정 최대 25%. 윤곽선 없이 경계를 부드럽게 처리한다. 이 위치·크기는 제작 지정값이다.

### 적용 규칙
- 외지몽의 입 주변과 보이는 귀 안쪽은 동일한 크림빛 흰색 #F8F0E4를 적용한다. 순백색으로 바꾸지 않는다.

## 09. 표정·동작 가이드

### 공통 불변 요소
표정이 달라져도 기본 머리·몸통 실루엣, 기본색, 종족별 귀 구조, 안테나 2개와 구슬, 꼬리의 고유 구조, 캐릭터별 코와 입 주변 영역을 유지한다.

### 변경 가능한 요소
눈의 개폐와 시선, 입의 벌어짐과 곡선, 몸 방향과 자세, 팔·다리 제스처, 귀의 기울기, 안테나 기울기, 꼬리 움직임. 기쁨 등 감정에 따른 홍조는 허용하되 기본 얼굴에는 넣지 않는다.

### 눈 하이라이트
눈을 완전히 떴을 때 한쪽 눈당 큰 별 1개와 작은 반짝임 2개, 총 3개다. 반쯤 감긴 눈에서는 눈꺼풀에 가려지는 것을 허용한다. 완전히 감긴 눈에는 억지로 하이라이트를 그리지 않는다.

### 귀와 홍조
대키미의 귀는 감정에 따라 기울어도 삼각형 구조를 유지한다. 외지몽은 귀가 움직이며 안쪽이 보일 때만 입 주변과 같은 크림빛 흰색을 드러낼 수 있다. 홍조는 #FDB6C1, 불투명도 기본 0%·감정 15%·강한 감정 최대 25%이며 영구 무늬로 취급하지 않는다.

### 소품
보드의 마이크, 수첩 등은 장면용 소품이다. 소품은 캐릭터의 신체 구조를 바꾸지 않으며 기본형에 항상 부착하지 않는다.

## 10. AI 이미지 생성 프롬프트

반드시 해당 캐릭터 설정 보드를 참조 이미지로 함께 제공한다. 문장만으로 원본 실루엣과 작은 하이라이트 개수의 재현을 보장할 수 없으므로 결과를 스펙과 대조한다. HEX는 목표 기본색이며 입체 이미지의 모든 픽셀이 같은 색일 필요는 없다.

### 대키미 고정 프롬프트
첨부 참조 이미지의 공식 캐릭터 대키미를 동일한 디자인으로 재현한다. 대구 출신의 하늘색 고양이형 외계인. 대표색 #6DCFF5. 둥글고 큰 머리, 작고 통통한 몸통, 별도 목 없이 이어지는 치비형 비율. 짧고 통통한 팔과 다리, 둥근 손과 구분되는 작은 발. 머리 위에 분홍색 #FDB6C1 안쪽이 보이는 삼각형 고양이 귀. 구형 구슬이 달린 안테나 정확히 2개. 안테나 줄기는 외지몽보다 길다. 몸 뒤 하단에 연결되어 둥글게 위로 말린 두꺼운 고양이 꼬리. 큰 검정 눈 #282727. 완전히 뜬 각 눈에 큰 별 하이라이트 1개와 작은 반짝임 2개로 총 3개. 작고 가로로 납작한 검정 코와 바로 아래로 이어지는 고양이형 곡선 입선. 코와 입 주변 얼굴은 하늘색이며 흰색 주둥이 영역은 없다. 부드러운 입체 볼륨과 매끄러운 표면, 광택 있는 눈. 기본 얼굴은 홍조 없음. 원본 실루엣과 얼굴 비율 유지.

### 외지몽 고정 프롬프트
첨부 참조 이미지의 공식 캐릭터 외지몽을 동일한 디자인으로 재현한다. 우주에서 대구로 찾아온 초록색 강아지형 외계인. 대표색 #008C3A. 둥글고 큰 머리, 작고 통통한 몸통, 별도 목 없이 이어지는 치비형 비율. 짧고 통통한 팔과 다리, 둥근 손과 구분되는 작은 발. 머리 위쪽 양옆에서 아래로 늘어진 둥근 강아지 귀. 구형 구슬이 달린 안테나 정확히 2개. 안테나 줄기는 대키미보다 짧고 구슬은 아주 약간 크다. 몸 뒤 하단에 연결된 상대적으로 짧고 두꺼우며 끝이 뭉툭한 꼬리. 큰 검정 눈 #262524. 완전히 뜬 각 눈에 큰 별 하이라이트 1개와 작은 반짝임 2개로 총 3개. 대키미보다 큰 둥근 역삼각형 검정 코와 바로 아래로 이어지는 곡선 입선. 코와 입을 둘러싼 둥근 주둥이 영역은 크림빛 흰색 #F8F0E4. 감정이나 귀 움직임으로 보이는 귀 안쪽에도 같은 #F8F0E4를 사용한다. 부드러운 입체 볼륨과 매끄러운 표면, 광택 있는 눈. 기본 얼굴은 홍조 없음. 원본 실루엣과 얼굴 비율 유지.

대키미 전체 키 103cm, 외지몽 전체 키 105cm. 안테나 구슬 최고점부터 발바닥까지의 키다. 두 캐릭터를 함께 그릴 때는 같은 바닥선·카메라 거리·축척에서 외지몽이 2cm 더 크게 보이도록 한다. 안테나 구슬 지름은 대키미 약 11.8cm, 외지몽 약 13.7cm. 자세와 원근이 다르면 화면상의 키 차이만으로 크기를 비교하지 않는다.

## 11. 금지 사항과 결과 확인

### 공통
안테나가 1개 또는 3개 이상, 구슬 누락, 구슬이 뾰족한 형태, 길고 가는 팔다리, 드러난 긴 목, 지나치게 작은 머리, 평평하고 가느다란 몸통, 분리된 구형 어깨 관절, 기본 자세의 개별 손가락, 발 구분 없는 다리, 검정이 아닌 기본 눈, 완전히 뜬 눈의 하이라이트 총 개수가 3개가 아닌 상태, 코와 입의 분리, 캐릭터 간 코·귀·꼬리 혼동, 기본 얼굴의 상시 홍조, 원본에 없는 영구 무늬·털 결·수염 추가를 피한다.

별 모양 하이라이트는 금지 대상이 아니다. 각 눈의 큰 별 1개는 필수다. 감정에 따른 홍조는 금지 대상이 아니며 기본형에서만 제외한다. 감거나 가려진 눈에는 하이라이트 개수 규칙을 기계적으로 강제하지 않는다.

### 대키미
흰색 또는 크림색 주둥이 패치, 아래로 늘어진 강아지 귀, 분홍색 귀 안쪽 누락, 초록색 몸, 짧은 강아지 꼬리, 외지몽과 같은 크고 둥근 코로 변경하지 않는다.

### 외지몽
솟은 삼각형 고양이 귀, 크림색 주둥이 누락, 주둥이를 순백색으로 변경, 귀 안쪽을 분홍색이나 주둥이와 다른 색으로 변경, 귀 겉면 전체를 크림색으로 변경, 하늘색 몸, 길고 가는 고양이 꼬리, 점처럼 짧은 꼬리, 대키미와 같은 작은 납작한 코로 변경하지 않는다.
