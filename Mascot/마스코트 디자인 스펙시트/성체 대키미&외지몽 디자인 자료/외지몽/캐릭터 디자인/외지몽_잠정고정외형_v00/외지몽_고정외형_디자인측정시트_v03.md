# 외지몽 캐릭터 디자인 스펙 시트 v03

**버전03 / 2026-11-03 / 전체 키 105cm / 사용자가 지금은 일단 픽스라고 한 마지막 비교 이미지의 오른쪽 초록색 캐릭터만 잠정 고정**

## 1. 이번 버전에서 고정한 것
마지막으로 보여준 비교 이미지의 **오른쪽 초록색 외지몽만** 사용자가 현재는 잠정 고정한 외형으로 삼는다. 같은 이미지의 왼쪽 대키미는 이전 검토형이므로 대키미 기준으로 사용하지 않는다. 얼굴·몸통·구슬·귀의 현재 상대 크기를 유지하고 추가 확대·축소를 하지 않는다.

앞서 얼굴·몸통5% 확대, 얼굴 추가3% 확대, 구슬3% 축소 등의 수치는 검토용 제안이었다. 추가 얼굴 보정 생성은 한도로 완료되지 않았고 모든 배율이 이미지에 정확히 반영됐다고 확인하지 못했다. 이 버전에서는 그 배율을 누적 명령으로 사용하지 않고, 실제 잠정 고정 이미지 자체를 우선한다.

### 기준 우선순위
사용자가 고정한 최신 기준 이미지 → 이번 시트의 동일 이미지 관측값 → 충돌하지 않는 원본 보드의 종별 구조·손·측후면 참고 → 이전 PDF 관측자료 순이다. 오래된 표나 문장의 비율로 최신 기준 얼굴을 다시 바꾸지 않는다.

## 3. 얼굴형과 눈 윤곽
머리는 기준 이미지의 이마·볼·턱선과 가로세로 비율을 유지한다. 얼굴을 새 원·완전한 타원으로 단순화하거나 볼을 부풀리지 않는다. 눈은 코 쪽 아래 모서리가 좁아지는 둥근 삼각형 윤곽이다. 날카로움을 아이라인·속눈썹·각진 돌기로 추가하지 않는다. 눈의 가로폭만 맞추고 윤곽을 둥근 버튼으로 바꾸지 않는다.

| 관측 항목 | 화면 왼쪽 눈 | 화면 오른쪽 눈 |
|---|---|---|
| 검정 영역 경계 | [881, 384, 1025, 536] | [1147, 386, 1293, 540] |
| 너비×높이px | 144×152 | 146×154 |
| 전체 키 환산 크기 | 약19.6×20.6cm | 약19.8×20.9cm |

검정 영역은 max(R,G,B)<100으로 읽은 관측 경계다. 정확한 원본 벡터 곡선으로 오해하지 않는다. 각 픽셀 행의 좌우 경계를 data의 JSON에 기록했으며, 머리 크기를 바꿔 눈을 맞추거나 눈 간격을 임의로 넓히지 않는다.

### 눈 하이라이트
눈을 완전히 뜬 경우 각 눈에 **큰 별1개 + 작은 반짝임2개, 총3개**다. 큰 별은 밝고, 작은 별은 더 어두운 회색, 아주 작은 반짝임은 회백색으로 구분한다. 좌우 눈에 같은 좌표를 무조건 복사하지 않는다. 눈을 감거나 가리면 함께 가려질 수 있다.

| 눈·요소 | 눈 내부 중심(x%,y%) | 기준 이미지 관찰색 |
|---|---|---|
| 왼쪽 큰 별 | 58.8, 33.1 | #FBF9F3 |
| 왼쪽 작은 회색 반짝임 | 28.0, 70.7 | #A4A4A5 |
| 왼쪽 아주 작은 마름모 | 23.5, 23.8 | #D5D5D4 |

| 오른쪽 아주 작은 마름모 | 22.5, 53.9 | #F8F6F2 |

중심은 눈 경계 좌상단(0,0)·우하단(100,100) 기준이다. 색은 조명과 반사가 포함된 이미지 관찰값으로, 영구 색상 코드나 모든 장면에서 고정된 빛 위치가 아니다. 디자인 모티프3개와 눈 표면의 연속적인 광택을 구분한다.

## 4. 코·입·얼굴 색 영역
코는 대키미보다 큰 둥근 역삼각형 검정 형태이며 바로 아래로 곡선 입선이 이어진다. 코와 입을 둘러싼 크림빛 흰색 주둥이 #F8F0E4를 유지한다. 주둥이는 얼굴에 자연스럽게 붙은 얕은 볼륨이며 별도의 큰 흰 공처럼 돌출시키지 않는다.

기본 홍조는 없다. 감정에 따른 일시적인 연한 홍조는 허용하되 얼굴의 영구 무늬로 만들지 않는다.

## 5. 귀·안테나·꼬리
- 귀는 아래로 늘어진 강아지 귀다. 고정한 오른쪽 외지몽의 귀 크기·끝 위치·부착 구조를 유지한다. 고양이 귀로 세우거나 큰 날개처럼 펼치지 않는다.
- 귀 안쪽이 보이면 주둥이와 동일한 크림빛 흰색 #F8F0E4다. 겉면은 초록색이며 안쪽을 보여주려고 기본 자세의 귀를 뒤집지 않는다.
- 안테나2개, 각각 끝 구슬1개. 이번 잠정 고정 이미지의 크기를 유지한다. 과거3% 축소 지시를 다시 적용하지 않는다.
- 꼬리는 짧고 뭉툭한 강아지형이다. 길게 말린 고양이 꼬리로 만들지 않는다.

## 6. 몸통 곡선·팔다리·엄지

## 두 캐릭터가 함께 등장할 때의 공통 기준

- 대키미 전체 키103cm, 외지몽105cm. 같은 축척의 비슷한 자세에서 외지몽의 전체 키가 약1.94% 더 크다. 기준은 안테나 구슬 최고점부터 발바닥까지다.
- 대키미의 머리가 원래 더 넓으므로 머리 너비만 보고 전체 키를 판정하지 않는다. 크기 검증은 같은 바닥선·카메라 거리·시점·자세에서 한다.
- 앉은 장면에서는 골반 지지면과 상체 각도·다리 자세를 비슷하게 맞춘다. 외지몽을 더 뒤에 두거나 더 숙이게 만들어 작아 보이게 하지 않는다. 서로 다른 포즈의 머리 꼭대기 높이를 실제 키로 해석하지 않는다.
- 캐릭터별 얼굴·몸 비율을 유지한 채 전체 캐릭터를 하나의 단위로 배치한다. 상대 키를 맞추려고 얼굴·몸통·구슬을 각각 늘이지 않는다.
- 각 캐릭터의 원본 종, 귀 구조, 얼굴 색 영역, 안테나2개, 각 눈 하이라이트3개를 혼합하지 않는다.


## 8. 바꿀 수 있는 것과 고정할 것
고정: 종·얼굴형·머리와 몸 비율·눈 윤곽·코와 입의 고유 형태·얼굴 색 영역·귀의 종별 구조·안테나 개수와 구슬·꼬리 기본 형태·기본색·질감.

변경 가능: 상황에 맞는 시선·눈 개폐·입 표정·팔과 다리·몸 방향·종별 구조를 유지한 귀·안테나·꼬리 움직임, 의상·소품·배경. 축제별 색상은 의상·액세서리·소품에 적용하며 신체 기본색을 바꾸지 않는다.

흰색 배경·정면·팔 내림·소품 없음은 **기본형 검증 장면에만** 적용한다. 사용자가 피크닉·공연·관광 등 장면을 요청하면 포즈·배경·소품 지시는 그 요청을 따른다. 캐릭터 고정 디자인은 유지한다.

## 9. 다른 AI에 입력하는 방법
이 MD와 이 캐릭터의 고정 기준 이미지를 함께 첨부한다. 두 캐릭터가 함께 나오면 두 MD와 두 기준 이미지를 함께 제공한다. 외지몽 비교 참고 이미지의 왼쪽 대키미는 사용하지 말고, 대키미는 별도의 고정 단독 이미지를 사용한다. 원본 보드는 손·측면·후면처럼 최신 고정 이미지에서 보이지 않는 부분을 보완하는 참고다.

문서 수치만으로 모든 AI가 같은 픽셀·윤곽을 보장하지는 않는다. 기준 이미지·상대 비율을 함께 사용하고 결과를 검수한다. 원본에서 복원할 수 없는3D 깊이·재질계수를 공식값으로 임의 지정하지 않는다.

### 복사해서 사용할 고정 지시문

첨부한 외지몽 v03 스펙과 고정 기준 이미지를 사용해 같은 캐릭터를 재현한다. 새 마스코트로 재디자인하지 않는다. 비교 이미지의 오른쪽 초록색 외지몽만 현재 잠정 고정형으로 사용한다. 그 얼굴·몸통·귀·구슬의 현재 비율을 유지하고 추가 확대·축소를 하지 않는다. 주둥이와 보이는 귀 안쪽은 같은 크림빛 흰색이다. 전체 키는105cm이며 안테나 구슬 최고점부터 발바닥까지다. 눈은 안쪽 아래가 좁아지는 원본 윤곽을 유지한다. 각 눈에 큰 별1개·작은 회색 반짝임1개·아주 작은 회백색 반짝임1개로 총3개를 유지한다. 안테나는2개다. 기본 홍조는 없다. 손은 둥근 손바닥과 자세에 따라 보이는 엄지로 표현하고 추가 손가락을 만들지 않는다. 몸의 부드러운 낮은 광택과 눈의 검정 광택을 구분한다. 요청한 포즈·표정·소품·배경만 바꾸고 기본 디자인은 유지한다. 두 캐릭터가 함께 나오면 같은 축척·비슷한 자세에서 대키미103cm·외지몽105cm 관계를 유지한다. 장면: [원하는 포즈·상황·배경·의상·소품을 입력].
