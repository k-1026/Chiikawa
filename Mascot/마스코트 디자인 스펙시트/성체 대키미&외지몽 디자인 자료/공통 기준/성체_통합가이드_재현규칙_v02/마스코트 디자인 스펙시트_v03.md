## 01. 문서 개요와 적용 기준

버전: **3.0 — 원본 재현 보정안** · 작성일: **2026-11-03**

대구 사투리 축제 기획 AI 에이전트, 일러스트, 홍보물, 굿즈 제작에 사용하는 대키미·외지몽 통합 디자인 가이드다. v2의 키·얼굴 확정 규칙·색상 코드를 유지하면서, 정면 생성 테스트에서 확인된 체형·귀·구슬·질감·색감의 이탈을 막도록 수정한 원본 재현 보정안이다. 새로 만든 캐릭터가 아니라 원본 보드의 동일 캐릭터를 재현하는 데 사용한다.

| 핵심 항목 | 대키미 | 외지몽 |
|---|---|---|
| 종족 | 고양이형 외계인 | 강아지형 외계인 |
| 출신 | 대구 | 우주 |
| 전체 키 | 103cm | 105cm |
| 키의 측정 구간 | 안테나 구슬 최고점~발바닥 | 안테나 구슬 최고점~발바닥 |
| 1u의 실제 길이 | 1.03cm | 1.05cm |
| 안테나 구슬 지름 | 11.845cm (표시 11.8cm) | 13.65cm (표시 13.7cm) |
| 대표색 | #6DCFF5 | #008C3A |

### 이번 수정에서 최우선으로 적용할 원본 재현 규칙

사용자가 최근에 지적한 문제는 대키미의 외형 이탈, 다른 텍스처, 과한 채도, 뭉툭한 대키미 귀, 두 캐릭터의 부푼 몸통, 외지몽의 큰 구슬과 귀다. 이 수정은 해당 생성 오류를 원본 보드 수준으로 되돌리기 위한 것이다.

- 기준 이미지: 두 원본 보드의 TURNAROUND 정면을 기본 실루엣·비율·얼굴 배치 기준으로 삼는다. 상단 대표 이미지는 표면 질감·조명·색감 확인에 보조적으로 사용한다. 서로 다른 뷰의 치수를 섞어 새 형태를 만들지 않는다.
- 우선순위: 사용자 직접 확정 규칙 → 해당 시점의 원본 보드 → 원본 근사 판독값 → 이전 제작 지정값. 원본과 지정값이 충돌하면 지정값으로 원본 외형을 바꾸지 않는다.
- 생성된 front_comparison_v02.png와 front_comparison_v03.png는 검토용 결과물이며 공식 원본으로 채택하지 않는다. 두 번째 생성본도 사용자 승인된 기준 이미지가 아니다.
- 이전 보정 프롬프트의 몸통 15~18% 축소, 귀 18% 축소, 구슬 20% 축소 등은 해당 오출력에 적용한 일회성 지시다. 이를 원본 캐릭터의 공식 비율로 등록하지 않는다.
- 키 103cm·105cm, 안테나 각각 2개, 완전히 뜬 각 눈의 하이라이트 3개, 기본 홍조 없음, 대키미의 하늘색 입 주변, 외지몽의 동일한 크림색 주둥이·귀 안쪽 규칙은 유지한다.
- 이 버전은 실물 크기를 바꾸는 리디자인이 아니다. 구슬·귀·체형은 원본보다 부풀리지 않는 재현 규칙으로 보정한다.

### 우선 적용하는 사용자 확정 사항

- 눈을 완전히 뜬 기본 표정에서 한쪽 눈당 하이라이트 총 3개. 큰 별 1개와 작은 반짝임 2개이며 별 모양 사용은 확정이다.
- 기본 얼굴에 홍조는 없다. 감정 표현에 따라 홍조를 허용한다.
- 대키미 얼굴은 코·입 주변까지 하늘색으로 유지하며 흰색 주둥이 영역을 만들지 않는다.
- 외지몽의 입 주변과 감정·귀 움직임으로 드러나는 귀 안쪽은 같은 크림빛 흰색이다.
- 두 캐릭터의 코와 입은 각각의 원본 형태를 유지한다.
- 대키미 전체 키 103cm, 외지몽 전체 키 105cm를 적용하며, 기존 부위별 상대 비율은 유지한다.

### 정보의 근거

| 구분 | 의미 |
|---|---|
| 사용자 확정 | 이번 대화에서 직접 확정한 외형·표현·키 규칙 |
| 보드 명시값 | 설정 보드에 적힌 대표색 등의 값 |
| 원본 근사 판독값 | 원본 PNG의 부위 경계·픽셀·색상 견본을 읽은 값 |
| 제작 지정값 | 깊이·가림 부위·세부 도형·허용 오차 등 반복 제작을 위해 지정한 작업 규격 |

제작 지정값은 사용자에게 개별 승인받은 원본 치수가 아니며, 원본 이미지와 대조해 검증하기 전까지 참고값이다. 생성용 프롬프트에서 원본보다 우선하는 고정 명령으로 사용하지 않는다. 제작 지정값을 원본 3D 모델의 실측값으로 해석하지 않는다. 전체 키를 제외한 부위 치수는 원본 근사 판독 또는 기존 작업 기준의 환산 결과다. 제조용 금형이나 물리 구조를 검증한 도면은 아니다.

### 캐릭터 관계와 메시지

대키미는 자신만만하지만 허당스럽고 친구를 진심으로 챙기는 대구 토박이다. 외지몽은 호기심이 많고 솔직하며 실수 후에도 다시 도전하는 여행자다. 둘은 표현을 오해하면서 티격태격하지만 서로 배우고 영향을 주는 친구다.

기본 보드 문구는 **“말이 달라도, 친구가 된다.”**다. 이전 기록의 “표현이 달라도, 친구가 된다.”는 같은 관계의 의미를 설명하는 문구로 남긴다.

## 02. 실제 키·지름·cm 치수표

### 전체 키
사용자 지정 전체 키: **대키미 103cm, 외지몽 105cm**. 두 캐릭터 모두 안테나 구슬의 가장 높은 지점부터 발바닥까지를 측정한다. 안테나를 제외한 머리 꼭대기까지의 키가 아니다.

기존 정규화 비율 100u를 유지하고 대키미 1u=1.03cm, 외지몽 1u=1.05cm로 환산한다. 외지몽은 대키미보다 2cm, 약 1.94% 크다.

아래 실치수는 기존 근사 판독값 또는 제작 지정값의 비례 환산 결과다. 키를 제외한 부위 치수는 원본 재현이 검증된 최종값이 아니다. 이번 수정에서 근거 없는 축소 수치를 새로 만들지 않고 기존 수치를 비교 참고값으로 보존한다. 원본 관찰값의 불확실성은 그대로 존재한다. 표시는 소수 첫째 자리까지이며, 계산 원장은 성체_실제키_환산치수.json에 저장했다.

### 둥근 부위의 지름 확인
구슬은 둥근 구형을 유지한다. 아래 지름은 v1에서 지정한 대키미 11.5u, 외지몽 13.0u의 환산 참고값이다. 원본과의 시각 비교 없이 생성 결과의 구슬을 이 값에 맞았다고 승인하지 않는다. 각 캐릭터의 좌우 구슬 지름은 동일하다.

| 항목 | 대키미 | 외지몽 |
|---|---|---|
| 안테나 구슬 지름 | 11.8cm | 13.7cm |
| 꼬리 기본 단면 지름 | 10.3cm | 11.6cm |

구슬 지름 계산: 대키미 11.5×1.03=11.845cm, 외지몽 13.0×1.05=13.65cm. 외지몽 구슬은 약 1.8cm, 15.2% 더 크다. 전체 키에 대한 구슬 비율은 각각 11.5%, 13.0%로 유지했다. 새 키 때문에 구슬 비율을 추가로 키우지 않았다. 외지몽의 구슬이 원본보다 두드러지게 커지면 재현 실패로 판정한다. 결과 이미지에서 구슬 지름/전체 키, 구슬 지름/머리 너비를 각각 확인한다. 구슬이 크다는 피드백만으로 키나 머리 전체를 키워 비율을 맞추지 않는다.

머리와 몸통은 타원형이므로 단일 “지름” 대신 정면 너비·높이와 앞뒤 깊이를 구분한다. 안테나 줄기의 아래 너비는 기울어진 줄기의 투영 경계 너비이며 원통 단면의 실제 지름으로 해석하지 않는다. 꼬리 지름은 기본 몸통 부분의 단면이며 둥근 끝으로 갈수록 마감된다.

### 정면 부위 실치수
가로 × 세로, 단위 cm. 귀·구슬·팔·다리·발은 한쪽 기준. 부위는 서로 겹치므로 세로 치수를 합산하여 전체 키를 계산하지 않는다.

| 머리 본체 | 69.8 × 51.0 | 60.0 × 52.0 |

| 귀 1개 | 22.1 × 22.6 | 22.0 × 39.0 |

### 얼굴·표정·허용 오차 환산
얼굴 도형과 표정 가이드에서 u로 정의된 모든 길이는 대키미 ×1.03, 외지몽 ×1.05로 cm 환산한다. 각도, 불투명도, 면적 비율, 눈 개폐율 등 무차원 비율은 그대로 사용한다. 안테나 구슬 2개·눈 하이라이트 각 3개 규칙도 그대로 적용한다.

| 작업 오차 범위 | 대키미 | 외지몽 |
|---|---|---|
| 머리·몸통 외곽 ±2u | ±2.06cm | ±2.10cm |
| 얼굴 중심·눈·코·입 크기 ±1u | ±1.03cm | ±1.05cm |
| 귀·안테나 크기 ±1.5u | ±1.545cm | ±1.575cm |

103cm·105cm는 이번에 지정한 정확한 전체 키 기준이다. 위 작업 오차는 개별 부위 조정용이며 전체 키를 임의로 바꾸는 허용 범위가 아니다. 굿즈를 축소 제작할 때는 전체 키와 각 부위를 같은 배율로 줄인다.

## 03. 공통 디자인 규칙

### 형태
- 둥근 큰 머리와 작은 몸통의 치비형. 약 2등신에 가까운 인상이지만 수치 2.0을 측정값으로 사용하지 않는다.
- 목은 별도로 드러나지 않는다. 몸통은 머리보다 충분히 작은 짧은 타원형이다. 원본에서 보이는 최소한의 둥근 볼륨을 유지하며 배·허리·가슴이 부풀어 오르는 체형으로 만들지 않는다. 배의 앞쪽 돌출은 원본 측면에서 확인되는 범위까지만 허용한다.
- 팔과 다리는 짧고 끝이 부드럽게 둥글다. 원본보다 두껍게 부풀리지 않는다. 어깨 관절을 별도 구체로 분리하지 않으며 몸통과 팔이 하나의 큰 덩어리처럼 보이지 않게 한다.
- 손은 둥근 덩어리형이다. 기본적으로 개별 손가락이 없으며 동작에 필요한 경우 엄지 정도를 구분할 수 있다.
- 다리와 작고 둥근 발은 형태가 구분되어야 한다.
- 머리 위 안테나는 정확히 2개. 각 줄기 끝에 둥근 구슬 1개가 달린다. 줄기는 가깝게 배치하되 서로 맞닿지 않는다.
- 꼬리는 몸통 뒤쪽 하단에 연결된다. 캐릭터별 길이와 굴곡을 유지한다.

### 얼굴
- 큰 검정 눈을 사용한다. 기본 정면은 좌우 대칭을 기준으로 하며 간격과 외곽 윤곽은 원본을 따른다.
- 완전히 뜬 각 눈에는 하이라이트 총 3개: 큰 별 1개와 작은 반짝임 2개. 별 모양 사용은 확정되었다. 작은 반짝임은 작은 네 갈래 1개와 둥근 마름모 1개로 제작 기준을 통일한다. 도형별 크기와 좌표는 「얼굴·하이라이트 세부 기준」를 따른다.
- 감거나 찡그린 눈은 눈꺼풀에 의해 하이라이트가 가려질 수 있다. 닫힌 눈 위에 하이라이트 3개를 따로 붙이지 않는다.
- 기본 얼굴에는 홍조가 없다. 감정 표현에 따라 일시적으로 허용한다.
- 코 바로 아래에 입선이 이어진다. 코와 입 사이에 분리된 빈 간격을 만들지 않는다.
- 코와 입의 기본 형태는 캐릭터마다 다르다. 같은 얼굴로 통일하지 않는다.

### 표현과 재질
원본 보드의 부드러운 입체 표현과 은은한 표면 변화를 그대로 재현한다. 피부·몸통·귀·안테나·꼬리는 빛이 넓고 부드럽게 퍼지는 낮은 광택을 기준으로 하며, 눈의 광택과 분리한다. 딱딱한 플라스틱, 번들거리는 고무·비닐, 매끈하게 도금한 피규어처럼 강한 반사와 날카로운 하이라이트를 만들지 않는다.

원본에서 보이지 않는 거친 점토 결, 솜털, 직물, 털 뭉치, 입자 노이즈를 추가하지 않는다. '점토', '봉제', '비닐 토이' 등의 재료명을 임의로 지정해 다른 제품 스타일로 바꾸지 않는다. 원본 보드의 표면 관찰이 우선이다. 눈은 원본처럼 윤기가 있는 검정 표면을 유지한다.

조명은 원본처럼 밝고 부드러운 중립 확산광을 사용한다. 얼굴 앞면이 검게 가라앉거나 윤곽이 강한 대비로 갈라지지 않도록 한다. 반사광과 음영은 영구 무늬가 아니다. 털 결, 수염, 옷, 가방은 기본형에 임의로 추가하지 않는다.

### 관리 원칙
이번 대화의 확정 내용 > 첨부 보드의 기본형 > 이전 기록 순으로 충돌을 해석한다. 해결되지 않은 충돌은 임의로 확정하지 않는다. 색상은 「색상 팔레트와 추출 근거」를 참조한다.

### 제작 기준의 적용
치수·가려진 연결부·깊이는 「정규화 비율·배치 기준」의 지정값을 참고하되 원본과 외형을 대조한다. 해당 값이 원본보다 비만한 몸통이나 부푼 볼을 만들면 고정값으로 강제하지 않는다. 새로운 디자인 장식 없이 기존 실루엣을 수치화하기 위한 기준이다. 문서의 “제작 지정값”은 원본에서 실측된 값이나 사용자가 개별적으로 승인한 값과 구별한다.

### 기준과 근거
안테나 구슬의 최고점부터 발바닥까지를 H=100으로 통일한다. 아래 수치는 턴어라운드 정면의 원본 픽셀을 수동으로 읽어 환산한 근사값이며, 원본 모델의 설계 치수를 복원한 값은 아니다. 귀와 안테나를 제외한 둥근 머리 본체를 머리 높이로 삼는다.

대키미는 y=638~852, H=214 px, 중심축 x=130을 사용했다. 외지몽은 y=705~915, H=210 px, 중심축 x=120을 사용했다. 원본 좌표 원점은 이미지 좌상단이다. 측정 경계는 보통 ±3 px, 가림·접합부는 ±6 px 정도의 판독 불확실성이 있다. 원본이 미세하게 비대칭인 경우 양쪽 평균을 사용하여 중립 정면을 대칭화한다.

### 측면·입체와 가림 부위의 제작 지정값
아래는 정밀 직교도·3D 원본 없이 이전 버전에서 지정한 참고값이다. 이 표가 부드러운 배 볼륨을 과장하거나 원본 실루엣을 바꿔도 된다는 허용 규칙은 아니다. 검증 전에는 측정 확정값이나 사용자 개별 승인값으로 표시하지 않는다.

### 기본 자세·허용 오차
양발을 바닥에 붙인 정면 중립 자세를 기본으로 한다. 양팔은 몸 옆에 자연스럽게 늘어뜨리며 몸통과 붙어 읽히지 않도록 얕은 틈을 둔다. 머리 중심과 몸통 중심은 같은 축이다.

정규화 제작 목표: 머리·몸통 외곽은 표의 값에서 ±2u, 얼굴 중심 위치는 ±1u, 눈·코·입 크기는 ±1u, 귀·안테나 크기는 ±1.5u 이내를 작업 허용 범위로 둔다. 이는 원본 판독 정확도가 아니라 향후 제작물에 적용할 지정 허용 오차다. 동작에 따른 원근 단축은 정면 도면의 비율 오차로 판정하지 않는다.

### 원본 좌표 원장
각 부위의 원본 경계 사각형과 근거 구분은 신체형태_비율측정_원장.json에 기록했다. 검정 픽셀 연결영역 분석은 눈과 코 경계 판독에 보조적으로 사용했다. 모호한 접합부까지 자동 검출한 것으로 해석하지 않는다.

## 07. 얼굴·하이라이트 세부 기준

전체 높이를 100u로 두며, 1u는 전체 높이의 1%다.

이 문서는 관찰된 얼굴을 반복 제작할 수 있도록 지정한 도형·배치 기준이다. 원본 벡터 경로를 복원한 데이터가 아니다. 전체 위치와 크기는 「정규화 비율·배치 기준」를 따른다.

### 코와 입
- 대키미: 코 너비 3.7u, 높이 2.3u. 가로로 납작하고 모서리가 둥근 검정 형태. 코 아래 중앙에서 두 갈래의 짧은 고양이형 곡선 입선이 이어진다. 기본 열린 입의 너비 6.5u, 높이 6.1u. 입 주변 패치 없음.
- 외지몽: 코 너비 5.7u, 높이 4.3u. 둥근 역삼각형에 가까운 검정 형태. 코 아래 중앙에서 둥근 주둥이를 따라 두 갈래 곡선 입선이 이어진다. 기본 열린 입의 너비 9.5u, 높이 8.6u.
- 외지몽 주둥이: 너비 21.4u, 높이 19.0u, 중심 (x=0, y=54.8u)의 부드러운 타원형을 작업 기준으로 사용한다. 원본의 미세한 비대칭을 영구 특징으로 만들지 않는다. 입 주변과 귀 안쪽 모두 #F8F0E4.
- 코와 입선은 연결되며 분리 간격 0. 닫힌 입에서는 열린 입 내부와 혀가 보이지 않는다. 혀는 열린 입 하단에 너비 입 너비의 55%, 높이 입 높이의 35%로 지정한다. 입선 두께는 0.7u, 끝은 둥글게 처리한다. 이 선 두께와 혀 비율은 제작 지정값이다.

### 눈과 하이라이트
기본 정면의 검정 눈 형태와 좌우 간격은 원본 판독값을 사용한다. 대칭 제작을 위한 눈 하나의 평균 크기는 대키미 20.8 × 20.8u, 외지몽 19.3 × 20.2u로 지정한다. 표정에 따라 눈꺼풀이 가리거나 눈이 감기는 것은 허용한다.

각 눈의 하이라이트는 큰 별 1개 + 작은 반짝임 2개로 고정한다. 큰 별은 보드처럼 끝이 둥글고 팔이 네 방향으로 뻗은 형태를 사용한다. 작은 반짝임 2개의 형태는 작은 네 갈래 반짝임 1개와 작은 둥근 마름모 1개로 제작 기준을 통일한다. 모두 같은 크기의 별 3개로 만들지 않는다.

눈 하나의 경계 사각형 좌상단=(0,0), 우하단=(100,100) 기준: 큰 별 중심 (57,30), 크기 31×34; 작은 네 갈래 중심 (29,73), 크기 14×16; 작은 마름모 중심 (23,18), 크기 7×8. 이 배치·도형 수치는 반복 제작을 위한 지정값이며 원본 모든 장면의 하이라이트 좌표와 일치한다는 의미가 아니다. 두 눈 모두 화면 기준 같은 배치를 사용한다. 눈을 가리는 눈꺼풀이 있으면 하이라이트도 함께 가린다.

### 홍조
기본은 없음. 감정에 따라 눈 아래 바깥쪽에 연한 홍조를 허용한다. 타원 크기 너비 5u × 높이 2.5u, 중심은 해당 눈 중심에서 얼굴 바깥쪽으로 4u, 아래로 10u 이동한 위치를 기준으로 한다. 색상 #FDB6C1, 불투명도 15%, 강한 감정 최대 25%. 윤곽선 없이 경계를 부드럽게 처리한다. 이 위치·크기는 제작 지정값이다.

## 08. 색상 팔레트와 추출 근거

### 작업 기준값
보드에 HEX가 명시된 대표색은 해당 표기값을 우선한다. 보조색은 원본 PNG의 색상 견본에서 추출한 값을 사용한다. 추출값은 이미지에서 얻은 작업 기준이며 원본 제작 파일의 재질값이나 인쇄 표준색을 확인한 것은 아니다.

| 캐릭터 | 적용 부위 | HEX | RGB | 근거 |
|---|---|---|---|---|
| 대키미 | 대표색 | `#6DCFF5` | 109, 207, 245 | 보드 명시값 |
| 대키미 | 귀 안쪽 분홍색 | `#FDB6C1` | 253, 182, 193 | 색상 견본 추출값 |

| 외지몽 | 대표색 | `#008C3A` | 0, 140, 58 | 보드 명시값 |
| 외지몽 | 입 주변·귀 안쪽 크림빛 흰색 | `#F8F0E4` | 248, 240, 228 | 색상 견본 추출값 |

코·입선·입 안쪽·혀의 작업 기준은 아래 추가 팔레트를 적용한다. 대표색 및 보조색의 기존 값은 유지한다.

### 화면에서의 색감·밝기 기준

대표색 #6DCFF5·#008C3A와 보조색 HEX는 유지한다. HEX와 렌더링된 화면의 외관은 구분한다. 원본 보드와 같은 밝고 부드러운 중간톤, 은은한 음영, 낮은 국부 대비를 재현한다.

- 하늘색을 과포화된 시안·형광 파랑으로 만들지 않는다. 초록색을 원본보다 진하고 쨍한 장난감 초록으로 만들지 않는다.
- 원본의 밝은 앞면을 유지하며 어두운 그림자로 몸의 외곽과 배를 과장하지 않는다.
- 단순히 채도를 일괄 낮추어 회색빛으로 바꾸거나 원본보다 옅은 파스텔색으로 바꾸지 않는다. 원본과 나란히 비교해 색감·중간톤을 맞춘다.
- 매체 변환을 제외하고 임의의 새 HEX로 캐릭터 색을 대체하지 않는다. 거칠기·조명·노출·채도 보정 수치는 실제 렌더러가 정해진 뒤 기록하며, 현재 확인되지 않은 수치를 원본값으로 만들지 않는다.

### 추출 방식
이미지 크기는 두 보드 모두 793 × 1983 px이다. 좌상단을 (0, 0)으로 하여 아래 좌표 중심의 9 × 9 px를 채널별 중앙값으로 집계했다. 배경·글자·색상 원의 경계를 피하도록 견본 내부를 선택했다. 실제 추출값과 원본 SHA-256은 원본_색상견본_관측값.json에 기록했다. 재현 명령은 프로젝트 루트에서 `python3 tools/extract_palette.py`이다.

| 캐릭터 | 견본 | 중심 좌표 (x, y) |
|---|---|---|
| 대키미 | 하늘색 | (523, 489) |
| 대키미 | 분홍색 | (608, 485) |
| 대키미 | 검정 | (672, 485) |
| 대키미 | 흰색 | (736, 485) |
| 외지몽 | 초록색 | (623, 504) |
| 외지몽 | 크림빛 흰색 | (533, 578) |

| 외지몽 | 흰색 | (717, 577) |

### 대표색 표기와 픽셀의 차이
대키미 하늘색 견본 추출값은 #73CDF7, 보드 표기는 #6DCFF5이다. 외지몽 초록색 견본 추출값은 #028437, 보드 표기는 #008C3A이다. 이처럼 보드 표기와 렌더링 픽셀은 일치하지 않으므로 대표색을 추출값으로 대체하지 않았다. 차이가 생긴 원인은 자료만으로 확정하지 않는다.

### 적용 규칙
- 외지몽의 입 주변과 보이는 귀 안쪽은 동일한 크림빛 흰색 #F8F0E4를 적용한다. 순백색으로 바꾸지 않는다.
- 대키미 얼굴에는 흰색 주둥이 영역을 만들지 않는다.
- 하이라이트 흰색의 추출값은 #FEFEFE이다. 흰색 견본을 근거 없이 #FFFFFF로 치환하지 않았다.
- 두 보드의 검정 견본은 소폭 다르다. 임의로 하나의 검정값으로 통일하지 않았다.
- 기본색은 조명·음영을 적용하기 전의 목표색이다. 입체 이미지의 밝고 어두운 픽셀까지 모두 이 HEX로 채우지 않는다.
- 혀·입 안쪽·홍조는 아래 추가 기준을 적용한다. CMYK·별색은 출력 장비와 종이에 따른 변환 항목이며 캐릭터 기본색의 정의는 sRGB HEX/RGB로 통일한다. 임의의 인쇄 프로파일을 지정하지 않는다.

### 추가 팔레트: 코·입·감정 색상
아래 코·입 안쪽·혀는 각 보드 상단의 큰 캐릭터 이미지에서 3 × 3 px 중앙값을 읽은 것이다. 독립 색상 견본이 아닌 렌더링 표면의 관찰값이며, 이번 버전의 작업 기준으로 채택한다. 광택을 포함한 원본 재질의 정확한 기본색으로 단정하지 않는다. 좌표와 RGB는 얼굴세부_관측색상.json에 기록했다.

| 부위 | 대키미 | 외지몽 | 적용 |
|---|---|---|---|
| 코·입선 | #060A06 | #111213 | 코 표면 관찰색을 코·입선 작업 기준으로 지정 |
| 입 안쪽 | #2D0405 | #480101 | 벌어진 입 내부 |

홍조는 일반 감정에서 불투명도 15%, 강한 감정에서 최대 25%, 기본 상태에서 0%로 지정한다. 별도의 영구 볼 무늬를 만들지 않는다. 이 수치와 홍조색의 채택은 이번 버전의 제작 선택이며 원본 보드의 홍조를 정량 복원한 값은 아니다. sRGB IEC 61966-2-1을 작업 색 공간으로 지정하고, 인쇄는 출력 업체의 ICC 프로파일로 변환한다.

## 09. 표정·동작 가이드

### 공통 불변 요소
표정이 달라져도 기본 머리·몸통 실루엣, 기본색, 종족별 귀 구조, 안테나 2개와 구슬, 꼬리의 고유 구조, 캐릭터별 코와 입 주변 영역을 유지한다.

### 변경 가능한 요소
눈의 개폐와 시선, 입의 벌어짐과 곡선, 몸 방향과 자세, 팔·다리 제스처, 귀의 기울기, 안테나 기울기, 꼬리 움직임. 기쁨 등 감정에 따른 홍조는 허용하되 기본 얼굴에는 넣지 않는다.

| 캐릭터 | 보드의 표정·행동 예시 | 유지할 특징 |
|---|---|---|
| 대키미 | 자신만만·답답함·머쓱함·인정·위로·토론 | 삼각형 귀, 하늘색 입 주변, 작은 납작한 코 |
| 외지몽 | 궁금함·확인·기쁨·시무룩함·재도전·추억 기록 | 처진 귀, 크림색 주둥이, 둥근 역삼각형 코 |

### 눈 하이라이트
눈을 완전히 떴을 때 한쪽 눈당 큰 별 1개와 작은 반짝임 2개, 총 3개다. 반쯤 감긴 눈에서는 눈꺼풀에 가려지는 것을 허용한다. 완전히 감긴 눈에는 억지로 하이라이트를 그리지 않는다.

### 귀와 홍조
대키미의 귀는 감정에 따라 기울어도 삼각형 구조를 유지한다. 외지몽은 귀가 움직이며 안쪽이 보일 때만 입 주변과 같은 크림빛 흰색을 드러낼 수 있다. 홍조는 #FDB6C1, 불투명도 기본 0%·감정 15%·강한 감정 최대 25%이며 영구 무늬로 취급하지 않는다.

### 소품
보드의 마이크, 수첩 등은 장면용 소품이다. 소품은 캐릭터의 신체 구조를 바꾸지 않으며 기본형에 항상 부착하지 않는다.

### 표정별 제작 지정값
기본 뜬 눈 높이를 100%로 두고, 아래 수치는 기본 자세에 대한 변형 범위다. 종족별 귀 구조와 안테나 개수는 유지한다.

| 캐릭터·표정 | 눈·입 | 몸·귀·꼬리 | 홍조 |
|---|---|---|---|
| 공통 기본 | 눈 100%, 기본 웃는 입 | 머리 기울기 0°, 중립 자세 | 0% |
| 대키미 자신만만 | 눈 100%, 열린 웃는 입 | 머리 5° 기울임, 한 손 들어 설명 | 선택 15% |
| 대키미 답답함 | 한쪽 눈 높이 55%, 말하는 입 | 머리 8° 기울임, 한 팔 앞으로 | 0% |
| 대키미 머쓱함 | 눈 높이 70%, 작게 다문 입 | 고개 앞쪽 12° 숙임, 귀 바깥쪽 10° 기울임 | 15% |
| 대키미 인정 | 웃으며 눈 완전히 감음 | 두 손 모음 또는 앉기 | 선택 15% |
| 대키미 위로 | 눈 높이 90%, 부드러운 작은 미소 | 상대 쪽으로 고개 8°, 손 내밀기 | 0% |

## 10. AI 이미지 생성 프롬프트

### 입력 패키지

매회 원본 설정 보드와 아래 고정 프롬프트를 함께 입력한다. 기본형 단독 재현부터 확인하고, 승인 후 다른 표정·시점으로 확장한다. 텍스트만으로 원본과 픽셀 단위로 같은 결과나 모든 세부 수치를 보장할 수는 없다. 승인된 단독 기준 이미지가 생기면 원본 보드와 함께 동일한 파일을 재사용한다.

1. 단독 생성: 해당 캐릭터의 원본 보드 1장 + 공통 고정 문장 + 해당 캐릭터 문장 + 기본 장면 문장.
2. 두 캐릭터 비교: 원본 보드 2장 + 공통 고정 문장 + 캐릭터별 문장 + 비교 장면 문장.
3. 바꾸는 것은 장면 설명뿐이며, 원본·정체성 문장·색상·재질 문장은 고정한다.

### 공통 고정 문장

첨부 이미지는 새 캐릭터를 만드는 영감 자료가 아니라 반드시 그대로 재현할 공식 캐릭터 원본이다. 해당 캐릭터 보드의 TURNAROUND 정면을 얼굴 윤곽·눈 배치·귀·몸통·팔다리·꼬리의 기준으로 사용하고, 상단 대표 이미지에서 표면 질감과 부드러운 색감을 참고한다. 캐릭터를 일반적인 귀여운 고양이·강아지나 다른 피규어 스타일로 다시 디자인하지 않는다.

원본과 같은 큰 머리와 작은 짧은 타원형 몸통, 짧은 팔다리, 드러나지 않는 목을 유지한다. 배·볼·가슴·어깨·팔다리를 원본보다 부풀리지 않는다. 몸 표면은 원본에서 보이는 부드러운 낮은 광택과 은은한 표면 변화를 유지하고, 눈만 원본처럼 윤기가 있는 검정으로 표현한다. 반짝이는 고무·비닐·딱딱한 플라스틱 피부, 임의의 거친 점토 결이나 솜털을 추가하지 않는다. 원본의 밝고 부드러운 색감과 확산광을 유지하고 채도·대비를 높이지 않는다.

눈을 완전히 뜬 경우 한쪽 눈당 큰 별 1개와 작은 반짝임 2개, 총 3개다. 안테나는 정확히 2개이며 끝은 구형이다. 기본 홍조는 없다. 코 바로 아래에 입선이 이어진다. 의상·액세서리·소품·배경 장식·글자 없이 흰색 배경에서 기본형을 보여준다.

### 대키미 고정 문장

대키미만 정면 전신으로 재현한다. 하늘색 고양이형 외계인으로 대표색 #6DCFF5를 유지한다. 원본처럼 머리는 둥글고 좌우로 넓지만 볼을 부풀리지 않는다. 귀는 끝으로 좁아지는 뾰족한 삼각형이고 안쪽은 분홍색 #FDB6C1이다. 귀 끝을 뭉툭한 둥근 덩어리로 만들거나 바깥 테두리를 두껍게 부풀리지 않는다. 코와 입 주변까지 하늘색이며 흰색·크림색 주둥이는 없다. 작은 납작한 검정 코와 바로 아래로 이어지는 원본의 작은 고양이형 입을 유지한다. 길고 둥글게 말린 고양이 꼬리와 원본 크기의 작은 안테나 구슬 2개를 유지한다. 전체 키는 구슬 최고점부터 발바닥까지 103cm다.

### 외지몽 고정 문장

외지몽만 정면 전신으로 재현한다. 초록색 강아지형 외계인으로 대표색 #008C3A를 유지하되 원본 렌더링의 부드러운 초록색 외관을 맞춘다. 귀는 원본처럼 아래로 늘어진 강아지 귀이며, 부착 위치·폭·끝 위치를 그대로 따른다. 귀를 얼굴 양옆의 거대한 날개나 두꺼운 긴 덩어리로 확대하지 않는다. 코와 입을 둘러싼 둥근 주둥이는 크림빛 흰색 #F8F0E4이며, 귀 안쪽이 보이면 같은 색을 사용한다. 대키미보다 큰 둥근 역삼각형 검정 코와 원본의 입 형태를 유지한다. 꼬리는 짧고 뭉툭한 강아지형이다. 안테나 구슬은 원본과 같은 작고 분리된 구형이며, 대키미 구슬보다 아주 약간 큰 관계를 유지하되 과장하지 않는다. 전체 키는 구슬 최고점부터 발바닥까지 105cm다.

### 기본 장면 문장

같은 바닥선에 양발을 붙이고, 머리를 기울이지 않은 정면 전신. 양팔은 몸 옆에 자연스럽게 내려놓는다. 정면 직교에 가까운 시점, 원근 왜곡 없음, 흰색 배경, 원본 보드와 같은 밝고 부드러운 중립 조명. 원본의 캐릭터 얼굴·실루엣·재질·색감을 유지한다.

### 두 캐릭터 비교 장면 문장

두 캐릭터를 같은 바닥선, 같은 축척, 같은 카메라 거리의 정면 전신으로 배치한다. 대키미 103cm, 외지몽 105cm이며 구슬 최고점부터 발바닥까지 측정한다. 외지몽은 총높이 기준으로 약 1.94%만 더 크다. 키 차이를 만들기 위해 외지몽의 몸통·귀·구슬을 각각 부풀리지 않는다. 각 캐릭터의 원본 비율을 유지한 전체 크기로 비교한다. 나머지는 기본 장면 문장을 따른다.

### 수치 입력 정책

키·개수·확정 색상 규칙을 유지한다. 부위별 cm·깊이·좌표 표는 비교 참고 자료이며, 전부를 생성 프롬프트에 나열하여 원본보다 우선하는 새 캐릭터 설계로 만들지 않는다. 구슬·귀·몸통이 원본보다 커지면 재현 실패로 보고 해당 요소만 원본에 맞춰 보정한다. 일회성 축소 퍼센트를 다음 생성의 영구 디자인으로 누적하지 않는다.

## 11. 금지 사항과 결과 확인

### 공통
안테나가 1개 또는 3개 이상, 구슬 누락, 구슬이 뾰족한 형태, 길고 가는 팔다리, 드러난 긴 목, 지나치게 작은 머리, 평평하고 가느다란 몸통, 분리된 구형 어깨 관절, 기본 자세의 개별 손가락, 발 구분 없는 다리, 검정이 아닌 기본 눈, 완전히 뜬 눈의 하이라이트 총 개수가 3개가 아닌 상태, 코와 입의 분리, 캐릭터 간 코·귀·꼬리 혼동, 기본 얼굴의 상시 홍조, 원본에 없는 영구 무늬·털 결·수염 추가를 피한다.

### 대키미
흰색 또는 크림색 주둥이 패치, 아래로 늘어진 강아지 귀, 분홍색 귀 안쪽 누락, 초록색 몸, 짧은 강아지 꼬리, 외지몽과 같은 크고 둥근 코로 변경하지 않는다.

### 외지몽
솟은 삼각형 고양이 귀, 크림색 주둥이 누락, 주둥이를 순백색으로 변경, 귀 안쪽을 분홍색이나 주둥이와 다른 색으로 변경, 귀 겉면 전체를 크림색으로 변경, 하늘색 몸, 길고 가는 고양이 꼬리, 점처럼 짧은 꼬리, 대키미와 같은 작은 납작한 코로 변경하지 않는다.

- 두툼하고 끝이 둥글게 뭉친 대키미 귀, 튜브처럼 두꺼운 귀 테두리.

## 15. 원본 재현 기준·검증 절차·변경 이력

### 현재 상태

이 문서는 v3 수정안이다. 아직 사용자가 승인한 정면 기준 생성 이미지는 없다. 생성 이미지를 보고 원본 디자인이 바뀐 것으로 취급하지 않으며, 새 결과가 나와도 사용자 승인 전에는 기준 이미지로 등록하지 않는다.

### 먼저 맞출 순서

1. 대키미 단독 정면: 원본의 얼굴 윤곽·귀 끝·작은 몸통·질감·색감을 우선 확인한다.
2. 외지몽 단독 정면: 원본의 귀 크기·구슬 크기·작은 몸통·주둥이·질감·색감을 확인한다.
3. 두 단독 기본형이 승인되면 같은 바닥선과 축척의 비교 이미지를 만든다.
4. 그다음 측면·후면, 기쁨·시무룩함 등 다른 표정으로 확장한다. 동시에 여러 부위를 바꾸어 승인 원인을 알 수 없게 하지 않는다.

### 비교 방식

- 같은 캐릭터를 비교할 때 구슬 최고점~발바닥 높이를 같은 픽셀 높이로 정규화한다. 가로·세로를 따로 늘려 맞추지 않는다.
- 얼굴 윤곽, 귀 부착점·끝점, 몸통 좌우 폭, 발바닥, 구슬 경계를 원본과 나란히 또는 투명 겹침으로 비교한다.
- 귀 너비/머리 너비, 몸통 너비/머리 너비, 구슬 지름/전체 키를 기록한다. 정확한 경계가 가려졌다면 가려진 위치를 기록하고 실측 확정값으로 단정하지 않는다.
- 키 차이는 같은 축척과 바닥선에서 105/103으로 비교한다. 이는 단독 이미지의 실루엣 정규화와 다른 검사다.
- 색감은 원본의 몸 앞면 중간톤·음영·광택을 함께 비교한다. 조명 영향을 받는 한 점의 HEX만 일치시켜 통과시키지 않는다.
- 수치가 맞더라도 귀 끝 모양·볼륨·표면이 다르면 불합격이다. 반대로 이미지 생성 실패만으로 기존 원본 측정값이 틀렸다고 단정하지 않는다.

### v3 변경 이력

| 항목 | v2에서의 문제 | v3 수정 |
|---|---|---|
| 원본 우선순위 | 숫자·추상적인 형용사가 원본보다 강하게 작용할 수 있음 | 시점별 원본 보드를 고정 기준으로 명시 |
| 체형 | 통통함의 범위가 모호함 | 작은 짧은 몸통, 원본보다 배·볼·어깨·팔다리 팽창 금지 |
| 대키미 귀 | 삼각형이라는 설명만으로 두껍고 뭉툭해질 수 있음 | 끝으로 좁아지는 윤곽·테두리 두께를 원본과 비교 |
| 외지몽 귀·구슬 | 원본보다 커진 출력이 발생 | 원본의 상대 크기와 부착 위치·끝점으로 검수 |
| 질감 | 매끄러움만 강조되어 고무 같은 표면으로 변함 | 원본의 낮은 몸 광택·부드러운 표면과 검정 눈 광택 분리 |
| 색감 | 대표 HEX만으로 화면 색감이 고정된다고 오해할 수 있음 | 대표색 유지 + 원본의 중간톤·조명·대비 동시 비교 |
| 입체 치수 | 미검증 지정값이 확정 도면으로 사용될 수 있음 | 기존 수치를 보존하되 원본보다 우선하지 않는 참고값으로 명시 |
| 프롬프트 | 많은 수치와 포괄적인 치비 표현에 의존 | 원본 재현 중심 고정 문장과 장면 문장을 분리 |

기존 전체 키·색상 코드·안테나 개수·눈 하이라이트 개수·기본 홍조 규칙·주둥이 색상 규칙은 유지했다. 대키미 꼬리를 외지몽보다 반드시 굵다고 서술한 문장은 기존 두께 표와 충돌하여 원본 굵기 유지로 정리했다. PART별 IP 가이드라인 원문 파일은 수정하지 않았다.
